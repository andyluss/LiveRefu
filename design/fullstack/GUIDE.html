Framework GUIDE · Features & Usage

TypeScript + Web 基础，
变成全栈默认路

青橙全栈（QC Stack）是一个 Web 优先、HTML-first、可替换依赖的应用框架。会用 TypeScript、HTML/CSS 和基本 HTTP，就能做网站、后台、API 与大部分应用服务端；需要时随时接管底层。

01 / Four words

先学四个词，剩下的框架替你决定

page

用户看到什么。`load` 读数据，`render` 返回 HTML。

action

用户提交什么。自动解析表单、校验、CSRF、重定向。

table

数据长什么样。SQLite schema + SQL 迁移，不靠运行时自动改表。

auth

谁能做什么。session、密码、角色、OAuth adapter。

建页面

文件即路由：`app/pages/index.page.ts` → `/`。

建动作

`app/actions/notes/create.action.ts` → `/actions/notes/create`。

建表

`app/data/migrations/*.sql`；`qc db migrate` 应用。

起服务

`qc dev` 开发；`qc build` + `qc start` 生产。

02 / Code

一个页面，一个动作

// app/pages/index.page.ts import { definePage, html } from '@qingcheng/qc' export default definePage({ auth: 'required', load({ db, user }) { return { notes: db.query( 'select * from notes where user_id = ?', [user.id]) } }, render({ notes }, ctx) { const csrf = ctx.auth.csrfField(ctx.session) return html\` <form method="post" action="/actions/notes/create"> \${csrf} <input name="title" required> <button>创建</button> </form> \${notes.map(n => html\`<h2>\${n.title}</h2>\`)} \` }, })
// app/actions/notes/create.action.ts import { defineAction, redirect, object, string } from '@qingcheng/qc' export default defineAction({ auth: 'required', input: object({ title: string({ min: 1, max: 120 }), body: string({ min: 1, max: 10000 }), }), handle({ input, db, user }) { db.insert('notes', { title: input.title, body: input.body, user_id: user.id, created_at: nowIso(), }) return redirect('/') }, })

04 / Capabilities

全栈默认路，按需升级

01
Routing

文件即路由

page / action / api；`[id]` 参数；静态优先；404/405。

02
Rendering

HTML-first + islands

服务端 HTML、真实表单；需要交互时局部挂载；不强制 SPA。

03
Data

SQLite + SQL 迁移

参数化、事务、insert、迁移表；复杂查询直接 SQL。

04
Auth

Session / scrypt / CSRF

HttpOnly cookie、密码哈希、角色、CSRF、`auth: 'required'`。

05
Validation

同步/异步 schema

`object/string`；`fromStandard`；`Action.onError` 回填。

06
Mail

console/file/memory/API/SMTP

密码重置、邮箱验证；token 哈希/一次性；SMTP 隐式 TLS。

07
OAuth

OAuth/OIDC + PKCE

state、token、userinfo、refresh、撤销、token AES-GCM。

08
Storage

Local / Memory / S3

签名 PUT/DELETE、预签名 GET、multipart、checkpoint、校验和、扫描钩子。

09
Ops

Bundle / health / backup

`qc build`、`/health`、request id、JSON 日志、`qc db backup/restore`。

06 / Design system

界面不是另起一套，是 LRDS

全栈 UI 复用青橙设计系统的语义 token、字号、间距、圆角与焦点规则；`design/kits/` 是介质接入包，全栈是装配线。

--lr-color-action-primary
--lr-color-feedback-warning
--lr-color-feedback-danger
--lr-color-focus-ring

硬规则

  • 面板 8px、控件 4px，不用大圆角。
  • 焦点环必须可见；对比度不靠肉眼。
  • 语义 token 优先，不写裸色值。
  • 风格卡可换，理解方式不换。

07 / Limits

能做什么，不能假装做什么

DONE

Web 全栈

路由、HTML、SQLite、auth、校验、bundle、日志、备份、mail、OAuth、S3、dogfood。

PARTIAL

分发 / 运行时

`qc new` 本地 file/symlink；HMR 整页刷新；npm 未发布；SMTP 无 STARTTLS/DKIM。

EXTERNAL

发布 / 扫描

npm registry、真实 SMTP、ClamAV/图片解码、Postgres/多端 adapter。
