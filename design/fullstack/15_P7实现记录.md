## 三、API 形状

```ts
const auth = createAuth(db, {
  ...
  oauth: {
    github: {
      authorizationUrl: 'https://github.com/login/oauth/authorize',
      tokenUrl: 'https://github.com/login/oauth/access_token',
      userInfoUrl: 'https://api.github.com/user',
      clientId: env('GITHUB_ID'),
      clientSecret: env('GITHUB_SECRET'),
      scope: 'read:user user:email',
    },
  },
  mail: {
    transport: 'api',
    from: 'no-reply@example.com',
    endpoint: 'https://mail.example/send',
    token: env('MAIL_TOKEN'),
  },
}, mailer, { fetch })
```

应用侧需要加两个路由：开始授权（`oauthStart` + redirect）和回调（`oauthCallback` + setCookie）。P8 会提供通用路由。

## 五、安全说明

- OAuth state 存 DB、10 分钟、一次性；回调校验 provider + redirect_uri。
- 没有 PKCE；公共客户端/移动端接入前必须补。
- OAuth 建号依赖 userinfo 的 email；没有邮箱时拒绝。
- 测试用 fake fetch；真实 IdP 的字段差异需要 provider 映射（P8）。
- API 邮件 token 从 env/config 读取；不要写仓库。
