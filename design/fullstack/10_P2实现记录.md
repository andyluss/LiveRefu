## 一、做了什么

| 能力 | 实现 | 备注 |
| --- | --- | --- |
| Session | `qc_sessions` + HttpOnly/SameSite/Lax cookie | 匿名 session 提供 CSRF token；登录后轮换 |
| Password | Node `scrypt` + salt + timing-safe 比较 | 无外部依赖；不是 argon2，后续可换 adapter |
| CSRF | 表单 `_csrf` / header `x-csrf-token` | 所有 action 在 auth 启用时校验 |
| 用户/角色 | `qc_users` + `role`；`auth: 'required'` | 注册默认 `user`；admin 角色待后台 |
| 校验 | `object/string` + `ValidationError` | 422 错误页；表单回填仍待完善 |
| 安全头 | CSP/nosniff/frame/referrer/permissions | 默认值；CSP 允许内联 style |
| 限流 | 内存窗口 | 登录/注册 5 次/分钟/IP |
| 请求体上限 | 2 MiB（`content-length` + 流式累计） | 文件上传另做 |
| Dogfood | notes 注册/登录/个人笔记/删除/退出 | 每个用户只看到自己的笔记 |
| 测试 | 2 个测试（HTML + 完整 auth CRUD） | 通过 |

## 三、API 形状

```ts
export default definePage({
  auth: 'required',
  load({ db, user }) {
    return { notes: db.query('select ... where user_id = ?', [user!.id]) }
  },
  render(data, ctx) {
    const csrf = ctx.auth!.csrfField(ctx.session!)
    return html`<form method="post" action="/actions/notes/create">${csrf}...</form>`
  },
})

export default defineAction({
  auth: 'required',
  input: object({
    title: string({ min: 1, max: 120, label: '标题' }),
  }),
  handle({ input, db, user }) {
    db.insert('notes', { title: (input as any).title, user_id: user!.id })
    return redirect('/')
  },
})
```

## 四、和文档的差异（诚实边界）

| 项 | P2 实际 | 后续 |

## 五、安全说明

- `secureCookie` 在示例里是 **false**（本地 HTTP）；生产必须 HTTPS + true。
- CSRF token 存在 session 表；XSS 仍能读页面里的 token，所以输出转义/依赖治理同样重要。
- 没有邮箱验证/账号枚举防护的完整策略；登录错误统一为“邮箱或密码错误”。
- 没有审计日志/会话管理 UI；P3 补。
