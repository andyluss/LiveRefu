# 03 · 应用契约与开发者体验

> 青橙全栈 · 技术框架提案 ｜ 状态：提案 / 未实现 ｜ 日期：2026-10-26 13:24
> 目标：使用者不需要懂 bundler / HTTP / ORM / session / 部署，也能做出一个完整应用。

## 一、四个词

第一版只要求使用者掌握四个词：

| 词 | 放哪 | 回答 |
| --- | --- | --- |
| **page** | `app/pages/**.page.ts` | 用户看到什么 |
| **action** | `app/actions/**.action.ts` | 用户提交什么 |
| **table** | `app/data/schema.ts` | 数据长什么样 |
| **auth** | `app/auth/config.ts` | 谁能做什么 |

其它（router、session、migration、build、deploy）由框架默认处理。

## 二、命令

```bash
qc new my-app          # 创建应用
qc dev                 # 本地开发
qc build               # 生成可部署产物
qc start               # 启动生产进程
qc db migrate          # 应用迁移
qc db studio           # 本地查看数据（可选）
qc auth add github     # 添加 OAuth provider（可选）
qc test                # 测试
qc typecheck           # 类型检查
qc doctor              # 诊断配置/路由/数据库/产物
qc update              # 升级框架与依赖（带 codemod/迁移提示）
```

设计原则：

- 命令少；默认值清晰；
- 失败时给出“下一步做什么”，不只报错；
- 不要求用户记环境变量/构建参数；
- 不在 `qc dev` 里藏一套和生产不同的逻辑。

## 三、页面

```ts
export default definePage({
  auth: 'optional', // 'public' | 'optional' | 'required' | role
  async load({ db, params, session }) {
    const post = await db.one('select * from posts where slug = ?', [params.slug])
    if (!post) throw notFound()
    return { post }
  },
  render({ post }) {
    return html`
      <article>
        <h1>${post.title}</h1>
        <div>${post.body}</div>
      </article>
    `
  },
})
```

约定：

- `load` 只读，返回 plain data；
- `render` 返回 HTML/Response；
- 不在 render 里查数据库；
- 错误用 `notFound()` / `unauthorized()` / `redirect()`；
- 自动转义；需要 raw HTML 必须显式 `raw()`。

### 3.1 布局与组件

```ts
export default defineLayout(({ children }) => html`
  <html>
    <head><title>My App</title></head>
    <body>
      <header>...</header>
      <main>${children}</main>
    </body>
  </html>
`)
```

- 组件就是返回 HTML 的函数；
- 需要客户端交互时，用 `island()` 挂载；
- UI 直接用 LRDS 的 class/token，不另造视觉语言。

## 四、动作（表单/API）

```ts
export default defineAction({
  input: object({
    title: string().min(1).max(120),
    body: string().min(1),
  }),
  auth: 'required',
  async handle({ input, db, session }) {
    const post = await db.insert('posts', {
      title: input.title,
      body: input.body,
      authorId: session.userId,
    })
    return redirect(`/posts/${post.slug}`)
  },
})
```

- 自动解析 form/JSON；
- 自动校验；错误回填到表单；
- 自动 CSRF；
- 返回 `redirect` / `html` / `json`；
- 未授权/校验失败有默认页；
- 动作可以被 `<form action="/actions/posts/create" method="post">` 直接调用。

### 4.1 错误

```ts
throw validationError({ title: '标题不能为空' })
throw unauthorized()
throw notFound()
throw conflict('slug 已存在')
```

开发环境显示修复建议；生产环境显示 request id + 联系入口。

## 五、数据

```ts
export const posts = defineTable('posts', {
  id: 'integer primary key',
  slug: 'text unique not null',
  title: 'text not null',
  body: 'text not null',
  authorId: 'integer not null references users(id)',
  createdAt: 'text not null',
})
```

```bash
qc db migrate --name add_posts
```

- schema 是 TypeScript/SQL 的混合 DSL，输出 SQL 迁移；
- 迁移文件可读、可审、可回滚（或明确 forward-only）；
- 不做运行时自动改表；
- 复杂查询允许 raw SQL；
- 开发/测试用独立 SQLite 文件；生产可换 Postgres adapter。

## 六、Auth

```ts
export default defineAuth({
  session: { store: 'sqlite', cookie: 'qc_session', maxAge: '30d' },
  password: { min: 10, hash: 'argon2id' },
  roles: ['admin', 'editor', 'user'],
  oauth: {
    github: { clientId: env('GITHUB_ID'), clientSecret: env('GITHUB_SECRET') },
  },
})
```

```ts
const user = await requireUser(ctx)
await requireRole(ctx, 'admin')
```

- 默认 session + password；
- OAuth/OIDC 是可选 adapter；
- 角色是应用层，不写死在框架；
- 不把用户/权限业务塞进核心。

## 七、内置配方（recipes）

第一版提供可复制的“配方”，不是黑箱生成器：

- 列表 + 分页 + 空状态；
- 详情页 + 404；
- 创建/编辑表单 + 校验 + 错误回填；
- 删除 + 确认 + 权限；
- 登录/注册/退出；
- 文件上传（本地/S3 adapter）；
- 邮件（SMTP/adapter）；
- 后台布局 + 导航 + 当前页高亮；
- 健康检查 + 结构化日志。

每个配方包含：代码、说明、可访问性注意、测试。

## 八、开发体验

### 8.1 错误信息

```text
[qc] 页面 app/pages/posts/[slug].page.ts 加载失败
  → 数据库: data/app.db 不存在
  → 修复: 运行 `qc db migrate`
  → 或检查 qc.config.ts 的 db.path
```

- 指向文件/行/命令；
- 不把内部堆栈当唯一信息；
- 给出“最小修复动作”。

### 8.2 诊断

```bash
qc doctor
# 配置 / 路由表 / 数据库连接 / 迁移状态 / session / 构建产物 / 端口
```

### 8.3 测试

```ts
test('create post', async ({ app }) => {
  const res = await app.post('/actions/posts/create', { form: { title: 'Hi', body: '...' } })
  expect(res.status).toBe(303)
})
```

- 内置 HTTP 测试客户端；
- 每个配方带测试；
- `qc test` 可用临时 SQLite；
- 可访问性检查（HTML 结构/标签/焦点）作为推荐项。

## 九、AI 协作

- 文件结构、命令、错误格式稳定；
- `qc docs` / `qc explain <file>` 给出局部说明；
- 生成代码必须过类型/测试/安全闸门；
- 不把“魔法约定”藏在运行时，AI 和人看到同一套规则。

## 十、第一版不承诺

- 多租户/SaaS 计费；
- 实时协作/WebSocket 全家桶；
- 完整 CMS；
- 移动端/游戏/CLI 统一 UI；
- 自动部署到所有云。

先把“一个完整 Web 应用”做对。
