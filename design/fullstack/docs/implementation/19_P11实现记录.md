## 一、做了什么

| 能力 | 实现 |
| --- | --- |
| **预编译包** | `qc pack`：esbuild → `dist/index.mjs`（51K）+ `dist/cli.mjs`（56K） |

| **验证** | `/tmp` 新建应用 → `doctor` 识别 2 路由 → `start` 200 → 创建笔记 303 |

## 二、为什么必须预编译

P10 末尾已实测：Node 24 对 `node_modules` 内的 `.ts` 直接报：

```text
ERR_UNSUPPORTED_NODE_MODULES_TYPE_STRIPPING
```

因此不能把 `@qingcheng/qc` 直接指向 `src/index.ts`。P11 改为：

```text
qc/src/*.ts ──esbuild──► qc/dist/index.mjs
                       └► qc/dist/cli.mjs
```

新应用通过包入口加载 JS；源码仍只用于开发/测试。
