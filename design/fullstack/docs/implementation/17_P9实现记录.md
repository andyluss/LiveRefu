## 一、做了什么

| 能力 | 实现 |
| --- | --- |
| **SMTP** | `mail.transport='smtp'`；`node:net`/`node:tls` 最小客户端，AUTH LOGIN，支持隐式 TLS |
| **存储接口** | `Storage` + `LocalStorage` + `MemoryStorage`；`saveUpload({storage})` |
| **开发自动刷新** | `qc dev` 下 `/__qc/version` + `/__qc/reload.js`；进程重启后浏览器自动刷新 |
| **CI 模板** | `templates/ci.yml`：Node 24、test、build、`/health` smoke |
| **测试** | notes 4 + bookmarks 1 + oauth 1 + oauth routes 1 + smtp 1 = **8/8** |

## 三、API 形状

```ts
// SMTP
mail: {
  transport: 'smtp',
  host: 'smtp.example.com',
  port: 465,
  secure: true,
  user: env('SMTP_USER'),
  pass: env('SMTP_PASS'),
  from: 'no-reply@example.com',
}

// 存储
const saved = await saveUpload(file, {
  dir: 'data/uploads',
  storage: new MemoryStorage(), // 或自定义 Storage
})
```
