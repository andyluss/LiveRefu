## 一、做了什么

| 能力 | 实现 |
| --- | --- |
| **S3 校验和** | PUT/分片请求带 `x-amz-checksum-sha256`（base64） |
| **分片限速** | `uploadLarge({maxPartsPerSecond})` 每片后节流 |
| **上传扫描钩子** | `saveUpload({scan})`；扫描失败即拒绝，不落盘 |
| **测试** | 10/10；S3 校验和断言，上传扫描负向用例 |
