## 一、做了什么

| 能力 | 实现 |
| --- | --- |
| **Mailer** | `console` / `file` / `memory` 三种传输；`auth.mail` 配置 |
| **密码重置** | `qc_password_resets` 表；token 哈希存储、30 分钟、一次性、使用后删除该用户所有 session |
| **页面/动作** | `/forgot`、`/reset`、`/actions/auth/forgot`、`/actions/auth/reset`；CSRF + 表单回填 |
| **StandardSchema** | `fromStandard()` 适配位；同步 validate，映射 issues 到字段错误 |
| **上传** | `saveUpload(file,{dir,maxBytes,types})`；大小/类型限制、随机文件名、目录创建 |
| **测试** | 3/3：StandardSchema+上传、HTML 转义、完整 auth/CSRF/重置/CRUD |

## 五、安全说明

- 重置 token 只存 SHA-256；有效期 30 分钟；一次性；成功后删除该用户所有 session。
- 忘记密码返回统一页面，避免邮箱枚举；实际发送失败只写服务端日志。
- 重置链接的 origin 来自请求；生产要在可信反代后设置 `QC_PUBLIC_ORIGIN`（P6）。
- 上传只校验大小/声明 MIME；**不能替代**病毒扫描/图片解码/对象存储签名（P6）。
- `mail` 默认 console 只适合本地；生产必须接 SMTP/API。
