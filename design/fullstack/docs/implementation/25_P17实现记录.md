## 二、为什么没做剩下三项

| 项 | 阻塞 |
| --- | --- |
| **npm 发布/远程 `qc new`** | 需要 registry、账号/token、公开/私有决定；代码侧已能 `npm pack` |
| **组件级 HMR** | 需要客户端运行时/HMR 协议，是独立工程，不是当前 HTML-first 架构的小改 |
| **SMTP STARTTLS/DKIM** | 需要真实 SMTP 服务/证书/域名；本地 fake 只能验证明文/隐式 TLS |
| **图片解码/病毒扫描** | 需要外部扫描器/解码库；当前只有 `scan` 钩子 |

这些不是“再写一点代码”能诚实完成的；用空壳实现会破坏“禁止伪造信号”的原则。
