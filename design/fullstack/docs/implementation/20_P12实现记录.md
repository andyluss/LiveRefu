## 一、做了什么

| 能力 | 实现 |
| --- | --- |
| **S3 预签名** | `presignGet(key, seconds)`：SigV4 query 签名，GET 临时 URL |
| **S3 删除** | `delete(key)`：SigV4 DELETE |
| **OAuth Refresh** | `oauthRefresh(provider,userId)`：用 refresh_token 换新 access_token，更新表 |
| **测试** | 仍为 9/9；S3/OAuth 测试扩展覆盖 presign/delete/refresh |

## 二、验证

```bash
node --experimental-strip-types design/fullstack/qc/test/s3.test.ts
# ✔ S3 storage: SigV4 PUT（含 presign/delete）

node --experimental-strip-types design/fullstack/qc/test/oauth.test.ts
# ✔ OAuth/OIDC: state + token + userinfo + session（含 PKCE/refresh）
```

- presign：断言 `X-Amz-Signature` 和 `X-Amz-Expires`；
- delete：断言 `DELETE` + Authorization；
- refresh：fake token endpoint 返回 `refreshed-token`，断言 refresh 请求体。
