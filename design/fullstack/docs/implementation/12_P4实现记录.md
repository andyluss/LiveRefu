## 一、做了什么

| 能力 | 实现 |
| --- | --- |
| **Request ID** | 每个响应带 `x-request-id`；客户端传入则复用 |
| **结构化日志** | `QC_LOG_FORMAT=json` 时输出 `{time,requestId,method,path,status,ms}` |
| **健康检查** | `/health` 已含 DB 检查（P3） |
| **SQLite 备份** | `qc db backup [file]`（`node:sqlite` backup，WAL 安全） |
| **SQLite 恢复** | `qc db restore <file> --force`（覆盖当前 DB，清理 -wal/-shm） |
| **Docker 模板** | Node 24 slim、非 root、`/data` 卷、healthcheck、`server.mjs` |
| **Compose 模板** | `app-data` 卷、`QC_DB_PATH=/data/app.db` |

## 三、部署模板

见 [`templates/README.md`](../../templates/README.md)：

```bash
qc build
docker build -t my-app -f /path/to/qc/templates/Dockerfile dist
docker run -p 3000:3000 -v my-data:/data -e QC_DB_PATH=/data/app.db my-app
```

- `dist/` 作为构建上下文；`Dockerfile` 只复制产物，不复制源码/`node_modules`。
- 数据库必须挂载 `/data`；否则容器重启丢数据。
- 生产必须 HTTPS + `secureCookie: true`。
