## 一、做了什么

| 能力 | 实现 |
| --- | --- |
| **S3 兼容存储** | `S3Storage`：SigV4 PUT、path-style、content-type、session token；可注入 fetch |
| **OAuth PKCE** | `OAuthProvider.pkce`：S256 challenge/verifier，state 表存 verifier，回调带 `code_verifier` |
| **测试** | notes 4 + bookmarks 1 + OAuth 1 + OAuth 路由 1 + SMTP 1 + S3 1 = **9/9** |

## 二、验证

```bash
node --experimental-strip-types design/fullstack/qc/test/s3.test.ts
# ✔ S3 storage: SigV4 PUT

node --experimental-strip-types design/fullstack/qc/test/oauth.test.ts
# ✔ OAuth/OIDC: state + token + userinfo + session
```

- S3：断言 URL、`AWS4-HMAC-SHA256`、payload hash；
- PKCE：授权 URL 带 `code_challenge`/`S256`，token 请求带 `code_verifier`；
- 不依赖真实 S3/IdP。

## 三、API 形状

```ts
const storage = new S3Storage({
  endpoint: 'https://s3.example',
  region: 'ap-east-1',
  bucket: 'uploads',
  accessKeyId: env('S3_KEY'),
  secretAccessKey: env('S3_SECRET'),
})

await saveUpload(file, { dir: 'unused', storage })

oauth: {
  github: { ...githubProvider(id, secret), pkce: true },
}
```
