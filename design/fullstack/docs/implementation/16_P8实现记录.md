## 二、验证

```bash
node --experimental-strip-types design/fullstack/qc/test/oauth-routes.test.ts
# ✔ OAuth 通用路由：开始与回调

node --experimental-strip-types design/fullstack/qc/test/oauth.test.ts
# ✔ OAuth/OIDC: state + token + userinfo + session
```

OAuth 路由测试覆盖：

- `GET /api/auth/oauth/test` → 303 到 IdP，带 state；
- `GET /api/auth/oauth/test/callback?code=...&state=...` → token + userinfo + session cookie；
- 用户写入 `qc_users`；
- 全流程 fake fetch，无外网。

## 三、API 形状

```ts
// app/auth/config.ts
import { githubProvider } from '../qc.ts'

export default {
  oauth: process.env.GITHUB_ID
    ? { github: githubProvider(process.env.GITHUB_ID, process.env.GITHUB_SECRET!) }
    : {},
}
```

```text
GET /api/auth/oauth/github
GET /api/auth/oauth/github/callback?code=...&state=...
```
