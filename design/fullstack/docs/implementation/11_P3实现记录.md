## 一、做了什么

| 能力 | 实现 |
| --- | --- |
| **真 bundle** | esbuild 打包 `dist/server.mjs`（42 KB）+ sourcemap；Node 24 运行 |
| **路由打包** | 构建时生成 routes manifest，page/action/api 作为静态 import 打包，不依赖运行时源码扫描 |
| **`qc start`** | 自动识别 `dist/server.mjs`；`qc start` / `qc start dist` 均可启动 bundle |
| **表单错误回填** | `Action.onError` + 共享 auth form；422 时保留邮箱、显示字段错误 |
| **健康检查** | 内置 `GET /health`：`{ ok, uptime, db }`；DB 失败返回 503 |
| **配置传入** | bundle 内嵌 `qc.config.ts`/layout/auth config；运行时不再动态读这些源码 |
| **迁移/静态资源** | `dist/app/data/migrations` + `public/` 复制；`dist/qc-manifest.json` |

## 二、验证

```bash
cd design/fullstack/examples/notes
node --experimental-strip-types ../../qc/src/cli.ts build
# ✓ bundle 到 dist/server.mjs（9 条路由）

node --experimental-strip-types ../../qc/src/cli.ts start
# 自动使用 dist/server.mjs
# GET /health → 200 {"ok":true,"uptime":2,"db":"ok"}
# GET / → 303 /login
# GET /register → 200
# 短密码注册 → 422，回填 email + 显示“至少 8 个字符”
```

集成测试仍为 **2/2 通过**：HTML 转义 + 注册/登录态/CSRF/个人笔记/删除/退出。

## 三、和文档的差异

| 项 | P3 实际 | 后续 |
| --- | --- | --- |
| bundle | ✅ esbuild，但 `node:sqlite` 仍为外部平台 API | 跨 Node 版本测试 |
| `qc start dist` | ✅ | 生产数据库默认在 `dist/data`；需 `QC_DB_PATH` 指持久盘 |
| 表单回填 | ✅ 仅 auth 表单；notes 表单仍是 422 通用页 | 抽成通用 form helper |
| 部署 | ❌ 没有 Docker/备份/日志轮转 | P4 |
| 邮件/密码重置/OAuth | ❌ | P4 |
| 上传 | ❌ 只有 2 MiB 请求体上限 | P4 |
| 管理后台 | ❌ | P4 |
| `qc new` | 仍是本机绝对 bridge | P4 包导入 |
| HMR | 仍整进程重启 | P4 |
