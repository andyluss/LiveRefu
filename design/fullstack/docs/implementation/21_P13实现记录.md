## 一、做了什么

| 能力 | 实现 |
| --- | --- |
| **S3 multipart** | `createMultipart` / `uploadPart` / `completeMultipart` / `abortMultipart`；SigV4 请求 |
| **OAuth 并发锁** | `qc_oauth_tokens.refreshing`；刷新先抢占，busy 返回 409 |
| **OAuth 撤销** | `revokeOAuth(provider,userId)` 删除 refresh/access token |
| **CI** | `.github/workflows/qc.yml`：Node 24 跑 6 个测试文件 |
| **测试** | 9/9；S3/OAuth 测试扩展 multipart、撤销 |

## 二、验证

```bash
node --experimental-strip-types design/fullstack/qc/test/s3.test.ts
# ✔ S3 storage: SigV4 PUT（含 multipart）

node --experimental-strip-types design/fullstack/qc/test/oauth.test.ts
# ✔ OAuth/OIDC: state + token + userinfo + session（含 refresh/revoke）
```

- multipart：fake S3 返回 UploadId/ETag，覆盖 create/upload/complete/abort；
- refresh：抢占 `refreshing`，完成后释放；撤销后再刷新失败；
- CI：6 个测试文件按顺序跑，Node 24。
