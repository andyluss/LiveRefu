## 三、推荐的“最小可决策集”

如果你只想先拍最关键的五项：

1. **F2 薄核心 + adapter**；
2. **F3 Node 第一、Bun 可选**；
3. **F4 HTML-first + islands**；
4. **F5 SQLite + SQL-first**；
5. **F10 先做一个小型内容/后台 dogfood**。

这五项定了，P1 就可以开始；其余可以边做边定。

## 四、如果“按推荐”

则 P1 的范围是：

- `qc new/dev/build/start`；
- 文件路由 + page/action；
- SQLite + schema/migration；
- HTML 布局 + 表单；
- 错误页/日志/doctor；
- 一个“笔记/文章 + 登录 + 后台”最小应用；
- Node 生产启动 + 测试；
- 不碰移动/游戏/CLI/多租户。
