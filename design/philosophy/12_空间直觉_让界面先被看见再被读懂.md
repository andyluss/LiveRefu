## 一、人不是先读界面，人先读空间

想象你走进一个陌生房间。你还没有读任何标签，就已经知道：

- 门在哪一边；
- 哪里是中心，哪里是边缘；
- 什么东西离你近，什么东西需要绕过去；
- 哪块区域看起来可以坐，哪块区域看起来不能碰；
- 哪条路通向别处，哪里是尽头；
- 这个空间是开阔的还是压迫的。

这不是“审美”，而是**空间直觉**：人类在没有文字、没有说明书的条件下，仍然能从位置、方向、距离、边界、遮挡、尺度和动势中快速推断关系。

界面设计经常忘记这一点。我们把世界压成列表、表格、折叠面板和设置页，然后要求用户读标签、记路径、理解层级。用户当然能学会，但学习成本很高；更糟的是，学会之后，他们仍然很难在脑中形成一张**可用的地图**。

空间直觉要做的，不是把界面做成 3D 游戏，也不是复古拟物，而是：

> **利用人已经具备的空间认知能力，让关系先被看见，再被读懂。**

## 二、空间直觉不是一种风格

“空间感”常被误解为：

- 大留白；
- 卡片阴影；
- 3D 透视；
- 视差滚动；
- 玻璃拟态；
- 深色背景加发光线条。

这些最多是空间的**视觉暗示**，不保证空间**可读**。一个看起来很深的界面，可能仍然让用户不知道自己在哪、下一步去哪、什么和什么有关系。

真正的空间直觉至少包含五种能力：

1. **预注意（pre-attentive）**：在意识到之前，颜色、大小、方向、位置已经让人注意到差异；
2. **格式塔（Gestalt）**：接近、相似、连续、闭合、共同命运，让人自动分组；
3. **可供性（affordance）**：形状与位置暗示“可以推、可以拉、可以打开、可以放下”；
4. **心理地图（mental map）**：人能记住“东西大致在哪”，而不是记住每一个坐标；
5. **身体尺度**：远近、轻重、阻挡、容纳，和身体经验直接相关。

设计可以利用这些能力，也可以违背它们。违背的代价不是“不好看”，而是用户必须用工作记忆去替代空间记忆。

## 三、为什么空间直觉有效

### 1. 它是并行处理

读一个词是串行的：一个字接一个字。看一个空间关系是并行的：左边、右边、里面、外面、近处、远处，可以同时进入注意。

这就是为什么一张好的地图能在一秒内回答“我在哪、我要去哪、还有多远”，而一张列表需要读很多行。

### 2. 它把关系外化

工作记忆容量有限。空间把关系放到外部世界：

- “这两个东西相关”可以表现为放在同一个容器里；
- “这个流程有先后”可以表现为从左到右、从上到下；
- “这个层级更深”可以表现为缩进、嵌套、进入另一层；
- “这个状态更紧急”可以表现为靠近视线中心、变大、变亮、出现动势。

用户不需要在脑中维持这些关系，空间替他们维持。

### 3. 它利用空间记忆

人记“钥匙在门口左边的柜子上”比记“钥匙在第三个抽屉的第二层”更容易。空间记忆不是精确坐标，而是**相对关系 + 地标 + 路径**。

界面如果提供稳定的地标、稳定的区域和可重复的路径，用户就能形成心理地图；如果每次打开都换位置、换分组、换顺序，用户就只能每次重新扫描。

### 4. 它让行动先于解释

空间直觉常常先给出行动线索：门把手让你想拉，斜坡让你想走，边缘让你想停。界面里的按钮、轨道、画布、时间轴、地图，也可以让“下一步”先于说明出现。

这不是说不要标签。标签负责确认，空间负责引导；两者不是替代关系。

## 四、把空间直觉转译成界面

### 1. 位置就是关系

- 相近 = 相关；
- 同容器 = 同类；
- 上下 = 层级或时间；
- 左右 = 并列、对照、前后；
- 中心 = 当前重点；
- 边缘 = 次要、辅助、可退出；
- 距离 = 关联强度或成本。

但位置不是任意的。把“删除”放在“保存”旁边，就是在用空间暗示危险与安全的错误关系。

### 2. 方向就是路径

人会自动寻找“入口—路径—出口”。界面需要回答：

- 我从哪里进来？
- 我现在在哪一段？
- 前面还有多远？
- 我可以回头吗？
- 哪里可以离开？

面包屑、步骤条、时间轴、地图路线、滚动进度，都是方向的具体化。没有方向的界面，用户会不断问“然后呢”。

### 3. 尺度就是优先级

大小、密度、留白、字体粗细，会形成视觉重量。重要的东西不一定最大，但**空间上占主导的东西会被认为更重要**。

如果一个设置页每个选项都一样大、一样密，用户就无法从空间上判断“先做什么”。层次不是把东西变小，而是让大小与重要性一致。

### 4. 边界就是分组

容器、卡片、分隔线、背景色、圆角、阴影，都是边界。边界告诉用户“里面是一组”“外面是另一组”“这个边界可以穿过/不能穿过”。

边界过多会让界面变成监狱；边界过少会让所有东西糊成一团。好的边界是**刚好足以解释关系**，而不是装饰。

### 5. 深度就是层级

遮挡、模糊、明度、透视、阴影可以表达前后关系。深度用得好，用户能理解“这是覆盖层”“这是背景”“这是下一层”；用得不好，用户会误以为所有东西都在同一平面。

深度不是“更酷”，而是**层级关系的视觉语法**。如果深度不能对应真实层级，它就是噪音。

### 6. 动势就是注意

运动、方向线、渐变、透视消失点，会引导视线。动势可以用来提示“接下来看这里”“这里正在变化”，也可以制造焦虑。

青橙对动势的要求是：**动势必须对应真实状态变化，并且提供关闭/降级选项。** 不是所有变化都值得动。

## 五、空间直觉的边界

### 1. 空间隐喻可能错位

“桌面”“文件夹”“回收站”是成功的空间隐喻，但不是所有东西都能空间化。把“权限”“隐私”“时间”硬做成房间和门，可能让用户误以为它们真的可以被“走进去”。

### 2. 文化差异

左右方向、阅读顺序、颜色含义、地图习惯都不是普世的。空间设计要避免把某一种文化直觉当成人类直觉。

### 3. 无障碍

空间直觉高度依赖视觉。必须提供：

- 可读的文本结构；
- 屏幕阅读器可理解的顺序；
- 不依赖颜色/位置/运动的替代信息；
- 键盘可达的路径；
- 缩放与高对比度支持。

空间不是视觉特权的借口。

### 4. 小屏与低精度

在小屏、触屏、低精度输入下，空间关系会被压缩。移动端不是把桌面地图缩小，而是重新决定哪些关系必须保留、哪些可以折叠。

### 5. 数据映射失真

把数据映射到位置、面积、角度、颜色时，要防止“看起来更大”被误读为“真的更大”。空间编码必须诚实，尤其是面积和体积。

### 6. 3D 不是自动更好

3D 增加深度，也增加遮挡、导航成本与眩晕风险。只有当第三维承载真实信息时，3D 才值得。

## 六、青橙的空间原则

### 1. 先可感，再可读

空间应该让状态先被注意到，再让数字和标签被读到。两者都要有。

### 2. 先关系，再装饰

每个位置、边界、方向、深度都应该回答一个关系问题。回答不了，就删掉。

### 3. 地图必须诚实

空间位置不能伪造优先级、不能隐藏代价、不能把不确定性画成确定。地图不是广告。

### 4. 保留退路

用户可以在空间里迷路，但必须能回到已知地标、切换到列表、搜索、撤销、退出。

### 5. 允许多种空间

不同世界可以有不同空间语法：地图、控制台、档案柜、工作台、沙盘。共享的是空间认知原则，不是同一种布局。

## 七、怎么验证空间设计有没有用

| 测试 | 问什么 | 观察什么 |
| --- | --- | --- |
| 五秒测试 | 第一眼看到什么？ | 视觉重心是否与任务重点一致 |
| 盲图测试 | 关掉界面后，能画出大致布局吗？ | 是否有稳定地标与区域 |
| 找路测试 | 从 A 到 B 怎么走？ | 是否需要反复读标签 |
| 回忆测试 | 昨天那个功能在哪？ | 位置记忆是否形成 |
| 破坏测试 | 把顺序打乱，用户是否崩溃？ | 空间关系是否真的承载意义 |
| 无障碍测试 | 不用视觉/颜色/鼠标还能用吗？ | 是否有等价信息与路径 |
| 规模测试 | 内容翻十倍，地图还成立吗？ | 是否依赖固定坐标 |
| 退出测试 | 迷路后能否回到已知点？ | 是否有搜索、首页、撤销、面包屑 |

## 八、一个例子：从列表到空间

假设一个生活应用有 16 个入口。列表版：

```text
记账 / 睡眠 / 饮食 / 运动 / 阅读 / 居住 / 穿着 / 饮水
写作 / 观看 / 倾听 / 学习 / 出行 / 照料 / 整理 / 交流
```

用户需要读 16 个词，逐个判断“我现在要哪个”。

空间版：

- 把“日常维持”放在左上区域；
- 把“输入/学习”放在中间；
- 把“输出/创作”放在右下；
- 把“关系/交流”放在边缘；
- 用大小表达使用频率；
- 用位置稳定性建立记忆；
- 保留搜索与列表作为退路。

这不是把 16 个入口做成 16 个漂亮卡片，而是让用户在一周后仍然记得“喝水在左上角、写作在右下角”。**空间把选择变成位置记忆。**

## 九、检查表

- [ ] 这个布局在回答什么关系问题？
- [ ] 位置、距离、方向、边界、深度是否与真实关系一致？
- [ ] 用户能否在五秒内说出“这是哪、下一步去哪”？
- [ ] 关掉界面后，用户能画出大致地图吗？
- [ ] 是否有稳定的地标、区域与路径？
- [ ] 空间是否只服务视觉，而牺牲了可读与无障碍？
- [ ] 迷路后能否回到已知点、切换列表、搜索、退出？
- [ ] 内容规模变化后，空间是否仍然成立？
- [ ] 这个空间是在揭示代价，还是在掩盖代价？

## 十、结语

空间直觉不是让界面“更有感觉”，而是承认人本来就用身体、位置和关系理解世界。

好的空间设计不要求用户先学会一套抽象规则，再开始使用；它让关系先被看见，让行动先有方向，让记忆有地方落脚。

> **先让界面像一个可以理解的空间，再让它像一个可以阅读的文档。**

这也是青橙“可感”的另一面：不是把数字变成装饰，而是把关系放回人能够直接感知的位置。
