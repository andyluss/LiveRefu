# 01 · 未来考古：复古未来不是怀旧

> 上一篇：[00 总纲](00_总纲_青橙设计.md) ｜ 下一篇：[02 可感](02_可感_从数字到现象.md)

## 一、未来不是年份，是想象

我们习惯把“未来”说成一个年份：2027、2035、2050。

但在设计里，未来更像一种**想象的结构**：

- 我们相信技术会往哪走；
- 我们相信社会会变成什么样；
- 我们相信哪些东西会消失、哪些会留下；
- 我们相信“更好的生活”长什么样。

复古未来主义之所以迷人，不是因为它“旧”，而是因为它保留了**过去的人对未来的想象**。

那些想象有的实现了，有的失败了，有的被资本收编，有的被遗忘。它们像地层一样堆在今天下面：

- 一层是 1950 年代的原子能乐观；
- 一层是 1970 年代的太空计划与塑料乌托邦；
- 一层是 1980 年代的 CRT、磁带、霓虹与个人电脑；
- 一层是 1990 年代的互联网承诺与千禧年焦虑；
- 一层是 2000 年代后的扁平化、极简、玻璃、云。

**未来考古**，就是把这些地层挖开，看当时的人相信了什么、谁为这种相信付了钱、谁被排除在外、为什么后来放弃了。

这不是怀旧。怀旧问的是“能不能回到那个时候”；考古问的是“那个时候的人为什么那样想，我们今天还在不在那个想法里”。

## 二、三种未来考古

### 2.1 被放弃的未来

有些未来不是“没实现”，而是“被放弃”：

- 社区能源、公共计算、开源硬件、太空居住、核能城市、个人飞行器；
- 有些是技术不成熟，有些是资本不划算，有些是政治选择。

被放弃的未来最值得考古，因为它们提醒我们：**今天的选择不是唯一可能。**

青橙对这类未来有兴趣，不是要“复古”，而是要把“另一种可能”重新放回桌面。

### 2.2 被商品化的未来

另一些未来被做成了商品：

- 复古霓虹、CRT 滤镜、像素风、蒸汽波、赛博朋克霓虹；
- 它们把“未来”变成一种可消费的氛围，却剥离了当时的政治、劳动与技术条件。

被商品化的未来不是不能使用，而是不能只使用它的皮。

如果青橙只做“CRT 扫描线 + 青橙渐变 + 故障艺术”，它就会变成另一种“未来皮肤”，而不是未来考古。

### 2.3 被压扁的未来

还有一种未来，被压扁成单一叙事：

- 未来 = 更快的芯片、更大的屏幕、更多的自动化；
- 未来 = 赛博朋克霓虹；
- 未来 = 太阳朋克田园；
- 未来 = 某种意识形态的必胜。

被压扁的未来没有“选择”，只有“趋势”。青橙要做的，是把被压扁的未来重新打开：

- 技术可以有不同组织方式；
- 城市可以有不同尺度；
- 生活可以有不同节奏；
- 游戏/科幻可以展示不同结局。

## 三、怀旧与考古的分界线

| 怀旧 | 未来考古 |
| --- | --- |
| “过去更好” | “过去的人相信什么” |
| 把旧物当滤镜 | 把旧物当证据 |
| 消除当时的矛盾 | 展示当时的矛盾 |
| 让观众感到安全 | 让观众感到问题 |
| 回到一个从未存在的天堂 | 打开一个被关闭的可能性 |

怀旧不是罪。人需要安慰，需要熟悉感，需要“旧物的温度”。但如果一个作品只提供安慰，它就不是未来考古，而是未来麻醉。

青橙不拒绝怀旧，它要求怀旧**诚实**：

- 这个“旧”是谁的旧？
- 谁在那个时代被排除？
- 那种技术依赖了谁的劳动？
- 那种乐观建立在什么代价上？
- 我们今天还在不在那个结构里？

## 四、物质文化：未来是有重量的

未来考古不能只做“视觉风格”，要做**物质文化**。

- **材料**：塑料、搪瓷、镀铬、胶木、纸张、玻璃、橡胶、铝；
- **工艺**：注塑、冲压、丝印、胶印、烤漆、拉丝；
- **使用痕迹**：磨损、泛黄、划痕、补丁、贴纸、手写标签；
- **维修**：可拆、可换、可校准、可退；
- **声音**：继电器、风扇、磁带、CRT 的高频、键盘的段落感；
- **文档**：说明书、保修卡、登记表、档案号、盖章、手写批注。

这些细节不是“氛围”，它们是**证据**：

- 这个未来用什么材料？材料从哪来？
- 这个设备谁维护？坏了怎么办？
- 这个界面为什么长这样？它继承了哪种旧媒介？
- 这个“旧”是使用过的旧，还是做旧的旧？

青橙的视觉语言里，Archive（档案纸、油墨、登记章）与 Console（屏幕、仪表、扫描线）之所以能并存，不是因为它们“好看”，而是因为它们代表两种**人与系统的关系**：

- Archive：记录、归档、可翻阅、可批注、可保存；
- Console：监控、操作、反馈、实时、可干预。

好的复古未来，不是把两者贴在一起，而是让它们发生关系：

- 一张纸质档案，记录的是屏幕里的系统状态；
- 一个仪表盘，保留着手写标签与维修记录；
- 一个未来设备，外壳是旧的，内部是新的，接口是妥协的。

## 五、对青橙设计的含义

### 5.1 设计要能“被时间使用”

青橙不追求“全新感”，而追求“时间感”：

- 组件要能承受长期使用：可维护、可替换、可升级；
- 视觉要能容纳磨损：不是一脏就难看，而是越用越有痕迹；
- 系统要能保留历史：版本、档案、迁移记录、旧接口；
- 产品要能“退役”：不是无限增长，而是有结束、有回收、有纪念。

### 5.2 风格卡要有来源

每一种风格卡都应该能回答：

- 它借的是哪个时代、哪种材料、哪种媒介？
- 它保留了哪些真实细节，省略了哪些代价？
- 它的“旧”是证据还是装饰？
- 它与青橙的共同语法是什么？

风格卡不是“换色”，而是“换一段未来考古的切片”。

### 5.3 游戏/科幻是未来考古的实验室

游戏和科幻最适合做未来考古，因为它们可以：

- 建造一个完整世界，让玩家在其中生活；
- 展示一个未来的日常物件、制度、空间与劳动；
- 让玩家发现“这个未来是怎么来的”；
- 让玩家体验“如果当时选了另一条路会怎样”。

《未来残片》这样的项目，名字本身就带着青橙的考古态度：不是“未来会怎样”，而是“未来破碎之后，留下了什么”。

游戏里的“残片”可以是：

- 一张旧卡；
- 一段损坏的录音；
- 一个被弃用的界面；
- 一座废弃的能源塔；
- 一本维修手册；
- 一条被删除的法规。

这些残片不是收集品，而是**证据**。玩家通过它们拼出一个未来，也拼出这个未来的代价。

## 六、风险：别把考古做成怀旧消费

### 6.1 过去滤镜

把过去做成“更简单、更温暖、更真实”的滤镜，会掩盖过去的问题：

- 那时的性别、阶级、殖民、劳动；
- 那时的技术排斥；
- 那时的环境代价。

青橙的复古未来必须能看见“谁的过去”。

### 6.2 技术乌托邦

把未来做成“技术解决一切”的广告，会掩盖：

- 谁控制技术；
- 谁承担失败；
- 谁被排除；
- 谁维护。

### 6.3 衰败美学

“破败 = 深刻”“故障 = 高级”“霓虹 = 赛博朋克”是懒惰的等式。

衰败美学如果没有结构，只是氛围；故障如果没有系统，只是滤镜；霓虹如果没有权力关系，只是配色。

### 6.4 无限怀旧

怀旧可以是一个入口，但不能是终点。一个只会回望的未来，没有能力想象另一种未来。

## 七、五个考古问题

在任何“复古未来”设计前，先问：

1. **这是谁的未来？** 谁被看见，谁被省略？
2. **这是哪种过去？** 哪个年代、哪种技术、哪种媒介？
3. **它的材料与劳动从哪来？** 谁生产、谁维护、谁承担污染？
4. **它为什么被放弃/被商品化/被压扁？** 今天还在不在那个结构里？
5. **它留下了什么可选择的余地？** 观众/玩家能带走什么判断？

## 八、结语

复古未来不是“把旧东西做得更酷”。

它是**用过去的未来，照亮现在的选择**。

青橙的未来考古，最终不是为了回到过去，而是为了回答：

> **我们今天相信的未来，是否也值得被一百年后的人考古？**
