八条原则

先语义，后色值

业务代码只引用 sys.* 或 product.*。

一套语法，多种介质

Web / Godot / App / 印刷共用层级与无障碍下限。

产品可变，理解方式不变

换风格卡，不换信息位置与交互语法。

可访问性是闸门

对比度、焦点、减少动态、缩放由机器守。

单一事实来源

JSON 只写一次；CSS / Godot / App 由脚本生成。

设计是闸门

实现前有规格，发布前有验收；设计债按 P1 处理。

先收编，再统一

不推翻既有合理差异；先对齐语义，再替换取值。
