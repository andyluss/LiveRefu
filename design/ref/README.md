## 二、使用边界

- **引用不等于采纳**：青橙会明确写出“借了什么、保留什么分歧”；
- **不复制长段**：参考材料保留原文，青橙理念写自己的判断；
- **不把参考当教义**：FA 偏真实代谢，LiveTech 偏技术纲领，赛博朋克/太阳朋克偏社会叙事；青橙要覆盖游戏、科幻、应用与实体，必须更广、更包容；
- **参考版本会变**：如果原文更新，青橙不追着改，而是在文章里注明参考版本/分歧。
