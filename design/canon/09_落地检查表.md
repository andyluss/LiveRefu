# 09 · 落地检查表

> 纲领第十篇 ｜ 从现有资产迁移到本纲领的验收问题
> 目标不是“文档写完”，而是 **ref/sys/component/product 真正成为唯一事实来源**。
> 当前项目进度由项目文档维护，不写进纲领。

## 一、Token 层

- [ ] scale 归入 `ref`，不再出现在厂商顶层；
- [ ] 厂商原生源归入 `ref.source.<vendor>`，不再占顶层；
- [ ] 默认语义角色落在 `sys`，并复用已有路径；
- [ ] 风格卡差异只写 `product.<card>.*`，不做全量副本；
- [ ] 没有新增 `theme.*` 全量副本；历史副本已迁移或登记；
- [ ] 组件尺寸/部件归 `component`，且只引用 ref/sys；
- [ ] 别名无循环，全部可追溯到 `ref`；
- [ ] `sys` / `component` / `product` 不写裸 `#hex` 或裸尺寸。

## 二、风格卡

- [ ] 每张卡有 `mode`；
- [ ] 每张卡的角色有来源（继承或覆盖）；
- [ ] 风格卡不写 hex，只引用 token；
- [ ] 对比度通过；
- [ ] 深/浅模式原生控件跟随；
- [ ] 截图基线存在；
- [ ] owner/代价/弃用条件已写。

## 三、组件

- [ ] 有 anatomy/states/tokens/keyboard/a11y/do/dont；
- [ ] 只引用 sys/component；
- [ ] 所有交互状态完整；
- [ ] 200% 字号/减少动态/键盘走查通过；
- [ ] 有真实消费者。

## 四、工具与闸门

- [ ] token 结构/别名检查；
- [ ] 对比度检查；
- [ ] 风格卡 audit；
- [ ] 截图回归；
- [ ] 生成物可复算；
- [ ] CI/本地命令文档化。

## 五、文档

- [ ] 纲领与规则不冲突；
- [ ] 决策记录链接到纲领条目；
- [ ] 迁移步骤可执行；
- [ ] 旧路径有迁移映射；
- [ ] README 能让人 5 分钟找到入口。

## 六、完成定义

一个设计系统变更只有在以下同时成立时才算完成：

```text
源改完 + 生成物复算 + 闸门通过 + 文档/版本 + 可回滚
```

否则只是“改了几个值”。
