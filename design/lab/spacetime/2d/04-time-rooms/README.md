## 一句话

日、季、十年不是缩放级别，是四种时间流速；换一个房间，换一个问题。

## 在试什么

**H4：尺度是建筑，不是滑块。** 同一个事件，在“现在”的房间里是待办，在“十年”的房间里是痕迹。走进不同房间，时钟变快，问题也改变——这比把同一张图放大更接近真实的时间判断。

## 怎么玩

- 点击平面房间（现在 / 日 / 季 / 十年）；
- 或使用底部按钮、`←` / `→` 换房间；
- 观察中央时钟：1× → 24× → 365× → 3650×；
- 右侧面板显示：房间问题、看见什么、看不见什么；
- 时钟流速是视觉模拟，不是物理时间。

## 空间编码

| 房间 | 时间尺度 | 问题 |
| --- | --- | --- |
| 现在 | 1× | 我现在要做什么？ |
| 日 | 24× | 今天什么被推进了？ |
| 季 | 365× | 什么在变好，什么在变坏？ |
| 十年 | 3650× | 什么值得留下？ |

## 危险

- 长期房间容易被短期房间挤到角落；
- “十年”如果不可见，长期代价就会被短期流速吞掉；
- 时钟越快，越容易把“忙”误当成“进展”。

因此长期房间必须始终有一扇可见的门。

## 可能沉淀

- “换尺度 = 换问题”的导航语法；
- 时钟流速作为尺度反馈；
- 长期问题的固定入口；

## 边界

- 房间、时钟、文案均为模拟；
- 没有真实日历、提醒或时间追踪；
- “时间流速”只是隐喻，不代表真实时间感知研究。
