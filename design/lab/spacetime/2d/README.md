## 为什么先做平面

平面是空间直觉的最小实验场：没有相机、遮挡与透视，先验证“位置、邻居、方向、折叠”本身是否成立，再进入 3D 纵深。

## 边界

- 全部为模拟数据；
- 没有真人实验；
- 不进入生产规范；成立与否要看使用与评审。
