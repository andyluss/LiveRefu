# 05 · 折叠时间 / Folded Time

## 一句话

把二十七年折成一页：折叠让远距离年代并置，但它不缩短因果距离。

## 在试什么

**H5：折叠产生比较。** 均匀时间线很难让人比较 1999 与 2026；把时间折成蛇形，能否让“同构 / 回声 / 差异”进入同一视野，同时不假装距离消失？

## 怎么玩

- 拖动“折叠度” 0–4；
- “展开”回到单行，“折三折”快速进入多层；
- 点击年份节点（1999 / 2004 / 2009 / 2014 / 2019 / 2026）查看说明；
- 观察 1999 ↔ 2026 的并置线与“27 年 / 不可压缩”的提示；
- 折痕越多，视野越密，也越容易误读。

## 空间编码

| 元素 | 含义 |
| --- | --- |
| 蛇形折线 | 时间被折叠后的形状 |
| 折痕 | 时间段的转向点 |
| 年份节点 | 可比较的时间切片 |
| 虚线 | 并置关系，不是因果 |
| 折叠度 | 视野密度，不是时间压缩 |

## 危险

**折叠会制造“近”的错觉。** 1999 和 2026 在同一页上，不代表它们之间的 27 年、维护与代价被折掉了。

## 边界

- 年份与文案为模拟；
- 折叠只改变视觉排列，不改变时间数据；
- 没有真实历史事件或因果链。
