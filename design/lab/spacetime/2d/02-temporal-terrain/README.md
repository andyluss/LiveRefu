## 一句话

过去是地形，未来是天气；高度不是“更重要”，而是“更确定”。

## 在试什么

**H2：时间可以被行走，而不只是被读取。** 水平刻度会让所有时刻看起来等价；把时间映射为高度、天气与阴影，能否让“确定性 / 记忆重量 / 未知”变成可感的东西？

## 怎么玩

- 点击地形上的事件，查看年份、确定性、证据与说明；
- 切换 **日 / 月 / 年 / 十年** 尺度，观察同一个问题如何换分辨率；
- “沿山脊走到现在”按顺序走过种子、第一版、规则卡、现在；
- “显示/隐藏天气”切换未来层；
- 右侧事件列表是完整的文字退路。

## 时间编码

| 视觉 | 含义 |
| --- | --- |
| 高度 | 确定性 / 已被证据压实 |
| 阴影 | 记忆强度 |
| 虚线 / 浅色 | 假设、未发生 |
| 橙色光平面 | 现在 |
| 天气 | 未知与不确定性 |

## 危险

**未来节点仍然占据一个“看起来已确定”的位置。** 这是这个隐喻最大的风险：地形会让人把假设误读成事实。

因此必须同时使用浅色、虚线与“假设”标签，并保留真实年份刻度。

## 可能沉淀

- “高度 = 确定性，天气 = 未知”的时间编码；
- 未来节点的不可信视觉规则；
- 时间尺度的切换不改变事实，只改变问题；
- 3D 版对照：[../3d/01-terrain/README.md](../../3d/01-terrain/README.md)。

## 边界

- 2024–2028 事件均为模拟；
- 没有真实日历、来源或项目数据；
- 尺度按钮改变的是阅读问题，不是数据精度。
