## 一句话

时间站起来，变成一片可以绕着走的地形；高度是确定性，纵深是时间。

## 在试什么

**把 2D 时间地形推到 3D：** 平面版只能看见坡度；3D 版能否让人看见山脊、谷地、未来低处的雾，以及“现在”在山脊上的位置？

## 3D 编码

| 轴 | 含义 |
| --- | --- |
| X | 同一时间切面内的位置 |
| Z | 时间：过去 → 现在 → 未来 |
| Y | 确定性 / 被证据压实的高度 |
| 橙色光平面 | 现在 |
| 橙色低地 / 雾 | 未来与未知 |

## 怎么玩

- 拖拽旋转、滚轮缩放；
- “复位视角”回到默认相机；
- “自动旋转”观察地形背面；
- “走到现在”让相机沿时间轴移动；
- 点击右侧事件，查看年份、确定性、高度与证据；
- 文字列表始终保留，不把 3D 当唯一入口。

## 3D 增加了什么

- 能看见坡面的背面与谷地；
- 能绕着“现在”走，感受它是一道面而不是一条线；
- 能看见未来低处的“雾”，而不是一个扁平的浅色节点。

## 危险

- 透视会让未来看起来更近；
- 旋转会遮住远处；
- 相机可能迷失，必须保留复位；
- 3D 的“更真实”可能强化“未来已经存在”的错觉。

## 可能沉淀

- “高度 = 确定性、纵深 = 时间”的 3D 时间视图；
- 复位视角 + 文字退路；
- 未来低地的不可信视觉规则。

## 边界

- 数据均为模拟；
- 没有真实地形/项目数据；
- 相机移动是视觉叙事，不是时间旅行。
