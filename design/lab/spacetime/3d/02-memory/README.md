## 一句话

房间浮起来，路径变成细线；旋转之后，你还知道自己在哪个盒子吗？

## 在试什么

**把平面星图推进纵深：** 当房间有前后、有遮挡、有相机旋转，人还能靠“位置 + 邻居 + 路径”记住内容吗？还是只会迷失在 3D 里？

## 3D 编码

| 元素 | 含义 |
| --- | --- |
| 盒子 | 一个可停留的房间 |
| 盒子中心 / 顶部标签 | 房间名与当前选中 |
| 地面细线 | 房间之间的路径 |
| 深度 | 房间之间的距离 |
| 橙色高亮 | 当前所在房间 |

## 怎么玩

- 拖拽旋转、滚轮缩放；
- “复位视角”回到默认相机；
- “回到工作室”把当前房间设为中心；
- 右侧房间列表选择任意房间；
- 面板固定显示“我在哪 / 怎么来的 / 怎么回去”。

## 3D 增加了什么

- 房间有了前后与遮挡，更像“走进去”而不是“点开”；
- 旋转会改变方向，测试空间记忆是否依赖固定视角；
- 中心房间可以作为旋转中的锚点。

## 危险

- 盒子互相遮挡，标签会重叠；
- 旋转后“上/下/左/右”都变了；
- 没有固定中心时，3D 比 2D 更容易迷路。

## 可能沉淀

- “中心 + 邻居 + 回退”三件套；
- 3D 场景中的当前位置常驻提示；
- 旋转中的锚点设计。

## 边界

- 房间与内容为模拟；
- 没有真实文档、搜索、持久化；
- 未做真人空间记忆实验。
