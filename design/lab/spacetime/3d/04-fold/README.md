# 3D 04 · 折叠时间 / Folded Time

> **LAB / EXPERIMENTAL** ｜ 状态：`prototype` ｜ 2026-11-02
> 入口：[index.html](index.html) ｜ 3D 实验台：[../index.html](../index.html) ｜ 系列：[../../README.md](../../README.md)

## 一句话

把时间折成一条有厚度的带子；3D 让“并置但不等价”变得可见。

## 在试什么

**把平面折叠推进纵深：** 每一折成为一层独立的时间切片；绕到侧面，看见折层之间的空间关系，同时不忘记它们并不是同一条线。

## 3D 编码

| 元素 | 含义 |
| --- | --- |
| 纵深 Z | 每一折是一层切片 |
| 蛇形带 | 1999—2026 的折叠形状 |
| 折痕 | 时间段的转向点 |
| 橙色节点 | 选中的年份 |
| 虚线 | 1999 ↔ 2026 的并置关系，不是因果 |

## 怎么玩

- 拖动“折叠度” 0–4；
- “展开”回到单层，“折三折”快速进入多层；
- 拖拽旋转、滚轮缩放；
- “复位视角”回到默认相机；
- 点击右侧年份查看说明；
- 始终保留“27 年 / 不可压缩”的提示。

## 3D 增加了什么

- 每一折成为有厚度的切片，而不只是折线；
- 能绕到侧面看见折层之间的深度；
- 透视让“近”更强烈，也让“并置不是等价”的提示更重要。

## 危险

- 3D 透视会强化“距离变短”的错觉；
- 折层可能互相遮挡；
- 旋转后年份标签会移动，必须保留文字列表。

## 可能沉淀

- 折叠带 + 年份刻度 + “并置但不等价”提示；
- 3D 时间切片的导航；
- 折痕作为可点击节点。

## 边界

- 年份与文案为模拟；
- 折叠只改变视觉排列，不改变时间数据；
- 没有真实历史或因果链。
