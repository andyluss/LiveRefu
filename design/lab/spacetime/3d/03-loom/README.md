## 一句话

三股线在不同的深度里交织；事件不是线上的点，是空间里的结。

## 在试什么

**把 2D 织网推进 3D：** 知识、设计、工程各占一个深度；旋转时，“同时发生”是否还能被理解成“不在同一个位置”的多股过程？

## 3D 编码

| 轴 | 含义 |
| --- | --- |
| X | 时间 |
| Z | 股线 / 深度（知识 / 设计 / 工程） |
| Y | 因果重量 / 事件高低 |
| 弧线 | 因果或时间相邻 |
| 橙色 | 当前节点及其连线 |

## 怎么玩

- 拖拽旋转、滚轮缩放；
- 点击右侧节点，查看上游 / 下游；
- 切换“因果 / 时间”模式；
- “剪断未来”观察分叉；
- “复位”回到默认相机与意图节点。

## 3D 增加了什么

- 三股线不再压在同一平面；
- 旋转时能看见“同时发生”其实有深度差；
- 选中节点的上下游在 3D 中更明显地分组。

## 危险

- 旋转会改变“前后”，容易把深度误读成因果；
- 弧线在 3D 中会互相遮挡；
- 没有“因果 / 时间”双模式，3D 会强化因果幻觉。

## 可能沉淀

- 三维股线的上下游高亮；
- 剪断分叉；
- 因果 / 时间双模式；
- 深度作为“不同过程”的编码。

## 边界

- 节点与连线为模拟；
- 没有真实依赖图；
- 剪断只改变视觉状态。
