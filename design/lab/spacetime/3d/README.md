# spacetime / 3d · 有纵深的时空模型

> **LAB / EXPERIMENTAL** ｜ 状态：`prototype` ｜ 2026-11-02
> 四个使用 Canvas 3D 投影的案例：时间地形、空间记忆、因果织网、折叠时间。
> 不使用 Three.js/WebGL addon；`engine3d.js` 是一个很小的本地投影引擎，离线可开。

## 一、为什么再做 3D

前五个案例主要在平面里做空间化。这里进一步问：

1. 当“高度 / 纵深 / 透视”成为主要编码，时间与空间的关系会不会更直观？
2. 3D 带来的额外维度，是帮助理解，还是只增加眩晕？
3. 旋转、缩放、遮挡之后，人还能保留“我在哪、这是什么时间”吗？

## 三、共同操作

- **拖拽**：旋转视角
- **滚轮**：拉近/拉远
- **按钮**：复位、自动旋转、选择节点/年份
- 顶部三态主题：系统 / 浅色 / 深色

## 四、边界

- 所有数据为模拟；没有真实项目/时间数据；
- 投影引擎是教学/实验用，不处理复杂遮挡、光照、材质；
- 3D 不等于更高级：小屏幕、眩晕、遮挡都可能让它更难读；
- 每个案例都保留文字/列表退路，不用 3D 替代信息。

## 五、可能沉淀

- 3D 时间地形的“高度=确定性 / 纵深=时间”编码；
- 3D 房间的“可旋转但始终知道自己在哪”；
- 3D 因果线的上下游高亮；
- 折叠带的“并置但不等价”提示；
- 一套 3D 界面的可读性/眩晕/退出检查表。
