## 一句话

时间不是一条线，而是一匹被拉开的布；每一股线有自己的速度，交叉的地方才叫“事件”。

## 在试什么

**H3：因果需要多股过程。** 单条时间线会把“同时发生”压成同一个点；把知识、设计、工程拆成三股线，能否让人看见“谁在等谁、谁改变了谁”？

## 怎么玩

- 点击节点，查看它的上游（由什么织成）与下游（改变了什么）；
- 切换 **因果 / 时间** 两种连线模式；
- “剪断一条未来”观察分叉：过去仍在，结果未发生；
- 右侧节点列表是完整退路；
- 底部图例区分知识、设计、工程三股线。

## 空间编码

| 元素 | 含义 |
| --- | --- |
| 横向 | 时间 |
| 三条平行线 | 知识 / 设计 / 工程 |
| 节点 | 一个事件或决定 |
| 交叉弧线 | 因果或时间相邻 |
| 高亮 | 当前节点的上游 / 下游 |

## 危险

**连线会制造因果幻觉。** 两条线相邻，不代表一条导致另一条。这个实验用“因果 / 时间”双模式明确提醒：空间邻接 ≠ 因果。

- 没有真实依赖图或项目数据；
- “剪断”只改变视觉状态，不删除任何真实内容。
