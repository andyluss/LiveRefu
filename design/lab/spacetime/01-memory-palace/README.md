# 01 · 记忆星图 / Memory Palace

> **LAB / EXPERIMENTAL** ｜ 状态：`prototype` ｜ 2026-11-02
> 入口：[index.html](index.html) ｜ 时空实验室：[../index.html](../index.html) ｜ 系列：[../README.md](../README.md)

## 一句话

把目录树拆成房间、邻居与路径：先记住它在哪，再记住它叫什么。

## 在试什么

**H1：位置先于标签。** 当对象有稳定空间位置和邻居关系时，人是否会更少依赖文字层级，而更多通过“它在谁旁边、从哪条路过来”来记忆？

这是“空间直觉”系列的第一个实验：它把“知识”摆成一个可以直接走进去的平面星图，没有侧边栏树。

## 怎么玩

- 点击房间，右侧显示当前位置、描述、邻居、坐标和路径；
- 拖拽平移，滚轮缩放；
- `←` / `→` 按顺序切换房间；
- “回到工作室”回到中心与默认视角；
- 每个房间都有固定位置，不会因为内容多少而移动。

## 空间编码

| 元素 | 含义 |
| --- | --- |
| 房间 | 一个可停留的认知位置，不是文件夹 |
| 邻居 | 你上一次从哪个问题走进来 |
| 路径 | 一条可回退的访问历史 |
| 中心 | 工作室：所有路径的起点 |
| 出口 | 不依赖记忆的退出机制 |

## 危险

- 空间一旦变大，方向感会丢失；
- 位置如果不稳定，导航会退化成猜谜；
- “邻居”可能被误读成“分类”，但这里只是访问关系。

因此必须始终保留三件套：**我在哪、我怎么来的、我怎么回去**。

## 可能沉淀

- “中心 + 邻居 + 回退”三件套；
- 空间导航的当前位置常驻提示；
- 用位置而不是层级组织内容的评审问题；
- 3D 版对照：[../3d/02-memory/README.md](../3d/02-memory/README.md)。

## 边界

- 全部为模拟房间与模拟内容；
- 没有真实文档索引、搜索、持久化；
- 没有做真人空间记忆实验。
