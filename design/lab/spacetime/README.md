# 时空实验室 · 空间直觉与时间的空间化

> **LAB / EXPERIMENTAL** ｜ 状态：`prototype` ｜ 2026-11-02
> 目的：把[《空间直觉》](../../philosophy/12_空间直觉_让界面先被看见再被读懂.md)从阅读材料推到可操作的空间/时间隐喻，供设计参考，不进入生产规范。

## 一、实验问题

1. 人能否**先读懂空间，再读懂标签**？
2. 时间除了变成一条从左到右的线，还能怎样被空间化？
3. 当“位置 / 距离 / 方向 / 折叠 / 房间 / 因果”成为主要界面语法，什么变清楚了，什么变危险了？
4. 这些空间隐喻中，哪些可以被回收成 LRDS 的组件、布局或评审问题？

## 三、共同假设

- **H1 位置先于标签**：稳定位置与邻居关系能减少对文字层级的依赖。
- **H2 时间可变成地形**：高度、天气、距离比均匀刻度更能表达确定性/记忆重量。
- **H3 因果需要织物**：单线时间无法表达多股过程；平行股 + 交叉节点更接近真实。
- **H4 尺度需要建筑**：不同时间尺度不是同一个视图的缩放，而是不同房间。
- **H5 折叠产生比较**：把远距离时间折近，能让人看见同构/回声，但必须提醒距离没有消失。
- **H6 3D 需要退路**：多一个维度，必须多一个文字入口与复位方式。

## 四、边界

- 所有节点、事件、房间、年份均为模拟内容；
- 没有后端、网络请求、真实日历/账号；
- 交互是设计探索，不是可用性结论；没有做真人实验；
- 移动端为可用性降级，键盘/触控只覆盖主要路径。

## 六、可能沉淀

- “空间先于标签”的布局评审问题；
- 时间地形的“高度 = 确定性、天气 = 未知”编码；
- 因果织网的 upstream/downstream 高亮；
- 时间房间的“换尺度 = 换问题”导航；
- 折叠时间的“并置但不等价”提示；
- 2D / 3D / 应用三层的实验组结构；
- 每个案例独立 README + 索引的扩展方式。

## 七、不做什么

- 不把这些案例当成已验证的交互模式；
- 不用 3D/动效制造“未来感”而牺牲可读性；
- 不隐藏时间刻度、来源、当前位置与返回路径；
- 不让“空间化”变成对真实因果/时间距离的误导。
