## 一、为什么是这两个演示

原文档给出的不是一个页面，而是一套**坐标系统**：

- 三生：生存 / 生活 / 生产；
- 三圈：个人 / 家庭团队 / 组织社区 / 社会生态（责任半径）；
- 四环：资源 → 方法 → 价值 → 反馈；
- 时空：每个节点都有空间范围与时间尺度。

把它直接画成表格会丢失最重要的东西：**位置、半径、方向、层次与流动**。所以这里做两份空间直觉演示：

| 演示 | 空间直觉 | 时间的处理 | 入口 |
| --- | --- | --- | --- |
| **三生罗盘** | 同心圆 = 责任半径；扇区 = 三生；中心 = 事务闭环 | 每个圈层对应一个时间尺度：日 / 月 / 季 / 年 | [三生罗盘.html](三生罗盘.html) |
| **时空织机** | 垂直层 = 时间尺度；水平环 = 空间圈层；节点 = 三生事务 | 时间成为可穿行的层，反馈沿线程回流 | [时空织机.html](时空织机.html) |

## 二、三生罗盘

**一句话**：你不是在填一张三生三圈的矩阵，而是在一个同心圆里找到“这件事发生在哪一圈、属于哪一生、正在跑哪个闭环”。

- 4 个圈层：个人 / 家庭团队 / 组织社区 / 社会生态；
- 3 个扇区：生存 / 生活 / 生产；
- 中心：资源 → 方法 → 价值 → 反馈的循环；
- 时间：每个圈层绑定一个主节奏（日 / 月 / 季 / 年）；
- 点击任意扇区，右侧显示节点卡：坐标、问题、四环、周期、风险。

**它在试什么**：同心圆能否让人先感知“责任半径”，再读文字？时间尺度与空间圈层绑定，是否会让人自然地问“这个反馈需要多久”？

## 三、时空织机

**一句话**：把时间尺度竖起来，把空间圈层铺成环，三生节点成为织机上的结；资源、价值与反馈在经纬之间流动。

- 垂直 Y：日 / 月 / 季 / 年四层时间；
- 水平环：个人 / 团队 / 组织 / 社会四层空间；
- 每个环上三个节点：生存 / 生活 / 生产；
- 径向线程：同一事务跨圈层的扩展；
- 橙色反馈线：外圈结果如何延迟回到内圈；
- 可旋转、缩放、自动旋转；右侧列表是文字退路。

**它在试什么**：把时间变成“可以上下穿行的层”，是否比一条水平时间线更能看见反馈延迟与尺度跃迁？

## 四、共同边界

- 节点卡文案来自对原文档的**设计转译**，不是原文档逐字复制；
- 所有数据为模拟，不代表任何真实个人/组织；
- 没有真实日历、任务、指标或 AI 建议；
- 两个演示都不进入生产规范；成立与否要看真人使用与评审；
- 颜色映射（生存红 / 生活蓝 / 生产绿）仅用于空间区分，不是价值排序。

## 五、可能沉淀

- “责任半径 + 时间尺度”双编码；
- 三生三圈的可点击坐标卡；
- 四环闭环作为中心动画；
- 3D 时空层的反馈延迟可视化；
- 一套“空间位置是否真的帮助理解三生三圈”的评审问题。
