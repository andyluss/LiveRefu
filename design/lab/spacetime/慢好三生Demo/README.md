## 一、为什么是这五个演示

原文档给出的不是一个页面，而是一套**坐标系统**：

- 三生：生存 / 生活 / 生产；
- 三圈：个人 / 家庭团队 / 组织社区 / 社会生态（责任半径）；
- 四环：资源 → 方法 → 价值 → 反馈；
- 时空：每个节点都有空间范围与时间尺度。

把它直接画成表格会丢失最重要的东西：**位置、半径、方向、层次与流动**。所以这里做五个空间直觉演示（两个平面、三个 3D）：

| --- | --- | --- | --- |

## 二、三生罗盘

**一句话**：你不是在填一张三生三圈的矩阵，而是在一个同心圆里找到“这件事发生在哪一圈、属于哪一生、正在跑哪个闭环”。

- 4 个圈层：个人 / 家庭团队 / 组织社区 / 社会生态；
- 3 个扇区：生存 / 生活 / 生产；
- 中心：资源 → 方法 → 价值 → 反馈的循环；
- 时间：每个圈层绑定一个主节奏（日 / 月 / 季 / 年）；
- 点击任意扇区，右侧显示节点卡：坐标、问题、四环、周期、风险。

**它在试什么**：同心圆能否让人先感知“责任半径”，再读文字？时间尺度与空间圈层绑定，是否会让人自然地问“这个反馈需要多久”？

## 三、时空织机


**一句话**：把时间尺度竖起来，把空间圈层铺成环，三生节点成为织机上的结；资源、价值与反馈在经纬之间流动。

- 垂直 Y：日 / 月 / 季 / 年四层时间；
- 水平环：个人 / 团队 / 组织 / 社会四层空间；
- 每个环上三个节点：生存 / 生活 / 生产；
- 径向线程：同一事务跨圈层的扩展；
- 橙色反馈线：外圈结果如何延迟回到内圈；
- 可旋转、缩放、自动旋转；右侧列表是文字退路。

**它在试什么**：把时间变成“可以上下穿行的层”，是否比一条水平时间线更能看见反馈延迟与尺度跃迁？

## 四、四环螺旋

**一句话**：闭环不是圆圈，是沿时间盘旋的螺旋；资源 → 方法 → 价值 → 反馈，每一圈都比上一圈多一层时间。

- 3 条生命线（生存 / 生活 / 生产）；
- 4 个时间层（日 / 月 / 季 / 年）；
- 4 个闭环阶段（资源 / 方法 / 价值 / 反馈）；
- 3D 螺旋让你看见“反馈回到资源时已经换了高度”；
- 风险：螺旋会让不同轮的同一阶段看起来相邻。

## 五、树网星丛

**一句话**：树是骨架，网是血流；根 → 干 → 枝 → 叶，跨生虚线让树变成活的。

- 根：底线；干：三生；枝/叶：4 个圈层 × 3 生；
- 虚线：跨生、跨圈的网络连接；
- 3D 纵深让网络不被压成同一层；
- 风险：树天然有中心，容易被读成权力；网线太多会变成毛线团。

## 六、时空立方

**一句话**：三生不是三列，是三个高度上的平面；X=空间圈层，Z=时间，Y=三生。

- 3 个平面 × 4 个空间 × 4 个时间 = 48 个坐标；
- 同一格在三个平面上有不同问题；
- 虚线 triad 连接同一空间/时间的三个生命域；
- 风险：Y 轴会被误读成等级；必须说明这是三个生命域，不是高低。

## 七、共同边界

- 节点卡文案来自对原文档的**设计转译**，不是原文档逐字复制；
- 所有数据为模拟，不代表任何真实个人/组织；
- 没有真实日历、任务、指标或 AI 建议；
- 五个演示都不进入生产规范；成立与否要看真人使用与评审；
- 颜色映射（生存红 / 生活蓝 / 生产绿）仅用于空间区分，不是价值排序。

## 八、可能沉淀

- “责任半径 + 时间尺度”双编码；
- 三生三圈的可点击坐标卡；
- 四环闭环作为中心动画；
- 3D 时空层的反馈延迟可视化；
- 一套“空间位置是否真的帮助理解三生三圈”的评审问题。
