## 二、两个试点

### 网站《未来档案》

**改了什么**：
- `app/assets/theme.css` 的 16 个颜色定义移入生成物；旧变量名通过别名保留，其余 CSS 一行未改；
- `nuxt.config.ts` 在 `theme.css` 之前加载 `tokens.generated.css`；
- `tools/verify-contrast.ts` 改为从生成物读 token，并解析 `var(--x)` 别名；
- 新增 `app/assets/tokens.generated.css`（生成物）。

**唯一有意的视觉变化**：`--focus` 从 `#57D8C8`（= `--teal-bright`）改为 `#8AB4F8`。
这是现状盘点里的第 1 号缺陷——焦点指示不得复用强调色。它只在键盘焦点时可见，不影响静态截图。

**其他值**：`bg / bg-elev / bg-elev-2 / line / line-strong / text / text-dim / text-faint / teal / teal-bright / cream / amber / rust / chrome` 全部等值；`--radius` 仍为 6px，`--maxw` 仍为 1240px，`--focus-width` 仍为 2px。

**验收**：
- `bun run tools/verify-contrast.ts`：27/27 组合达 WCAG AA，层级与 focus 分离通过；
- `bun run build`：通过，产物 CSS 中确认包含 `--bg:var(--lr-future-archive-bg)` 与生成 token。

### 游戏《未来残片》

**改了什么**：
- `game/data/tokens.json` 改为生成物，schema 与字段保持不变；
- 18 个颜色、5 级字号、间距/圆角/描边/动效/图标全部等值；
- 场景、脚本、Theme 生成器一行未改。

**验收**：
- `python3 tools/check_tokens.py`：文档 ↔ 引擎 **PASS**（18 颜色 / 5 级字号）；
- `./run.sh contrast`：30 组对比度 + 层级 + 3 个样张 **PASS**；
- `./run.sh theme`：**15 项主题断言全部通过**，`future_debris.tres` 重新生成后无 diff。

## 三、可复算性

- 改 `design/tokens/` → 跑 `build_tokens.ts` → 产品副本更新；
- CI / 本地用 `build_tokens.ts --check` 防止“改了源、忘了生成”；
- 游戏侧还有 `check_tokens.py` 的“文档 ↔ 引擎”对账，website 侧还有 `verify-contrast.ts` 的“生成物 ↔ 页面规则”对账。
- **四道闸门已接入根 pre-commit 与 CI**：暂存涉及设计系统或两个试点消费面时自动跑；CI 另加网站 `verify-contrast.ts`。
