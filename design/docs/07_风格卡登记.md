# 07 · 风格卡登记（Style Card Registry）

> **风格卡不是主题**：主题是“换一套颜色”；风格卡是“换一套世界观的物质语言”——色板、材质、光源、装饰母题、图像处理、字体族、UI 外壳、音频语气。
> 本文是**登记表**：每张风格卡必须有 ID、产品、源文件、引擎投影与对账方式。没有登记的“换皮”不算风格卡。

## 二、每张卡的可变 / 不变

### SC-FUTURE-ARCHIVE-CONSOLE-v1

- **可变**：强调青、奶油白、琥珀、CRT 装饰强度、材质处理。
- **不变**：语法层（字阶、间距、焦点、`--line` / `--line-strong` 分工、对比度下限）。
- **当前特例**：圆角 6px（EX-20261021-02），待视觉评审。

### SC-FUTURE-DEBRIS-ATOMIC-v1

- **可变**：原子纪元的镀铬/搪瓷/塑料、`power` 青、`residue` 橙、扫描线强度。
- **不变**：卡面六段位置、5 级 UI 字阶、焦点环规则、按钮三态可区分。
- **产品语义**：`power` / `residue` 只在本卡；换纪元时新增 `SC-FUTURE-DEBRIS-<ERA>-vN`，语法层不动。

### SC-LIVEFAB-CONSOLE-v1

- **可变**：低饱和青、深空蓝黑、功能优先的少量状态色。
- **不变**：与《未来档案》共享的 `sys.*` 语义、焦点独立蓝、对比度纪律。

### SC-TOMORROWS-CHANNEL-TAPE-v1

- **可变**：
  - 9 个颜色：`baseDark` / `midBeige` / `litWarm` / `phosphorAmber` / `phosphorGreen` / `emphasis` / `housingBeige` / `housingDark` / `dialAmber`；
  - 光照：设备色温 2400K、台灯 2800K、光比 6:4；
  - 装饰：扫描线开关、强度 0.08、装饰字体名（当前空）。
- **不变**：共用交互骨架、正文可读性下限、装饰可关闭、正文不使用装饰字体。
- **为什么不是 `tokens.json`**：`ChannelSkin` 是 Godot `Resource`，除了颜色还有 `Vector2` / 色温 / 布尔 / 字符串；它不是 UI 主题，而是**材质 + 光照风格卡**。v0.1 只登记 + 对账，不强行把 `.tres` 改成生成物。
- **对账口径**：
  - `Color(r,g,b,a)` 的 sRGB 分量 ×255 取整，与 token 的 `#RRGGBB` 完全一致；
  - 6 个光照/装饰字段与 token 文件 `meta.lighting` 一致。
- **验收**：`node design/tools/check_tomorrows_channel_skin.ts`（7/7 自检）。

## 三、登记规则

1. **一个产品/纪元一张卡**；卡 ID 用 `SC-<PRODUCT>-<ERA>-vN`。
2. **卡只改取值与物质语言，不改语法层**；需要改信息位置时，先改语法层契约与版本。
3. **必须能对账**：要么产品消费生成物，要么有检查器把引擎资源与 token 源对齐；两者都没有 = 还没登记。
4. **不删除旧卡**：纪元/产品下线时标 `retired`，保留源文件与当时的判断。
5. **新卡不重复造核心语义**：产品专属语义放 `product.*`；三个以上产品都需要时才上移 `sys.*`。
