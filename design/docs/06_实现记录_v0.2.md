## 一、交付

### 1. 多产品 Web 生成

`design/tokens/dist/web/` 不再只有一个 `tokens.css`，而是**每个 Web 产品一份**：

| 产物 | 内容 | 消费方 |
| --- | --- | --- |
| `future-archive.css` | `sys.*` + `product.future-archive.*` + 旧变量别名 | 网站 |
| `livefab.css` | `sys.*` + `product.livefab.*` + 旧变量别名 | LiveFab 门户 |
| `godot/tokens.json` | `product.future-debris.*` + UI 字阶/尺度 | 《未来残片》 |

新增产品风格卡 [`livefab.tokens.json`](../tokens/products/livefab.tokens.json)：12 个颜色，等值迁移现有内联色；`focus` 改用独立蓝。

### 2. 网站全量颜色 token 化

- [`theme.css`](../../projects/website/app/assets/theme.css)：CRT 扫描线/暗角改用 `--lr-future-archive-scanline` / `-vignette`；
- [`GalleryGrid.vue`](../../projects/website/app/components/GalleryGrid.vue)：灯箱遮罩、深底、半透明面板改用产品 token；
- [`SearchDialog.vue`](../../projects/website/app/components/SearchDialog.vue)：搜索遮罩、投影、警告高亮文字改用产品 token；
- [`gallery/index.vue`](../../projects/website/app/pages/gallery/index.vue)：深底改用 `-surface-deep`。

新增的 8 个产品 token（支持 `#RRGGBBAA`）：

| token | 值 | 用途 |
| --- | --- | --- |
| `scanline` | `#00000024` | CRT 扫描线（0.14 alpha） |
| `vignette` | `#0000006B` | CRT 暗角（0.42 alpha） |
| `overlayStrong` | `#03060AED` | 灯箱强遮罩（0.93 alpha） |
| `overlayPanel` | `#121A26D9` | 半透明面板（0.85 alpha） |
| `overlaySearch` | `#04080DB8` | 搜索遮罩（0.72 alpha） |
| `shadow` | `#0000008C` | 搜索框投影（0.55 alpha） |
| `surfaceDeep` | `#06090D` | 画廊深底 |
| `onWarning` | `#1A1206` | 琥珀高亮上的深色文字 |

> 8 位 hex 与原来的 `rgba()` 是同一 sRGB + alpha 值，**视觉等价**。

### 3. 裸色值闸门扩大到整个网站 app

`check_no_raw_values.ts` 的默认受检面从 `theme.css` 扩到 `projects/website/app/**/*.{vue,ts,css}`（26 个文件），生成物除外；`--all` 增加游戏脚本，并剥离 GDScript 注释（注释里的示例色值不算债，字符串里的真实色值仍会被检出）。现在网站 app 里出现任何 `#hex` 都会在提交前被拦住。

### 4. LiveFab 门户接入

- [`Base.astro`](../../projects/livefab/portal/src/layouts/Base.astro) 删除 11 个内联色值，改为 `import '../assets/tokens.generated.css'`；
- 生成物 `portal/src/assets/tokens.generated.css` 由 `design/tokens` 产出；
- 焦点描边从 `--teal-bright` 改为 `--focus`（独立蓝）；
- 旧变量名（`--bg` / `--teal` / `--amber` …）由生成物别名提供，页面其余 CSS 未改。
