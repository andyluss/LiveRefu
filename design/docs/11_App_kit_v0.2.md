## 一、做了什么

## 二、导出内容

| 类别 | 内容 |
| --- | --- |
| 颜色 | 20 个 `sys.color.*`（bg / text / line / action / feedback / focus / material） |
| 字阶 | UI 5 级（28 / 20 / 16 / 14 / 32），含行高、字重、用途 |
| 尺寸 | 控件 32/40/48；触控最小 44；图标 16/24/32 |
| 尺度 | 间距 4/8/12/16/24/32；圆角 4/8；描边 1.5/2/1 |
| 动效 | 120/220/420ms；standard / emphasis 曲线 |
| 无障碍 | 最小触控 44、文字对比 4.5、UI 对比 3、文字缩放 2.0 |

- 单位：`logical-px`，基线上 1:1 映射 iOS pt / Android dp；文字必须用 Dynamic Type / `fontScale` 缩放。
- 颜色只含 `sys.*`；产品风格卡另行叠加。
- 不含平台组件代码、导航结构、图标资源、启动图与权限文案。

## 三、移动端规则（摘要）

1. **触控**：≥44pt / 48dp；视觉可以更小，命中区不能。
2. **安全区**：刘海/灵动岛/Home Indicator/手势区不压关键操作。
3. **文字缩放**：200% 不裁切、不重叠；不用固定高度容器。
4. **键盘与导航**：正确键盘类型、自动填充、返回手势/返回键。
5. **焦点**：硬件键盘/辅助技术有可见焦点；焦点不复用强调色。
6. **深色模式**：当前只有 Console 暗色；Archive 亮色未落地前不自动反相。
7. **减少动态**：系统开关生效；动画不是唯一状态信号。
8. **触觉**：可选增强，不替代文字/视觉，不过度震动。
9. **颜色**：不用 Material You 动态取色覆盖品牌语义色。
10. **屏幕阅读器**：按钮有名称、字段有标签、错误可读出。

完整清单见 [App kit README §四](../kits/app/README.md)。
