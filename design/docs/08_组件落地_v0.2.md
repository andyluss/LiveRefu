# 08 · 组件落地记录：共享 Web 组件层与渐进接入

> 记录 button / panel / form-field 三个契约如何进入真实产品。
> 日期：2026-10-21 ｜ 状态：**渐进接入 → 皮肤收口（见 [10](10_皮肤收口_v0.2.md)）** ｜ 前置：[07 风格卡登记](07_风格卡登记.md)

## 一、交付

### 1. 共享组件层

- 源：[`kits/web/components.css`](../kits/web/components.css)（手写，只引用 `--lr-*`）。
- 生成物：
  - `design/tokens/dist/web/components.css`
  - `projects/website/app/assets/components.generated.css`
  - `projects/livefab/portal/src/assets/components.generated.css`
- 复制与对账：[`build_web_kit.ts`](../tools/build_web_kit.ts)，`--check` 防止产品副本漂移。
- 校验：[`check_component_contracts.ts`](../tools/check_component_contracts.ts) 现在同时检查契约 Markdown 与组件 CSS（五节 / token / 裸值 / 状态），自检 **8/8**。

### 2. 产品渐进接入

| 组件 | 网站 | LiveFab | 方式 |
| --- | --- | --- | --- |
| Button | 4 文件 / 12 处 | 1 文件 / 1 处 | `.deco-btn` / `.cta` 叠加 `lr-button`；产品皮肤保留 |
| Panel | 6 文件 / 22 处 | 1 文件 / 1 处 | `.card` / `ul.svc li` 叠加 `lr-panel`；产品表面/间距保留 |
| Form Field | 1 文件 / 1 处 | 无 | 搜索框 wrapper + `lr-field__control`；LiveFab 当前没有表单 |

- 加载顺序：`tokens.generated.css` → `components.generated.css` → 产品主题。产品样式仍在最后，避免“组件层一上就把现有视觉推翻”。
- **搜索框焦点修复**：`.search-input:focus` 从 `--teal` 改为 `--focus`（独立蓝），并改用 `--lr-border-focus` / `--lr-border-focus-offset`。
- **语义修正**：论坛的静态阶段卡只用 `lr-panel`，不加 `lr-panel--interactive`；可点击卡片才加。

### 3. 使用审计

[`check_component_usage.ts`](../tools/check_component_usage.ts) 扫描两个 Web 产品：

```
组件        文件  产品  引用  要求  判定
Button        4     2    12  ≥2    ✓
Panel         6     2    23  ≥2    ✓
Form Field    1     1     1  ≥1    ✓
```

自检 **4/4**；零使用或少于最低产品数会失败。

## 三、视觉影响（诚实记录）

- **搜索框焦点**：teal → 独立蓝，键盘焦点时可见；这是有意的无障碍修复。
- **Button / Panel**：组件层作为基础层，产品 `.deco-btn` / `.card` / `.cta` / `ul.svc li` 仍覆盖主要视觉；**未做像素级前后对比**，目前证据是构建通过 + 预览图 + 产品样式覆盖关系。
- **Form Field wrapper**：搜索框外层多了一个 `.lr-field`（grid，单子元素），不改变视觉；`min-width: 0` 保证可收缩。
