# R-005 · 间距、圆角、描边、焦点

> **状态**：`active` ｜ **级别**：MUST ｜ **生效**：2026-10-21
> **范围**：所有 Web/App 界面 ｜ **Owner**：设计主控
> **关联**：E06、[02 §3](../docs/02_系统架构.md)、[10 皮肤收口](../docs/10_皮肤收口_v0.2.md)

## 一、规则

**尺度只用 4/8/12/16/24/32；控件圆角 4px、面板 8px、描边 1.5px、焦点 2px + 1px offset。**

## 二、要求

1. **间距**：只用 4 的倍数表；不得出现 5、7、10、14 等值。
2. **圆角**：控件 4px；面板/卡框 8px；不得使用大圆角或胶囊化面板。
3. **描边**：交互控件/卡框 1.5px；装饰分隔线可用 1px 低对比度 `line.subtle`。
4. **焦点**：2px 实线 + 1px offset；`focus-visible` 才显示；不得移除 outline 而不提供替代。
5. **阴影**：只允许 `0 2px 8px rgba(0,0,0,.35)` 用于浮起面；不做多层阴影。
6. **触控**：最小 44×44px；桌面控件 32/40/48 三档。

## 三、验收

```bash
node design/tools/check_no_raw_values.ts --all
bash design/tools/check.sh
```

## 四、例外

- 印刷/实体按物理尺寸另定，不受 px 表约束，但必须走打印/实体 kit。
- 平台原生控件由平台规范覆盖，App kit 负责映射。

## 五、反例 / 迁移

- **反例**：6px 卡片圆角；10px 间距；1px 交互边框；移除 outline；三层阴影。
- **迁移**：把旧值归并到 4/8/12/16/24/32、4/8px 圆角、1.5px 描边；视觉差异走一次走查。
