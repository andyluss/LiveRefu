# 17 · 外部 Token 适配器（P1）

> 版本：v1.16 ｜ 日期：2026-10-28 ｜ 范围：DTCG / CSS variables / Tailwind JSON → LiveDSO vault

## 一、边界

适配器**不修改用户 token**，也不要求用户采用 LRDS 命名。它做的是：

```text
用户源（只读）
  → 显式 mapping profile
  → 校验（角色/别名/对比度）
  → 生成 LiveDSO vault（ref.source.external + sys + product + style cards）
```

生成物是派生物；源变化后必须重新 `adapt --check`。

## 二、P1 支持

- **DTCG**：`$value` / `$type` 文件或目录；
- **CSS variables**：`:root` / `.dark` 等块中的 `--name: value`；
- **Tailwind JSON**：`theme.extend.colors` / `theme.colors` 导出；
- **多主题**：`themes[]` → 默认 `sys.color.*` + 差异 `product.<theme>.role.*`；
- **B 档角色建议**：`--suggest` 只输出建议，不自动写入；
- `--dry-run` / `--check` / `--json`；
- source hash、style cards、严格 schema 输出。

仍不支持：

- Figma / Style Dictionary 原始文件（需先导出 JSON）；
- Tailwind JS config（不执行用户代码）；
- 自动语义猜测/自动写入 B 档；
- 组件 token 映射。

## 三、Mapping profile

单主题：

```json
{
  "theme": { "id": "paper-brand", "name": "Paper Brand", "mode": "light" },
  "source": { "format": "dtcg" },
  "roles": {
    "bg": "color.background",
    "surface": "color.surface",
    "surfaceRaised": "color.surfaceRaised",
    "surfaceSunken": "color.surfaceSunken",
    "text": "color.text",
    "textMuted": "color.textMuted",
    "textInverse": "color.textInverse",
    "action": "color.action",
    "onAction": "color.onAction",
    "actionHover": "color.actionHover",
    "focus": "color.focus",
    "border": "color.border",
    "borderStrong": "color.borderStrong",
    "danger": "color.danger",
    "success": "color.success",
    "warning": "color.warning"
  }
}
```

多主题：

```json
{
  "source": { "format": "css" },
  "themes": [
    { "id": "brand-light", "mode": "light", "roles": { "bg": "css.default.bg", "...": "..." } },
    { "id": "brand-dark", "mode": "dark", "roles": { "bg": "css.dark.bg", "...": "..." } }
  ]
}
```

- 主题 id 只允许小写字母/数字/连字符；
- 每个主题 16 个 A 档角色必须映射；
- 源路径必须存在且为 color；
- 别名必须能解析；
- 对比度必须通过。

## 四、源格式

### DTCG

```text
light.color.bg
dark.color.bg
```

### CSS variables

```css
:root { --bg: #F7F3EA; }
.dark { --bg: #1B222B; }
```

适配器把变量读成：

```text
css.default.bg
css.dark.bg
```

只支持简单声明块；`@media` / 嵌套规则 / 复杂 `var()` 不保证。

### Tailwind

只接受 **JSON 导出**：

```json
{ "theme": { "extend": { "colors": { "bg": "#F7F3EA" } } } }
```

读取为 `tailwind.color.bg`，不执行 JS 配置。

## 五、命令

```bash
cd design/projects/livedso

# DTCG
node src/cli.ts adapt --source examples/adapt/source.tokens.json \
  --profile examples/adapt/profile.json --out /tmp/adapted-brand

# 多主题 DTCG
node src/cli.ts adapt --source examples/adapt/multi.tokens.json \
  --profile examples/adapt/multi-profile.json --out /tmp/adapted-multi

# CSS / Tailwind
node src/cli.ts adapt --source examples/adapt/theme.css \
  --profile examples/adapt/css-profile.json --out /tmp/adapted-css
node src/cli.ts adapt --source examples/adapt/tailwind.tokens.json \
  --profile examples/adapt/tailwind-profile.json --out /tmp/adapted-tw

# 选项
--dry-run    只校验，不写
--check      生成物与源不一致时失败
--suggest    输出 B 档角色建议（不写入）
--json       机器可读结果
```

## 六、输出结构

```text
<tokens/tokens.json>
  meta（sourceHash / profile / format / themes）
  ref.source.external.*     用户源副本
  sys.color.*               默认主题 16 A 档角色
  product.<theme>.role.*    非默认主题的差异（若有）
<style-cards/<theme>.style.json>
  roles → sys.color.* / product.<theme>.*
README.md                   来源/hash/格式/主题
```

- 生成 vault 通过 `check-vault-schema.ts`；
- 每个主题一张风格卡，只含 A 档角色；
- B 档/预览 fallback 由 LiveDSO 处理；
- source hash 用于漂移检查。

## 七、失败语义

- 缺主题 / 缺 A 档角色 / 源不存在 → error；
- 别名断链 → error；
- 颜色无法解析 → error；
- 对比度不足 → error；
- `--check` 生成物不一致 → error。

P1 仍不放宽到 warning；有真实客户后再决定是否允许显式豁免。
