# 17 · 外部 Token 适配器（P0）

> 版本：v1.15 ｜ 日期：2026-10-28 ｜ 范围：DTCG → LiveDSO 兼容 vault

## 一、边界

适配器**不修改用户 token**，也不要求用户采用 LRDS 命名。它做的是：

```text
用户 DTCG 源（只读）
  → 显式 mapping profile
  → 校验（角色/别名/对比度）
  → 生成 LiveDSO vault（ref.source.external + sys + style card）
```

生成物是派生物，源变化后必须重新生成。

## 二、P0 支持

- DTCG 风格 `$value` / `$type`；
- 单主题；
- 16 个 A 档核心角色；
- 生成 `ref.source.external.*`、`sys.color.*`、一个风格卡；
- `--dry-run` / `--check` / `--json`；
- 缺角色、坏别名、对比度失败直接 error。

不支持（后续）：

- Tailwind / CSS / Figma 输入；
- 多主题一次导入；
- 自动语义猜测；
- B 档角色自动补全；
- 组件 token 映射。

## 三、Mapping profile

```json
{
  "theme": { "id": "paper-brand", "name": "Paper Brand", "mode": "light" },
  "source": { "format": "dtcg" },
  "roles": {
    "bg": "color.background",
    "surface": "color.surface",
    "surfaceRaised": "color.surfaceRaised",
    "surfaceSunken": "color.surfaceSunken",
    "text": "color.text",
    "textMuted": "color.textMuted",
    "textInverse": "color.textInverse",
    "action": "color.action",
    "onAction": "color.onAction",
    "actionHover": "color.actionHover",
    "focus": "color.focus",
    "border": "color.border",
    "borderStrong": "color.borderStrong",
    "danger": "color.danger",
    "success": "color.success",
    "warning": "color.warning"
  }
}
```

- `theme.id` 只允许小写字母/数字/连字符；
- 16 个角色都必须映射；
- 源路径必须存在且 `$type=color`；
- 别名必须能解析；
- 对比度必须通过。

## 四、命令

```bash
cd design/projects/livedso
node src/cli.ts adapt \
  --source examples/adapt/source.tokens.json \
  --profile examples/adapt/profile.json \
  --out /tmp/adapted-brand

node src/cli.ts adapt ... --dry-run
node src/cli.ts adapt ... --check
node src/cli.ts adapt ... --json
```

## 五、输出结构

```text
<tokens/tokens.json>
  meta（sourceHash/profile/mode）
  ref.source.external.*   用户原 token（只读副本）
  sys.color.*             16 A 档角色
<style-cards/<theme>.style.json>
  roles → sys.color.*
README.md                 来源/hash/profile/计数
```

- 生成 vault 通过 `check-vault-schema.ts`；
- `style-card` 只含 A 档角色，B 档/预览 fallback 由 LiveDSO 处理；
- source hash 用于漂移检查。

## 六、失败语义

- 缺角色 / 源不存在 → error；
- 别名断链 → error；
- 颜色无法解析 → error；
- 对比度不足 → error；
- `--check` 发现生成物不一致 → error。

P0 不放宽到 warning；有真实客户后再决定是否允许显式豁免。
