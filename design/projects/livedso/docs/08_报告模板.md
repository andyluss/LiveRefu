# LiveDSO · 本地报告模板

> 状态：v1.19 ｜ 日期：2026-10-28 ｜ 原则：模板是本地 Markdown，不执行代码、不上传
> 相关：R05（变更日志）、本地 CI（`ci`）

## 一、模板来源

内置：

| id | 内容 |
| --- | --- |
| `health` | 完整健康报告（默认） |
| `release` | 发布摘要：健康/问题/token/契约/风格卡 |

自定义：

- 目录：`design/projects/livedso/templates/reports/*.md`；
- 文件名去掉 `.md` 即模板 id；
- 占位符替换，**不执行 JS**。

## 二、CLI

```bash
node src/cli.ts report --list-templates
node src/cli.ts report --template health --out reports/health.md
node src/cli.ts report --template release --out reports/release.md
node src/cli.ts report --template summary --out reports/summary.md
```

`report [vault] [out]` 仍可用；带 `--template` 时建议用 `--out` 明确输出路径。

## 三、占位符

| 占位符 | 值 |
| --- | --- |
| `{{title}}` | `LiveDSO Report` |
| `{{generatedAt}}` | 东八区时间 |
| `{{vault.root}}` | vault 绝对路径 |
| `{{vault.name}}` | vault 名称 |
| `{{vault.version}}` | vault 版本 |
| `{{score}}` | 健康分 |
| `{{errors}}` / `{{warnings}}` / `{{infos}}` | 计数 |
| `{{counts.tokens}}` | token 数 |
| `{{counts.deprecated}}` | 弃用 token 数 |
| `{{counts.contracts}}` | 契约数 |
| `{{counts.styleCards}}` | 风格卡数 |
| `{{issues}}` | Markdown 问题列表 |
| `{{tokensTable}}` | Markdown token 表 |
| `{{contracts}}` | 契约列表 |
| `{{styleCards}}` | 风格卡列表 |

未知占位符替换为空字符串。

## 四、示例

`templates/reports/summary.md`：

```markdown
# LiveDSO · Summary

> Vault: `{{vault.name}}` ｜ Generated: {{generatedAt}}

- Health: **{{score}}/100**
- Tokens: {{counts.tokens}}（deprecated {{counts.deprecated}}）
```

## 五、报告包

```bash
node src/cli.ts report --bundle --out-dir reports/bundle
```

生成：

- 全部内置与自定义模板（`health` / `release` / `inventory` / `summary` / `deprecations` / `contracts`…）；
- `index.md` 目录；
- 适合作为 CI artifact。

API：`POST /api/report/bundle` 返回 `{ files, index }`，不写服务器目录。

## 六、循环与条件

自定义模板支持安全的循环/条件，不执行代码：

```markdown
{{#tokens}}
- `{{path}}` — {{resolved}}{{#if deprecated}} · **deprecated**{{/if}}
{{/tokens}}
```

可用循环：

| 块 | 每项字段 |
| --- | --- |
| `{{#tokens}}…{{/tokens}}` | `path` / `tier` / `type` / `raw` / `resolved` / `deprecated` / `replacedBy` / `note` / `cssVar` / `file` |
| `{{#issues}}…{{/issues}}` | `severity` / `code` / `path` / `message` / `detail` |
| `{{#contracts}}…{{/contracts}}` | `id` / `title` / `status` / `summary` / `states` / `tokens` |
| `{{#styleCards}}…{{/styleCards}}` | `id` / `name` / `era` / `note` / `colors` |

条件支持嵌套：

```markdown
{{#if deprecated}}…{{#if replacedBy}} → `{{replacedBy}}`{{/if}}{{/if}}
```

示例：[`templates/reports/inventory.md`](../templates/reports/inventory.md)。

## 七、API / Workbench

- `GET /api/report/templates`
- `POST /api/report` body `{ "template": "release" }`
- Workbench Report 页选择模板后生成。

## 八、边界

- 只读本地模板文件；
- 不执行模板内代码；
- 不上传报告；
- 不接云/账号/团队。
