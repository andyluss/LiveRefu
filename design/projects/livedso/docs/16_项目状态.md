# LiveDSO · 项目状态（从纲领移入）

> 版本：v1.14 ｜ 日期：2026-10-28 ｜ 上位：[`design/canon/`](../../../canon/README.md)

## 一、定位

LiveDSO 是 LRDS 的**本地操作台与参考实现**：

- 读取 DTCG 风格 vault；
- 解析别名、契约、角色、对比度；
- 投影 CSS、生成报告；
- 本地优先，不接云/账号。

## 二、当前状态

- LRDS schema 增加可选 `component` 层；
- 11/11 vault 通过严格 schema：`meta + ref + sys + component + product`；
- 原生源在 `ref.source.<vendor>`，scale 在 `ref`，组件在 `component`，角色在 `sys`/`product`；
- A 档 16 角色进 `sys.color.*`，其余进 `product.<card>.role`；
- 原始色进 `ref.generated`；
- `theme-roles.tokens.json` 已移除；
- `livedso-v2.0.0` 仅作为实验 tag 保留。

## 三、命令

```bash
cd design/projects/livedso
npm test
npm run schema:check
npm run skin:check
npm run skin:snapshot
```

## 四、边界

- 不修改 LRDS 核心规则；
- 新角色/组件先回流 `design/canon` 与 `design/rules`，再进入项目；
- 项目内文档只记录实现，不复制纲领。
