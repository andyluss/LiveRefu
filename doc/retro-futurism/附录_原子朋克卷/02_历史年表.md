# 原子朋克 · 历史年表

> 关键词：编年史；原子乐观；核末日；命名；Fallout
>
> 摘要：原子朋克的历史按"许诺—过时—命名—混血"四段展开，本篇以年表呈现（太空侧细节见主卷 09，末日侧见主卷 16）。

## 读法

年表的戏剧性在于：**许诺（1953—1958）与末日叙事（1959—1964）几乎同时发生**——原子朋克不是先乐观后悲观，而是自始双轨。2008 年命名时，回望者打包回收的正是这份自始存在的拧巴（见 00 对读篇）。
