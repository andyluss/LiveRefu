# doc · 复古未来主义知识库（索引）

> **这是什么**：本工作区的**题材知识库**——收集"过去时代所想象的未来"，以及这些未来如何被回收、消费与再创造。
> **这不是**：不是项目文档（那些在各 `projects/*/docs/`），也不是工程约定（那些在 [`rules/`](../rules/README.md) 与 [`tech/`](../tech/README.md)）。
> **怎么用**：下面三卷**各自自成体系、各有独立卷首**。**从本索引进去，再按各卷的卷首读**——
> 本文只维护"有哪几卷、入口在哪"，**不维护卷内清单**（两处清单必然分叉）。

## 三、约定

- **题材权威在本目录**：工作区其它部分（如 [`projects/mainline/`](../projects/mainline/README.md)）**引用**本目录的结论，**不复制、不改写**。
- **各卷自成体系**：卷内结构、阅读顺序、篇目一览一律见各卷 `README.md`。
- **本目录豁免 M1/M2 的结构与命名要求**（见 [`rules/README.md` §三](../rules/README.md)）——它是知识库，以内容为目的而非工程结构。
  但**文档体例（[R01](../rules/R01-docs-convention.md)）与链接校验（[R03](../rules/R03-link-validation.md)）仍然适用**：豁免不等于可以写坏链接。
- **本索引何时更新**：**新增 / 移除 / 改名一整卷时**。卷内加篇不必改本文（改该卷自己的卷首）。
