## 一、定位与缘起

**生物朋克（Biopunk）**指以基因工程、湿件等生物技术为技术底座、延续赛博朋克"高科技低生活"基调的朋克系文类与设定（定义见 01）。与蒸汽朋克等"回望型"支系不同，它的主流姿态是把生物学当下外推为近未来，不在"过去的未来"里寻找素材；因此在《复古未来主义论文集》（doc/retro-futurism/）主卷的朋克谱系表上，它至今仅以一行条目出现（主卷 12 谱系篇："基因工程主导的近未来……1990 年代科幻圈已见用例，词源存疑"），并无专篇。本卷即补此缺口，先在独立目录 doc/biopunk/ 成稿；卷首 00 对读篇负责把生物朋克放回"复古未来主义"的坐标系。

## 二、命名史现状：缺乏公认定论

与蒸汽朋克不同——后者一般认为有 1987 年可考的信件用例作命名原点——**biopunk 一词没有公认的命名原点**：先行词 ribofunk 归于保罗·迪菲利波（1990 年代，同名结集一般认为 1996 年前后，存疑）；biopunk 本身约在 1990 年代末至 2000 年代经网络社群与"朋克盘点"类词条化清单流通（存疑）。故本卷存疑标注密度高于多数朋克支系，读者引用时请连带标注。
