# 11 · 数值框架表（每卡一表）

> 卡面：用途＝数值工作基线 ｜ 依赖：[02_卡片规则系统](02_卡片规则系统.md) ｜ 状态：v0.1 · 2026-09-14
> 一句话：**一张卡＝一张表＝一个独立数值块**；卡表之间不互相引用数值，只通过标签与槽位交互。

## 一、三条硬规则

1. 每张卡独立建表，改卡只改本表（[02](02_卡片规则系统.md) 五律之四）；
2. 表内数值不写"引用他卡数值"，需要联动时用标签与触发钩子；
3. 每张表带版本号（v0.x → v1.0 冻结）与状态（草案/测试/冻结）。

## 二、通用字段（所有卡必填）

| 字段 | 含义 |
| --- | --- |
| card_id | 唯一 ID：`族-类-序号`（如 `ANV-T01`） |
| name / type / owner | 名称 / 七类卡之一 / 主族·从族·中立 |
| cost / slot | 费用 / 合法槽位 |
| tags | 羁绊与克制用标签（如 `护盾`、`腐蚀`、`弹药`） |
| cooldown / target | 冷却 / 目标类型（地面/空中/单体/群体） |
| values | 数值块（见第三节，按类型填） |
| hooks | 触发钩子（on_kill / on_wave_end / on_shield_break 等） |
| version / status | 版本 / 状态 |

## 三、按类型的数值块模板

| 类型 | 数值块字段 |
| --- | --- |
| 塔卡 | 伤害、攻速、射程、溅射半径、穿透、特殊效果 |
| 单位卡（含支援） | 生命、攻击、攻速、射程、移速、人口占用、存在时间 |
| 技能卡 | 效果值、持续时间、作用范围、能量消耗 |
| 修饰卡 | 修正值（±%）、触发条件、叠加规则、上限 |
| 地图卡 | 塔位数、路径长度、地形修正、事件槽数 |
| 波次卡 | 敌人构成、数量、出场间隔、波次预算 |
| 事件卡 | 触发条件、持续时间、全局修正 |
| 规则卡 | 资源上限、胜利条件、禁用/替换卡类、模式参数 |

## 四、示例（铁砧联邦，占位首值待数值轮次）

| card_id | 名称 | 类型 | cost | 数值块要点 |
| --- | --- | --- | --- | --- |
| ANV-T01 | 模块炮塔 | 塔卡 | 20 | 伤害 12 / 攻速 1.0/s / 射程中 / 无溅射 |
| ANV-M01 | 齿轮帮·维修工 | 单位卡（支援） | 15 | 修复 8/s、持续 6s、人口 1 |
| ANV-X01 | 交叉火力 | 修饰卡 | — | 同标签塔 +15% 攻速，最多叠 2 层 |

## 五、全局曲线（与卡表分离，单独建表）

- 能量增长：基础速率 + 击杀返还；关卡预算 = 波次预算 × 系数；
- 难度公式与卡片预算见 [06_关卡与地图卡](06_关卡与地图卡.md)；
- 成长上限：等级增益 ≤ +20%，变体改机制不改数值上限（[08](08_成长与经济.md)）。

## 六、调参流程（与 R05 衔接）

改一张卡：改卡表 → 记录（card_id / 旧值 / 新值 / 原因）→ 根 [`CHANGELOG.md`](../../CHANGELOG.md) 记一行 → 卡表版本号 +0.0.1。
