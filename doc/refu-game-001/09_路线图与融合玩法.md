# 09 · 路线图与融合玩法

> 卡面：用途＝玩法如何扩展、版本怎么排 ｜ 依赖：[02](02_卡片规则系统.md)、[06_关卡与地图卡](06_关卡与地图卡.md)、[00_决策记录](00_决策记录.md)（D9）｜ 状态：v0.2 · 2026-09-14

## 一、核心机制：玩法 = 规则卡组

每种玩法都是一套**规则卡**（资源规则、胜利条件、禁用/替换卡类、地图与波次限制）：

- 首发包「**塔防基础**」：固定路径 + 塔位 + 波次防守；
- 融合 = 换一套规则卡，而非改底层或加系统补丁；
- **难度轴与玩法轴正交**：玩法由规则卡决定，难度由挑战卡（见 [06](06_关卡与地图卡.md)）决定。

## 二、挑战卡：向赛季与排行榜延伸（D9）

- 常规关卡：挑战卡自愿叠加，用于自我挑战与素材加成；
- 赛季模式：每期限定挑战卡池 + 合约总分排行榜，是低成本的长期目标系统；
- 与异步 PvP 组合：同一关卡比"谁能在更高合约总分下通关"。

## 三、可规划的融合包（按优先级）

| 包 | 规则卡要点 | 复用的既有卡 |
| --- | --- | --- |
| Roguelike 远征 | 关卡链、每关三选一永久修饰、失败即结束 | 塔卡、修饰卡、地图卡 |
| 潜行/护送 | 目标卡、视野与警戒、限时 | 单位卡、事件卡、地图卡 |
| 自动战斗 | 预设卡组自动施放，玩家只调卡组 | 全部战斗卡 |
| 异步 PvP | 双方波次卡组互为对手，录像/快照结算 | 波次卡、规则卡（公平模式） |
| 双人合作 | 共享基地、分工卡池 | 支援卡、事件卡 |

## 四、版本路线

- **v0.1 原型**：单主族、10 张卡、2 张地图卡，验证"卡片即规则"手感；
- **v0.3 三族 PvE**：三主族 + 三从族支援卡、20 张卡组、战役前 3 章、首批挑战卡；
- **v0.6 赛季与异步**：周常长局、异步 PvP、挑战卡总分排行榜、赛季通行证（外观）；
- **v1.0 融合玩法包**：接入 1 个融合包（优先 Roguelike 远征）+ 关卡编辑器**内测**（D10）；
- **v1.x 之后**：编辑器内测达标 → 开放 UGC 分发（门槛与审核方案按 D10 细化）。

## 五、扩展性验收标准

新增一个玩法包时，以下三项必须成立，否则说明卡片系统耦合过紧：

1. 不改动既有卡的规则层字段；
2. 新玩法可由 1–3 张规则卡 + N 张内容卡完整表达；
3. 移除该玩法包后，其余模式与存档不受影响（remove-safe）。
