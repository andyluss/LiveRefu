## 一、这份设定要解决什么

策划案锁定了玩法与数值，但没写"它长什么样"。001 号美术设定把 [D7 美术基调](../../00_决策记录.md) 展开成可执行的东西：材质、色板、剪影、卡面版式、动效与生产规范。

它的底线只有一条：**美术不解释机制，机制先于美术**。所有视觉决定都能回指到策划文档的某一条（种族机制、卡表、地图表、界面规范）。

## 四、怎么用

1. **先锁风格卡**：主美术出 1 张风格卡（含三族各一单位 + 一张地图 + 一张卡面），评审通过后本目录才进入批量生产；
2. **按族分包**：01／02 号文件是识别基准，任何新单位先过"黑白剪影能否认出族"这一关；
3. **改数值必须回头改美术**：数值一变，[03 卡牌视觉规范](03_卡牌视觉规范.md)、[06 动效与特效](06_动效与特效.md)、[07 敌人与BOSS视觉](07_敌人与BOSS视觉.md) 三处要同步，见 [09 号文件](09_生产管线与审查清单.md) 的同步机制。

## 四、与 002 的关系

[002 号方案](../美术设定002/README.md) 是"六族全透明化"的千禧美学平行提案，**有意与本案不同**（材质、光照、信息载体全换，数值与机制不动）。两案的叫法对照见 [002 的术语对照表](../美术设定002/11_术语与命名对照.md)，差异清单见 [002 的冲突清单](../美术设定002/10_与策划案的冲突清单.md)。
