配方

L1 体表膜n ≈ 1.55（全案最高）；无瑕疵大切面；色散只在棱线
L2 内芯光棱镜白 + #5FE3D6；亮度随共鸣计数三档
L3 界面层棱面刻字与编号，不受折射影响
L4 边缘光细锐菲涅尔 2–3 px；接通时偏护盾青；禁柔光与 Bloom 溢出
主光性格最硬：2 px 高光条沿棱走，阴影锐利
专属补光掠射灯 15°／0.25，扫出切面节奏
粒子全息尘 16；禁水痕与杂物
