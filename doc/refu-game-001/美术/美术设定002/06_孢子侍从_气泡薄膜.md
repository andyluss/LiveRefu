# 06 · 孢子侍从：气泡薄膜

> 卡面：用途＝孢子侍从透明细案（气泡与肥皂膜）｜ 依赖：[00_主题宣言](00_主题宣言_千禧透明美学.md)、[01_透明体系总则](01_透明体系总则.md) ｜ 数值：[15](../../15_卡表_涌潮虫群核心12卡.md)、[数值／02](../../数值/02_涌潮虫群_12卡.md) ｜ 考据：[设定圣经](../../故事/小说_节点之海/00_设定圣经.md) ｜ 状态：v0.1 · 2026-09-14

**主张**：孢子侍从是战场上最薄的一层透明，一层会呼吸的肥皂膜。腐蚀在它身上不是数字，是膜的厚度。

**数值口径（只引用不改）**：腐蚀每层 +3% 受伤、上限 5 层。菌毯扩张 TID-M01 14 费、敌人 −10% 移速、友方腐蚀伤害 +10%、范围 2 格、人口 1、每波范围 +1 格。孢子孵化 TID-M02 18 费、召唤 3 只幼虫、人口 1、到期留腐蚀地 5s。腐蚀附着 TID-M03 12 费、为 1 张塔卡附加「腐蚀」标签、不占人口、附着时目标 +1 层。羁绊酸蚀（3 张「腐蚀」全场腐蚀伤害 +15%）、巢群（2 张「孵化」每波自动产 1 只幼虫）。见 [15](../../15_卡表_涌潮虫群核心12卡.md)。

## 一、为什么透明

| 层 | 答案 |
| --- | --- |
| 世界观 | 它本身是一层膜，是"把坏的东西搬走"的生物工具，膜即工作界面：菌丝伸手抓取，层数随膜进出 |
| 机制 | 层数必须被看见：腐蚀每层 +3% 受伤、上限 5 层，长在膜上比长在 UI 上直观 |
| 心理 | 肥皂泡短暂而美丽，破的一刻最好看；千禧审美偏好轻、脆、干净，它慢、软、有耐心 |

## 二、材质配方

| 层 | 配方 | 状态映射 |
| --- | --- | --- |
| L1 体表膜 | 薄膜干涉虹彩，色带沿膜厚呈同心环｜厚 90–340 nm｜n＝1.33｜雾度 8% | 厚度随情绪与负载变：待机 180 nm，受击 90 nm，每层 +30 nm。破裂阈值：5 层张力最高，最薄处先破 |
| L2 内腔光核 | 苔绿偏青柔光，被膜包住的漫射体，从内壁照亮膜 | 亮度＝携带层数：20%／34%／48%／62%／76%／90% |
| L3 界面层 | 菌丝在膜上生长的纹路｜赤道 5 个刻度点，等距 72° | 每拾 1 层逆时针亮 1 点，菌丝覆盖每层 +8%，5 层绕满 |
| L4 边缘光 | 膜边缘的高光必须最亮，这是它比别的族更飘的原因 | 受击收窄变锐，呼吸时外缘亮环比膜面亮 40% |

禁令：不得用半透明贴图假装薄膜，内部结构必须真画。

## 四、造型与比例

几何语言：球与泡、薄膜褶皱、悬浮孢子团，没有直角与棱。剪影规则：泡状轮廓 ＋ 一个不透明内核，全黑下只看边缘光也要读出泡里有一颗核。

| 部件 | 占高 | 透明档 | 说明 |
| --- | --- | --- | --- |
| 体表膜 | 100% | 全透 | 最薄处 2 px 等效屏厚 |
| 内腔光核 | 45% | 雾透 | 苔绿偏青漫射团 |
| 孢子核 | 22% | 不透明 | 唯一硬芯，腔体中下部，朝向锚点 |
| 根须 | 30% | 不透明 | 1–3 条，扎进菌毯 |

内部结构：菌丝、孢子团、正在被搬运的腐蚀液、刻度点、气室（破裂起点）。**不透明芯放在孢子核（胸腔位）与根须（下缘）**。

## 五、个体「芽」的视觉

小说口径：不到谢临胸口高、没有眼睛但有脸、裹着发白的一层、做事很慢，是全族最薄的一个。

| 项 | 规格 |
| --- | --- |
| 体型 | 高 1.2 m、泡径 0.9 m、核径 0.2 m |
| 慢速动作 | 抬脚—停顿—落地，单步 1.2 s，转身 2.4 s，膜比核晚 3 帧到位 |
| 说话 | 膜面浮字，每字间隔 0.4 s，字号不随膜形变 |
| 「拉」的动作 | 菌丝钩住目标的腐蚀纹→腐蚀液沿菌丝流回芽、目标刻度灭一颗→芽膜胀一圈、刻度亮一颗、核亮一档、浮出新虹彩环，全程 1.6 s，禁止吸附式高速，收尾把一片膜贴回目标 |
| 与幼虫、母巢同框 | 母巢 2.4 m、芯 40%、居中，幼虫 0.5 m、芯 25%、成排，芽 1.2 m、芯 12%、边缘支援位。边缘光按越轻越亮排序：芽 > 幼虫 > 母巢 |

## 六、逐卡视觉要点

| 卡 | 落场 | 持续中 |
| --- | --- | --- |
| 菌毯扩张 TID-M01 | 根须扎地，薄膜状菌毯从脚下摊开（0.9 s），边缘一圈青虹彩 | 全透无核的平地膜，只有边缘光与流动菌丝。每波范围 +1 格时边缘重涨一圈，无核反衬芽的有核 |
| 孢子孵化 TID-M02 | 大泡鼓起，泡内 3 个孢团在转，0.6 s 后壁从三点破开，3 只幼虫分三向落地 | 残膜留地瘪下；到期向内塌成腐蚀地，地面冒 5 s 酸黄绿小气泡逐个破掉计时 |
| 腐蚀附着 TID-M03 | 芽撕下膜上一小片贴到目标塔卡，目标覆一层半透湿绿膜 | 膜留在塔卡上，看得见菌丝在爬，每 +1 层多一圈波纹，随目标受击闪动 |

## 七、动效

| 状态 | 表现 | bling |
| --- | --- | --- |
| 待机 | 呼吸式膨胀收缩 ±4%，高光滑过泡顶，核亮度同步 ±6%，周期 2.4 s | 级 2（低端降级 1） |
| 搬运层数 | 腐蚀液沿菌丝流动，≤8 粒微粒，膜胀—亮刻度—抬核亮依次发生，1.6 s | 级 2（≤12 粒） |
| 层数到 5 | 膜面满格：5 点连成一圈、通体泛光、菌丝绕满，到达瞬间一次环状脉冲 | 泛光级 1＋脉冲级 3 |
| 破裂 | 留一圈光并释放孢子：气室先裂，炸出青虹彩光环（留 0.5 s），6–10 颗孢子飘散落地 | 级 3（≤40 粒） |
| 被摧毁 | 膜不发亮地内瘪，核落地滚一段后熄灭，只剩湿苔影余烬 | 级 2（≤12 粒） |

闪烁 ≤ 3 Hz 且不覆盖超过 25% 屏幕；呼吸只作用 L1 与 L2，L3 刻度不缩放。

## 八、UI 表现

| 位置 | 表现 |
| --- | --- |
| 卡面薄膜质感 | 深苔底压暗，正面覆 60 nm 等效薄膜，虹彩只在倾斜 25°–60° 出现 |
| 模型层数 | 刻度点＋膜厚（虹彩环数）＋核亮度三重冗余，任一被挡另两者仍可读 |
| 卡面层数 | 右下角 `n／5`，最高对比白，永远最亮，不带虹彩与光晕 |
| 羁绊酸蚀 | 全场孢子侍从膜面同时泛满格酸黄绿，并从刻度环拉细线连向相邻「腐蚀」卡 |
| 羁绊巢群 | 每波开始菌毯边先鼓 3 个小泡，1 个落地成幼虫、2 个瘪掉 |

## 九、好处清单

1. **层数可视化**：腐蚀每层 +3% 受伤、上限 5 层有了不看 UI 的读法。
2. **腐蚀流动的叙事性**：腐蚀液在菌丝里流进流出可见，看得懂这层是拉来的。
3. **与光尘侍从的区分**：一个用箔的色散，一个用膜的厚度干涉。
4. **治愈动作的温柔感**：最薄最慢最亮的材料，把辅助做成战场上最好看的事。
5. **失败的节奏感**：泡一定会破，破裂留的那圈光把消耗变成可期待的节拍。

## 十、弱点与对策

| 弱点 | 对策 |
| --- | --- |
| 薄膜在手机上太难看见 | 最小可见厚度：最薄处等效屏宽 ≥ 2 px｜边缘光提到同屏最高｜核亮度兜底 |
| 虹彩与背景撞色 | 虹彩限定角度 25°–60°｜菌毯区背景压暗 20%｜与深苔绿留 ≥ 40% 明度差 |
| 破裂特效与死亡混淆 | 破裂＝向外扩的青虹彩光环、膜上翻｜死亡＝膜内瘪、不发亮 |
| 性能（透明排序与 overdraw） | 同屏全透 ≤ 6、单帧透明层 ≤ 8｜膜用单面折射，远 12 格降雾透 |

## 十一、验收清单

1. 全黑剪影下能读出泡＋不透明核＋根须，且无第二个不透明体。
2. 不含 UI 的截图上任取一个孢子侍从，只靠膜面能数出 1–5 层。
3. 转灰度后 1 层与 5 层仍可分，差异来自刻度点数而非只有颜色。
4. 关闭级 2／级 3 bling 后，材质、层数、朝向仍全部可读。
5. 同屏 6 个全透孢子侍从＋12 只幼虫＋2 张菌毯，透明层 ≤ 8，闪烁 ≤ 3 Hz。
6. 任意状态下费用数字与 `n／5` 都不被光效覆盖或降低对比度。
