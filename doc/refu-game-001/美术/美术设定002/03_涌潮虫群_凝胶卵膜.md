# 03 · 涌潮虫群：凝胶卵膜

> 卡面：用途＝涌潮虫群在 002 号方案下的材质、色板、造型与验收 ｜ 依赖：[00_主题宣言](00_主题宣言_千禧透明美学.md)、[01_透明体系总则](01_透明体系总则.md) ｜ 引用：[03](../../03_种族总览.md)、[15](../../15_卡表_涌潮虫群核心12卡.md)、[数值/02](../../数值/02_涌潮虫群_12卡.md) ｜ 状态：v0.1 · 2026-09-15
> 涌潮的透明不是玻璃，是湿的：凝胶、卵膜、水母体，会呼吸，里面有东西在动。

## 一、为什么透明

| 层 | 论证 | 画面后果 |
| --- | --- | --- |
| 世界观 | 卵是招牌、幼虫是传单、母巢是广告牌 | 地盘要有看得见内部的卵、囊、腔、膜 |
| 机制 | 进化枝与孵化上限（[孵化巢](../../数值/02_涌潮虫群_12卡.md) 上限 3、母巢上限 5）是累积量 | 卵串满溢＝孵化进度，刻度填满＝进化条件 |
| 心理 | 柔弱、恶心、美三者共存，即千禧果冻审美 | 圆润轮廓配直白内脏，靠看得清楚而非看得脏 |

001 靠泥浆甲壳成立，002 必须先排内脏再画外壳。

## 二、材质配方

| 部件 | 参数与建议值 |
| --- | --- |
| 体表膜 | 折射率 n 1.33 至 1.42，母巢 1.40（越低越水） |
| 体表膜 | 雾度 8% 至 18%，受伤临时升 30% 表浑浊 |
| 体表膜 | 膜厚 0.6／1.2／2.4mm（幼虫／成虫／母巢） |
| 体表膜 | 薄膜干涉虹彩 420 至 560nm，随镜头滑动 |
| 内腔光核 | 基色 `#5BF0C0`，随腐蚀层数与孵化进度变色 |
| 内腔光核 | 脉动 0.25／0.8／2.4Hz，上限 3Hz |
| 界面层 | 孢子与菌丝吸附膜面作刻度：点＝计数，线＝连线 |
| 界面层 | 1 格＝1 层腐蚀或 1 轮孵化，与层数一一对应 |
| 边缘光 | 菲涅尔 1.5／2.5／4px（幼虫／成虫／母巢） |
| 边缘光 | 湿润边缘与水痕，底部连续顶部断续 |

三档分工：外壳与卵膜全透（>80%）负责宣传，内脏与腐蚀液半透（40% 至 80%）是招牌层，骨架与甲片雾透（<40%）给重量。

## 三、色板

| 色系 | 名称与十六进制 | 用途 |
| --- | --- | --- |
| 腐殖绿主色 | 腐殖深绿 `#0E1F16` | 不透明芯底色与阴影 |
| 腐殖绿主色 | 腐殖绿 `#3E7A4E`、藻绿 `#5FA86B` | 体液／菌丝刻度 |
| 腐殖绿主色 | 凝胶绿 `#7FD08A`、浅膜绿 `#BCE8C4` | 膜高光／膜边缘 |
| 生物荧光 | 荧光青绿 `#5BF0C0`、荧光柠檬 `#D6FF6B` | 卵核常驻／就绪与进化达成 |
| 生物荧光 | 糖果青 `#6BE8FF`、荧光洋红 `#FF7BD5` | 操作反馈／母巢警戒 |

| 状态 | 色值 | 冗余与读法 |
| --- | --- | --- |
| 腐蚀 1 至 5 层 | `#8FBF6A`／`#B7C24E`／`#D8A63C`／`#C6613A`／`#8E2F3E` | 单斜纹至点阵加外扩波纹，第 5 层触发腐蚀喷口的 on_stack5 范围 +20% |
| 孵化 0 至 33／34 至 66／67 至 99／就绪 | `#4E7F63`／`#7FD08A`／`#D6FF6B`／`#FFF3B0` | 卵串稀疏／占腔一半／撑出膜凸／就绪环可点击 |

## 四、造型与比例

| 项 | 规则 |
| --- | --- |
| 几何语言 | 水滴、卵形、触须：主卵形加水滴子体加菌丝连线，禁直角与锐角 |
| 比例 | 幼虫 1:1.2 扁圆低重心，成虫 1:1.6 拉长有颈，母巢 1:2.2 横向扩张 |
| 剪影规则 | 幼虫＝单卵形加短触须，成虫＝卵形加雾透头甲加下垂触须，母巢＝卵形底座加裂开产道。纯黑下两两可辨 |
| 内部结构 | 消化腔、卵串、腐蚀液流动、菌丝。腐蚀液从尾流入口器，兼作朝向指示 |
| 不透明芯 | 幼虫＝口器与颚片，成虫＝口器加背甲，母巢＝产道钙化环，卵核是唯一完全不透光处 |

## 五、逐卡视觉要点

| 卡 | 透明化后的样子 |
| --- | --- |
| TID-T01 孵化巢 | 半透囊体，腔内 3 枚卵串，每 8s 一枚破裂出幼虫 |
| TID-T02 腐蚀喷口 | 漏斗凝胶囊，液面高度即层数，5 层时外扩亮波纹 |
| TID-T03 酸液喷射者 | 细长成虫，背部酸液囊明暗交替，落点留 3s 腐蚀液 |
| TID-T04 群落粘网 | 菌丝织的半透黏膜，腐蚀目标经过的网眼更窄 |
| TID-M01 菌毯扩张 | 地面薄菌毯，菌丝爬出一格即转凝胶绿 |
| TID-M02 孢子孵化 | 升空孢子囊，膜内可数 3 个幼虫轮廓，破裂留 5s 腐蚀地 |
| TID-M03 腐蚀附着 | 带菌丝触手的小孢子，攀附后目标补一格刻度 |
| TID-S01 群体孵化 | 全场卵膜波纹，6 处水泡同时破裂，孵化巢亮加速底纹 |
| TID-S02 腐蚀风暴 | 战场覆一层抬升的腐蚀液，光核转暖色，刻度满格 |
| TID-X01 酸蚀腺体 | 宿主一对搏动腺体，伤害增益即腺体增大 |
| TID-X02 快速孵化 | 膜面多一圈加速水痕，召唤物更脆即膜更薄更透 |
| TID-X03 过度繁殖 | 多叠一层半透膜带独立刻度，是「孵化」标签凭证 |
| TID-T01E 母巢 | 由孵化巢替换：囊体撑至 2 格、产道裂开、卵串 3 增至 5 枚，产出更快，获「腐蚀」后转暖色 |
| TID-M02E 孢子母体 | 由孢子孵化替换：5 个轮廓外加护盾膜，护盾用圆润边缘以免混同星辉 |

## 六、动效

| 状态 | 表现 | bling 级 |
| --- | --- | --- |
| 待机呼吸与搏动 | 0.25Hz 体积呼吸，光核随明暗，幅度 ≤ 6% | 级 2，≤ 4 粒 |
| 孵化 | 卵下沉、膜鼓起、虹彩增亮、破裂溅水痕 | 级 3，≤ 40 粒 |
| 叠层到 5 层 | 色相推到 `#8E2F3E`，刻度补满并扩散波纹环，触发 on_stack5 范围 +20% | 级 3，≤ 40 粒 |
| 进化枝触发 | 旧膜变白近乎只剩骨架，新形态撑破旧膜长出 | 级 3，≤ 40 粒 |
| 死亡 | 不爆炸而是破裂瘪掉，地面留残膜与水痕 | 级 1，零成本 |
| 腐蚀风暴 | 全场液面抬升，光核同步变色，刻度满格 | 级 3，一次性 |

红线：闪烁 ≤ 3Hz 且不覆盖超过 25% 屏幕，孵化与死亡不同时用全屏粒子。

| 位置 | 做法 |
| --- | --- |

| 羁绊巢群 | 2 张「孵化」触发，两卡卵鞘间出现脉动菌丝脐带 |
| 羁绊缠缚 | 2 张「拦截」触发，两张粘网吸附成一整片 |
| 数值层 | 能量、基地生命、漏怪计数与卡面数字用不透明实心字块 |

## 八、好处清单

1. 孵化进度不必读数字：卵串拥挤度与就绪环把上限 3 与上限 5 直接画出来。
2. 层数可数：5 层上限与每层 +3% 受伤靠五格刻度与五档色长在敌人身上。
3. 母巢自带压迫感：能看见 5 枚卵在动的巨型囊体，比数值面板更能预告波次。
4. 同屏区分度高：铁砧方正、星辉棱形、涌潮圆润流动，密集波次不混淆。
5. 机制统一为一种材质：进化枝、孵化、腐蚀、羁绊共用凝胶卵膜语言。

## 九、弱点与对策

| 弱点 | 对策 |
| --- | --- |
| 透明生物辨识度低 | 加粗 L4 描边，超过 8 只只留描边与口器实心点 |
| 叠放与排序开销大 | 遵 [01](01_透明体系总则.md) 上限与降档，后层降 20% 亮度，超阈值切剪影 |
| 恶心度失控 | 内脏做糖果凝胶质感，禁血迹腐肉，产道用雾透只留轮廓 |
| 性能与 overdraw | 低端机只留级 1 与 L4，内部结构降为贴图，远镜头停折射 |
| 护盾膜与星辉撞车 | 护盾保持圆润凝胶边缘，仅受击闪一次棱形高光 |
| 色弱读不出层数 | 五档配条纹点阵冗余，刻度可数，就绪态另给形状提示 |

## 十、验收清单

1. 截图能指出体表膜、内腔光核、界面层、边缘光，且三档透明度并存。
2. 转黑白剪影后，幼虫、成虫、母巢仍可独立认出，朝向可读。
3. 腐蚀 1 至 5 层彩色与去色均可区分，第 5 层带外扩波纹环。
4. 孵化巢逼近 20 只时出现进化前兆，母巢与孢子母体有别于基础卡。
5. 闪烁 ≤ 3Hz，内发光有预算，透明单位与层数满足 [01](01_透明体系总则.md) 红线。
