## 一、这是什么

002 号方案是**有意与策划案基调不同的平行提案**：它把三主族与三从族全部改成**透明或半透明体质**，主题取自千禧年前后（Y2K、透明消费电子、水光界面、镭射文具）推崇的**透明感、光耀感与 blingbling 感**。

- 它不是 001 的修订版，而是另一种答案：001 问"旧机器里怎么装未来"，002 问"未来刚拆封时长什么样"；
- 它**不改任何数值与机制**（B 值、卡费、胜率、羁绊阈值全部沿用策划案），只在材质、光照、色彩、动效与信息载体上分道；
- 六族的透明不是"都变透明了"这么一句：每族有各自的**透明原因、材质配方、可见内部结构、机制收益与代价**，逐族见 02–07 号文件。

## 三、怎么用这份设定

- **提方案**：把 002 当成"另一种可以选的未来"，与 001 并列给决策者看；
- **做验证**：只挑一族（建议从齿轮帮或孢子侍从起）做一两张风格图，验证"透明主体在手机小屏上是否还可读"；
- **写文档**：任何 002 文档里的机制描述，若与策划案冲突，以策划案为准。

## 四、一条底线

透明是**信息设计**，不是滤镜：玩家必须能通过透明看到"塔里插了什么、虫群长到哪一步、共鸣接到谁、护盾还剩多厚"。如果一张图只是把东西变透明而没有让机制更清楚，它就不属于这份设定。
