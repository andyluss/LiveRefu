## 二、质感层（本批统一加了四件事）

1. **内发光**：中心径向高光（`url(#inner)`），让透明材质"有芯"；
2. **薄膜干涉**：虹彩光带（`url(#iri)`）——只走页眉与页脚，**不压数字与文案**（这是可读性红线）；
3. **折射畸变**：`feTurbulence + feDisplacementMap` 生成的边缘重影，模拟玻璃边界；
4. **掠射高光**：左侧镜面条 + 整体 sheen，负责"刚拆封"的塑料感。

001 的样例用另一套：沙尘噪点 + 扫描线 + CRT 辉光（复古未来口径）。

## 五、怎么用与再生成

- 卡面里的每个数字都来自 14 / 15 / 16 号卡表，**图不创造数值**；改数值时必须重跑生成器；
- 生成器逻辑：解析卡表数据 → 套用统一模板（页眉箔带 / 画框纹章 / 三数值块 / 槽位色带 / 边缘光）→ 输出 SVG → `rsvg-convert` 出 PNG/PDF；
- 单张导出：

```bash
rsvg-convert -w 700 卡面/ANV-T01_模块炮塔.svg -o out.png
rsvg-convert -f pdf 卡面/ANV-T01_模块炮塔.svg -o out.pdf
```
