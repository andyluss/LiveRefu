## 二、写作约定（卡片式）

- 每篇文档先给**卡面**（用途／依赖／状态），再展开 3–6 个小节，单篇不超过约 800 字；
- 一切设定以"卡"为单位表达：可独立阅读、可替换、可移除；
- 未定项标 **【待定】**，裁决后写入 [00_决策记录](00_决策记录.md)；
- **变更记录（方案 C：分层混合）**：根 [`CHANGELOG.md`](../../CHANGELOG.md) 是唯一权威；本卷仅"契约类"文档——[00_决策记录](00_决策记录.md)、[02_卡片规则系统](02_卡片规则系统.md)、[11_数值框架表](11_数值框架表.md)——维护文末「修订记录」小表；细粒度历史看 `git log -- <文件>`，错别字/格式不记（R05 琐碎豁免）；
- 简体中文、相对链接；日期取系统东八区时间。
