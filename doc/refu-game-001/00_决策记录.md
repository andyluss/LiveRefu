# 00 · 决策记录（Refu Game 001）

> 卡面：用途＝锁定全卷前提 ｜ 依赖：无 ｜ 状态：**已裁决** v1.3 · 2026-09-14
> 任一决策变更时，改写本文件并在根 [`CHANGELOG.md`](../../CHANGELOG.md) 记账。

## D1 种族原型与命名 → **保留气质 + 原创命名设定**

借鉴三族"互克且体系完整"的结构方法，命名/世界观原创；从族（小跟班）同为原创。命名细节见 [03_种族总览](03_种族总览.md)，属 v0.1 可改。

## D2 塔防核心形态 → **固定路径 + 固定塔位**

棋盘可控、手机触控友好；"路障改道/自由迷宫"作为未来**规则卡组**扩展（见 [09_路线图与融合玩法](09_路线图与融合玩法.md)），不进入首发。

## D3 卡片化深度 → **全要素卡化（含地图/事件）**

单位、塔、技能、建筑、事件、地图板块同属一套卡规范；"高内聚松耦合"是规则目标，不只是 UI 皮肤。核心规范见 [02_卡片规则系统](02_卡片规则系统.md)。

## D4 从族定位 → **主族卡池内的支援/召唤卡**

每主族配一个从族，以支援卡形态随主族出战；不单独成阵营、不改变主族体系完整度。

## D5 单局节奏 → **碎片关 3–5 分钟 + 周常长局**

日常：3–5 分钟一关（约 6–8 波）；周常：加长波次 + 特殊规则卡的长局。

## D6 商业化 → **外观 + 便利付费，不卖数值**

卡牌通过游玩解锁；付费只买外观、赛季通行证与便利（如卡组栏位），卡牌数值不进入商店。

## D7 美术基调 → **延续工作区"复古未来"**

与本工作区 `doc/retro-futurism/` 知识体系及既有项目资源联动；具体年代拼贴风格由主美术出风格卡后再定。

## D8 对抗形态 → **PvE 为主 + 异步 PvP**

首发纯 PvE；异步 PvP（对手波次卡组录像/快照）作为第二层；实时 PvP 留作远期规则卡组实验。

## D9 难度修饰 → **采纳"挑战卡"**（旧称合约卡）

游戏内提供**挑战卡**（自选难度修饰卡组，旧称"合约卡"）：局前选 1–3 张，声明难度代价与额外奖励。参考《明日方舟》"危机合约"的自选难度思路（见 [12_参考_明日方舟设计拆解](12_参考_明日方舟设计拆解.md)），规则化落点写入 [06_关卡与地图卡](06_关卡与地图卡.md) 与 [09_路线图与融合玩法](09_路线图与融合玩法.md)；卡表样例见 [13_卡表_挑战卡样例](13_卡表_挑战卡样例.md)。

## D10 编辑器与 UGC → **先内测，后开放**

编辑器优先服务内部关卡生产与小范围测试；验证"卡组装"体验、审核成本与内容质量后，再决定开放玩家 UGC 分发（详见 [06](06_关卡与地图卡.md) 第五节与 [09](09_路线图与融合玩法.md) 版本路线）。

## D11 首个融合玩法 → **Roguelike 远征**

按 [09](09_路线图与融合玩法.md) 的优先级，首发融合包定为 **Roguelike 远征**（5–8 节点、三选一永久修饰、失败即结束）；规则卡组草案见 [23_规则卡组_Roguelike远征](23_规则卡组_Roguelike远征.md)。
