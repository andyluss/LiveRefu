# 12 · 参考：《明日方舟》设计拆解

> 资料采集：2026-09-14；引用的商业数字与部分机制参数来自第三方拆解，均已标注**存疑**，以官方公示为准。

## 一、基础信息

- 品类：塔防 × 养成 Gacha；开发鹰角网络，发行鹰角/龙成（国服）、Yostar（海外）；
- 上线：国服 2019-05，海外 2020-01；平台 iOS/Android（海外有 PC）；
- 商业（第三方口径，**存疑**）：Naavik（2023-01）称累计收入约 6.78 亿美元 / 1700 万下载；中文拆解称首年超 4 亿美元、累计 15 亿美元+。

## 二、战斗机制（最值得学的一层）

| 机制 | 做法 | 设计价值 |
| --- | --- | --- |
| 部署费用（DP） | 随时间缓慢增长，放干员、开技能都吃资源 | 把静态塔防变成有 RTS 节奏的实时资源管理 |
| **朝向** | 干员攻击范围朝摆放方向展开 | 同一干员因朝向不同而价值不同，逼迫预判 |
| **阻挡（Block）** | 近战干员 1–3 个阻挡格，被阻挡者才可被攻击 | 站位与拦截成为核心资源 |
| 技能时机 | 手动触发、有技力（SP）循环 | 操作深度来自"何时开"，而非"放更多塔" |
| 部署上限 | 通常 6–10 人（远小于 300+ 干员池） | 强制取舍，卡池宽而不废 |
| 地形/机关 | 高台/地面、可交互地块、环境伤害 | 地图本身是解谜题面 |

费用曲线（本拆解口径，**存疑**）：起始约 10 DP、约每秒 +1 DP，先锋职业可加速。

## 三、职业体系：职业 × 分支 × 干员 三层

八职业：先锋、近卫、重装、狙击、术师、医疗、辅助、特种；每职业再分 3–5 个分支（如近卫分强攻手/剑豪/斗士/术战者/领主…）。
**关键原则**：强度靠职业互补而非数值碾压——"没有医疗就是过不去"。

## 四、关卡与常驻模式

- 主线/活动关卡（剧情驱动，交替出新敌人与新地块）；
- 剿灭作战（无尽波次）、资源关（轮换的定向产出）；
- **集成战略**（Roguelike：连续作战 + 分支路线，2022 年起成为老玩家续命模式）；
- **危机合约**（玩家自选合约叠加难度等级，越高越难、赏金越多）——**自选难度修饰**的经典实现。

## 五、成长与养成

精英化（升阶改属性/技能/天赋）、技能专精、模组（后期新增的定制强化）、潜能（重复获取的小幅增益）、信赖（陪伴成长），另有**基建**离线生产链（1.6 版本后简化为五大设施）。

## 六、商业化（D6 只借鉴其"可预期"部分）

- **理智（体力）**：上限 135、6 分钟回 1（**存疑**）；日产出可预测，主线消耗低，不设硬性付费墙；
- 卡池：6★ 2% / 5★ 8% / 4★ 50% / 3★ 40%；约 99 抽硬保底；限定 300 抽硬保（**存疑**，以官方公示为准）；
- 月卡 + 通行证 + 皮肤为主力付费点，被视为"中氪友好、重氪上限低"。

## 七、可迁移到 Refu Game 001 的清单

| 方舟做法 | 我们的对应 |
| --- | --- |
| DP 实时费用与节奏 | **直接借鉴**：能量系统强化"实时取舍"，技能卡时机即深度 |
| 阻挡/拦截 = 站位资源 | 改造：以**单位卡的拦截职责 + 支援槽**实现，不做朝向（固定塔位轻量化，D2） |
| 职业 × 分支 × 干员三层 | 映射为**卡类 × 标签 × 羁绊**三层，保证每卡有独特角色 |
| 部署上限强制取舍 | 已有**人口上限**（[04](04_塔防核心战斗.md)） |
| 集成战略 Roguelike | 对应 [09](09_路线图与融合玩法.md) 的"Roguelike 远征"规则卡组 |
| 危机合约自选难度 | **建议新增**："合约卡"作为难度修饰卡组（可拆可组，天然贴合卡片式） |
| 基建离线产出 | 可选：轻量"基地卡"离线生产，不与战斗强耦合 |
| 体力与保底的可预期性 | 借鉴"可预期日产出"；**不借鉴**抽卡数值售卖（D6） |

## 八、明确不借鉴（边界）

1. 抽卡卖数值、重复角色叠强度（与 D6 冲突）；
2. 体力墙 + 重度日常（与 D5 碎片节奏冲突）；
3. 角色通胀导致职业功能稀释（我们用"每卡独立、remove-safe"约束）；
4. 高密度剧情负担（我们只做轻叙事卡面）。

## 九、关键差异一览

| 维度 | 明日方舟 | Refu Game 001 |
| --- | --- | --- |
| 战场 | 横向地图、可自由选点与朝向、可撤退 | 固定路径 + 固定槽位（D2） |
| 深度来源 | 站位/朝向/技能时机 | 卡组构筑 + 槽位组合 + 羁绊 |
| 成长 | RPG 式精英化/模组/潜能 | 卡等级 + 变体（无数值售卖，D6） |
| 玩法扩展 | 新模式逐个开发 | **换规则卡组**（[09](09_路线图与融合玩法.md)） |
| 商业化 | Gacha + 月卡 + 皮肤 | 外观 + 便利，不卖数值（D6） |
