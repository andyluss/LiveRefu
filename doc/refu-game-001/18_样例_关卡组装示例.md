# 18 · 样例：一张关卡的卡组装

> 数值为占位示例，用于验证**组装流程**而非平衡结论。

## 一、四件套声明

| 组成 | 卡 | 要点 |
| --- | --- | --- |
| 地图卡 | MAP-ANV-01「峡谷哨站」 | 单入口；塔位 12（标准 8 / 支援 3 / 修饰 1）；地形：高台 ×2（射程 +15%）、沼泽 ×1（敌人 −20% 移速）；事件槽 1 |
| 波次卡组 | WAV-ANV-A（6 波） | 见下表 |
| 事件卡组 | EVT-A | 沙暴：每波 10% 概率触发，命中 −10% |
| 规则卡 | RUL-BASE | 标准塔防；基地生命 20；起始能量 10 |

## 二、波次预算

| 波次 | 构成 | 威胁值合计（占位） |

## 三、挑战卡组合与校验

- 组合：**加压（L1）+ 封锁（L2）** → 总等级 3；
- 按 [17](17_算例_挑战卡与波次预算.md)：B′ = 158 × 1.30 ≈ 205；P′ = P × 0.90 → **D′ ≈ 1.44**（高难）；
- 奖励：掉落 ×1.45、评级 +15%；
- 不可选：CHL-04「双流」——本图单入口，不满足白名单条件（[13](13_卡表_挑战卡样例.md)）。

## 四、组装检查清单

1. **四类卡齐备**：地图 1 / 波次 1 组 / 事件 1 组 / 规则 1，槽位一一匹配；
2. **挑战卡条件**：双流类需双入口；能量类挑战卡与 RUL-BASE 的资源上限不冲突；
3. **标签可达**：塔卡中含「弹药」「工事」「维修」标签，羁绊可触发；
4. **remove-safe**：移除事件卡组后关卡仍可通关；移除规则卡回落默认塔防；
5. **可读性**：首波仅 1 种敌人、1 条路径；教学关不开放挑战卡。

## 五、结论与待调

- 流程验证通过：**四件套 + 挑战卡各自独立可换**，组装即产关，符合 [06](06_关卡与地图卡.md) 的卡片预算与复用目标；
- 待"数值初稿"回填：真实威胁值、塔位数量与能量曲线；并据此重算 D′ 的目标区间（建议 0.9–1.1 为常规、1.3+ 为挑战）。
