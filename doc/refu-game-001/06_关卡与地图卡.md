# 06 · 关卡与地图卡

> 卡面：用途＝关卡如何由卡构成 ｜ 依赖：[02](02_卡片规则系统.md)、[00_决策记录](00_决策记录.md)（D9）｜ 状态：v0.2 · 2026-09-14

## 一、关卡 = 四张卡的组合

| 组成 | 卡类 | 作用 |
| --- | --- | --- |
| 地图卡 | 地图 | 出生点、固定路径、基地、塔位分布、地形效果、事件槽 |
| 波次卡组 | 波次 | 每波的敌人构成、数量、节奏（3–6 张一组） |
| 事件卡组 | 事件 | 随机或定时改变战场条件（可被规则卡禁用） |
| 规则卡 | 规则 | 定义玩法变体、胜利条件、资源上限 |

这四类卡分别独立可换：换地图＝换棋盘，换波次＝换难度曲线，换规则＝换玩法（见 [09_路线图与融合玩法](09_路线图与融合玩法.md)）；**合约卡**（第三节）是叠加在四件套之上的可选难度修饰层，不改变关卡本体。

## 二、地图卡规范

- **路径端口**：地图边缘的入口/出口与连接点，决定路径走向；
- **塔位**：标准槽/支援槽/修饰槽三类，数量与位置即关卡难度的一部分；
- **地形效果**：高台（射程+）、沼泽（减速）、腐蚀地（持续伤害）等，以"地形卡"挂载；
- **事件槽**：0–3 个，供事件卡插入。

## 三、合约卡：难度也是卡（D9）

- **定义**：局前自选 1–3 张**合约卡**，每张声明"难度代价 + 额外奖励"；总分越高，通关评级与掉落越好；
- **字段**：名称 / 危机等级（1–3）/ 修饰效果 / 额外奖励 / 互斥或前置标签；
- **示例**：`敌人生命 +30%`（1 级）、`禁用某一卡类`（2 级）、`双路同时开波`（3 级）、`能量增长 -20%`（2 级）；
- **约束**：只做加法与替换，**不改卡表数值**（[11_数值框架表](11_数值框架表.md)）；与规则卡正交——规则卡定"玩什么"，合约卡定"多难"；
- **复用价值**：同一地图 + 同一波次卡组，配不同合约组合即产生新挑战，直接提高内容复用率（与第四节的卡片预算互补）。

## 四、难度设计（卡片预算）

- 难度 ≈ 敌方波次预算 ÷（塔位数量 × 资源增长曲线），再由合约卡做玩家自选的二次调节；
- 同一张地图卡可配三套波次卡组（普通/精英/周常），避免为难度重复造地图；
- 新手关只用 1 种族、1 事件、1 规则卡、**不开放合约卡**——可读性是第一难度参数。

## 五、编辑器与 UGC（远期）

- 编辑器以"卡组装"为交互模型：拖地图卡、拼波次卡、挂规则卡与合约卡，即可发布关卡；
- 发布关卡＝发布一个卡组包，天然可版本化、可下架、可兼容旧客户端；
- UGC 分发与审核 **【待定：后续决策】**。

## 六、自检

新关卡上线前问三句：**这张地图卡可被复用到几张波次卡组上？这套波次卡组能配几张规则卡？这套配置能挂几张合约卡？** 复用率越高，内容产能越健康。
