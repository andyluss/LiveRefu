# 火线换装

> 短篇 ｜ 族属：铁砧联邦 ｜ 2026-09-14

风从哨塔的缺口灌进来，带着沙。唐砺把护目镜推上额头，镜片上已经磨出一道白痕。

峡谷哨站是旧时代留下的东西：一层水泥壳，顶上架着褪色的霓虹管，白天不亮，入夜才吐出半截粉色的光，把沙尘照得像悬在空中的铁锈。控制台是三台歪着摞起来的旧机器。左边那台 CRT 一行一行往上吐绿字，像有人拿磷火在里面写字：`MAP-ANV-01`，`入口 1`，`塔位 标准 8 / 支援 3 / 修饰 1`。右边那台在放磁带，波次预告录在带子里，卷轴转一圈，屏顶多一道黄线。中间那台前面，卡匣箱敞着盖，樟脑和黄铜的味道混着沙土往外冒。

唐砺抽出一张卡。卡面比别的厚半分，边角压着一圈橄榄色的漆。

「加压。」他念出卡名，像吐掉一颗牙。

卡匣插进局前槽，黄铜触点咬合，发出很轻的一声"咔"。中屏闪了一下，绿字重新排布：`敌人生命 +30%`，下面一行小字，`掉落 +15%`。他盯着那行字看了两秒，把袖口卷到小臂。

纸质战术图钉在台角，方格纸上是他自己画的铅笔线：一条主路径从西口斜插进来，两处高台用双圈标着，一处沼泽打了斜影。他在高台上写了"炮"，在沼泽后面那截窄口写了"桩"。

「首波，小兵八只。」耳机里是哨塔观测员的声音，干得像砂纸，「唐调度，你真带加压？」

「带。带了才有得掉。」

「掉了也得有命捡。」

唐砺笑了一声，没接话。布防期的十五秒里他什么都没放。能量从十点慢慢涨，绿条爬得像有人拿线一点点拽。等到二十，他把模块炮塔按进左侧高台的槽位，卡面边缘亮起一圈琥珀色，炮塔的骨架从地面升起来，液压杆顶开沙土，咬住岩石。射程圈在图上张开，因为高台，多出百分之十五。

能量条归零。他吹了声口哨，不长。

第一波小兵踩进射程。炮塔开火，声音是沉的，"咚、咚"，像有人在铁砧上砸铆钉。波间结算的绿字跳出来：击杀返还八点，自然增长八点，十六。他抽了贫铀弹芯挂上修饰口，炮管的散热片立刻红了半圈，射速掉一档，每一发都重了四分之一。第八只小兵走到一半就散了架。

第二波是六只快速加四只小兵，贴着沼泽边跑，被泥地拖掉两成速度，像踩进糖浆。波末账本涨到二十四，他按了支援槽。

齿轮帮·维修工爬上台面，四条折叠腿，抱着一个比它身子还大的油壶，走到炮塔下面拧开阀门。修复是持续的，八点每秒，六秒一轮，波末还要加五成。十五点从账本上划掉。

「垫圈。」唐砺说。维修工抬起玻璃眼转了转，算是应了，然后低下头继续拧它的阀门，油从接口处渗出来一小滴，挂在铜壳上，晃了晃，掉进沙里。

第三波末尾，磁轨钉枪架上右侧高台，三十二点，账本被压到十六。它第一次击发时整个哨站都嗡了一下，一根钢钉穿过三只小兵，尾迹在空气里留下一条淡白的线。接着他放出了搬运工。

齿轮帮·搬运工只有半人高，铜壳身子，三条腿，头顶绑着木托盘。它落地时先"吱"了一声，把托盘上的铜壳电池往两边一推——相邻两座塔各灌两点能量，账本从四浮到八。它的光环贴地铺开，同标签的炮塔攻速提了一成。沙从它膝关节的缝里漏出来，它自己抖了抖，抖出一小股尘土。

「铆钉。」唐砺说。

第四波的空当里，账本涨回五十二。他把路障工事塞进沼泽后面那截窄口，四百点生命，不还手，只把来路顶住三成速度；又给桩子挂上应急修复，单体修复两百，护盾八十。维修与应急修复凑成两张——后勤链接上，此后每波开始，全体自动回血百分之五。账本剩下二十二，他一直没动。

第五波来了。装甲四只，精英两只，后面还跟着八只小兵。装甲正面的脏绿纹路从沙里拱出来，肩膀比人还宽。

第一只装甲走进炮塔射程。咚。咚。咚。

它没死。

加压那三十个百分点全堆在这层壳上。模块炮塔配贫铀弹芯，一发十五点，一秒不到一发，打单体够，可这一波是一串。第一只还没倒，后面四只已经趿着沙压进窄口。路障工事硬顶，血条一格一格往下掉。磁轨钉枪的钉子能穿三个，可零点六秒才响一次，缝里漏出去的越来越多。

一只小兵绕过路障。第二只跟着。第三只撞在维修工身上，把它掀翻，油壶滚出去，沙地里淌出一小滩黑亮的油。

「左塔换成火力网。」唐砺说完自己愣了一下——交叉火力网要二十八点，账本上二十二。

他把手按在模块炮塔上。

拆。卡匣拔出来时触点带着余温，弹了一下。绿字报出返还：`+9`。投入二十加八，拿回来九点，这是账本的规矩。他拇指在卡面上蹭了蹭，把沙蹭掉，随手插回箱子里。

「基座。」

铆钉拖着一个扁平的铁家伙过来，托盘在沙上划出一道直沟。模块化基座，六点，铁壳"啪"地扣在原塔位的底座上，长出一个新挂点，给塔多加一个标签——工事。空着的槽口朝上敞着，像一张摊开的手。账本：二十二加九减六，二十五。

交叉火力网，二十八。差三点。

磁轨钉枪那边响了，路障工事那边也响了。三只小兵倒在沼泽边上，返还一点一点滚进来，二十五、二十六、二十七、二十八——

唐砺数着，手指在台面上一下一下敲。卡匣落进槽位。塔基一转，炮管撤下去，换上来一串短粗的散射管，管口排成扇形。它开火时不再"咚"，而是"唰——"，弹幕扇出去，落在小兵群里，溅起来的沙子是热的。

交叉火力，五点。差五点。

唐砺的手在箱子里摸应急修复，摸到了又松开——桩子身上那层护盾还没碎。就在这时，一只装甲挥下前肢，护盾"叮"地碎成一片光屑。

绿字跳出来：`on_shield_break：+5`。

他把交叉火力插进修饰口。五点进账，五点燃掉。账本归零。

代价在别处。前后不过四秒，两只小兵从路障侧面的缝里钻过去，一直摸到基地门前。基地生命二十，变成十八。他把齿轮帮·路障小队扔在门前，两百点生命，阻挡两个，存在十五秒。两个小铜人扛着木板砸进地里，用肩膀抵住。

火力网那一栏，在这一刻满了。交叉火力网、搬运工的光环、刚挂上的交叉火力——三张弹药。羁绊触发：全场弹药塔攻速加一成。工事那一栏也满了：路障工事加模块化基座，两张工事，加固阵列，工事卡生命加十五。路障工事原本见底的血条，忽然往回顶了一格。

唐砺按了过载射击。十五点他早就攒在手里没舍得花。全场攻速加四成，持续六秒；同标签的塔再多一成。散射管从暗红烧成橘白，弹幕密得像雨。交叉火力网每命中一次，同标签的塔攻速再叠百分之二，最多两层。

两只精英撞在路障上，停住了。维修工从沙里翻起身，抱着油壶一瘸一拐爬回路障底下，修复开始跳数。

六秒过完，第五波结束了。

CRT 上绿字一行一行吐出来：波次结算、击杀返还、后勤链自动修复全体百分之五。基地生命往后回了一点。磁带转到头，"咔哒"一声回卷。唐砺在纸质图上把那座塔的铅笔"炮"字划掉，改写成"网"，旁边补了一个小小的"火"字。

铆钉把空托盘翻过来倒掉沙，抬头看他。

「值吗。」

唐砺翻到账本最后一页，看了一眼那两点基地生命，又看了一眼掉落系数后面那个加百分之十五。

「值。」他说，「下次把桩子往前提两格。」

「前两格是沼泽边。」

「那就前两格。」

铆钉"吱"了一声，拖着托盘往回走，三条腿在沙上留下一串小坑。窗外的沙还在下。散射管的余温把落在管口的沙粒烤得发红，一点一点亮，像哨站自己长出来的霓虹。
