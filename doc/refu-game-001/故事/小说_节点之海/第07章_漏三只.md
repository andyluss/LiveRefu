# 第 07 章 漏三只

> 卷一《卡匣新兵》 ｜ 第 07 章 ｜ 2026-09-14

入夜之后，峡谷里的风改成从东往西刮。哨站水泥壳顶上那两截褪色的霓虹管亮起来，把沙尘照成很淡的粉色。谢临把值班记录摊在控制台左边，纸角压了一枚黄铜触点，免得叫风掀走。

这是她通过考核之后的第三班夜哨。值班表上她的名字在第二行，第一行是柯岭，军衔那一栏她还空着。

「磁带预告，三波。」柯岭把耳机往里按了按，「小兵八只，隔一段，快速六只，再隔一段，装甲四只。分三趟走。」

「分三趟。」她跟着念了一遍。

柯岭没往下走。他站在那儿，一只手还搭在耳机上。

「观测席昨天的话，你还记着吧。」他说，「后半夜有三波一起压。」

「后半夜有三波。」她把纸图按平，「预告上写着三趟。一趟一趟来，都落在后半夜。」

「我不是这个意思。」

「那你是哪个意思。」

柯岭张了一下嘴，最后把耳机按回去，没再说话。

她把纸图铺开。西口进，一条路走满约四十秒，两处高台夹在中段前后，沼泽陷在窄口里。她在两处高台上各画一个双圈，在窄口画一道斜影，再翻开户头，在最上面写：`起始 10`、`自然增长 +1/s`。

第一笔是模块炮塔。她等到二十点，把它按进左侧高台的槽位。骨架从沙里升起来，射程圈因为高台多张开百分之十五，搭到窄口前半段。账本上写 `−20`，结余零。

第二笔是交叉火力网。二十八点，架在右侧高台。她等自然增长，也等先头那几只小兵的击杀返还，一点一点凑够的时候，磁带已经转过预告里第一段间隔的三分之一。

「窄口先压一道。」柯岭说。

「压。」

路障工事，十八点，四百点生命，不还手，只把来路顶住三成速度。木桩一排排从沙里长出来，横在岩壁和沼泽之间那道缝上。

支援槽有三个。第一个她放齿轮帮·搬运工，十二点。秤落地先吱了一声，三条腿在沙上踩出三个小坑，木托盘上的铜壳电池往两边一推，相邻两座塔各灌进两点能量。光环贴地铺开，同标签的塔攻速提一成。第二个槽放齿轮帮·维修工，十五点，铆钉抱着油壶蹲到路障底下，修复八点每秒，持续六秒。

第三个槽，她空着。

「留一个。」柯岭看着那个空格。

「留给下一波。」她说，「下一波是装甲。装甲挤进窄口，我再决定往这里放什么。」

柯岭把纸图往她那边推了半寸，转身去对磁带了。

修饰口只有一格。她把贫铀弹芯插进去，八点，伤害加两成五，攻速掉一成。剩下的能量她攒着，攒到十二点就停手。十二点是搬运工的价，也是应急修复的价。她算过很多遍：三趟之间各有一段缝，缝里能收一次自然增长，还能收一笔波间奖励，五点。她把第三张支援卡和手里这点钱全押在那道缝上。

这是她这本账里唯一没有写下来的前提。波和波之间，有空隙。

唐砺给过她一句话，说账本记的是你花了多少，它记不住你漏了谁。今晚她把空格留给下一波的时候，想起过它，又把它按回去了。有缝可等的人，用不上那句话。

---

磁带转到头，没有回卷。

那声很轻的咔哒没有来。中屏的绿字往上一顶，中间空了一行结算，直接吐出三行。每行后面跟着一个数，是威胁值。

`小兵 2`、`快速 3`、`装甲 5`

三行并排，各带一个正在走的秒数。三条波同时压线。

「三趟一起。」柯岭的声音干了。

她先把账本翻回去对了半页。出项、进项、结余，一笔不差。她的账没有错。错的是她算的那个东西：她算的是“下一波”。现在没有下一波，只有同一波。

窄口塞满的时候，两座高台都在啃装甲。装甲一百八十点生命，正面五点护甲，减伤两成。模块炮塔一发十二点，落上去像敲在铁轨上。窄口外那截贴着沼泽的边，两座塔的射程圈都只是堪堪搭住一角。

第一只快速就是从那一角过去的。她看见了。它贴着泥地跑，沼泽拖掉两成速度，剩下的还是比瞄准快。它绕过路障工事的尾端，往基地去。绿字很轻地跳了一下。

`基地生命 20 → 19`

「一只。」柯岭说。

她没抬头。她把手伸向那个空着的支援槽，齿轮帮·路障小队，二十点，生命两百，阻挡二，存在十五秒。差八点。自然增长一秒一格，她要八秒。

八秒里第二只过去了。她那时候的眼睛在别处，只从余光里看见绿字跳了一格。

`基地生命 19 → 18`

八秒到，路障小队按进槽里，两排桩子从沙里立起来，挡住两只贴着边的快速。第三只不是快速。第三只来的时候，她正把贫铀弹芯从修饰口里拔出来，换成交叉火力，五点，同标签攻速再抬一成五。那张卡的触点在她指头底下咬合，很轻的一声咔。

她再抬头，绿字已经写完了。

`基地生命 18 → 17`
`漏怪 3 / CAP 3`
`判失守`

基地生命还在，十七点。归零才算失守，这是规则。可下一行写着失守。两个数并排停在那里，谁也不再往下动。

两座高台的射程圈一圈一圈灭下去。路障小队的桩子还立着，存在时间没走完，沙从桩子缝里穿过去。柯岭那边静了一会儿，然后他把耳机摘下来放在台面上，动作很轻。

---

天亮前军法席来了两个人。一个夹着硬皮文件夹，一个站在门口不进来。夹文件夹那个把值班记录抽出来，翻到今晚这一页。

「值班人。」

「我。」柯岭先开口，「记录上是我签的。」

那人抬了下眼皮。「波次预告谁报的。」

「我报的。」柯岭说，「三趟分开，是我从磁带里念出来的。」

谢临把手从控制台上收回来。「卡是我放的。」她说，「坐在台前的是我。」

柯岭没看她。他把那页纸往那人手里送了半寸，指节有点发白。「记录上只有一个名字，」他说，「你把账本收好。」

那人签了两笔，把纸夹回文件夹，转身走了。门口那个跟着走。霓虹管的粉色在门框上晃了一下。

下一班的值班表，第一行是空的。这件事她第二天才知道。

---

机房在控制台后面，一间放电机和磁带柜的小屋子，铁门上那个圆窗蒙着沙。她把自己关进去，把今晚那盘磁带抽出来，塞进回放机。

磁带里只有绿字和提示音。回放的时候她一遍一遍看那三行并排的波次，看它们怎么在同一秒开始，看自己在第几秒做了哪一笔出项。她把纸图摊在膝盖上，重新排了一遍：假如她知道三波一起走，她会先压路障小队，再上磁轨钉枪，把支援槽的钱全花在窄口，而不是攒给一道不存在的缝。

她又把这半页账从头抄了一遍，抄在纸图背面，像抄一份别人的账。抄完对着看，两边一模一样，每一格都追得到出处。她第一次觉得，一笔做得这么平的账，也可以这么不干净。

排到第五遍她停下了。就算她全排对，十二点也只够买一张支援卡。一条线一张，三条线三张。她的账从来不缺算术，缺的是一个前提。

她想起柯岭昨天那句后半夜有三波一起压。她当时把「一起」听成了「都在后半夜」。现在她明白，那句话里三个字都有分量，她只算了最后两个字。

她开始在纸上给漏掉的那三只写名字。

第一只她认得出来。她闭上眼还能看见它贴着沼泽边跑，泥把它拽掉两成速度，它还是比瞄准快半拍。它比预告里的第二趟早到。

第二只她只剩下一个数。`19 → 18`，那一格跳的时候，她的眼睛在支援槽上。她记得自己等了八秒，数着一格一格往上爬，可她记不起那八秒里走过去的是什么。

第三只，她什么都没有。那一秒她在修饰口。她的手指记得触点咬合的触感，记得那是五点，记得同标签攻速加一成五。再往下就没有了。

她在机房里坐了一夜。以前她以为“漏算不清”是一句形容，说出来还有点体面，像承认自己尽力了。现在她知道不是。账能算清，进项出项结余都对得上。算不清的是那些她根本没看见的格子。它不在账上，也不在图上，它只在绿字里留下了一格。

天亮的时候霓虹管灭了，沙从圆窗外面往下落。她裁了一小截胶带，按在控制台侧沿，贴在第一张的下面。第一张的边角卷了，字是暗的：`没停的那只`。

她想了想，写下一行字：`早到的那只`。

第二张粘住的时候，她已经在裁第三张。胶带裁好了，摆在旁边，还空着。她把铅笔尖凑过去，笔尖停在第三个名字上方。
