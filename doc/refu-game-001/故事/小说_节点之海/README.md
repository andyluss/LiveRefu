## 一、这是一部什么小说

一个边陲哨站的见习调度官，从第一次漏怪的新兵，走到三族同台、跨族授权、远征通关。全书五卷 40 章，一章一文档，可独立成章，连读是一条完整的线。

- **主角**：谢临（铁砧联邦调度官 → 自由调度官），第三人称限知，全书只跟她的视线；
- **世界**：见 [共同设定](../README.md) 与 [00_设定圣经](00_设定圣经.md)——三主族争夺节点，卡匣即战术；
- **基调**：复古未来。CRT 绿字、磁带与纸图、黄铜触点、霓虹与沙尘；
- **规矩**：书中所有卡片、数值、规则都来自策划文档，只引用不创造（见 [数值/README](../../数值/README.md)）。

## 三、与既有故事集的关系

- 短篇《火线换装》《孢子雨》《共鸣的间隙》与中篇《第八节点》是同一宇宙的独立切片；长篇是那条主线的完整展开；
- 长篇第 36 章《卡掉了》与中篇《第八节点》写的是**同一局远征**，视角与写法不同，结局一致；
- 人物命名全卷统一：维修工＝**铆钉**、搬运工＝**秤**，详见 [人物术语对照卡](../人物术语对照卡.md)。
