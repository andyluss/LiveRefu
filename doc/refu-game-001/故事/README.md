## 一、共同设定（写作基调）

- **世界**：三主族在废弃轨道带与行星残骸之间争夺"**节点**"——节点既是补给站，也是通往旧时代网络的接口。战争以"布防—突破"的阵地战形式反复上演；
- **玩家角色**：**调度官**——坐在控制台前的人，手边是一箱**战术卡匣（简称"卡"）**。卡是蚀刻在合金板上的战术模块，插入槽位即部署；拔出即回收；
- **技术基调**：**复古未来**——CRT 绿字、磁带与纸图、黄铜触点、霓虹与沙尘同框。高技术存在于卡匣里，而生活仍是旧的；
- **三族气质**：铁砧联邦＝模块化工事与后勤；涌潮虫群＝数量、腐蚀与进化；星辉议会＝护盾、精准与共鸣；三支小跟班（齿轮帮 / 孢子侍从 / 光尘侍从）以支援卡形态随主族出战；
- **禁忌**：不改动任何策划文档的数值与规则；不新增种族与专有名词体系；故事可以创造**配角与地名**，但机制必须与文档一致。
