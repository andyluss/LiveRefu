## 一、本卷做什么

塔防是少数"状态离散、动作有限、单局短、判负清晰、可复现、且难度可解释"的策略游戏。本卷讨论它为什么适合做 AI 基准、最优解为什么不可求、近年 LLM 与 RL 在塔防上做了什么，以及如何把本作的 `B/P/D` 模型变成评测维度与可执行协议。

合计约 9,392 汉字。
