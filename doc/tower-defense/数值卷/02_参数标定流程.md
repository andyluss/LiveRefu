# 02 · 参数标定流程

> 卡面：用途＝从零标定一套塔防难度参数的可执行流程 ｜ 依赖：[01_模型定义与推导](01_模型定义与推导.md) ｜ 状态：v0.2 · 2026-09-15

## 一、八步标定法（总览）

| 步 | 做什么 | 产出 | 常见错误 |
| --- | --- | --- | --- |
| 1 | 定义威胁值基准 | 一张敌方原型表（生命/护甲/移速/威胁值） | 直接抄别作的权重，导致 `B` 失去可比性 |
| 2 | 选定基准关 | `B_ref`（建议取"教学关之后的第一场硬仗"） | 取第 1 章当基准，导致后续 D 全在高位 |
| 3 | 定义我方战力 `P` | `P = 塔位数 × 平均有效 DPS × 覆盖系数`，基准卡组 = 1.0 | 用"等级/稀有度"当 `P` |
| 4 | 采集胜率数据 | 每关 ≥200 局（模拟或真人） | 样本太少，胜率被方差吞掉 |
| 5 | 拟合 `D50` 与 `k` | logistic 参数 | 用肉眼画曲线 |
| 6 | 校准 `λ0` 与 `γ` | 漏怪分布的幂律参数 | 只拟合胜率、不拟合漏怪 |
| 7 | 定 `cap` | 允许失误数（设计意图） | 把 `cap` 当拟合参数 |
| 8 | 冻结参数 + 建立目标带 + 接入 CI | 断言与阈值 | 参数随版本漂移，历史数据不可比 |

## 二、第 5 步：怎么拟合 `D50` 与 `k`

胜率对难度是单调下降的，用 logistic 近似：

```
P(胜) ≈ 1 ÷ (1 + e^{k(D − D50)})
```

做线性化（注意用 `1 − P` 保持斜率为正）：

```
ln((1 − P) ÷ P) = k·D − k·D50
```

把实测的 `(D, P)` 对做**最小二乘线性回归**：斜率 = `k`，截距 = `−k·D50`，于是 `D50 = −截距 ÷ k`。本作得到 `k = 7`、`D50 = 1.25`。

**验收这条拟合的标准**：模型与实测的偏差在目标区间内应 ≤3pp（本作实测最大偏差 2.3pp，见 [01 号文件](01_模型定义与推导.md) 第四节的对照表）。若偏差更大，通常说明：`P` 的定义里漏了因素（覆盖、地格），或 `cap` 与实际判负条件不一致。

## 三、第 6 步：怎么校准 `λ0` 与 `γ`

漏怪期望服从幂律 `λ = λ0 · D^γ`。取对数：

```
ln λ = ln λ0 + γ · ln D
```

于是又是一个线性回归：斜率 = `γ`，截距 = `ln λ0`。数据来源可以直接从模拟器读"平均漏怪数"。

- 若 `γ` 拟合出 ≈1，说明你的漏怪随难度线性增长——这通常意味着 `cap` 太大或单波压力太平均，缺少"临界感"；
- 若 `γ` 拟合出 >4，说明难度断层：玩家会在某一档突然从"轻松"跳到"必败"；
- 本作取 `γ = 3`（整数便于沟通与反解）。

## 四、第 7 步：`cap` 是设计决策，不是拟合结果

`cap` 决定"允许玩家犯几次错"，它必须先由**体验目标**确定，再反过来影响胜率曲线：

| `cap` | 体验 | 适合 |
| --- | --- | --- |
| 1 | 零容错，一次漏怪即输 | 硬核挑战关、限时活动 |
| 3（本作） | 允许少量失误，紧张但可复盘 | 主线与远征的默认 |
| ≥5 | 宽容，漏怪变成"扣血"而非"判负" | 轻量休闲、教学关 |

**同一套 `B/D` 换一个 `cap`，胜率会显著变化**——这就是为什么 `cap` 必须写进冻结清单。

## 五、第 8 步：从参数到断言

参数标定完只是"模型能跑"，要让它变成"设计守得住"，需要把设计意图写成断言：

| 设计意图 | 断言（可自动检查） |
| --- | --- |
| 主线必须是教学式渐强 | 五章胜率依次下降且落在各自目标带 |
| 远征第八节点是"少数人的成就" | 节点 8 胜率落在 3–12% |
| 三族对空不能差太多 | 三档空袭 × 三族的行内极差 ≤15pp |
| 永久修饰没有必选项 | 平均增益 6–12pp、契合流派 ≤20pp |
| 单卡不能杀死一套牌 | 族专属卡对纯流派跌幅 ≤35pp |

每条断言的实现与阈值见 [05_验收与CI](05_验收与CI.md)。

## 六、标定一份新游戏的最短路径（清单）

1. 写下敌方原型表（≥5 种，含 1 个精英与 1 个 BOSS，BOSS 给阶段技）；
2. 选一张"单入口、塔位中等"的图作为基准关，标定 `B_ref`；
3. 定义基准卡组，把它的 `P` 定为 1.0；
4. 设计 5 个难度档（`D` 约 0.8 / 1.0 / 1.2 / 1.4 / 1.7），每档跑 ≥200 局；
5. 拟合 `k`、`D50`、`λ0`、`γ`；
6. 按体验目标定 `cap`；
7. 给每档定"目标胜率带"，把带位写进 CI；
8. 此后**只改内容、不改常量**：需要更难，就抬 `B`；需要更简单，就调 `P`。
