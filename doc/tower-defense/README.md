## 一、这篇论文在写什么

一句话：**把塔防从"一类好玩的关卡"写成"一个可以被研究、被验算、被批评的对象"。**

它用三条线索组织：

1. **内涵**——塔防由哪七个要件构成，"抽掉哪一个就不再是塔防"；
2. **外延**——塔防与塔攻、MOBA 兵线、生存防守、自动战斗、放置、RTS 基建、卡牌塔防之间的家族相似，以及一张"要素 × 类型"判定矩阵；
3. **设计空间与文化位置**——空间/时间/资源/难度的形式化（含可复现的胜率曲线）、心理机制、产业结构、美学语法，以及"坏塔防的六种症状"。

## 四、它和《Refu Game 001》的关系

本卷是**研究**，策划卷是**样本**。

- 论文里的公式、曲线与阈值，全部来自策划卷与 [`tools/sim_refu_game_001.ts`](../../tools/sim_refu_game_001.ts) 的实测（五章 94.9%→43.6%、远征八节点 84.4%→3.6%、对空极差、PMOD 双口径、挑战卡双口径）；
- 论文提出的方法论（可验算设计、四种平衡口径、容器化接口三条）在策划卷里都有落地实现；
- 反过来，论文也承担**批评**职责：十节的六种症状可以直接拿来审自己。

## 五、体例与边界

- 论文中的**理论引用**给到作者与年份（见论文附录 B），**资料性来源**（作品史实）使用公开页面并标注；
- **不做玩家实证**：心理机制部分是解释性的，不是验证性的；凡本文归纳的一般规律都可被证伪；
- 论文里的游戏数值一律引用自策划文档，**未作改动**；如与策划文档冲突，以策划文档为准。
