# 太阳朋克（Solarpunk）资料库与体系笔记

> **doc/solarpunk/** · 独立调研卷 · 简体中文
>
> 本目录系统记录太阳朋克（Solarpunk）——2010 年代以来以"可持续文明的未来"为核心的文类、美学与社会运动——的概念、历史、作品与资料。优先做体系化梳理，无法归入体系的部分以资料清单兜底，凡引述均尽量附来源链接。

## 与既有卷的关系

本工作区另有一套《复古未来主义论文集》（doc/retro-futurism/），其 19 多元篇把太阳朋克作为"非回望的未来主义"做过一节处理。本目录与之的关系：

- **分工**：retro-futurism 从"复古未来"的视角看太阳朋克（它如何拒绝回收旧未来）；本目录把太阳朋克**本身**当作调研对象，做正面、全面的记录；
- **术语**：两卷一致采用主译名「**太阳朋克**」，并在需要处注明"又译索拉朋克"（详见 01 定义篇与 07 中文语境篇）；
- **互引**：本卷在合适处注明（见 doc/retro-futurism/19）。

## 体例说明

沿用 doc/retro-futurism/00 的写作纪律：简体中文、篇首关键词+摘要、术语首次出现加粗附英文、表格与列表可用、**禁用 emoji**、事实不确定时按"约/一般认为/存疑"降档、不编造、引述尽量给来源链接。资料库条目（08）为客观罗列，标注获取时间与渠道。
