# 02 · 工程结构与运行

> 用途：看懂代码往哪写、怎么跑起来、为什么这么切 ｜ 建立于 S1 · 2026-09-30
> 上游决策：[`mainline 05 美术与技术方向`](../../mainline/docs/05_美术与技术方向.md)（Q7 = Godot 4.x + 表驱动管线）

## 一、技术栈与约定

| 项 | 值 | 说明 |
| --- | --- | --- |
| 引擎 | **Godot 4.7 stable**（GL Compatibility） | 与工作区既有工程同引擎同渲染后端；无授权费与抽成 |
| 语言 | GDScript | **无 addon、无第三方依赖**，clone 下来即可跑 |
| 数据 | JSON（`game/data/tables/`） | 卡 / 势力 / 关卡 / 模式 / 残片；**逻辑不硬编码数值** |
| 契约 | `game/data/schema.json` | 由 `tools/check_data.py` 执行校验（含负向自检） |
| 分辨率 | 设计 1280×720（横屏） | **Q5 平台裁决前为占位**：这是最容易被推翻的一项，改它只动 `project.godot` |
| 工作目录 | `HOME` 指到工作区 `.godot-home` | 由 `run.sh` 自动上溯定位，避免污染真实用户目录与沙箱权限问题 |

## 二、四层结构（为什么这么切）

```
输入/界面  scripts/app/*.gd        ← 只做布局、输入、弹窗
   ↓ 读状态 / 调 API
表现       scripts/view/*.gd       ← 只画，不改战斗状态
   ↓ 读领域对象
逻辑       scripts/core/*.gd       ← 纯逻辑，可在无头环境被脚本驱动
   ↓ 查数据
数据       scripts/autoload/*.gd + data/tables/*.json
```

两个直接好处（这是**继承自 `refu-game-001` 的最有价值的部分**，不是重新发明）：

1. **可验收**：`core/` 不依赖任何场景/贴图，`scenes/tools/` 里的无头用例能在没有渲染的环境跑完整局；
2. **可换表现**：将来把程序化绘制换成 sprite 图集，只动 `view/`。

## 三、文件预算（硬门槛，不放松）

| 目录 | 上限（代码行） | 理由 |
| --- | --- | --- |
| `scripts/core/` | 50 | 纯逻辑，必须小到能被无头断言 |
| `scripts/app/` | 100 | 界面与装配 |
| `scripts/view/` | 100 | 表现层 |
| `scripts/autoload/` | 60 | 全局数据 |
| `scenes/tools/**/*.gd` | 50 | 无头探针与用例 |

口径：只算**代码行**（去空行与 `#` 注释行），另有物理行兜底（上限 × 3）防止用注释撑大。
由 `./run.sh lint` 强制，`./run.sh check` 第一道闸门。

## 四、统一入口 `run.sh`

| 命令 | 作用 |
| --- | --- |
| `./run.sh run` | 打开占位主界面 |
| `./run.sh editor` | 打开 Godot 编辑器 |
| `./run.sh check` | **四道闸门**：文件预算 → 数据契约 → 工程导入 → 无头自检 |
| `./run.sh boot` | 只跑无头自检（快速确认工程还能装载） |
| `./run.sh lint` | 只跑文件预算（可加 `--self-test`） |
| `./run.sh data` | 只跑数据契约校验（可加 `--self-test` / `--file cards.json`） |

**为什么所有 Godot 调用都必须走 `run.sh`**：它统一设置 `HOME`（否则 Godot 会往真实用户目录写缓存，在沙箱/CI 里直接失败），并对无头输出做错误扫描。

## 五、无头自检（`boot_probe`）断言了什么

1. 工程与 autoload 能装载（打印一行自述）；
2. `res://data/tables` 可枚举且非空；
3. 每张表是**合法 JSON**、顶层含 `entries` 数组，并逐表打印条目数；
4. 全部通过则打印 **`BOOT OK`**；任一失败则打印 `BOOT FAILED` 并以退出码 1 结束。

**为什么还要扫日志而不只看退出码**：Godot 对部分脚本错误仍返回 0，所以 `run.sh` 会同时 grep `SCRIPT ERROR / Parse Error / Failed to load / Cannot open` 并要求出现 `BOOT OK`。

## 六、踩过的坑（如实记录，避免重复）

1. **`HOME="$HERE/../../../../.godot-home"` 这类含 `..` 的路径在本环境会被沙箱拒绝**（`Operation not permitted`），且错误信息只有一行 `mkdir`，极易误判为权限问题。
   → 改为**上溯找 `.git`** 定位工作区根（`run.sh` 里的 `while` 循环），拿绝对路径，彻底消除层数歧义。
2. **`set -euo pipefail` 下前一条命令失败会立刻中断**，所以调试路径时看不到自己的 `echo`——排错时先临时 `set +e` 或分步验证。
