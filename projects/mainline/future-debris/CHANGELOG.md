## [0.39.0] - 2026-10-23 13:39

### 新增
- **新增 [`GUIDE.html`](GUIDE.html)：给"第一次听说这个游戏的人"看的玩法说明**（面向非策划读者）。
  - **为什么另做一份**：`HUB.html` 讲的是**项目状态与决策**（给项目负责人），这份讲的是**这游戏在玩什么**（给任何人）。两份文档的读者不同，混在一起谁都不好用。
  - 结构与"小白顺序"：三十秒版本 → 一局流程 → **电力与残渣的张力** → 降级区 → **卡面六段图解** → 六类卡 → 四势力（含"为什么胜利条件跟着玩法走"）→ 规则卡（用**同一件事两种相反后果**的真实规则对讲"规则改物理法则"）→ 难度曲线 → **一局里的决策循环** → 输赢与评级 → 词表 → 现在做到哪。
  - **图表全部从游戏数据表现读生成**（`guide/build_guide.py`）：16 关难度曲线（真实配额，含章节分隔与"每章先松后紧"的锯齿）、势力卡数条形图、稀有度分布、示例卡六段解剖。**改数据重跑即同步**；`--check` 在页面落后于数据时报错。
  - 刻意用了**浅色纸面**而不是游戏里的深色：这份是拿来读的说明书，不是产品界面；两份文档一深一浅也更好区分。

### 变更
- **卡牌库改用更小的卡面**（`GALLERY_SCALE 0.62`，一屏 5 列）：原来看不清是"卡片过大被裁"——
  列数是按**设计宽度 520**算的，而卡片实际按 `UiScale`（1080p 下 1.5×＝780px）渲染，
  于是算出的列数偏多、卡片互相挤压。现在按**设计宽度 × 缩放**算列数，并给 [CardView](game/scripts/view/card/card_view.gd) 加了
  `display_scale` 覆盖（`UiScale` 是为可读性放大，卡牌库要的恰好相反）。
- 重出 `card_gallery.png` / `card_gallery_1080p.png`（新卡面 + 小卡面）。

## [0.38.0] - 2026-10-23 13:25

### 新增
- **卡面材质回灌引擎**：卡面从"纯色块"升级为**归档的搪瓷提案板**，与 `cards/` 里的设计一致。
  - 新增三层，按职责拆文件（每个都在 100 行预算内）：[`card_material.gd`](game/scripts/view/card/card_material.gd)（投影/镀铬包边/搪瓷面/视窗/扫描线）、[`card_type.gd`](game/scripts/view/card/card_type.gd)（文字原语）、[`card_stats.gd`](game/scripts/view/card/card_stats.gd)（数值 + 规则/风味排版）。
  - **两套朝向按场景混用**（与 `cards/` 的判断一致）：**卡牌库＝杂志式 `light`**（米白搪瓷 + 凹陷视窗）、**局内手牌＝暗卡 `dark`**（黑铬 + 发光视窗）。同一版式，只换材质明暗。
  - **颜色全部由既有 token 混合而来，未新增任何颜色**——所以视觉 token 闸门仍是 30 组、不需要新增对比组合。
  - 补上设计里的细节：左缘**打孔**、底栏**条码**、关键词**圆角搪瓷小牌**、数值格加**势力色顶条**、费用改**搪瓷圆章**、打不起的牌**整体压暗**（不再换底色，避免与材质打架）。

### 修复
- **卡面的「战力」一直是「电力」的替身**（用户可见的错误）：卡表只有一列 `power`，`CardData.might = row.power`，而生成器**算出了真实战力却只写进正文**。
  实测 **120 张里 94 张**的卡面战力与它自己正文写的战力**不一致**。
  - 修法：把 `might` 提升为**正式契约字段**（schema + 生成器契约白名单 + 卡表 + `CardData`）。迁移是**纯新增**：已有字段 0 改动、卡数 120 不变、迁移后不一致降为 **0/120**。
  - 刻意记下：原先"不把 might 写表"的注释理由是"怕污染契约"——**用户看得见的错，比契约多一个字段严重得多**。
- **生成器的危险默认值**：`--target` 默认 12，**裸跑 `python3 tools/gen_cards.py` 会把卡池重置成 12 张并覆盖**（实测一次抹掉了 108 张生成卡，已从备份恢复）。
  现在默认 = **当前表规模**，裸跑变成幂等重建；要缩池必须显式给 `--target`。

### 修复（设计侧）
- `cards/index.html`：**卡牌在浏览器里叠在一起**——网格轨道最小 340px，而默认尺寸是 520px，卡片撑破轨道与邻居重叠。改用 **flex 换行**，永不重叠。
- 同上：卡面三项数值改为 **电力 / 残渣 / 战力**（此前写成了 残渣/战力/算力，且把 `power` 标成了战力）——现在与引擎同一口径。
- 风味文字入表：`flavor` 作为**可选字段**进入 cards schema，9 张展示卡写入文案（其余留空不显示，不留空洞）。

### 变更
- 卡牌库截图与战斗截图按新卡面重出（`docs/shots/`）。
