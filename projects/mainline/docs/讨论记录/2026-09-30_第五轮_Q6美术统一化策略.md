## 结论

用户指示"先把 Q6 定下来"。Q6 有**两半**：

| 半 | 状态 |
| --- | --- |
| **美术统一化策略**（怎么统一） | ✅ **已裁决：纪元风格卡 + 共享语法层**，并且**已落地为可执行物**（token 契约 + 对比度闸门 + 视觉样张） |
| **美术产能来源**（美术从哪来） | ⏳ **待你提供**：自画 / 外包 / AI 出量 / 素材包改造 + 可用现金量级 + 每周工时 |

**做法**：先把推荐项做成"看得见、可验证"的东西再请你拍板——否则"风格卡 + 语法层"只是口号。

## 论点与依据

- **核心规则**：**纪元改变外观，不改变理解方式。** 语法层（颜色语义、5 级字号、间距、圆角、描边、动效、图标语言、**卡面信息位置**）永不变；风格卡（色板取值、材质、光源、装饰母题、图像处理、UI 外壳、音频语气）每纪元替换。
- **语义 token 优先**：脚本与素材只引用 `--power` / `--residue` 这类**语义名**。原子纪里 `--power` 是薄荷青（出自题材权威 [`atompunk 03`](../../../../doc/punks/atompunk/03_美学与视觉.md) 的"薄荷绿打底"），换纪元可换成别的色相而语义不变。
- **卡面信息位置写进契约**：卡牌的可读性全靠位置，玩家不该在每个新纪元里重新找"这张卡几点费用"。
- **对比度与层级由机器守**（第三道闸门）：对比度是唯一可纯计算判定的无障碍维度；并额外断言**层级亮度顺序**，用来抓"颜色达标但与相邻层级挤在一起、用户分不出主次"这种只靠肉眼很难发现的退化。
- **成本口径的关键区分**：**一次性投入**（语法层 + 风格卡 + 版式模板 + 管线）不随内容量增长；**边际成本**（每张卡面）才决定"纪元能做多大"。纪元契约 v2 要 200–300 张卡，所以边际成本必须低到"多 100 张不心疼"。

## 亮点与教训（值得单独记住）

1. **闸门第一次运行就抓出两个真缺陷**：`--text-faint` 对 `--bg-elev-1` 仅 **4.43:1**（需 ≥4.5）；`--line-strong` 对 `--bg-elev-2` 仅 **2.82:1**（需 ≥3）。**后者与既有项目《未来档案》当年栽的是同一个坑**：交互控件边框误用了装饰用色（`--line`）。→ 修复为 `#9E9889` 与 `#6F7B89`，27/27 组合达标。
2. **校验器自检第一版有假通过**：三条负向用例都"报错"了，但报的是**另一条无关错误**（某个无关的颜色组合恰好也不达标）。改成"必须命中**指定类别**的报错"之后才真正可信。→ 教训：**负向用例必须断言错误类型，不能只断言"有错"**。
3. **子代理的样张与我的契约不符两处**（已让它返工）：用了过期 token 值；字体层级整档缩小（20/14/11/9 vs 契约 28/20/15/13）。→ 教训：**契约要先冻结再派活**，并且**派出去的活必须回来对账**，不能因为"图好看"就默认合规。

## 分歧与未决

- **产能来源已定**（本轮补充）：AI 出量 + 自画语法层 + 外包精修关键件；现金**万元级以内**；工时**波动很大、无法估**。
- **由此新增风险 R10 与 D10**：**工时不可估 × 卡量门槛 = 交付风险**；已改为**卡量阶梯**（T1 12 张 / T2 40–60 张 / T3 120–150 张 / T4 200–300 张），S5 只到 T2（见 [06 产能预算与卡量阶梯](../../../future-debris/docs/06_产能预算与卡量阶梯.md)）。
- **配音/旁白是否必要**（原 Q6 补充 3）仍空缺：它影响"纪元电台"的成本量级。
- **样张的人工评审未做**：需要 5 名外部人员做"10 秒辨识 + 30 秒氛围"测试（S3 前）。

## 补记：样张返工对账与 token 缺口（本轮最有信息量的部分）

子代理的样张产出**经对账发现两处不合契约**并已返工（第二次验收通过）：

1. 用了**过期 token 值**（`#8B8578` / `#66727F`）；
2. **字体层级整档缩小**（20/14/11/9），且它**正确指出根因在我**：我派活时写"大标题/小标题/正文/脚注**四级**"却没给任何字号值，而契约是**五级且有值**——两者不一致，执行者只能自编。→ 教训：**派活的提示词必须直接引用契约文件与具体值，不能凭记忆复述**。

它另外如实列出 **7 条 token 缺口**，我已全部处理：

| 缺口 | 处理 |
| --- | --- |
| 五级之下没有"标注级" | **明确禁止**产品界面 < 13px；评审图须加 `【评审标注】` 前缀并声明不在阶梯内 |
| 没有焦点色 token | **新增 `--focus` = `#8AB4F8`**（与 accent/power/residue 都不同色相），并规定焦点环 2px + 1px 偏移 |
| 费用数字无专属色 | **决定不设**：费用用 `--text` + `--line-strong`，避免被误读为第三种资源 |
| 明暗变体无 token | **新增材质组**：`--surface-sunken` / `--material-mid` / `--material-hi` / `--material-shadow` |
| `--line-strong` 一身二职 | **拆分**：控件边框只用 `--line-strong`；镀铬渐变中调用 `--material-mid`（避免改边框顺手破坏材质） |
| 卡面纵向余量未定义 | **定死**：合计 666 / 余 54 = 上 26 + 下 28 |
| 样张色彩可能漂移 | **新增机器闸门**：样张里每个色值都必须能追溯到契约 token（已用注入自调灰 `#3C3C3C` 反向验证会拦） |

**这一轮最值钱的一条经验**：子代理的"7 条缺口"比它的三张图更有价值——**它把"契约里没写清的地方"变成了清单**。而根治办法不是写更长的提示词，而是**让机器守住契约**（第 7 条那个闸门）。
