## 已产出的关键结论（供快速索引）

来自 [02](02_玩法与内容量对标.md)：**内容量决定差评下限，不决定销量上限**；$19.99–$24.99 档的内容底线约为 **200–300 张可构筑卡 + 6–10 个阵营 + 8–12 关卡 + ≥3 模式**；**若第一版卖 $24.99，第一版自己就必须接近一整部 $19.99 作品的体量**（这是它对本项目最重的一条压力测试）。所有精确销量**未取得**（SteamDB/SteamSpy 等拒访），只有"评测数 × 30–50"的 B 级量级区间。

## 反例记录（同样有价值）

调研不只收成功案例。**失败与停更的同类作品**应单独成节记录：它们通常更能说明"风险在哪里"，而且这类信息在公开渠道往往比成功案例更完整。
