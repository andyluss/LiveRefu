它是什么

形态

复古未来主义 · 时代提案卡组 + 自走式防线；以「纪元」为单位滚动成长。

PC 买断 $19.99 + 免费 Demo；不卖数值、不抽卡。

一句话玩法

你向一个相信清洁能源的明天提交改造提案：每一次供电都更快，也把一点代价留在了地图上。

差异化在哪

复古未来题材本身热门到无法靠题材被记住，所以差异来自机制：「代价」不是失败惩罚，而是第二种资源。

核心循环（三句话）

① 双资源：电力 ↔ 残渣

电力是供给，残渣是代价——每次供能都会留下它。

② 残渣堆积成「降级区」

残渣在地图上形成降级区，持续腐蚀你的基地；清不掉就会输在自己造的东西上。

③ 规则卡改变这一关的物理法则

同一张牌在不同规则下结果不同（例：污染从「惩罚」变「燃料」）。这是纪元差异的载体。

四个势力：同一套数字，四种活法

势力对残渣的姿态玩法差异胜利条件
原子能委员会 AECcleans 清理把残渣清掉，甚至能换来一次性爆发守成（活到最后）
郊区秩序 SUBavoids 回避保持干净格，越干净战力越高守成（活到最后）
清运承包方 HAUmoves 搬运把残渣搬到最脏的格子上，回收更划算清剿（清完波次）
辐射漫游者 ROAfeeds 喂养把残渣从惩罚翻转为燃料清剿（清完波次）

同一套数值，因为「姿态 + 胜利条件」不同而产生四种体验——这是 4 势力共 4 个却不像换皮的原因。

06 · 已经纠正过的判断与踩过的坑

这一节的价值是别再踩一遍。每条都附「当时怎么想错 → 证据是什么 → 改成了什么」。

① 直觉给内容量定标，被证据证伪

我按直觉把旗舰纪元写成「可构筑 40–60 张卡」。M3 调查 46 部作品（Steam 官方接口）后发现，这个价位的成功样本是 200–440 张——差了约 4–5 倍。
→ 契约上调为 v2（200–300 卡 + 6–10 势力）。教训：内容量不能凭直觉定，要么有对标，要么承认不知道。

② 四次「看着像数值问题，其实是工具问题」

症状真实原因
自动玩家卡在 4 张牌、战力却一直涨放置判定用了全盘残渣聚合，且把已放置的塔重复计入 → 改成逐格判定
自动玩家既不落子也不抽牌playable_count() 只算「付得起」，没算「放得下」 → 两件事统一成一个谓词
卡池变大后某势力突然崩掉（627 → 373）构筑器取「池子前 8 张」/「性价比前 4」——小池子碰巧对，大池子必错 → 改为按 ramp 选
标定时四势力输出全都显示 144读的是被配额截断后的 dealt，不是原始 output → 改成读原始值
教训（最值钱的一条）：怀疑数值之前，先怀疑测量。四次里有四次都不是数值错，是尺子错。

③ 三次「静默失效」——没报错，但结果是假的

发生了什么为什么会静默
验收断言写进了真实存档「记录」和「计算」是同一个函数 → 拆成纯函数 + 落盘两步
哈希校验「通过」了，其实只比了长度比对逻辑写漏 → 补上真实比较
未知取值退化成静默默认查不到就悄悄用默认值 → 改为未知即不生效
教训：「未知」必须是不生效，不能是「悄悄用默认」。没报错」不等于「对」。

④ 结算顺序就是规则

出现过两次语义错误：一次是「守住」没要求基地还活着（于是 0 血也能算通关）；一次是胜负判定跑在伤害结算之前，且清剿分支没检查基地存活。
→ 胜负必须在所有伤害之后判定；基地死亡覆盖任何胜利条件。并补了一条常驻断言：「判通关 ⇒ 防线还在」。

⑤ 「规则适用」不等于「有人检查」

有一段时间我以为「定了规则 = 有人守」。实际上机器校验只覆盖了 rules/ 与 lab/，其它关注点只是「适用规则但没人查」。
后果很具体：讨论记录的命名与元规则冲突没有任何检查会发现。
→ 建了覆盖清单，并明确区分四种状态：纳入闸门 / 只报告 / 尚未配置 / 明确豁免——把缺口写在明处，比让它隐形好。

⑥ 「文档说的」必须等于「闸门做的」

变更日志的技术详解曾把版本头规定为只到日期，而检查器明确拒绝缺时分的格式——照文档写会被自己的闸门拦下；示例也不合规，而示例是被人抄的。
→ 把「文档 ↔ 实现」的一致性也纳入检查。
