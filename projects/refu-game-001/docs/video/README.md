## 三、怎么重新录

```bash
cd projects/refu-game-001
tools/record_demo.sh                 # 540x960 @30fps
tools/record_demo.sh 720 1280 30     # 指定分辨率与帧率（默认即此）
```

脚本做的事：临时摘掉 `project.godot` 的窗口覆盖尺寸（否则只能录到 540×960）→ 用
Godot Movie Maker 以固定帧率录 PNG 帧 → 用 `tools/make_video.swift` 编码成 H.264 MP4 →
让系统解码器探一遍时长尺寸 → 清理中间帧。**不依赖屏幕录制权限，也不需要联网。**

> 两个环境坑（已在脚本里处理）：Godot 的 PNG 序列写入器**不会自建输出目录**；
> Movie Maker 的录制尺寸等于**窗口尺寸**而不是 viewport 尺寸。

## 四、分镜脚本在哪

[`game/scripts/tools/demo_director.gd`](../../game/scripts/tools/demo_director.gd)：
一个按时间轴实例化各界面、自动操盘并叠加字幕的"导演"。战斗段字幕**跟着当前波次走**
（不是按秒硬编码），所以改倍速、改平衡、改出怪节奏都不会让字幕与画面对不上。
