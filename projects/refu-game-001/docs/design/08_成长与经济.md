# 08 · 成长与经济

> 卡面：用途＝解锁、升级与付费边界 ｜ 依赖：[00_决策记录](00_决策记录.md)（D6）｜ 状态：v0.1 · 2026-09-14

## 一、三条成长线

| 线 | 对象 | 方式 |
| --- | --- | --- |
| 卡牌成长 | 单卡 | 卡经验 → 等级（小幅数值）+ 变体（改机制） |
| 玩家成长 | 战役进度 | 解锁新卡、新规则卡、新地图卡 |
| 种族成长 | 三主族声望 | 解锁从族支援卡与族专属修饰卡 |

## 二、资源

| 资源 | 获取 | 用途 |
| --- | --- | --- |
| 合金 | 关卡掉落 | 卡等级提升 |
| 晶尘 | 周常/成就 | 解锁变体与稀有规则卡 |
| 声望 | 使用某种族通关 | 解锁该族支援卡与外观 |
| 赛季点 | 赛季任务 | 通行证进度（含外观） |

## 三、解锁节奏（首月体验）

第 1 天：1 主族 + 8 张核心卡；第 3 天：从族支援卡首次登场；第 7 天：第二主族开放；第 14 天：第一张规则卡（新玩法预告）；第 30 天：三族齐全 + 首次周常长局。

## 四、付费边界（D6）

- **只卖**：外观（卡面皮肤、族徽、战场主题）、赛季通行证、便利（卡组栏位、加速与存档槽）；
- **不卖**：卡牌本体、数值、随机卡包、体力；
- 所有影响胜负的内容均可通过游玩获得，且不在商店出现。

## 五、防碾压

异步 PvP 按"卡池深度 + 关卡进度"匹配；数值压缩（等级收益设上限），确保技巧与组合仍占主导。

## 六、数值工作衔接

数值策划按 [02](02_卡片规则系统.md) 的"数值块独立"原则建表：每张卡一张表、每类资源一张表；调参记录随卡版本走。
