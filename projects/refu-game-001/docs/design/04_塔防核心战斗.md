# 04 · 塔防核心战斗

> 卡面：用途＝局内循环与胜负 ｜ 依赖：[02](02_卡片规则系统.md)、[05_卡组与组合](05_卡组与组合.md) ｜ 状态：v0.1 · 2026-09-14

## 一、棋盘（D2：固定路径 + 固定塔位）

- 地图由**地图卡**决定：出生点、固定路径、基地、塔位分布、地形效果（见 [06_关卡与地图卡](06_关卡与地图卡.md)）；
- 敌人沿路径推进，抵达基地即扣基地生命；**基地生命归零＝失败**；
- 玩家不移动、不操作单位走位，只做"放卡与调度"，保证单指可玩。

## 二、局内资源

| 资源 | 来源 | 用途 |
| --- | --- | --- |
| 能量 | 自动增长 + 击杀返还 | 放塔卡 / 升级 / 放技能卡 |
| 人口 | 规则卡给定上限 | 限制同时存在的单位卡数量 |
| 调度点 | 每波结束 +1 | 三选一调度（见 [05](05_卡组与组合.md)） |

## 三、单局流程

1. **布防期**（约 15 秒）：查看地图卡与首波预告，放首批塔；
2. **波次循环**：波次卡驱动敌人出场 → 击杀/漏怪 → 波间结算（能量、调度三选一）；
3. **收尾**：通关结算（评级、掉落、卡经验）。
碎片关约 6–8 波（3–5 分钟）；周常长局 20+ 波并附加特殊规则卡。

## 四、塔与卡的行为

- **塔卡**：放入塔位即生效；升级＝替换为高阶卡（组合法则二）；拆除返还部分能量；
- **技能卡**：一次性或持续，消耗能量，服务于"救场"；
- **单位卡**：召唤到路径或支援槽，负责拦截、输出或辅助；
- **事件卡**：由地图事件槽触发，改变战场条件（如沙暴、断电），可由规则卡禁用。

## 五、胜负与评级

- 胜利条件由**胜利条件卡**定义（默认：守住全部波次；变体：守住 N 分钟、保护目标卡等）；
- 评级三维：基地剩余生命、能量使用效率、组合触发次数——鼓励"用卡组合"而非单纯堆数值。

## 六、操作约束

支持暂停与 1×/2× 速度；单次操作不超过两指；一切战斗信息以卡面与槽位高亮呈现（见 [07_移动端与界面](07_移动端与界面.md)）。
