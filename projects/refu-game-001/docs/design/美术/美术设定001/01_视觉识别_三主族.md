## 一、三族一眼辨

| 维度 | 铁砧联邦 | 涌潮虫群 | 星辉议会 |
| --- | --- | --- | --- |
| 几何语言 | 方正：矩形母题，45 度倒角 | 有机：卵形、弧、分叉与毛刺 | 棱形：三棱柱，六十度斜切 |
| 轮廓剪影 | 上宽下窄箱体加支腿 | 低矮横铺，边多毛刺 | 高瘦收尖，底部离地留缝 |
| 主色板 | 冷钢蓝 `#2F4A63`、钢蓝亮 `#7C9DB8`、沙尘土黄 `#C7A46B` | 腐殖绿 `#45663A`、孢黄绿 `#9CB84A`、腐黑 `#2A2119` | 棱镜白 `#EAF1FA`、光谱紫 `#8E7BD6`、星辰青 `#6FD3E0` |

比例基准：以铁砧塔高为 1.0，其余皆为相对值，供同框与卡面立绘取用。

## 三、涌潮虫群

| 项目 | 规格 |
| --- | --- |
| 几何语言 | 卵形与不规则弧、分叉，无标准直角 |
| 轮廓剪影 | 低矮横铺，高小于宽，边缘多毛刺 |
| 主色板 | 腐殖绿占约 65%，孢黄绿打高光，腐黑压阴影，点缀酸雾黄绿 |
| 材质 | 湿膜生物质带脉络水珠，干壳带纸纤维感 |
| 建筑与工事 | 巢为多层囊壁，腐蚀喷口是地表裂孔，粘网贴地半透 |
| 单位比例 | 巢 1.1、成虫 0.6、幼虫 0.4 |

背光透出内部颜色，是涌潮与铁砧最关键的差别。进化枝变体只做加法：母巢加孢环，孢子母体侧挂小囊。

## 四、星辉议会

| 项目 | 规格 |
| --- | --- |
| 几何语言 | 三棱柱与菱形切面，顶部收束为尖 |
| 轮廓剪影 | 高瘦垂直，底部离地一拳，靠细光柱托起 |
| 主色板 | 棱镜白占约 60%，光谱紫做结构与共鸣，星辰青做能量弹，点缀金线 |
| 材质 | 玻璃棱面加细金线，内有气泡，厚边出现虹线 |
| 建筑与工事 | 哨塔细高棱柱，方尖碑发光不攻击，炮台由开合棱面构成 |
| 单位比例 | 塔 1.3、悬浮单位 1.0，光尘侍从为 0.15 至 0.25 的碎片 |

邻塔之间用白色光桥连接，桥的粗细随共鸣层数变化，这是星辉最易认出的"活的语言"。

## 五、黑白剪影自检

| 自检项 | 通过标准 |
| --- | --- |
| 灰度化 | 纯黑白下仍可分族：铁砧方、涌潮横、星辉瘦 |
| 摘色测试 | 遮色看形状与纹理仍能说出族属 |
| 边缘测试 | 缩到 64px 高仍能分清族属与槽位角色 |
| 同框测试 | 三族混编时前后景清楚，颜色不互相吃掉 |
| 色弱测试 | 红绿盲与蓝黄盲下靠剪影与纹理可辨 |

任一项不过即退回重画。
