# 02 · 铁砧联邦：亚克力工事

> 卡面：用途＝主族一透明体质细案 ｜ 依赖：[00](00_主题宣言_千禧透明美学.md)、[01](01_透明体系总则.md)、[03](../../03_种族总览.md) ｜ 数值：[14](../../14_卡表_铁砧联邦核心12卡.md)、[数值/01](../../数值/01_铁砧联邦_12卡.md) ｜ 状态：v0.1 · 2026-09-14
> 定位：工业级层压亚克力与钢化玻璃，能检修、看得见插了什么、能当场点数故障的透明工事。数值只引用不改。

## 一、为什么透明

| 层 | 理由 | 材质落点 |
| --- | --- | --- |
| 世界观 | 工事坏了要当场修，检修口必须外露 | 观察窗全透、紧固件外置、面板可卸 |
| 机制 | 模块换装要看得见插了什么，标签阈值要能数 | 槽座外露、徽记上铭牌、换装可动画 |
| 心理 | 工业透明＝可信、可检查 | 结构不遮掩、线路有走向、故障有指示 |

- 损伤表现为层间问题（起泡、脱层、铜线烧蚀、液压渗漏），在外面就能诊断。
- 修饰槽座对上换装机制（[03](../../03_种族总览.md)），能量管光带对上 [04](../../04_塔防核心战斗.md) 的击杀返还。

## 二、材质配方（四层）

**L1 体表膜**

| 子参数 | 雾透·承力 | 全透·观察窗 | 半透·过渡件 |
| --- | --- | --- | --- |
| 折射率 n | 1.49–1.52 | 1.52 | 1.49 |
| 光透过 | < 40% | > 80% | 40–80% |
| 雾度 | 55–75% | 6–12% | 20–35% |
| 厚度感 | 板厚 1.6–2.5 | 0.8–1.2 | 1.0–1.6 |
| 偏光 | ≤ 5%，仅棱边 | ≤ 10%，仅高光条 | 5–15% |

**L2 内腔光核**

| 项 | 建议 |
| --- | --- |
| 主色／高亮／深腔 | #4FA8D8／#9FE0FF／#2E6E9E |
| 待机／交战 | 30% 阶梯脉动（0.8Hz）／70–85% 跳频随攻速 |
| 蓄力／受伤 | 40% 升到 95%（磁轨钉枪）／受伤 40% 抖动，≤ 3Hz |
| 硬上限 | 不盖过卡面数字、能量条、基地生命 |

**L3 界面层与 L4 边缘光**

| 层 | 建议 |
| --- | --- |
| L3 界面层 | 丝网印刷白 #F2F7FA＋黄铜蚀刻刻度，印槽位标记与标签徽记；永远锐利，字高 ≥ 0.12H；徽记形状区分（圆弹药、方工事、三角维修、菱形穿甲） |
| L4 边缘光 | 菲涅尔宽 1.5–2.5 px（@1080p），常态冷钢蓝，受伤偏琥珀 #FFB020，摧毁前摇偏红 #E4533C，保证黑白剪影与低端机降级 |

**分工铁律**

| 部件 | 档位 | 理由 |
| --- | --- | --- |
| 承力结构 | 雾透 | 层压亚克力＋钢化玻璃，要重并压掉噪声 |
| 观察窗 | 全透 | 低雾度钢化玻璃，让光核与结构可见 |
| 接头 | 不透明 | 黄铜 #B08D4F，提供不透明芯与朝向锚点 |
| 过渡件 | 半透 | 凝胶／糖果塑料，承接护盾与减速场 |

## 四、造型与比例

| 项 | 规则 |
| --- | --- |
| 几何语言 | 长方体与直角，圆角 ≤ 0.08H，侧面可见 3–5 层压板与 0.05H 暗缝 |
| 螺栓阵列 | 沿边等距 0.15H，四角必有 |
| 剪影 | 直线＋直角＋一个特征凸起，雾透板边界即剪影边界；纯黑填充下能区分塔／支援／路径／修饰，顶部特征件两两不同 |
| 面积配额 | 宽高比 1 : 1.4，观察窗 ≤ 35%，不透明芯 ≥ 18% |

| 内部可见结构 | 位置 | 表达 |
| --- | --- | --- |
| 液压杆 | 关节、升降臂 | 伸缩，杆身带压力刻度 |
| 齿轮组 | 基座、传动箱 | 恒速旋转，转速对应攻速 |
| 线路板 | 腔体侧壁 | 走线亮暗＝通电／断路 |
| 能量管 | 基座到炮塔 | 光带流向＝on_kill 能量 +1 的方向 |
| 弹链／弹匣 | 弹药类塔 | 随射击位移 |

不透明芯只放三处：关节（黄铜球铰，朝向锚点）、基座（铁砧黑底盘，最暗块）、螺栓（黄铜六角头，兼作损伤指示）。禁止把芯放在观察窗正后方。

## 八、好处清单

1. **模块换装零提示**：槽座外露，不用开详情就知道插了哪张修饰卡。
2. **标签可数**：羁绊阈值进度变成"数徽记"。
3. **能量流可追溯**：光带流向即 on_kill 能量 +1 的方向（[04](../../04_塔防核心战斗.md)）。
4. **损伤可诊断**：受伤表现为层间问题而非整体变红，支援卡时机更清楚。
5. **状态有冗余**：亮度、边缘光、形状三通道并行，色弱与强光下仍可读。

## 九、弱点与对策

| 弱点 | 对策 |
| --- | --- |
| 高光干扰 | 高光条宽 ≤ 观察窗 15%，走固定斜对角，不经过徽记，印刷层永远压在高光之上 |
| 透明叠放 | 同屏全透 ≤ 6，后层降 20% 亮度；重叠超 2 层只留最前一座观察窗 |
| 性能 | 单帧透明层 ≤ 8，距镜头 12 格外自动降雾透；级 3 可关 |
| 沙尘／水汽 | 沙暴抬高一档内芯光并加琥珀边，雾天边缘光加宽 0.5 px，单位周围留低细节暗区 |

## 十、验收清单

1. 12 张卡纯黑填充后仍能认出铁砧，顶部特征件两两不同。
2. 修饰槽座默认视角无遮挡，内芯色与所插修饰卡对应。
3. 卡面数字、能量条、基地生命、漏怪计数不被任何光效覆盖。
4. 每个单位同时有雾透、全透、不透明三类部件。
5. 每个单位都有不透明关节或基座，状态色均配形状冗余，闪烁 ≤ 3Hz。
