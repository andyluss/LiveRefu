> 一句话主张：**星辉的透明不是玻璃壳，而是一台运行中的光学仪器——看得见光从哪进、在哪拐、打向谁。**

## 一、为什么透明

| 层 | 理由 | 画面后果 |
| --- | --- | --- |
| 世界观 | 共鸣要求光必须走通：增益靠光在结构间传导，不透明材料在设定层就掐断共鸣 | 塔体必须通光 |
| 机制 | 共鸣链与护盾厚度必须肉眼可见，不能只靠 UI 数字 | 链子画在格间，护盾做成有厚度的膜 |
| 心理 | 水晶与全息＝昂贵、克制、优雅，是千禧年的干净未来想象 | 零锈迹零涂鸦，只有切割面与编号 |

星辉是最彻底的全透族：外壳常驻全透（> 80%），棱面切割本身就是观赏面。

## 二、材质配方（四层）

| 层 | 规格 | 禁止 |
| --- | --- | --- |
| L1 折射率 | n ≈ 1.55，折射感强于他族 | 贴图假透明 |
| L1 切割面 | 单体 6–14 个主面，面平棱锐 | 碎面、磨砂面 |
| L1 色散 | 只在棱线显彩虹，色差仅在掠射角 | 整面彩虹渐变 |
| L1 瑕疵 | 无气泡指纹，允许细切割纹 | 雾面、脏污 |
| L2 光核 | 棱镜白／彩虹核心，悬浮重心 | 无来源泛光 |
| L2 亮度 | 随共鸣计数分四档（0／1／2–3／≥4） | 常驻满亮 |
| L2 蓄力态 | 核心转单色高亮并沿光路前推 | 蓄力与待机同亮 |
| L3 界面层 | 棱面刻字、刻度、编号 | 悬浮贴纸标签 |
| L3 清晰度 | 不受折射影响，永远笔直 | 随之扭曲变形 |
| L4 边缘光 | 细锐菲涅尔，2–3 px，接通时偏护盾青 | 柔光、Bloom 溢出 |

| 角色 | 名称 | 十六进制 | 用法 |

| 主色暗阶 | 冷晶灰 | `#BAC6DA` | 未受光棱面 |
| 底色 | 深空靛 | `#0E1526` | 承载亮色的底 |
| 点缀 | 护盾青 | `#5FE3D6` | 护盾膜、共鸣接通 |
| 色散 A | 棱红 | `#FF6B9D` | 仅棱线处 |

| 色散 C | 棱青 | `#6BD5FF` | 仅棱线处 |

色散是折射产物而非涂装：只允许出现在棱线、膜边缘、光路拐点，单屏占比 ≤ 8%。

## 四、造型与比例

| 项目 | 规则 |
| --- | --- |
| 几何语言 | 棱形、切面、细杆、悬浮 |
| 剪影 | 不透明接头 → 细杆 → 悬浮棱体，间隙可见 |
| 比例 | 棱体 45–55%，细杆 25–35%，底座 15–20%，禁止坐地 |
| 朝向与投影 | 由接头与铭牌决定，离地 0.15–0.25 格，投影加深 10–15% |

**内部可见结构**：S1 折射光路（棱面入口到光核的折线光带）｜ S2 共鸣环（赤道双环，计数增加多亮一环）｜ S3 护盾膜层（体外 0.2 格同心膜壳，膜厚＝剩余护盾比例）｜ S4 蓄力腔（炮台内沿射向的长腔，2.5s 填满）。

**不透明芯**：底座接头（唯一定点，负责朝向与投影）、铭牌（石墨底白字，承载卡名编号）、相位炮台绕组（石墨线圈）。每卡至少一处不透明部件，且须承担朝向、编号或数值职能。

## 六、动效

| 场景 | 表现 | 约束 |
| --- | --- | --- |
| 待机 | 棱体约 12s 自转一圈，扫光每 6s 掠过 | ≤ 3Hz |
| 共鸣接通 | 光从共鸣环出发，沿相邻格逐格走出 | 只走真实邻接格 |
| 计数分级 | 1＝单环微亮，2–3＝双环常亮且扫光加快（+5% 攻速），≥4＝四环反向旋并上浮（+10%、+5% 射程） | 形状可辨，不靠颜色 |
| 护盾生成 | 膜层从体外 0.2 格涨出 | 叠放后层降 20% |
| 破盾反弹 | 膜碎成棱形片反向弹出（反弹 10 伤害） | ≤ 12 粒，1s 回收 |
| 蓄力 | 2.5s 内蓄力腔填满，末端转琥珀，加速时填速可见变快 | 进度连续可读 |
| 时空缓滞 | 敌人覆半透棱壳，壳内光似慢放 | 只改表现层 |
| 破盾反噬沿链传导 | 反噬光沿共鸣链逆流，整链护盾青转棱红再回青，途经膜层依次闪裂纹，最终在源头炸开 10 伤害 | ≤ 1.2s，链上最多 4 塔，禁止全屏泛红 |

## 七、UI 表现

| 元素 | 表现 |
| --- | --- |
| 卡面 | 亚克力质感：4 mm 厚、磨圆倒角、底部内发光条，数字印在不折射的表层 |
| 护盾条 | 透明膜刻度：十格同心棱环，满格呈护盾青，缺格露出背后卡面 |
| 羁绊 | 谐振拉青色谐振线（范围 +1 格），护盾链棱环咬合并标上限 +15%，节能的费用外套旋转薄棱镜并刷新为 −10% 后值 |
| 棱面映字 | 状态文字刻在棱面，随角度略缩但水平可读，长按展开为平面 |
| 数值优先 | 数值层永远最亮，光效不遮挡能量、基地生命与卡面数字 |

## 八、好处清单

1. **共鸣链可视化**：链子画在格与格之间，不必读面板就知道谁连上；
2. **护盾厚度可视化**：膜厚等于剩余护盾比例，120 与 +80 一眼可量；
3. **同屏区分度高**：铁砧层压、涌潮凝胶、星辉单晶，剪影与内部结构双区分；
4. **蓄力窗口可读**：2.5s 填满过程连续可见，加速时能看出快了；
5. **换装可见**：修饰卡插在棱面，各自改变一小块几何。

## 九、弱点与对策

| 弱点 | 问题 | 对策 |
| --- | --- | --- |
| 透明排序 | 多塔叠放前后关系错乱 | 单帧透明层 ≤ 8，同屏全透 ≤ 6，后层降 20% 亮度，12 格外转雾透 |
| 色散干扰数值 | 彩虹跑进数字 | 色散限三处，L3 不参与折射，数值下垫 60% 不透明深空靛底板 |
| 过亮 | 全场白光致对比度崩塌 | 战斗区外禁内发光，Bloom 阈值上调，边光限 2–3 px，暖高亮只留琥珀 |
| 雪地／水面 | 亮底亮塔，剪影消失 | 切暗芯模式：膜加 15% 冷晶灰吸收，边光转深空靛描边 |
| bling 过度 | 自转加扫光加脉动叠成闪烁 | 同单位最多一个动态光效，低端机只留级 1 与边光 |

## 十、验收清单

1. 每卡可拆出 L1–L4 四层，且至少一处不透明部件承担朝向或数值职能；
2. 全透外壳下能辨认 S1 光路、S2 共鸣环、S3 膜层、S4 蓄力腔；
3. 共鸣计数在 1／2–3／≥4 三档间有形状可辨的差异，不靠颜色区分；
4. 色散仅在棱线、膜边缘、光路拐点，单屏占比 ≤ 8% 且不覆盖数字；
5. 破盾反噬沿链传导 ≤ 1.2s 完成，链上最多 4 塔，全程不全屏泛红。
