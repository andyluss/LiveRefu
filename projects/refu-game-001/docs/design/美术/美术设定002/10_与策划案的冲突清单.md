# 10 · 与策划案的冲突清单

> 卡面：用途＝明确 002 号方案与原策划案（及 001 号方案）**有意不合**的地方与处理边界 ｜ 依赖：[00_主题宣言](00_主题宣言_千禧透明美学.md) ｜ 状态：v0.1 · 2026-09-14

## 一、冲突分级口径

| 级 | 含义 | 处理 |
| --- | --- | --- |
| **A 有意冲突** | 与策划案基调、材质、信息载体不一致，但不改玩法 | 保留为平行方案；若要落地需先改 [00_决策记录 D7](../../00_决策记录.md) |
| **B 新增设定** | 策划案没有写、002 需要补的东西 | 允许新增，但必须在本文登记，且不得反推修改策划文档 |
| **C 不可碰** | 数值、机制、卡名、术语、UI 布局与手势 | 一律沿用，两案共享 |

## 二、A 级：有意冲突

| 项 | 策划案 / 001 口径 | 002 口径 | 影响范围 |
| --- | --- | --- | --- |
| 美术基调（D7） | 延续工作区"复古未来"：CRT 绿字、磁带纸图、黄铜沙尘 | 千禧透明美学：水光、亚克力、镭射箔、糖果色 | 全局；落地前需重开 D7 |
| 主材质 | 黄铜、纸、磁带、混凝土、锈蚀金属 | 亚克力、凝胶、水晶、透明 PVC、镭射箔 | 单位、场景、UI、特效全部材质库 |
| 环境气质 | 干旱、沙尘、旧轨道带的废土感 | 湿润、浅水、抛光地面、恒温洁净感 | 六张地图的地形材质与天气 |
| 光照 | 霓虹与沙尘散射，多光源拼贴 | 单主光 + 水面反射 + 内发光 | 场景灯光与后处理 |
| 信息载体 | 纸图、CRT 绿字、黄铜卡匣触点 | 背光屏、透明胶片、镀铬触点 | 界面、道具、过场表现 |
| 挑战卡难度标记 | 纸质盖章与难度星 | 镭射贴纸（分越高箔面越花） | 挑战卡与关卡选择界面 |
| 记录片 | 金属/纸质片，刻字归档 | 镭射箔挂件，角度变色 | 远征台、排行榜、叙事道具 |
| 载具与道具质感 | 磨砂、油污、划痕、修补痕迹 | 抛光、水痕、气泡、指印（无油污） | 所有道具与手持物件 |

## 三、B 级：002 新增的设定

| 新增项 | 内容 | 为什么需要 |
| --- | --- | --- |
| 敌方透明口径 | 三族与从族为"秩序透明"（干净、有内部结构）；敌方增殖体与失控单位为"浑浊雾透"（悬浮杂质、无清晰内部） | 全屏都是透明材质时，敌我需要第二套区分语言 |
| 透明度三档定义 | 全透 > 80%／半透 40–80%／雾透 < 40% | 让"透明"可被验收，而不是感觉 |
| 不透明芯规则 | 每个单位至少一个不透明部件 | 保证剪影、朝向与可读性 |
| bling 三级与降级 | 静态贴图 → 动态粒子 → 交互闪耀，低端机降到级 1 | 千禧美学天然高光，必须有性能闸门 |
| 单主光规则 | 每张地图只允许一个主光方向 | 透明材质对光照一致性极敏感 |
| 记录片＝挂件 | 把档案做成可收集实体挂件 | 让叙事道具在 002 的材质体系里有落点 |
| 术语对照表 | 见 [11_术语与命名对照](11_术语与命名对照.md) | 防止两案叫法混用 |

## 四、C 级：不可碰（002 必须沿用）

- 全部数值：B 预算、难度比 D、能量曲线、卡费、护盾 120、腐蚀每层 +3%、精英 420/护甲 8、BOSS 2200/护甲 15 与 50% 阶段技、漏怪上限 3；
- 全部机制：模块换装、进化枝、共鸣、羁绊九条、挑战卡难度分口径、永久修饰五项、远征八节点与种子规则；
- 全部名称：三主族与三从族名、36 张卡名与 card_id、六张地图编号与名称、D1–D11 决策编号；
- 全部界面骨架：竖屏 60/40、卡面三层信息、手势表、触控目标 ≥ 9mm、会话节奏。

## 五、落地成本提示

| 资源 | 两案能否共用 | 说明 |
| --- | --- | --- |
| 模型拓扑与动画骨架 | **可以** | 同一套骨骼，两套材质与特效 |
| 材质库与光照贴图 | 不可以 | 金属锈蚀 vs 透明折射，参数体系完全不同 |
| 卡面版式（九字段布局） | **可以**（改材质不改版式） | 版式属于 C 级 |
| 特效库 | 不可以 | 沙尘粒子 vs 水光折射没有复用空间 |
| UI 图标形状语言 | 部分可以 | 图标语义可共用，描边与高光需重做 |

**结论**：002 若被采纳，应当是"换材质与光的整体重制"，而不是在 001 上叠加滤镜。若只做一族试点，建议选**齿轮帮**（透明玩具壳最贴千禧主题、面积小、易验证）。
