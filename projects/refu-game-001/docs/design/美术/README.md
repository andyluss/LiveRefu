## 怎么选

- 要落地到当前产品：看 **001**，它与 [D7](../00_决策记录.md) 一致，六张地图、36 张卡、七类卡面、动效与生产清单齐备；
- 要找另一种可能：看 **002**，它逐族写清了"为什么透明、透明带来什么好处、代价与对策"，并用 [冲突清单](美术设定002/10_与策划案的冲突清单.md) 明确标出与策划案有意不合之处；
- 两案的叫法对照见 [002 的术语与命名对照](美术设定002/11_术语与命名对照.md)，避免文档混用。

## 共同底线

1. 数值与机制只引用不改（美术不解释机制，机制先于美术）；
2. 任何单位都要过"黑白剪影能否认出族"这一关；
3. 数值与状态信息永远压在视觉特效之上，不得被光晕、粒子或透明材质遮挡。
