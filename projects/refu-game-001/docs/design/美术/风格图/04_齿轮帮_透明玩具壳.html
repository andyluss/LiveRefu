配方

L1 体表膜n ≈ 1.50；雾度 12–18%；厚 6–10 px；必有流痕与合模线，允许指纹与 ≤2 px 划痕
L2 内芯光电池冷光 #4C8DFF + 灯泡 #FFD23F，呼吸 0.5–2 Hz（≤3 Hz）
L3 界面层贴纸、丝印、小窗；贴纸永远清晰
L4 边缘光菲涅尔 2–3 px，白高光 85%
主光性格柔：高光圆钝、饱和度高，塑料感来自高光形状
专属补光背光 0.20；地面加糖果色反弹
粒子闪粉 24（仅交互级 3）；禁烟尘
