# 01 · 游戏概述

> 卡面：用途＝一页读懂本作 ｜ 依赖：[00_决策记录](00_决策记录.md) ｜ 状态：v0.1 · 2026-09-14

## 一、一句话定位

**星际式三族对抗的卡片塔防**：玩家以"卡组"布防，抵御一波波由卡驱动的敌人；所有内容——塔、技能、地图、事件、甚至玩法模式——都是同一套规范下的卡。

## 二、三根支柱

1. **卡片即规则**：不是给系统套皮，而是把系统拆成卡；玩家能拖、能读、能换、能组合（详见 [02_卡片规则系统](02_卡片规则系统.md)）。
2. **三主族 × 三从族**：每主族一套完整体系（塔/单位/技能/机制），各带一个从族作支援卡池；主族是骨架，从族是特色插件（见 [03_种族总览](03_种族总览.md)）。
3. **手机优先的深度**：固定路径＋固定塔位，单指可玩；碎片 3–5 分钟一关，周常有长局（见 [07_移动端与界面](07_移动端与界面.md)）。

## 三、玩家体验目标

- 前 60 秒：看懂"拖一张卡上去就能打"；
- 前 3 分钟：完成一次卡组小循环（放塔 → 升级 → 触发一次组合）；
- 前 10 分钟：感到"这套卡是我的"（首次组卡并通关）；
- 长期：收集卡与变体、试验组合、挑战周常与异步 PvP。

## 四、平台与形态

- 首发手机（竖屏为主，横屏可选 **【待定：由主程序评估】**），可离线玩 PvE；
- 单局：3–5 分钟碎片关 / 周常长局；
- 商业模式：外观与便利付费，不卖数值（见 [08_成长与经济](08_成长与经济.md)）。

## 五、玩法边界与扩展

首发＝固定路径塔防（规则卡组 A）。未来融合玩法（Roguelike、潜行、自动战斗、异步 PvP、合作）全部以**替换规则卡组**的方式接入，无需重写底层（见 [09_路线图与融合玩法](09_路线图与融合玩法.md)）。

## 六、不做什么（首版）

- 不做自由迷宫建造、不做实时 PvP、不做开放世界；
- 不把卡片化做成"只有 UI 是卡"的表层设计；
- 不在商店出售卡牌数值。
