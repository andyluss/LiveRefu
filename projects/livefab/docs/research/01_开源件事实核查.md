# 01 · 开源件事实核查

> 用途＝逐件的可核实事实（版本 / 许可证 / 自托管 / 资源 / 中文 / OIDC / 活跃度）与**未核实项清单**
> 来源：18 个类别的并行检索核查，2026-10-03。**每条以"未核实"如实标注查不到的部分**
> 依赖：[04 选型](../04_开源件调研与选型.md)（本文件只给事实，选型判断在 04）

## 〇、阅读须知（两个否决项优先看）

本文每个工具都标了 `许可证` 与 `OIDC` 两项——它们是 [04 §一](../04_开源件调研与选型.md) 定的**否决项**。
请特别留意这几类**容易误判为"开源可用"**的情况：

| 陷阱类型 | 本次核查实例 |
| --- | --- |
| **源码可见但非 OSI 开源** | Directus 12（MSCL-1.0-GPL）、Outline（BSL 1.1）、Vault（BUSL 1.1）、tldraw（自定义许可） |
| **核心开源但关键能力锁在商业版** | Medusa（SSO/RBAC）、Chatwoot（SSO/SLA/自定义角色）、Mattermost Team（OIDC）、Plane（OIDC）、OpenProject（OIDC）、Docmost（OIDC）、OpenObserve（SSO/RBAC） |
| **包照常发布在 npm，但源码属商业材料** | `@medusajs/auth-oidc`（"可见不可用"） |
| **传染性许可证（AGPL/GPL）** | Zammad、listmonk、HumHub、Forgejo、Zitadel、Grafana/Loki、Vendure 3.x（GPLv3）、Plane、Vikunja、Wiki.js、Docmost 核心、Permify |
| **停止维护 / 已终止** | Vanilla Forums OSS（官方终止）、Helpy（2023 起停更）、UVdesk（发版停滞一年） |

> **一句话**：选型时**先看许可证与 OIDC 两项**，再看功能。功能不满意可以忍，许可证踩坑要重做。

**推荐**：能接受自研 OIDC → **Payload**；必须有现成 SSO 且愿意付费 → Directus 锁 11.x + 授权 或 Strapi + SSO 包；纯静态内容 → Sveltia（认 beta 风险）。

> **本次核查最重要的发现**：Directus 12 起把 SSO 移出免费档并加了许可证强制校验，整体改为 **MSCL-1.0-GPL**（源码可见、禁止竞品商业化、四年后转 GPL-3.0）。对要做商业交付的底座，这是**实打实的法律约束**——原先把 Directus 当默认首选是过时的。

### 7.1 `NOASSERTION` 这个信号本身很有用

上表有 **7 个仓库**的 license 字段是 `NOASSERTION/Other`：
Strapi、Directus、Medusa、Vendure、PostHog、Formbricks（以及未及列入的同类）。

**它不是"没有许可证"，而是"GitHub 无法自动识别为标准开源许可证"**——
在本批里，它**恰好都指向双许可或非 OSI 许可**（MIT+商业 ee/、MSCL、GPL+商业切割等）。
所以实践中可以把它当成一个**值得停下细看的信号**：
**看到 `NOASSERTION` 就去读 LICENSE 原文，不要默认它是 MIT。**
（这与 [04 §〇](../04_开源件调研与选型.md) 的两个否决项是同一件事的另一个入口。）

### 7.2 §7 暴露的两个候选遗漏（应补进选型）

Formbricks（调研平台替代，license 非标准需核实）、HeyForm（表单构建器，**AGPL-3.0**）。
→ **建议列入 A 段**；但两者许可都要先过 [04 §〇](../04_开源件调研与选型.md) 的否决项。
