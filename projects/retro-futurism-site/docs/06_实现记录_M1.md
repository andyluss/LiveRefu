## 三、M1 的技术决定（实现期拍的板）

### 3.1 搜索：客户端 FTS，不引入搜索服务（落实 D9）

Nuxt Content 3 的 `useSearchCollection` 在**浏览器本地**加载集合并建 FTS 索引。好处是不需要
Meilisearch / Typesense 这类外部服务，与 D5「零外部服务」取向一致。

- **首次真正检索时才 `init()`**（`immediate: false`），避免每个页面都下载索引；
- 输入 **250ms 去抖**，不逐字建索引；
- 中文分词受 SQLite FTS5 限制（按字切分），实测短词命中良好；长词组召回一般，
  按 [05](05_实施路线图与验收.md) §七 R5 的预案，M2 视情况评估 Orama/外部分词。

**集成注意（实测）**：搜索被放在 `SearchDialog.vue` 内部，其触发按钮同时充当页头的搜索入口——
无需额外的 provide/inject 或全局状态，组件自身就是入口 + 弹层。

### 3.2 画廊素材：只读暴露，不复制（落实 D2）

素材位于 `doc/refu-game-001/美术/`，在 Nuxt 工程之外。按「`doc/` 是唯一内容权威」：

- **不复制**进 `public/`，**不修改**源文件；
- 新增 Nitro 路由 [`server/routes/media/[...].get.ts`](../server/routes/media/[...].get.ts)，
  把 `/media/**` **只读**映射到 `doc/`，带 MIME 推断与 7 天缓存；
- **目录穿越防护**：解析后必须仍在 `doc/` 内，越界返回 403。实测：
  `/media/../../etc/passwd` → 404；`/media/%2e%2e%2f...` → **403**。

### 3.3 画廊条目：一条 md 一个作品

[`tools/sync-gallery.ts`](../tools/sync-gallery.ts) 扫描素材生成 `content/gallery/*.md`。
选 md 而非 JSON 的理由：条目同样是**可版本化、可人工补充 `credit`/`era`/`note` 的文本**，
且复用 Nuxt Content 的 schema 校验。`credit` 是**必填**字段（沿用工作区既有版权约定）。

### 3.4 七纪时间轴：不是装饰，而是入口

每个纪都挂到**该纪代表篇目的正文**（如「原子与太空纪」→ 主卷 08 原子篇），
篇号↔篇目对应关系直接取自论文集总论 §2.1 原表的「对应篇目」列。
数据见 [`app/assets/eras.ts`](../app/assets/eras.ts)，附原作者的重要限定：
**分期的是「想象的技术」，不是真实历史。**

## 四、M1 踩到的坑

### 4.1 服务端查询必须用 `@nuxt/content/server` 的版本

`/rss.xml` 与 `/sitemap.xml` 初次实现用了客户端的 `queryCollection('blog')`，**两个端点都 500**：

```
TypeError: undefined is not an object (evaluating 'event.node.req')
    at getRequestHeaders → fetchContent → fetchQuery → all
```

**根因**：客户端版 `queryCollection(collection)` **不接收 event**；在 Nitro 路由里，
内容层需要从请求上下文取信息（headers/路径），拿不到就崩。

**修正**：
```ts
import { queryCollection } from '@nuxt/content/server'
const posts = await queryCollection(event, 'blog').all()   // ← 显式传入 event
```

> 这是个**容易反复踩**的坑：同名函数、同样的链式 API，只在**是否传 event** 上有区别，
> 类型错误在构建期不一定暴露（本次是运行时 500）。已写入本文档备查。

### 4.2 画廊标题重复（数据层面的坑，非代码错误）

地图动态的文件名是 `MAP-ANV-02_双路并行_动画.png`，去掉前缀后只剩「双路并行 · 动画」——
**四张图标题完全相同**，在画廊里无法区分。

**修正**：从「地图」专辑的文件名建立 `地图 ID → 中文名` 映射，用作地图动态标题的限定词。
现在标题是「双闸峡谷 · 双路并行 · 动画」等，全站 **0 个重复标题**。

（这类问题不会让构建失败，只会让页面看起来"对但没用"——所以需要**实际看渲染结果**。）
