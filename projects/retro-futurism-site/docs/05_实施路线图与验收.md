## 一、里程碑总览

| 里程碑 | 目标 | 交付物 | 预估 |
| --- | --- | --- | --- |
| **M0** | 骨架与选型落地 | 工程脚手架 + `bun run dev` 出首页 + 内容适配层打通 | 2–3 天 |
| **M1** | 读：Wiki + 博客 + 画廊 + 搜索 | 可公开阅读的完整站点（无论坛） | 2–3 周 |

## 四、M2 · 写：论坛 + 账号（1.5–2 周）

按 [00 决策记录](00_决策记录.md) D4 的裁决分两条路，工作量差别很大：

| 路径 | 工作量 | 交付 |
| --- | --- | --- |
| **A. 外挂成熟论坛**（Discourse/PocketBase 等） | **2–4 天** | 单向 SSO/跳转 + 主题化对齐；帖子数据在论坛自己的库 |
| **B. 站内自建论坛** | **1.5–2 周** | 表结构（见 [03](03_信息架构与内容模型.md) §3.4）+ 注册登录 + 发帖/回复/分页/权限 |

**共同验收**：注册 → 登录 → 发主题 → 回复 → 看到回复 → 登出，全链路跑通；有基本反垃圾（频率限制/最小发帖间隔）。

**明确不做**：私信、@提醒、富文本编辑器、附件上传、版主后台（M4 再议）。

## 五、M3 · 打磨（1–1.5 周）

1. **主题皮肤**：CRT 质感（可关闭）、原子时代配色、镀铬标题、机械动效；
2. **首页重做**：从"能看"到"想逛"——精选论文 + 最新博客 + 画廊九宫格；
3. **性能**：图片懒加载与优先级、字体子集化、路由预取、缓存头；
4. **SEO**：结构化数据核对、OG 图自动生成、合订本 PDF 下载页；
5. **运维**：备份脚本（见 [04](04_数据存储与同步方案.md) §D）、部署文档、`CHANGELOG` 与文档同步。

## 八、首个可运行版本的"完成"定义（DoD）

M1 结束时，需同时满足：

- [ ] `bun run build` 退出码 0，`bun run preview` 可访问；
- [ ] 91 篇论文 + 博客 + ≥40 张画廊素材在线可读；
- [ ] 交叉引用可点击，未命中清单为空或已登记；
- [ ] 搜索可用；
- [ ] 项目 `README.md` / `CHANGELOG.md` / `docs/` 与实际一致；
- [ ] 根 [`README.md`](../../../README.md) 目录导览已加入本项目入口；
- [ ] 链接校验（R03）通过。

> `[ ]` 全勾 = 可以对外说"上线了"。
