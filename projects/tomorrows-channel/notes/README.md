# notes · 笔记与会议纪要

> 存放《明日频道》的会议纪要、灵感暂存、与角色协作过程中的杂项笔记。**非正式产出**，与 [`docs/`](../docs/)（正式文档）、[`decisions/`](../decisions/)（正式决策）区分。

## 一、内容类型

- **会议纪要**：评审会 / 例会 / 提案会，用 [`meeting-template.md`](meeting-template.md)。
- **灵感暂存**：频道点子、氛围描述、关键词——可先记于此，成熟后整理进 GDD / 主美术风格方向。
- **协作记录**：跨角色沟通的结论、待确认项（正式结论进 decisions，此处只做过程留痕）。

## 二、命名约定

- 会议纪要：`YYYY-MM-DD-<主题>-meeting.md`（如 `2026-09-08-m0-meeting.md`）。
- 灵感 / 杂项：`<主题>-note.md`（kebab-case）。

## 三、与其它文档的关系

- **正式文档**（GDD、角色草案）在 [`docs/`](../docs/)；**正式决策**在 [`decisions/`](../decisions/)。
- notes 是"工作台"，内容成熟后应**沉淀**到正式文档，此处可保留或删除。

## 四、空目录

以 `.gitkeep` 占位。
