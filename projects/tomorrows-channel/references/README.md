# references · 参考资料

> 存放《明日频道》开发时可查阅的**参考资料**：外部链接快照、知识库引用索引、版权/合规资料摘录等。
> 与 [`docs/lead-artist/moodboard/`](../docs/lead-artist/moodboard/README.md)（风格参考图）区分：本目录偏**文字/文献/索引类**参考。

## 一、内容类型

- **知识库引用索引**：从 [`doc/`](../../../doc/) 各卷摘出的、与本项目频道相关的篇目清单。
- **外部链接快照**：关键官网、文档、文章（记录 URL + 摘要 + 存档日期，避免链接失效后无从查证）。
- **版权/合规资料**：许可协议说明、字体授权、素材合规口径。

## 二、命名约定

- `kebab-case` 或 `NN-<主题>.md`（如 `retro-channels-reference.md`、`fonts-license.md`）。
- 每条记录注明来源、捕获日期、是否本地快照或仅链接。

## 三、用途

- 供各角色在定方向 / 做实现时快速回溯依据，避免凭记忆。
- 关键引用的权威出处应回链根 [`doc/`](../../../doc/) 知识库原文。

## 四、空目录

以 `.gitkeep` 占位。
