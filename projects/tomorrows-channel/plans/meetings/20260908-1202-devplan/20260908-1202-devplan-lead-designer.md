## 1. 一句话立场（排期与范围是否成立）

**成立，且方向正确。** M1 = 单频道（磁带暖未来）闭环、M2 = 三频道三套氛围，这个"先验证陪伴手感、再铺频道"的次序我认同，也符合 GDD §11 的 M0→M4 渐进线与"用最小闭环验证体验钩子"的程序原则。**无需推翻，只需修两处对齐、堵一处蔓延、并为 M2 做一处优先级修正**（见 §4）。

- 排期量级接受：M1 主程序 7.5–8.5 人日 + 图形 0.5–1 人日、1.5–2 周日历，与"最快验证手感"目标匹配；M2 与 M1 可并行（主程序已指出渲染器/频道区分），我支持并行。
- 范围克制接受：主程序 §5"不该进首期"清单（勿扰/快捷键/完整图鉴/解锁经济/今日信号/呼吸引导/正式资源等）**全部同意**，均为防蔓延的正确边界。

## 2. M1 交付视角（策划验收标准：怎样算 M1 通过）

> GDD §11 M1 出口 = 磁带频道闭环可玩（专注 25min 不被打断、混音台可用、可收藏 1 卡）。以下是从**策划侧**补强的验收口径，即"手感成立"而非"功能跑通"。

### M1 必须包含（策划验收——功能位）

| 项 | 策划验收标准（到位即算） |
| --- | --- |
| ① 频道氛围"成立"（世界观能立住） | 磁带频道**占位皮肤 + 1 音景循环 + 2–3 张内容卡**能低打扰轮播，关闭动态后**静态底图 + 音景**频道仍成立（GDD §9 静默可用，判一等公民） |
| ② 番茄计时"不打断" | 25min 专注后台/最小化仍准确；**专注态进入时内容自动转"降噪"**（非必要元素隐藏/淡出）；结束用**频道音色轻提示 + 一次极简泛光**，可关、不弹窗（GDD §8.3/§4.3） |
| ③ 三态骨架可切换 | 漫游 / 专注 / 设置-图鉴三态在**磁盘频道**内能切换，且**切换不抢占焦点、不打断专注**（UI 美术 A 三态提案的落地判据） |
| ④ 收藏动作落位 | 内容卡可点"收藏"→ 写入本地图鉴最小列表（1 条目即可），有"归档"的最小反馈 |
| ⑤ 混音台可用 | ≥2 轨（嗡鸣/磁带底噪）音量滑杆**实时生效**，音轨走数据驱动 |
| ⑥ 正反馈占位 | 完成一段专注给 **1 次信号碎片正反馈**（数值初值即可），确认"陪伴不施压、无惩罚"基调在原型里成立 |

### M1 明确不含（策划确认——不做，防蔓延）

- 不作托盘 / 全局快捷键 / 系统勿扰（后置为独立 spike，GDD §10 风险 1 缓解已如此安排）；
- 不作完整图鉴（进度/归档/稀有度/卷）——图鉴进度是长线目标（§3.3），M1 只落"收藏 1 卡 + 最小列表"；
- 不作解锁与成长经济（频道/音景解锁曲线、成就）——只留"1 次正反馈"占位，完整曲线 M3 前；
- 不作今日信号（M3 垂直切片）、不作呼吸引导器（P1 子工具）；
- 不投入正式美术 / 音频资源——**用占位，但占位必须携带磁带频道的基调**（见 §3 对主美术/UI 的请求）；
- 不作 3 频道全量、不作商业化形态、不进红旗/中国/多元篇频道。

## 3. 与其它角色的依赖 / 请求（关键阻塞项，标【待定】）

> 下列为**阻塞 M1 关键路径**的项；其余不阻塞，从主程序 §4 已列。所有【待定】需对应角色在 M1 开工前给答复，否则"占位级"也无法落地。

### 对主程序
- 【待定】**引擎定稿 `01_`**：Godot 4.7.x 是否按回执锁定（解锁 01_ 引擎/目录）。M0 已倾向，请尽快拍板。
- 【待定】**渲染器选择**：M1 单频道以 2D/UI 为主 → 是否就用 Compatibility / 纯 2D，**不启用 Forward+**（减少负担与工期）。此决定也波及"是否允许每频道切后端"（磁带=2D、太空/蒸汽波=Forward+），不阻塞 M1 但**直接决定 M2 排期**，请一并给出。
- 【待定】**系统集成 spike 插入点**：主程序建议插在 M1 之后、M2 之前——**同意**，但请明确"spike 不阻塞 M2 风格切片"（M2 是图形/美术平行活，与系统桥解耦），避免 spike 拖住 M2。

### 对图形程序员 A
- 【待定】**磁带轻量后处理**（扫描线 / 微噪 / 暗角）可行性与性能初估 + **M1 用哪几个 effect**（占位级即可）——最迟在"氛围播放器"前给，决定占位皮肤怎么叠。
- 【待定】**后处理是否盖 UI + 强度上限**：影响 UI 字号与可读性（CRT 覆盖文字磨损是翻车点），需与 UI 美术 A 共同定。
- 【待定】**容器暖光实现**（主美术"双层光"）：M1 用 Way A 分层合成（2D 假辉光、Compatibility 兼容）是否确认——暖光属"基底、动效关闭后保留"，别把它做成可关动效。

### 对主美术
- 【待定】**磁带频道风格锚点 + LUT 色值**（暖/琥珀/终端感）+ **"容器暖光"量化色温/区域界定**（承接 M1 前置，评审汇总 §五 已列为 M1 前置）。
- 【待定】**占位皮肤交付**：M1 用占位色块可，但请给**至少带磁带频道基调**的最小皮肤（暖米底 + 终端绿/琥珀），使"频道世界观能否立住"在占位下就可测——**占位 ≠ 无意义色块**，否则验收 ①、⑧ 判不了。

### 对 UI 设计美术 A
- 【待定】**三态骨架 + 磁带频道最小可用面板**（专注计时角标/混音台滑杆/收藏按钮，placeholder 色块即可）——M1 需 1 套。
- 【待定】**字体字号规范**（中文系统回退 + 等宽数字）：影响正文与计时/混音数字显示，防乱码与低清放大锯齿（合订本 v1→v2 教训）。**这是 M1 可读性验收的硬线**。

### 对数值策划 A
- 【待定】**配置表结构**（频道 / 内容卡 / 计时参数 / 混音轨 的 schema）：接数值策划 A `01_` 骨架 + 主程序配置表规范；**内容卡须含强制版权字段**（合规闸门），需纳入 schema。
- 【待定】**番茄 25+5 / 5–120 与信号碎片发放初值**：M1 只需"完成一段专注给 1 次正反馈"，给初值即可；完整解锁曲线 M3 前。

## 4. 对 M2（三频道）的优先级建议

**我的建议：三频道不必强绑"同时定稿"；用"领先频道 + 差异化验证"策略，M2 先出 2 套，第 3 套后续跟进。**

理由：M2 的真实风险不是"三套风格是否都美好"，而是──**"共用骨架 + 频道 Token 换肤"这套架构，到底能不能只靠 LUT + 材质 + 动态元素就拉开频道差异、而不用重绘骨架**。这个命题**用一对差异最大的频道对照就能真实验证**，比三频道一起上更有针对性、更省。

**优先级排序（建议）：**
1. **磁带暖未来**（定稿第一）——复用 M1 基础，成本最低、最快跑通"原型→风格定稿"整条管线，并锁死 Token / 骨架。它同时是 M1 的延续与默认专注频道。
2. **太空时代**（定稿第二）——与磁带**差异最大**（深空、3D/Forward+、深度工作频道），最能暴露"区分度是否真靠 LUT 达成"以及"渲染器切后端"这一主程序/图形待定项。作为 M2 的**差异化验证切片**，若发现骨架不够通用，就在此阶段修正，代价可控。
3. **蒸汽波黄昏**（跟进第三）——偏 2D（慢色偏为屏幕后处理），成本较低，放到磁带+太空定稿后跟进即可，不构成 M2 出口的硬门槛。

> **对主程序 / 评审的请求**：把 M2 出口口径从"三频道三套氛围同时成立"调整为"**磁带 + 太空两套定稿（含动效开/关两态验收），蒸汽波跟进**"。这一调整**不改变 GDD §11 M2 的"三套氛围成立"最终目标**，只是把第 3 套作为跟进项，降低 M2 一次性并行三频道的资源与管理压力。
