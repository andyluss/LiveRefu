## 一、会议结论（一句话）

**M1 = 单频道（磁带暖未来）闭环，范围成立、方向正确；但排期按"核心 2–3 周 / 全套（含去风险项）3–4 周"计，不压单人 2 周。M1 第一周必须锁定「渲染器选择 + 配置表 schema + 版权 taxonomy」三件事；M2 三频道按"磁带 → 太空 → 蒸汽波"顺序做**（蒸汽波素材搜集与小样并行提前启动），并通过"频道 = 可插拔 bundle"抽象避免 M2 重构。**

六角色意见来源与核心主张见 [`meetings/devplan-*.md`](meetings/)。

## 二、口径确认（先消除歧义）

- **产品类型**：氛围陪伴应用（Ambient Companion），**非传统游戏**；主程序 `01_`/`02_` 需按"Godot 4.7.x 桌面导出 + 氛围陪伴应用"刷新 M0 前语境（见 §六 待办）。
- **技术主线**：Godot 4.7.x 桌面导出（macOS + Windows），渲染器倾向 **Compatibility（2D/UI 为主、弱 3D、支持 Web 降级）**——最终以 M1 第一周的双渲染器对照切片拍板。
- **里程碑节拍**：沿用 GDD §11 的 M0→M4，本次细化 M1/M2。

## 三、里程碑与排期（M1 为重点）

### M1 · 单频道（磁带暖未来）闭环

**目标**：验证"氛围陪伴手感"——专注 25min 不打断、混音台可用、收藏 1 卡。

**排期（按主程序 §二）**：
- 核心闭环（工程引导/配置表/频道装载/氛围播放/番茄计时/混音台/收藏1卡/三态UI/集成）≈ **2–3 周（单人）**；
- 全套 M1（含频道滤镜最小 + App 壳去风险 spike）≈ **3–4 周（单人）/ 2–2.5 周（双人）**；若人力单薄，将滤镜与 App 壳下移为"去风险尾插"。

**M1 必须包含（策划验收标准，主策划 §2 补强）**：

| # | 项 | 验收口径 |
| --- | --- | --- |
| 1 | 频道氛围成立 | 磁带占位皮肤 + 音景 + 2–3 卡低打扰轮播；关动态后静态底图+音景仍成立（静默可用） |
| 2 | 番茄不打断 | 25min 后台/最小化准确；专注态自动降噪；结束用频道音色轻提示+一次极简泛光，可关不弹窗 |
| 3 | 三态可切换 | 漫游/专注/设置-图鉴可切，切换不夺焦、不打断专注 |
| 4 | 收藏落位 | 点卡收藏→本地最小列表（1 条），有归档反馈 |
| 5 | 混音台可用 | ≥2 轨音量实时生效，数据驱动 |
| 6 | 正反馈占位 | 完成一段专注给 1 次信号碎片（数值初值） |

**M1 不做（守门清单，前后端一致）**：勿扰/全局快捷键系统级、完整图鉴、解锁经济、今日信号、呼吸引导、正式美术音频、3 频道、影音卡真播、登录云端、Web/移动/手柄、C# 混写。

**M1 第一周必锁（最高返工风险）**：
1. **渲染器选择**（图形 A + 主程序）：默认 Compatibility，双渲染器 2D 后处理对照切片后拍板；
2. **配置表 schema**（数值 A + 主策划）：五张表（content_card 含强制版权字段 + 稀有度 / channel / timer / mixer_track / collectible）+ CI 校验；
3. **版权 taxonomy**（主策划）：版权类型取值域（公版/CC0/自产默认入池，CC BY/BY-SA 需复核标记）。

**M1 App 壳（去风险）**：托盘 + 迷你窗 + 1 个全局快捷键 作独立 spike 先行（Godot 4 无原生托盘/系统级热键 API，需插件/GDExtension，且 macOS/Windows 差异大）；系统级勿扰/后台自启/多快捷键后置 M2/M3。

### M2 · 三频道风格切片

**目标**：磁带 / 太空 / 蒸汽波三频道各达风格定稿。**排序：磁带 → 太空 → 蒸汽波**。

- **前段**：磁带风格定稿（M1 已有薄皮肤）+ 太空风格定稿（反差最大，钉死换肤范围/对比度/材质跨度）；
- **蒸汽波并行提前**：因零素材覆盖，**在 M2 前段就并行启动蒸汽波素材搜集与小样**（主美术高优先），避免拖到 M2 后段才补而卡期；
- 须先由主美术 + UI 美术 A **一次定稿中央 Token/色板系统**（色板/频道 LUT/材质/字体角色/动效档位，含图形侧"容器暖光×频道色"分层），三频道皮肤只挂 Token、绝不各自重画；
- 程序侧：频道化架构泛化 + 滤镜栈定型 + 2D 后处理性能预算 + 内容池批量装载。

**M2 关键依赖**：M1 的频道装载按"**可插拔 bundle**"抽象（否则 M2 需重构）；需主程序先定"是否每频道切渲染后端"（磁带=Compatibility；若太空/蒸汽波可用 2D/Compatibility 实现则单后端最省）。

## 五、主要风险与对策（主程序 §四 排序）

| 风险 | 概率/影响 | 对策 |
| --- | --- | --- |
| Godot 托盘/系统级快捷键原生缺口（macOS/Windows 差异大） | 高/高 | M1 独立 spike 先行；若不顺降级"关窗→隐藏迷你窗+应用内快捷键"，系统级热键后置；平台差异记 ADR |

| 氛围手感不成立 | 中/高 | M1 本身验证；用最小闭环 + 可调参数尽早试玩；**不在 M1 提前投入滤镜/美术** |
| 复古滤镜性能超标 | 中/中 | 图形 A 出 2D 后处理预算；滤镜可关闭 |
