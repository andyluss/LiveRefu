# 渲染与后处理技术草案（草案 v0.1）

> 图形程序员 A · 2026-09-06 · 状态：待主程序引擎决策与主美术风格定稿
> 目标：给出复古未来三候选方向各自的渲染重点与可复用后处理栈，使风格切片（M2）能快速验证。

## 一、总体路线

1. 优先 **后处理栈复用**：三方向的复古感大量依赖屏幕后处理，统一实现可复用管线；
2. 素材层优先 **引擎内置 PBR/2D 管线**，自研 shader 仅用于风格化差异点；
3. 每个效果一个可开关的 feature，便于性能 A/B 与逐项取舍。

## 二、按风格方向的渲染重点

| 方向 | 核心效果 | 建议技术 | 风险 |
| --- | --- | --- | --- |
| A 磁带暖未来 | CRT 扫描线/暗角/色差、荧光单色 | 屏幕后处理（post fx） | 分辨率低时字体可读性 |
| B 原子镀铬 | 镀铬反射、柔光棚拍感 | PBR + 反射探针/环境贴图 | 反射成本 |
| C 太空时代 | 辉光霓虹、轮廓光、深空雾 | HDR bloom + rim light + fog | 辉光过曝 |

> 风格论述出处见主美术 [01_美术风格方向草案](../lead-artist/01_art-direction-draft.md)，视觉锚点引用 doc 卷。

## 三、推荐后处理栈骨架（待引擎确认）

```
游戏画面
  → 色调映射 / 色彩 LUT（统一复古调色）
  → 风格化特效（按方向开关：scanline / chrome / glow）
  → 色差与颗粒（磁带方向）
  → UI 合成（注意：部分复古特效需盖住 UI，需与 UI 美术 A 约定）
```

## 四、与主程序的接口约定

1. 渲染层只暴露给场景/表现层，玩法逻辑不直连 shader；
2. 所有 post fx 通过可配置资源（`data/fx_preset.json`）控制参数；
3. 开发期提供参数调试面板，参数收敛后冻结进配置。

## 五、开放问题

- 【待定】目标平台性能档位。
