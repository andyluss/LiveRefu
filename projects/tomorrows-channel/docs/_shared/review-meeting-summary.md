## 三、跨角色达成一致的关键决策（可收敛进 GDD v0.2）

1. **技术主线**：主程序推荐 **Godot 4.7.x 桌面导出**（MIT、渲染/UI/复古后处理最优），系统级常驻用薄原生桥（GDExtension/helper）补齐托盘/全局快捷键/勿扰；**不采用 Electron/Tauri 作为主线**（渲染/UI 重，不值得进 WebView）。图形程序员 A 确认与该路线**无原则冲突**。→ 建议 M0 确认后，主程序 `01_` 据此定稿引擎。
2. **M1 范围**：单频道（磁带暖未来）闭环——氛围播放 + 番茄计时 + 混音台 1 版 + 收藏 1 卡；2D/UI 为主、后处理轻量化；系统级集成（勿扰/快捷键）后置为独立验证切片。粗估主程序 7.5–8.5 人日 + 图形 0.5–1 人日，1.5–2 周日历。
3. **"陪伴不施压"数值纪律**：数值策划 A 自检 8 项全过（无连击/签到惩罚、无失败态、无每日任务压迫、无付费、无负数/扣减、无排名）。频道解锁按累计专注分钟、永不回退、无时间窗；碎片递减带保底 1；今日信号**不计碎片**（纯累计天数标记），杜绝"必须打开"诱因。
4. **"静默可用"列为一级特性**：图形程序员 A 把动效做成独立可关 feature，基底（LUT+材质+静态底图+皮肤）与动效层解耦，M2 交付"动效开/关"两态截图验收；UI 美术 A 同步确立"可读性优先 + 静默可用"硬边界。
5. **内容版权 → 工程合规闸门**：主程序把版权从"法律风险"转为"工程闸门"（内容卡强制版权字段 + schema 校验 + CI 脚本）；主美术素材库已全量 CC/公有领域可追溯。

## 四、M0 评审【待定】项 —— 已全部拍板（2026-09-08）

1. **版权口径复核责任人**：定为 **主策划**（内容合规口径判定）；程序侧只做"防漏放"工程闸门（强制版权字段 + schema + CI）。范围：公版 / CC0 / 自产可入池；CC BY/BY-SA 需署名+复核可商用，不作默认入池来源。
2. **§12.6 放松 vs 游戏化解锁边界**：收敛到**纯正反馈、零惩罚、零强制、零时限**区间（采纳数值策划 A 建议）；**今日信号不计碎片**（纯累计天数标记）。
3. **技术主线**：**确认 Godot 4.7.x 桌面导出为 M1/首期主线**（含薄原生桥补齐托盘/快捷键）；不采用 Electron/Tauri 为主栈；主程序 `01_` 据此定稿引擎。
4. **执行壳渲染目标 / 每频道切渲染后端**：随技术主线收敛为 **Godot Shader（原生导出）**；渲染后端允许**每频道切**（磁带=Compatibility/2D，太空/蒸汽波=Forward+/3D），由主程序/图形程序员 A 在 M2 前具体定（不阻塞 M1）。

## 五、跨角色依赖对齐（图形程序员 A"双层光"）—— 已闭环

- 主美术将母意象升级为"世界容器/装帧"层：接收机本体 = 跨频道稳定框架（拧盘换频道），频道 = 频率信号；母意象呈现需图形侧承接"**容器暖光 × 频道色**"双层光合成，并列为 **M1 磁带原型前置**。
- 图形程序员 A 追加 §八（`0100468`）对齐结论：
  - **可行**且与 Godot 4.7.x/桌面双端及"后处理栈复用 + 基底-动效层解耦"契合；**容器暖光不属于第三个滤镜**，是"容器(框架)层"自身的恒定光，与三频道滤镜分属不同层、可平行存在、互不污染。
  - **推荐实现**：采纳主美术"2D 仿 3D 设备皮肤"，按 **容器(接收机框架+暖光) / 信号(频道内容+频道LUT，限中央窗口) / 动效(可关)** 三层解耦；暖光与频道色用区域/分层遮罩隔离。M1 用分层合成（Way A），M2 可升为"单全屏 pass + 双 LUT 遮罩"（Way B）。
  - **性能增量 ≈0.1–0.3 ms，不新增全屏 pass**；单频道总成本 ≈0.6–1.3 ms，仍 ≤3 ms 预算内；Way B 运行增量≈0，仅 +<8 MB 遮罩纹理。
  - **静默可用关系**：**容器暖光属"基底"，动效关闭后仍保留**（契合"一盏亮着的灯 + 静止刻度盘"）；拆成"暖光基本常亮（基底）"+"暖光呼吸/辉光动态（可关）"两层。建议给"灯下气氛"两档，**不建议"完全无暖光"档**。
  - **新增【待定】**：向主美术＝容器暖光量化色温/色值、中央窗口区域界定、暖光"静默可用"边界、sRGB vs Display P3；向主程序＝暖光用真 bloom（Forward+ 独占）还是 2D 假辉光（建议后者）、"拧盘换频道"时容器光不闪/信号平滑过渡由图形侧还是逻辑层承担。
