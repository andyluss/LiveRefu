## 0. 一句话概念（logline）

> **你收到了一段来自"从未到来的未来"的广播信号——调频、收藏、陪着你把今天的工作与学习做完。**
> 《明日频道》是一款复古未来主义氛围陪伴应用：切换不同"复古未来"频道，让图文音视频低打扰地流淌，用专注计时、环境混音、呼吸放松等小工具陪你学习与工作。

**类型**：氛围陪伴 / 数字电台（Ambient Companion）；轻游戏化（收集与解锁），非强玩法。
**时长形态**：单次陪伴 25–120 分钟，可随时开始与离开，无每日任务压迫。

## 1. 核心体验与卖点

| # | 卖点 | 展开（给玩家的承诺） |
| --- | --- | --- |
| 1 | **一拧就换一个未来** | 频道即世界观：磁带暖未来、原子镀铬、太空时代、蒸汽波……每个频道 = 视觉氛围 + 环境音景 + 图文/影音内容 + 界面皮肤的统一体 |
| 2 | **陪学习、陪工作** | 专注计时（番茄钟）内嵌于频道氛围，不弹窗打断；时间到了用"频道自己的方式"轻轻提醒 |
| 3 | **能放松，不躺平** | 环境混音台（多轨复古底噪自由混合）、呼吸引导动画、沉思型频道（如末日废墟、星海漫游） |
| 4 | **图文音视频一体的"未来标本"** | 内容池可漫游可收藏：文章卡、引言卡、公版影像卡、自产环境音卡，形成私人"未来档案" |
| 5 | **低压力轻成长** | 收藏图鉴"未来碎片"、频道签到、成就；无连击惩罚、无失败态（反"被取消的未来"焦虑） |

**氛围基准**（一句话给主美术）：温柔、可久处、像一盏点着的旧台灯；每个频道的情绪基调都允许不同，但都要"暖而不燥、静而不闷"。

## 2. 目标玩家与平台

**目标人群**（按优先级）：
1. 知识工作者 / 学生 / 远程办公者——需要专注陪伴与背景氛围；
2. 复古未来、蒸汽波、磁带未来、Y2K 等美学爱好者（与知识库读者画像重合）；
3. 对"数字极简 / 防打扰工具"有需求、偏好桌面应用的人群。

**使用场景**：
- 上午写代码/论文：太空频道 + 环境混音 + 专注计时；
- 下午做设计/阅读：磁带暖未来频道 + 图文漫游；
- 深夜放松/睡前：蒸汽波或末日频道 + 呼吸引导；
- 午休碎片：浏览"今日信号"（每日一张未来明信片）。

**平台策略（待主程序核）**：
- **桌面 PC（macOS/Windows）为首期目标**：常驻后台、全局快捷键、勿扰集成是陪伴形态的前提；
- Web 版作次期降级（内容池共享，缺失系统级常驻能力需说明取舍）；
- 移动端暂不做首期，作为远期"放松电台"形态保留（见 §12 待定）。

## 3. 核心玩法循环

### 3.1 分钟级循环（单次使用内）
```
进入频道（选一个想待的"未来"）
  → 氛围自动起播：环境音景 + 视觉皮肤 + 内容池低打扰轮播
  → [可选] 启动专注计时（默认番茄 25+5，可调）
  → 专注中：内容自动"降噪"（转低打扰氛围），计时器以频道皮肤呈现
  → 完成一段：获得"信号碎片"（成长货币）· 轻提示音 · 进入休息/漫游
  → [可选] 漫游收藏：点开图文/影音卡 → 收藏入图鉴
```

### 3.2 小时级循环（一次工作/学习时段）
- 25min 专注 → 5min 休息（休息提示切"漫游/放松"子氛围）→ 循环；
- 时段结束（2–4 个番茄）后：查看"时段小结"（专注时长/收藏数），氛围进入"谢幕"动画。

### 3.3 天级循环（留存）
- **今日信号**：每天一句复古未来引文 + 一张图文卡（明信片感）；
- 频道"信号强度"进度：连续使用/专注累积，解锁新频道与新音景皮肤；
- 收藏图鉴推进：卡集按"卷-频道"归档，图鉴进度 = 长线目标。

### 3.4 循环图（文本）
```
[选频道] → [氛围播放] → [专注计时] ⇄ [放松/漫游] → [碎片/收藏] → [解锁/图鉴] → 回到[选频道]
     ↑___________________________ 次日"今日信号"衔接 ________________________________|
```

## 5. 世界观与叙事框架

### 5.1 叙事立意（从知识库理论转译）
产品叙事直接引用"被取消的未来"与"未来遗产化"命题（[01_理论篇](../../../../doc/retro-futurism/01_理论篇_怀旧乡愁与未来的遗产化.md)）：
> 二十世纪曾许诺过许多未来，它们大多没有抵达。但那些信号的余波仍在广播里游荡。
> 你是一名**守夜接收员**：坐在频道前，把飘来的"从未到来的未来"收下、归档，然后继续你自己的今日。

- 玩家身份：**守夜接收员**（而非"玩家"），动作是"调频—收听—归档"；
- 频道被叙述为"某条未成真的时间线"的残留广播（引用 [12_谱系篇](../../../../doc/retro-futurism/12_谱系篇_朋克宇宙学_从时钟朋克到磁带未来主义.md) 的谱系即"时间线族谱"）；

## 7. 数值与成长目标（转数值策划 A 落表）

本产品数值纪律：**陪伴不施压**——解锁全部由正反馈驱动，禁止惩罚性设计。

| 目标 | 方向性数值 | 说明 |
| --- | --- | --- |
| 默认专注节奏 | 25+5，范围 5–120 可调 | 番茄默认值，可全自定义 |
| 频道解锁 | 首期 3 频道开箱即用；扩展频道按"累计专注时长"解锁（方向：每新增频道 3–6 小时） | 不设每日任务 |
| 信号碎片 | 完成一段专注 +N（N 随段数递减保底），收藏 +M | 货币仅用于皮肤/图鉴解锁，不设付费 |
| 今日信号 | 每日 1 条，连续收听弱激励（3/7/30 天小标记，无惩罚） | 防"断签焦虑" |
| 收藏图鉴 | 图鉴条目 = 卡数 × 频道；稀有度：普通/稀有/典藏 | 典藏用于关键引言 |
| 核心体验指标 | 周留存、人均陪伴时长、专注总时长、番茄完成率、收藏转化 | 验收看 §11 |

> 具体曲线与保底逻辑由数值策划 A 依据本表出 `01_数值框架` 附表；如需调参走既有"调参闭环"（数值策划 A `02_` 文档）。

## 8. UI/UX 需求清单（转 UI 设计美术 A）

1. **三态界面**：漫游态（频道内容低打扰轮播）/ 专注态（计时 + 降噪氛围）/ 设置与图鉴态；切换不打断专注；
2. **频道即皮肤**：每个频道有独立 UI 皮肤（边框/材质/字体倾向），但共用同一套交互骨架——"UI 是世界观器物"原则（UI 美术 A `01_`）；
3. **专注计时呈现**：默认不显眼（顶栏/角标），用户可切换"沉浸大计时"；结束提醒用频道音色轻提示 + 可关闭；
4. **勿扰与降噪**：专注态自动隐藏非必要元素、通知静默；全局开关；
5. **迷你窗/托盘态**：最小化后以迷你窗或托盘图标常驻，快捷显示计时与频道名；
6. **字体**：中文正文用高可读性回退体系；装饰字体只用于频道标题与引言；数字用等宽数字（对齐数值策划 A 字段规范）；
7. **可及性**：动效可全局关闭（晕动/癫痫友好）、对比度满足基础线、音量分级；
8. 所有界面文案提供"一句话帮助"，无黑话。

## 9. 美术风格要点（转主美术定稿）

- **全局氛围锚**：温柔灯下感——"一台点着灯的旧接收机"作为产品母意象；各频道在其内部定义独立锚点，遵循"一主锚 + 同源辅助 ≤20%"纪律（主美术 `01_`）；
- **频道区分度**：主要靠 色调 LUT + 材质语言 + 动态元素，而非重绘 UI 骨架；
- **动态氛围**：磁带=扫描线与微噪、太空=星雾缓移、蒸汽波=慢速色偏（图形程序员 A 后处理栈承接）；
- **"静默可用"要求**：任何动态效果在关闭后频道仍成立（静态图 + 音景）；
- 输出需满足主美术 `02_` 资源规格（命名/尺寸/导入）。

## 10. 技术风险与原型范围（转主程序核）

**风险登记（程序侧关注）**：
| 风险 | 概率 | 影响 | 缓解 |
| --- | --- | --- | --- |
| 后台常驻/勿扰/快捷键的平台差异 | 高 | 高 | 首期先做"托盘+迷你窗+本地快捷键"，系统级勿扰集成后置 |
| 内容版权（图文/影像/音频来源） | 高 | 高 | 内容管线内置授权登记闸门；只上公版/自产/已授权内容 |
| 音视频播放与耗电 | 中 | 中 | 播放器统一、低优先级解码、动态降低刷新 |
| 频道滤镜性能 | 中 | 中 | 图形程序员 A 性能预算；动效可关闭 |
| 内容量铺不开 | 中 | 中 | 首期 3 频道 + 内容批量改写管线（可借助工作区 doc 语料） |

**原型范围（M1 建议，主程序 `02_` 对齐）**：
- 单频道（磁带暖未来）完整闭环：氛围播放 + 番茄计时 + 混音台 1 版 + 收藏 1 张卡；
- 技术选型倾向 Web 技术栈或跨平台桌面壳（Godot/Electron/Tauri 待主程序 `01_` 决），首期以"最快验证陪伴手感"为准。
