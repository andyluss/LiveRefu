## 〇、一句话基调

> **M1 的磁带频道是一台"点着暖灯的旧接收机"：暖黑灯下底 + 塑料米色机身 + 一块琥珀/终端绿的 CRT 中央窗口。** 这是"最小可辨关键氛围"的全部（先立"暖未来"辨识度，不投正式美术、不追求风格定稿）；其中**容器暖光是基底 = 动效关闭后仍保留**，用于兑现 GDD §9「静默可用」与开发计划 M1 验收 #1。

**为什么带温度而非无差别灰块**：M1 出口标准是功能（专注 25min 不打断 / 混音台 / 收藏 1 卡），但 M1 真正要验的是**「陪伴手感」**这一体验；磁带是 M1 唯一频道，若连"暖未来"的辨识度都没有，体验指标会被误判成"题材没钩子"。故 placeholder 应**带温度**。

## 一、暖底 LUT（频道信号层 · 颜色分级）

> 作用域：只作用在**接收机"中央窗口"的信号层像素**，不接触容器皮肤（见 §四 双层光隔离）。LUT 方向 = **低饱和暖米底 + 单色荧光点缀（琥珀主 / 终端绿辅）**，对比中低、氛围柔和、可读；与赛博朋克的"暗霓虹、冷、刺眼"**对立**——本频道是"机房灯、暖、可读"。

| token（sRGB 初值） | 用途 | HEX | 说明 |
| --- | --- | --- | --- |
| `tape_lut_base_dark` | 信号层暗部 / 窗口背景 | `#221610` | 低饱和暖黑褐（灯下暗） |
| `tape_lut_mid_beige` | 信号层中调 / 塑料米色 | `#C7B394` | 低饱和暖米 |
| `tape_lut_lit_warm` | 信号层暖白高光 | `#F5E9CE` | 低饱和奶油白 |
| `tape_lut_phosphor_amber` | **主荧光 · 琥珀 CRT 发光** | `#FFB000` | 单色荧光主色（指示灯/字符/泛光） |
| `tape_lut_phosphor_green` | **辅荧光 · 终端绿 CRT 发光** | `#7FC98A` | 低饱和磷光绿（辅助/状态，低占用） |
| `tape_lut_emphasis` | 状态 / 强调（备用，低用） | `#E39A4C` | 琥珀偏橙，用于计数/槽位等小元素 |

**LUT 关键**：荧光体（琥珀/绿）只在**暗**底上成立（CRT 发光=亮字暗屏），所以窗口信号层默认"暗底 + 琥珀/绿凸出"，通道底图的暖米/暖白仅用于内容卡面，不铺满窗口。可调初值，凡收敛回 `data/fx_preset.json` 前须图形 / 程序确认 sRGB vs 广色域（见 §六 【待定】P4）。

## 二、容器暖光（接收机机身 · 色温）

> 作用域：只作用在**容器层（接收机框架）皮肤材质**，作为其乘法光场 + 小范围辉光；**不接触信号层像素**（避免暖光被"染"成频道色，频道色也不"糊"到框架上——此即图形 A §八的"区域/分层隔离"）。

| token（初值） | 用途 | 值 | 说明 |
| --- | --- | --- | --- |
| `tape_container_housing_beige` | 机身外壳·塑料米色 | `#C7B491` | 面板/边框主色 |
| `tape_container_housing_dark` | 机身暗部 / 木 / 阴影 | `#2C2113` | 立体感暗部 |
| `tape_container_dial_amber` | 刻度盘背光·琥珀 | `#FFB04A` | 模拟表盘/刻度背光 |
| `tape_container_device_warm_k` | **设备自身暖光**（真空管/刻度背光）色温 | **≈ 2400 K**（琥珀） | 暖光"存在"主体 |
| `tape_container_lamp_warm_k` | **外部"灯下"台灯**色温 | **≈ 2800 K**（暖钨丝） | 局部照明 |
| `tape_container_glow_ratio` | 设备自身 : 外部台灯 强度比 | **6 : 4** | 双来源配比初值 |
| `tape_container_glow_radius` | 辉光径向衰减半径 | ≈ 220px @1080p，alpha→0 | 2D 假辉光（径向/`PointLight2D`） |
| `tape_container_lamp_direction` | 外部灯具方位 | 左上倾斜照明（柔和） | 与"灯下"母意象一致 |

**色温档位**：容器暖光落在 **2200–3000 K** 区间（琥珀→暖钨丝），初值给 **2400K（设备自身）/ 2800K（台灯）**，二者叠加后整体偏琥珀暖。**不建议**冷白（>4000K）——那会破坏"温柔灯下感"，滑向赛博霓虹。

## 三、终端边框 / 中央窗口（容器×信号区域界定）

> 回应图形 A §八【待定】「容器层与频道窗口区域界定」——本字段给出**初值**，供其落 `02_` 资源规格与分层裁剪/遮罩，需程序 + UI 美术确认。

| 项 | 初值 | 说明 |
| --- | --- | --- |
| 窗口形状 | 圆角矩形（rounded rect） | 类比 CRT 玻璃屏，避开"现代平板"直角 |
| 圆角半径 | ≈ 16px @1080p 基准 | 随分辨率缩放 |
| 窗口占屏 | 基准 16:9：约 **64% 宽 × 58% 高**，居中略偏上 | 留出顶部频道条与底部控制带 |
| bezel（边框）厚度 | ≈ 10–14 px 屏幕单位 | 参考 DEC VT100 / IBM 3279 的塑壳占比 |
| bezel 材质 | 塑料米色 + 顶部高光条 + 缓降阴影 | 2D 仿 3D"设备皮肤"（图形 A §8.2） |
| 遮罩 | 信号层裁剪区 = 窗口内；容器层在窗口外框住 | 保证暖光/频道色互不污染 |

**信号层内容被限制在窗口内渲染**；窗口 = 频道 LUT 的作用域；容器层在窗口周围框住它。识别基准：壳是**机壳**（刻痕/旋钮/刻度/网罩），窗口是**屏幕**（内容/信号）。

## 四、双层光隔离（复用图形 A Way A）

M1 用 **Way A 分层合成**（不加第二全屏 pass，成本 ≈ 0.1–0.3 ms 增量）。四层职责与本频道对应：

| 层 | 承载 | 本频道内容 | 恒常？ | 对应渲染层 |
| --- | --- | --- | --- | --- |
| 信号层（频道内容） | 内容卡 + 频道 LUT | 暖底 LUT + 琥珀/绿荧光 | 恒常（基底） | 窗口遮罩内 |
| 容器层（接收机框架） | 机身 + **容器暖光** | 塑料米色 + 刻度盘背光琥珀 + 灯下暖光 | 恒常（基底） | 独立 2D 皮肤层 |
| 动效层（可关） | 扫描线/微噪 + 琥珀指示灯呼吸/辉光 | 见 §五 | 可关 | 独立子场景/材质槽 |

**暖光与频道色用"区域/分层"隔离**：暖光只作用于容器皮肤（乘法光场 + 小范围辉光），不接触信号层像素；频道 LUT 只作用于窗口区，不接触框架。结论：**容器暖光属"基底"，动效完全关闭后仍保留**——这才是"一盏亮着的灯"能成立的原因。

## 五、磁带占位皮肤（琥珀/终端绿）+ 动效样本

### 5.1 占位皮肤基调（可用初值）

垂直三段式经典终端布局（`系统_类型_用途[变体]` 命名参照 `02_`）：

1. **顶栏（约 8% 高）**：频道名「磁带暖未来」+ 一行状态文本，**琥珀等宽**字（`tape_lut_phosphor_amber`），底为暖黑（`tape_lut_base_dark`）；右侧电源指示圆点**常亮**（琥珀，属基底）。
2. **中央窗口（约 58% 高）**：内容卡区。占位皮肤 = **暗底 + 琥珀/绿单色 CRT 字符风**；内容卡面可为低饱和暖米色块（`tape_lut_mid_beige`）+ 少量暖白高光（`tape_lut_lit_warm`）。窗口内禁用高饱和冷色。
3. **底部控制带（约 20% 高）**：一条**调谐刻度带**（琥珀 ticks + 频道档位指示）、2–3 个**旋钮**、一枚 **VU / 信号强度条**（琥珀）。整体由塑料米色 bezel 框住。

```
┌──────────────────────────────────────────────┐  ← 塑壳机身(beige) + 顶部高光条
│ [磁带暖未来]  ……  状态文本            ●(常亮) │  ← 顶栏 · 琥珀等宽字
│ ┌────────────────────────────────────────┐ │
│ │  中央窗口(16px 圆角)                    │ │  ← 信号层: 暗底+琥珀/绿荧光 | 暖米内容卡
│ │   ███ ███  琥珀单色 CRT 字符          │ │
│ │   —— 静态内容卡 面: 低饱和暖米 ——        │ │
│ └────────────────────────────────────────┘ │
│  ══╪══╪══╪══╪══  调谐刻度带      [旋钮][旋钮] │  ← 底部控制带
└──────────────────────────────────────────────┘
```

> 这是一版**可实现的占位皮肤说明**（非风格定稿）；UI 美术 A 可按此做骨架模板，区分度全靠皮肤（共用交互骨架、不重画骨架）。

### 5.2 动效样本（交图形 A 收敛进 `data/fx_preset.json`）

| 项 | 初值 | 说明 |
| --- | --- | --- |
| 扫描线周期 | ≈ 3px @1080p（2x 栅格），暗线 ≈ 1.2px | 占屏幕比例低，保可读 |
| 扫描线强度 | opacity ≈ 0.06–0.10 | 纹理叠加法（图形 A §八） |
| 微噪（luma noise） | 强度 ≈ 0.03–0.06，粒度 ≈ 1px | 细粒、静态回退也成立 |
| 指示灯呼吸 | ≈ 0.5–2 Hz | 动效层，可关 |
| 屏刷残影 / 色差 | 极微 / 可选 | M1 可按需关，不承担"频道成立"职责 |
| 动效档位 | 「灯下气氛：开启」/「灯下气氛-减轻」两档 | 减轻 = 仅保留暖光常亮、关呼吸/辉光（仍满足静默可用） |

**关键（暖光边界）**：**暖光"存在"（常亮台灯、静止刻度盘、暖米机身）= 基底，不可关**；**暖光"动态"（缓慢呼吸、辉光振幅、淡入淡出）= 动效，可关**。全局"减少动态/关闭动效"开关只关后者，**不关前者**——否则"一盏亮着的灯"这条母意象判空。

## 七、"静默可用"静态验收基图要求

> 对齐 GDD §9「任何动态效果在关闭后频道仍成立（静态图 + 音景）」、开发计划 M1 验收 #1「关动态后静态底图+音景仍成立」。**静默 = 动效全关、基底全留**，是"一等公民特性"，不是"删掉动效后的残次状态"。

**规格**：1080p 基准 / 16:9 / PNG（无损），命名对齐 `02_` → `tape_static_accept_baseline_1080p.png`。状态 = 全局「减少动态/关闭动效」下的**单帧**。

**必须成立（自检清单）**：
- [ ] 中央窗口内有 1 张**静态**内容卡 / 频道静止信号，应用暖底 LUT（琥珀/绿单色 或 暖米图面）；
- [ ] 容器层完整：塑料米色边框 + 顶部高光条 + 静止刻度盘 + 旋钮 + **电源灯常亮（琥珀）**；
- [ ] **无任何可见动态**：无扫描线滚动残影、无闪光/呼吸、无粒子、无 UV 滚动、无慢速色偏；
- [ ] **基底暖光保留**：一盏亮灯 + 一块静止刻度盘 + 暖米机身（这就是能判"静默可用"的锚）；
- [ ] 对比度 / 可读性满足基础线（UI 语义色在窗口内仍可辨，扫描线覆盖区不糊字）；
- [ ] 与音景共同构成完整氛围（静态图 + 音景即一套完整氛围）。

**用途 / 交付**：作为 M1 出口标准的**静态验收材料**（交图形 A 收敛静态回退样式、UI A 做皮肤骨架、主程序做静态截图基线）；建议同时附一张「动效开 / 关」对照图（同一套 LUT / 材质），实证"关动效频道仍成立"。

## 八、范围守门（避免越界）

本基线**只做磁带暖未来（M1 单频道）**，交付物对应主美术会议意见 §一的"0.25–0.5 周·最小可辨关键氛围"：

- **不做**：太空 / 蒸汽波的任何正式美术铺路，不做三频道皮肤定稿，不投正式美术资产、不量产；
- **暂不动**：合成波 / 太空 / 蒸汽波（对应主美术会议意见 §二/§三，均留 M2；蒸汽波素材搜集为 M2 前段并行项，非本基线）；
- **不越界替他角色拍板**：渲染后端分工、执行壳 shader 语言、是否每频道切渲染后端（主程序拍板）；渲染器对照切片、2D 后处理预算（图形 A）；三态 UI 骨架、中文字体回退（UI A）。本基线只在"磁带基调"一侧给值，标注【待定】由其确认。
