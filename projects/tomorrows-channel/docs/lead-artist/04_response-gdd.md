## 1. 全局母意象确认：「一台点着灯的旧接收机」

### 1.1 主美术侧确认

**成立。** 该意象与 GDD §1 "氛围基准"、§5.1 "守夜接收员" 叙事是同一条线：它既是产品的视觉母题（一盏亮着的旧台灯/接收机），也是玩家身份的具象（守夜接收员的工位设备）。主美术全票支持，并建议把它**从"氛围锚"升级为"世界容器/装帧"**——见下。

### 1.2 关键界定：母意象是**容器**，不是频道内容

这是本回执最重要的美术判断，直接决定混搭纪律能否守住（对齐 `01_美术风格方向草案` 的"一主锚 + 同源辅助 ≤20%"，见 [`01_art-direction-draft.md`](01_art-direction-draft.md) 二）：

- **母意象 = 接收机本体 = 跨频道的稳定"宇宙框架"**（设备的木/金属/塑料外壳、调谐刻度盘、旋钮、扬声器网罩、电源指示灯、天线、刻度背光）。
- **频道 = 接收机收进来的"不同频率信号"**（每个频道是容器里放的一个"信号内容"，各有自己的色调 LUT / 材质 / 动态 / 皮肤）。
- **切换频道 = 拧刻度盘换信号**。这一动作同时兑现 GDD 卖点 1 "一拧就换一个未来"，也让"守夜接收员调频—收听—归档"的叙事在 UI 上有动作落点。

**因此母意象不属于任一频道的"装饰"，不违反 ≤20% 辅助约束**；它是叙事与 UI 的公用结构层，恒定存在、与频道色叠加。

### 1.3 意象细化（供 UI 设计美术 A 与图形程序员 A 落稿）

| 维度 | 主美术建议 | 说明 |
| --- | --- | --- |
| 形体语言 | 30s—70s 老式接收机：圆形调谐刻度盘 + 多档旋钮 + 扬声器网罩 + 信号强度表（VU/调谐灯） | 类比"仪表盘"，避开"现代平板"质感 |
| "点着灯"光 | 双来源：①设备自身暖光（刻度盘背光/真空管暖辉）②外部"灯下"桌面台灯局部照明 | 暗背景 + 局部暖光 = "温柔灯下感" |
| 核心交互件 | 调谐刻度盘（频道 = 刻度上的一个档位）+ 中央小屏（显示当前频道信号） | 屏幕即"世界窗口"，信号即频道 |
| "信号"态 | 静态也成立：一盏亮着的灯 + 一块静止的刻度盘 | 保证 GDD §9 "静默可用"——动效关闭后母意象仍是完整场景 |
| 频道色叠加 | 母意象容器持**暖光**；频道信号持**频道色**（绿/琥珀、星云紫、粉紫……） | 双层光，见 1.5 |

### 1.4 可行性判断（主美术侧）

- **完全可行**，且成本可控。首期不做硬件级 3D，建议以**2D 仿 3D 的"设备皮肤"**（矢量/切片 + 分层光）落地，作为桌面 app 的窗口/启动壳与托盘态，避免真实 3D 渲染成本爬升。
- 母意象作为**跨频道的公用 UI 骨架层**，与"频道皮肤"分层：骨架恒定、频道只换"信号层"。这与 GDD §8 "频道即皮肤、共用同一交互骨架" 完全一致。
- 反案例自警：**不要让母意象的五金造型侵入频道内容的材质语言**（例如频道 2 太空时代内部的 Googie 金属，不应与接收机外壳混淆），否则容器与信号会串味。

### 1.5 需主程序 / 图形程序员 A / UI 设计美术 A 配合的点

| 配合方 | 需要其确认/承接 | 优先级 |
| --- | --- | --- |
| 图形程序员 A | **"双层光"合成方案**：容器暖光（恒定）+ 频道色信号（频道 LUT）叠加，二者不互相污染；给出暖光/辉光（bloom）、面板材质高光的后处理实现与性能预算 | P0 |
| 图形程序员 A | 频道滤镜栈（磁带扫描线微噪 / 太空星雾缓移 / 蒸汽波慢速色偏）可行性切片，含"动效完全关闭后仍成立"的最低开销路径 | P0 |
| 主程序 | 母意象作为 app 壳在桌面双端的呈现形态：启动壳/窗口皮肤 + 托盘/迷你窗的简化接收机；"拧盘换频道"的交互与全局快捷键映射 | P0 |
| 主程序 | 频道切换的加载策略：切换频道时，"容器光不闪、信号平滑过渡" | P1 |
| UI 设计美术 A | 母意象"接收机"的 UI 骨架（旋钮/刻度/spinner）如何与三态界面（漫游/专注/设置图鉴）共存，且不喧宾夺主 | P0 |

### 2.1 太空时代频道的美术警戒线（与 01_ 方向草案衔接）

方向 B（原子镀铬）与方向 C（太空时代）在素材库有若干**同源重复**（Googie、Space Needle 均出现在 B 与 C 目录，见[素材库 README](moodboard/README.md) 六）。二者共享"太空竞赛 / Googie"血统，但**情感基调不同**：方向 B 是"乐观、明亮、塑料+金属的按钮生活"，方向 C 是"辽阔、肃穆、纪念碑感"。

**主美术建议**：《明日频道》首期"太空时代"**坚持方向 C 的肃穆基调**（深空、霓虹、Googie 乐园感），把方向 B 的高饱和粉蓝粉红"轻快生活"感**排除出首期**——即使同源，也因其情感基调与"深度工作"的定位不符。方向 B 素材**保留**，供扩展频道（GDD §5.2 "原子镀铬"）使用，不在首期混入。

### 2.2 蒸汽波黄昏频道的美术警戒线（本频道最易串味的点）

蒸汽波与合成波（Outrun）共享同一批视觉库存（品红霓虹、网格地平线、VHS、CRT），是最容易串的一对。依据 [17_蒸汽波篇](../../../../doc/retro-futurism/17_蒸汽波篇_蒸汽波与合成波_时代错置的听觉乡愁.md) 一、三节的辨析：

- GDD 定名"蒸汽波黄昏"，情绪关键词是"**松弛、慢、复古空调风**"（放松/漫游）→ 明确落在**蒸汽波**一侧（悼念、安抚、商场软波、粉紫柔光）。
- **排除**合成波/Outrun 一侧（跑车剪影、迈阿密霓虹、硬朗鼓机、更激越）——那更接近"激越的 80 年代 again"，会破坏"沉浸在慢里"的放松定位，也与频道 2 的霓虹竞争。
- 因蒸汽波与太空时代都偏紫/品红系，**两条频道的 LUT 区分度必须拉满**：太空时代 = 冷、对比强、轮廓光、肃穆；蒸汽波 = 暖粉、低对比、柔光、松弛。若区分不足，会在漫游与深度工作之间造成视觉混淆（详见 §4【待定】3）。
