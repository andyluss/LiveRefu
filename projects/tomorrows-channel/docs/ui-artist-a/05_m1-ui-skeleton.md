## 一、一句话结论

**M1 用「最小可用面板 + 磁带频道一套轻量 Token 皮肤」，把「共用交互骨架 + 频道主题令牌（Token）」这套换肤骨架钉下来；先跑通「漫游 ↔ 专注」两个态与基础容器，设置/图鉴态只在**骨架层**定义到位（避免 M3 重构），不做全流程。**字体规范（系统中文回退 + 等宽数字）作为不可让的可读性底线，在本文档 §七 一次性锁死，为 M2 三频道皮肤共用铺路。**

> 核心：M1 的目的不是"做不做正式美术"，而是**把「频道即皮肤」的骨架与 Token 管线早定**——骨架一旦因灰盒变形，M2 就是重画而非换肤。

## 二、范围收口（M1 做什么 / 不做什么）

### 2.1 M1 UI 范围（磁带最小集）

M1 UI 最小集 = **专注计时 / 混音台 / 收藏动作** 三件，另加**频道氛围底 + 基础容器**，正对应 GDD §11 的 M1 出口（专注 25min 不被打断、混音台可用、可收藏 1 卡）。

| # | M1 UI 要做的 | 说明 |
| --- | --- | --- |
| 1 | 三态**骨架**（漫游/专注/设置-图鉴）——结构定义到位 | 骨架不变，M3 才补全流程 |
| 2 | 漫游 ↔ 专注 **两态切换**（M1 实测） | 切换不夺焦、不打断专注 |
| 3 | 磁带频道**最小面板**（接收机中央窗口） | 一层容器 + 一档边框材质 + 荧光单色 |
| 4 | 专注计时器呈现（默认角标 + 可切沉浸大计时） | 频道皮肤化计时 |
| 5 | 混音台 ≥2 轨滑杆（实时生效、数据驱动） | 数值策划 A 字段 |
| 6 | 收藏动作（点卡收藏 → 最小列表 1 条 + 归档反馈） | 本地最小列表 |
| 7 | 频道切换（漫游态内） | 单频道下为频道选择器/切换入口 |
| 8 | **字体规范**：系统中文回退 + 字号阶梯 + 等宽数字 | 可读性底线，跨频道共用 |

### 2.2 M1 UI 不做（守门，前端一致）

完整图鉴流程与图鉴条目页、今日信号、呼吸引导、正式美术优化（润色/贴图打磨）、全屏托盘/迷你窗（→ 主程序独立 spike）、系统级勿扰/全局快捷键、3 频道皮肤、影音卡真播、手柄/触屏适配。

> **注**：开发计划 M1 验收口径 #3 写「三态可切换（漫游/专注/设置-图鉴）」；而本角色 M1/M2 会议意见 §二 写「设置态、图鉴态后置 M3」。二者**不一致**，需主策划在本文 §八 拍板边界。我按「**骨架三态可切 + 设置/图鉴仅极简占位**」落地（见 §三 完整度矩阵），既满足"可切"，又不为 M1 烧全流程——合并为一条【待定】。

## 三、三态 UI 骨架（架构层）

GDD §8 / 本角色 `04_` §二：三态**不是三个独立应用**，而是**同一套骨架上的三种「信息密度档位」**，靠「降噪 + 焦点转移」区分。M1 只实测漫游/专注，但**骨架结构一次性定到位**，避免 M3 重构。

### 3.1 三态结构（同一频道内）

| 态 | 核心任务 | 界面主导 | 信息密度 | 对专注的打扰 | M1 完整度 |
| --- | --- | --- | --- | --- | --- |
| **漫游态** | 看内容、收藏、选频道 | 内容低打扰轮播 + 频道皮肤 | 中 | 无（默认） | 实测 |
| **专注态** | 完成一段专注 | 计时 + 降噪氛围 | 低 | 无（降噪后更低） | 实测 |
| **设置与图鉴态** | 配置、查收藏 | 工程台面板/列表容器 | 高（临时） | 有意进入才显示 | **骨架/极简占位**（全流程 M3） |

### 3.2 三态完整度矩阵（骨架定 vs 实现范围）

| 层 | 骨架（M1 定） | M1 实测 | M3 补 |
| --- | --- | --- | --- |
| 状态机 / 图层可见度 | ✅ 定义 | 漫游+专注 两套可见度 | 设置/图鉴 可见度 |
| 焦点策略（不劫持） | ✅ 定义 | ✅ 实现 | 沿用 |
| 漫游态容器 | ✅ 定义 | ✅ 最小实现 | 全流程 |
| 专注态计时/降噪 | ✅ 定义 | ✅ 实现 | — |
| 设置态（工程台） | ✅ 架构 | ⭕ 极简（音量/动效开关/退出） | 完整设置 |
| 图鉴态（未来档案库） | ✅ 架构 | ⭕ 占位（"已收藏 1 卡"列表） | 卷-频道归档 |

### 3.3 给主程序的实现口径：三套图层可见度 + 一套焦点策略，不是三套窗口

- **三态 = 图层可见度开关 + 焦点不劫持**，不是三个独立场景。
- 切换**不抢焦点、不弹模态遮罩、不抢键盘/鼠标焦点**；设置/图鉴态进入时若正处专注，计时器于顶栏角标**继续走表**，设置只在地面以下增厚、**不盖住计时**。
- 状态持久化**可出可回**：任何态均可经频道选择器/托盘/快捷键无损回退；专注期最小化到托盘/迷你窗时计时不中断。

## 五、专注计时器呈现（M1 核心手感触点）

GDD §8.3 / 本角色 `04_` §四：计时的重点是**别抢戏**。M1 落两种形态 + 克制结束提醒。

### 5.1 默认形态：不显眼（顶栏/角标）

- 默认出现在**接收机表带**上：一条细小的**频道色进度胶囊/角标**，显示当前时段剩余时间 +（可选）进度光条。
- **用频道皮肤呈现**：磁带频道里它是一台**转动的磁带倒计时盘**（一弧进度 + 琥珀点缀），器物式点缀，不喧宾夺主。
- 数字用**等宽数字**（§七），防倒计时跳动引发焦虑。
- 提供「隐藏计时」开关：不显示计时，只靠结束提醒报时——真正「隐形番茄钟」。

### 5.2 沉浸大计时（用户显式切换）

- 需要聚焦/自控时段，用户主动切成**全屏大计时**：频道皮肤化**大表盘/大字**居中，氛围文字/引言留白，动态层降到最低。
- **不弹窗、不遮其他必要信息**；沉浸态一键还原为角标；不做秒表滴答、夸张转场、红色紧迫色。
- 遵守**静默可用**：计时本身不依赖任何动态层，关闭装饰层后依然成立。

### 5.3 结束提醒：克制设计（声音第一、视觉第二、绝不打断）

- **声音**：每频道一套「频道音色」轻提示，用频道自己的方式报时——磁带=卡带弹出声 + 微噪渐弱（音频/美术占位）。
- **视觉**：仅在计时器处做一盏「轻轻呼吸」的泛光或一次极简淡入，**不用全屏遮罩、不用强弹窗**。
- **可关闭**：音/视提示各自独立开关，并提供「静默到段」选项。一段结束后给**轻提示 + 进入休息/漫游子氛围 + 「时段小结」入口**，不强制打断当前内容。

> 给图形程序员 A 的协调：结束提醒「轻轻泛光」是**频道装饰层的一部分**，须服从「关闭动态后频道仍成立」，动画强度需与后处理栈一致（§八 · ③）。

## 六、换肤骨架（共用骨架 + Token）

### 6.1 结构：骨架（Globals）⇄ 皮肤（Theme）

```
共用交互骨架（跨频道不变，一次实现）
  ├─ 布局/栅格/容器结构
  ├─ 组件：面板、按钮(3态)、开关、滑杆、进度条、图标(线性/填充)、弹窗、Toast
  ├─ 字体排印阶梯（字号/行高/中英回退/等宽数字）——可读性底线，跨频道统一
  ├─ 九宫格/切片、Hit area、焦点态、键盘导航
  ├─ 图标 language（线性-填充两级）——形状统一，仅着色可频道化
  └─ 交互反馈逻辑（悬停/按下/禁用）——行为统一，仅曲线可频道化

频道主题令牌 Theme Token（每频道一套值，填入骨架）
  ├─ 色板: bg / surface / primary / accent / glow / text / scanline
  ├─ 材质/纹理: 面板材质、边框语言、切角圆角、光照意象
  ├─ 装饰层: 扫描线 / 星雾 / 慢色偏（动态，可关）
  ├─ 装饰字体倾向: 标题/引言用（正文不随频道变动）
  └─ 动效基调曲线: 缓动、呼吸、微噪强度（须保证关闭后频道仍成立）
```

### 6.2 换肤机制约定（M1 需与主程序对齐，见 §八 · ②）

- 目标：能在**不改骨架结构**前提下，仅更换一套 Token 值（色板/材质/装饰层/装饰字体/动效曲线）得到一个新频道皮肤。
- 两类实现路径（主程序拍板）：**运行时 Token 热切换** / **预烘焙 UI 主题**。二者决定 Token 系统组织方式与 M2 成本。
- 若某频道需要**新容器/新结构** → 那属于**新增骨架能力**，须经骨架层评审，**不得**由该频道自带皮肤，否则退化为每频道一套 UI。

### 6.3 三类元素归属：统一 vs 随频道

| 元素 | 全局统一（骨架） | 随频道变（Token） | 理由 |
| --- | --- | --- | --- |
| 布局/容器/栅格 | ✅ | — | 骨架一致，低成本 |
| 组件形状/九宫格/3 态 | ✅ | — | 一次实现，不重绘 |
| 字体排印阶梯 / 中英回退 | ✅（可读性底线） | — | 可读性不随频道打折 |
| 等宽数字（tabular figures） | ✅ | — | 防跳动 |
| icon 形状 | ✅ | — | 语言一致 |
| 色板（bg/surface/accent/glow） | — | ✅ 每频道 | **频道区分度主战场** |
| 材质/边框/切角 | — | ✅ 每频道 | 器物感来源 |
| 装饰层（扫描线/星雾/慢色偏） | — | ✅ 每频道 | 靠后处理叠加 |
| 装饰字体（标题/引言） | — | ✅ 每频道倾向 | 仅装饰字 |
| 动效基调曲线 | — | ✅ 每频道 | 磁带=扫描线微噪、太空=星雾缓移、蒸汽波=慢速色偏 |

> **纪律**：随频道变的只允许是「Token 值」，不允许改「骨架结构」。

## 七、中文字体回退与字体排印规范（M1 必锁）

承接本角色 `01_` §三、`04_` §五；历史教训见工作区合订本 v1→v2 字体兼容事故（`04_` §5.2）——**字体必须显式验证、显式声明回退、绝不假设某系统字在 macOS/Windows 双端可用**。

### 7.1 中文字体回退链（可读性底线，跨频道共用）

**规则 A（中文正文 / 卡片文案）**：走**系统中文回退**，**不用终端等宽字**排中文正文（多数复古终端字缺 CJK 字形 → 豆腐块/乱码）。

| 字体槽 | 用途 | 首选 | 回退链 | 原则 |
| --- | --- | --- | --- | --- |
| `font_body_cn` | 中文正文/卡片文案 | macOS `PingFang SC`，Windows `Microsoft YaHei` | 系统默认 sans → Godot 内置默认字体 | 可读性优先、跨端一致；不取终端字 |
| `font_digit_tabular` | **数字**（时长/进度/收藏/碎片） | 支持 `tnum`（tabular figures）的独立数字字体 | 系统字体 + 显式启用 tnum → 定宽格式兜底 | 等宽数位，防跳动（见 7.3） |
| `font_decor_<channel>` | 频道标题/引言（装饰字） | 各频道复古装饰字体 | 回退 `font_body_cn` | **仅标题与引言**，不做正文；版权与回退须单列 |
| `font_latin` | 纯西文 | 随正文槽/装饰槽 | — | 中西文分槽，避免缺字 |

**规则 B（中英混排）**：中西文**分别回退**，避免西文字体缺字（`01_` §三.3）。中文句子内的阿拉伯数字 → 用 `font_digit_tabular` 槽。

**规则 C（装饰字只做「皮」）**：装饰字只用于频道标题与引言，承担器物感；**正文永不使用装饰字**——这是「可读性优先 + UI 是器物」的边界。

### 7.2 字号阶梯（1080p 基准，运行时按窗口缩放）

| 级 | 名称 | 字号(px @1080p) | 行高 | 用途 | 字体 |
| --- | --- | --- | --- | --- | --- |
| 1 | 沉浸计时 | 96 | 1.2 | 沉浸大计时数字 | `font_digit_tabular` |
| 2 | 频道标题 | 36 | 1.25 | 频道名/装饰标题 | `font_decor_<ch>` |
| 3 | 标题 | 24 | 1.4 | 面板标题/区块标题 | `font_body_cn` |
| 4 | 正文 | 17 | 1.6 | 卡片文案/正文 | `font_body_cn` |
| 5 | 说明 | 14 | 1.6 | 辅助/提示 | `font_body_cn` |
| 6 | 角标/标签 | 12 | 1.4 | 计时角标/标签/控件 | `font_digit_tabular` + `font_body_cn` |

> 相对 `01_` §三.1 的"4–5 级"，本表扩到 6 级（新增沉浸计时级、频道标题级），覆盖标题/正文/说明/角标 + 2 个装饰/计时级。各级**行高、字重、字距**须组内统一，跨频道共用（骨架层），仅频道标题级随频道的装饰字体变化。

### 7.3 数字等宽规范（tabular figures）——防乱码/跳动，M1 必锁

1. **数字一律走 `font_digit_tabular` 等宽数位**：倒计时、时长（`MM:SS`）、进度、收藏数、碎片数等**所有数字字段**用等宽数字，避免数位宽度不同导致数字跳动/错位（对齐数值策划 A 字段规范，`02_` §四、`04_` §6·⑥）。
2. **显式启用 tnum**：优先用支持 OpenType **tabular figures（`tnum`）**的字体；若无，用系统字体并显式启用其 tnum 特性；再不行，用**定宽格式兜底**（如 `%02d` + `monospace` 数字克隆字体）。**须显式验证 macOS/Windows 双端渲染**（合订本 v1 教训）。
3. **位宽约束**：数字显示节点必须预留**固定宽度**（不因位数变化撑开），避免倒计时跳行/面板变形；具体字段最大位数见 7.4。
4. **数字允许字符集**：仅 `0-9`、`:`、`-`、`+`、`/`、`%` 等固定符号，禁止全角数字混入。

### 7.4 数字字段位宽（占位，待数值策划 A 定稿）

| 字段 | 范围（GDD §7 方向） | 显示位宽（占位） | 溢出风险 |
| --- | --- | --- | --- |
| 专注时长 | 5–120（默认 25+5） | `MM:SS`（≤3 位数），可扩 `HH:MM` | 中 |
| 信号碎片 | 完成专注 +N（占位） | 3 位数（`999+` 兜底） | 中 |
| 收藏数 | 逐频道累计（占位） | 3 位数 | 中 |
| 进度（信号强度） | 百分比 | 3 位数 | 低 |

> 以上为**占位位宽**，实际最大位数须由数值策划 A 在 M1 入口冻结 `data/schema` 时一并给出，避免 UI 溢出（见 §八 · ④）。

### 7.5 排印落地（写入 `01_` 正文 v0.2 建议）

| 用途 | 字体策略 | 原则 |
| --- | --- | --- |
| 中文正文/卡片文案 | 系统中文回退（PingFang SC / Microsoft YaHei），不用终端等宽字 | 可读性/跨端一致 |
| 数字 | 等宽数字（tabular figures）+ 等宽回退 | 防跳动，对齐字段 |
| 频道标题/引言 | 各频道复古装饰字，仅用法 | 装饰字只做「皮」 |
| 中英混排 | 中西文分别回退 | 避免缺字 |
