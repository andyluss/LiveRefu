# 立项概念草案（草案 v0.2）

> 主策划 · 2026-09-06 · 状态：方向 D 已获指定立项，GDD v0.1 待全工作室评审
> 目标：提出复古未来题材下可开发的概念方向，供数值策划 A / 主美术 / 主程序 / UI 设计美术 A / 图形程序员 A 评估可行性。v0.2 起以**方向 D（复古未来氛围陪伴）**为当前立项主线，A/B/C 转为传统玩法候选保留在案。

## 一、方向总述

本工作区专注 **复古未来（Retro-futurism）**：对"过去时代所想象的未来"的回收、消费与再创造。
立项应从知识库中可复用的美学-情感模块出发，而非泛泛的"科幻"。候选方向按《总论》[00](../../../../doc/retro-futurism/00_总论_未来的考古学与全卷地图.md) 的三层时间模型与四元素框架归类。

## 二、候选方向

### 方向 D：明日频道 —— 复古未来主义氛围陪伴（★ 当前立项）

- 定位：把复古未来做成 **学习/工作时的氛围陪伴应用**：一个可切换"复古未来频道"的空间，图文音视频低打扰地流淌，内置专注计时、环境混音、呼吸放松等小工具。
- 核心体验：体验各种复古未来主义（磁带暖未来/原子镀铬/太空时代/蒸汽波…），像同时拥有一座"未来电台 + 专注时钟 + 放松舱"。
- 参考卷：全卷皆可为"频道词典"，重点 [01_理论篇](../../../../doc/retro-futurism/01_理论篇_怀旧乡愁与未来的遗产化.md)（被取消的未来/遗产化）与 [12_谱系篇](../../../../doc/retro-futurism/12_谱系篇_朋克宇宙学_从时钟朋克到磁带未来主义.md)。
- 玩法（轻游戏化）：以"收听时长/专注时长"驱动解锁频道与收藏，无强玩法压力。
- 商业/合规要点：内容版权（图文音视频来源）必须立规，见 GDD。
- 主笔文档：[../_shared/gdd-tomorrows-channel.md](../_shared/gdd-tomorrows-channel.md)

### 方向 A：磁带暖未来 —— 模拟接口的怀旧冒险（候选保留）

- 关键词：磁带未来主义、CRT 终端、暖色模拟、个人电脑黎明期。
- 参考卷：[14_磁带篇](../../../../doc/retro-futurism/14_磁带篇_磁带未来主义_模拟接口的暖未来.md)、[17_蒸汽波篇](../../../../doc/retro-futurism/17_蒸汽波篇_蒸汽波与合成波_时代错置的听觉乡愁.md)
- 玩法想象：在"一台老终端里的世界"中解谜/叙事，UI 即世界观的一部分。
- 美术：低保真、扫描线、暖光。
- 风险：非 3D 重渲染，图形程序员 A 的发挥空间偏后处理与风格化。

### 方向 B：原子镀铬 —— 幸福原子时代的桌面乐园（候选保留）

- 关键词：原子朋克、镀铬郊区、按钮生活、太空竞赛乐观主义。
- 参考卷：[08_原子篇](../../../../doc/retro-futurism/08_原子篇_原子朋克_幸福原子与镀铬郊区.md)、[06_机器篇](../../../../doc/retro-futurism/06_机器篇_速度与钢骨_未来主义与装饰艺术的机器乌托邦.md)
- 玩法想象：建造/经营 1950s 想象未来中的家园；经济系统负担重（数值策划 A 舞台大）。
- 美术：亮铬、粉蓝、圆润流线。
- 风险：题材乐观底色与当代玩家的批判视角需要叙事平衡。

### 方向 C：太空时代 —— Googie 射线枪哥特（候选保留）

- 关键词：太空时代、Googie 建筑、射线枪、明日世界乐园。
- 参考卷：[09_太空篇](../../../../doc/retro-futurism/09_太空篇_太空时代_Googie射线枪哥特与明日世界.md)
- 玩法想象：动作/冒险于"被取消的太空未来"废墟中。
- 美术：霓虹星云紫、镀铬流线、飞碟剪影。
- 风险：玩法同质化风险高，需要独特钩子。

## 三、初步推荐

**方向 D 为当前立项**（由项目方指定：主打体验复古未来图文音视频并作为学习工作陪伴）。方向 A/B/C 保留为后续传统玩法立项候选。

## 四、待定问题（供各角色评审）

1. 目标平台（桌面 PC / Web / 移动）与后台常驻形态？
2. 内容版权策略（图文/音频/视频来源与授权）？
3. 商业化模式（买断 / 订阅 / 免费+扩展包）是否需要立项初期考虑？
4. 专注/放松功能与"游戏化解锁"的边界（防打扰 vs 提供正反馈）？

## 五、协作请求（方向 D）

- 主美术：为"频道-视觉-音景"三联给出风格锚点初判。
- 图形程序员 A：频道滤镜/氛围渲染（CRT、镀铬辉光、星云）实现难度初判。
- UI 设计美术 A：频道切换 + 专注计时 + 混音台的界面舞台评估。
- 数值策划 A：专注/解锁节奏的数值承载（时长驱动解锁曲线）。
- 主程序：常驻后台 + 音视频播放 + 全局快捷键的可行性。
