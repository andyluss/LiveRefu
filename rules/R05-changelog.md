## 规则要点（当前）

- **每次变更都须写入变更日志**（工作区根 `CHANGELOG.md`；项目/实验各自根 `CHANGELOG.md`），除非**琐碎改动**——如改错别字、纯格式（空白/缩进）、不改语义的措辞润色等。
- 变更日志格式遵循 [`tech/changelog-convention.md`](../tech/changelog-convention.md)（Keep a Changelog 类目 + SemVer 版本 + 东八区日期）。
- 条目**一条对应一个逻辑变更**，面向人（写清"改了什么、为什么、影响谁"）；与 git 提交粒度对齐，但不以日志替代提交记录。

## 琐碎改动的判据（不写日志）

满足**全部**以下条件可视为琐碎、免写条目：

1. 不改变对外/可观察语义（无行为、接口、目录结构、文档结论的变化）；
2. 不新增、不删除、不改动任何需被追踪的产物（新增/改版规则、文档类目、数据 schema 等）；
3. 纯文字层面：错别字、标点、格式、空白、措辞润色、相对链接深度修正。

> 反之，只要触及**内容/结构/约定/产物**之一，就必须记录。
