# R01 · 文档约定（已定 · 现行）

**一句话**：工作区 Markdown 一律**简体中文 + UTF-8**；`doc/`、`studio/` 按各自体例；**相对链接**按"目标相对当前文档的正确深度"书写；**日期**取东八区系统时间。

## 一、目标

让全工作区文档"体例一致、链接可跳转、日期可信"，使人与 AI 依据同一条约定书写。

## 二、规则条款（主选）

1. **语言与编码**：简体中文，Markdown（UTF-8）。
2. **`doc/` 编号体例**：`00_总论_…`、`01_理论篇_…`；专题卷 `00_对读篇_…` 起。
3. **`studio/` 体例**：角色目录内 `README.md` 为身份入口，工作文档为 `两位序号_主题.md`；草案标 `v0.x`，未决问题标 `【待定】`，结论记入各文档「决策记录」。
4. **跨目录引用**优先使用**相对路径**链接。
5. **相对链接深度**：以文件自身所在目录为基准，**朝向工作区根每深一级多一个 `../`**；例如 `studio/主策划/…` 指向 `doc/` 须写 `../../doc/…`。校验见 [R03](R03-link-validation.md)。
6. **日期**：一律**东八区（Asia/Shanghai，`+0800`）**、**取自系统实际时间**（写前先跑 `date '+%Y-%m-%d'`），**禁止"脑内手写"或相对推算**。

## 三、备选（被放弃的选项）

| 备选 | 为何不为主选 | 代价 |
| --- | --- | --- |
| 中英混排 / 英文文档 | 工作区读者与既有文档以中文为主 | 阅读成本、术语不一 |
| 站内绝对路径链接 | 本地 IDE / 预览器 / 网页版不通用 | 链接大量失效 |
| 手写日期 / 相对日期推算 | 易与实际（提交时间）不一致（曾发生写错案例） | 记录不可信 |

## 四、判定标准

- 新文档：简体中文 + UTF-8；体例属 `doc/` 或 `studio/` 之一并符合其编号/命名。
- 含链接：按当前文件深度书写；经 [R03](R03-link-validation.md) 的 pre-commit / CI 校验通过。
- 含日期：其值等于运行 `date`（东八区）所得。
