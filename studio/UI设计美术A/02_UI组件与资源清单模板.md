## 三、资源命名与规格（并入主美术 02_ 规范）

- 前缀：`ui_`（通用）、`ui_a_/ui_b_/ui_c_`（按方向候选区分，定稿后统一）；
- 九宫格切片按钮提供 3 态；图标提供线性/填充两档；
- 尺寸基准 1080p，4x 上限；颜色空间 sRGB（对齐主美术 02_）；
- 字体资源单列：注明版权与回退字体（CJK 可读性检查见 01_ 第三节）。
