# UI 视觉与字体规范草案（草案 v0.1）

> UI 设计美术 A · 2026-09-06 · 状态：待主美术风格方向（主美术 01_）定稿后细化
> 目标：在"复古未来"主锚点下统一界面语言与字体排印，保证风格成立且信息可读。方向候选对应主策划 [01_立项概念草案](../主策划/01_立项概念草案.md)。

## 一、UI 语言派生原则

1. UI 是"世界观里的器物"，不是悬浮的现代面板——方向 A 的 UI 应是"终端里的界面"，方向 B 应是"按钮生活家电面板"，方向 C 应是"乐园/飞船控制台"；
2. 所有组件从主美术锚点取材质与配色，不引入锚点外的风格；
3. 形式服从功能：风格化不得压过可读性与操作效率。

## 二、按候选方向的 UI 基调

| 方向 | UI 关键词 | 字体倾向 | 陷阱 |
| --- | --- | --- | --- |
| A 磁带暖未来 | CRT 终端、绿/琥珀单色、模拟表盘 | 等宽/终端感 | 扫描线下中文可读性 |
| B 原子镀铬 | 圆润按钮、流线面板、未来家居感 | 圆体/几何感 | 高光过强刺眼 |
| C 太空时代 | 乐园导视、控制台、星云描边 | 海报衬线/宽字距 | 信息层级混乱 |

## 三、字体排印规范（草案）

1. 建立 **字号阶梯**（标题/正文/说明/角标 4—5 级），每级登记磅值与行高；
2. 中英文混排规则：中文用系统中文回退字体，避免西文字体缺字造成豆腐块；
3. 数字（数值策划 A 的字段）用 **等宽数字**（tabular figures），避免跳动；
4. 若采用复古终端字体：需额外验证小字号下的 CJK 字形与抗锯齿，必要时回退系统字体（历史教训：合订本字体兼容性问题曾导致乱码，见 doc 仓库提交记录）。
