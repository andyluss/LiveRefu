# 立项概念草案（草案 v0.1）

> 主策划 · 2026-09-06 · 状态：待全工作室评审
> 目标：提出复古未来题材下 2—3 个可开发的概念方向，供数值策划 A / 主美术 / 主程序 / UI 设计美术 A 各自评估可行性。

## 一、方向总述

本工作区专注 **复古未来（Retro-futurism）**：对"过去时代所想象的未来"的回收、消费与再创造。
立项应从知识库中可复用的美学-情感模块出发，而非泛泛的"科幻"。候选方向按《总论》[00](../doc/retro-futurism/00_总论_未来的考古学与全卷地图.md) 的三层时间模型与四元素框架归类。

## 二、候选方向

### 方向 A：磁带暖未来 —— 模拟接口的怀旧冒险

- 关键词：磁带未来主义、CRT 终端、暖色模拟、个人电脑黎明期。
- 参考卷：[14_磁带篇](../doc/retro-futurism/14_磁带篇_磁带未来主义_模拟接口的暖未来.md)、[17_蒸汽波篇](../doc/retro-futurism/17_蒸汽波篇_蒸汽波与合成波_时代错置的听觉乡愁.md)
- 玩法想象：在"一台老终端里的世界"中解谜/叙事，UI 即世界观的一部分（强项：UI 设计美术 A 舞台大）。
- 美术：低保真、扫描线、暖光。
- 风险：非 3D 重渲染，图形程序员 A 的发挥空间偏后处理与风格化。

### 方向 B：原子镀铬 —— 幸福原子时代的桌面乐园

- 关键词：原子朋克、镀铬郊区、按钮生活、太空竞赛乐观主义。
- 参考卷：[08_原子篇](../doc/retro-futurism/08_原子篇_原子朋克_幸福原子与镀铬郊区.md)、[06_机器篇](../doc/retro-futurism/06_机器篇_速度与钢骨_未来主义与装饰艺术的机器乌托邦.md)
- 玩法想象：建造/经营 1950s 想象未来中的家园；经济系统负担重（数值策划 A 舞台大）。
- 美术：亮铬、粉蓝、圆润流线。
- 风险：题材乐观底色与当代玩家的批判视角需要叙事平衡。

### 方向 C：太空时代 —— Googie 射线枪哥特

- 关键词：太空时代、Googie 建筑、射线枪、明日世界乐园。
- 参考卷：[09_太空篇](../doc/retro-futurism/09_太空篇_太空时代_Googie射线枪哥特与明日世界.md)
- 玩法想象：动作/冒险于"被取消的太空未来"废墟中；图形表现空间大（图形程序员 A 舞台大）。
- 美术：霓虹星云紫、镀铬流线、飞碟剪影。
- 风险：玩法同质化风险高，需要独特钩子。

## 三、初步推荐

**方向 A 作为首推**：差异化最强、UI/叙事协同深、工程量可控、题材与"复古未来"工作区定位咬合最紧。
方向 B、C 作为后续立项候选，保留在案。

## 四、待定问题（供各角色评审）

1. 目标平台（PC / 移动 / 网页）与目标时长？
2. 叙事与玩法的比重？
3. 商业化模式是否需要立项初期考虑？

## 五、协作请求

- 数值策划 A：评估方向 A/B 的数值承载量。
- 主美术：三个方向各给一段风格基调初判。
- 主程序：工程量与原型周期初判。
- UI 设计美术 A：方向 A 的 UI 舞台评估。
- 图形程序员 A：方向 A 与 C 的渲染/后处理实现难度初判。
