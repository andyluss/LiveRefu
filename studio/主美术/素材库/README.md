## 二、各方向要点与选图说明（美术视角）

### 方向 A · 磁带暖未来
- 视觉重点：**终端即器物**。DEC VT100、IBM 3279、Apple II 等真实机型是 70—80 年代"模拟接口的暖未来"的实物锚点；磁带机/便携唱机带来塑料米色与机械质感的怀旧温度。
- 可提取：终端屏幕发光配色（绿/琥珀）、键位与面板分件、CRT 体积感与屏占比、圆润外壳切角。
- 建议作为情绪板主色调与"屏幕 UI 即世界观"的参考主源。

### 方向 B · 原子镀铬
- 视觉重点：**1960s 乐观未来**。1939 纽约世博会 Futurama/Shell 明日之城是"幸福原子"时代的规划图景；Googie 加油站、50s 尾鳍车与太空火箭（Sputnik/Vostok/Agena）带来镀铬、流线、粉蓝粉红与太空竞赛的乐观基调。
- 可提取：镀铬高光材质、流线型轮廓、荧光粉蓝撞色、圆盘/卫星几何母题、火箭与发动机的工程感。
- 适合做"乐观、明亮、塑料+金属"的建造/经营场景参考。

### 方向 C · 太空时代
- 视觉重点：**Googie 与射线枪哥特**。西雅图太空针、Cinerama Dome、Googie 店面是"被取消的太空未来"的纪念碑；复古科幻封面（Amazing Stories、Planet/Exciting Comics）与射线枪、UFO 飞碟直接给出星云紫与霓虹对比的时代视觉语言。
- 可提取：伞形/尖塔屋顶剪影、霓虹招牌、深空紫蓝底色、轮廓光、飞碟剪影与复古科幻插画字型。
- 适合做"废墟感+明日世界乐园"混合氛围参考。

## 三、使用建议与边界（遵主美术混搭纪律）

1. 一次立项只确定一个主锚点，另两个目录仅作交叉参考，不混搭进同一场景；
2. 本批为**风格素材**，不是最终素材；项目沿用需再核原创性、许可与版权（见下方说明）；
3. 分辨率已按需缩至接近 960px（缩略图），适合画快速情绪板与方向初判；正式立项后应回源站取高清原图。
