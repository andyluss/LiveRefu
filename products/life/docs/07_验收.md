# 07 · 验收

> 版本：v2.0

## 自动

```bash
cd products/life
npm test
npm run check
```

- 共享 core 的 CRUD/校验/摘要；
- 五份 config 的字段/端口/accent/summary 空数据；
- 五份 config 每款至少两个 pack，模块 summary 14 点；
- 五个静态入口存在；
- 五个 app 可启动；
- pack 开关、模块 CRUD、关闭后 403。

## 手工

每款 app：

1. 首次打开有 seed/空态；
2. 新建/编辑/删除 core 记录；
3. 摘要数字变化；
4. 打开设置，开启两个扩展包；
5. 模块出现在导航；
6. 新建/编辑/删除模块记录；
7. 关闭 pack 后模块消失、API 403、数据保留；
8. 主题切换不影响数据；
9. 刷新后仍存在；
10. 手机宽度可用，无 console error。

