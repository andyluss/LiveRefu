# 07 · 验收

> 版本：v1.0

## 自动

```bash
cd products/life
npm test
npm run check
```

- 共享 core 的 CRUD/校验/摘要；
- 五份 config 的字段/端口/accent/summary 空数据；
- 五个静态入口存在；
- 五个 app 可启动。

## 手工

每款 app：

1. 首次打开有 seed/空态；
2. 新建一条记录；
3. 编辑；
4. 删除；
5. 摘要数字变化；
6. 刷新后仍在；
7. 手机宽度可用；
8. 无 console error。

## 独立分发

```bash
npm run bundle
cd dist/sleep/apps/sleep
node server.ts
```
