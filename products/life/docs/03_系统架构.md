# 03 · 系统架构

> 版本：v2.0 ｜ Node 24+，零第三方依赖。

```text
Browser (shared app.js)
  → GET /api/state
  → POST/PATCH/DELETE /api/entries
  → POST/PATCH/DELETE /api/modules/:moduleId
  → shared static /shared/*
Server (packages/core/server.ts)
  → config (app-specific)
  → validate
  → JSON store (data/store.json)
  → summary(config.summary)
```

## 共享核心

`createLifeApp(config)` 负责：

- HTTP server；
- 静态文件（app `web/` + `/shared/`）；
- `GET /api/state`：`{config, settings, entries, summary, modules}`；
- `GET /api/entries`；
- `POST /api/entries`；
- `PATCH /api/entries/:id`；
- `DELETE /api/entries/:id`；
- `GET /api/modules/:moduleId` 由 pack 开关控制；
- `PATCH /api/settings` 开关 pack；
- `GET /api/backup`；
- 校验 field（必需/数字/选项/日期）；
- 原子写 + `.bak`。

六款节律 app 只提供 config；路由/存储/校验不再各写一份。慢慢记保留自定义财务 server，但复用共享主题与静态资源布局。

## Store

```json
{ "version": 2, "settings": { "packs": {} }, "entries": [], "modules": {} }
```

- 每个 app 一个文件；
- 首次启动写 seed；
- 写前备份；
- 临时文件 + rename；
- v1 store 读取时自动迁移；`version` 留给未来。

## 静态资源

```text
/                apps/<id>/web/index.html
/shared/*        packages/web/*
```

- 只监听 `127.0.0.1`；
- 路径规范化，拒绝越界；
- 无 CORS、无远程资源、无遥测。

## 独立分发

共享包通过相对路径导入；`tools/bundle.ts` 把 app 与 packages 复制到 `dist/<app>/`。

```text
dist/<app>/
  apps/<app>/server.ts
  apps/<app>/config.ts
  apps/<app>/web/
  packages/core/
  packages/web/
```

启动：`node dist/<app>/apps/<app>/server.ts`。

## 未来统合

- 存储：JSON → SQLite/Postgres，保持 `/api/entries` 不变；
- 服务：每 app 独立 → 统一 gateway，config 不变；
- 前端：共享 app.js → React/Vue 壳，字段/summary 契约不变；
- 设计：`--life-*` → LRDS `product.life`。
