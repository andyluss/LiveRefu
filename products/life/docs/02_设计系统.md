# 02 · 设计系统

> 版本：v2.0 ｜ 共享 `packages/web/tokens.css` 与 `life.css`；语义映射 LRDS。

## 一、设计语言

**安静的生活记录工具**：

- 纸感底色、低饱和、细边框；
- 大标题用衬线，数字用等宽；
- 卡片是“纸片”，不是玻璃拟态；
- 每个 app 一个 accent，不改变骨架。

## 二、Token

```text
--life-bg / bg-2 / surface / raised
--life-text / muted / faint
--life-line / line-strong
--life-accent / on-accent / accent-soft
--life-danger / warning / success
--life-radius / shadow / font-*
```

映射：

| Life | LRDS 语义 |
| --- | --- |
| `--life-bg` | `sys.color.bg.base` |
| `--life-surface` | `sys.color.bg.surface` |
| `--life-text` | `sys.color.text.primary` |
| `--life-muted` | `sys.color.text.muted` |
| `--life-accent` | `sys.color.action.primary` |
| `--life-on-accent` | `sys.color.action.onAction` |
| `--life-danger` | `sys.color.feedback.danger` |
| `--life-warning` | `sys.color.feedback.warning` |
| `--life-success` | `sys.color.feedback.success` |

每个 app 只覆盖 `--life-accent` / `--life-on-accent`（配置里的 accent），不覆盖结构。

## 三、组件

共享 Web 只有一组：

- `life-header`：产品名 / 一句话 / 今日日期；
- `life-metric`：一个数字 + 标签 + 注释；
- `life-chart`：14 天柱状；
- `life-table`：记录列表；
- `life-modal`：新建/编辑；
- `life-empty`：空态；
- `life-toast`：反馈。

无按钮库、无图标库、无 CSS 框架。

## 四、排版

- 标题：衬线，clamp(30–48px)；
- 正文：14px，1.5；
- 元信息/表格：等宽 8–10px；
- 数字：等宽，右对齐；
- 所有可交互元素有 `:focus-visible`。

## 五、无障碍

- 正文对比度 ≥ 4.5；
- 表单 label 与输入关联；
- 状态不只靠颜色；
- 模态框 `dialog`，Esc 可关；
- 移动端 360px 可用。

## 六、与 LRDS 的关系

- Life 消费语义角色，不复制色阶；
- v2.0 用本地 `--life-*` / 共享生成层，验证后可按 `product.life` 提升进 `design/tokens/products/`；
- 六款 app 共享 token 是统合的最低成本方式。
