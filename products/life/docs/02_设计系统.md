# 02 · 设计系统

> 版本：v3.2 ｜ 默认浅/深色来自 LRDS `product.life`；`themes.generated.css` 由 LiveDSO 风格卡生成。

## 一、设计语言

**安静的生活记录工具**：

- 纸感底色、低饱和、细边框；
- 大标题用衬线，数字用等宽；
- 卡片是“纸片”，不是玻璃拟态；
- 每个 app 一个 accent，不改变骨架。

## 二、Token

```text
--life-bg / bg-2 / surface / raised
--life-text / muted / faint
--life-line / line-strong
--life-accent / on-accent / accent-soft
--life-focus
--life-danger / warning / success
--life-radius / shadow / font-*
```

映射：

| Life | LRDS 语义 |
| --- | --- |
| `--life-bg` | `product.life.color.bg` |
| `--life-surface` | `product.life.color.surface` |
| `--life-text` | `product.life.color.text` |
| `--life-muted` | `product.life.color.muted` |
| `--life-accent` | `product.life.color.accent` |
| `--life-on-accent` | `product.life.color.onAccent` |
| `--life-danger` | `product.life.color.danger` |
| `--life-warning` | `product.life.color.warning` |
| `--life-success` | `product.life.color.success` |
| `--life-focus` | `product.life.color.focus` |

深色默认对应 `product.life.dark.color.*`；`--life-*` 由 `tools/build-themes.ts` 生成，不手写。

每个 app 仍以 config 的 accent 覆盖 `--life-accent` / `--life-on-accent` 作为产品差异；默认基座来自 `product.life`，不覆盖结构。

## 三、组件

共享 Web 只有一组：

- `life-header`：产品名 / 一句话 / 今日日期；
- `life-metric`：一个数字 + 标签 + 注释；
- `life-chart`：14 天柱状；
- `life-table`：记录列表；
- `life-modal`：新建/编辑；
- `life-empty`：空态；
- `life-toast`：反馈。

无按钮库、无图标库、无 CSS 框架。

## 四、排版

- 标题：衬线，clamp(30–48px)；
- 正文：14px，1.5；
- 元信息/表格：等宽 8–10px；
- 数字：等宽，右对齐；
- 所有可交互元素有 `:focus-visible`。

## 五、无障碍

- 正文对比度 ≥ 4.5；
- 表单 label 与输入关联；
- 状态不只靠颜色；
- 模态框 `dialog`，Esc 可关；
- 移动端 360px 可用。

## 六、与 LRDS 的关系

- Life 消费语义角色，不复制色阶；
- v3.2 起默认浅/深色已提升为 LRDS `product.life`（`design/tokens/products/life.tokens.json`）；
- 14 个风格变体仍由 LiveDSO 风格卡覆盖 `--life-*`；
- 16 款 app 共享 token 是统合的最低成本方式。
