# 11 · 统合主页

> 版本：v1.0 ｜ 入口：`http://127.0.0.1:4200`

## 一、定位

一个**入口 + 状态聚合**，不是第六套数据层。跨应用节律已拆到独立页面 `/rhythm`：

- 16 款 app 仍各自独立启动、独立 `data/apps/<id>/store.json`；
- 主页只读取 `/api/health` 和 `/api/state`；
- 打开 app 用新标签，不复制数据到主页。

## 二、启动

```bash
cd products/life
npm run home       # 只开主页（应用离线显示）
npm run dev:all    # 主页 + 16 款 app
```

## 三、聚合约定

- 主页 `GET /api/apps` 返回 app 清单；
- 各 app API 返回 local CORS 头，主页才能跨端口读取；
- 首个摘要指标来自各 app 的 `summary.metrics[0]`；慢慢记无统一 summary 时显示“在线”；
- 主页主题只控制主页自身；各 app 主题仍按自身 origin 的 `life-style` 保存。

## 四、跨应用节律

独立页面 `http://127.0.0.1:4200/rhythm`：

- 应用多选过滤；
- 周期：近七天 / 近十天 / 近三十天 / 本周 / 本旬 / 本月 / 本朋 / 本季 / 本年；
- 以月为核心，默认本月；本旬按 1–10、11–20、21–月末；本朋两月一期、一年六期；本季从 3 月立春起算；
- 年视图按月聚合；本季、本朋、本月、本旬、本周、近 N 天均按日聚合；除本周、本年外，图表叠加周界虚线；
- 纵轴按当前数据自动选取 1/2/5/10 级刻度，最多约 6 条网格线。

主页只保留入口链接。

## 五、边界

- 不代写数据、不代登录、不跨 app 同步；
- 不做远程请求；
- 不替代各 app 的备份。
