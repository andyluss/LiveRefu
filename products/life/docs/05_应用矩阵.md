# 05 · 应用矩阵

> 版本：v1.0 ｜ 五款 app 的领域字段与摘要。

## 好好睡 Sleepwell

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| date | date | 醒来日期 |
| sleepAt | time | 入睡 |
| wakeAt | time | 醒来 |
| quality | rating 1–5 | 主观质量 |
| caffeine | number | 咖啡因杯数 |
| screenMinutes | number | 睡前屏幕分钟 |
| note | textarea | 备注 |

摘要：平均睡眠时长、平均质量、连续记录天数；14 天睡眠时长。

## 好好吃 Mealtime

| 字段 | 类型 |
| --- | --- |
| date | date |
| meal | select 早餐/午餐/晚餐/加餐 |
| food | text |
| vegetables | select 有/没有 |
| waterMl | number |
| rating | rating 1–5 |
| note | textarea |

摘要：本周记录餐数、有蔬菜天数、平均饮水；14 天饮水。

## 慢慢走 DailyWalk

| 字段 | 类型 |
| --- | --- |
| date | date |
| activity | select 步行/跑步/力量/拉伸/骑行 |
| minutes | number |
| intensity | select 轻/中/高 |
| mood | rating 1–5 |
| note | textarea |

摘要：本周活动分钟、活动天数、连续天数；14 天分钟。

## 好好读 ReadingLog

| 字段 | 类型 |
| --- | --- |
| date | date |
| book | text |
| pages | number |
| minutes | number |
| quote | textarea |
| note | textarea |

摘要：本月页数、本月阅读分钟、连续天数；14 天页数。

## 好好住 HomeBoard

| 字段 | 类型 |
| --- | --- |
| date | date |
| task | text |
| area | select 厨房/客厅/卧室/浴室/阳台/全屋 |
| minutes | number |
| dueDate | date |
| done | select 完成/待办 |
| note | textarea |

摘要：本周完成数、待办数、本周家务分钟；14 天完成数。

## 共同边界

- 每 app 只解决一个生活节律；
- 不做社交、排行榜、打卡压力；
- 不做跨 app 自动联动（v1.0）；
- 每个 app 可单独使用，无需安装其它 app。
