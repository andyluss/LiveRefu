## 慢慢记 Manmanji

| 字段 | 类型 |
| --- | --- |
| date | date |
| type | income/expense/transfer |
| amount | cents |
| accountId | id |
| categoryId / toAccountId | id |

摘要：净资产、本月收入/支出/结余、预算进度、发票待收；主题与 Life 共享。

> 慢慢记是自定义财务 app，不复用通用 AppConfig 表单，但复用 theme/token、主题生成、Life 工程规范与打包。

## 共同边界

- 每 app 只解决一个生活节律；
- 不做社交、排行榜、打卡压力；
- 不做跨 app 自动联动（v2.0）；
- 每个 app 可单独使用，无需安装其它 app。
