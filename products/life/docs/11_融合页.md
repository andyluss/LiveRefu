# 11 · 融合页

> 版本：v2.0 ｜ 入口：`http://127.0.0.1:4200`

## 一、定位

融合页是 Life 的入口与空间：

- 16 款应用仍各自独立启动、独立 `data/apps/<id>/store.json`；
- 融合页只做入口、状态和布局，不复制应用数据；
- 跨应用节律拆到独立页 `/rhythm`。

## 二、空间布置

默认是 12 列自由空间，每张卡片可拖动、缩放、持久化；格子为正方形，卡片最大 6×6。详细模型、交互、响应式与验收见 [`13_融合页空间布局.md`](13_融合页空间布局.md)。

## 三、数据

- 应用状态：`/api/state`；
- 全部导入/导出：`/api/export`、`/api/import`；
- 布局：`localStorage['life-fusion-layout-v1']`，不进入业务数据。

## 四、启动

```bash
cd products/life
npm run home
npm run dev:all
```

## 五、边界

- 不代写数据、不代登录、不跨应用同步；
- 不做远程请求；
- 不替代各应用自己的导出/备份。
