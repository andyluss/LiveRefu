# 04 · 数据模型

> 版本：v2.0 ｜ entries（core）+ modules（pack），字段由 CollectionConfig 定义。

## Store

```json
{
  "version": 2,
  "settings": { "packs": { "sleep-environment": true } },
  "entries": [],
  "modules": { "environment": [] }
}
```

## Entry

```json
{
  "id": "ent_xxx",
  "date": "2026-10-29",
  "createdAt": "2026-10-29T08:00:00.000Z",
  "updatedAt": "2026-10-29T08:00:00.000Z",
  "data": {
    "sleepAt": "23:30",
    "wakeAt": "07:10",
    "quality": 4,
    "note": "睡前没有看屏幕"
  }
}
```

- `date` 是列表分组/图表的主日期；
- 领域字段全在 `data`，由 config fields 定义；
- 不把 summary 写进 store；
- 模块在 `modules.<moduleId>`；开关在 `settings.packs`；
- 删除是硬删除；v2.0 不做审计。

## Field

```ts
{
  key, label, type,
  required?, options?, min?, max?, step?,
  placeholder?, default?
}
```

## Summary 契约

```ts
{
  metrics: [{ label, value, note? }],
  chart: { label, values: number[] }, // 最近 14 天
  streak?: number,
  hint?: string
}
```

- summary 必须能处理空数组；
- 图表只画一个指标，避免仪表盘化；
- 不在服务端写 UI 文案以外的结构。

## 迁移

v1.x 只允许**新增可选字段**。破坏性变化：

1. 提升 `version`；
2. 写迁移脚本；
3. suite major；
4. 保留旧数据备份。
