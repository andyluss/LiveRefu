# 13 · 融合页空间布局

> 版本：v1.0 ｜ 日期：2026-10-29 ｜ 状态：设计先于实现

## 一、为什么是空间

人的生活不是一条列表。地点、时间、人物、物件之间有位置关系；人天生擅长用“在哪里、离什么近、占多大”记住东西。

融合页不再把所有应用排成统一卡片网格，而是给用户一块**可布置的空间**：

- 应用是空间里的“物件”，不是列表项；
- 位置、大小、邻近关系由用户决定；
- 默认布局只是起点，不是唯一答案；
- 布局是本地偏好，不进入应用业务数据。

## 二、空间模型

```text
12 列 × N 行
每格为正方形，桌面约 72px 见方
卡片占 x / y / w / h 个格
```

- 12 列在桌面端保证可读性，也允许 2/3/4/5/6 列宽；
- 卡片最小 1×1，最大 6×6；
- 行数按最底部卡片自动扩展；
- 卡片占满格子，卡片之间无间距；用卡片内侧 1px 边框区分相邻格子；
- 空格子以极淡格线显示。

## 三、交互

### 布置

- 每张卡片左上角有拖动柄；
- 拖动时显示半透明目标格；
- 目标格与其它卡片重叠时，目标框变红，松手不落位；
- 右下角有缩放柄，拖动改变 w/h；
- 键盘：拖动柄聚焦后方向键移动一格，Shift + 方向键缩放；
- “重置布局”恢复默认。

### 记忆

- 布局写入 `localStorage['life-fusion-layout-v1']`；
- 新应用加入时自动补默认位置，不破坏已有布局；
- 布局不进入 store、不参与跨设备同步。

### 移动端

- 小于 720px 时退化为单列流式卡片；
- 拖动/缩放柄隐藏；
- 布局偏好仍保留，回到桌面恢复。

## 四、卡片内容分级

| 尺寸 | 形状 | 显示内容 | 说明 |
| --- | --- | --- | --- |
| 1×1 | 单格 | 仅 Logo | 最小空间；点击 Logo 打开应用；拖动/缩放手柄悬停出现 |
| 1×2 / 1×3 | 竖条 | Logo + 竖排名称 | 不显示描述、指标、状态文字 |
| 2×1 | 横条 | Logo + 名称 + 状态 | 不显示描述、指标 |
| 2×2 | 小方块 | Logo + 名称 + 状态 | 信息入口，不显示描述/指标 |
| 2×3 / 3×2 | 小竖块/小横块 | Logo + 名称 + 状态 + 一个指标 | 不显示描述 |
| 2×4 | 窄高块 | Logo + 名称 + 状态 + 一个指标 | 不显示描述；竖向留白更多 |
| 4×2 | 宽矮块 | Logo + 名称 + 状态 + 一个指标 | 不显示描述与端口 |
| 3×3 | 中方块 | Logo + 名称 + 状态 + 描述 + 指标 | 标准信息密度 |
| 3×4 / 4×3 | 中大块 | Logo + 名称 + 状态 + 描述 + 指标 + 端口 | 完整卡片 |
| 4×4–6×6 | 大块 | 完整内容 | 空间更大，但信息语义不变 |

## 五、视觉

- 空间底色使用 `--life-bg`，格子线用 `--life-line` 低透明度；
- 卡片使用 `--life-surface`，在线状态以 accent 边框/点提示；
- 离线卡片降低不透明度、灰度、去链接、`pointer-events:none`；
- 大卡片显示摘要指标，小卡片只显示名称、Logo、状态和入口；
- 卡片尺寸变化只影响内容密度，不改变信息语义。

## 六、与 LRDS 的关系

未来提升为 LRDS `product.life` 的空间子层：

```text
product.life.layout.grid.columns = 12
product.life.layout.cell = square（随宽度流体，桌面约 72px）
product.life.layout.gap = 0
product.life.layout.card.border = 1px（inset）
product.life.layout.card.min = 1×1
product.life.layout.card.max = 6×6
```

当前阶段先以 Life 内部常量实现；等布局稳定、跨产品复用时，再进入 `design/tokens` 与 LRDS 组件契约。

## 七、边界

- 不做自由画布/任意像素拖拽，避免不可对齐；
- 不做卡片重叠，避免遮挡；
- 不做多人协作布局；
- 不把布局写进应用数据或备份；
- 不强制用户布置，默认布局开箱可用。

## 八、验收

1. 拖动卡片到空格，位置持久化；
2. 拖动到占用格，松手回退；
3. 缩放卡片，内容密度随尺寸变化；
4. 新应用自动补位；
5. 重置恢复默认；
6. 刷新后布局保持；
7. 720px 以下单列，可正常打开应用；
8. 离线卡片不可点击，但仍可布置；
9. 键盘可移动/缩放；
10. 无 console error。
