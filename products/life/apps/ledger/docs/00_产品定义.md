# 00 · 产品定义

> 版本：v1.3 ｜ 日期：2026-10-28

## 1. 问题

个人和小工作室的财务工具通常走两个极端：

- 极简记账：只能记流水，没有账户、预算、报表与开票；
- 专业财务：需要会计科目、云端、订阅、团队权限，个人用不起来。

自由职业者还多一层断裂：**记账软件不开发票，开票工具不记账**。

## 2. 用户

| 用户 | 任务 | 为什么用 |
| --- | --- | --- |
| 独立开发者 / 自由职业者 | 记流水、看结余、开票、追款 | 一个本地工具闭环 |
| 小工作室 | 多账户、预算、月度报表 | 不上云也能对账 |
| 对隐私敏感的个人 | 数据只在本机 | 无账号、无同步、可备份 |

## 3. 价值主张

> 先记清楚，再开好票；数据留在自己电脑里。

## 4. v1.0–v1.1 范围

**核心**：

- 现金 / 银行 / 信用账户；
- 收入 / 支出 / 转账；
- 分类、标签、备注、过滤；
- 月度预算；
- 月度报表、分类占比；
- CSV / JSON 导出；
- 本地 JSON 持久化；
- 7 个风格族、14 个 light/dark 变体；风格卡来自 LiveDSO 的 7 组风格卡。

**扩展包**：

- `pack.freelance`：客户、发票、行项目、税、状态、收款入账、逾期视图。

**不做**：

- 云同步、账号、团队权限、订阅；
- 银行直连、自动抓取；
- 多币种汇率换算；
- 税务申报/会计科目；
- 移动原生 App。

## 5. 成功标准

- 5 分钟内完成第一次记账；
- 30 秒内看清本月结余与最大支出分类；
- 开一张发票并收款，流水自动出现；
- 断网可用；
- `store.json` 可复制到另一台机器继续用。

## 6. 非目标

- 不做“AI 财务顾问”；
- 不替用户做税务判断；
- 不把复杂藏在默认值里。
