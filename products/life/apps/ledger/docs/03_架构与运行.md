# 03 · 架构与运行

> 版本：v1.4 ｜ Node 24+，零第三方依赖。

```text
web/ (单页)
  → fetch /api/*
server/index.ts (HTTP + 路由 + 校验)
  → server/domain.ts (纯计算)
  → server/store.ts (JSON 读写/备份)
  → data/store.json
```

## 请求

- 只监听 `127.0.0.1`，默认端口 `4206`；
- JSON body 上限 1 MB；
- 所有写操作返回最新 `state`；
- 错误统一 `{ error: "中文说明" }` + 4xx/5xx。

## 存储

- 首次启动无 `store.json` 时写入 seed；
- 写入前复制 `store.json.bak`；
- 先写临时文件再 rename，避免半写；
- 不做数据库迁移；`version` 字段留给 v1.x。

## 安全边界

- 无账号/无远程；
- 静态文件路径规范化，拒绝越界；
- 不执行 store 中的代码；
- 不自动提交 Git；
- 不发送遥测。

## 运行

```bash
npm run dev          # 127.0.0.1:4206
PORT=4191 npm run dev
DATA_FILE=/path/store.json npm run dev
```

## 测试

- `server/domain.ts` 纯函数：余额、月度汇总、预算、发票；
- `server/store.ts`：seed/读写/原子备份；
- API 冒烟：用临时 store 启动服务，覆盖核心增删与收款。
