# 05 · 设计系统接入

> 版本：v1.3 ｜ 产品皮肤在 `web/tokens.css`；主题由 Life 共享层从 LiveDSO 风格卡生成到 `../../packages/web/themes.generated.css`。

## 原则

- 产品消费语义角色，不直接消费 `ref` 原始色阶；
- 产品自己的 `--mm-*` 变量是**产品层 token**，等价于 LRDS 的 `product.manmanji.*`；
- 输入/按钮/焦点/危险色必须有明确语义；
- 暗色不是反色，而是独立的一组 product token。

## 映射

| 产品变量 | LRDS 语义 | 用途 |
| --- | --- | --- |
| `--mm-bg` | `sys.color.bg.base` | 页面底 |
| `--mm-surface` | `sys.color.bg.surface` | 卡片 |
| `--mm-raised` | `sys.color.bg.raise` | 浮层/按钮 |
| `--mm-text` | `sys.color.text.primary` | 正文 |
| `--mm-muted` | `sys.color.text.muted` | 次要文字 |
| `--mm-action` | `sys.color.action.primary` | 主行动 |
| `--mm-on-action` | `sys.color.action.onAction` | 主行动前景 |
| `--mm-focus` | `sys.color.focus.ring` | 焦点 |
| `--mm-danger` | `sys.color.feedback.danger` | 删除/超支 |
| `--mm-warning` | `sys.color.feedback.warning` | 预警 |
| `--mm-success` | `sys.color.feedback.success` | 正常/已收 |

## 当前状态

- 基础默认仍由本地 `web/tokens.css` 的 paper/night 变体提供；
- **v1.1 开始吃 LiveDSO 狗粮**：`products/life/tools/build-themes.ts` 读取 `design/projects/livedso/vaults/<id>/style-cards/<card>.json`，解析角色并生成：
  - `packages/web/themes.generated.css`
  - `packages/web/themes.generated.js`（主题列表）
- 当前 7 个风格族（14 个 light/dark 变体）：paper、retro、cassette、atompunk、material、tailwind、carbon；
- 不手写这些主题的 hex；改 LiveDSO 风格卡后运行 `cd products/life && npm run themes`；
- `npm run themes:check` 校验生成物是否最新；
- 产品仍未加入 `design/tokens/products/`：先以 LiveDSO **风格卡消费者**验证，稳定后再提升为正式 product token。

## 无障碍

- 正文对比度 ≥ 4.5；
- 焦点环 2px，键盘可达；
- 状态不只靠颜色：发票状态有文字，预算超支有“超支”标签。
