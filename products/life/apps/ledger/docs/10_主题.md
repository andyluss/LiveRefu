# 10 · 主题、外观与 LiveDSO 狗粮

> 版本：v1.3 ｜ 风格卡与浅/深外观是两个独立维度。

## 一、两个维度

| 维度 | 控制 | 取值 | 持久化 |
| --- | --- | --- | --- |
| 风格 | 顶栏/设置里的“风格主题” | 7 个风格族 | 服务端 `settings.theme` + 本地 `life-style`（兼容旧 `manmanji-family`） |
| 外观 | “系统 / 浅色 / 深色”三段控件 | `system` / `light` / `dark` | `localStorage['lrds-theme']` |

外观不循环切换风格；风格也不决定浅/深。每个风格族固定有 light/dark 两个变体：

```text
paper     paper / night
retro     retro-paper / retro-crt
cassette  cassette-daylight / cassette-amber
atompunk  atompunk-chrome / atompunk-alert
material  material-3 / material-3-dark
tailwind  tailwind-paper / tailwind
carbon    carbon / carbon-night
```

## 二、DOM 约定

```html
<html data-theme="system|light|dark" data-style="retro-paper">
```

- `data-theme` 只表示外观（R-001 的 `lrds-theme`）；
- `data-style` 只表示当前风格变体；
- 不把风格写进 `data-theme`，避免“外观”和“品牌皮肤”再次混在一起。

## 三、LiveDSO 狗粮

`products/life/tools/build-themes.ts` 读取：

```text
design/projects/livedso/vaults/<id>/style-cards/<card>.json
```

解析角色，生成：

```text
packages/web/themes.generated.css   每个变体的 --life-* / --mm-* 覆盖
packages/web/themes.generated.js    风格族列表
```

命令：

```bash
cd products/life
npm run themes
npm run themes:check
npm run themes:list
```

- 不手写这些变体的 hex；
- LiveDSO 风格卡变更后必须重新生成；
- `npm run check` 会跑生成物校验。

## 四、R-001 对齐

- 默认 `system`；
- 顺序固定：系统 / 浅色 / 深色；
- `system` 监听 `prefers-color-scheme` 实时切换；
- `color-scheme` 写入根元素；
- 首次渲染前由 `<head>` 内联脚本设置 `data-theme` / `data-style`，避免闪烁；
- 对比度与焦点按每个变体验收。

## 五、边界

- 风格是视觉皮肤，不改变记账/发票数据；
- 暗色不是反色，每个风格族有独立 dark 变体；
- 产品未把 `manmanji` 提升为 LRDS `product` 前，只消费现有风格卡。
