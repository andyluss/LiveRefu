# 02 · 数据模型

> 版本：v1.3 ｜ 金额统一为 **integer cents**，避免浮点误差。

## Store

```json
{
  "version": 1,
  "settings": {
    "currency": "CNY",
    "theme": "paper",
    "packs": { "freelance": true }
  },
  "accounts": [],
  "categories": [],
  "transactions": [],
  "budgets": [],
  "recurring": [],
  "clients": [],
  "invoices": []
}
```

## Account

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 稳定 id |
| `name` | string | 显示名 |
| `type` | `cash` / `bank` / `credit` | 账户类型 |
| `opening` | cents | 期初余额 |
| `color` | string | 展示色 |
| `createdAt` | ISO | 创建时间 |

## Transaction

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | |
| `date` | `YYYY-MM-DD` | |
| `type` | `income` / `expense` / `transfer` | |
| `amount` | cents > 0 | |
| `accountId` | string | 转出账户 |
| `toAccountId` | string? | 仅 transfer |
| `categoryId` | string? | transfer 为空 |
| `note` | string | |
| `tags` | string[] | |
| `createdAt` | ISO | |

## Budget

`{ id, month: "YYYY-MM", categoryId, amount }`；同月同分类唯一。

## Client

`{ id, name, company, email, note, createdAt }`。

## Invoice

```json
{
  "id": "inv_x",
  "number": "INV-2026-001",
  "clientId": "cli_x",
  "issueDate": "2026-10-28",
  "dueDate": "2026-11-11",
  "status": "draft | sent | paid | void",
  "items": [{ "description": "设计服务", "qty": 1, "unitPrice": 120000 }],
  "taxRate": 0.06,
  "note": "",
  "depositAccountId": "acc_bank",
  "paidAt": null,
  "transactionId": null,
  "createdAt": ""
}
```

计算：

```text
subtotal = Σ(qty × unitPrice)
tax      = round(subtotal × taxRate)
total    = subtotal + tax
```

## Recurring

v1.0 预留字段，未在 UI 暴露；v1.1 做“每月自动生成流水”。

## 不变量

- `amount` 必须正整数；
- 转账的 `accountId ≠ toAccountId`；
- 已 paid 发票不可再次收款；
- 删除账户/分类前必须没有引用（v1.0 API 会拒绝）；
- 所有派生值在读取时计算，不写入 store。
