# 02 · 数据模型

> 版本：v2.0 ｜ 共享 store：`{version, settings, entries, modules}`

## Core entry

```json
{ "id": "ent_x", "date": "YYYY-MM-DD", "createdAt": "...", "updatedAt": "...", "data": { ... } }
```

字段：日期、书、页数、分钟、摘录、想法。

## Pack modules

- `read-library` → `modules.books`；开关在 `settings.packs.read-library`。
- `read-quotes` → `modules.quotes`；开关在 `settings.packs.read-quotes`。

## 不变量

- 金额/数值类字段用 number；日期 `YYYY-MM-DD`；
- 删除是硬删除；不做软删除/审计；
- 关闭 pack 不删除数据。
