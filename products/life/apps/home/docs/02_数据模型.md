# 02 · 数据模型

> 版本：v2.0 ｜ 共享 store：`{version, settings, entries, modules}`

## Core entry

```json
{ "id": "ent_x", "date": "YYYY-MM-DD", "createdAt": "...", "updatedAt": "...", "data": { ... } }
```

字段：日期、任务、区域、耗时、下次到期、状态、备注。

## Pack modules

- `home-inventory` → `modules.items`；开关在 `settings.packs.home-inventory`。
- `home-maintenance` → `modules.maintenance`；开关在 `settings.packs.home-maintenance`。

## 不变量

- 金额/数值类字段用 number；日期 `YYYY-MM-DD`；
- 删除是硬删除；不做软删除/审计；
- 关闭 pack 不删除数据。
