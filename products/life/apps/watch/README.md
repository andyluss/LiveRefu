# 好好看 · Watchlog

> 端口 4210 ｜ 电影、剧集、片单、影院、进度

```bash
cd products/life/apps/watch
npm start
```

Core：观看日期、片名、类型、评分、平台、观后感。
Packs：`watch-watchlist` 片单、`watch-cinema` 影院、`watch-series` 剧集进度。
