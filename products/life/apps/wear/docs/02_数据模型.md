# 02 · 数据模型

> 版本：v1.0 ｜ 共享 store：`{version, settings, entries, modules}`

## Core entry

日期、outfit、weather、comfort、note。

## Pack modules

- `wear-closet` → `modules.closet`；开关 `settings.packs.wear-closet`。
- `wear-laundry` → `modules.laundry`；开关 `settings.packs.wear-laundry`。
- `wear-wishlist` → `modules.wishlist`；开关 `settings.packs.wear-wishlist`。

金额 `price` 用元（number）；日期 `YYYY-MM-DD`。
