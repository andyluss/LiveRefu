# 好好穿 · Wearwell

> 端口 4207 ｜ 穿搭、衣橱、洗衣、愿望清单

```bash
cd products/life/apps/wear
npm start
```

核心记录：日期、穿了什么、天气、舒适度、备注。  
扩展包：

- `wear-closet`：衣橱；
- `wear-laundry`：洗衣批次；
- `wear-wishlist`：愿望清单。
