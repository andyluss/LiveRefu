# 好好睡 · Sleepwell

> 端口 4201 ｜ 睡眠记录

```bash
cd products/life/apps/sleep
npm start
```

记录：醒来日期、入睡/醒来时间、质量、咖啡因、睡前屏幕、备注。  
摘要：近 14 天平均睡眠、平均质量、连续记录；14 天睡眠时长。

数据：`data/store.json`（首次自动 seed）。
