# 02 · 数据模型

> 版本：v2.0 ｜ 共享 store：`{version, settings, entries, modules}`

## Core entry

```json
{ "id": "ent_x", "date": "YYYY-MM-DD", "createdAt": "...", "updatedAt": "...", "data": { ... } }
```

字段：醒来日期、入睡/醒来时间、质量、咖啡因、屏幕分钟、备注。

## Pack modules

- `sleep-environment` → `modules.environment`；开关在 `settings.packs.sleep-environment`。
- `sleep-routine` → `modules.routine`；开关在 `settings.packs.sleep-routine`。

## 不变量

- 金额/数值类字段用 number；日期 `YYYY-MM-DD`；
- 删除是硬删除；不做软删除/审计；
- 关闭 pack 不删除数据。
