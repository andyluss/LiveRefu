# 06 · 质量与验收

> 版本：v1.1 ｜ 目标：一个人能在本地每天用，不丢数据，算得对。

## 自动检查

```bash
npm test
npm run check
```

覆盖（当前 8 项）：

- 账户余额（含转账、信用负余额）；
- 月度收入/支出/结余；
- 预算按分类聚合；
- 发票 subtotal/tax/total；
- 已收款幂等；
- store 原子写入/备份；
- API 核心 CRUD 冒烟；
- 主题生成物/主题列表。

## 手工验收

1. 新建现金账户，记一笔支出，余额减少；
2. 银行 → 现金转账，总额不变；
3. 设本月餐饮预算，记一笔餐饮，进度增加；
4. 总览看到最近流水与预算；
5. 开票 → sent → paid，流水出现“自由职业收入”；
6. 关闭发票包，导航/接口不可用，数据仍在；
7. 导出 CSV / JSON，重新导入可读（JSON）；
8. 刷新/重启，数据仍在。
