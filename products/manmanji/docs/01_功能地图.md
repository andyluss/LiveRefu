# 01 · 功能地图

> 版本：v1.2 ｜ 所有功能均在本地可用；标注“包”的功能需要 `pack.freelance`。

## 总览

- 净资产 = 所有账户余额之和（信用账户余额为负）；
- 本月收入 / 支出 / 结余；
- 预算使用率最高的 4 个分类；
- 最近 8 条流水；
- 发票待收总额与逾期数（包）。

## 流水

- 新增收入/支出/转账；
- 删除流水（不提供静默改写；删除即重新计算）；
- 按月、类型、账户、分类、关键词过滤；
- 转账不计入收入/支出，只改变账户余额。

## 账户

- 类型：现金 / 银行 / 信用；
- 期初余额；
- 当前余额 = 期初 + 收入 − 支出 + 转入 − 转出；
- 归档（v1.0 只做删除，归档留到 v1.1）。

## 分类

- 收入类 / 支出类；
- 颜色用于图表；
- 系统预置常用分类；
- v1.0 不在 UI 里新增分类，避免分类膨胀；API 已支持。

## 预算

- 按 `YYYY-MM` + 支出分类设置；
- 实际支出从流水聚合；
- 进度 > 100% 显示超支；
- 没有预算的分类不显示。

## 报表

- 近 6 个月收入/支出；
- 本月分类占比；
- CSV 导出（流水）；
- JSON 备份（完整数据）。

## 发票（包）

- 客户：名称、公司、邮箱、备注；
- 发票：编号、客户、开票日、到期日、行项目、税率、备注、收款账户；
- 状态：`draft → sent → paid`，可 `void`；
- 标记 paid 时生成一条收入流水（分类“自由职业收入”）；
- 待收/逾期从 `sent` 且到期日 < 今天计算；
- 已收款发票不可重复入账。

## 设置

- 扩展包开关；
- 主题：纸感 / 夜间；
- 货币显示（v1.0 仅 CNY）；
- 数据重置。
