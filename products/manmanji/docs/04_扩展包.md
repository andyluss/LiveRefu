# 04 · 扩展包

> v1.0 只实现一个包：`pack.freelance`。它的存在是为了验证“核心 + 扩展”的架构，而不是堆功能。

## 契约

```text
core            账户 / 流水 / 分类 / 预算 / 报表
pack.freelance  客户 / 发票 / 收款 / 逾期
```

- `settings.packs.freelance` 是唯一开关；
- 关闭时：导航隐藏、API 返回 403、数据保留不删除；
- 重新开启：原客户/发票恢复可见；
- 收款：`POST /api/invoices/:id/pay`，幂等，生成一条收入流水；
- 备份：包数据在同一个 store，无需单独导出。

## 为什么发票属于扩展包

- 不是每个记账用户都需要开票；
- 开票依赖客户、税率、收款账户，属于另一条工作流；
- 核心只承诺“记清楚”，扩展承诺“交付/收款”。

## 未来包（不在 v1.0）

- `pack.recurring`：订阅/房租自动流水；
- `pack.project`：项目成本/工时；
- `pack.tax`：税务估算（必须明确“不是申报”）。
