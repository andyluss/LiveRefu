# 07 · 决策记录

> 版本：v1.0 ｜ 记录会影响后续演进的取舍。

| # | 决策 | 结论 | 理由 |
| --- | --- | --- | --- |
| M1 | 形态 | 本地 Node 服务 + 无构建单页 | 零依赖、可审计、离线 |
| M2 | 存储 | 单个 JSON + `.bak` | 易备份、可读、够个人用 |
| M3 | 金额 | integer cents | 避免浮点误差 |
| M4 | 账户 | 期初 + 流水派生余额 | 不改写历史余额 |
| M5 | 转账 | 一条 transfer，两个账户 | 不产生虚假收入/支出 |
| M6 | 扩展包 | 真实 API/导航开关 | 不做营销式“假开关” |
| M7 | 发票收款 | 生成收入流水 | 开票与记账闭环 |
| M8 | 删除 | 直接删除流水，派生重算 | v1.0 不做软删除/审计 |
| M9 | 多币种 | 不做 | 汇率与税务会让 v1 失焦 |
| M10 | UI 设计 | 产品自有 `--mm-*`，映射 LRDS 语义 | 验证后再迁入设计系统 |
| M11 | 分类新增 | v1.0 只预置，API 可扩展 | 避免空产品先堆设置 |
| M12 | 账号/云 | 不做 | 本地优先是产品承诺 |
