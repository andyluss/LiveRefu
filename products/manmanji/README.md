# 慢慢记 · Manmanji

> **版本**：1.2.0 ｜ **状态**：v1.1 可运行产品 ｜ **日期**：2026-10-28
> **一句话**：一款本地优先、通用记账为主、可插拔扩展包的轻量财务工作台。
> **首个扩展包**：自由职业者发票管理（客户、发票、收款、逾期）。
> **原则**：数据留在本机；不接云、不登录、不追踪；所有功能离线可用。

## 一、它是什么

慢慢记不是“极简记账 Demo”，而是一个可以每天用的个人/小工作室财务台：

- 多账户：现金、银行卡、信用卡；
- 收入 / 支出 / 转账；
- 分类、标签、备注、搜索、按月过滤；
- 月度预算与实际支出；
- 月度报表、分类占比、账户余额；
- CSV 导出、完整 JSON 备份；
- 可选扩展包：自由职业发票（客户 / 发票 / 收款）；
- 本地服务，浏览器访问；数据写在一个可备份的 JSON 文件里。

## 二、5 分钟跑起来

要求 **Node 24+**，无第三方依赖。

```bash
cd products/manmanji
npm run dev
# 打开 http://127.0.0.1:4190
```

首次启动会生成 `data/store.json` 并写入示例数据；也可以删除它重新开始。

```bash
npm test          # 领域与 API 测试
npm run reset     # 清空本地数据
```

## 三、功能地图

| 模块 | 能力 |
| --- | --- |
| 总览 | 净资产、本月收入/支出/结余、预算、最近流水、发票待收 |
| 流水 | 新增/删除、类型/账户/分类/月份/关键词过滤 |
| 账户 | 现金/银行/信用账户、期初余额、当前余额 |

| 报表 | 近 6 个月收支、分类占比、CSV 导出、JSON 备份 |
| 发票包 | 客户、发票、行项目、税、状态、收款入账 |
| 设置 | 扩展包开关、7 个风格族 × 浅/深变体、系统/浅/深外观、货币、数据重置 |

## 四、扩展包模型

扩展包不是营销页，而是真实的**能力开关**：

```text
core          账户 / 流水 / 分类 / 预算 / 报表
pack.freelance 客户 / 发票 / 收款 / 逾期
```

- 关闭后导航与 API 都不可用；
- 开启后发票收款会生成一条真实收入流水；
- 扩展包数据与核心数据在同一个 `store.json` 中，备份即完整。

详见 [`docs/04_扩展包.md`](docs/04_扩展包.md)。

## 五、数据与安全

```text
data/store.json     唯一事实来源（运行时生成）
data/store.json.bak 写入前备份
```

- 只监听 `127.0.0.1`；
- 无账号、无云同步、无遥测；
- 写操作只改本地 JSON；
- 备份/导出由用户主动触发；
- 金额在内部统一用**分**存储，避免浮点误差。
