# 03 · 验收

## 命令

```bash
cd products/calculator
npm test
npm run check
node tools/build-theme.js --check
```

## 已覆盖

- 初始状态、数字输入、15 位上限；
- 四则、连续运算、重复等号、运算符替换；
- 浮点格式化；
- `±`、百分比、开方 / 平方 / 倒数；
- 错误语义与恢复；
- 纸带记录、取回、AC 保留纸带、50 条上限、坏数据丢弃；
- `load` 内存取回；
- 3 套皮肤对比度与 token 生成物对账。

## 手动验收

1. 桌面键盘：`2 + 3 Enter` → `5`；
2. `5 + ± 3 Enter` → `2`；
3. `200 + 10 % Enter` → `220`；
4. `5 ÷ 0 Enter` → Error，按数字恢复；
5. 纸带点击取回；
6. 切换 3 套皮肤；
7. 断网刷新仍可打开；
8. 手机 200% 字号不裁切（待真机）；
9. 屏幕阅读器读出结果与错误（待真机）。
