# 手边计算器 · TODO / 产品路线

> 目标：**做一款真正最酷、也真正卖得动的复古未来计算器。**
> 不是“功能最多的计算器”，而是**一眼记得住、每天愿意用、愿意为设计付一次钱**的计算器。
> 当前：v0.1.0 · Web/PWA · 3 套皮肤 · 20 项核心测试。
> 最后更新：2026-11-13

## 一、北极星

```text
一个像物件、而不是像网页的计算器。
按下去有回应，纸带像从机器里吐出来，
离线、无账号、无追踪；买一次，长期用。
```

三个判断标准：

1. **有用**：打开 1 秒内能算，不比系统计算器慢。
2. **有物性**：按键、纸带、材质、声音、触感让人相信它是一台“机器”。
3. **可分享**：算完能留下一个好看的纸带/结果卡，而不只是一个数字。

## 二、发布与商业化

### 推荐模式

| 项 | 建议 | 理由 |
| --- | --- | --- |
| Web/PWA | **免费 Demo**（Archive + Console） | 降低尝试门槛；可安装、离线 |
| iOS / Android | **一次性买断 $4.99 首发 / $6.99 常规** | 工具类用户不接受订阅；买断符合“物件”定位 |
| Era Pack | 后续 $1.99/包，纯外观 | 只卖设计，不卖功能/数值；不做抽卡 |
| 订阅 | **不做** | 计算器没有持续服务成本，订阅会伤害信任 |
| 广告/追踪 | **不做** | 与本地优先、清澄相冲突 |
| 免费版限制 | 不限制计算功能；限制导出/皮肤 | 不用功能阉割惩罚用户 |

### 商业化前置阻塞

- [ ] **解决许可**：当前参考项目为 `UNLICENSED`；正式售卖前必须确认代码、字体、图标、产品名的权利。
- [ ] **确定原生壳**：推荐 Capacitor（iOS/Android）；先做 PWA 稳定，再包壳。
- [ ] **App Store / Play 素材**：图标、启动图、5–8 张截图、预览视频、隐私说明。
- [ ] **隐私政策 / 服务条款**：明确“无账号、无网络、无追踪、数据只在本机”。
- [ ] **定价与退款策略**：首发价、常规价、Era Pack 是否首发。
- [ ] **真实用户验证**：至少 10 名外部用户完成“安装 → 计算 → 找到纸带 → 切换皮肤”。

### 不该做的事

- 不做广告、订阅、账号、云同步；
- 不卖“更快的计算”“更高精度”这类功能；
- 不做 13 套皮肤全量堆叠；
- 不用“AI 计算”当卖点；
- 不把 PWA 说成原生已验收。

## 四、P1 · 让它“最酷”

按“性价比 / 差异化”排序，不是按工程量。

### 1. 纸带作为物件（最高优先）

- [ ] **导出纸带**：PNG / PDF / 纯文本，带日期与皮肤；
- [ ] **分享结果卡**：一张像票据/收据的图，适合发消息；
- [ ] **打印纸带**：A4/热敏小票两种版式；
- [ ] 纸带搜索、置顶、删除单条；
- [ ] 纸带“撕下”动效（可选，减少动态时关闭）。

为什么：它把“计算”变成可保存、可分享的物件，是这款产品最容易被记住的差异点。

### 2. 触感与声音（可选、默认克制）

- [ ] 机械键感：按下位移 + 轻触觉；
- [ ] 可选“键声”：机械/继电器/静音；
- [ ] 触觉强度设置；默认只保留极轻反馈；
- [ ] 不在每次点击都震动；
- [ ] 减少动态时关闭非必要动效。

为什么：计算器的“物性”很大程度来自按下去的那一下；但必须可关。

### 3. CRT / Phosphor 模式

- [ ] Phosphor 皮肤加可选扫描线、余辉、轻微噪点；
- [ ] 默认关闭；对比度不降级；
- [ ] 提供“纯净模式”一键关闭；
- [ ] 不在低端设备上默认开启。

为什么：它是复古未来的视觉签名，但不能以可读性为代价。

### 4. 桌面/横屏“仪器模式”

- [ ] 横屏时显示更大的纸带与记忆槽；
- [ ] iPad / 平板双栏；
- [ ] 键盘用户：数字区 + 纸带并排；
- [ ] 不强制旋转，保持手机竖屏优先。

### 5. 快速入口

- [ ] iOS/Android 主屏小组件：直接算一个简单表达式；
- [ ] 锁屏/快捷指令入口；
- [ ] 分享菜单接收数字并打开计算器；
- [ ] 不做后台常驻、不申请无关权限。

### 6. 记忆与历史增强

- [ ] 多记忆槽 M1–M4（可命名）；
- [ ] 纸带按日期分组；
- [ ] 长按结果复制/取回；
- [ ] 导出纸带时保留表达式与错误原因。

### 7. 键盘电源用户

- [ ] 完整快捷键表（含 `%`、`√`、`x²`、`1/x`）；
- [ ] 可选 RPN 模式（后置）；
- [ ] 计算器布局切换：标准 / 紧凑 / 大按键。

## 五、P2 · 扩展但不要变味

### 1. 可选科学模式

- [ ] 以“抽屉”形式展开，不污染标准模式；
- [ ] 三角函数、对数、幂、括号；
- [ ] 角度/弧度切换；
- [ ] 科学模式单独测试集。

### 2. Era Packs（外观扩展）

- [ ] 每包 2–3 套皮肤，一个有明确时代/材质主题；
- [ ] 主题包只改视觉，不改计算；
- [ ] 每套皮肤过对比度与 200% 字号；
- [ ] 不做抽卡/限时逼氪。

候选：
- **Atomic**：原子朋克、奶油黄、仪表盘；
- **Tape**：磁带未来、铬、荧光；
- **Terminal**：单色磷光、等宽、继电器；
- **Paper**：票据、印章、热敏纸；
- **Brass**：黄铜、皮革、模拟仪器。

### 3. 结果叙事

- [ ] “这张纸带属于哪一天”自动标题；
- [ ] 可选一句极短的复古未来文案（不干扰计算）；
- [ ] 分享卡上带产品签名，不加水印广告。

### 4. 无障碍深化

- [ ] 屏幕阅读器逐键播报；
- [ ] 高对比模式；
- [ ] 大字号布局；
- [ ] 左手模式；
- [ ] 色盲友好的状态区分（不只靠颜色）。
