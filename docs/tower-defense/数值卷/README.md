## 一、本卷解决什么问题

论文证明了"塔防的难度可以被写成公式"。但公式要能用，还需要四件事：**定义清楚**（每个符号是什么）、**能标定**（从零得到一组参数）、**能对照**（与别的作品怎么比）、**能守住**（改数值时怎么不把设计意图弄丢）。

本卷就是这四件事的手册，合计约 9254 汉字。

## 三、三种读法

| 目的 | 读什么 |
| --- | --- |
| 我要给一款新塔防标定难度 | 01（定义）→ 02（八步标定法）→ 05（把意图写成断言） |
| 我想知道这套模型能不能信 | 01（模型 vs 实测对照）→ 04（参数敏感性：只有 γ=3 五章全 PASS） |
| 我想横向比较别的作品 | 03（代理指标、置信度 A/B/C、不等价性四条） |

## 五、维护约定

- 本卷的公式与常量引用自策划卷与 [`tools/sim_refu_game_001.ts`](../../../tools/sim_refu_game_001.ts)，**不得在本卷里改数值**；需要变更时先改策划卷与脚本，再回来改本卷的示例；
- 04 号文件里的实测数字（如 γ=2/4 时五章 FAIL、cap=2/4 各四章 FAIL）是可复现的命令结果，重跑后如有变化需同步更新；
- 新增作品对照时，必须在 03 号文件里标注置信度等级与"估算"字样。
