## 一、远征八节点的预算序列

远征的难度不是"设计八个数"，而是**一条被写死的曲线**：

```
B_i = 170.6 × (0.9 + 0.10 × i)      i = 1…8
D_i = 0.9 + 0.10 × i
```

代入得 `B = 171 / 188 / 205 / 222 / 239 / 256 / 273 / 290`，`D = 1.00 → 1.70`。设计含义有三点：

1. **步长固定**（每格 +17.06 预算、+0.10 难度），因此每一格的"难一点"是可感知且等量的；
2. **终点由公式决定**：第八格 `D = 1.70` 直接决定了"通关率极低"这一体验目标，而不是先定体验再凑数值；
3. **可外推**：若要做 12 节点的长链，序列继续延伸即可，不需要重新设计难度语言。

配合 `cap = 3` 与 `λ0/γ`，得到实测胜率 84.4% → 3.6%（设计表，见 [23 号文档](../../refu-game-001/23_规则卡组_Roguelike远征.md)）；当前脚本 `--verify-rogue --n 20000` 的复现值为 84.5% → 3.8%，逐点差 ≤0.6pp（口径说明见 [01 号文件](01_模型定义与推导.md) 第四节）。

## 二、永久修饰（PMOD）的增益口径

PMOD 在每节点结束三选一，效果是**本局持续**。它的强度不能只看"数值加了什么"，要看**胜率提升多少**：

```
平均增益   = E[P(胜 | 带该 PMOD)] − P(胜 | 基准)
契合流派增益 = 同一算法，但样本换成与该 PMOD 契合的卡组
```

本作实测（基准关 `B = 205`、`P = 1.08`、基准胜率 58.5%）：

| PMOD | 效果 | 平均增益 | 契合流派增益 | 允许带 |
| --- | --- | --- | --- | --- |
| PMOD-01 加压涂层 | 全体塔伤害 +10%，可叠 3 层 | 10.1pp | 纯弹药 15.6pp | 平均 6–12pp；契合 ≤20pp |
| PMOD-02 扩建基座 | 本局塔位 +1 | 8.5pp | 多塔 13.0pp | 同上 |
| PMOD-03 备用电源 | 起始能量 +5 | 7.0pp | 能量重 11.6pp | 同上 |
| PMOD-04 首放免费 | 每波第一张卡费用 −50% | 8.5pp | 低费 14.3pp | 同上 |
| PMOD-05 羁绊加速 | 羁绊阈值 −1（最低 2） | 10.1pp | 纯标签 16.9pp | 同上 |

**双口径的设计意义**：平均增益控制"拿了不亏"，契合增益控制"值得为它改卡组"。两者的差（约 5–7pp）就是这张 PMOD 的**决策价值**。若某张 PMOD 的平均增益超过 12pp，它就变成了必选项（伪选择）；若契合增益超过 20pp，它就会把卡组锁死成一套。

## 三、挑战卡：难度分与奖励的线性口径

挑战卡是局前自选的难度修饰。本作把"难度"量化为**难度分**，奖励随之线性增长：

```
掉落系数 = 1 + 0.05 × 难度分合计      （上限 ×2.0）
评级加成 = 5% × 难度分合计
单局难度分合计 ≤ 15                    （约三张高难度卡）
```

| 挑战卡 | 难度分 | 主要作用 |
| --- | --- | --- |
| 加压 | 3 | 敌人生命 +30% → 抬高 `B` |
| 断供 | 4 | 能量自然增长 −20% → 压低 `P` |
| 封锁 | 3 | 禁用技能卡 → 压低 `P` 的爆发项 |
| 双流 | 5 | 出生点 +1 → 改变路径拓扑（见第五节） |
| 疾行 | 2 | 移速提升 → 缩短输出窗口，等价于压低 `P` |

**为什么不用"等级"**：等级把不同强度的卡强行归为同级，玩家会挑同级的便宜卡，奖励被薅。改用难度分后，"代价—奖励"变成一条直线，堵住了刷奖励的动机。

挑战关的设计带：`D = 1.25–1.45`，目标胜率 25–50%。这意味着挑战卡不是"越难越好"，而是**被约束在一条窄带里**。

## 四、族专属挑战卡的双口径判据

族专属卡只在该族卡组可选，因此必须同时满足两条：

1. **平均卡组跌幅**落在分数带内（3 分卡 12–25pp、2 分卡 5–12pp）；
2. **纯流派卡组跌幅 ≤ 35pp**（"一张卡不能杀死一套牌"）。

实测 9 张全部通过，最贴线的是三张 31.8pp 的卡（弹药禁令、腐蚀逆流、共鸣干扰）——它们的设计意图正是"逼纯流派转型"，但不能转型失败。

## 五、双流折算：多路并行的预算换算

双入口地图的两路并非始终同时活跃（有喘息窗口），因此 `×1.4` 的系数不能整局生效。本作的折算规则是：

```
有效系数 = 1 + 0.4 × (两路同时活跃的波次数 ÷ 总波数)
```

样例（[22_样例_双入口关卡组装](../../refu-game-001/22_样例_双入口关卡组装.md)）：`WAV-MUL-A` 共 6 波、其中 4 波两路同时活跃 → 有效系数 ≈ **×1.24**；`B′ = 218 × 1.24 ≈ 276`；取中期卡组 `P = 1.3`，则 `D = (276 ÷ 158) ÷ 1.3 ≈ 1.34`，落在挑战带内，实测胜率 **36.3%**。

**被否决的组合**：双流 + 加压（难度分 8）→ `D ≈ 1.75`、模拟胜率 2.1%，超出挑战带。这条否决记录本身就是模型的价值：它在开工前就告诉你"这个组合不该出现"。

## 六、一条可复用的远征检查清单

1. 序列是否由公式生成（而非手填）？
2. 每格的 `D` 是否落在目标带内，且末位是否低到"稀有成就"量级？
3. PMOD 是否满足双口径（平均 6–12pp、契合 ≤20pp）？
4. 挑战卡是否用难度分而非等级？掉落系数是否封顶？
5. 是否存在被否决的组合记录（说明你真的验算过）？
6. 多路地图是否用了"有效系数"而不是整局乘系数？
7. 远征是否禁用了主线难度系统（避免两套难度互相污染）？
