# 04 · 敏感性分析：γ、cap、B_ref、P 与样本量

本文件所有数字均可复现：解析值＝泊松累积 `P(X < cap)`（`X ~ Poisson(λ)`，`λ = λ0 · D^γ`）；实测值＝脚本 `--verify-bands`，运行参数 `n = 20000`、`seed = 20260914`（默认）。脚本常量已全部暴露为命令行参数，**无需改代码**：

```bash
S=projects/refu-game-001/tools/sim_refu_game_001.ts
node $S --verify-bands --n 20000                  # 基准：γ=3、cap=3、λ0=1.35、B_ref=158
node $S --verify-bands --n 20000 --gamma 2        # γ 敏感性（2 / 3 / 4）
node $S --verify-bands --n 20000 --cap 4          # cap 敏感性（2 / 3 / 4）
node $S --verify-bands --n 20000 --b-ref 189.6    # B_ref +20%（−20% 用 126.4）
node $S --verify-bands --n 20000 --lambda0 1.0    # λ0 扰动
node $S --verify-bands --n 20000 --seed 12345     # 种子扰动
```

两个量**没有**开关：`D50 = 1.25` 与 `k = 7` 只出现在 logistic 近似式里，脚本用的是精确泊松累积（两者在本作区间内方向一致）；`--alpha` 仅作用于 `--stage` 单关模式。要扰动它们，须在脚本或近似式中调整常量后重跑。

本文件回答"改了会怎样"，参数的标定顺序与取值来源见 [02_参数标定流程](02_参数标定流程.md)，冻结后的必跑清单见 [数值卷 README](../../../projects/refu-game-001/docs/design/数值/README.md) 第三节。

## 一、γ：漏怪陡度（每 +0.1 D 的漏怪增量）

`λ = λ0 · D^γ`，故 `Δλ = λ0 · [(D + 0.1)^γ − D^γ]`，`λ0 = 1.35`。

| 起点 `D` | γ=2：Δλ（相对） | γ=3：Δλ（相对） | γ=4：Δλ（相对） |
| --- | --- | --- | --- |
| 0.9 | 0.256（+23.4%） | 0.366（+37.2%） | 0.464（+52.4%） |
| 1.2 | 0.338（+17.4%） | 0.633（+27.1%） | 1.056（+37.7%） |
| 1.5 | 0.419（+13.8%） | 0.973（+21.4%） | 2.013（+29.5%） |

两点读法：其一，`D = 1.0` 是唯一不动点——任何 γ 都给出 `λ = 1.35`，γ 只改变"偏离基准的速度"；其二，同样 `D = 1.5`，胜率是 γ=2 的 41.5%、γ=3 的 16.7%、γ=4 的 3.4%，**一档 γ 就是十几个百分点的终局难度**。实测印证：`--gamma 2` 得 93.0 / 79.3 / 72.7 / 69.2 / 60.3%（第 3–5 章冲高 FAIL）；`--gamma 4` 得 96.0 / 72.2 / 55.6 / 47.4 / 27.7%（第 5 章跌破 FAIL）。只有 γ=3 让五章全 PASS，故它不可自由调节。

## 二、cap：容错上限

| `D` | λ | cap=2 | cap=3 | cap=4 |
| --- | --- | --- | --- | --- |
| 0.8 | 0.691 | 84.7% | 96.7% | 99.4% |
| 1.0 | 1.350 | 60.9% | 84.5% | 95.2% |
| 1.2 | 2.333 | 32.3% | 58.7% | 79.3% |
| 1.4 | 3.704 | 11.6% | 28.5% | 49.3% |
| 1.6 | 5.530 | 2.6% | 8.7% | 19.8% |

`cap` 每降 1，整条曲线约等于把 `D` 上浮 0.15–0.2：cap 越小，**同样的漏怪期望被更严厉地判负**，且惩罚集中在高 `D` 段（`D=1.2` 处三档相差 47pp）。实测：cap=2 得 81.4 / 50.8 / 38.3 / 33.1 / 21.3%（四章偏低 FAIL）；cap=4 得 98.8 / 90.4 / 83.0 / 78.7 / 65.2%（四章偏高 FAIL）。`cap` 同时是玩法字段（基地生命），改它等于改玩法，不只是改数值。

## 三、B_ref：只是标尺

`D = (B ÷ B_ref) × (P_ref ÷ P)`，所以 `B_ref` 乘一个因子 `c`，全部 `D` 同步乘 `1/c`。它**不改变曲线形状，也不改变同一作品内关卡的相对次序**，只做整体平移。

| `B_ref` | 相对 158 | 真值 `D=1.2` 处映射为 | 胜率（γ=3, cap=3） | 真值 `D=1.5` 处 |
| --- | --- | --- | --- | --- |
| 126.4（−20%） | ×1.25 | 1.500 | 16.7% | 0.7% |
| 158（基准） | ×1.00 | 1.200 | 58.7% | 16.7% |
| 189.6（+20%） | ×0.833 | 1.000 | 84.5% | 50.9% |

实测确认：`--b-ref 189.6` 得 98.7 / 92.1 / 87.1 / 84.2 / 74.9%（全章偏高 FAIL）。另有退化关系：`log λ = log λ0 + γ·log D`，而 `log D` 已含 `−log B_ref`，所以 **`λ0` 与 `B_ref` 在 log 空间共线**——标定时只能独立定一个，另一个由目标胜率反解（`--lambda0 1.0` 实测 97.5 / 86.6 / 78.9 / 74.7 / 62.3%，同样整体偏高）。

实践含义有一条：既然 `B_ref` 只做平移，**目标胜率带一旦按 158 校准完毕，就不必随 `B_ref` 重写**——若将来换基准关，正确做法是同时换算所有文档里的 `D`，而不是重调胜率带。

## 四、P：最危险的输入

`D ∝ 1/P`，且两侧不对称：P 下调 10% 使 `D` 上升 11.1%，上调 10% 只使 `D` 下降 9.1%。

| 情形 | 从 `D₀=1.2`（58.7%）出发 | 从 `D₀=1.44`（23.4%）出发 |
| --- | --- | --- |
| P 高估 10% | `D`=1.091 → 74.3%（+15.6pp） | `D`=1.309 → 41.7%（+18.3pp） |
| P 低估 10% | `D`=1.333 → 38.0%（−20.7pp） | `D`=1.600 → 8.7%（−14.7pp） |

这就是为什么 `P` 必须按卡组**实测**而非按面板估算：±10% 的 P 误差在挑战区等价于 15–21pp 的胜率误差，已经远大于九项校验允许的极差带（如对空 ≤15pp）。相比之下，`B_ref` 的 ±20% 虽然看起来更激进，却只是平移。

## 五、样本量 n

| 口径 | 第 1–5 章实测胜率 | 与 n=20000 的差异 |
| --- | --- | --- |
| n=5000 | 95.0 / 75.6 / 64.3 / 58.8 / 43.6% | 0.1 / 0.4 / 0.1 / 0.0 / 0.0pp |
| n=20000（默认种子） | 94.9 / 76.0 / 64.4 / 58.8 / 43.6% | 基准 |
| n=20000（seed=12345） | 94.9 / 75.9 / 64.5 / 58.7 / 43.6% | ≤0.1pp |

单关标准误 `SE = √(p(1−p)/n)`：p≈0.44 时，n=5000 为 0.70pp，n=20000 为 0.35pp；而章节均值是 5–12 关的平均，SE 再除以 `√关数`，降到约 0.1–0.3pp——这正是本作经验值"章节末位差异约 0.1pp"的来源。结论：样本量只影响末位，不会翻转 PASS/FAIL（除非该章恰好压在带边上），本地用 n=5000、CI 用 n=20000 即可。**判定裕度建议**：把带位断言写死为目标带，但心里留 `2×SE ≈ 0.2pp` 的余量——卡在带边 0.2pp 以内的 PASS 不算真 PASS。

## 六、参数—影响—是否可冻结

| 参数 | 现值 | 扰动响应 | 敏感度 | 是否可冻结 |
| --- | --- | --- | --- | --- |
| `γ` | 3 | 改 1 档 → 终局胜率 ±13–25pp | 高 | **冻结**（唯一让五章全 PASS） |
| `cap` | 3 | 每 ±1 ≈ `D` ∓0.15–0.2 | 高（且是玩法字段） | **冻结**（改动须重跑九项校验） |
| `B_ref` | 158 | 全局平移 `D`（×`1/c`），形状不变 | 标尺级 | **冻结** |
| `λ0` | 1.35 | 与 `B_ref` 在 log 空间共线 | 高（但不可独立标定） | **冻结** |
| `P` | 逐关输入 | `D ∝ 1/P`；±10% → 挑战区 ±15–21pp | 最高 | **不可冻结**（每关重算） |
| 章节 α | 1.00 / 1.06 | 章内 `D` ±6% | 低 | 版本内冻结 |
| `n` | 20000（CI）/ 5000（本地） | 末位 ±0.1–0.4pp | 低 | 可冻结 |
| `D` 目标带 | 逐章 | 校准目标而非输入 | — | 不可冻结（随内容迭代） |

三条结论：

1. `γ`、`cap`、`B_ref`、`λ0` 是"定义难度"的四个参数，全部冻结；其中 `B_ref` 与 `λ0` 在 log 空间退化，标定时只能定一个、另一个由目标胜率反解。
2. `P` 是唯一逐关变化的输入，也是最大误差源：±10% 的 P 误差在挑战区等于 15–21pp 的胜率差。预算应当花在 `P` 的标定上，而不是加大 `n`。
3. 样本量只影响末位（章节均值 0.1–0.3pp）。n=5000 与 n=20000 的结论一致，不必为"更精确"付出十倍算力。
