## 一、本卷做什么

塔防是"以看为主"的策略游戏：画面必须同时说清敌人往哪走、我能放哪、我放了什么、现在几比几。本卷讨论这套视觉语法怎么成立，以及两种美学取向（复古未来 / 千禧透明）在塔防上的具体落点与代价。

合计约 9,730 汉字。
