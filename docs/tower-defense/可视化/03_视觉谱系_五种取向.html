塔防视觉谱系 · 五种取向

来自 美学卷 05：五种视觉取向各给语言、信息层级、风险与一条可迁移做法。它们不是互斥风格，而是"权重"。

卡通表演型

植物大战僵尸（2009，PopCap）／Bloons TD（2007 起，Ninja Kiwi）
视觉语言粗剪影 + 高饱和 + 表情与动作夸张；塔会被吃掉，攻防关系可见
信息层级画面第一读数：谁在吃谁；数值压在边角、不在战场中央
可读性风险高饱和互撞导致"塔位"被淹没；剪影过胖会遮路径
可迁移让塔"可被攻击"——把风险画在防线上，而不是只画敌人

手绘关卡型

Kingdom Rush（2011，Ironhide Game Studio）
视觉语言手绘材质路 + 可建点专属底片；图标风格统一，英雄单位独立剪影
信息层级画面第一读数：这条路的样子；可建点用底片而非描边区分
可读性风险手绘细节与粒子争抢注意力，路径容易被纹理吃掉
可迁移给"可放置"一个专属材质（底片），不要只靠描边

现代军事型

Anomaly: Warzone Earth（2011，11 bit studios）
视觉语言俯视车队 + 路线折线 + HUD 情报风格；主语从"塔"换成"入侵路线"
信息层级画面第一读数：威胁圈与路线；信息层与战场层分明
可读性风险HUD 过密会压缩战场，路线折线盖住地形
可迁移把"路线"当一等公民来画——它是玩家真正要读的对象

都市机能型

明日方舟（2019，Hypergryph）
视觉语言高台/地面双位型材质分工；停顿时界面下沉、指令层上浮
信息层级画面第一读数：这块地能放谁；暂停布防把"读"与"操作"分离
可读性风险高台与地面若只靠颜色区分，色弱下不可辨
可迁移用材质与形状区分位型；把"暂停"当成一种信息设计手段

极简工程型

Desktop Tower Defense（2007，Paul Preece）
视觉语言纯几何网格，颜色极少，路径由敌人运动实时生成
信息层级画面第一读数：网格本身即信息；数字直接压在格子上
可读性风险过于朴素会缺少情感抓手；路径随塔位变化，需要额外的可读性提示
可迁移网格不是偷懒——把"规则"直接画出来，玩家学得更快

共同底线

数值与路径优先于装饰：四项关键信息（能量／基地生命／漏怪／卡面数字）在任何风格下都必须 1 秒可读；风格是可换外壳，可读性是不可换内核（美学卷 01 第六节、04 第六节）。
