## 一、任务定义与环境接口

**任务**：给定一张关卡（地图卡 + 波次卡组 + 规则卡）与一份卡组（局前携带 20 张卡，核心／支援／修饰三区），智能体在**槽位—卡—能量**构成的动作空间里输出布防与局内决策，直到通过全部波次或基地生命归零。

| 口径 | 内容 | 来源 |
| --- | --- | --- |
| 槽位 | 标准槽（塔卡）／支援槽（从族支援卡）／修饰槽（修饰卡）／事件槽（地图卡预留）；卡不能做它槽位没声明的事 | [策划卷 02](../../refu-game-001/02_卡片规则系统.md)、[策划卷 06](../../refu-game-001/06_关卡与地图卡.md) |
| 卡 | 七类：地图／波次／事件／塔／单位／技能／规则卡；前三类由关卡给定，后四类是决策对象 | [策划卷 02](../../refu-game-001/02_卡片规则系统.md) |
| 能量 | 起始 10、自然增长 +1/s、击杀返还（小兵／快速／空中 +1、装甲 +2、精英 +3、BOSS +10）、波间 +5、上限 99 | [策划数值/05](../../refu-game-001/数值/05_能量与关卡预算曲线.md) |
| 判据 | 累计漏怪 `< cap`（`cap = 3`）；难度三元组 `(B, P, D)` 随关卡给出 | [论文 5.5](../00_塔防游戏研究_内涵与外延.md)、[04](04_可解释难度作为评测维度.md) |

| 接口 | 建议 | 理由 |
| --- | --- | --- |
| 观测 | 波次预告（构成、数量、间隔、威胁值）＋能量及增长率＋地图槽位（分型、位置、地形）＋已有塔（类型、等级、范围、冷却） | 不含隐藏信息，与"预告使不确定性可规划"一致（[论文 5.2](../00_塔防游戏研究_内涵与外延.md)） |
| 动作 | 买卡／放卡（卡 → 声明过的槽位）／换装（替换修饰卡改变塔职能）／技能（消耗能量的主动卡） | 覆盖 [策划卷 04](../../refu-game-001/04_塔防核心战斗.md) 的行为集合；动作离散，便于与搜索、RL 对照 |
| 步进 | **波次步进**（每波一个决策点，默认）或 **1 秒步进**（考调度） | 混合步进必须声明；波次步进最易保证"同种子同结果" |

## 二、种子与样本量

| 项 | 规定 | 依据 |
| --- | --- | --- |
| 种子 | 固定 `--seed`（默认 20260914）；**同种子必须同结果** | [数值卷 05](../数值卷/05_验收与CI.md)、[策划卷 26](../../refu-game-001/26_远征_种子与排行榜验收.md) |
| 样本量 | 单关 **≥200 局**；主结论本地 n = 5000、出结论 n = 20000 | [数值卷 02](../数值卷/02_参数标定流程.md)、[数值卷 04](../数值卷/04_敏感性分析.md) |
| 置信区间 | `SE = √(p(1−p) ÷ n)`，报 `p ± 1.96·SE`（95%） | 同上 |
| SE 量级 | `p ≈ 0.44`：n = 5000 → 0.70pp；n = 20000 → 0.35pp；n = 200 → 约 3.5pp | [数值卷 04](../数值卷/04_敏感性分析.md) |

三条读法：**样本量只影响末位**（本作 n = 5000 与 20000 的五章通关率差 0.1／0.4／0.1／0.0／0.0pp，不翻转结论；n = 200 必须连 ±3.5pp 区间解读）；**"≥200 局"是下限**（只支撑"两档差 10pp 以上"，要分辨 3pp 级差异至少 n ≈ 2000）；**随机源必须点名**（脚本为固定种子的 `mulberry32(seed)`，`--selftest` 要求同参数两次相等；智能体侧的温度采样、ε-greedy 等同样要种子化）。

## 三、基线设计：六条，各自只需"可复现"

| 基线 | 实现 | 复现要求 | 用途 |
| --- | --- | --- | --- |
| 随机 | 合法动作上均匀采样（受能量约束） | 固定种子；报采样分布 | 下限；校验动作空间 |
| 贪心 | 每步选"边际 DPS ÷ 能量"最高者 | 确定性 | 廉价上界；暴露短视 |
| 启发式 | 按威胁值排序，先占覆盖弧长最长的槽位，按能量阈值升级 | 规则写成判定表 | 人类风格可行解 |
| ILP／搜索 | "槽位 × 卡 × 波次"建成整数规划或束搜索，受限时用局部搜索 | 声明求解器、时限、是否可行 | 近似上界（[论文 4.7](../00_塔防游戏研究_内涵与外延.md)） |
| RL | 动作按槽位／卡离散化，奖励为通关加漏怪惩罚 | 声明算法、步数、种子、测试关是否未见 | 学习基线（同上） |
| LLM | 观测序列化为提示，输出动作 JSON；重试算一次尝试 | 声明模型版本、解码参数、提示词、重试次数 | 被测对象；记录非法动作占比 |

三条底线：**可复现即可，不必最强**；**随机基线也要报区间**（换种子后成绩可能相差很大）；**调参必须记账**（测试关卡上调过参就要写进"已知偏差"）。

## 四、指标与报告模板

一行＝一个"关卡 × 智能体"：

| 字段 | 口径 | 格式示例 |
| --- | --- | --- |
| 关卡与标签 | 关卡 id ＋ `D` 区间标签 | `CH4-01／挑战（D≈1.20）` |
| 通关率 ± 置信区间 | `p ± 1.96·SE`，注明 n | `58.7% ± 0.7pp（n=20000）` |
| 平均漏怪 | 均值，与 `cap = 3` 并列 | `λ̄ = 2.33，容错余量 +0.67` |
| 首次通关／策略多样性 | 尝试次数中位数；族间或卡组间通关率极差 | `中位 2 次；三族极差 9.7pp（阈值 ≤15pp）` |
| 失败原因分布 | 预算／经济／机制／执行四类占比 | `机制 __% ／ 经济 __% ／ 执行 __% ／ 预算 __%` |

示例数字取自本作公开锚点：`D = 1.2` 处 `λ = 2.333`、解析通关率 58.7%（[数值卷 04](../数值卷/04_敏感性分析.md)），对空三档极差 9.7pp（[数值卷 05](../数值卷/05_验收与CI.md)），仅示范格式。两条硬规定：**报告头**须写 `n / seed / λ0 / γ / cap / B_ref`，且与校验同一次跑出；**原始结果落盘**为逐局记录，报告由结果生成，不手抄。

## 五、复现清单 12 条

| # | 条目 | 要写什么（括号内为反例） |
| --- | --- | --- |
| 1 | 环境版本 | 仓库 commit、脚本与文档版本、运行时版本（非"最新版"） |
| 2 | 种子 | 每个实验的 `--seed`、智能体侧随机源种子（非"随机种子"） |
| 3 | 参数 | `λ0`／`γ`／`cap`／`B_ref`／α／`ROGUE_P` 等冻结量取值（不得静默用默认值） |
| 4 | 样本量 | 每关 `n`、总对局数、每档卡组数（非"跑了很久"） |
| 5 | 随机源 | 发生器与调用顺序：脚本为 `mulberry32(seed)` |
| 6 | 硬件 | CPU／内存／是否 GPU，用于说明耗时而非成绩 |
| 7 | 代码路径 | 智能体实现、评测脚本、结果目录（非"只有对话记录"） |
| 8 | 关卡／卡组版本 | 地图卡、波次卡组、规则卡与卡组清单版本（非"第 3 章"） |
| 9 | 评测脚本 | 一条命令跑出全部表格（非手动点界面） |
| 10 | 原始结果 | 逐局记录落盘，可被第三方重算（非只留汇总表） |
| 11 | 失败案例 | 至少 3 个失败轨迹，含错误动作（非只报通关率） |
| 12 | 已知偏差 | 调参范围、被排除样本、与真人玩家的差距 |

## 六、风险与伦理

| 风险 | 缓解 |
| --- | --- |
| LLM 幻觉导致"看似合理但不可执行"的布防（引用不存在的卡、放到未声明的槽位） | 动作层做合法性校验并单列"非法动作率"；非法动作计入失败，不得静默纠正 |
| 把结论外推到真人玩家（"智能体通关率 43.6%，说明人类也这么觉得"） | 评测对象是智能体；`D` 描述题目而非体验，跨作品不可比（[数值卷 03](../数值卷/03_横向对照方法.md)）；本工作区不做玩家实证 |
| 用测试关卡调参（反复改到四档都漂亮） | 记录调参范围；保留未用于调参的关卡集 |
| 省略样本量与区间（只报"通关率 60%"） | 强制 `p ± 1.96·SE`；`n < 200` 只能作探索性报告 |
| 忽略 `P` 的误差（按面板估算，±10%） | 挑战区 `P` 的 ±10% 等价于 15–21pp 通关率差，必须实测标定（[数值卷 04](../数值卷/04_敏感性分析.md)） |

总纲：**协议的价值在于写下"什么不算数"**——不看 `D` 的通关率、不写 `n` 的胜率、不声明合法性的动作、外推到真人的结论，都不算数。
