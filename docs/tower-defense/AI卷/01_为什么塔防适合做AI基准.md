# 01 · 为什么塔防适合做 AI 基准

> **卡面**：用途＝论证塔防作为 AI 基准的适配性与实验边界｜ 依赖：[论文第二节](../00_塔防游戏研究_内涵与外延.md)、[论文第五节](../00_塔防游戏研究_内涵与外延.md)、[数值卷 01](../数值卷/01_模型定义与推导.md)、[数值卷 04](../数值卷/04_敏感性分析.md)｜ 状态：v0.1 · 2026-10-12

## 一、基准的选型问题

一个 AI 基准要同时满足三件互相拉扯的事：**足够难**（不能靠查表拿分）、**足够便宜**（能跑几百上千局）、**足够诚实**（可复现、失败可解释）。围棋与即时战略满足第一条却昂贵，多数街机游戏满足第二条却易被记忆；塔防居中——规则可枚举，后果却长到必须规划。

本文论证的是一个更窄的命题：**塔防是结构完整的序列决策问题，其难度可被一组冻结参数标注**；机制口径以论文第二节与第五节为准。

## 二、任务结构：三重耦合的序列决策

塔防单局可写成标准序列决策：**状态**＝（资源、塔位与塔型、波次进度、已漏怪数、敌人构成）；**动作**＝（放塔、升级、拆除、技能、等待）；转移由波次与敌人行为决定，玩家只改变火力沿路径的分布。

决策结构由三件事**耦合**而成：

1. **长时程资源分配**：能量是可积累的现金流（论文 5.3），"现在买塔"与"存到波间爆发"是非对称决策；
2. **空间布局**：有限槽位里选择覆盖哪段路径，是沿程伤害曲线的分布问题，不是单点最强（论文 5.1）；
3. **时序决策**：技能何时开、升级何时买，其价值取决于未来的波次构成。

三者互相牵制：开局布局决定中期收入，中期收入又决定终局能否补对空。**决策后果在几分钟后才结算**，这是信用分配最经典的形态。

## 三、对 AI 友好的六个属性

| 属性 | 塔防的体现 |
| --- | --- |
| 状态离散可枚举 | 塔位 × 塔型 × 占用是有限集合；塔位按槽位分型，卡只能落声明槽位 |
| 动作空间有限 | 每步候选＝可用槽位 × 可负担卡牌，另加等待；能量与人口上限进一步剪枝 |
| 单局时长短 | 3–15 分钟；本作碎片关 6–8 波（3–5 分钟） |
| 失败判据清晰 | 漏怪数是整数，胜负是布尔量；本作以整局漏怪 `< cap = 3` 即胜 |
| 随机性可控 | 结构随机而非战斗随机；本作远征每日一枚种子，同种子同序列 |
| 结果可解释 | 难度可分解为 `B`、`P`、`D = (B ÷ B_ref) × (P_ref ÷ P)` 三个量 |

前四条解决"能不能跑实验"，后两条解决"能不能说服人"：多数基准只能报告得分，塔防还能报告"**在什么难度下**得分"。

## 四、对 AI 不友好的地方（诚实清单）

1. **状态空间组合爆炸**。地图卡 × 波次卡 × 卡组 × 塔型的组合是笛卡尔积；本作六图配三套波次即有 18 套基础关卡组合（论文 8.5），再叠事件卡与规则卡继续翻倍。
2. **最优布局不可求**。Suttichaya 证明，广义 n × n 网格塔防上"放置 k 座塔以最大化起点到终点最短距离"是 NP-hard（2017，DOI: [10.1007/978-3-319-60675-0_2](https://doi.org/10.1007/978-3-319-60675-0_2)）。这意味着**没有可用的最优解标签**：监督式基准只能放弃 oracle，学习信号只能来自胜率与启发式基线。
3. **奖励稀疏且塑形有风险**。主奖励只在局末结算，中间只能靠塑形信号（本波漏怪、能量效率），塑形不当会退化成保守摆塔。
4. **人类偏好难量化**。"像人一样打"包含留余量、不滥用暂停等不成文约束，缺少统一标注口径；LiverDefense 把塔防改造成可定制研究工具（DOI: [10.1007/s00371-016-1314-0](https://doi.org/10.1007/s00371-016-1314-0)），可见"可定制"既是优势，也意味着协议未必统一。

## 五、三类可用任务

1. **求解型**：给定波次预算序列 `B` 与固定卡组，求布局与升级序列，使胜率最大或漏怪最少。基线可用贪心、局部搜索与整数规划，例如把 Bloons TD 建成"时序二维背包"求解（DOI: [10.1111/itor.70238](https://doi.org/10.1111/itor.70238)）；强化学习也可作用在这一层，塔防高层策略控制的 RL 工作见 IEEE CoG 2024（DOI: [10.1109/CoG60054.2024.10645621](https://doi.org/10.1109/CoG60054.2024.10645621)）。
2. **适应型**：在随机种子（关卡链、三选一增益）下考察策略迁移。"会玩一关"与"会玩这个游戏"是两种能力，结构随机恰好把二者分开测量（论文 5.4）。
3. **评测型**：把模型当作被测对象，用塔防做低算力、可复现的智能体基准。TowerMind 给出多模态观测与幻觉评测的实例（AAAI-26，DOI: [10.1609/aaai.v40i31.39818](https://doi.org/10.1609/aaai.v40i31.39818)）：它关心的不是"能不能打通"，而是长时程规划与空间推理的表现，以及会不会编造机制。

一句话：**求解型问"能不能更好"，适应型问"换个题是否还行"，评测型问"会不会"。**

## 六、与本作数值卷的接口：把难度当作横轴

塔防作为基准最有价值的一点，是能把"模型失败"变成可比结果。接口是论文第五节的三个量与一条判据（见数值卷 01）：

```
B = Σ(敌人数量 × 威胁值)                 敌方压力
P = 塔位数 × 卡组平均有效 DPS × 覆盖系数   我方战力
D = (B ÷ B_ref) × (P_ref ÷ P)           难度比（B_ref = 158）
胜 ⇔ 整局漏怪总数 < cap                   cap = 3
```

实验协议因此是：**以 `D` 为关卡难度标签（自变量），以胜率与漏怪分布为模型表现（因变量）**。得到的不是"模型在第 5 关失败"，而是"模型在 `D ≈ 1.3`（目标胜率约 40–55%）上失败"，后者可与人类曲线和其他模型叠在同一张图上。

三条纪律：**`D` 是标签而不是奖励**，奖励仍由胜负与漏怪给出，否则模型会去刷难度；**解析式用于设计、模拟用于验收**，解析与实测在中段有约 2pp 偏差（数值卷 01），报告的胜负须来自实跑；**参数冻结才有可比性**，`B_ref = 158`、`λ0 = 1.35`、`γ = 3`、`cap = 3` 一经改动即等于重新定义难度（数值卷 04）。

## 七、塔防 AI 实验最小可行协议

下表规定接口而非算法。

| 维度 | 最小要求 |
| --- | --- |
| 任务 | 单关或固定关卡链上的序列决策，明确属于三类任务之一 |
| 观测 | 波次构成、已漏怪数、能量与槽位占用；结构化观测优先 |
| 动作 | 有限动作集＝（槽位 × 塔型）×（放／升级／拆除／技能／等待），非法动作须屏蔽 |
| 奖励 | 主奖励只由胜负与漏怪（`< cap`）给出，塑形项须单列并做消融 |
| 评测指标 | 胜率、平均漏怪数、种子间方差、`D`–胜率曲线（同 `D` 带对比基线）、每局动作数 |
| 复现要求 | 固定种子与卡组快照、塔表与常量版本、报告 `B/P/D` 与局数；样本量 5000（本地）／20000（验收） |

核心在最后一行：可信度不来自算法多新，而来自**任何人都能重跑出同一条 `D`–胜率曲线**。
