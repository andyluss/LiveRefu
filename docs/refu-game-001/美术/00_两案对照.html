001 · 复古未来

目录：美术设定001/（11 篇）

002 · 千禧透明美学

另类提案：未来刚拆封的那一天。六族全部透明或半透明，光与水是材料。
目录：美术设定002/（13 篇）· 风格图：风格图/（6 张）

成本与复用

资源能否共用
模型拓扑与动画骨架可以（同一套骨骼，两套材质）
卡面版式（九字段布局）可以（改材质不改版式）
材质库与光照贴图不可以（锈蚀金属 vs 透明折射）
特效库与粒子不可以（沙尘火星 vs 水光闪粉）
UI 图标形状语言部分（语义共用，描边与高光重做）

结论：002 若采纳应为"换材质与光的整体重制"，不是叠滤镜。若只做一族试点，建议 齿轮帮——最贴千禧主题、面积最小、最易验证。

选型建议

选 001：需要与工作区既有 复古未来知识体系 联动、与长篇《节点之海》的叙事质感一致（沙尘、纸图、黄铜）。

选 002：需要年轻向、屏幕感强、社交平台传播友好的辨识度；透明体质天然适配"模块换装看得见、进化枝看得见、共鸣看得见"这套机制表达。

混合：以 001 为产品基底，把 002 收窄为"特定赛季／事件／活动皮肤"（例如限时透明主题），用同一套骨骼切两套材质，成本可控且能验证市场反应。

不可碰的红线（两案共同）

全部数值（B 预算、难度比 D、能量曲线、卡费、护盾 120、腐蚀每层 +3%、BOSS 2200/护甲 15/50% 阶段技、漏怪上限 3）、全部机制（模块换装／进化枝／共鸣／羁绊九条／挑战卡难度分／永久修饰五项／远征八节点）、全部名称（族名、36 张卡名与 card_id、六张地图编号）、界面骨架（竖屏 60/40、三层信息、手势表、≥9mm 触控）。
