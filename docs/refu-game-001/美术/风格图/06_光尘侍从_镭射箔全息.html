配方

L1 体表膜镭射箔：雾度≈0、全透强偏光；角度色青→紫 #5FF3E0→#B26BFF
L2 内芯光白线与小灯泡 #7CF9FF，广播时脉冲亮起
L3 界面层刻字面 #F4F6F3：箔透明、字不透明（第一原则）
L4 边缘光银色切边 1–2 px，偏青
主光性格扫：主光 + 15° 掠射灯扫箔面，靠角度变化出内容
专属补光背光 0.20；环境反射压到 0.10
粒子闪粉 120（全案最高，仅交互与广播瞬间）
