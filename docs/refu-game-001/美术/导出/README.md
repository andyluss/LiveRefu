## 二、怎么再生成

```bash
# 2048px PNG
rsvg-convert -w 2048 源.svg -o 导出/2048/名字.png
# 矢量 PDF
rsvg-convert -f pdf 源.svg -o 导出/PDF/名字.pdf
# 指定高度（等价于 2 倍图）
rsvg-convert -h 2048 源.svg -o 名字@2x.png
```

本机已装 `rsvg-convert`（librsvg）。仓库里**只把 SVG 当源文件**，PNG/PDF 是生成物——改图请改 SVG 后重跑上面两条命令，不要直接改位图。
