# 09 · 生产管线与审查清单

本文件是美术交付的流程与验收口径。一张图在过完第四节八条清单之前不算完成，风格探索阶段的草稿不进入正式产线。

## 一、风格卡流程

风格卡是全部美术资源的唯一源头，先锁定再分支，避免各支各画一套。

| 步骤 | 产出 | 负责 | 完成判据 |
| --- | --- | --- | --- |
| 出风格卡 | 主视觉 1 张、三族色板各 5 色、敌方色带、材质 6 件、字号层级 | 主美术 | 三族与敌方可灰度区分 |
| 锁定 | 色板与材质配方冻结 | 主美术加策划 | 数值可读性抽检通过 |
| 分支 | UI、单位、场景、特效四支并行 | 各支主美 | 每支产出对照卡 1 张 |
| 回灌 | 对照卡并入风格卡 | 主美术 | 风格卡版本 +0.1 |
| 冻结 | 风格卡 v1.0 | 主美术 | 后续改动走变更单 |

分支期间的主色、材质与字号不得各支自定。三族命名仍是 v0.1 占位（见 [03](../../03_种族总览.md)），族徽重绘不影响规则层，这是风格卡可以放心迭代的前提。

## 二、资源命名与分层规范

命名规则为 `族_类型_序号_部件_变体_版本`，例如 `ANV_T01_turret_body_v03`。类型代号固定：塔卡 T、支援 M、技能 S、修饰 X、地图 MAP、敌人 ENM、界面 UI、特效 FX。文件名只用半角字母、数字与下划线，不写中文与空格，版本号两位。

| 层 | 后缀 | 内容 |
| --- | --- | --- |
| 基础色 | `_alb` | 固有色，不含光照 |
| 法线 | `_nrm` | 表面起伏与铆钉 |
| 自发光 | `_emi` | 指示灯、CRT 与霓虹 |
| 遮罩 | `_msk` | 磨损、掉漆、发光区域 |

图集分卡面、单位、特效三本，各配一份索引文件，索引里记录每张图的 card_id，便于策划改数值时反查。发光元素单独走 `_emi`，是为了把后处理的强度集中管理，也方便低端机直接关掉一层。

## 三、交付尺寸与格式

| 类别 | 尺寸 | 格式 | 备注 |
| --- | --- | --- | --- |
| 卡面插画 | 1024×1536 | PNG sRGB | 2:3，缩略图 512 |
| 卡面框体 | 512×512 | PNG 九宫格 | 可拉伸不变形 |
| 单位精灵 | 单帧 512×512 | PNG 序列或图集 | 8–12 帧 |
| 场景地块 | 256×256 | PNG 可平铺 | 2 px 出血 |
| 地图卡俯视图 | 2048×1152 | PNG | 路径与塔位分层 |
| 特效序列 | 图集 1024×1024 | PNG 图集 | 单帧 ≤256 |
| UI 图标 | 96×96 | SVG 或 PNG | 双倍图 |
| 立绘海报 | 2048×1152 | PNG | 宣发用 |

体积约束：单张卡面不超过 1.5 MB，单本图集不超过 4 MB，首包总量不超过 120 MB。移动端优先，体积超限时先压插画色深，再压特效帧数，最后才考虑降分辨率。

## 四、八条审查清单

每张交付物必过，任一条不通过即打回，不打折通过。

| 编号 | 项 | 判据 |
| --- | --- | --- |
| 1 | 族辨识度 | 遮住族徽后 3 秒内仍能认出所属族 |
| 2 | 剪影可读性 | 纯黑剪影下可区分六种敌方原型 |
| 3 | 数值不被遮挡 | 卡面 3 数字与 HUD 无特效或后处理覆盖 |
| 4 | 色弱 | 灰度化后仍可靠形状、图标与明度区分 |
| 5 | 移动端最小字号 | 正文 ≥12 dp、卡面主数值 ≥24 dp、HUD ≥14 dp |
| 6 | 低端机性能 | 单帧 draw call ≤60、粒子 ≤200、贴图 ≤2048 |
| 7 | 与策划数值一致 | 卡面数字逐项对照卡表与数值文件 |
| 8 | 无 emoji 无侵权 | 素材自绘或已授权，字体可商用 |

第 7 条由策划与美术双签，第 6 条由主程序提供实测数据，其余由主美术判定。第 3 与第 5 条在低端机档位上同样执行，降级方案不得触碰这两条。

## 五、与策划文档的同步机制

数值只引用不改，但数值一变，美术必须回头改对应文件。下表是固定的反查关系，改数值只改一边视为未完成。

| 策划变更 | 受影响美术文件 | 动作 |
| --- | --- | --- |
| 卡费用或数值块 | 卡面数字层与卡面图集 | 重导出卡面，图集版本 +1 |
| 敌人数值与原型 | 07 号剪影与配色表 | 复核体型比例与底座环 |
| 羁绊阈值 | 06 号特效触发档与 05 号羁绊进度 | 改档位与进度点 |
| 能量上限与起始值 | 05 号 HUD 能量条刻度 | 改刻痕与量程 |
| 挑战卡难度分 | 06 号盖章动画等级与 05 号局前界面 | 改印章等级 |
| 远征节点数 | 05 号八格节点表与 07 号重影层数 | 改格子数与层数 |
| 新增卡 | 卡面插画、卡框、图标、特效、剪影 | 走风格卡分支 |

每次同步在根 [`CHANGELOG.md`](../../../../CHANGELOG.md) 记一行，并更新本目录文件的版本号（v0.x 草稿，v1.0 冻结）。冻结后的改动必须说明原因、影响范围与重导出清单，避免出现卡面数字与实际数值长期不一致这种最难查的问题。
