# 06 · 动效与特效

> 卡面：用途＝动效时长、逐机制特效与安全边界 ｜ 依赖：[03_种族总览](../../03_种族总览.md)、[04_塔防核心战斗](../../04_塔防核心战斗.md)、[16_卡表_星辉议会核心12卡](../../16_卡表_星辉议会核心12卡.md) ｜ 状态：v0.1 · 2026-09-15

动效是规则的回执，不是装饰。玩家造成的变化必须有回执，玩家没有造成的变化不得抢注意力。本文件定下时长、预算与安全三条底线，逐机制特效以此为准。

## 一、动效原则

| 原则 | 口径 |
| --- | --- |
| 时长 | 常规反馈 150–240 ms，机制反馈 240–400 ms |
| 例外 | 结构性事件（开波、BOSS 变招、结算）400–600 ms，不阻断输入 |
| 触发源 | 只解释玩家操作、击杀与波次事件，自然行走与自然回能不做特效 |
| 层级 | 特效永远在卡面与 HUD 之下，不覆盖卡面数字与 HUD 三条信息 |
| 叠层 | 同屏同色系特效不超过 3 层，避免糊成一片 |
| 减动 | 尊重 prefers-reduced-motion，退化为淡入淡出与跳字 |

减动模式下屏幕震动归零，扫描线与噪点减半，位移改为透明度变化，判定与数值完全不变。这是可用性开关，不随低端机自动开启。

## 二、局内机制特效

| 机制 | 触发 | 特效 | 时长 |
| --- | --- | --- | --- |
| 模块换装 | 局内替换修饰卡 | 旧模块弹出、新模块滑入卡匣，接口亮一次触点火花 | 320 ms |
| 进化枝 | 孵化巢累计产出 20 只 | 巢体鼓起、外壳裂成四瓣、母巢撑开，地面微微下陷 | 560 ms |
| 共鸣 | 相邻计数 ≥2 | 相邻塔之间拉起一条半透明音波链，链上浮点向右流动 | 280 ms |
| 共鸣高档 | 相邻计数 ≥4 | 同一链条加粗并转为金色，仅提升表现层级，不新增数值 | 280 ms |
| 破盾反噬 | 护盾破碎 | 裂面碎片沿链逐跳传导，每跳 8 ms，落点闪一次 | 240 ms |
| 漏怪 | 敌人抵达基地 | 基地灯条灭一格并留焦痕，红色脉冲沿路径逆推回出生点 | 400 ms |

模块换装必须画出黄铜触点，让替换读起来是插拔而不是变身。进化枝只在第一次进化播完整版，同局后续缩短为 280 ms。共鸣链只画相邻关系，不画全场连线，否则塔多成蛛网。破盾反噬沿护盾链与共鸣链传导，伤害、攻速与能量口径见 [16](../../16_卡表_星辉议会核心12卡.md) 与 [14](../../14_卡表_铁砧联邦核心12卡.md)。漏怪逆推脉冲让玩家看见它从哪来，终点必须落在出生点。

## 三、羁绊触发的九种特效

九条羁绊同标签阈值触发，特效做成通用骨架加族色皮肤，避免九套独立资源。

| 羁绊 | 阈值 | 触发视觉 | 时长 |
| --- | --- | --- | --- |
| 火力网 | 3 弹药 | 路径上方织出黄铜弹道网，节点依次点亮 | 300 ms |
| 加固阵列 | 2 工事 | 工事外圈叠铆钉护板，地面浮出六角格 | 240 ms |
| 后勤链 | 2 维修 | 输送线连向受损塔，末端出扳手图标 | 400 ms |
| 酸蚀 | 3 腐蚀 | 路径渗出酸绿液面，气泡沿路径推进 | 320 ms |
| 巢群 | 2 孵化 | 巢口同时吐出新卵，卵壳弹跳一次 | 280 ms |
| 缠缚 | 2 拦截 | 地面长出粘网，减速敌人脚踝缠线 | 300 ms |
| 护盾链 | 3 护盾 | 三层六角护盾面依次闭合 | 360 ms |
| 谐振 | 2 共鸣 | 共鸣区边界扩散一圈音波纹 | 280 ms |
| 节能 | 2 能量 | 手牌费用数字削去一角并下跳一格 | 200 ms |

## 四、局前与阶段动画

| 事件 | 表现 | 约束 |
| --- | --- | --- |
| 挑战卡盖章 | 黄铜印章落下，印油沿纸纹扩散，卡角卷起 | 每张 320 ms，最多 3 张 |
| 永久修饰三选一 | 三张卡从卡座弹出，选中贴纸落盒，落选退回 | 总时长 ≤900 ms |
| BOSS 阶段技 | 血量降到 50% 时裂甲，露出核心并换一套动作 | 一次性 600 ms，之后形态常驻 |

挑战卡局前自选 1–3 张、等级合计 ≤6（见 [13](../../13_卡表_挑战卡样例.md)），难度分合计上限 15（见 [数值/05](../../数值/05_能量与关卡预算曲线.md)）。盖章是不可撤销的宣告，动画结束前不允许开战，给玩家反悔窗口。永久修饰三选一来自远征规则卡（见 [23](../../23_规则卡组_Roguelike远征.md)），三张卡的弹出口径必须一致，选中反馈要重于落选反馈。BOSS 阶段技的形态变化见 07 号文件，动效这边只负责"裂甲"这一下。

## 五、粒子预算与同时特效上限

预算是硬约束：宁可少一个火花，不可掉一帧。

| 档位 | 单机制粒子 | 同屏粒子总量 | 同屏特效数 |
| --- | --- | --- | --- |
| 高端 | ≤120 | ≤800 | ≤12 |
| 中端 | ≤80 | ≤450 | ≤8 |
| 低端 | ≤40 | ≤200 | ≤4 |

超预算时按固定顺序降级：先减重复火花，再减环境粒子，最后才减机制信号特效。羁绊触发、进化、护盾破碎与漏怪四类信号特效优先保留，它们承载规则信息。BOSS 阶段技可瞬时借用 200 粒子，但须在 800 ms 内归还。

## 六、色弱与光敏安全

| 风险 | 上限 | 兜底 |
| --- | --- | --- |
| 闪烁频率 | ≤3 次／秒 | 高频警示改用常亮加呼吸 |
| 单次闪烁面积 | ≤屏幕 25% | 禁止全屏白闪 |
| 亮度跳变 | ≤10% | 强对比改用色相变化 |
| 纯色相编码 | 0 处 | 一律叠加形状、图标或明度差 |

色弱安全的核心是永不单靠色相传递信息。三族色板与敌方色带在灰度化后必须仍有明度差（见 07 号文件），羁绊特效除族色外还要带各自图形母题。光敏安全照通行口径执行，不出现大面积高对比闪烁；设置提供"减弱闪烁"开关，与 prefers-reduced-motion 独立。
