# 05 · 卡组与组合

> 卡面：用途＝局前组卡 + 局内调度 ｜ 依赖：[02](02_卡片规则系统.md)、[03_种族总览](03_种族总览.md) ｜ 状态：v0.1 · 2026-09-14

## 一、局前：卡组（Deck）

建议基线（可调）：**20 张**

| 分区 | 张数 | 说明 |
| --- | --- | --- |
| 核心区 | 12 | 主族塔卡/单位卡/技能卡 |
| 支援区 | 4 | 从族支援卡（D4），不超过 4 张以保主族辨识度 |
| 修饰区 | 4 | 修饰卡、规则外挂、中立项 |

组卡规则：同名牌最多 2 张；中立卡 ≤ 20%；卡组必须包含至少 2 个不同标签以触发羁绊。

## 二、局内：调度（Draw）

- 每波结束获得 1 调度点，**三选一**从卡组抽牌（轻随机）；
- 抽到的卡进入手牌区，可立即使用或保留；
- 可开启**公平模式**（关闭随机调度，改为固定轮转），用于周常与异步 PvP。

## 三、组合示例（示范"融合感"）

1. **铁砧 · 火力网**：炮塔卡 + 齿轮帮"弹药搬运" + 修饰卡"交叉火力" → 触发连锁：每次击杀返还能量，形成滚雪球布防；
2. **涌潮 · 腐蚀潮**：孢子侍从"菌毯扩张" + 虫群"孵化加速" + 事件卡"酸雨" → 羁绊（3 张"腐蚀"标签）使路径持续掉血。

## 四、平衡原则

- 组合强度上限由"触发条件难度"决定：条件越具体，效果越强；
- 任何组合都必须能被至少一种敌方波次卡或事件卡针对（避免无解）；
- 改一张卡的数值，不得迫使其他卡改数值（[02](02_卡片规则系统.md) 五律之四）。

## 五、卡组界面（小屏）

一屏看全 20 张：横向滑动的卡列 + 顶部种族/标签筛选；长按读卡、拖拽换位、双击替换（见 [07](07_移动端与界面.md)）。
