# 第 28 章 加压卡带

> 卷四《三族同台》 ｜ 第 28 章 ｜ 2026-09-14

卡带是钉在站台口的木牌上的。

木牌立在候车厅外面那根歪柱子旁边，风从轨道那头灌进来，牌子上那张纸的一角一直在翻。纸是议会的纸，白得跟沙面上别的东西都不像一家人。上面两行字，第一行是番号，第二行是处置。

谢临把两行都看完了。处置写得比番号短，抗令不撤，罚以三张挑战卡，本波由该哨全员执行，未通过者编制另议。

「另议是什么意思。」柯岭问。

「意思是撤掉。」

卡带挂在木牌侧面的铁钩上。三块合金板，一根黄铜丝串着，板的边上有编号槽，槽里压着封条的漆。她认得这种做法，是军需口的手艺，把三张卡钉成一条，谁要戴就得整条戴，拆一张，封条就断。

白手套的老调度官站在牌子底下，手里没有茶杯。铁砧那侧的军需官也在，袖口那排铜扣还是擦得发亮的。

「议会的章在封条上。」老调度官说，「空袭那一晚的 B 到二百四，三族都在这张图上挨打。丁四哨在那一晚没有按联合命令后撤。它让开位置，合流点就会空一格，那一格是整条外沿的喉咙。它守住了，这是战果。它没撤，这是抗令。战果归战果，抗令归抗令。」

「所以你们给它一条带子。」

「上一回在这张台子上，四行纸我们只签了三行。」老调度官说，「我说过，议会的章不在我手上。这一回它自己来了。」

谢临没有立刻去碰那三块板。她先看封条压着的数。三张卡的难度分写在板背，书记用绿笔描过一遍，五、四、三。合起来十二。单局难度分上限是十五，这条带子离上限只差三分。

「挑得挺准。」柯岭在旁边小声说，「三张都是这张图上钉得住的。」

「不是准，是算过的。」谢临说，「双流只认双入口，双岔要塞是中立图里唯一一张双入口，换一张图，这条带子就废掉三分之一。他们不是要它难，是要它看上去正当。带子钉得住，判决就站得住。」

军需官没有接话。他把那张纸翘起来的一角按回钉子底下。

「什么时候打。」

「今晚的波次。」

「丁四哨的人知道吗。」

「名册已经报上去了。」军需官说，「全哨执行，一个不落。」

她把手套摘下来，塞进口袋，走到牌子跟前。

---

丁四哨的人在站台下站成两排。有人还背着卡匣箱，箱角磕得发白。哨长在最前面，帽檐压得低，看见她过来，先把箱子放下了。

「我叫谢临，混编协调调度官。」她说，「这波归我排。这条带子我先念一遍，念完，你们自己决定跟不跟。」

她从钩子上把卡带摘下来。封条没断，整条还是完整的。她把它摊在长椅上，三块合金板并排，板面朝上，绿字的蚀刻在浅光里发暗。

「第一张，双流。」她说，「出生点加一，两路同时开波。难度分是五。它只对双入口的图生效，别的图上钉不上去。今晚这张是双岔要塞，两个入口，中段合流，它钉得上去。你们守的是一个入口，可敌人从另一个入口进来的时候，支援位也得跟着动。两路一起开着的那几波，火力要分到两个口上，折算按一点四乘上去，只算同时开着的那几波。掉落加两成半。」

有人抬头看那三块板。

「第二张，断供。」她说，「能量自然增长减两成。起始能量还是十，本来一秒回一点，戴上它，一秒不到一点。波间奖励五点不动，击杀返还也不动，小兵一只一点，装甲两点，精英三点。听清楚，它不是不给你能量，是让你每一秒都要算。难度分四，掉落加两成。」

「第三张，封锁。」她说，「技能卡全部禁用。应急修复、过载射击、时空缓滞，这一局从卡匣里拿出来，放回箱子里去。手上只剩塔、支援和修饰。难度分三，掉落加一成半。」

三张念完，她把板背翻过来给他们看。绿笔的字一个挨着一个，描过的地方比别处亮。

「三张加起来，难度分十二。」她说，「结算的掉落系数是一加零点零五乘十二，一点六。评级加成是十二乘五，六成。上限是二点零，你们这条带子到不了上限，可也够重。」

她停了一下。

「还有一条。带挑战卡的关，D 带落在一点二五到一点四五之间，胜率二成五到五成。这是模拟跑出来的带子，不是谁拍脑袋写的。也就是说，你们今晚有至少一半的机会打不过。」

站台下没有人说话。风把牌子上的纸吹得响了一下。

「按规则，挑战卡是局前自选。」她说，「自选的意思是，选的人只能是打这一局的人。这条带子现在钉在木牌上，选它的不是你们。」

哨长开口了。他的声音比谢临想的要低。

「名册发下来的时候，上面只写了罚卡带三张。哪三张，多少分，怎么算，我们刚才才知道。」

「我知道。」她说，「写清楚就没人肯站这两排。所以念卡这件事，得由我来做。」

---

她伸手去解铁钩上的封条。

军需官往前一步。「谢调度官。」

「封条我来断。」她说。

「你要替丁四哨戴。」

「我带这一波。」她把封条挑开，黄铜丝在钩子上刮出一声，很短。三块板落到她掌心里，比看上去沉。她把卡带扣到自己肩线上的钩环里，正好挂在心口这一侧，板边贴着外套，走一步就蹭一下。

老调度官看着她扣完。

「你扣上它，账就换人了。」他说，「议会纸上前一行写的还是丁四哨。打不过，追责追的是你。你替他们戴，就是替他们担。」

「纸上前一行可以改。」

「改不了。章已经盖了。」

「那就让它错一次，错在我账上。」

她转过去，对着站台下那两排人。

「难度如果不能由打的人自己选，卡带就变成刑具。」她说，「刑具不用算账，刑具只要有人挨着。这条带子本来是要你们挨的。现在我戴着，名册还在你们自己手上。愿意上的，把名字留下。不愿意的，把名字划掉，我这一页上记的是没跟，不是抗令。划掉的人今晚回自己宿舍，明早照常上工，我不写他一个字。」

哨长把帽子往上推了一寸。

「划掉的不算逃兵。」他说。

「不算。算我请的假。」

有人笑了一声，很短，笑完就没有了。长椅边上站着几个年轻的调度官，手都插在兜里，谁也不先动。柯岭把名册摊开，压在一块废枕木上，铅笔搁在旁边。

---

她走回长椅前，把三块合金板又翻了一次，让绿字朝上。她开始念第二遍。

这一遍她念得更慢。双流，五。断供，四。封锁，三。每念一张，她就说一遍这张卡考什么，考不出什么，以及它会把哪一格的火力拧干。念到断供的时候，她让人把卡匣箱打开，把能量表盘擦了一遍，让每个人自己去看那一秒一格是怎么走的。念到封锁的时候，她让拿技能卡的人把卡抽出来，一块一块摆在长椅上，摆完了数一遍，再收回去。

念完第三张，天已经暗到要看不清板上的字。灯柱上那截霓虹亮起来，亮一下，暗两下。

名册传了一圈。传回来的时候，柯岭低头看了很久。

「多了几笔。」他说。

「划掉的呢。」

「划掉四个。都划得很轻，笔尖只走了一次。」他把名册转过来给她看。

她没去数剩下的。她看见最后一行格子里多了一个名字，字写得小，挨着格线。

「这是谁。」

「管登记的那个。」柯岭说，「上个月才来，肩线还新着。他今天不管登记，站在第二排最边上。」

她走过去。那个年轻人比她矮半个头，手里还捏着铅笔，笔尖上有一点铅灰。

「你为什么签。」

他抬了一下眼，很快又低下去。

「因为你念了每一张。」他说。

她站在原地，没有马上答。霓虹又亮了一下，暗了两下。公频响起来，观测席报外沿那两处孢子云的位置，报得很平，最后说第二波的开波时间不变，说风从东边来。

她把名册拿过来，在第一行的番号底下添了自己的名字。铅笔走得很重，一笔就把那格填满了。

名册上原本只有一支哨的名字，现在多了一个不属于任何哨的人。
