## 约定

- 每个概念一个目录；`概念设计.md` 是主文档，`*可视化.html` 是离线可打开的辅助页；
- 概念阶段允许“未定/存疑”，但必须写明**核心隐喻、单局循环、玩家决策、失败方式**；
- 概念不进入 `docs/` 正式知识库卷，也不自动进入 `games/`；立项后才迁入项目；
- 本目录受 R01/R03 约束：相对链接必须可解析。
- 现有 `*可视化.html` / `游戏演示.html` 是概念阶段的既有原型页，尚未统一到 R-016 三态；实质修改或重新生成时按 R-016 补齐。
