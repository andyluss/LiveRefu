07 怎么读这张图

三个视角，不用背概念。

先看传导

物理、平台、数据、接口……任何一层的选择，都会沿着依赖放大到产品和治理。

再看张力

架构不是找“最优解”，而是明确当前阶段愿意承担哪一组代价。

最后看复利

技术债、可靠性、组织负载都会随时间复利；早期的小选择，后期会变成大约束。

当提问器用

每次选型、发布、采购、招人，都回来问：哪一层被牺牲了？退出路径是什么？
