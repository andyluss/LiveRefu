# 07 · 生活层：健康、教育与家庭

> **一句话**：生活软件争夺的不是“功能时长”，而是**习惯、信任与注意力**；最成功的生活产品往往最安静。

## 一、这一层有什么

- **健康**：运动、睡眠、饮食、心理、慢病、医疗记录；
- **教育**：K12、语言、技能、考试、课程管理、学习工具；
- **家庭**：家务、账单、购物、家庭日程、家庭服务器、照片；
- **媒体**：音乐、播客、阅读、流媒体、创作；
- **个人财务**：预算、记账、保险、税务；
- **旅行/本地**：行程、地图、本地服务。

生活层的用户是个人/家庭，付费意愿分散、价格敏感、获客成本高；但一旦进入日常，留存极强。

## 二、经济结构：订阅疲劳与信任

- **订阅疲劳**：每个小需求都想按月收费，用户会合并/放弃；
- **平台依赖**：应用商店/社交/搜索决定获客；
- **隐私敏感**：健康/家庭/财务数据一旦泄露，信任不可恢复；
- **硬件/服务组合**：家庭服务器、健康设备、打印/课程可以形成更高客单；
- **AI 冲击**：通用助手可能吞掉“轻量记录/建议”，但深度工作流与信任仍在。

## 三、设计在哪里创造价值

1. **低摩擦记录**：一次点击/一句话/一张照片，而不是表单。
2. **可解释建议**：为什么给这个建议、依据是什么、何时该看医生/老师。
3. **家庭共享**：权限、隐私、孩子/老人模式。
4. **离线/降级**：网络不好/设备旧时仍可用。
5. **退出**：数据导出、设备迁移、账号删除。

> 生活产品最重要的设计不是“增加粘性”，而是**让用户在不需要时能离开**。

## 四、复古未来的角度

家庭生活里的旧技术——日历、账本、药盒、相册、收音机、厨房计时器——有数字产品常丢失的**触感与仪式**：

- 物理位置（放在哪）；
- 重复（每天/每周）；
- 声音/光线提示；
- 家庭共同可见；
- 可被继承/转交。

青橙的机会不是“把 App 做成旧家电”，而是把**仪式与共同照料**带回家庭软件，同时保留数字的可检索/可备份。

## 五、机会与反模式

**机会**：

- 家庭档案/照片/账单/维护的统一入口；
- 学习工作面（阅读/卡片/项目/作品集）；
- 健康记录 + 家庭共享（不做诊断）；
- 家庭服务器/媒体/备份；
- 本地优先的个人财务。

**反模式**：

- 用焦虑/连续打卡制造留存；
- 用 AI 诊断替代医生；
- 把家庭数据锁在订阅里；
- 用儿童/老人数据做增长。

## 六、给青橙的判断

生活层适合做**低摩擦、可共享、可退出**的基础工具，而不是“全能生活助手”。最优先：家庭档案/服务器、学习工作面、个人财务；它们能与知识层、资产层、交易层组合。

## 附：参照与可验证假设

**代表参照**：

- **Apple Health/Google Fit**：把多设备数据聚合；教训是“平台入口”能聚合数据，但隐私/互操作仍是问题。
- **Strava**：运动记录 + 社交；教训是“社区/挑战”能增强留存，也可能制造焦虑。
- **Khan Academy/Coursera**：教育内容 + 进度；教训是“课程结构/认证”比视频本身更重要。
- **Anki**：个人学习工具；教训是“可定制/可带走”能形成长期用户。
- **Nextcloud/Home Assistant**：家庭/自托管；教训是“数据主权 + 可扩展”能形成社区。

**可验证假设**：

- 家庭是否愿意为“照片/账单/维护的统一归档 + 可继承”付费？
- 学习工具是否愿意为“作品集/项目/反馈”付费，而不是为更多课程付费？

**一个反例**：用打卡/焦虑/排行榜制造留存，最后用户把产品当成压力源。
