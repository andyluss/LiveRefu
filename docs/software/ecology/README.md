## 四、写作原则

- **分层不是分类**：同一家公司可以横跨多层；层是“依赖与责任”的视角。
- **不写公司百科**：每层只保留解释结构必要的代表。
- **每个判断带代价**：增长、锁定、开源、合规都不是免费的。
- **复古未来不是限定词**：它只在第 10 篇集中处理；前九篇讨论真实软件经济。
- **面向行动**：每篇末尾给“设计含义 / 机会 / 反模式”。

> 这套文集是地图，不是终点。读完后，你应该能画出自己的“依赖图”，而不是记住更多名词。
