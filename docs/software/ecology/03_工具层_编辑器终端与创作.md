# 03 · 工具层：编辑器、终端与创作

> **一句话**：工具不是“功能集合”，而是**认知外骨骼**：它决定你看见什么、能改什么、愿意反复做什么。

## 一、这一层有什么

- **代码工具**：编辑器/IDE（VS Code、Zed、JetBrains、Cursor）、终端、版本控制、调试、构建、包管理；
- **设计工具**：Figma、Sketch、Affinity、Penpot、设计系统工具；
- **创作工具**：图像/视频/音频/3D、ArtCraft 类 AI 创作、素材库、字体/图标；
- **自动化**：脚本、CLI、工作流、插件、快捷指令；
- **协作层工具**：评审、标注、版本、交付。

工具层最接近“手工艺”：用户对延迟、手感、快捷键、视觉噪音极其敏感；迁移成本高，但一旦被爱上，付费与传播都强。

## 二、经济结构：工作台、插件与身份

- **工作台逻辑**：工具占据一天中的大块时间；用户不愿频繁切换。
- **插件生态**：核心小、扩展多；平台通过插件获得长尾，也把维护转嫁给社区。
- **身份认同**：编辑器/设计工具是“我是谁”的一部分；品牌与社区能形成忠诚。
- **开源替代**：Blender、Krita、Penpot、Zed 证明开源可以进入专业工作流，但需要长期投入。
- **AI 冲击**：生成能力快速商品化，价值从“生成”转向“工作流、资产、协作、信任”。

## 三、设计在哪里创造价值

1. **手感**：启动速度、输入延迟、滚动、缩放、快捷键；这些是工具的“触觉”。
2. **可逆**：撤销、版本、自动保存、恢复；让用户敢试。
3. **可组合**：命令面板、扩展、脚本、API；让用户把工具变成自己的。
4. **可读状态**：构建、同步、冲突、错误、资源占用；不要用 spinner 掩盖。
5. **可退出**：开放文件格式、导出、CLI、离线；用户不怕被锁。

> 工具的最高设计目标不是“功能多”，而是**让用户在忘记界面时仍在工作**。

## 四、Zed 与 ArtCraft 的启示

**Zed**：用性能、原生协作、GPU 渲染切进编辑器市场。它证明“成熟市场仍有体验缝隙”，但也提醒：编辑器是平台战，插件、语言服务、远程、企业支持缺一不可。

**ArtCraft 类创作工具**：把 AI 生成嵌入创作流程，降低“从想法到视觉”的门槛。它证明创作工具可以从“专业软件”转向“表达工具”，但风险是：

- 生成能力商品化，价格战；
- 风格/资产/授权难以管理；
- 社区模板会迅速同质化。

**机会不在“更强的生成”，而在“更可信的作者关系”**：风格卡、资产来源、版本、授权、协作、可导出。

## 五、复古未来的角度

工具是复古未来最容易“翻车”的地方：把界面做成旧电脑，只会降低效率。

真正可用的复古未来工具，应该借用旧工具的**约束智慧**：

- 终端的键盘优先与可组合；
- 仪表的单色高密度与告警分级；
- 档案的编号、版本、登记；
- 物理按钮的确认感与不可撤销性。

把这些变成现代工具的结构，而不是皮肤。

## 六、机会与反模式

**机会**：

- 垂直工作台（设计系统、世界创作、研究写作、维修）；
- 本地优先/离线工具 + 托管协作；
- 资产/授权/来源管理；
- 插件/模板市场；
- 培训、迁移、定制服务。

**反模式**：

- 用“AI 原生”当唯一差异；
- 用“开源”掩盖不完整的核心；
- 把插件生态当免费劳动力；
- 用“复古”降低可读性。

## 七、给青橙的判断

工具层是青橙最自然的方向，但必须选**垂直工作流**，不要做通用编辑器/通用生图。设计系统操作台、世界创作、研究写作、资产库，都是“工具 + 方法 + 服务”的组合。

## 附：参照与可验证假设

**代表参照**：

- **VS Code**：用开放扩展生态赢得长尾；教训是“平台 + 插件”比单点功能更强，但维护成本转移给社区。
- **Zed**：用性能/协作/原生体验切市场；教训是“成熟市场仍有手感缝隙”，但平台战需要长期投入。
- **Figma**：把协作放进设计工具，改变评审流程；教训是“协作不是附加功能，是工作流重写”。
- **Blender**：开源 + 社区 + 专业能力；教训是“开源可以进入专业工作流”，但需要基金会/商业支持。
- **ArtCraft 类工具**：把生成嵌入创作；教训是“降低门槛”能带来用户，但“资产/授权/风格一致性”才是留存。

**可验证假设**：

- 垂直工具（设计系统/世界创作/研究写作）的用户，是否愿意为“可导出 + 可协作 + 可审计”付订阅？
- 插件/模板市场是否能在不剥削社区的前提下形成正循环？

**一个反例**：做一个“功能齐全”的通用工具，但没有一个工作流做到最好；用户会回到平台默认。
