## 怎么读

- **想尽快有收入**：02 → 06 商业模式 → 90 天验证。
- **想做差异化产品**：03 → 10 美学层 → 资产/授权。
- **想先自用、长期做**：04 → 02 数据层 → 07 生活层。
- **判断要不要做**：每篇末尾的“停止条件”比“愿景”更重要。

> 三篇都假设你是**产品设计开发者**：能设计、能写前端/全栈、愿意做服务，不假设你有销售团队或融资。
