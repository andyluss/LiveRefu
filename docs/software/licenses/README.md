# 开源协议文集 · 从 MIT 到 AGPL，再到源可用

> **一句话**：许可不是“法律附件”，而是**产品的社会契约**：谁能用、谁能改、谁能卖、谁必须开源、谁承担专利/商标风险。
> 建立：2026-10-27 ｜ 状态：v0.1 ｜ 面向：独立开发者、小团队、开源产品负责人。
> **不是法律意见**：本文是产品/工程决策材料；正式发布前请让律师审阅。

## 一、先给结论

- **开源 ≠ 免费 ≠ 没有商业模型**。许可决定“权利边界”，商业模型决定“谁付钱”。
- **宽松许可**（MIT/Apache-2.0/BSD）适合“最大化采用”；**著佐权**（GPL/AGPL）适合“保护共同体的改写权”；**源可用**（BUSL/Elastic/FSL）不是开源，适合“先保护商业，再择机开放”。
- **LiveDSO 已选 A**：Apache-2.0 核心 + 商业托管/团队/审计；贡献者政策 DCO 1.1。见 [08_LiveDSO 许可选项](08_LiveDSO许可选项.md)。
- **专利/商标/数据/AI** 是许可之外的独立问题；不要以为选了 MIT 就“什么都授权了”。

## 二、许可地图（速查）

| SPDX | 类型 | 允许商用 | 衍生作品 | 专利 | 网络服务（SaaS） | 主要义务 |
| --- | --- | --- | --- | --- | --- | --- |
| MIT | 宽松 | 是 | 可闭源 | 无明示 | 无特殊 | 保留版权/许可声明 |
| Apache-2.0 | 宽松 | 是 | 可闭源 | **明示** | 无特殊 | 保留声明/NOTICE；专利终止条款 |
| BSD-2/3 | 宽松 | 是 | 可闭源 | 无明示 | 无特殊 | 保留版权/许可；3-clause 禁止背书 |
| MPL-2.0 | 弱著佐权 | 是 | 文件级开源 | 明示 | 无特殊 | 修改的 MPL 文件需开源 |
| LGPL-2.1/3 | 弱著佐权 | 是 | 可闭源（动态链接） | 有 | 无特殊 | 修改库需开源；允许链接 |
| GPL-2.0/3.0 | 强著佐权 | 是 | 分发需开源 | 有 | 通常不触发（分发才触发） | 提供源码/许可 |
| AGPL-3.0 | 强著佐权 | 是 | 分发/网络服务需开源 | 有 | **触发** | 网络用户可获取源码 |
| BUSL-1.1 | 源可用 | 通常有限制 | 受限 | 看具体 | 受限 | 一定期限后转开源 |
| Elastic-2.0 | 源可用 | 受限 | 受限 | 看具体 | 受限 | 不能提供竞争性服务 |
| SSPL-1.0 | 源可用 | 受限 | 受限 | 看具体 | 受限 | 提供服务需开源整个栈（争议大） |
| FSL | 源可用 | 受限 | 受限 | 看具体 | 受限 | 2 年后转 MIT/Apache |

> 表中“允许商用”是概括，不替代全文；不同版本/例外条款会改变结论。
