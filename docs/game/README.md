## 怎么用

- 先读文章，建立整体框架；
- 再打开可视化，用滑杆和预设观察“同一套系统在不同项目里如何被拉向不同方向”；
- 最后用十问检查表回到自己的项目，找短板，而不是继续堆内容。

可视化里的数值是启发式示例，不是评分标准，也不代表某一款具体游戏。
