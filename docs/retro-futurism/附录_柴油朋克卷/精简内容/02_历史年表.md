# 柴油朋克 · 历史年表

> 关键词：编年史；真实战间期；后世回望；命名
>
> 摘要：柴油朋克的历史必须分两栏读：A 栏是**真实战间期的未来展演**（第一序档案，细节见主卷 07），B 栏是**后世的回望与虚构**（柴油朋克本体）。本篇双栏对照。

---

## A 栏：真实战间期（第一序档案）

| 约时间 | 事件 |
| --- | --- |
| 1920s—30s | 装饰艺术摩天楼与纽约天际线（洛克菲勒中心等，主卷 06/07） |
| 1936—37 | 兴登堡号飞艇跨大西洋客运及其 1937 年空难 |
| 1939 | 泛美"快帆"水上飞机越洋客运（波音 314 一类）；1939 纽约世博会"明日世界"与 Futurama 展（主卷 07） |
| 1930s—40s | 流线型设计（火车/汽车/家电）进入量产；连环画冒险英雄（巴克·罗杰斯、飞侠哥顿——后者更偏太空，见主卷 07） |

## B 栏：后世回望（柴油朋克本体）

| 约时间 | 事件 | 意义 |
| --- | --- | --- |
| 1980s—90s | 回望萌芽：火箭人漫画（约 1982）与电影（1991）、《夺宝奇兵》系列（1981 起，冒险母本） | 战间冒险美学的"第二春" |
| 1992 | 《红猪》（宫崎骏）：战间期意大利航空浪漫 | 动画对柴油纪的致敬 |
| 2000 | 游戏《赤色天空》（Crimson Skies） | 飞艇空战世界观的成型作 |
| 约 2001 | "dieselpunk"术语出现 | 追溯命名（01 篇） |
| 2004 | 电影《天空上尉与明日世界》 | 柴油朋克影像的代表作（第二序仿作典型） |
| 2012 | 电影《钢铁苍穹》（Iron Sky）：月球纳粹戏仿 | 法西斯美学的黑色后设（04 篇） |
| 2000s—2010s | Weird War（怪战）题材（纳粹科技想象）在游戏/影视中流行（泛化） | "酷法西斯"争论现场 |

## 读法

双栏对照可见：A 栏（真实未来展演）与 B 栏（柴油朋克虚构）相隔约 60—80 年且图像高度同源——这正是 00 对读篇所说的"档案与虚构竞速"：今天的柴油朋克，几乎是在给昨天的"明日世界"做翻拍。
