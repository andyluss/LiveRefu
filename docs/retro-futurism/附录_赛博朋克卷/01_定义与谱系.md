# 赛博朋克 · 定义与谱系

> 关键词：赛博朋克；Cyberpunk；高科技低生活；命名史；后赛博朋克
>
> 摘要：本篇给出赛博朋克的定义与命名考据（布鲁斯·贝斯克 1983 年短篇用词 → 编辑加德纳·多佐伊斯推广 → 吉布森《神经漫游者》1984 立标 → 斯特林《镜影》1986 编派），并以边界表厘清它与蒸汽朋克、磁带未来主义、生物朋克、后赛博朋克的关系。

---

## 一、定义

**赛博朋克（Cyberpunk）**：1980 年代成型的科幻文类与美学，核心命题常被概括为"**高科技、低生活（high tech, low life）**"——信息技术与义体越先进，城市与个体越腐坏。词源上 "cyber" 取自控制论（cybernetics，人与机器的接缝），"punk" 挪用摇滚的反叛姿态。与 1960 年代太空乐观（主卷 09）相对，它是"反未来主义"的未来：技术不带来解放，只带来新的阶层鸿沟。

## 二、命名史考据

| 时间 | 事件 | 说明 |
| --- | --- | --- |
| 1983 | 布鲁斯·贝斯克（Bruce Bethke）短篇《Cyberpunk》刊出 | 首次使用该词（指黑客少年，一说 1980 年写成、1983 年发表，存疑降档） |
| 约 1984 | 编辑加德纳·多佐伊斯（Gardner Dozois）在书评中推广该词 | 从短篇标题变成运动标签（精确年份诸说不一） |
| 1984 | 吉布森《神经漫游者》（*Neuromancer*）出版 | **立标文本**：雨城大都会、义体、赛博空间（cyberspace，吉布森造词，"共识性幻觉"） |
| 1986 | 斯特林（Bruce Sterling）编《镜影》（*Mirrorshades*）及序言 | 把散兵游勇编成"运动"，序言有纲领性质 |

注意："赛博朋克"一词的诞生史没有单一权威版本，上述为通行叙事，细节按"一般认为/存疑"处理（主卷 15 赛博篇同此口径）。

## 三、谱系位置：源头与诸分支

赛博朋克是全部"××朋克"的**词源祖先**（详见主卷 12 谱系篇）；它自己也长出了分支：

| 相邻概念 | 关系 |
| --- | --- |
| 蒸汽朋克（主卷 13） | 反方向的后裔：把"反叛"换成"复魅"，把近未来换成维多利亚 |
| 磁带未来主义（主卷 14） | 共享 80 年代技术底座（CRT/键盘/磁带），但氛围温暖、办公室化——对照表见 03 美学篇 |
| 生物朋克（附录_生物朋克卷） | 把"技术"从硅件换成湿件（基因/生物改造）的衍生系 |
| 后赛博朋克（post-cyberpunk） | 1990 年代末的温和转向：技术不再必然等于压迫，主角常为体制内专家（相关"宣言"约 1998 年，存疑） |
| 赛博庞克/cyberpunk 的亚洲接受 | 日本（攻壳、Akira）与美国赛博朋克互为镜像（详见 05 作品篇） |
