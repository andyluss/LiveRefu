# 05 · 作品与媒介

> 关键词：先声作品；能力展示；游戏；维修玩法；机构叙事
>
> 摘要：本篇按「文学—影像—游戏—设计档案」四条媒介线整理可归入 NASA朋克谱系的作品，并对六部关键样本做拆解：它们分别示范了「机构叙事」「用过的未来」「能力展示」「维修劳动」「命名后的主题公园化」「叙事模拟」六种路径。文末给出一张按四条判据打分的对照表，供创作者定位自己的项目。

## 一、文学：工程作为情节

NASA朋克的文学源头不是太空歌剧，而是**工程叙事**：问题有明确成因，解决靠知识、资源与程序。

| 作品 | 年份 | 与 NASA朋克的关系 |
| --- | --- | --- |
| 汤姆·沃尔夫《太空先锋》（*The Right Stuff*） | 1979 | 纪实文学，把宇航员还原成有缺陷的岗位人；奠定「机构里的人格」这一主题 |
| 安迪·威尔《火星救援》（*The Martian*） | 2011 | 极致的「用工程解决问题」；NASA 作为远程机构在场；能力展示的原型 |
| 玛丽·罗比内特·科瓦尔《计算之星》（*The Calculating Stars*） | 2018 | 另类航天史，把性别与种族政治放进 NASA 机构内部；对「谁被允许上天」的直接回应 |
| 玛格特·李·谢特利《隐藏人物》（*Hidden Figures*） | 2016 | 纪实，揭示计算员、后勤与被排除者的劳动；NASA朋克「隐形劳动」主题的基石 |
| 安迪·威尔《挽救计划》（*Project Hail Mary*） | 2021 | 工程乐观 + 孤独岗位；更偏太空冒险，但保留了「用检查单活命」的语法 |

文学线的一个共同点：**冲突不是「人类 vs 外星人」，而是「人 vs 问题」**。这也是 NASA朋克改编成游戏时最自然的接口——问题可以被拆成资源、时间与流程。

## 二、影像：从白盒到控制室

| 作品 | 年份 | 定位 |
| --- | --- | --- |
| 《2001 太空漫游》 | 1968 | 先声：白盒空间、清晰标识、极简装饰；NASA朋克视觉的祖型 |
| 《静默奔跑》 | 1972 | 先声：生态舱与孤独岗位；「一个人的工作」 |
| 《异形》 | 1979 | 先声/反面：用过的未来、工业管线、船员劳动；机构被替换成公司 |
| 《太空先锋》 | 1983 | 把「选拔」与「表演」写进航天叙事 |
| 《阿波罗 13 号》 | 1995 | 地面团队成为主角；检查单救人的经典样本 |
| 《火星救援》 | 2015 | 能力展示的流行巅峰；NASA 作为「远程同事」 |
| 《隐藏人物》 | 2016 | 把镜头转向被省略的劳动与排除 |
| 《登月第一人》 | 2018 | 把任务还原成个人代价；更阴郁、更身体性 |
| 《阿波罗 11 号》 | 2019 | 纯档案纪录片；NASA朋克「档案权威」的直接展示 |
| 《For All Mankind》 | 2019— | 剧集；另类航天史，机构、预算、性别与政治长期在场；目前最完整的「机构叙事」样本 |

影像线的关键分化在于**镜头对谁**：对英雄（《登月第一人》）、对团队（《阿波罗 13 号》）、对机构（《For All Mankind》）、对隐形劳动（《隐藏人物》）。NASA朋克越往后走，镜头越往下、往旁边。

## 三、游戏：维修、供能、排班

游戏是 NASA朋克在 2020 年代最重要的媒介，因为它天然要求**系统可操作**。

| 作品 | 年份 | 玩法 | 与 NASA朋克的关系 |
| --- | --- | --- | --- |
| 《Kerbal Space Program》 | 2015 | 航天器建造与轨道模拟 | 把「工程试错」做成乐趣；卡通化，但精神接近 |
| 《Deliver Us the Moon》 | 2018 | 解谜/叙事 | 近未来月球供能任务；维修与供能是核心动作 |
| 《Observation》 | 2019 | 叙事解谜 | 空间站 AI 视角；模拟界面与机构程序高度在场 |
| 《Hardspace: Shipbreaker》 | 2022 | 拆船模拟 | 最接近「劳动」核心：按规程拆解、债务、公司；视觉 NASA朋克、政治赛博朋克 |
| 《星空》 | 2023 | 开放世界 RPG | 命名的来源；视觉与器物到位，但劳动与机构较薄，常被批评为「主题公园」 |
| 《无敌号》 | 2023 | 叙事模拟 | 改编自莱姆 1964 年小说；1970 年代复古未来，偏太空时代/原子朋克，但常被归入邻近谱系 |
| 《Stationeers》 | 2019 | 工程模拟 | 气压、电力、温控；硬核维修，视觉朴素 |

### 3.1 深拆：《Hardspace: Shipbreaker》——最接近核心判据

玩家是拆船公司的合同工，在零重力下按规程切割一艘艘飞船：先扫描、再断电、再泄压、再切割。它的动作全是**维护/拆解**，它的界面全是**模拟仪表**，它的叙事全是**债务与合同**。

它同时暴露了 NASA朋克的一个政治缺口：最像 NASA朋克的玩法，往往发生在**公司**而不是**公共机构**里。玩家感受到的不是「公共责任」，而是「被债务绑定的劳动」。这是一次成功的混血：NASA朋克的器物 + 赛博朋克的政治。

### 3.2 深拆：《星空》——命名的代价

《星空》是「NASApunk」这个词的出生地，也是它被质疑的样本。它的飞船内饰、宇航服、控制台、殖民地模块都高度符合四件套；但它的世界更接近「太空主题公园」：劳动被压缩成对话选项，机构被压缩成阵营任务，维护被压缩成资源条。

这不是说它「不 NASA朋克」，而是说它示范了**判据 3（劳动可见）与判据 4（机构在场）可以被视觉绕过**。一个作品可以长得非常 NASA朋克，却在叙事上仍然是英雄冒险。这个案例提醒创作者：**风格不是判据，制度才是**。

### 3.3 深拆：《Observation》——界面即叙事

玩家扮演空间站的 AI，通过切换摄像头、操作面板、读取文档来推进。它的界面不是 HUD，而是**世界的一部分**：玩家必须学会这套系统的语法，才能理解发生了什么。

这是 NASA朋克游戏设计最有价值的一课：**把 UI 做成机构**。当玩家读一份检查单、按一个物理按钮、看一盏警报灯时，他同时在学习这个组织的规则。

### 3.4 深拆：《无敌号》——复古未来的另一种配方

《无敌号》改编自斯坦尼斯瓦夫·莱姆 1964 年的同名小说，视觉上更接近 1970 年代的太空时代/原子朋克：橙色宇航服、模拟设备、荒凉星球。它不属于核心 NASA朋克（缺少公共机构与任务控制），但它是**邻近样本**：同样相信「设备有重量、按钮有手感、任务有程序」。

它提醒我们：NASA朋克不是唯一的「模拟未来」。在它周围，还有原子朋克、太空时代、磁带未来主义三个近邻（见 [01 定义与谱系](01_定义与谱系.md)）。

## 四、设计档案：被当作艺术品的工程文件

NASA朋克有一个其他复古类型少见的材料库：**真实的设计档案本身就可以出版、展览、被消费**。

- 《NASA 图形标准手册》（1975，Danne & Blackburn 设计）：网格、无衬线、蠕虫标志、编号系统；2010 年代被重新出版，成为平面设计界的经典；
- 阿波罗任务照片（哈苏相机）：高对比、大景深、真实光影；今天仍是「可信太空」的视觉基准；
- 任务控制室、发射台、航天器内饰的工程照片：管线、标签、席位、指示灯；
- 航天服与工具的设计图：功能决定形态，几乎没有装饰。

这类档案的价值在于：它们**不需要被「设计」得像 NASA朋克，因为它们就是**。创作者可以直接从中提取图形语言，而不是从二手科幻插画里提取。

## 六、给创作者的三个提示

1. **先选镜头，再选风格**：你拍的是英雄、团队、机构，还是隐形劳动？这决定你的美术该往哪一边偏。
2. **先选动词，再选界面**：维修、供能、排班、检查——选两个动词，界面自然长出来。
3. **先选制度，再选敌人**：敌人是外部碎片、内部故障，还是制度本身？这决定你的游戏是爽游、恐怖，还是讽刺。
