# 对读篇：NASA 朋克与复古未来主义——把未来降格为岗位

> 关键词：NASA 朋克；复古未来主义；档案外推；工程劳动；机构乐观
>
> 摘要：NASA 朋克是复古未来主义家族里的一条**逆流**：它回望的不是「过去的人如何想象未来」，而是「过去的人如何真的把东西送上天」。本篇论证三点：其一，它是「第一序档案的外推」——把真实任务报告与设计手册当作未来世界的施工图，而非把旧插画当风格贴图（见主卷 00 总论的三序模型）；其二，它的定义性动作是「把未来降格为岗位」，用排班、检查单、预算与维护替代英雄叙事；其三，它的当代性来自一种成年人的双重情感——相信机构能完成长期任务，也知道机构会消耗人。

## 一、一条逆流：从「想象未来」到「外推档案」

主卷把复古未来主义的材料按生产秩序分三序：第一序是 T₀ 原生档案，第二序是对 T₀「未来味」的刻意仿作，第三序是把多个 T₀ 自由重组的混血建构（见主卷 [00 总论](../00_总论_未来的考古学与全卷地图.md) 1.2）。按这个框架，原子朋克、蒸汽朋克、磁带未来主义都更像第二序或第三序：它们回收的是**关于未来的图像**——镀铬汽车、黄铜齿轮、CRT 终端——再把这些图像重新装配成世界。

NASA 朋克（NASApunk）走的是另一条路。它的档案不是「1960 年代的人想象的 2000 年」，而是「1960 年代的人实际做出来的登月系统」：阿波罗制导计算机的 DSKY 键盘、土星五号的检查单、任务控制中心的席位与电话、航天器上「Remove Before Flight」的红标签。它不需要先翻译「未来味」，因为这些物件**本来就是未来工程的原件**。它做的事情是把这个原件**外推**：如果这套工程文化继续演进，三百年后的飞船应该长什么样？

所以本卷给它的定位是：**第一序档案的外推**——不是混血，而是把 T₀ 当作 T₁ 的施工图。这解释了它为什么看起来「不怀旧」却仍然属于复古未来主义：它怀旧的对象不是某个年代的美学，而是某个年代的**工作方式**。

## 二、定义性动作：把未来降格为岗位

原子朋克把未来做成消费场景：厨房、客厅、车库、郊区。太空时代把未来做成游乐场：Googie 屋顶、火箭招牌、明日世界（见主卷 [08](../08_原子篇_原子朋克_幸福原子与镀铬郊区.md)、[09](../09_太空篇_太空时代_Googie射线枪哥特与明日世界.md)）。NASA 朋克则把未来做成**职场**。

这个动作可以拆成三张时间表（本卷框架）：

| 时间表 | 内容 | 戏剧来源 |
| --- | --- | --- |
| **任务时间** | 发射窗口、倒计时、轨道周期、氧气余量 | 不可延期的硬约束 |
| **机构时间** | 预算周期、国会听证、承包合同、轮班表 | 人的努力被制度稀释或托住 |
| **人的时间** | 职业生涯、家庭、退休、代际交接 | 一个人只能看到任务的一小段 |

NASA 朋克的张力几乎没有例外地来自这三张表**对不齐**：任务等不了预算，预算等不了人的一生。阿波罗计划在 1969 年到达顶点，1972 年最后一次登月，随后半个世纪的「被取消的未来」（见主卷 [16](../16_末日篇_被取消的未来_复古末日与废墟乡愁.md)）——这段历史本身就是三张表错位的最大样本。于是它的主角常常不是英雄，而是**地面团队、轮班工程师、维修工、通讯员**；它的高潮不是「击败敌人」，而是「按检查单把故障隔离掉」。

这也解释了它对「朋克」一词的挪用为何别扭：朋克通常站在机构外面反叛，NASA 朋克却站在机构里面**把机构修好**。它的反叛对象不是 NASA，而是「未来必须靠奇观说服人」这件事。

## 三、与三个近邻的边界

| 近邻 | 它的未来靠什么驱动 | NASA 朋克的差异 |
| --- | --- | --- |
| 原子朋克 | 核能带来的家庭丰裕 | 不消费能量，而是**管理**能量；不镀铬，而是贴标签 |
| 太空时代 / Googie | 消费社会的太空化想象 | 不把火箭当招牌，而把火箭当**需要维护的系统** |
| 磁带未来主义 | 模拟媒介的暖质感 | 共享 CRT 与拨杆，但 NASA 朋克的重点是**系统的可操作性**，不是媒介的乡愁 |
| 赛博朋克 | 公司权力与身体改造 | 机构是公共的、笨重的、可问责的；技术是工具，不是鸦片 |
| 太阳朋克 | 生态与社区的乌托邦 | 同样相信集体，但 NASA 朋克不保证胜利，只保证**有人值班** |

与太阳朋克的关系尤其值得注意：两者都常被批评「朋克味不足」，因为它们描绘的是**治理**而不是**反抗**。区别在于，太阳朋克把治理想象成花园，NASA 朋克把治理想象成控制室——前者怕的是生态崩溃，后者怕的是 checklist 漏了一项。

## 四、为什么是 2020 年代

一个 2022 年才被造出来的词，为什么会迅速被接受？至少有四条土壤：

1. **奇观疲劳**：观众已经看过太多「蓝色全息界面 + 无缝白色飞船」的未来，反而对「有螺丝、有标签、会坏」的未来产生信任感；
2. **机构经验的回潮**：疫情、供应链、气候治理让「长期、笨重、跨代的公共工程」重新成为可想象的解决方案；
3. **航天叙事的现实化**：可回收火箭、商业空间站、深空探测把「航天」从国家仪式拉回产业与岗位；
4. **游戏工业的产能逻辑**：可维修的模块化资产比全息奇观更容易做厚、做一致、做玩法（资源、维修、电力、氧气）。

换句话说，NASA 朋克流行的真正原因，可能不是人们更爱 NASA 了，而是人们更想相信**「复杂系统可以被负责任地维持」**。这是一种比乐观更疲惫、比悲观更有用的情感。

## 五、接到 LiveBay：三环就是岗位地图

LiveBay 的设定几乎是这条逆流的直接延伸：一座月牙形移动太空城，外环护卫与采集、中环居住、内环政治经济；大多数人活在「慢好三生保障体系」里，少数人被选拔为工作人员，做三环的各种工作，压力大时可以退役或轮岗。

这套设定把 NASA 朋克的三张时间表换成了**一座城的空间表**：

- **外环**是任务时间：护卫、采集、能源，硬约束在这里；
- **中环**是人的时间：养生、娱乐、教育，生活在这里被安放；
- **内环**是机构时间：政治、经济、文化，预算与合法性在这里分配。

玩家扮演的不是舰长，而是从护理师、环卫兵、工程师到执政官的**岗位序列**——这正是「把未来降格为岗位」的玩法化。本卷因此不只是风格参考，也是 LiveBay「为什么塔防可以是职业的」这一问题的上游论证。项目侧展开见 [`games/livebay/docs-ai/design01/03_职业体系.md`](../../../games/livebay/docs-ai/design01/03_职业体系.md) 与 [`04_塔防玩法.md`](../../../games/livebay/docs-ai/design01/04_塔防玩法.md)。

## 六、收束：成年人的未来

复古未来主义大多在悼念一个未兑现的许诺。NASA 朋克悼念的东西更具体：**一种曾经存在过的、把复杂事情做成的能力**。它不假装那种能力没有代价——冷战、预算、事故、被裁掉的第 18、19、20 次登月——但它也不假装那种能力不值得再来一次。

所以它给出的未来不是「我们终将抵达群星」，而是「今天这班岗，谁来接」。这句话既是它的局限（没有政治方案），也是它的力量（把宏大叙事还原成可承担的责任）。
