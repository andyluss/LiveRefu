## 二、去重口径

- **保留**：五卷的完整正文、年表、美学、作品、批评、中文语境与资料库；
- **删除**：`docs/punks/README.md` 原卷首索引（已由本文件替代）、旧版精简原子朋克附录（完整原卷已覆盖）；
- **保留主卷**：`07_战间篇`、`08_原子篇`、`13_蒸汽篇`、`15_赛博篇`、`19_多元篇` 是主卷的**纵向叙事**；五卷附录是**横向资料卷**，两者不是逐字副本，故不互相删除；
- **不重复造入口**：五卷正文使用 `附录_*朋克卷/` 命名；原五卷的合订与统计只作为残留资料，不再作为独立入口。

## 三、差异对比

| 维度 | 主卷章节（07/08/13/15/19 等） | 朋克附录卷 |
| --- | --- | --- |
| 写作目的 | 把朋克放回复古未来主义的历史叙事 | 对一个朋克谱系做定义、年表、作品与批评的深度资料 |
| 时间范围 | 跨世纪、跨媒介的纵向线索 | 单一朋克类型的完整切片 |
| 内容密度 | 叙事与判断 | 词条、档案、作品清单、争议与中文接受 |
| 重复处理 | 保留主卷判断 | 保留附录独有资料；不再复制主卷整段叙事 |
| 入口 | [`../README.md`](../README.md) | 本说明 + 五个附录 README |
