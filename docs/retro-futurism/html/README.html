复古未来主义论文集（Retro-futurism Papers）

docs/retro-futurism/ 卷首导读 · 21 篇全卷目录

本卷是一套多篇目协作写成的论文集合（简体中文，Markdown），主题为复古未来主义（retro-futurism）——对"过去时代所想象的未来"的回收、消费与再创造。覆盖从远古神话（飞天、永生、自动人偶）到 19 世纪凡尔纳与威尔斯，从蒸汽朋克、柴油朋克、原子朋克等"××朋克"诸系，到当代蒸汽波、合成波、Y2K、Frutiger Aero 与网络"美学词条化"，并收入非洲未来主义、丝绸朋克、Solarpunk 等多元未来叙事，以及"未来如何过时、如何被考古、如何被二次消费"的完整机制。

一、卷内结构（四段）

段 篇目 内容
理论地基 00—01 定义、作者体系（七纪/四元素/七机制）与怀旧/遗产化理论
未来的考古 02—11 按年代发掘"当时的未来"：神话纪→乌托邦纪→蒸汽纪→机器纪→原子与太空纪→红旗纪→中国线索
回收的未来 12—16 "××朋克"全谱系地图与各专篇（蒸汽/磁带/赛博/末日）
当代乡愁与多元 17—19 蒸汽波与合成波、千禧互联网美学、多元未来文化星丛
收束 20 结语、未来年表、术语对照、延伸阅读

阅读建议：顺序通读（考古流最顺）；或先读 00 总论，再跳读 12 谱系篇与 17、18 当代两篇，最后回头读 02—11 的历史篇——当代诸篇本就是对历史篇的消费与回收。

三、写作说明

  • 体例：全卷遵守 00_总论 第四节「写作凡例」（简体中文、关键词+摘要、术语首现加粗附原文、交叉引用以"（见 NN 篇名）"标注、文末分类「核心作品清单」、事实不确定时按"约/一般认为/存疑"降档且严禁编造）。
  • 术语体系：卷内自用的"七纪分期—四元素—七机制"框架系主编设计，见于 00 总论；术语总表见 20 附录二。
  • 事实核验：关键命名源流（retro-futurist 最早用例 1981、射线枪哥特 1981、蒸汽朋克 1987、柴油朋克约 2001、Frutiger Aero 2018 命名、anemoia 2012、丝绸朋克/太阳朋克等）已依英语维基百科等公开资料核验，细节与在线词条清单见 20 附录三。
  • 版本：本卷自 git init 起逐篇分批提交，完整历史见仓库 git log（共 16 次提交：建卷总论 → 理论篇/结语附录 → 各批次篇目 → 核验修正 → 收尾润色 → 篇幅统计）。
