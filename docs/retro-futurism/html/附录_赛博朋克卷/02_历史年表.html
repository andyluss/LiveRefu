赛博朋克 · 历史年表

关键词：赛博朋克；历史年表；设定年份；过期未来；银翼杀手；攻壳机动队；神经漫游者

摘要：本篇以现实年份为轴，编列赛博朋克 1968—2020 年的关键节点：迪克《电子羊》（1968）→《银翼杀手》（1982，设定 2019）→《神经漫游者》（1984）→《阿基拉》（1988，设定 2019）→《攻壳机动队》（漫画约 1989—1991、剧场版 1995）→《黑客帝国》（1999）→《荒潮》（2013）→《银翼杀手 2049》（2017，设定 2049）→《赛博朋克 2077》（2020，设定 2077），并为每部作品标注设定年份及其过期状态：设定年份既是文类的招牌，也是它过期的倒计时。

二、怎么读这张表：双轨纪年

表里始终有两条时间轴在并跑：现实年份（作品出现的时间）与设定年份（作品许诺的未来）。赛博朋克常把设定年份写进标题或片头（《银翼杀手》的 2019、《赛博朋克 2020》《赛博朋克 2077》），等于给自己装了一个倒计时器。截至 2020 年代中期写作时：2019（《银翼杀手》《阿基拉》）与 2013、2020（庞德史密斯桌游两版）已经过期；2049、2077 尚在倒计时。凡是"设定年份已过"的作品，其身份自动从"预言"转向"档案"——这正是本卷 00 对读篇所述遗产化的第一道门。而即便设定年份未到（2049、2077），画面内的技术底座（CRT、公用电话、拨号网络）也早已过期，因此"过期"在赛博朋克里从来不是全有或全无，而是设定层与道具层分别计时。

把"已过期"者单列，可以看得更清楚。截至写作时，表中已过期的设定年份共四个：2019 出现两次（《银翼杀手》《阿基拉》——1982 年的电影与 1988 年的动画不约而同把未来设在同一年，仿佛整个 1980 年代都指向同一个远方），2013 与 2020 各一次（庞德史密斯桌游两版）；2049 与 2077 仍在倒计时。而现实的 2019 年既没有复制人，也没有《银翼杀手》许诺的那座洛杉矶。设定年份因此是一份"承诺书"，也是一块"墓碑"：在它到达之前是倒计时，在它到达之后是遗物。

三、编年的边界说明

表中不确定处按论文集纪律降档：阿基拉剧场版设定年份为 2019（一般认为）；攻壳漫画连载期约 1989—1991（一般认为）；攻壳剧场版与《黑客帝国》均未在片中明确纪年，故不标注；《电子羊》的具体设定年份因版本不一而不标注；桌面角色扮演游戏两版出版年按"一般认为"。年份与事实口径与《复古未来主义论文集》15 赛博篇一致；本表与其错位互补：只做编年与过期标注，不复述作品情节。此外，表中未标纪年者（《神经漫游者》《攻壳机动队》《黑客帝国》《荒潮》）同样参与过期大潮：它们的"近未来感"主要靠界面与城市形态维系，而非片头纪年，设定层虽未自爆，道具层（CRT、公用电话、拨号网络）照样随真实历史过期。
