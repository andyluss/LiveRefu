03 · 美学与视觉

关键词：白盒硬件；可维修性；检查单；模拟界面；机构色；标签系统

摘要：NASA朋克的视觉不是「白色 + 橙色」的配色表，而是一套关于可信度的语法：外露的结构、可替换的模块、可读的标签、可操作的控件。本篇把它拆成四件套（白盒硬件、检查单、模拟界面、机构色），给出材质、色彩、字体、图形、光与声音的具体规则，并说明这套语法如何落到 LiveBay 的三环空间。

一、总原则：美感来自「坏了能修」

大多数科幻美术追求「不会坏」：无缝外壳、全息投影、自修复材料。NASA朋克反过来，追求「坏了能修」：

  • 接缝可见，因为面板要能拆；
  • 管线外露，因为要能查漏；
  • 标签手写或打印，因为要能改；
  • 控件是物理的，因为戴手套也要能按；
  • 备份是双份的，因为单点会失效。

这条原则有一个直接推论：做旧不是脏，而是使用痕迹。NASA朋克的磨损应该像工具而不像废墟——边角发亮、把手掉漆、标签翘起，但结构完好、随时可用。它与「废墟乡愁」（主卷 16 末日篇）的区别在于：废墟是「没人维护了」，NASA朋克是「一直有人在维护」。

二、四件套（本卷框架）

2.1 白盒硬件（white-box hardware）

指把设备的内部逻辑暴露在外的设计：机架、线束、接口、指示灯、备份开关。它的视觉特征是分层：

层 内容 视觉处理
结构层 骨架、桁架、舱壁 哑光金属、可见铆接/螺栓
功能层 设备、管路、线束 模块化、颜色编码、快拆接头
信息层 标签、编号、状态灯 高对比、等宽字、贴纸质感
消耗层 滤芯、电池、胶带、扎带 可替换、略有不齐

白盒硬件不等于「乱」。它的秩序来自编码：颜色、编号、方向箭头、区域划分。看得懂的人一眼知道哪根管子通向哪里——这就是 NASA朋克的专业感来源。

2.2 检查单（checklist）

检查单是 NASA朋克最有辨识度的平面设计：一列项目、方框、缩写、签字栏、页脚编号。它把「冒险」拆成可复核的步骤，也把「人」固定在流程里。

视觉上可以直接使用：

  • 方格纸或工程表格底纹；
  • 等宽字体与手写批注混排；
  • 红色「Remove Before Flight」飘带；
  • 夹板、活页环、油墨印章；
  • 「第 X 页 / 共 Y 页」与修订号。

检查单还是叙事装置：一张被划掉一半的检查单，比一段独白更能说明「这里出过事」。

2.3 模拟界面（analog interface）

拨杆、旋钮、按钮、CRT、七段数码管、DSKY 式的动词-名词键盘。它们的功能不是复古，而是可操作：每个控件对应一个明确动作，状态可以被肉眼读出。

设计规则：

  1. 一控件一功能，不做隐藏菜单；
  2. 状态可见：灯、表、纸带，至少有一种冗余反馈；
  3. 层级靠物理分区，不靠弹窗；
  4. 故障可读：警报色、闪烁频率、蜂鸣音区分严重度；
  5. 戴手套可用：控件尺寸大于指尖，间距足够。

2.4 机构色（institutional palette）

NASA朋克的色彩不是「复古滤镜」，而是机构识别系统的延伸：一枚徽标、一条色带、一种编号规则，让所有东西看起来属于同一个组织。

色 用法 注意
暖白 / 米白 舱壁、面板、纸张 不要纯白，加一点黄灰
安全橙 警示、救生、活动部件 面积小、饱和高，作为视觉锚点
深青 / 灰绿 机柜、控制台、地面 压低整体明度，衬托橙色
琥珀 警报、背光、CRT 荧光 与橙色区分：琥珀偏黄，橙偏红
深灰 / 石墨 结构件、文字、边框 提供对比，不要纯黑

配色比例建议：70% 中性（白/灰/米）+ 20% 深色结构 + 10% 高饱和强调。高饱和色只出现在「需要被看见」的地方——按钮、警示、状态灯——这样界面才有呼吸。

三、材质与光

  • 金属：阳极氧化铝、拉丝不锈钢、喷砂面板；高光弱、反射模糊。
  • 塑料：米色 ABS、灰色 PVC、半透明亚克力；允许发黄（老化痕迹）。
  • 织物：尼龙织带、Velcro、帆布；用于束缚、标识、临时修补。
  • 纸：标签纸、检查单、胶带；边缘可翘、可有手写。
  • 玻璃：CRT 弧面、厚边框、轻微反光；避免无边框全息。

光的设计比材质更重要：

  • 主光：冷白工作灯（约 5000—6000K），均匀、无戏剧阴影；
  • 辅光：琥珀色警报/背光，局部；
  • 环境：设备指示灯的点状光、CRT 的屏幕光；
  • 禁用：霓虹、紫蓝渐变、体积光滥用——这些是赛博朋克的语法。

四、字体与图形

  • 标题/标识：几何无衬线（Helvetica 系）或机构定制字；字距紧、字号克制。
  • 数据/编号：等宽字体；用于坐标、序列号、倒计时。
  • 手写：只用于批注、临时标签；不要整段手写体。
  • 图形：网格、分区线、箭头、警告三角、条码、检查框、修订章。
  • 图标：功能优先，线条粗细一致；避免拟物插画。

一个实用技巧：给所有东西编号。舱段号、管线号、岗位号、班次号。编号本身就是世界观——它暗示有一个更大的系统在管理这些编号。

五、空间语法

空间 特征 情绪
控制室 阶梯座位、大屏、电话、纸质记录 集体、紧张、有序
机舱/走廊 管线、格栅地板、应急灯、舱门 封闭、可维修、略带压迫
居住舱 折叠家具、织物、个人物品、暖光 临时但有人味
工作台 工具墙、零件盒、台灯、检查单 专注、手感、时间感
过渡区 气闸、更衣、消毒、标识 仪式感、边界感

NASA朋克的空间几乎总是模块化的：舱段可以拼接、房间可以改用途、墙面可以拆。这为关卡设计与叙事都提供了便利——同一套模块，换标签就是另一个岗位。

六、声音

  • 底噪：风扇、变压器、继电器、远处金属应力声；
  • 信号：无线电静电、摩尔斯、打印机的机械声、CRT 的电流声；
  • 警报：分层的蜂鸣（注意/警告/危急），不要用电影式大音墙；
  • 人声：被无线电滤波的短句、呼叫代号、重复确认；
  • 静默：NASA朋克需要静默，因为「没声音」意味着系统正常。

七、落到 LiveBay：三环三套语法

LiveBay 的月牙形太空城可以按环分配视觉语法，让玩家一眼知道自己在哪：

环 功能 主色 材质 光 关键词
外环 护卫、采集、能源 冷灰 + 安全橙 金属、装甲、外露桁架 冷白 + 警示琥珀 暴露、强度、任务
中环 居住、养生、娱乐、教育 暖白 + 木色 + 柔绿 织物、塑料、植物 暖白 + 局部彩色 安稳、重复、生活
内环 政治、经济、文化 米白 + 深青 + 黄铜 石材、玻璃、抛光金属 均匀、无影 秩序、仪式、距离

三环之间的过渡区（气闸、电梯、检查站）是视觉上最有趣的地方：外环的橙色警示带会在这里变成中环的柔色导视，金属格栅变成地毯，警报声变成广播——一条走廊就是一次阶级转换。

这套分配也直接服务于玩法：外环塔防的界面应该像战情室，中环的界面应该像家居面板，内环的界面应该像档案系统。具体见 games/livebay/docs-ai/design01/08_美术与音频方向.md。

八、反例清单

  • 全息投影 + 透明蓝屏（这是 2010 年代科幻，不是 NASA朋克）；
  • 无缝白色 + 苹果式极简（没有维修入口）；
  • 过度做旧 + 锈迹斑斑（这是废墟，不是在用）；
  • 霓虹紫蓝 + 雨夜（这是赛博朋克）；
  • 无标签的管线与无编号的舱门（失去了机构感）；
  • 纯装饰性的检查单（没有真实流程）。

九、一句话验收

随手截一张图，问三个问题：这东西坏了怎么修？谁在值班？它属于哪个编号系统？ 三个都能答上来，才是 NASA朋克。
