一卷关于「把未来降格为岗位」的美学：真实的航天机构、可维修的白盒硬件、检查单与模拟仪表，如何被 2020 年代的游戏工业重新命名为一种「朋克」。

一、与主卷的关系

  • 关联主卷：09 太空篇、08 原子篇、12 谱系篇、14 磁带篇、15 赛博篇；
  • 主卷按「过去时代所想象的未来」做纵向考古；本卷处理一个晚近的逆流：不是回望某个年代的未来想象，而是回望真实存在过的航天工程，并把它 extrapolate（外推）成未来；
  • 本卷卷首 00_对读篇 负责把这条逆流接回主卷的三层时间与「朋克」谱系；两者不是逐字副本。

三、卷内核心判断（先看这五条）

  1. NASApunk 不是「NASA 风格的科幻」，而是「以真实航天工程为档案的复古未来主义」：它的权威来源是任务报告、设计手册与发射照片，不是 1950 年代的插画。
  2. 它的定义性动作是「把未来降格为岗位」：未来不再是奇观，而是一份有排班、有检查单、有预算、有退休制度的工作。英雄不是舰长，是地面团队。
  3. 它的视觉语法是「可维修」：外露管线、标签、拨杆、CRT、标准件、备份系统。美感来自「这套东西坏了能修」，而不是「这套东西不会坏」。
  4. 它的情感是「机构乐观」与「机构疲惫」的并存：相信集体能完成长期任务，同时知道预算、政治与官僚会消耗人。这种双重性是它比原子朋克更成年、比赛博朋克更温和的地方。
  5. 它的「朋克」是产业命名，不是政治宣言：2022 年由 Bethesda 为《星空》造词，先有美术方向、后有文化讨论；把它当学术分类会过度解释，把它当纯营销又会漏掉它真实的表达力。

五、写作凡例与事实核验

  • 体例沿用主卷 00 总论 第四节「写作凡例」：关键词 + 摘要、术语首现加粗附原文、交叉引用、文末清单、事实不确定时按「约 / 一般认为 / 存疑」降档，不编造引文与数据。
  • 本卷的特殊困难：NASApunk 是一个 2020 年代才被命名的词，学术文献极少。因此本卷把材料分三级：
    1. 一手档案：NASA 公开的设计标准、任务报告、照片与口述史；
    2. 创作者自述：开发者访谈、美术指导（如《星空》团队 2022 年的命名自述）；
    3. 社群归纳：玩家、设计师与媒体对「NASApunk」的用法——这类材料只作为「用法证据」，不当作定义权威。
  • 凡属于本卷自建的分析框架（如「四件套」「三张时间表」），均在首次出现处标明「本卷框架」，避免与既有术语混淆。
  • 关键事实的出处见 08 资料库。

六、与 LiveBay 的关系

LiveBay（《逍遥湾》）把本卷的美学当作总体风格，但不是照搬 NASA：它把「真实航天机构」替换成一座移动太空城的三环保障体系，把「任务」替换成「轮班与生活」。本卷因此也是 LiveBay 美术与世界观的上游参考之一，项目侧落地见 games/livebay/docs-ai/design01/08_美术与音频方向.md。

一句话：NASApunk 的未来不是「我们终将抵达群星」，而是「今天这班岗，谁来接」。
