千禧互联网美学 · 历史年表（1995—2025）

关键词：千禧美学；编年史；网页 1.0；镀铬拟物；扁平化；词条化复兴

摘要：千禧互联网美学的历史可以分成三幕：第一幕"网页 1.0 与信息高速公路"（1995—2000），未来感来自网络本身；第二幕"镀铬拟物与 Web 2.0"（2000—2010），未来感装进个人电脑的界面；第三幕"扁平化之死与词条化复兴"（2010—2025），旧界面集体入土，又被命名工业批量出土。本篇以三幕为纲、年表为体，标注约数。

第一幕：网页 1.0 与信息高速公路（约 1993—2000）

背景：万维网从学术工具变成大众媒介，"信息高速公路"成为新的未来总意象；个人主页是第一代网民的"自留地"。

约时间 事件 意义
1991—1993 WWW 向公众开放（CERN）；Mosaic 浏览器（1993） 图形化网页诞生，网页美学的原料场
1994—1995 "贝弗利山互联网公司（Beverly Hills Internet）"开放免费主页托管，更名 GeoCities（1994 成立、一般认为 1995 正式开放） 个人主页时代的开端：星空背景、计数器、留言板的温床
1995 中国互联网元年（中国公用计算机互联网向社会开放；瀛海威等先行者） 中文网页 1.0 起点（详见 07 中文语境篇）
1996—1998 Hotmail（1996）；网易（1997）、搜狐（1998）、新浪（1998 前后）等门户出现；Google 成立（1998） "门户+搜索"的网页信息架构定型
1997 GeoCities 第 50 万个"拓荒者（Homesteader）"（1997-04）；空间上限扩容 个人主页规模化的标志（Archive Team 档案）
1998-08 iMac G3 发布（邦迪蓝半透明一体机） Y2K 美学硬件图腾：半透明果冻塑料进入寻常百姓家
1999 QQ 前身 OICQ 上线（1999-02 前后）；雅虎收购 GeoCities；".com"狂潮顶点 即时通讯与门户时代交汇
1999-12-31 → 2000-01-01 千年虫（Y2K bug）事件：全球计算机平安度过 "最后一个全球性未来事件"（主卷 20 年表亦收录）
2000-03 互联网泡沫开始破裂 数字乌托邦叙事第一次"过期"

第二幕：镀铬拟物与 Web 2.0（约 2000—2010）

背景：个人电脑与手机普及，"未来感"从"上网"下沉到"界面"；硬件与操作系统成为新的未来图腾。

约时间 事件 意义
2000—2001 Mac OS X 公测与发布（Aqua 玻璃界面）；Windows XP 于 2001-10 发布（默认壁纸 Bliss 草原蓝天） 拟物/清爽界面的双源头；XP 桌面成为一代人的"默认未来"
2000—2001 PlayStation 2（2000）、iPod（2001-11） 数字消费硬件的黄金件
2004 "Web 2.0"术语流行（O'Reilly 等） 从"网页"到"平台"的叙事转折（美学上则是从"个人主页"走向"UGC 平台"）
2005 QQ 空间（Qzone）上线（约 2005）；校内网成立（2005-12）；YouTube 上线 中文"个人主页第二春"+全球视频时代
2007-01 Windows Vista 发布（Aero 玻璃特效）；同年 iPhone 初代发布（拟物图标） Frutiger Aero 的软件总装与触屏纪元开端
2009-10-26 雅虎关停 GeoCities；Archive Team 自 2009-04 起抢救 个人主页时代"入土"日，抢救即"出土"（本卷 00/05 详述）
2009 Windows 7 发布 Aero 美学的成熟与绝唱准备

第三幕：扁平化之死与词条化复兴（约 2010—2025）

背景：移动优先与扁平化设计杀死拟物；十年后，死去的界面被"美学词条工业"成批复活。

约时间 事件 意义
2010—2013 Metro/扁平化推进：Windows Phone（2010）、Windows 8（2012）、iOS 7（2013-06，苹果全面扁平化） 拟物与 Frutiger Aero 的官方死刑；设计师转投"少即是多"
2013 Neocities 上线 网页 1.0 美学的当代"还魂"平台
2010s 中后期 Aesthetics Wiki（Fandom）等词条库扩张；"webcore""McBling"等词条成形 词条化命名工业起步（年份存疑，降档）
2018 前后 "Frutiger Aero"之名被提出（一般认为 CARI 成员 Sofi Xian，年份诸说不一） 死界面的"命名即出土"（详见 03 篇）
2019—2020 CARI（消费者美学研究所）正式成站（一般认为 2020 年前后；创始人与成立年份诸说不一，维基作 Evan Collins）；疫情期 Y2K 美学全球复兴（学者杨晓春指出与疫情及经济衰退相关） 怀旧商品化与"宅家回望"合流
2020-12-31 Adobe Flash 终止支持 Flash 一代（含中文 4399 小游戏）集体作古（详见 05/07 篇）
2021—2024 "Y2K 美学"泛化：小红书/抖音/TikTok 标签、时装周回潮、"新怀旧（New Nostalgia）"（与音乐人 PinkPantheress 相关，2021—2022 媒体化） 广义 Y2K（含 2000s 时尚）成为可消费的复古
2022 前后 "千禧年美学"在中国网络二次翻红：杀马特/非主流怀旧、QQ 空间考古贴 中文语境的"第一人称怀旧"（详见 07 篇）

读法：三幕里的两条主线

  1. 媒介主线：未来感的第一载体从"网络本身"（第一幕）→"个人电脑界面"（第二幕）→"词条与标签"（第三幕）——美学的"家"从网页搬进操作系统，再从操作系统搬进博物馆式的词条库；
  2. 时间主线：从"许诺"到"过期"的间隔越来越短——.com 时代许诺了近十年（1995—2000 酝酿、2001 破裂），拟物界面许诺了约六年（2007—2013），词条化复兴只等了三五年就开始（2013 扁平化死 → 2018 命名 → 2020 复兴）。这正是主卷 00 2.4"未来感半衰期缩短"在数字纪元的完整实证（本卷 04 篇展开理论）。
