# 蒸汽朋克 · 历史年表

> 关键词：编年史；文本；命名；影视；亚文化
>
> 摘要：蒸汽朋克的历史分三段：文本前史（1959—1990）、标签与亚文化（1987—2000s）、媒介黄金期与全球扩散（2000s—今）。本篇按创作年编年。

---

| 约时间 | 事件 | 意义 |
| --- | --- | --- |
| 1959 | 皮克《泰特斯独行》 | 追认起点之一 |
| 1967 | 克拉克《维多利亚女王的炸弹》 | 维多利亚"另类科技"主题 |
| 1971—1981 | 穆尔科克"时间之流"系列 | 蒸汽母题延续 |
| 1979 | 杰特《莫洛克之夜》 | 三杰文本之一 |
| 1986 | 宫崎骏《天空之城》 | 蒸汽飞行器的动画浪漫（常被纳入蒸汽朋克讨论） |
| 1987 | 杰特致《Locus》信提出 "steam-punks"；《地狱装置》 | **命名点** |
| 1990 | 吉布森与斯特林《差分机》 | 圣典化 |
| 1990s—2000s | 蒸汽朋克亚文化成形：时装、集会、手作、乐队（泛化） | 从文类走向生活方式 |
| 1999 | 电影《飙风战警》（漫画改编）；漫画《非凡绅士联盟》（摩尔/奥尼尔，2003 年电影） | 大众化推力 |
| 2000s—2010s | 游戏黄金期：《奥秘》（2001）、《生化奇兵：无限》（2013）、《羞辱》（2012，鲸油朋克归类存疑）等 | 蒸汽朋克成为游戏世界观常备选项 |
| 2004 | 《蒸汽男孩》（大友克洋） | 动画蒸汽朋克的集大成之一 |
| 2005—2010s | 蒸汽朋克在华流行：译名扩散、网络小说标签（泛化） | 中文接受（详见 06 篇） |

## 读法

年表可见两条线索并行：**创作线**从 1959 绵延至今从未断档，**命名线**自 1987 才开启——蒸汽朋克又一次印证"文本先于标签"的追溯命名规律（00 对读篇），其亚文化产业化（第三条线）则是复古未来主义的商业模式样板。
