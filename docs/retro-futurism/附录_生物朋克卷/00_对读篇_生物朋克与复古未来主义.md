# 对读篇：生物朋克与复古未来主义——最"不怀旧"的朋克与它的认祖式复古

> 关键词：生物朋克；复古未来主义；认祖；湿件；对读
>
> 摘要：在所有"××朋克"里，生物朋克是最不怀旧的一支：它通常不设定于"过去的未来"，而是把当下的生物技术外推成近未来。但正因如此，它反而示范了复古未来主义的"认祖机制"——弗兰肯斯坦（1818）与莫罗博士（1896）被追认为祖先，两百年来的"造人恐惧"档案被整体收编。

---

## 一、异类：不面向过去的朋克

对比同族：
- 蒸汽朋克回望 19 世纪，原子朋克回望 1950s，磁带未来主义回望 70—80s——它们都回收"过去的未来"；
- 生物朋克通常写"从现在往前推十年到几十年"的基因时代：CRISPR、合成生物、生物黑客——它更像是**当下科幻**（与太阳朋克相似，都"看向未来"）。

于是它站在主卷 00 定义的边缘：复古未来主义回收"过去时代所想象的未来"，生物朋克却几乎不回收任何时代的"未来形象"。它的复古性不在题材，而在**方法**。

## 二、认祖式复古：造人恐惧的档案柜

生物朋克虽不回收"未来形象"，却深度回收"恐惧母题"（主卷 02 远古篇的自动人偶-造人谱系在此技术化）：

- 玛丽·雪莱《弗兰肯斯坦》（1818）：技术造人+反噬的原型（主卷 04 已述）；
- 威尔斯《莫罗博士的岛》（1896）：活体改造与物种界限；
- 恰佩克 R.U.R.（1920）：人造劳工的反叛（"robot"词源）。

这构成一种"反向认祖"：别的朋克先有文本后被命名（蒸汽朋克等），生物朋克则把一批**比"生物朋克"这个词早一两百年**的文本追认进自家家谱——这正是主卷 12"追溯命名律"的又一实例：**标签史不是作品史**。

## 三、与复古未来家族的关系小结

| | 蒸汽/原子/磁带等 | 生物朋克 |
| --- | --- | --- |
| 时间方向 | 回望过去的未来 | 外推当下 |
| 复古机制 | 回收时代图像 | 回收恐惧母题（认祖） |
| 与主卷的关系 | 复古未来主义本体 | 复古未来主义的"边缘镜片" |
| 能源/基底 | 蒸汽、核、微电子 | 生命/基因（wetware） |

结语：生物朋克提醒我们，复古未来主义的边界不只在"年代的图像"——还包括"想象的母题"。当一种技术足够新，人们会去故纸堆里认祖；而这种认祖，本身就是复古（对"过去的未来焦虑"的回收）。
