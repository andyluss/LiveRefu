# 生物朋克 · 历史年表

> 关键词：编年史；造人母题；基因想象；现实生物技术
>
> 摘要：生物朋克的历史最好读成两条线：**虚构线的造人母题**（1818—1990s）与**现实线的生物技术时间表**（2000s—今）——两者在"基因时代"汇合。凡没把握的年份一律降档。

---

## 一、虚构线（造人母题技术化）

| 约时间 | 作品/事件 | 意义 |
| --- | --- | --- |
| 1818 | 雪莱《弗兰肯斯坦》 | 技术造人+反噬原型（主卷 04） |
| 1896 | 威尔斯《莫罗博士的岛》 | 活体改造与物种界限 |
| 1920 | 恰佩克 R.U.R. | 人造劳工与反叛（robot 词源，主卷 06） |
| 1984 前后 | 巴特勒《血孩子》（Bloodchild） | 共生/寄生的身体政治（年份降档） |
| 1985 | 斯特林《分裂矩阵》（Schismatrix） | "塑造者/机械师"后人类谱系 |
| 1987—1989 | 巴特勒"黎明三部曲"（Xenogenesis） | 基因融合与异种共生的宏大尝试（通行锚点） |
| 1997 | 电影《千钧一发》（GATTACA） | 基因决定论反乌托邦的公众形象 |
| 1990s—2000s | ribofunk/biopunk 标签流通（存疑，见 01 篇） | 命名纪 |

## 二、现实线（生物技术时间表）

| 约时间 | 事件 | 意义 |
| --- | --- | --- |
| 2000s 前期 | 合成生物学兴起；iGEM 竞赛（年份降档，通行说法为 2003/2004 前后） | "工程化生命"成为现实议题 |
| 2000s | "车库生物学/DIYbio"与生物黑客话语 | biopunk 的现实对应（门槛与争议见 04 篇） |
| 2012 | CRISPR 基因编辑关键论文（通行说法） | 基因编辑平民化叙事的起点 |
| 2010s—今 | 基因测序成本下降、"设计婴儿"伦理辩论 | 生物朋克从科幻滑向社论 |

## 读法

两条线的对照说明生物朋克的特殊性：别的朋克是"时代图像的乡愁"，生物朋克是"实验室新闻的提前量"——它的"未来"一直与真实科研进度赛跑（见 00 对读篇）。
