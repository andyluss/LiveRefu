# 生物朋克 · 美学与视觉

> 关键词：有机质感；实验室美学；基因符号；视觉特点
>
> 摘要：生物朋克没有蒸汽朋克那样统一的"时代视觉"，这是它作为"当下外推型"朋克的结构性特点（见 00 对读篇）。本篇整理其碎片化的视觉语汇，并说明它与赛博朋克（金属义体）的视觉分野。

---

## 一、视觉语汇（碎片清单）

1. **有机质感**：肉质、藤蔓、菌丝、共生体、半透明的生物组织——"活的机器"取代齿轮；
2. **实验室美学**：培养皿、移液枪、凝胶电泳图、洁净室——未来感藏在实验台而非仪表盘；
3. **基因符号**：双螺旋、碱基序列条带、DNA 图案被用作身份/品牌符号；
4. **身体变异**：鳞片、植皮、额外器官、共生寄生物——身体的"可编程性"；
5. **生物朋克色调**：偏实验室白/培养液粉绿/暗红组织色——无霓虹（赛博）也无黄铜（蒸汽）的统调。

## 二、与赛博朋克的视觉分野

| | 赛博朋克 | 生物朋克 |
| --- | --- | --- |
| 身体改造 | 金属义体/电子眼（硬） | 基因/组织改造（软） |
| 界面 | 终端/神经接口 | 植入体/共生体/基因开关 |
| 工厂 | 巨企塔楼 | 实验室/生物工厂 |
| 恐怖源 | 机器失控 | 生命失控 |

## 三、为什么生物朋克"没有时代脸"

蒸汽朋克有一张脸（维多利亚），原子朋克有一张脸（50s 郊区），生物朋克没有——因为它的"目标年代"就是现在+几年，而现在的视觉每五年换代（见主卷 00 2.4）。它只能靠"实验室+变异体"的意象簇维持识别度；这也是它长期停留在"赛博朋克变体"阴影下的原因之一（存疑开放）。
