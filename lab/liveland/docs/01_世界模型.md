# LiveLand · 世界模型与架构（v0.1）

## 1. 世界不是文件夹

```text
World
├── constraints   世界级规则（技术/能源/材料/社会/禁止）
├── eras          时代（同一世界的不同时间/尺度）
├── canon         可引用、可检查的事实
├── entities      地点/人物/组织/技术/事件
├── assets        带来源/许可/时代的资产记录
└── outputs       世界圣经/风格指南/资源清单
```

## 2. 关键对象

- **Era**：`tech / maintenance / cost / style(colors/materials/light)`；时代必须回答“谁维护/谁承担代价”。
- **CanonFact**：`statement / confidence / sources / dependsOn / conflictsWith / owner`；不是散文。
- **Entity**：`type / era / summary`；实体必须落到时代。
- **Asset**：`source / license / status / path`；没有许可不能发布。
- **Output**：`type / era / status`；输出不是事实源。

## 3. Lint

| 检查 | 级别 | 含义 |
| --- | --- | --- |
| canon.conflict | error | 同一/跨时代事实冲突 |
| canon.dependency | error | 依赖的 canon 不存在 |
| canon.era | error | canon 指向未知时代 |
| canon.source | warn | 没有来源 |
| era.cost / maintenance | warn | 没写代价/维护 |
| asset.source / license | warn | 资产来源/许可缺失 |
| entity.era / asset.era / output.era | error/warn | 引用未知时代 |

健康分：`100 - errors*14 - warnings*4`，下限 0。

## 4. API

- `GET /api/world`：world + lint + stats + runtime；
- `POST /api/lint`；
- `POST /api/canon`：添加事实并写回 JSON；
- `POST /api/export`：`bible` / `style` / `assets`；
- `GET /api/health`。

只监听 `127.0.0.1`；不执行世界数据中的代码；请求体上限 1MB。

## 5. 边界与扩展

- 世界 JSON 是权威；输出可重生成；
- 未来加多世界/资产库/协作时，保持同一套 canon 格式；
- 不把 AI 生成写进事实层；AI 只能作为“建议/草稿”，必须带来源与人工确认。
