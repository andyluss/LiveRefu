# LiveLand · 快速开始与案例

> 版本：v1.0 ｜ 状态：本地优先稳定核心 ｜ 日期：2026-10-28

## 一、5 分钟路径

```bash
cd lab/liveland
node src/cli.ts check
node src/cli.ts serve 4174
```

Workbench 顺序：

1. 总览：约束 / 健康 / 时代；
2. Eras：时代细节 + A/B 风格对比；
3. Canon：搜索、添加、编辑、删除；
4. Entities：人物/地点/组织；
5. Assets：缩略图 + 来源/许可；
6. Lint：冲突与缺口；
7. Outputs：世界圣经 / 风格指南 / 资产清单 / HTML。

## 二、两个本地案例

| 世界 | 文件 | 用途 |
| --- | --- | --- |
| 橙港 | `world/orange-harbor.world.json` | 3 时代、12 canon、8 实体、6 资产；含故意冲突/缺依赖演示 |
| 灰岸 | `world/glass-coast.world.json` | 2 时代、4 canon、3 实体、2 资产；多世界切换演示 |

```bash
node src/cli.ts check world/glass-coast.world.json
node src/cli.ts html world/glass-coast.world.json reports/glass-coast.html
node src/cli.ts style world/orange-harbor.world.json reports/orange-style.md
```

## 三、多世界

`worlds.json`：

```json
{
  "worlds": [
    { "id": "orange-harbor", "name": "橙港", "path": "world/orange-harbor.world.json" },
    { "id": "glass-coast", "name": "灰岸", "path": "world/glass-coast.world.json" }
  ]
}
```

Workbench 侧栏切换；`LIVELAND_WORLD` 可覆盖默认世界，`LIVELAND_REGISTRY` 可覆盖注册表。

## 四、资产

- 资产文件放 `world/assets/`；
- 元数据写 `path` / `source` / `license` / `status`；
- `/api/asset` 只读，路径限制在 world 目录内；
- 没有许可的资产不能发布。

## 五、v1.0 边界

- 本地优先、零运行时依赖；
- 不做生图、训练、云账号、团队权限、资产托管；
- 世界 JSON 是权威；输出是生成物；
- 许可/正式名仍待决策，发布前另行确认。
