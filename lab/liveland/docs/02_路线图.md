# LiveLand · 路线图与验证

## v0.1（当前，1–2 周）

- 单世界 + 3 时代 + canon/实体/资产/输出；
- lint + 添加 canon + 三种导出；
- 本地 Workbench。

**验证**：3 个爱好者能建世界；1 个 prosumer 愿意为资产/输出付费。

## v0.2（4–6 周）

- 多世界；
- canon 编辑/删除/版本；
- 资产文件预览/缩略图/来源链；
- HTML 世界页输出；
- 风格卡对比。

**验证**：1 个真实项目用 LiveLand 管 canon；愿意付费。

## v0.3（3 个月）

- 团队/权限/审阅；
- 游戏/印刷输出适配；
- 资产市场/模板；
- 本地/托管混合。

## 停止条件

- 3 个爱好者都不再用第二次；
- lint 误报高到用户关闭；
- 用户只用导出，不用 canon/资产；
- 12 个月后仍没有付费场景。
