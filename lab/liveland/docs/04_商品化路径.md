# LiveLand · 商品化路径（未来提案）

> **状态**：提案，**未实施、未排期** ｜ 日期：2026-10-27 ｜ 适用版本：v0.2+
> **原则**：核心仍是本地优先的世界/时代创作工具；商品化只在项目成熟后增加**可直接销售的成果物**，不改核心定位。
> **关联**：[产品定义](00_产品定义.md) · [路线图](02_路线图.md) · [决策记录](03_决策记录.md) · [世界模型](01_世界模型.md)

## 一、为什么现在不直接卖

LiveLand 现在卖的是“世界编译器”能力：

- 用户要自己建世界、写 canon、找美术、排版、发行；
- 爱好者愿意用，但预算低、流失快；
- 世界观本身不是商品，**被包装成可玩/可读的世界包**才是。

所以商品化不是做“AI 生成世界”，而是把 LiveLand 的 canon/时代/实体/资产输出成**一本能卖的世界包**。

## 二、Hero SKU：World Pack / 世界包

**名称（暂定）**：World Pack（设定书 + 冒险 + 地图/NPC 卡）。

| 项 | 内容 |
| --- | --- |
| **买家** | TTRPG 主持人、独立叙事团队、世界观爱好者、小型游戏工作室 |
| **交付物** | 48–64 页设定书（PDF/印刷）+ 1 个 system-agnostic 冒险/剧本 + 地图 + NPC 卡 + 势力关系图 + 资产许可清单 + 可选 VTT 素材 |
| **价格带** | 数字 ¥99–199；印刷 ¥299–399；系列/合集更高（待验证） |
| **渠道** | itch.io / DriveThruRPG / Gumroad / 自己的站 |
| **为什么能卖** | GM 买的是“能直接开团的世界”，不是编辑器；LiveLand 已有 canon/时代/实体/资产结构 |
| **不包含** | 不做完整电子游戏；不做通用 AI 生图；不承诺“自动生成可出版内容” |

### 最小扩展（未来再做）

- CLI `publish`：世界 → 设定书 HTML/print CSS；
- 模板：封面、时代章、canon 边栏、NPC 卡、地图页；
- 资产清单/许可页；
- 公开页（只展示 public 条目）。

**不做**：游戏引擎、VTT 平台、资产市场；先把一本书做出来。

## 三、备选方案

| 方案 | 卖什么 | 优点 | 风险 | 建议 |
| --- | --- | --- | --- | --- |
| **A. World Pack（推荐）** | 设定书 + 冒险 + 地图/NPC | 最接近“可直接开团”；可系列化 | 写作/美术/排版重 | 先做 |
| B. 纯设定书 | 世界圣经 | 制作较轻 | 不如“冒险”直接可用 | A 的子集 |

| D. 资产/风格包 | 地图、风格卡、素材 | 轻；可多次卖 | 依赖美术供给；易商品化 | 作为 add-on |

## 四、目标产品案例：世界观服务于什么

> 以下为**示例产品**，用于说明“世界 → 可售游戏/读物”的链路，不是路线图承诺。

### 案例 A · TTRPG 世界包《橙港》

- **形态**：48–64 页设定书（PDF/印刷）+ 3 个 system-agnostic 冒险 + 港口地图 + 8 张 NPC 卡 + VTT token 包。
- **用户**：TTRPG 主持人（GM）；想开一个“能源转型后的海港”短团，但没时间从零写设定。
- **核心体验**：GM 读完 20 页就能开第一场；每个冒险都能独立跑，又能拼成一条“维护者失踪”的线索；玩家能拿到一页“橙港居民须知”。
- **价格**：数字版 ¥129；印刷版 ¥299；VTT 包 +¥49。
- **世界观在其中的角色**：3 个时代（Archive/Solar/Cyber）不是三套皮肤，而是同一港口的三种能源/劳动/权力状态；每个时代有明确代价，玩家选择会改变结局。
- **没有 LiveLand 会怎样**：设定书、冒险、地图、NPC 卡各自为政；时间线/技术/能源矛盾；资产许可找不到来源。
- **LiveLand 的角色**：canon/时代/实体/资产/风格卡作为单一事实源；导出设定书、风格指南、资产清单；lint 阻止“这个冒险用了不存在的技术”。

### 案例 B · 叙事探索游戏《潮汐维修》

- **形态**：2–3 小时的单机叙事探索游戏；PC/移动端；2D 手绘 + 轻量系统模拟；无战斗。
- **用户**：喜欢《看火人》《肯塔基零号公路》式慢叙事、城市/劳动/技术题材的玩家。
- **核心体验**：玩家是橙港的维修学徒，一天内处理三处故障；每处故障都连着不同时代遗留的系统；玩家决定“先修谁、牺牲什么、告不告诉居民”；结局由维护选择而非战斗决定。
- **价格**：买断 ¥68 / $9.99；原声/设定集 DLC；不做内购/抽卡。
- **世界观在其中的角色**：三个时代以“闪回/旧系统”出现；每个故障都有 canon 依据；NPC 的立场由实体/势力关系决定；玩家能感到“技术选择=政治选择”。
- **规模**：3–5 人，6–9 个月；编剧/美术/程序/音频。
- **没有 LiveLand 会怎样**：三个时代的规则互相打架；任务文本与 canon 不一致；美术风格卡漂移；资产授权不可查。
- **LiveLand 的角色**：canon 是任务/对话/结局的约束；风格卡约束美术；资产清单保证可商用；v0.3 的输出适配游戏资源。

### 案例 C · 博物馆/品牌互动展《维护者的房间》

- **形态**：10–15 分钟互动装置；实体维修台 + 平板/投影；观众通过“诊断—拆解—选择”体验橙港的三个时代。
- **用户**：科技馆/城市博物馆/能源品牌；观众是家庭/学生。
- **核心体验**：观众拿起一个“故障模块”，选择先修电网、电池还是档案；屏幕展示不同时代的后果；最后打印一张“维修记录”带走。
- **价格**：机构授权 ¥5–15 万/6 个月；含内容定制/部署/维护培训。
- **世界观在其中的角色**：展览不是“复古布景”，而是用真实 canon 解释能源/维护/代价；每个时代有可触摸的材料与声音。
- **没有 LiveLand 会怎样**：展签/屏幕/语音导览三套设定；不同展区技术年代冲突；资产授权无法给馆方。
- **LiveLand 的角色**：输出展签/导览/资产清单/时代风格卡；canon 审核保证“可解释”；公开页只展示 public 内容。

## 五、成熟触发条件

- [ ] 多世界/资产预览/公开页至少有一项稳定；
- [ ] 一个世界能导出结构完整的设定书；
- [ ] 有 1 个 GM/作者愿意用真实世界试读；
- [ ] 美术/排版/授权链路可复用；
- [ ] 许可（工具与用户内容）边界写清。

## 六、商业化边界

- 用户世界与资产归用户；LiveLand 不声称拥有；
- AI 生成资产必须标注来源/模型/许可；
- 不做“未经编辑的 AI 长篇设定书”；
- 印刷/发行由合作方或按需印刷，不先建仓。

## 七、成功指标

- 第一本 World Pack 能卖出 50 份（数字+印刷）；
- 1 个 GM 实际开团并反馈；
- 制作第二本的边际成本明显下降；
- 不牺牲 canon 质量去追生成速度。

> **当前决定：只记录，不实施。** 等世界模型、导出与内容生产链路成熟后再启动。
