### 修复

- 修正灯塔光束：
  - 移除始终面向镜头、会越出底座的平面 Sprite 与旧贴图光带；

  - 保留灯室暖光与海面灯塔落点的克制光感。
- 同步重拍 `shots/` 六张 1600 × 900 截图。

- `node --input-type=module --check` 通过；
- Headless Chrome 1600 × 900 打开主视角，控制台无 JS 异常；
- 灯塔光束不再出现平面贴片感、底座外围光斑或岩石上的异常高光。

## [0.1.0] - 2026-11-17 18:59

### 新增

- 源提示词转录：`PROMPT.md`（不改变原提示词，原文仍以 `docs/prompts/` 为准）。
- 首个可交互版本：盛夏黄昏海边便利店三维微缩场景（Three.js r187，本地 vendor）。
- 36 × 36 树脂展示底座、海滨街道转角、停车位与浅蓝色小货车、西侧小巷与沙滩、浅海、防波堤 / 消波块、迷你灯塔与浮标。
- 原创品牌「ナギサマート」；全部招牌、海报、包装、路牌、地面纹理由 Canvas 程序化绘制。
- 便利店内部：货架、饮料柜、便当 / 饭团、收银台、冰咖啡机、冰淇淋柜、杂志架、夏季限定陈列、后场门、储物柜。
- 循环动效：海浪与泡沫、自动门、招牌闪烁、冷柜白雾、小风扇、风铃、空调滴水与涟漪、信号灯、灯塔光束、浮标、树影与水洼反光。
- 自由环绕相机（拖拽 / 滚轮 / 双指 / 键盘），`?view=` 视角预设与 `?t=` 定格参数。
- 1600 × 900 截图六张：`shots/hero.png`、`front.png`、`detail.png`、`aerial.png`、`alley.png`、`sea.png`。

### 验证

- 全部 `src/*.js` 通过 `node --input-type=module --check`；
- Headless Chrome 1600 × 900 打开 8 个视角，控制台无 JS 异常；
- CDP 模拟拖拽 / 滚轮，相机位移 38.2 / 15.3 场景单位；
- 无人物、无真实品牌、无乱码、无 UI overlay。
