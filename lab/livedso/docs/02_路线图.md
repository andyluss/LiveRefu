# LiveDSO · 路线图与验证

## v0.1（当前，1–2 周）

- 本地 vault、token 解析、3 类闸门、契约、风格卡、报告、CSS 投影、Workbench。

**验证**：自己和 1 个朋友的真实 vault 能跑；能发现真实问题。

## v0.2（4–6 周）

- 契约编辑 + 预览；
- 采用扫描（按 repo/产品）；
- GitHub App/PR 评论；
- 多 vault；
- 风格卡对比。

**验证**：1 个团队愿意为审计/迁移付费。

## v0.3（3 个月）

- 私有 registry、团队、版本/弃用；
- CI 集成；
- 自托管/托管；
- 插件 API。

**验证**：3 个付费团队；续费/服务收入。

## 12 个月

- 开源核心 + 企业版；
- 审计/迁移/培训服务；
- 设计系统“健康报告”成为入口。

## 停止条件

- 3 个目标团队都不愿为审计付费；
- 每次交付都要定制，无法复用；
- 12 个月后收入仍 100% 来自一次性服务。
