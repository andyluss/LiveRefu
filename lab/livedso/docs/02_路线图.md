# LiveDSO · 路线图与验证

## v0.1（已完成）

- 本地 vault、token 解析、3 类闸门、契约、风格卡、报告、CSS 投影、Workbench。

**验证**：自己和 1 个朋友的真实 vault 能跑；能发现真实问题。

## v0.2（已完成）

- 导入 `design/tokens` 真实 case（229 tokens）；
- token 值编辑、报告、投影、风格卡。

## v0.3（已完成）

- 契约编辑（写回 JSON）；
- 真实 token 组件预览。

## v0.4（已完成）

- 采用扫描（CLI/API/UI）；
- token 引用/裸色/未知变量统计；
- 只读，不改目标代码。

## v0.5（已完成）

- 多 vault 切换（`vaults.json`）；
- 风格卡并排对比。

## v0.6（当前）

- token 生命周期/弃用（deprecated/replacedBy/note）；
- 契约/风格卡弃用检查；
- 采用扫描统计弃用引用；
- 团队/私有 registry/托管下一步。

**验证**：1 个独立开发者/小团队愿意用真实 vault 连续跑一周；采用扫描能发现真实旧引用。

## v0.7（3 个月）

- 团队/权限、私有 registry、托管、插件 API；
- CI 集成；
- 自托管/托管；
- 插件 API。

**验证**：3 个付费团队；续费/服务收入。

## 12 个月

- 开源核心 + 企业版；
- 审计/迁移/培训服务；
- 设计系统“健康报告”成为入口。

- 12 个月后收入仍 100% 来自一次性服务。
