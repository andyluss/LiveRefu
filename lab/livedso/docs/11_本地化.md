## 一、语言切换

- 顶部 `EN` / `中文` 切换；
- 首次按输入 URL 的 `?lang=zh|en` 强制覆盖；
- 否则按 `navigator.language`，之后存 `localStorage.livedso-locale`；
- 默认 URL 不带 `?lang`；主动切换语言时移除该参数，避免日常链接被语言污染；
- `<html lang>` 同步。

正式名按语言显示：中文 **灵动构坊**，英文 **LiveAtelier**；代号 LiveDSO 只用于技术/配置。

## 二、规则 message

- 内置检查的每条 issue 同时携带 `message` / `messageEn`、`detail` / `detailEn`；
- API 通过 `?lang=en` 返回英文规则消息；
- CLI 通过 `--lang en` 返回英文；
- 插件可返回 `messageEn`。

```bash
curl 'http://127.0.0.1:4173/api/state?lang=en'
node src/cli.ts check --lang en
node src/cli.ts report --lang en --out reports/en.md
```

## 三、i18n 审计

```bash
cd lab/livedso
npm run i18n:check
node tools/i18n-audit.ts --json
```

验证词表条目、HTML 文案/属性覆盖率，以及 `?lang` 优先级、URL 清理、API 带语言、localStorage、`html lang` 等行为。

## 四、不翻译项

见 [`13_本地化词表.md`](13_本地化词表.md)：

- Token 等生态技术词保留；
- Vault 中文为“藏库”，技术路径/配置仍用 `vault`；
- 用户 vault 内容（风格卡说明、契约摘要等）保持源语言，不做机器翻译。

## 五、边界

- 不做账号/云端语言同步；
- 不自动翻译用户内容；
- 规则英文覆盖内置规则，插件需自行提供 `messageEn`。
