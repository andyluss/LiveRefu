# LiveDSO · 本地化词表与待处理项

> 版本：v1.3.1 ｜ 日期：2026-10-28

## 一、保留不译的技术词

这些词在中文 UI 中保留英文，因为它们是生态/协议/命令的一部分：

| 词 | 原因 |
| --- | --- |
| Token | DTCG/设计系统通用术语；翻译成“令牌”会与代码/文档脱节 |
| Vault / 藏库 | 中文 UI 用“藏库”；`vault/`、`LIVEDSO_VAULT`、API/代码继续用 Vault/vault |
| CSS / JSON / API / URL | 技术标准 |
| CI / PR / Git | 工具链术语 |
| ref / sys / product | token 层级标识符 |
| a11y | 无障碍领域缩写 |
| DTCG | 设计 token 规范名 |

## 二、UI 已英文化范围

- 导航、分组、页面标题、工具栏、按钮、空状态、常见 toast；
- 路由 hash 不随语言变化；
- 产品正式名按语言切换：灵动构坊 / LiveAtelier。

## 三、仍保持源语言的内容

以下**不是 UI 文案**，不自动翻译：

- vault 里的风格卡名称、era、维护说明；
- 契约标题/摘要/anatomy/states 等用户数据；
- 报告正文、token 路径/值、文件路径；
- 检查问题的具体 message：内置规则现在有中英文；插件可提供 `messageEn`。

如果你希望这些也按语言生成，需要为 vault 增加 locale sidecar；这是后续决策，不在 v1.1 做。

## 四、已实现

- 中文 UI：`Vault` → **藏库**；`Token` 保留；
- 内置规则 message 有英文版本；插件支持 `messageEn`；
- `?lang=zh|en` 强制覆盖，切换后同步 URL。

## 五、仍待你后续处理

- 是否把 `Token` 也翻成中文；
- 用户 vault 内容是否增加 locale sidecar。
