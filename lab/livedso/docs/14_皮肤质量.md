# LiveDSO · 皮肤质量诊断与修复

> 版本：v1.6.1 ｜ 日期：2026-10-28 ｜ 范围：风格卡应用到 Workbench 自身（狗粮）
> 相关：[`12_自我皮肤.md`](12_自我皮肤.md)、[`13_本地化词表.md`](13_本地化词表.md)

## 一、结论

问题不是“换肤失败”，而是三层叠加：

1. **风格卡角色太少**：只有 `bg/surface/text/action/focus/danger`，无法表达边框、抬升面、弱文字、按钮前景；
2. **映射把层级压平**：`surface2/raised=surface`、`line=surface`、`dim/muted=text`、`ok=action`、`warn=focus`；
3. **坏卡本身**：把主色当 surface、bg/surface 相同、line 与 surface 相同。

症状：面板融在一起、表格没有边界、弱文字消失、浅色皮肤下控件仍是深色、主题切换像失效。

## 二、证据

以三张卡为例（实际计算值）：

| 卡 | bg | surface | line | text | 结果 |
| --- | --- | --- | --- | --- | --- |
| Material 3 / Dark | `#1C1B1F` | `#6750A4`（primary） | `#6750A4` | `#FFFFFF` | 整页紫色，面板/边框同色 |
| Cassette / Daylight | `#D8C3A5` | `#D8C3A5` | `#D8C3A5` | `#171717` | 可读但完全无层级 |
| Tailwind / Paper | `#F8FAFC` | `#F8FAFC` | `#F8FAFC` | `#020617` | 全白，边界消失 |

共同点：

- `surface2 == raised == surface`；
- `dim == muted == text`；
- `line == surface`；
- `ok == action`，`warn == focus`；
- `color-scheme` 仍由旧主题决定。

## 三、目标 schema

风格卡可继续用 6 个基础角色，但建议逐步补齐：

```json
{
  "mode": "dark",
  "roles": {
    "bg": "...",
    "surface": "...",
    "surfaceRaised": "...",
    "text": "...",
    "textMuted": "...",
    "border": "...",
    "borderStrong": "...",
    "action": "...",
    "onAction": "...",
    "focus": "...",
    "danger": "...",
    "success": "...",
    "warning": "..."
  }
}
```

兼容策略：

- 新字段优先；
- 缺省时从 `bg/surface/text/action/focus` 派生，旧卡不改也能运行；
- `mode` 缺省时按 `bg` 亮度推断；
- 不把 `surface` 绑定到品牌主色，主色只做 action/焦点。

## 四、修复优先级

### P0 · 让现有卡可用

- 派生 `surfaceRaised` / `surface2` / `border` / `textMuted` / `onAction`；
- `--line` 不再等于 surface；
- 派生 `--shadow` / `--glass` / `--schema`；
- 皮肤激活时设置 `color-scheme` 与皮肤模式；
- 主题切换时先清除皮肤，避免两套系统打架；
- 修 Material 3 / Dark、Cassette / Daylight、Tailwind / Paper 三张坏卡。

### P1 · 把质量变成可检查项

- `npm run skin:check`：遍历所有 vault/风格卡，计算：
  - text/surface ≥ 4.5；
  - text/bg ≥ 4.5；
  - textMuted/surface ≥ 4.5；
  - textMuted/bg ≥ 4.5；
  - textMuted/sunken ≥ 4.5；
  - onAction/action ≥ 4.5；
  - focus/surface ≥ 3.0；
  - border/surface ≥ 3.0（非文本 UI）；
- 失败退出码 1，可接本地 CI；
- 风格卡页显示 `AA / AAA / FAIL` 徽标与通过数。

### P2 · 视觉回归

- `npm run skin:snapshot -- --limit N`：每张卡 × overview/tokens/checks 三页截图；
- 已提供 [`tools/skin-snapshot.ts`](../tools/skin-snapshot.ts)；
- 至少覆盖浅色、深色、高对比三类；
- 任何新卡先过 `skin:check` 再进选择器。

## 五、验收标准

- 33 张卡全部通过 `npm run skin:check`；
- `text/bg` 与 `textMuted/sunken` 必须纳入审计，避免“亮 surface 掩盖暗 bg”的假通过。
- 风格卡页可见 `AA/AAA/FAIL`；
- 任意卡下，正文/面板/边框可区分；
- 皮肤激活时，原生控件跟随明暗；
- 主题切换不会留下“半套皮肤”；
- 预览与 Workbench 使用同一套派生 token。

## 六、非目标

- 不把风格卡升级为完整品牌主题系统；
- 不引入第三方 UI 框架；
- 不保证任何用户自制卡都好看；坏卡应被检查器挡住，而不是静默应用。

## 七、扩展角色（v1.6）

在基础 6 角色之外，`roles` 现在还接受 50 个语义角色；缺省时自动派生：

```text
表面   bg / bgSubtle / surface / surfaceRaised / surfaceSunken / surfaceHover
文字   text / textOnSurface / textMuted / textSubtle / textInverse / textLink / textVisited / textDisabled
边框   border / borderStrong / borderSubtle / divider / focus
动作   action / actionHover / actionPressed / actionDisabled / onAction
       secondaryAction / onSecondaryAction / ghostAction
状态   danger / onDanger / dangerSubtle
       success / onSuccess / successSubtle
       warning / onWarning / warningSubtle
       info / onInfo / infoSubtle
扩展   accent / accent2 / selection / codeBg / codeText
图表   chart1 ... chart6
```

兼容策略：旧卡只写 6 个基础角色也能运行；新字段优先，缺失自动派生。
审计覆盖核心可读性对：text/bg、text/surface、muted/bg、muted/sunken、link/bg、onAction/action、focus、border。

## 八、URL 深链

藏库与皮肤选择会写入 URL，便于分享/复现：

```text
?vault=material-3&skin=material-3-dark
?vault=tailwind&skin=tailwind-paper&lang=en
```

- `vault`：当前藏库 id；
- `skin`：当前风格卡 id；为空则移除；
- `lang` 仍是输入型覆盖参数，不会自动添加；
- 切换藏库时，旧藏库不存在的 skin 会自动清空并从 URL 移除。
