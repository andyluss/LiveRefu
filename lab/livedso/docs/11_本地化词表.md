# LiveAtelier · 本地化词表与待处理项

> 版本：v1.1 ｜ 日期：2026-10-28

## 一、保留不译的技术词

这些词在中文 UI 中保留英文，因为它们是生态/协议/命令的一部分：

| 词 | 原因 |
| --- | --- |
| Token | DTCG/设计系统通用术语；翻译成“令牌”会与代码/文档脱节 |
| Vault | 本地数据目录概念；与 `LIVEDSO_VAULT` 配置一致 |
| CSS / JSON / API / URL | 技术标准 |
| CI / PR / Git | 工具链术语 |
| ref / sys / product | token 层级标识符 |
| a11y | 无障碍领域缩写 |
| DTCG | 设计 token 规范名 |

## 二、UI 已英文化范围

- 导航、分组、页面标题、工具栏、按钮、空状态、常见 toast；
- 路由 hash 不随语言变化；
- 产品正式名按语言切换：灵动构坊 / LiveAtelier。

## 三、仍保持源语言的内容

以下**不是 UI 文案**，不自动翻译：

- vault 里的风格卡名称、era、维护说明；
- 契约标题/摘要/anatomy/states 等用户数据；
- 报告正文、token 路径/值、文件路径；
- 检查问题的具体 message（来自规则/插件）。

如果你希望这些也按语言生成，需要为 vault 增加 locale sidecar；这是后续决策，不在 v1.1 做。

## 四、待你后续处理

- 是否把 `Token`/`Vault` 也翻成中文（当前保留）；
- 是否为规则 message 增加英文版本；
- 是否需要 `?lang=zh|en` 强制覆盖（当前用切换 + localStorage）。
