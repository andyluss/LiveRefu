# LiveDSO · 架构与数据模型（v1.3.1）

> 版本：v1.3.1 ｜ 日期：2026-10-28

## 1. 分层

```text
Web Workbench (web/)
  → Node HTTP API (src/server.ts)
  → Vault (src/vault.ts)
  → Domain (tokens / checks / history / ci)
  → File system (vault/)
```

无数据库、无云、无第三方运行时依赖；每次请求重读 vault，源就是真相。

## 2. Token

- DTCG 风格 `$value` / `$type`；
- 语义三层 `ref` / `sys` / `product`；
- 别名 `{a.b.c}` 递归解析；断链/循环 → error；
- 投影为 `--dso-<path>` CSS variables；
- 生命周期：`deprecated` / `replacedBy` / `deprecationNote`。

## 3. 检查与插件

内置规则同时返回中英文消息：

- alias.broken / token.raw-color；
- token.deprecated-*；
- focus.reuses-action；
- contrast.low；
- contract.* / style-card.*。

插件为本地 `.mjs` / `.js`，可返回 `message` + `messageEn`；无沙箱，只加载可信代码。

## 4. 本地能力

- 采用扫描：Token/裸色/未知变量/弃用引用；
- 快照：`vault/.history/`，diff 只读；
- 趋势：跨快照/跨 vault；
- CI：`ci` 聚合所有 vault、阈值、退出码；
- 报告：health/release/自定义模板、报告包；
- 路由：hash + 深链；
- 本地化：zh/en + `?lang` + 规则英文；
- 自我皮肤：风格卡 `roles` → 工作台 CSS 变量。

## 5. API

- `GET /api/state?lang=`
- `POST /api/check?lang=`
- `POST /api/report?lang=`
- `POST /api/report/bundle`
- `POST /api/token` / `POST /api/token/lifecycle`
- `POST /api/contract`
- `POST /api/adopt`
- `GET /api/history` / `POST /api/history` / `POST /api/history/diff`
- `GET /api/trends` / `GET /api/vaults/overview`
- `GET /api/report/templates`

所有响应 JSON；静态文件从 `web/` 提供；无 CORS/远程调用。

## 6. 安全边界

- 只监听 `127.0.0.1`；
- 静态文件路径规范化，拒绝越界；
- 请求体上限 1MB；
- 不执行 vault 中的任意代码；插件显式本地加载；
- 写操作只写源 JSON，不自动 Git 提交；
- 云/账号/团队/托管搁置。
