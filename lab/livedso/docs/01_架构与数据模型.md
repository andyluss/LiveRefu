# LiveDSO · 架构与数据模型（v0.1）

## 1. 分层

```text
Web Workbench (web/)
  → Node HTTP API (src/server.ts)
  → Vault (src/vault.ts)
  → Domain (tokens.ts / checks.ts)
  → File system (vault/)
```

无数据库、无云、无第三方依赖；索引即内存解析，每次请求重读 vault，保证“源就是真相”。

## 2. Token

- 兼容 DTCG 风格 `$value` / `$type`；
- 语义三层：`ref` / `sys` / `product`；
- 别名 `{a.b.c}` 递归解析；断链/循环 → `null` + error；
- 投影为 `--dso-<path>` CSS variables。

## 3. 检查

| 检查 | 默认严重度 | 说明 |
| --- | --- | --- |
| alias.broken | error | 别名目标不存在/循环 |
| token.raw-color | warn | 语义层直接写色值 |
| contrast.low | error（AA）/ warn（AAA） | 对比度低于阈值 |
| focus.reuses-action | error | 焦点色复用主行动色 |
| contract.missing | warn | 契约缺字段 |
| contract.states | warn | 状态少于 5 个 |
| contract.token-missing | error | 契约引用不存在的 token |
| style-card.* | warn | 风格卡缺名称/维护说明/未知 token |

健康分：`100 - errors*14 - warnings*4`，下限 0。

## 4. API

- `GET /api/state`
- `POST /api/check`
- `POST /api/token`（`{path,value}`）
- `POST /api/report`
- `POST /api/projection`
- `GET /api/health`

所有响应 JSON；静态文件从 `web/` 提供；无 CORS/远程调用。

## 5. 安全/边界

- 只监听 `127.0.0.1`；
- 静态文件路径规范化，拒绝越界；
- 请求体上限 1MB；
- 不执行 vault 中的任意代码；只读 JSON/写 token 值；
- 不自动 Git 提交。
