# LiveDSO · 产品定义（v1.5.0）

> 状态：stable ｜ 日期：2026-10-28 ｜ 代号 LiveDSO；正式名 **LiveAtelier / 灵动构坊**。

## 1. 问题

设计系统团队知道“应该有一个源”，但日常现实是：

- Token 在 Figma、代码、文档三处漂移；
- 组件只有样子，没有状态/键盘/错误处理；
- 对比度、裸值、弃用在发布前才发现；
- 不知道哪个产品用了旧组件；
- 每次变更都像拆弹。

## 2. 用户

| 用户 | 任务 | 付费理由 |
| --- | --- | --- |
| **独立开发者（首批）** | 一个人维护 token/组件/风格卡 | 省时间、能直接导出/报告 |
| 设计系统负责人 | 证明系统被采用、降低变更风险 | 审计/采用/迁移 |
| 设计工程师 | 从源生成多端、过 CI | 自动投影/闸门 |
| 产品设计师 | 看见代码里真正有什么 | 可信目录/状态 |
| 代理机构 | 复用方法交付客户 | 模板/白标/审计 |

## 3. 价值主张

> 不是“展示设计系统”，而是“运行设计系统”：让变更从源到所有产品可见、可检查、可回溯。

## 4. v1.4 范围

**本地核心**：

- Token 解析/别名、DTCG 风格、`ref/sys/product` 分层；
- 闸门：别名/裸色/对比度/焦点/契约/风格卡/弃用；
- 契约编辑、真实 Token 组件预览、风格卡对比；
- 采用扫描、快照/差异、跨快照趋势、跨 vault 趋势；
- 跨 vault CI、插件、报告模板/报告包、Vaults 总览；
- hash 路由、中文/English、自我皮肤、分组导航；
- i18n 审计脚本；
- 11 套 vault 样本：LRDS / minimal / 5 套流行系统启发 / 3 套复古未来。

**不做**（按用户裁决搁置）：Figma 同步、云协作、账号、计费、团队权限、私有 registry、托管、自动回滚、自动改目标代码。

## 5. 成功指标

- 10 分钟内接入真实 vault；
- 发现至少 1 个真实漂移/对比度问题；
- 改契约后在预览看到变化；
- 采用扫描找到旧 Token/裸色；
- 能切换多 vault 并保持判断一致；
- 快照 diff、CI、插件、报告包可在本地闭环；
- 中英文切换与 `?lang` 覆盖可验证；
- 自己每天愿意打开。

## 6. 非目标

- 通用设计工具/文档站；
- AI 自动生成设计系统；
- 把维护/代价藏起来。
