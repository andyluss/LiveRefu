# LiveDSO · 本地 CI 集成

> 版本：v1.3.1 ｜ 日期：2026-10-28 ｜ 原则：本地优先，不接云、不上传
> 命令：`node src/cli.ts ci`

## 一、它做什么

`ci` 读取 `vaults.json`，对所有 vault 聚合：

- 健康分 / errors / warnings；
- 可选采用扫描：Token 引用、裸色、未知 `--dso-` 变量、弃用引用；
- 可选基线快照 diff；
- 阈值与退出码；
- JSON 或 Markdown 报告。

不创建账号、不连接托管服务、不上传 vault。

## 二、本地运行

```bash
cd lab/livedso
node src/cli.ts ci
node src/cli.ts ci --strict
node src/cli.ts ci --adopt ../../design --out reports/ci.md
node src/cli.ts ci --json
```

退出码：`0` 通过，`1` 被阈值/错误/严格模式阻断。

## 三、阈值

| 参数 | 含义 |
| --- | --- |
| 无参数 | 只要求 `errors = 0` |
| `--strict` | warnings/裸色/未知变量/弃用引用必须为 0 |
| `--max-warnings N` | warnings 上限 |
| `--max-raw N` | 裸色上限 |
| `--max-deprecated N` | 弃用 Token 引用上限 |
| `--baseline <id>` | 每个 vault 与自己的快照对比 |

`--adopt <dir>` 对每个 vault 用它的 Token 映射扫描同一目录。

## 四、模板

- [`../templates/github-actions.yml`](../templates/github-actions.yml)
- [`../templates/gitlab-ci.yml`](../templates/gitlab-ci.yml)

模板默认工作目录 `lab/livedso`，按仓库结构调整。

## 五、边界

- 不做云托管、账号、团队权限、计费；
- 不自动改目标代码；
- baseline 只读，不自动回滚；
- 报告是否提交由项目决定；LiveDSO 不自动提交 Git。
