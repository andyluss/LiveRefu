# LiveDSO · 本地 CI 集成

> 状态：v0.8 ｜ 日期：2026-10-27 ｜ 原则：**本地优先，不接云、不上传**
> 命令：`node src/cli.ts ci`

## 一、它做什么

`ci` 读取 `vaults.json`，对**所有 vault** 聚合：

- 健康分 / errors / warnings；
- 可选的采用扫描：token 引用、裸色、未知 `--dso-` 变量、弃用引用；
- 可选的基线快照 diff；
- 阈值与退出码；
- JSON 或 Markdown 报告。

它不创建账号、不连接托管服务、不上传 vault。

## 二、本地运行

```bash
cd lab/livedso

# 只看汇总
node src/cli.ts ci

# 严格：任何 warning/裸色/未知变量/弃用引用都失败
node src/cli.ts ci --strict

# 带采用扫描与基线
node src/cli.ts ci \
  --adopt ../../design \
  --baseline 2026-10-27T22-28-38.973-08-00 \
  --max-warnings 0 \
  --max-raw 20 \
  --max-deprecated 0 \
  --out reports/ci.md

# 机器可读
node src/cli.ts ci --json
```

退出码：`0` = 通过；`1` = 被阈值/错误/严格模式阻断。

## 三、阈值

| 参数 | 含义 |
| --- | --- |
| 无参数 | 只要求 `errors = 0`（warnings 不阻断） |
| `--strict` | warnings / 裸色 / 未知变量 / 弃用引用全部必须为 0 |
| `--max-warnings N` | warnings 上限 |
| `--max-raw N` | 采用扫描的裸色上限 |
| `--max-deprecated N` | 采用扫描的弃用 token 引用上限 |
| `--baseline <id>` | 每个 vault 与自己的快照对比，diff 会进报告；缺快照即失败 |

`--adopt <dir>` 对每个 vault 用它的 token 映射扫描同一目录；适合多品牌/多产品共用代码库。

## 四、GitHub Actions 片段

不要求 LiveDSO 自建 CI 服务；把本地命令放进任意 CI：

```yaml
name: livedso
on: [push, pull_request]
jobs:
  design-system:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 24
      - name: LiveDSO CI
        working-directory: lab/livedso
        run: node src/cli.ts ci --strict --adopt ../../design --out reports/ci.md
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: livedso-ci
          path: lab/livedso/reports/ci.md
```

GitLab / 其他 CI 只需复用一个执行 `node src/cli.ts ci` 的 job。

## 五、边界

- 不做云托管、账号、团队权限、计费；
- 不自动改目标代码；
- baseline 只读，不自动回滚；
- 报告文件是否提交由项目决定；LiveDSO 不自动提交 Git。
