## 一、hash 路由

导航使用 hash 路由，刷新、收藏、前进/后退都可恢复视图：

| hash | 视图 |
| --- | --- |
| `#/overview` | 总览 |
| `#/tokens` | Token |
| `#/contracts` | 组件契约 |
| `#/preview` | 组件预览 |
| `#/style-cards` | 风格卡 |
| `#/checks` | 质量闸门 |
| `#/adoption` | 采用扫描 |
| `#/history` | 历史快照 |
| `#/trends` | 趋势 |
| `#/vaults` | 多藏库总览 |
| `#/report` | 报告与投影 |

未知 hash 回退 `#/overview`；服务端仍只提供静态文件，不需要额外 rewrite。

## 二、导航分组

- **工作台**：总览 / Token / 组件契约 / 组件预览；
- **审视**：风格卡 / 质量闸门 / 采用扫描；
- **本地**：历史 / 趋势 / 多藏库；
- **输出**：报告与投影。

## 三、边界

- 路由是前端 hash，不依赖服务端历史回退；
- hash 是技术标识，不随界面语言变化；
- 不引入前端路由依赖。
