## 一、路由

导航使用 hash 路由，刷新/收藏/前进后退都可恢复视图：

| hash | 视图 |
| --- | --- |
| `#/overview` | 总览 |
| `#/tokens` | Token |
| `#/contracts` | 组件契约 |
| `#/preview` | 组件预览 |
| `#/style-cards` | 风格卡 |
| `#/checks` | 质量闸门 |
| `#/adoption` | 采用扫描 |
| `#/history` | 历史快照 |
| `#/trends` | 趋势 |
| `#/vaults` | 多库总览 |
| `#/report` | 报告与投影 |

未知 hash 回退 `#/overview`；服务端仍只提供静态文件，不需要额外 rewrite。

## 二、导航分组

- **工作台**：总览 / Token / 契约 / 预览；
- **审视**：风格卡 / 闸门 / 采用扫描；
- **本地**：历史 / 趋势 / 多库；
- **输出**：报告与投影。

## 三、语言

- 顶部 `EN` / `中文` 切换；
- 首次按 `navigator.language` 判断，之后存 `localStorage.livedso-locale`；
- 中文正式名：**灵动构坊**；英文正式名：**LiveAtelier**；代号 LiveDSO 仅用于技术/配置；
- `<html lang>` 同步。

### 不翻译/保留项

见 [`11_本地化词表.md`](11_本地化词表.md)。用户 vault 数据（风格卡名称/说明、契约摘要）保持源语言，不做机器翻译。

## 四、自我皮肤（狗粮）

顶栏“皮肤”可选任一风格卡：

- 风格卡 `roles` 映射到 LiveAtelier 自身的 `--bg/--surface/--text/--accent/...`；
- 选择“默认”恢复全局主题；
- 选择保存在 `localStorage.livedso-skin`；
- 这是狗粮：用产品自己的风格卡验证角色是否足够，而不是只预览组件。

## 五、边界

- 不接云/账号；
- 皮肤是本地即时样式，不写回风格卡；
- 路由是前端 hash，不依赖服务端历史回退。
