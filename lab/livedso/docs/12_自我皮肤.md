# LiveDSO · 自我皮肤（狗粮）

> 版本：v1.3.1 ｜ 日期：2026-10-28 ｜ 代号 LiveDSO

## 一、是什么

顶栏“皮肤”选择器把 vault 里的风格卡应用到 LiveDSO 自身，而不只是预览组件：

- 验证风格卡 `roles` 是否足够表达背景/表面/文字/动作/焦点；
- 让工具本身成为设计系统的第一个消费者；
- 只改变本地即时样式，不写回风格卡。

## 二、映射

风格卡 `roles` → LiveDSO CSS 变量：

| 角色 | CSS 变量 |
| --- | --- |
| `bg` | `--bg` / `--bg2` |
| `surface` | `--surface` / `--surface2` / `--raised` |
| `text` | `--text` / `--dim` / `--muted` |
| `action` | `--accent` / `--ok` |
| `focus` | `--focus` / `--warn` |
| `danger` | `--danger` / `--accent2` |

## 三、使用

- 顶栏“皮肤”选择任一风格卡；
- “默认”恢复全局主题；
- 选择保存在 `localStorage.livedso-skin`；
- 主题切换与皮肤是两层：皮肤覆盖变量，主题切换仍可重置为默认。

## 四、边界

- 皮肤只在前端即时生效；
- 不修改 vault/风格卡；
- 不接云/账号；
- 不替代真实产品的组件级主题系统。
