# LiveDSO · 快速开始与案例

> 版本：v1.4.0 ｜ 状态：本地优先稳定核心 ｜ 日期：2026-10-28

## 一、5 分钟路径

```bash
cd lab/livedso
node src/cli.ts check                       # 默认 vault
for v in vaults/*/; do node src/cli.ts check "$v"; done  # 全部样本
LIVEDSO_VAULT=vaults/minimal node src/cli.ts check
node src/cli.ts serve 4173                  # Workbench
```

浏览顺序：

1. **Tokens**：解析值、alias、对比度、生命周期；
2. **Contracts**：契约字段与引用；
3. **Preview**：用真实 token 渲染；
4. **Style cards**：并排对比；
5. **Checks**：闸门；
6. **Adoption**：扫描代码引用；
7. **History / Trends / Vaults**：本地历史与多 vault；
8. **Report**：模板与报告包。

导航/深链、语言与自我皮肤分别见 [`10_路由.md`](10_路由.md)、[`11_本地化.md`](11_本地化.md)、[`12_自我皮肤.md`](12_自我皮肤.md)。

## 三、本地工作流

```bash
# 改 token / 契约 → 跑闸门
node src/cli.ts check

# 采用扫描（只读）
node src/cli.ts adopt ../../design

# 本地快照 + 差异
node src/cli.ts snapshot
node src/cli.ts diff <snapshot-id>

# 跨 vault CI
node src/cli.ts ci --strict --adopt ../../design --out reports/ci.md

# 插件自检
node src/cli.ts plugin-test --plugins examples/plugins

# 报告包
node src/cli.ts report --bundle --out-dir reports/bundle
```

## 四、接入自己的 vault

最小结构：

```text
my-vault/
  tokens/*.json
  contracts/*.json
  style-cards/*.json
  checks.json
```

```bash
LIVEDSO_VAULT=/path/to/my-vault node src/cli.ts check
LIVEDSO_VAULT=/path/to/my-vault node src/cli.ts serve 4173
```

`vaults.json` 注册全部 11 套样本；路径相对注册表解析。完整说明见 [`../vaults/README.md`](../vaults/README.md)。

## 五、v1.4 的稳定边界

- 本地优先、零运行时依赖；
- 不接云、不做账号/团队/托管；
- 写操作只写 vault 源 JSON，不自动提交 Git；
- 采用扫描/快照/报告均只读或本地生成。

详见 [`00_产品定义.md`](00_产品定义.md)、[`08_报告模板.md`](08_报告模板.md)、[`07_插件API.md`](07_插件API.md)。
