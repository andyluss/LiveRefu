# LiveDSO · 快速开始与案例

> 版本：v1.0 ｜ 状态：本地优先稳定核心 ｜ 日期：2026-10-28

## 一、5 分钟路径

```bash
cd lab/livedso
node src/cli.ts check                       # 内置示例 vault
LIVEDSO_VAULT=examples/minimal-vault node src/cli.ts check
node src/cli.ts serve 4173                  # Workbench
```

浏览顺序：

1. **Tokens**：解析值、alias、对比度、生命周期；
2. **Contracts**：契约字段与引用；
3. **Preview**：用真实 token 渲染；
4. **Style cards**：并排对比；
5. **Checks**：闸门；
6. **Adoption**：扫描代码引用；
7. **History / Trends / Vaults**：本地历史与多 vault；
8. **Report**：模板与报告包。

## 二、三个本地案例

| 案例 | 路径 | 用途 |
| --- | --- | --- |
| LRDS sample | `vault/` | 37 tokens；含契约/风格卡/生命周期示例 |
| LRDS real | `vault-lrds/` | 229 tokens；从 `design/tokens` 导入 |
| Minimal | `examples/minimal-vault/` | 10 tokens / 1 契约 / 1 风格卡；复制起点 |

```bash
node src/cli.ts report examples/minimal-vault reports/minimal-health.md
node src/cli.ts adopt ../../design --json
```

## 三、本地工作流

```bash
# 改 token / 契约 → 跑闸门
node src/cli.ts check

# 采用扫描（只读）
node src/cli.ts adopt ../../design

# 本地快照 + 差异
node src/cli.ts snapshot
node src/cli.ts diff <snapshot-id>

# 跨 vault CI
node src/cli.ts ci --strict --adopt ../../design --out reports/ci.md

# 插件自检
node src/cli.ts plugin-test --plugins examples/plugins

# 报告包
node src/cli.ts report --bundle --out-dir reports/bundle
```

## 四、接入自己的 vault

最小结构：

```text
my-vault/
  tokens/*.json
  contracts/*.json
  style-cards/*.json
  checks.json
```

```bash
LIVEDSO_VAULT=/path/to/my-vault node src/cli.ts check
LIVEDSO_VAULT=/path/to/my-vault node src/cli.ts serve 4173
```

`vaults.json` 可注册多个 vault；路径相对注册表解析。

## 五、v1.0 的稳定边界

- 本地优先、零运行时依赖；
- 不接云、不做账号/团队/托管；
- 写操作只写 vault 源 JSON，不自动提交 Git；
- 采用扫描/快照/报告均只读或本地生成。
