## 一、为什么现在不直接卖

LiveFile 现在卖的是“档案能力”：

- 用户要自己整理文件、补 sidecar、跑备份、决定公开什么；
- “本地优先/可继承”是理念，不是普通人会直接购买的商品；
- 普通人不会为“索引”付费，但会为**“把家人的东西留下来”**付费。

所以商品化不是做网盘，而是把档案输出成**一本可触摸的档案书**。

## 二、Hero SKU：Archive Book / 档案书

**名称（暂定）**：Archive Book（家庭档案书 / 个人档案书）。

| 项 | 内容 |
| --- | --- |
| **买家** | 家庭、信息密集的个人、纪念日/婚礼/搬家/退休礼物 |
| **交付物** | 精选照片/信件/票据/时间线 + 来源/许可页 + 隐私页 + 数字版 + 可选印刷版 |
| **价格带** | 数字 ¥99–199；印刷 ¥299–699（按页数/装帧，待验证） |
| **为什么能卖** | 情感价值高；书是可触摸的成品；LiveFile 已有 sidecar/时间线/集合/来源 |
| **不包含** | 不做云相册/网盘；不做法律遗嘱；不自动公开任何私密条目 |

### 最小扩展（未来再做）

- CLI `book`：选择条目 → 档案书 HTML/print CSS；
- 选择/删除/隐私检查；
- 来源/许可页；
- 按需印刷对接（先数字版，后印刷）。

**不做**：印刷供应链、仓储、物流；先做数字样书/按需印刷。

## 四、目标产品案例：个人档案服务于什么

> 以下为**示例产品**，用于说明“档案 → 可售书/服务”的链路，不是路线图承诺。

### 案例 A · 家庭档案书《橙港一家人》

- **形态**：96–120 页布面/纸面书；4 章：海、家、修、信；40 张照片、12 封信、8 张票据、1 条 2026–2031 时间线；数字版 + 印刷版。
- **用户**：一个家庭；给父母 60 岁/退休/搬家做纪念；子女负责整理，父母确认。
- **核心体验**：不是“全部文件打印”，而是 30–60 个被选择的瞬间；每张图有日期/来源/许可；隐私页说明哪些内容没有收进来。
- **价格**：数字版 ¥129；印刷版 ¥399–599；加印 ¥199。
- **档案在其中的角色**：照片/信件/票据/时间线来自 LiveFile 索引；sidecar 保证日期/来源/许可；隐私检查保证不把私密条目放进书。
- **没有 LiveFile 会怎样**：照片散在手机/云盘/旧硬盘；日期靠猜；谁授权使用不清楚；印刷前才发现缺原图。
- **LiveFile 的角色**：选择/去重/来源/时间线/导出；生成 print CSS；不改变原始文件。

### 案例 B · 研究者田野档案书《田野之后》

- **形态**：160 页限量版；访谈节选、田野笔记、地图、音频转录（二维码）、来源/许可页；100 本编号。
- **用户**：人类学/城市研究/设计研究者；把项目档案做成可引用、可收藏的出版物。
- **核心体验**：每个引文能追到访谈/日期/地点；图片有授权；公开版隐去受访者身份；书后附“档案索引”。
- **价格**：¥199–399；机构版含数据附录。
- **档案在其中的角色**：collections 对应章节；tags 对应主题；sidecar 记录来源/许可/保留；public/private 控制出版边界。
- **没有 LiveFile 会怎样**：引文与原始录音对不上；受访者授权过期；图片许可不清；出版后无法回应删除请求。
- **LiveFile 的角色**：来源/许可/保留/公开状态；导出目录/清单；备份保证原文件可回溯。

### 案例 C · 自由职业者的作品档案书《过程，不是作品集》

- **形态**：80 页书 + 数字版；5 个项目的过程：草图、失败稿、客户反馈、最终交付；每页标注客户许可/保密级别。
- **用户**：设计师/摄影师/独立开发者；用于接单、教学、回顾，不公开发布私密客户内容。
- **核心体验**：不是“精选美图”，而是“一个项目如何被做出来”；客户名称可脱敏；失败稿也有来源与日期。
- **价格**：¥199；定制版 ¥499（含 1 次整理咨询）。
- **档案在其中的角色**：项目集合/标签/时间线；sidecar 记录客户许可与公开范围；书只导出允许公开的版本。
- **没有 LiveFile 会怎样**：作品与过程散落；客户授权找不到；公开版误带保密内容；无法证明创作时间。
- **LiveFile 的角色**：许可/公开/保留字段；选择与导出；公开页只显示 public。

## 五、成熟触发条件

- [ ] sidecar 编辑/备份/恢复稳定；
- [ ] 有 1 个真实家庭/个人愿意提供素材做样书；
- [ ] 隐私/授权/公开范围可核验；
- [ ] 数字书导出可独立打开；
- [ ] 印刷合作/按需印刷成本可算清。

## 六、商业化边界

- 原始档案归用户；不静默上传/训练；
- 只使用用户明确选择、授权的内容；
- 私密条目默认不进入公开页/样书；
- 书是纪念物，不是法律文件；继承另做工具包；
- 印刷合作方需签数据处理/保密条款。

## 七、成功指标

- 第一本样书由真实家庭确认“愿意送人”；
- 数字版能卖出 20 份/印刷版 10 本；
- 隐私检查 0 事故；
- 制作第二本的边际成本下降。
