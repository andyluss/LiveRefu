# LiveFile · 快速开始与案例

> 版本：v1.0 ｜ 状态：本地优先稳定核心 ｜ 日期：2026-10-28

## 一、5 分钟路径

```bash
cd lab/livefile
node src/cli.ts check
node src/cli.ts serve 4175
```

Workbench 顺序：

1. 总览：条目/集合/健康；
2. Timeline：按时间；
3. Items：搜索、单条 sidecar、批量补元数据；
4. Collections：跨文件夹集合；
5. Health：问题、重复、保留期、备份/继承；
6. Export：目录/清单/备份报告/公开页/继承包。

## 二、示例档案

`archive/` 包含 11 个条目、9 个集合：

- 笔记、票据、信件、证件、照片、音频转写、inbox 未整理项；
- 含一组重复内容（hash）；
- 含 `public:true` 与私密条目，用于公开页边界演示；
- `archive/` 的条目可在 Workbench Items 页逐条查看。

```bash
node src/cli.ts manifest
node src/cli.ts public archive reports/public.html
```

## 三、批量与保留期

```bash
node src/cli.ts retention
```

- `permanent` / `YYYY-MM-DD` / `7y` / `6m`；
- overdue / due / invalid 会进入健康检查；
- 批量补元数据在 Workbench Items 页勾选后应用。

## 四、备份 / 恢复 / 继承

```bash
node src/cli.ts backup-run reports/backup
node src/cli.ts restore-check reports/backup
node src/cli.ts inherit reports/inheritance
```

- 备份写 `backup-manifest.json` 并逐文件 hash 校验；
- 恢复校验只读，不覆盖当前档案；
- 继承包包含 archive 副本、`inheritance-package.json`、公开页和 README。

## 五、v1.0 边界

- 本地优先、零运行时依赖；
- 不接云、不做账号/家庭共享/托管；
- 不自动删除到期文件；保留期只审计；
- 继承包是技术包，不是法律遗嘱。
