# LiveFile · 档案模型与架构（v0.1）

## 1. Vault 结构

```text
archive/
  files…                    # 原始文件（不动）
  file.ext.meta.json        # sidecar：标题/来源/许可/集合/保留
  .backup.json              # 备份状态
  inheritance.json          # 保管/继承安排
```

索引在内存中重建；删除索引不会损坏原始文件。

## 2. Item

```json
{
  "id": "notes/2026-04-12-电站维修.md",
  "title": "电站维修记录",
  "type": "note",
  "created": "2026-04-12",
  "source": "现场记录",
  "license": "private",
  "collections": ["家庭维护", "橙港"],
  "tags": ["维修", "能源"],
  "retention": "7y",
  "sha256": "…",
  "hasMeta": true
}
```

`sha256` 用于去重/备份校验；`hasMeta` 用于区分“未整理”。

## 3. 健康

| 检查 | 级别 | 说明 |
| --- | --- | --- |
| item.unmanaged | warn | 没有 sidecar |
| item.source/license/retention | warn | 来源/许可/保留缺失 |
| item.duplicate | warn | hash 重复 |
| backup.stale | warn | 上次备份 >90 天 |
| backup.unverified | error | 备份未验证 |
| backup.offsite | warn | 少于 2 个位置 |
| backup.restore | warn | 恢复演练缺失/过期 |
| inherit.missing/stale | warn | 保管人/复核缺失/过期 |

健康分：`100 - errors*14 - warnings*4`。

## 4. API

- `GET /api/state`：items/collections/timeline/backup/inheritance/health/stats；
- `POST /api/scan`：重新扫描；
- `POST /api/export`：`catalog` / `manifest` / `backup`；
- `GET /files/<path>`：只读原始文件。

只监听 `127.0.0.1`；不执行 archive 内容；不自动上传。
