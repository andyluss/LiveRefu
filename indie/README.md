# indie · 独立项目区

> 本目录存放与工作区主线（复古未来知识库与 AI 开发工作室）**无直接关联的独立项目**。
> 每个项目一个子目录，可自成体系、拥有自己的 README 与约定。

## 说明

- 本目录及其子目录**默认无须遵守工作区根目录的规则**（见根 [`README.md`](../README.md) 与 [`tech/`](../tech/README.md)），除非**特别约定**。
- 所谓根目录规则，指**面向工作区整体**的约定，例如：文档体例（简体中文 Markdown、`doc/` 编号体例、`studio001/` 角色体例、**相对链接深度**及其校验：pre-commit 钩子 + CI）、Git 提交信息（Conventional Commits）等。
- 各子项目可按自身性质**自定义**目录结构、文档体例与提交风格，不必迁就工作区主线。
- 若有**特别约定**（即某个子项目明确要求遵循某条根规则），在该子项目的 README 中写明即可；**未写明的，一律豁免**根目录规则。
