概念设定：【人类已定】总体风格是 NASApunk。 本文把它翻译成可执行的配色、形状、UI 与声音规则，并说明第一版工程如何用「程序化矢量」先跑起来。D13 已裁决：2D 矢量 / 程序化。

一、一句话

不是「白色 + 橙色」的科幻，而是「有人值班、坏了能修」的未来。

按 D01=B，画面要在「温暖、可靠」的底子上保留磨损、补丁与不平等：干净的公共区域与将就的维修通道并存，不把整座城做成统一的乐园。

二、三条视觉原则

  1. 可维修：每个物件都要有接缝、标签、接口、备份；拒绝无缝全息。
  2. 可读：玩家一眼能分清「这是什么、归谁管、现在什么状态」；UI 是世界观的一部分。
  3. 有人味：允许旧、允许不整齐、允许个人物品；但结构完好、随时可用。

三、配色

【AI 建议】第一版使用以下 token（工程里同步为常量）：

Token 色值 用途
paper #E9E3D5 背景、纸张、面板底
panel #D6CEBC 次级面板、舱壁
cream #F5EFE2 高光、文字底
ink #232B2F 主文字、边框
slate #2F3A3E 结构、深色面板
teal #3E6F6B 次级强调、内环
orange #D9622B 主强调、警示、外环
amber #E0A22E 警报、状态灯、倒计时
rust #8C4A32 做旧、危险、重壳
sage #7C8F6B 中环、植物、恢复

比例：70% 中性 + 20% 深色结构 + 10% 高饱和强调。橙色只在「需要被看见」的地方出现，否则画面会躁。

3.1 三环配色

环 主色 辅色 材质感
外环 冷灰 + 橙 琥珀（警报） 金属、桁架、警示带
中环 暖白 + 木色 + 鼠尾草绿 柔黄 织物、塑料、植物
内环 米白 + 深青 + 黄铜 深灰 石材、玻璃、抛光金属

四、形状语言

  • 圆角矩形为主，圆角半径小（4–8px），像面板与屏幕；
  • 切角用于军事/外环设备（45° 倒角），表示「工业」；
  • 标签：小矩形色块 + 等宽字 + 编号，贴在任何东西上；
  • 管线：用 2–3px 的折线，带接头圆点；不要软管乱舞；
  • 仪表：圆表盘、条形表、七段数字；不要全息环；
  • 图标：线性、统一粗细、功能优先。

五、角色

【AI 候选】第一版不做精细角色，用剪影 + 色带 + 岗位标识：

  • 外环：厚外套、头盔、橙色反光条；
  • 中环：连体工作服、围裙、软帽；
  • 内环：长外套、徽章、浅色手套；
  • 所有角色都有「姓名牌 + 编号」，这是 NASA朋克的视觉签名。

六、UI

6.1 布局（第一版）

┌────────────────────────────────────────────┐
│ 供能 120   保障度 86/100   第 3/5 波  [暂停] │
│                                            │
│              月牙弧 + 塔位                  │
│                                            │
│ [拦截炮 30] [脉冲环 45] [补给塔 40]   [开波] │
└────────────────────────────────────────────┘
  • 顶栏：资源、波次、速度/暂停；
  • 底栏：建塔按钮、开波按钮；
  • 塔位：空心圆 + 编号；选中时显示射程圈；
  • 敌人：三角/菱形/六边形，用形状区分类型；
  • 伤害数字：小号等宽字，快速淡出。

6.2 UI 风格

  • 面板像检查单/仪表盘：米色底、深色边框、等宽数字；
  • 按钮像物理按键：有厚度、按下有位移；
  • 警报像琥珀色指示灯：闪烁频率分三级；
  • 中文用系统字体回退（PingFang/Noto Sans CJK/微软雅黑），标题可用无衬线加粗；数字用等宽。

七、动效

  • 机械式：位移、翻转、灯亮，而不是弹性缩放；
  • 塔攻击：短促的射线/脉冲，0.1–0.2 秒；
  • 敌人死亡：碎片散开 + 短暂闪烁，不做血雾；
  • 界面切换：横向滑入，像舱门；
  • 待机：风扇转动、指示灯呼吸、纸张轻晃。

八、声音

8.1 环境层

  • 低频：舱体应力、通风、远处引擎；
  • 中频：继电器、打印机、脚步、门闩；
  • 高频：无线电静电、警报、仪表滴答。

8.2 音乐

【AI 候选】三种方向：

方向 描述 适合
A 慢合成器 低频 pad + 简单琶音，像 70 年代教育片 温和、怀旧
B 室内乐 弦乐/钢琴/木管，小编制 人文、叙事
C 工业氛围 金属敲击、磁带 loop、噪声 外环、紧张

【AI 建议】中环用 B，外环用 C，内环用 A；三种玩法共享同一套动机（motif），换编曲不换旋律。

8.3 语音

  • 第一版不做全语音；
  • 广播可用「滤波人声 + 字幕」；成本低、氛围强；
  • 关键台词可用 3–5 句配音，作为奖励内容。

九、第一版工程怎么落地

【工程占位】没有美术资源，用 Godot 的 _draw() 画：

  • 背景：米色 + 网格 + 舱段色块；
  • 路径：深灰弧线 + 虚线；
  • 塔位：空心圆 + 编号；
  • 塔：圆/方 + 炮管 + 状态灯；
  • 敌人：三角/菱形/六边形；
  • UI：Control 节点 + 主题色。

这样做的目的不是「省美术」，而是先验证手感与信息层级；等人类确认方向，再替换为正式美术。

十、参考

  • 本工作区 NASApunk 附录卷 的 03 美学与视觉；
  • NASA 图形标准手册（1975）：网格、无衬线、编号；
  • 阿波罗任务照片：光影、材质、真实感；
  • 《For All Mankind》的舱内布景；
  • 《Hardspace: Shipbreaker》的 UI 与工业感。

十一、美术风格（D13 已裁决）

裁决（2026-11-03）：2D 矢量 / 程序化。

  • 用 Godot 的矢量绘制与程序化图形做场景、塔、敌人与 UI；
  • 不采用像素风（与 NASApunk 的「工程感」不符，且需要另一套资产管线）；
  • 不采用 2.5D（第一版产能不够，透视与遮挡会增加关卡成本）；
  • 正式美术阶段可以在同一套 2D 矢量语言里细化，不推翻结构。

其余表现项仍可在制作中定：

  • 是否做角色立绘（第一版建议剪影 + 色带）；
  • 音乐方向 A/B/C（建议中环 B、外环 C、内环 A）；
  • 中文配音的投入（第一版只做广播滤波人声 + 字幕）。
