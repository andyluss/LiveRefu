三、样例包与命令

3.1 包

game/expansions/
  l1_shift_a/   # W4 复查；W5 隔离
  l1_shift_b/   # W4 按惯例；W5 隔离
  l1_shift_c/   # W4 照签；W5 旁路
  • 同属 variant_group = L1.shift；
  • 只能通过 preset slots 选一个；
  • baseline 不加载任何包。

3.2 Preset

game/data/expansion_sets/
  baseline.json
  l1_compare_a.json
  l1_compare_b.json
  l1_compare_c.json
  l1_invalid.json      # 同组同时启用，预期失败

3.3 命令

./run.sh test              # 73 项基础回归
./run.sh expansions-check  # 34 项扩展/变体/审计检查
./run.sh compare           # A/B/C 对比表
./run.sh compare --json    # JSON 行
./run.sh compare --csv     # CSV
./run.sh check             # 启动检查

六、已知缺口

  • W5 故障命中暂停是样例，不是完整故障链；
  • 事故记录只影响本局/低报 carry，没有长期档案页；
  • 已有短音效（UI/建造/故障/广播/结算），但没有音乐、音量滑杆；
  • 档案最多 10 班，没有持久化完整历史；
  • A/B/C 仍是样例包，不是正式 L1 内容；
  • compare 输出是终端表格，没有生成报告文件。

七、维护规则

  • 设计变更：改 00–05 / 14 / 16；
  • 实现变更：改代码 + 本表 + expansions-check；
  • 数值/文案变更：先改 numbers/，再跑 numbers-check；
  • 本页只做映射，不替代设计文档。
