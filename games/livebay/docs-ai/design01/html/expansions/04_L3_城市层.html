L3 城市层：轻城市与档案

范围：v0.5+；L1/L2 成立后再做。不是「城市模拟」，而是「你不在时，城怎么活」的轻量装置。 一句话：两间舱室、三个人、一个城市事件、一批档案；不逼上线，不卖数值。

一、L3 的目标

  • 给玩家一个「长期对象」：城会变，人会换班；
  • 让 L1/L2 的记录有地方沉淀；
  • 让沉浸玩法有可复用的 NPC/档案；
  • 不新增第二套主经济，不做全城模拟。

二、舱室（2 间）

舱室 产出 升级 叙事
养生舱 档案/心情 恢复更快、事件更多 湾民的身心
维修站 备件 拆解/维修效率 岗位劳动

规则：

  • 第一版只做 2 间，不做完整舱室树；
  • 离线产出上限 8 小时；
  • 产出是「备件/档案/便利」，不是塔防必需资源；
  • 回归报告 1 屏：产出 + 1 条人的变化 + 1 个可选事件；
  • 不设「离线惩罚」，离开不是错误。

三、3 名湾民

  • 与 L2 的 3 名湾民同一批人；
  • 有岗位、状态、关系、1 个小故事；
  • 不抽卡、不死亡、不做恋爱线；
  • 通过合同/剧情加入，不通过付费。

四、城市事件（1 个/月）

事件：外环停电
  ├─ 塔防入口：守一段临时防线
  ├─ 沉浸入口：读广播/做一次选择
  └─ 放置入口：分配维修工/备件
完成任意 2 个入口 → 推进事件
  • 事件不是日常任务；一个月 1 个，错过可补；
  • 完成任意 2 个入口即可，不强制三模式全玩；
  • 奖励：档案/外观/备件，不给主线硬门槛；
  • 事件结果写进城市档案，影响下一次广播文案。

五、职业执照

  • 每个职业 3 级：见习 → 正式 → 带班；
  • 升级靠「完成合同 + 记录」，不靠刷同一关；
  • 解锁：职业变体/新班次牌/外观，不解锁主线；
  • 不做技能树，不做等级数值膨胀。

六、档案网络

  • NPC、事故记录、班次合同、城市事件共享一套档案 ID；
  • 塔防救下的人、沉浸对话的人、放置照顾的人可以是同一个；
  • 档案只提供「世界是真的」的感觉，不提供数值；
  • 档案可在三种玩法中解锁，不强制跨模式。

七、与三玩法的耦合

阶段 耦合 做什么 不做什么
v0.2 L1 档案网络（NPC/记录） 不做资源互通
v0.3 L1/L2 备件少量共享 不做必须收菜
v0.5 L2 城市事件 1 个 不做日常/体力
v1.0 L2 资源循环 + 事件轮换 不做 L3 硬锁

仍遵守 D11：不强制跨模式；联动奖励是便利/外观/叙事，不是数值门槛。

八、数据与工程映射

内容 字段 模块
舱室 rooms[]：id、level、output MetaService/Profile
湾民 crew[] ModifierModule + Profile
城市事件 city_events[]：entrances、choices ProcedureModule/Meta
档案 archive[]：id、unlock、text Profile
离线 last_seen、offline_cap IdleService

L3 不进入 Sim 核心循环；它是 Meta 层，通过 MissionPack 的 modifiers/records 与塔防交互。

九、验收

  • 只玩塔防，不玩 L3，也能完整通关；
  • L3 不产生「必须登录」的压力；
  • 离线 8 小时收益有上限，回归报告 ≤1 分钟读完；
  • 城市事件可补，不做限时；
  • 不卖数值/备件；
  • 三模式只玩一种，不会觉得缺了什么。

十、L3 不做什么

  • 不做全城模拟/政策树/预算；
  • 不做每日签到/体力/限时；
  • 不做 L3 硬锁主线；
  • 不做第二套经济；
  • 不做多人/排行榜。
