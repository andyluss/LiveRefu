除【人类已定】外，以下都是参考候选。地名、距离、舱段编号都可以改；先保证它们能支撑玩法。

一、已定的空间骨架

【人类已定】逍遥湾是一座月牙形移动太空城，三环：

  • 外环：护卫、能源、资源采集；
  • 中环：居住、养生、娱乐、教育；
  • 内环：政治、经济、文化。

【人类已定】月牙凹面是港湾/船坞方向；外环沿凸面展开，最先承受外部风险。

二、空间模型

航向 ↑
        外环（凸面）
   ┌────────────────────┐
   │  中环（居住带）      │
   │   ┌────────────┐   │
   │   │ 内环（机构）│   │
   │   └────────────┘   │
   └────────────────────┘
        凹面：湾口 / 船坞

2.1 三条环境梯度

梯度 外环 中环 内环
辐射/碎片风险 高 低 极低
噪音/振动 高 中 低
温度 冷 暖 恒温
重力 可变/偏弱 接近标准 标准
光 冷白/警示橙 暖白/琥珀 石材/玻璃/黄铜
人的状态 值班、短住 生活、恢复 办公、仪式

这条梯度是美术、音效、玩法难度的共同依据：越往外，越“工程”；越往里，越“机构”。

三、外环：城的盾与手

3.1 功能

  • 护卫阵列：拦截碎片、乱流、异常轨道物；
  • 采集/能源：矿脉、冰、气体、太阳风；
  • 船坞/对接：货运、维修、救援；
  • 外环岗位：塔位、巡检、故障隔离、交接。

3.2 空间形态

【参考】外环不是一条完整走廊，而是一串可独立封闭的舱段：

湾口 → 第七段 → 第六段 → 第五段 → … → 外环枢纽
  • 每段有独立供电、氧气循环、舱门；
  • 段与段之间可以隔离，代价是失去通路/供能；
  • 塔位沿弧内侧分布，覆盖“敌人从湾口反向进入”的路径；
  • 故障沿舱段/管线传播，不会瞬间传遍全城。

这解释了塔防的“弧形路径 + 分段塔位”，也解释了生存模式的“封舱/断电/断氧”。

3.3 地图切片

工程里的三张地图是外环的不同切片，不是整座城：

四、中环：生活与恢复

【参考】中环是“人的时间”：

  • 居住舱：家庭/合住/单人舱，按贡献点与家庭规模分配；
  • 养生舱：恢复、睡眠、心理辅导，不是医院；
  • 娱乐舱：影院、桌游、虚拟场景、运动；
  • 教育舱：儿童教育、成人再教育、选拔培训；
  • 食堂/配给点：基本配给 + 加餐券；
  • 广播/公告：班次、事故、配给、选拔。

4.1 中环的空间逻辑

  • 以“生活半径”组织：居住—食堂—养生—娱乐，步行/短途轨道可达；
  • 与外环通过闸口/电梯井/轨道连接，非值班人员不能随意进入外环；
  • 越靠近内环，空间越安静、越正式、越“被设计”。

五、内环：机构与合法性

【参考】内环是“机构的时间”：

  • 议会厅：危机时接管；
  • 配给/算法署：日常资源分配；
  • 交易所/贡献点清算；
  • 档案馆：事故、班次、职业记录；
  • 广播中心：全城播报；
  • 礼制空间：交接仪式、纪念、裁决。

内环不是“坏人总部”；它真的维持了城市运转，只是它的效率建立在排除与低报上。

六、通行与隔离

通道 用途 限制
主环轨 三环日常通勤 高峰期拥挤，事故时停运
外环闸口 值班/维修/救援 需权限；可封舱
船坞对接臂 货运/救援 外部风险最高
维护竖井 管线/电缆/检修 狭窄、故障高发
应急通道 撤离/救援 平时关闭，需人工开启

6.1 封舱的空间代价

  • 封舱能阻断故障/泄漏/敌人；
  • 但被封的段会失去供能、氧气循环与通行；
  • 被封段里的人可能被困；
  • 封舱决定应该留下“谁按下的、为什么”的记录。

这直接支撑 S2 的“封舱/撤离”，也为未来“按舱段封舱”留接口。

七、玩法接口

玩法 可直接引用
塔防 弧形路径、分段塔位、湾口反向故障、外环闸口
生存 舱段、氧气循环、电力、封舱、撤离
沉浸 中环生活半径、养生舱、食堂、广播
放置 舱室/居住带/配给点
叙事 内环议会、档案馆、船坞救援

八、待裁决

  1. 外环分段的正式编号/命名；
  2. 三环之间的通行时间（分钟级）；
  3. 中环居住舱的分配规则；
  4. 湾口船坞是否常驻外部人员；
  5. 封舱是否有“自动/手动”两套权限。
