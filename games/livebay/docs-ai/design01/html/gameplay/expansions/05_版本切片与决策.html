三、每个版本的验收门槛

v0.2 L1a

  • 不用检查单/旁路，标准班仍 B / 40 / 59 / 9；
  • 复查/旁路不是必选/必不选；
  • 一局仍 ≤12 分钟；
  • 试玩者能说出「我为什么选复查/照签」。

v0.2 L1b

  • 下一班简报能引用上一班记录；
  • 玩家至少 1 次因为记录改变选择；
  • 不做永久惩罚，失败可重试。

v0.3 L2a

  • 不装模块也能过标准班；
  • 装模块不出现唯一最优；
  • 模块 ≤6 个；
  • 备件不逼每日刷。

v0.4 L2b

  • 湾民效果不超过一个塔等级的 30%；
  • 不做死亡/永久伤病；
  • 3 名湾民能在 1 局内被记住名字。

v0.5 L3a

  • 不玩 L3 也能通关；
  • 回归报告 ≤1 分钟；
  • 城市事件可补，不做限时；
  • 不卖备件/数值。

四、建议不要做

  • 不做第四种玩法；
  • 不做随机地图/无尽模式；
  • 不做抽卡/体力/日常；
  • 不做全城模拟/政策树；
  • 不做 L3 硬锁主线；
  • 不在 L1 未验证前做 L2。

五、如果范围要砍

砍的顺序：

先砍 L3 城市事件 → 再砍 L2 湾民 → 再砍 L2 模块
保 L1 检查单/故障/记录 → 保标准班

理由：L1 是主题与差异化的核心；L2/L3 是放大，不是地基。

六、一句话

先让「这一班」值得重玩，再让「这个岗位」值得养，最后让「这座城」值得回来。
