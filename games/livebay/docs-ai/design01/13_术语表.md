# 13 · 术语表

> 统一用词，避免同一概念在文档、代码、UI 里出现三种叫法。**状态**列：已定 / 候选 / 工程占位。

## 一、世界与空间

| 术语 | 英文/别名 | 定义 | 状态 |
| --- | --- | --- | --- |
| **LiveBay** | 逍遥湾 / Live Bay | 项目代号；也指这座月牙形移动太空城 | 已定 |
| **逍遥湾** | Live Bay | 游戏暂定中文名 | 已定 |
| **月牙城** | 湾 / Bay | 城的形状与别称；凹面为港湾，凸面为外环 | 已定（形状） |
| **外环** | outer ring | 护卫、采集、能源；任务时间 | 已定 |
| **中环** | middle ring | 居住、养生、娱乐、教育；人的时间 | 已定 |
| **内环** | inner ring | 政治、经济、文化；机构时间 | 已定 |
| **舰队集群** | fleet cluster | 主城 + 外围舰队的集合 | 候选 |
| **湾口** | bay mouth | 月牙凹面的港湾；塔防的「基地」所在 | 候选 |
| **舱室** | cabin / pod | 中环的功能单元：养生舱、娱乐舱、教育舱等 | 已定（存在） |

## 二、社会与制度

| 术语 | 英文/别名 | 定义 | 状态 |
| --- | --- | --- | --- |
| **慢好三生保障体系** | 保障体系 / 三生 | 维持大多数人生活的规划体系；三生 = 生存/生活/生产；慢好 = 慢 + 好 | 已定（D03） |
| **生存** | survival | 空气、水、食物、医疗、安全、应急；保障底线 | 已定 |
| **生活** | life | 居住、娱乐、教育、社交、心理、养老、尊严 | 已定 |
| **生产** | production | 工作、能源、资源、维护、照护劳动 | 已定 |
| **慢** | slow | 不追求效率最大化；给发呆、闲聊、走神留余量 | 已定 |
| **好** | good | 保障质量与尊严，而不是单纯给得多 | 已定 |
| **保障度** | integrity | 城的生命值；塔防中漏怪扣除，归零失败 | 工程占位 |
| **供能** | energy | 塔防的建造货币；也指城的能源 | 工程占位 |
| **贡献点** | contribution | 按工时/难度/风险发放的配给货币 | 候选 |
| **选拔** | selection | 从居民中选出工作人员的制度 | 已定（存在） |
| **轮岗** | rotation | 同环换岗或跨环支援 | 已定（存在） |
| **退役** | retirement | 离开岗位转为居民/顾问，不是惩罚 | 已定（存在） |
| **工作人员** | staff | 被选拔、在三环工作的人；少数 | 已定 |
| **湾民** | bay resident | 城里的居民；也用作「人」的统称 | 候选 |
| **无名岗位人** | unnamed worker | 玩家身份的裁决（D04=C）：没有固定姓名与外观，每个职业都是「你」 | 已定 |
| **值班** | shift | 一个工作班次；塔防一局的时间单位 | 候选 |
| **交接班** | handover | 上一班把未完成的事交给下一班；本项目的核心瞬间 | 候选 |
| **事故报告** | incident report | 塔防失败后的简报；可跳过 | 工程占位 |
| **湾民档案** | resident file | 每个 NPC 的资料页；三种玩法共享 | 候选 |
| **双轨制** | dual-track | 日常算法配给，危机议会接管（D07） | 已定 |
| **低报事故** | underreported incident | 外环事故被系统性少报；只埋线索、不揭开（D08） | 已定 |

## 三、玩法

| 术语 | 英文/别名 | 定义 | 状态 |
| --- | --- | --- | --- |
| **岗位防线** | 塔防 / tower defense | 主干玩法：在月牙外弧布防，扛过一班 | 已定（塔防） |
| **塔位** | slot | 地图上可建造的固定位置 | 工程占位 |
| **塔** | tower / unit | 玩家建造的防御单元；不同职业有不同「塔」 | 工程占位 |
| **故障** | fault | 内部故障敌人（C）：从湾口反向扩散，经过塔位使该塔短暂离线；不直接扣保障度 | 工程占位 |
| **波次** | wave | 一波敌人；第一版 5 波 | 工程占位 |
| **买断+内购** | premium + IAP | 基础买断，内购仅外观/扩展内容，不卖数值（D12） | 已定 |
| **沉浸体验玩法** | immersive mode | 分支玩法一：舱室日常、对话、事件 | 已定（存在） |
| **放置养成玩法** | idle mode | 分支玩法二：舱室、湾民、离线产出 | 已定（存在） |
| **耦合** | coupling | 三种玩法共享资源/进度的程度（L0–L3） | 候选 |

## 四、协作与工程

| 术语 | 定义 | 状态 |
| --- | --- | --- |
| **裁决** | 人类对某个设计问题的最终选择；记录在 [11](11_待人类裁决清单.md) | 现行 |
| **工程占位** | 为了让工程能跑而做的临时选择；不是设计定案 | 现行 |
| **AI 候选** | AI 提出的可选方向；不自动成为设定 | 现行 |
| **AI 建议** | AI 的倾向与理由；可被推翻 | 现行 |
| **可逆** | 改设定时不需要重写代码，只改数据 | 现行 |

## 五、易混淆

| 不要用 | 用什么 | 原因 |
| --- | --- | --- |
| 关卡 | 班 / 一局 | 「关卡」偏游戏化；「班」更贴岗位感（可保留「关卡」作为工程词） |
| 血量 | 保障度 | 「血量」是工程词，UI 用「保障度」 |
| 金币 | 供能 / 贡献点 | 两种资源不要混用 |
| 怪物 | 敌人 / 威胁 | 第一版是碎片/乱流/重壳，不是怪物 |
| 主城 | 湾 / 月牙城 | 避免「主城」的奇幻味 |
| NASA 风格 | NASA朋克 | 后者是美学谱系，不是「NASA 的周边」 |
