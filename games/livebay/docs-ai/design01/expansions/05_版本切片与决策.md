# 版本切片与决策：建议你先拍这五个

> 本文不替你做决定；只把「先做什么、后做什么、砍什么」摆成可拍板的表。
> **如果只拍一个：先做 L1。**

## 一、建议切片

| 版本 | 内容 | 验证什么 | 周期（AI 辅助，单人） | 不通过就停 |
| --- | --- | --- | --- | --- |
| **v0.2 L1a** | 检查单 + 第 5 波隔离/旁路 + 事故记录 | 流程判断是否成立 | 1–2 周 | 标准班被破坏/弹窗烦 |
| **v0.2 L1b** | 3 班合同 + 下一班简报 | 记录连续性是否成立 | 1 周 | 玩家不读记录 |
| **v0.3 L2a** | 塔座 2 槽 + 3 个模块 + 备件 | 模块是否产生选择 | 2–3 周 | 出现唯一最优/数值膨胀 |
| **v0.4 L2b** | 3 湾民 + 事故链 | 轻人员是否成立 | 2–3 周 | 变成配装/养成负担 |
| **v0.5 L3a** | 2 舱室 + 1 城市事件 + 档案 | 轻城市是否成立 | 2–3 周 | 逼登录/收菜疲劳 |
| **v1.0** | 资源循环 + 事件轮换 + 多职业 | 是否可发行 | 3–6 月 | 范围失控 |

> 周期是量级，不是承诺；每一步都必须先通过「不破坏标准班」。

## 二、需要你拍板的 8 个问题

| ID | 问题 | 选项 | AI 建议 | 代价/理由 |
| --- | --- | --- | --- | --- |
| **E17-1** | 扩展方向 | A 纵向做深一班 / B 横向加新模式 / C 两者 | **A** | 三种玩法已经够多；先让一班值得重玩 |
| **E17-2** | L1 现在做吗 | A 现在做 N1–N3 / B 先做别的 / C 只做叙事 | **A** | 成本最低、最贴 NASApunk；已裁决未实现 |
| **E17-3** | L2 模块槽 | A 2 槽 / B 3 槽 / C 不做 | **A 2 槽** | 3 槽会变成配装游戏；2 槽够产生取舍 |
| **E17-4** | 湾民 | A 3 名有名有姓 / B 通用人员 / C 不做 | **A** | 与沉浸/档案共用；不做抽卡 |
| **E17-5** | L3 范围 | A 轻城市（2 舱室+1 事件+档案）/ B 全城模拟 / C 不做 | **A** | 全城模拟范围过大；轻城市足够验证「城在活」 |
| **E17-6** | 跨模式耦合 | A L1/L2 软耦合 / B L2 资源互通 / C L3 硬锁 | **A**，v0.5 再看 B | 不逼玩；D11 不变 |
| **E17-7** | 新塔/新怪 | A v0.2 不加 / B 加 1 塔 1 怪 / C 加一批 | **A** | 先把现有 3 塔 4 敌做出深度 |
| **E17-8** | 商业模式 | A 维持买断+外观 / B 卖模块/备件 / C 订阅 | **A** | D12 不变；卖模块会逼设计变形 |

### 2.1 如果你只想拍三个

建议按顺序拍：

1. **E17-1 = A**（纵向做深）；
2. **E17-2 = A**（现在做 L1）；
3. **E17-3 = A / E17-5 = A**（2 槽、轻城市）。

其余可以先按「AI 建议」执行，试玩后再改。

## 三、每个版本的验收门槛

### v0.2 L1a

- 不用检查单/旁路，标准班仍 **B / 40 / 59 / 9**；
- 复查/旁路不是必选/必不选；
- 一局仍 ≤12 分钟；
- 试玩者能说出「我为什么选复查/照签」。

### v0.2 L1b

- 下一班简报能引用上一班记录；
- 玩家至少 1 次因为记录改变选择；
- 不做永久惩罚，失败可重试。

### v0.3 L2a

- 不装模块也能过标准班；
- 装模块不出现唯一最优；
- 模块 ≤6 个；
- 备件不逼每日刷。

### v0.4 L2b

- 湾民效果不超过一个塔等级的 30%；
- 不做死亡/永久伤病；
- 3 名湾民能在 1 局内被记住名字。

### v0.5 L3a

- 不玩 L3 也能通关；
- 回归报告 ≤1 分钟；
- 城市事件可补，不做限时；
- 不卖备件/数值。

## 四、建议不要做

- 不做第四种玩法；
- 不做随机地图/无尽模式；
- 不做抽卡/体力/日常；
- 不做全城模拟/政策树；
- 不做 L3 硬锁主线；
- 不在 L1 未验证前做 L2。

## 五、如果范围要砍

砍的顺序：

```text
先砍 L3 城市事件 → 再砍 L2 湾民 → 再砍 L2 模块
保 L1 检查单/故障/记录 → 保标准班
```

理由：L1 是主题与差异化的核心；L2/L3 是放大，不是地基。

## 六、一句话

**先让「这一班」值得重玩，再让「这个岗位」值得养，最后让「这座城」值得回来。**
