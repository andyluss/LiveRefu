# 恢复舱的第七床

> 岗位：养生舱护理师 · 时段：第 3 班 02:50 · 关键词：数据、选择、照护

养生舱的第七床在窗边。

从那里能看见月牙城的内弧，像一条被谁咬了一口的白面包。林姨喜欢那个位置。她每次来都指名要第七床，说“看得见外面，才知道自己还在船上”。

02:50，你推着巡检车经过第七床。舱里的灯是琥珀色，代表“观察中”。林姨闭着眼，呼吸平稳，监护屏上的曲线却比昨天低了一截。

你调出她的档案。

林姨，六十七岁，中环居民，慢性心肺功能下降。女儿小满，十九岁，正在参加外环护卫兵的选拔。档案里有一行小字：“家属选拔期，健康数据异常需人工复核。”

你盯着那行字看了两秒。

“姐。”

阿澈从帘子后面探出头。她今年刚轮岗到养生舱，胸牌还是新的。“第七床的数据是不是有点低？我按流程报一下？”

“先别报。”你说。

“为什么？”

“报了，系统会给她打一个‘健康风险’标记。小满的选拔正在复核期，家属档案会被一起调出来。”

阿澈皱眉：“可如果林姨真的出事呢？”

你没回答。你走到床边，轻轻叫醒林姨。

“林姨，今天感觉怎么样？”

“还行。”她笑了一下，嘴唇有点干，“就是胸口闷。老毛病了。”

“监护数据比昨天低。”

“我知道。”她看着窗外的月牙弧，“小满昨天来看我，说选拔最后一轮是外环夜班。她说她不怕。我告诉她，外环的夜班冷，记得多穿一件。”

她停了一下。

“你别给我报。报了，她选不上。”

“如果我不报，你今晚可能撑不过去。”

“那就撑不过去。”她说得很轻，“我这把年纪，撑不过去也不亏。她还年轻。”

你看着监护屏。曲线还在往下走，但走得很慢。按照检查单，你应该在数据低于阈值时立即上报；按照经验，你还有时间做一次人工复查。你把巡检车推到床边，给她接上便携监测，重新测了一遍。数据还是低，但没有到“立即转舱”的程度。

“我可以写‘待复查’。”你说。

“那是什么？”

“就是……不报，也不瞒。留一个口子，让下一班的人来决定。”

林姨看着你：“下一班的人会怎么决定？”

“我不知道。”你说，“但至少不是你一个人扛。”

阿澈在旁边小声说：“姐，这不合流程。”

“流程是给人用的。”你说，“不是给数据用的。”

你打开交接记录，在第七床那一栏写下：

“02:58 主诉胸闷，监护数据低于基线，未达转舱阈值。已做便携复测。建议 04:00 前复查；如继续下降，转深度恢复。家属选拔期，请人工复核。”

系统弹出一行提示：

“该记录将同步至家属档案。是否继续？”

你点了“继续”。

林姨看着你，没说话。窗外的月牙弧在星光里发白。她的呼吸慢下来，像一条终于找到节奏的曲线。

04:00，你交班。接班的护理师看完记录，抬头问你：“第七床，你打算怎么办？”

“先复查。”你说，“如果她撑得住，就让她撑。如果撑不住，就转舱。别让她女儿在选拔场上接到电话。”

接班的人点了点头，在记录末尾加了一句：

“同意。04:10 复查。”

你走出养生舱的时候，广播正在播早间新闻：

“全城通报：中环保障度 98，外环事故 0 起，系统运行正常。”

你想起林姨窗外的月牙弧，想起她说“她还年轻”。你不知道小满能不能选上。你只知道，第七床的记录里，现在有两行字，而不是一行。

## 场景卡：恢复舱的第七床

| 项 | 内容 |
| --- | --- |
| 玩法形态 | 沉浸体验（B+D）：一班、一舱、一个没有完美答案的选择 |
| 玩家目标 | 在不触发家属档案风险的前提下，让林姨撑到下一班 |
| 核心动词 | 巡检、复测、对话、写记录、交接 |
| 可复用系统 | 健康数据、家属档案、选拔状态、交接记录、关系值 |
| 关键选择 | ① 按流程上报；② 帮忙隐瞒；③ 写“待复查”，把决定交给下一班 |
| 分支后果 | 上报：林姨转舱，小满选拔受影响；隐瞒：风险累积，可能夜间事故；待复查：占用玩家休息时间，下一班关系变化 |
| 与现有玩法 | 可直接做成沉浸玩法的第一个场景；结果写进“湾民档案”，在小满的外环关卡里出现 |
| 可复用资产 | 第七床、林姨/小满/阿澈、监护屏、交接记录 UI、月牙弧窗景 |

> 这篇小说要测试的是：**当“正确”和“善良”冲突时，玩家愿不愿意找一个不体面的中间答案。**
