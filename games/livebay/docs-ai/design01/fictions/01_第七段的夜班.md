# 第七段的夜班

> 岗位：外环护卫兵 · 时段：第 3 班 03:12 · 关键词：交接、故障、低报

03:12，外环第七段的舱壁温度是十四度。

你从老周手里接过值班表。纸是热的，上一班的人把它揣在贴身口袋里，边角被汗浸得发软。老周的手套少了一只，他用那只没戴手套的手点了点表上的一行字：

“T-07 的阻尼器有点响。不碍事，响三天了。”

“报修了吗？”

“报了。维修排在第七位。”他把手套往口袋里塞，“第七位，就是等前面六个都修完。你懂的。”

你懂。外环的维修顺位按“影响保障度”排，不按“听起来吓不吓人”排。T-07 是一段老舱壁，后面是外环第七段的备用配电间，再后面才是中环的居民区。它坏掉，不会立刻死人；它只是会响。

老周走后，值班室安静下来。控制台上有一排琥珀色的小灯，像一排没有睡醒的眼睛。广播在 03:15 准时响起：

“全城通报：过去二十四小时，外环事故 0 起，系统运行正常。请各位湾民安心休息。”

你抬头看了一眼监控。T-07 的阻尼器在画面里轻轻发抖，像一根绷得太久的弦。

03:20，故障出现了。

控制台上多了一个青灰色的方块，从湾口方向沿着外弧往外走。它走得不快，比碎片快一点，比乱流慢。你认得这个图标：内部故障，C 类。它不撞舱壁，也不咬人；它只是经过塔位的时候，让那座塔离线几秒。

“T-07，故障接近。”通讯频道里有人报。

“看到了。”你说。

按照检查单，你该做的第一件事是切到备用回路，第二件事是通知维修，第三件事是记录。你做了第一件。备用回路的灯亮了，T-07 的炮塔却还是暗的——它的阻尼器太旧，备用回路带不动。

第二件事，你犹豫了。

维修频道里传来一个年轻的声音：“第七段，你们那边是不是有故障？我们这边排了三个单，最早 03:40 到。”

03:40。还有二十分钟。故障走到 T-07 只需要两分钟。

你可以把 T-07 的供电切给 T-06，让 T-06 多扛一段；代价是 T-07 后面的配电间会短时失压。你也可以让 T-07 离线，等维修；代价是下一波碎片会从那个缺口漏过去。你还可以把故障写进“已知风险”，不切电，赌它只停两座塔。

你选了切电。T-06 的射程圈在屏幕上扩大，T-07 暗下去，像一只闭上的眼睛。

03:22，碎片来了。

第一波只有六只，慢，散，像被风吹散的煤渣。T-06 开火，T-05 补位，T-07 的缺口被两座塔交叉盖住。你盯着保障度的数字，它从 100 掉到 96，又回到 96。没有漏过去。

03:26，故障走到了 T-07 的空位。它没有找到可以停的塔，在原地转了一圈，像一个人在空房间里找错了门。然后它继续往外走，消失在舱壁的阴影里。

你松了口气，又立刻把气提起来。

03:31，维修来了。一个穿灰色工装的人，背着一个比他还宽的备件箱，脸上有一道旧伤。他看了一眼 T-07，说：“阻尼器不是坏了，是装反了。”

“装反了？”

“上一班换的。装反了也能用，就是会响。响久了，备用回路带不动。”他把备件箱放下，“你们报的是‘异响’，不是‘装反’。这两个单在系统里不是一回事。”

你看着值班表上老周的字。他写的是“有点响”。他没写错。他只是不知道该怎么把“有点响”翻译成系统听得懂的话。

维修把阻尼器拆下来，重新装上。T-07 的灯亮了。你看了一眼时间：03:36。下一波还有二十四分钟。

你坐下来写记录。系统自动填了一行：

“03:20 内部故障 C-类，已按惯例处理。”

你把光标移到“已按惯例处理”上，停了停，在后面加了一句：

“T-07 阻尼器装反，已由维修重装。建议查上一班同批次安装记录。”

系统提示：该字段超出模板长度，是否继续？

你点了“继续”。

03:40，广播又响了：

“全城通报：外环事故 0 起，系统运行正常。”

你抬头看了一眼 T-07。它亮着，像什么都没发生过。

但你知道，明天早上，会有人看到你加的那句话。也许是一个维修主管，也许是一个内环的审计员，也许只是下一班的值班人。也许什么都不会发生。

你把值班表折好，放在控制台最显眼的位置。纸还是热的。

## 场景卡：第七段的夜班

| 项 | 内容 |
| --- | --- |
| 玩法形态 | 塔防教学关 / 故障教学关 |
| 玩家目标 | 守住外环第七段 5 波；在 T-07 故障时决定切电、等修还是冒险 |
| 核心动词 | 交接、检查、切电、补位、记录 |
| 可复用系统 | 塔位离线、备用回路、维修排位、低报事故、交接记录 |
| 关键选择 | ① 切电给 T-06，牺牲 T-07 后方配电间；② 等维修，放缺口；③ 不切电，赌故障只停两座塔 |
| 分支后果 | 切电：保障度损失小，但配电间事件 +1；等修：漏怪 +3，维修关系 +1；赌：随机停塔，可能崩 |
| 与现有玩法 | 直接对应塔防的「故障」与「检查单」；可把“切电”做成一个 10 秒的即时刻度小操作 |
| 可复用资产 | 外环第七段地图、T-07 塔位、故障图标、广播文案、交接记录 UI |

> 这篇小说要测试的不是“怪有多强”，而是**玩家是否愿意为一个看起来不严重的异响多做一步**。
