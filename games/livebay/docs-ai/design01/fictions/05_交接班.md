# 交接班

> 岗位：内环工程师 · 时段：第 3 班 23:40 · 关键词：裂缝、预算、故障链

热交换站 B-3 在内环的最底层。

它不在任何一条观光路线上。游客看的是内环的议会厅、交易所和广播中心；B-3 只有管道、泵、检修梯，以及一股永远散不掉的、像旧硬币一样的金属味。

23:40，你带着小覃做本班的最后一次巡检。

小覃是今年刚分到内环的见习工程师，安全帽上还贴着实习期的黄色标签。他走在你后面，手电筒的光在管道上跳来跳去，像一只不太安分的鸟。

“师傅，这个支架是不是有点歪？”

你停下来。

支架在 7 号泵的右侧，负责把回水管固定在一段承重梁上。它确实歪了，歪得很轻微，像一个人站久了把重心挪到另一条腿上。你用手电照了照支架和梁的接缝，看到一条头发丝一样的裂纹。

“不是有点歪。”你说，“是裂了。”

小覃的手电晃了一下：“那要停机吗？”

“停机要关掉 B-3 的半边回路。中环的养生舱、内环的档案馆，还有议会厅的空调，都会受影响。”

“现在是 23:40，议会厅没人。”

“档案馆有人。夜班归档。”

“那……报修？”

你拿出平板，调出维修单。系统已经自动生成了一个建议：

“B-3 7 号泵支架裂纹，风险等级：中低。建议：纳入下一季度检修计划。当前可继续运行。”

“下一季度。”小覃念了一遍，“还有四个月。”

“系统算过。”你说，“裂纹扩展速率、负载、冗余回路，都算过。它说能撑。”

“那它会不会算错？”

你没回答。你想起三年前的一次事故，也是“中低风险”，也是“可继续运行”。那次事故的报告最后写的是“已按规程处理”，没有写“规程本身有问题”。

23:55，你们回到控制室。控制台上有一封未读邮件，来自内环预算办公室：

“关于 B-3 热交换站 Q4 维护预算的听证，定于明日 09:00。请工程师代表准备 5 分钟陈述。”

你看了看邮件，又看了看巡检记录。支架裂纹的维修报价是 12 万贡献点。B-3 的季度维护预算是 40 万。如果修支架，就要砍掉另外两项——一项是 7 号泵的轴承更换，一项是地下管廊的防腐涂层。

你可以在听证会上说“支架必须修”，把另外两项往后推。也可以说“按系统建议，纳入下季度”，把今天的问题留给下一班。还可以自己做一个临时加固：用备件库里的旧夹具把支架卡住，撑到听证会之后。

你选了临时加固。

00:20，你和小覃蹲在 7 号泵旁边，把旧夹具一点一点卡进支架和梁之间的缝隙。夹具不合适，你用小覃的实习扳手敲了两下，又用你自己的扳手拧紧。金属发出一种很轻的、像牙齿咬合的声音。

“师傅，这算违规吗？”

“算。”

“那为什么还做？”

“因为不做的代价，可能比违规大。”

00:40，加固完成。支架不再歪了。你用手电照了照裂纹，它还在，但被夹具压住了。你拍了一张照片，上传到系统，备注：

“临时加固，建议 72 小时内复检。复检前限制 7 号泵负载至 70%。”

系统提示：该操作需要工程师权限与上级审批。

你点了“申请”。

00:42，审批通过。审批人是一个你从没见过名字的内环官员，头像是一枚灰色的徽章。系统在记录末尾自动加了一行：

“已按临时处置流程处理。”

你看着那行字，想起巡检记录里那条裂纹。它还在。它只是被压住了。

01:10，你交班。接班的工程师看完记录，问你：“支架怎么样？”

“临时加固了。”你说，“72 小时内要复检。”

“72 小时。”他重复了一遍，“明天听证会，你会去吗？”

“会。”

“那你打算怎么说？”

你看了看控制台。B-3 的泵还在转，声音平稳，像什么都没发生。窗外是内环的夜，议会厅的灯已经灭了，档案馆的灯还亮着。

“我会说，支架裂了。”你说，“然后我会说，我们暂时把它压住了。最后我会说，压住不等于修好。”

接班的人点了点头，在记录末尾加了一句：

“同意。01:15 复检。”

你走出 B-3 的时候，广播正在播午夜新闻：

“全城通报：内环保障度 99，外环事故 0 起，系统运行正常。”

你想起那根被夹具压住的支架。它还在那里，像一句没有说完的话。

## 场景卡：交接班

| 项 | 内容 |
| --- | --- |
| 玩法形态 | 节点防御 / 故障链变体（工程师职业） |
| 玩家目标 | 在预算与安全之间，决定修哪一处、压住哪一处、把什么留给下一班 |
| 核心动词 | 巡检、诊断、加固、限载、申请、陈述 |
| 可复用系统 | 节点/连线、裂纹、负载、冗余、预算、审批、故障链、交接记录 |
| 关键选择 | ① 停机大修；② 按系统建议拖到下季度；③ 临时加固 + 限载，72 小时后复检 |
| 分支后果 | 停机：保障度短时下降，预算超支；拖：故障链概率上升；临时加固：占用备件，复检事件，听证会筹码 +1 |
| 与现有玩法 | 可把塔防的“塔位”换成“泵/阀/节点”，敌人换成“故障链”；与沉浸玩法的听证会场景共享同一份记录 |
| 可复用资产 | B-3 热交换站、7 号泵、支架裂纹、旧夹具、预算邮件、审批记录 |

> 这篇小说要测试的是：**“临时加固”是一种负责任的妥协，还是一种把风险递给下一班的体面说法？**
