# 加餐券

> 岗位：中环食堂后勤 · 时段：第 2 班 18:20 · 关键词：配给、人情、慢好

中环食堂在 18:20 进入晚高峰。

你站在配给线后面，围裙上沾着两滴酱油。窗口外的队伍拐了一个弯，绕过“今日菜单”的电子牌，一直排到娱乐舱的门口。菜单上写着：菌菇汤、合成蛋白饼、腌黄瓜、米饭。下面一行小字：“加餐券可换炖蛋一份。”

“下一位。”

一个男人把餐盘放上来。他身后跟着一个小女孩，扎着两根不太对称的辫子。男人把三张券放在台面上，其中一张的边角是红的。

你拿起来看了一眼。

“这张过期了。”

“昨天刚发的。”男人说，“你看，日期是今天。”

“日期是今天，但批次是昨天的。系统按批次算，不按日期算。”

男人的脸僵了一下。他回头看了一眼小女孩。小女孩正踮着脚看炖蛋的保温柜，鼻尖几乎贴在玻璃上。

“能不能通融一下？”男人压低声音，“就一份。她今天生日。”

你看了看那张券。过期的券不是假券，只是上一批配给多印出来的。按规矩，过期券要回收，不能兑换。按经验，回收的券会被记进“损耗”，然后在下一次配给里扣掉。也就是说，不管给不给，这锅炖蛋都已经做出来了。

“你等一下。”

你转身去找方姐。方姐是食堂的带班，正在后厨门口核对送货单。她听完，头也没抬：“过期券不能收。收了，系统对不上。”

“可她已经排了二十分钟。”

“那也没办法。”方姐把送货单翻了一页，“你要是心疼，就把你自己的那份给她。你的加餐券今天还没用吧？”

你没说话。

你的加餐券在围裙口袋里，折成四折。你本来打算下班后去娱乐舱换一杯热豆浆。外环的夜班冷，豆浆能暖手。

你回到窗口。男人还站在那里，小女孩在看炖蛋。你打开保温柜，拿出一份炖蛋，放在餐盘上。

“这份算我的。”你说。

男人愣了一下：“那你的券——”

“我没用券。”你说，“这份是员工餐。员工餐不能转让，但今天多做了几份。”

这是假话。员工餐不能转让，但今天没有多做的。你只是把自己的那份让了出来。

男人看着你，嘴唇动了动，最后说了一句：“谢谢。”

小女孩把炖蛋抱在怀里，像抱着一只暖水袋。她走了两步，又回过头，把手里的一张画片放在台面上。画片上画着一座月牙形的城，城里有很多亮着灯的小窗户。

“送你。”她说。

你把画片收进围裙口袋。画片很小，和加餐券差不多大。

19:40，晚高峰过去。方姐来收单，看到保温柜里少了一份炖蛋，又看到你手边的过期券，什么都没说。她在损耗单上写了一行：“员工餐多备一份，已消耗。”

系统提示：“员工餐不可转让，是否确认？”

方姐点了“确认”。

“下次别这么干。”她说，“要帮人，提前说。我可以在备餐的时候多打一份。”

“多打的那份，系统不查？”

“查。”方姐把单子合上，“但系统查的是数，不是人。”

你笑了一下。窗外的中环走廊亮着暖白的灯，广播在播晚间的配给通知：

“明日配给：基础配额不变，加餐券按贡献点发放。请各位湾民合理安排。”

你把小女孩的画片贴在更衣柜门内侧。画片上的月牙城画得很歪，但每一扇窗户都涂成了琥珀色。

## 场景卡：加餐券

| 项 | 内容 |
| --- | --- |
| 玩法形态 | 沉浸体验（食堂小场景）+ 放置玩法的日常事件 |
| 玩家目标 | 在配给规则、排队压力和自己那份加餐之间做一次分配 |
| 核心动词 | 配给、核对、让出、记录 |
| 可复用系统 | 配给券、贡献点、损耗单、员工餐、关系值、食堂满意度 |
| 关键选择 | ① 按规矩回收；② 用自己的券换；③ 找带班多备一份 |
| 分支后果 | 回收：规则 +1，关系 -1；让出自己的：关系 +2，体力 -1；找带班：需要提前沟通，解锁“多备一份”的食堂升级 |
| 与现有玩法 | 可做成放置玩法的每日事件，也可做成沉浸玩法的 3 分钟小场景；食堂等级影响中环满意度 |
| 可复用资产 | 食堂窗口、配给券、炖蛋、方姐、小女孩的画片、损耗单 UI |

> 这篇小说要测试的是：**“慢好”不是给得多，而是给得有人味；但人味不能总靠员工自己贴。**
