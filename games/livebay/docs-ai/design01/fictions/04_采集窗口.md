# 采集窗口

> 岗位：外环采集兵 · 时段：第 1 班 06:10 · 关键词：窗口、配额、返航

采集窗口只有十一分钟。

外环的采集场在月牙城的凸面外侧，是一片被牵引索固定的碎石带。每隔几个小时，城市的轨道会把这片碎石带带进采集臂的最佳角度，然后离开。你不能让它停下来等你。你只能在它经过的时候，把能拿的拿走。

“还有九分钟。”老麦在频道里说。

老麦是你的搭档，采集龄比你长十二年。他的声音像被砂纸磨过，永远比实际年龄老一点。

你坐在采集臂的控制位里，看着屏幕上三条牵引索的张力。第一条已经锁住了一块富含稀有金属的碎块，第二条在空转，第三条的挂钩有点松。

“三号索的挂钩。”你说。

“看到了。”老麦说，“上次就想换，没排上。”

“现在换？”

“没时间。先采。”

你按下采集键。第一条索收紧，碎块慢慢离开碎石带，进入货舱。吨位表跳了一下：+4.2。

“不错。”老麦说，“再来两块就够配额了。”

你看向屏幕边缘。在碎石带的另一侧，有一艘小型采集船，船身上刷着另一支舰队的编号。它比你们快，比你们新，比你们更靠近那片富矿。

“竞争者。”老麦说，“别理它。我们采我们的。”

你继续采。第二条索抓住了一块冰，第三条索在空转。时间还剩六分钟。

然后，通讯频道里插进一个陌生的信号。

“这里是采集船‘灰雀’，我们的牵引索断了，货舱里有一箱医疗物资，正在往你们的采集场飘。能不能帮忙拦一下？”

老麦看了你一眼。

“灰雀”是另一支舰队的船。医疗物资在太空里飘，会撞上碎石带，然后变成一堆谁也认不出的碎片。

“我们只有六分钟。”老麦说。

“我知道。”

“配额还差三吨。”

“我知道。”

“拦住它，我们就得少采一块。”

你看了一眼屏幕。那箱医疗物资正在碎石带的边缘打转，像一片被风吹起来的纸。它的轨迹会经过你们的第三条索，如果挂钩还在，就能抓住；如果挂钩松了，就会脱。

“三号索的挂钩。”你说。

“我说了，没时间换。”

“不用换。”你解开安全带，“我出舱。”

“你疯了？”

“挂钩松了，但还能用。我出去把它卡紧，三十秒。”

“三十秒够你死两次。”

“那你就当我死了两次。”

你穿上舱外服，打开气闸。外面的星光是冷的，碎石带在头盔视野里像一条缓慢流动的河。你抓住三号索的检修梯，把自己固定住，然后伸手去够那个挂钩。

挂钩确实松了。它的锁扣没有完全咬合，像是有人上次维修时少拧了半圈。你用手套把它压下去，听到“咔”的一声。

“好了。”你说。

“灰雀”的医疗箱正好飘过来。三号索的挂钩张开，像一只手，把箱子捞住。

“抓住了。”老麦说。

“还有三分钟。”你说。

你回到舱里，摘下头盔。老麦没说话，只是把采集臂的角度调向另一块矿。你们又采了一块，吨位表跳到 +7.1。

“够了。”老麦说，“返航。”

“配额还差一吨。”

“医疗箱算半吨。”老麦说，“我记在备注里。”

“系统会认吗？”

“不认。”老麦说，“但人会。”

你们返航的时候，采集窗口正好关闭。碎石带在身后慢慢转走，像一扇关上的门。灰雀的船长在频道里说了一句“谢谢”，声音很轻，像怕被谁听见。

回到船坞，交接员看了一眼货舱，又看了一眼医疗箱。

“配额不足。”他说。

“医疗箱是救援物资。”老麦说。

“我知道。”交接员在单子上写了一行字，“但系统只看吨位。”

他停了一下，把单子翻到背面，手写了一句：

“另：协助灰雀回收医疗物资一箱，建议计入协作记录。”

系统提示：该字段不在标准模板内。

交接员抬头看了你一眼：“你们要写吗？”

“写。”你说。

回中环的摆渡舱里，老麦靠在座位上，闭着眼。你看着窗外，月牙城的外弧在星光里慢慢展开，像一条没有尽头的安全带。

“明天还有窗口。”老麦说。

“嗯。”

“下次记得换挂钩。”

“下次你换。”

他笑了一声，没再说话。

## 场景卡：采集窗口

| 项 | 内容 |
| --- | --- |
| 玩法形态 | 限时塔防变体：守的不是城，是采集窗口 |
| 玩家目标 | 在 11 分钟内采够配额，同时决定是否救“灰雀”的医疗箱 |
| 核心动词 | 锁定、牵引、切割、出舱、返航 |
| 可复用系统 | 倒计时、氧气、牵引索/挂钩、吨位、竞争者、救援事件、备注字段 |
| 关键选择 | ① 只采配额；② 花 30 秒修挂钩救医疗箱；③ 放弃三号索，抢竞争者旁边的富矿 |
| 分支后果 | 只采：配额达标，灰雀关系 -1；救：配额不足但协作记录 +1，船坞关系 +1；抢矿：收益高，竞争者关系 -2，可能碰撞 |
| 与现有玩法 | 与塔防共享“波次/窗口”时间结构；塔=采集臂/牵引索，敌人=乱流/枯竭/竞争船，资源=时间/氧气 |
| 可复用资产 | 采集场、三号索、灰雀、医疗箱、吨位表、船坞交接单 |

> 这篇小说要测试的是：**当“配额”和“救人”冲突时，玩家是否愿意用一次不达标的返航，换一个不在系统里的备注。**
