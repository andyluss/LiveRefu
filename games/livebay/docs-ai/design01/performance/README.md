# LiveBay · 性能基线

> 运行：`./run.sh perf` · 原始数据：[`bench.json`](bench.json)
>
> 口径：Godot 4.7 **headless**；模拟步进、CPU 绘制命令生成、静态内存、音频驱动参数。**不含 GPU 帧时间/渲染管线/真实音频输出。**

## 一、环境

| 项 | 值 |
| --- | --- |
| 引擎 | Godot 4.7-stable (official) |
| 系统 | macOS · Apple M1 Pro · 8 cores |
| 渲染 | headless；无 GPU 帧 |
| 音频 | Dummy driver · 44,100 Hz · 4 个播放通道 |
| 场景 | `bay01` standard（两座拦截炮 + 供给/补塔/升级） |
| 采样 | 地图预热后 20 次加载 / 9,930 帧 / 每档 120 步 / 18,000 帧长跑 / 1,000 帧绘制命令 |

## 二、结论

| 指标 | 结果 | 判定 |
| --- | ---: | --- |
| 5 波模拟 p95 | **0.099 ms/step** | 远低于 16.7 ms 帧预算 |
| 2,000 实体 p95 | **8.178 ms/step** | 约为 60 Hz 预算的 49%；max 25 ms 有尖峰 |
| 5 分钟长跑（18,000 帧） | **196.9 ms wall** | 无异常，约 0.0109 ms/帧 |
| 地图加载 p95 | **≤4.31 ms** | 三图均低于 5 ms |
| CPU 绘制命令 p95 | **0.092 ms/帧** | 176 draw calls/帧，不含 GPU |
| 静态内存（2,000 实体） | **26.16 MB** | 基线约 23.9 MB，+2.25 MB |

**结论**：headless 的模拟与 CPU 绘制预算充足；但 GPU 帧时间、真实音频输出、渲染管线与内存峰值仍未测，不能据此宣布“性能已验收”。

## 三、逐项数据

| 指标 | 值 |
| --- | ---: |
| 采样帧数 | 9,930 |
| avg | 0.044 ms |
| p50 | 0.032 ms |

> 这是 `Sim.step(1/60)` 的耗时，不是整帧渲染时间。

### 3.7 GPU

- headless 下 `RenderingServer` 没有真实 adapter，GPU 帧时间不可得；
- 本次未伪造 GPU 数字；
- 需要窗口/显示环境，用 Real 60/120 Hz 采样 `TIME_PROCESS`、`RENDER_TOTAL_DRAW_CALLS_IN_FRAME`、`RENDER_VIDEO_MEM_USED`。

## 四、已知限制

- headless，无 GPU/真实渲染管线；
- 音频为 Dummy driver，无真实输出；
- 合成实体不移动、不死亡，只压索敌/遍历；
- 未采样内存峰值、对象分配速率、磁盘 I/O；
- 不同机器结果会变化，应看同一机器的趋势。
