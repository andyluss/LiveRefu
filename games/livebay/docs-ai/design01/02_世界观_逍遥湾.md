# 02 · 世界观：逍遥湾

> 本文把概念设定里的骨架展开成可用的世界细节。**凡未标【人类已定】的，都是 AI 候选，不是设定。**

## 一、已定的骨架

【人类已定】来自概念设定：

- 时代：未来人类移民太空的漫长旅途；
- 主体：人类移民舰队集群成立的一座移动太空城，形状类似月牙；
- 三环：外环舰队负责护卫与能源资源收集；内环舰队是政治经济文化中心；中环舰队是居民区；
- 生活：大多数人在中环消磨时间，在「慢好三生保障体系」下生存、生活、生产；
- 中环设施：养生舱、娱乐舱、教育舱等多种功能舱；
- 工作：少数人被选拔为工作人员，在三环做各种工作，获得少量额外奖励；压力大时可申请退役或轮岗，由他人顶上。

## 二、城的形状：为什么是月牙

【AI 候选】月牙（crescent）不只是造型，它可以解释三件事：

1. **凹面是港湾**：月牙的凹面朝向航向后方，形成天然遮挡，船坞、采集场、货运码头集中在这里；两端的「尖角」是导航与推进阵列。
2. **凸面是盾牌**：外环沿着凸面展开，最先承受星际碎片与乱流；这也是外环护卫与采集舰队的驻泊带。
3. **环与环之间是梯度**：从凸面到凹面，辐射、重力、噪音、温度逐级变化，正好对应「外环—中环—内环」的功能分区。

```text
                航向 ↑
        ╭──────────────────────╮
      ╱  外环：护卫 / 采集 / 能源  ╲
     │   ┌──────────────────┐   │
     │   │ 中环：居住 / 养生 / │   │
     │   │ 娱乐 / 教育        │   │
     │   │   ┌──────────┐   │   │
     │   │   │ 内环：政治 │   │   │
     │   │   │ 经济 / 文化 │   │   │
     │   │   └──────────┘   │   │
     │   └──────────────────┘   │
      ╲      凹面：港湾 / 船坞     ╱
        ╰──────────────────────╯
```

> 上图是示意，不是最终布局。工程里的地图是弧线路径 + 若干塔位，见 [04](04_塔防玩法.md)。

## 三、舰队集群：城不是一艘船

【AI 候选】「舰队集群」可以这样理解：

| 层级 | 构成 | 功能 | 视觉关键词 |
| --- | --- | --- | --- |
| 主城 | 月牙形核心城 | 居住、行政、文化、医疗 | 稳定、密集、暖光 |
| 外环舰队 | 护卫舰、采集船、能源驳船 | 防御、采矿、供能 | 冷灰、橙色警示、外露桁架 |
| 中环舰船 | 居住舱、养生舱、娱乐舱、教育舱 | 生活与再生产 | 暖白、织物、植物 |
| 内环舰船 | 议会、交易所、档案馆、广播中心 | 决策与合法性 | 石材、玻璃、黄铜 |

这个结构的好处是：**每一环都可以独立成为关卡**。外环是塔防的主战场，中环是沉浸玩法的主场景，内环是叙事与政治的舞台。

## 四、时间：航行第几代（D06 已裁决）

**裁决（2026-11-03）**：**200 年，第七代。**

- 地球已经变成传说，不是日常记忆；
- 大多数居民认同「湾民」身份，而不是「地球人」；
- 祖辈的出发故事仍在节日、菜谱与方言里；
- 少部分传统派坚持「我们只是路过」。

为什么不是 80 年或「不可考」：

- 80 年（第三代）离地球太近，冲突容易变成「第一代 vs 第二代」的家庭剧，神秘感弱；
- 「不可考」叙事空间最大，但会把「历史断裂」变成主要谜题，容易失焦；
- 200 年刚好：足够让「湾民」成为独立文化，又不至于完全失去出发地的记忆。

> 「出发多久」本身可以成为一个被低报的数字（D08），但居民日常不会追问。

## 五、外部世界：外面有什么

【已裁决 D02】混合：自然风险 + 内部故障为主，人类冲突作为稀有事件。首版只做 A（自然）+ C（内部），B（人类）后置。

| 候选 | 外部 | 敌人 | 玩法含义 |
| --- | --- | --- | --- |
| A 自然风险 | 星际碎片、辐射、乱流、资源枯竭 | 碎片群、风暴、矿脉枯竭 | 偏生存/工程，政治性弱 |
| B 人类冲突 | 其他舰队、海盗、失联殖民船 | 掠夺者、走私者、失控 AI | 偏战争，戏剧性强，但容易落俗 |
| C 内部故障 | 外部只是背景，真正威胁来自系统老化与人为失误 | 故障链、压力波、事故 | 最贴合「岗位」主题，但需要更强的系统设计 |
| D 混合 | 外部自然风险 + 内部故障，人类冲突作为稀有事件 | 三类交替 | 最丰富，也最难平衡 |

> **裁决（2026-11-03）**：D。理由：混合最丰富；首版用自然 + 内部让玩家先理解「岗位」，人类冲突留作后期事件。
>
> **工程状态**：A+C 已实现。C 表现为「故障」从湾口反向扩散，经过塔位时使设施短暂离线；不会直接扣保障度，但会削弱防线。

## 六、日常生活：中环的一天

【AI 候选】中环的时间不是按「白天/黑夜」，而是按**班次**：

| 时段 | 活动 | 空间 |
| --- | --- | --- |
| 第一班 | 基础保障、医疗、教育、食堂 | 中环各舱 |
| 第二班 | 娱乐、社交、体育、课程 | 娱乐舱、教育舱 |
| 第三班 | 养生、睡眠、心理辅导 | 养生舱 |
| 交接 | 广播、值班表更新、事故通报 | 全城 |

- **养生舱**：不是医院，而是「恢复舱」；居民定期进入，监测身体与心理状态。
- **娱乐舱**：虚拟场景、桌游、影院、运动；也是信息交换与非正式经济的场所。
- **教育舱**：从儿童到成人再教育；也是选拔考试的培训地。
- **食堂**：配给制，但有「加餐券」；是阶层观察的最佳场所。
- **广播**：机构的声音；每天固定时段播报，是沉浸玩法的重要叙事载体。

## 七、政治、经济与文化

### 7.1 治理（D07 已裁决）

**裁决（2026-11-03）**：**双轨制**——日常由算法配给，危机由议会接管。

- **日常**：保障体系按算法分配资源，规则透明、效率高、无法处理例外；
- **危机**：议会召开特别会议，决定优先级、征用与例外；
- **甩锅**：算法说「这是议会批准的例外」，议会说「这是算法给出的建议」；
- **申诉**：居民可以申诉，但流程漫长，且常常在两条轨道之间被踢回。

这套结构的好处是：它天然产生「谁负责」的戏剧，也贴合「机构」主题。坏处是：它让「没有人负责」成为常态，而这正是 D01=B 想写的东西。

### 7.2 经济

【AI 候选】

- 货币：贡献点（工时 + 岗位难度 + 风险系数）；
- 配给：基本生活免费，额外享受靠贡献点；
- 限制：不能积累土地/生产资料，避免出现「湾内资本家」；
- 灰色地带：加餐券、娱乐舱预约、外环走私。

### 7.3 文化

【AI 候选】

- **出发地记忆**：节日、菜谱、方言、宗教；
- **湾民身份**：新一代的归属感，可能与传统派冲突；
- **体育/竞技**：零重力球类，跨环联赛；
- **艺术**：以「维修美学」为主，废料再创作。

## 八、秘密与裂缝（D08 已裁决）

**裁决（2026-11-03）**：埋 **低报事故**，且**只埋线索、不揭开**。

| 候选 | 状态 | 说明 |
| --- | --- | --- |
| A 城没有目的地 | 未采用 | 容易变成虚无主义 |
| B 优先级表被篡改 | 未采用 | 阴谋论，可做悬疑，但会抢走「岗位」主题 |
| **C 外环事故被系统性低报** | **采用** | 广播里的事故数字对不上；最贴「机构疲惫」 |
| D 第一代冷冻舱 | 未采用 | 伦理冲击强，留作后续素材 |

具体埋法：

- 广播每天播报「外环事故 0 起」，但玩家在塔防结算里看到的漏过数与之不符；
- 交接记录里偶尔出现「已按惯例处理」的措辞；
- 第 4 波故障出现时，广播仍然说「系统运行正常」；
- 第一版不解释谁在低报、为什么低报。

> 留白比揭秘更适合长线；D08 只决定「埋哪条」，不决定「何时揭开」。

## 九、基调：有裂缝的善意（D01 已裁决）

【已裁决 D01】逍遥湾不是完美乌托邦，也不是坏制度：

- 体系大体有效，真的救了很多人的命；
- 但它的效率建立在对少数人的排除上；
- 居民既依赖它，也怀疑它。

这条基调直接影响世界观的三处写法：

1. **广播不总是可信**：事故数字、配给理由、选拔结果都可能被修饰；
2. **外环的牺牲有名字**：事故不是背景数字，而是具体的人；
3. **中环的安稳有代价**：有人替他们承担了风险，而他们未必知道。

> 基调已定，裂缝已定为「低报事故」，具体埋法见第八节。
