# 03 · 敌人数值

> 四种敌人对应四种问题：数量、速度、厚度、内部故障。它们不是四个换皮怪，而是四种不同的防线压力。

## 三、故障：内部故障（C）的数值表达

故障不是「从外面打进来」的敌人，而是「系统里坏掉的一段」：

| 参数 | 值 | 含义 |
| --- | ---: | --- |
| HP | 36 | 一座拦截炮在它靠近前通常打不死 |
| 速度 | 58 | 比碎片快，比乱流慢 |
| 方向 | reverse | 从湾口沿路径向外扩散 |
| 停塔时长 | 2.5 s | 经过塔位时让该塔离线 |
| 停塔半径 | 100 px | 覆盖塔位到路径的距离 |
| 最多停塔 | 2 座 | 防止一次故障锁死整条防线 |
| 漏过伤害 | 0 | 它不直接打城，只削弱防线 |

设计意图：

- 故障让「只堆入口方向火力」的布局吃亏，因为它是从湾口方向来的；
- 停塔 2.5 秒足够让一波敌人漏过，但玩家可以用第二座塔或提前击杀来兜底；
- 最多 2 座，避免「一次故障 = 必败」；
- 故障奖励 4，击杀它不是主要经济来源。

## 四、敌人与塔的对应关系

| 敌人 | 最有效的塔 | 最不擅长的塔 | 原因 |
| --- | --- | --- | --- |
| 碎片 | 拦截炮 | 脉冲环单独 | 血量低，单体击杀快 |
| 乱流 | 脉冲环 + 拦截炮 | 重炮型单体 | 速度快，需要减速拉长射程时间 |
| 重壳 | 2 座拦截炮 / 三级拦截炮 | 单座脉冲环 | 90 HP，需要爆发 |
| 故障 | 中段拦截炮 | 靠湾口的补给塔 | 反向移动，靠湾口的塔先被停 |

## 五、调参旋钮

| 想改什么 | 改哪里 | 注意 |
| --- | --- | --- |
| 前期太难 | `debris.hp` / `turbulence.speed` | 先降 HP，再降速度；速度影响很大 |
| 后期太软 | `hulk.hp` / 第 5 波数量 | 重壳是后期主要压力 |
| 故障太烦 | `disable_duration` / `disable_targets` | 先降时长，再降目标数 |
| 故障没存在感 | `disable_radius` / `fault.speed` | 半径要覆盖塔位到路径的距离 |
| 经济太松 | `reward` | 奖励/HP 是经济滚雪球的核心 |
