## 三、表格怎么被导出

每张要导出的表前面有一行 HTML 注释：

```markdown
<!-- export: <key> -->
| id | name | cost | ... |
```

导出脚本按标记找到表格，读取表头和数据行，写出对应的 JSON。表格里不要用半角 `|` 作为内容分隔；需要竖线时用全角 `｜`。

## 四、导出命令

```bash
cd games/livebay
python3 tools/export_numbers.py          # 写入 game/data/*.json
python3 tools/export_numbers.py --check  # 只检查是否一致
./run.sh test                            # 数据加载 + 73 项玩法断言
```

## 五、规则

1. **不要手改 `game/data/*.json`**：它们是导出物，下次导出会覆盖；
2. **先改表格，再导出**：这样文档与运行时永远同源；
3. **改完必须跑测试**：至少 `./run.sh test` 与 `export_numbers.py --check`；
4. **一次只改一个旋钮**：难度问题先看 [06_难度与评级](06_难度与评级.md) 的调参优先级；
5. **数值未定案**：v0.1 是切片锁定值，不是最终平衡；人类试玩后可以重新裁决。
