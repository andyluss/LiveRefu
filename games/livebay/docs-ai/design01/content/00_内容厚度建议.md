# 00 · 内容厚度建议

> **一句话**：LiveBay 缺的不是“更多波”，而是**更多可复述的班次、更多能改变打法的塔/敌、更多会被记住的事故**。
>
> **结论**：先做 **v0.2「三班制」**——不新增第四种玩法、不增加日常/体力，用 3 份班次合同、2 座新塔、2 个新敌人、12 张检查单/故障卡、8 波/图，把“同一班”做出变化；再进 L2/L3。
>
> **当前**：上述核心内容已实现；3 名湾民、3 段音乐与 12 个环境音仍是下一步。

## 一、先把“厚度”定义清楚

内容厚度不是内容数量，而是玩家在相同规则下能产生多少**不同且可复述的经历**。建议用五个指标衡量：

| 指标 | 问题 | 当前 | 目标 |
| --- | --- | --- | --- |
| **决策厚度** | 一局里有多少次真正影响结果的选择？ | 建造 + 开波 + 偶发检查单 | 每波至少 1 个，整局 5–8 个 |
| **组合厚度** | 塔/敌/地图/合同能组出多少有效组合？ | 4 塔 × 5 敌 × 3 图 | 6 塔 × 7 敌 × 3 图 × 3 合同 |
| **情境厚度** | 有多少“这一班不一样”的作者情境？ | 1 套 5 波 × 3 图 | 3 合同 × 3 图 × 8 波 |
| **叙事厚度** | 有多少可被记住的人/事故/后果？ | 事故记录 + 低报 carry | 3 湾民 + 12 张卡 + 3 条事故链 |
| **复玩厚度** | 通关后为什么再开一班？ | 评级/记录 | 合同变体 + 解锁 + 城市回声 |

> 只增加波数，会增加“时长”，不会增加“厚度”。

| 项 | 当前 | 问题 |
| --- | ---: | --- |
| 职业 | 1 | 岗位身份主要靠文案，不靠规则差异 |
| 地图 | 3 | 地形与修正有差异，但缺少“这张图专属的班次” |

| 敌人 | 7 | 已加护盾载体/分裂残片，组合威胁仍少 |
| 检查单/故障卡 | 12 | 已常规化，但文本与后果还需人类试玩验证 |
| 合同 | 3 | 稳定/审计/故障潮已接入 |

| 音乐/环境音 | 短音效 | 夜班氛围不足 |

## 三、增加厚度的五条路径

### 3.1 每班多一个“岗位决策”，而不是多一波

不要用“第 6 波”填充时间，用**每波前的短决策**填充意义：

- 修哪段弧：修 A 段保覆盖，修 B 段保供能；
- 保哪座塔：隔离故障塔，还是旁路让相邻塔降级；
- 报不报：如实记录拿长期信任，低报拿短期供能；
- 接不接：班次合同改变本班规则，而不是加数值。

**验收**：一局至少 5 个可回述的决策点；每个决策都有可见代价与延迟后果。

### 3.2 塔与敌：增加“动词”，不要增加“数值皮肤”

当前 4 塔已经覆盖单体/范围/控制/经济。下一批不建议再做“更贵的单体塔”，而应增加**改变站位与时机**的动词：

| 新塔 | 动词 | 决策 |
| --- | --- | --- |
| **焊补塔** | 修复降级/停塔，消耗供能 | 修塔还是补输出？ |
| **信标塔** | 标记目标，提升其他塔伤害 | 自己不出伤，值不值得占一个塔位？ |

敌人同理，优先增加**组合型威胁**：

| 新敌人 | 动词 | 迫使玩家 |
| --- | --- | --- |
| **护盾载体** | 给周围敌人减伤 | 先点杀还是先控场？ |
| **分裂残片** | 死亡分裂 | 范围塔与单体塔的取舍 |
| **审计无人机** | 记录低报，改变结算 | 这一班要不要“按惯例”？ |

**验收**：每张图至少 3 套可行构筑；不存在一套“无脑最优”。

### 3.3 地图与波次：做“作者情境”，不是随机堆怪

三张图已经有不同长度、塔位与修正。下一步不是加第四张图，而是让每张图有**专属班次**：

| 地图 | 专属情境 | 改变什么 |
| --- | --- | --- |
| bay01 外环 | 长弧夜班 | 覆盖窗口长，适合教学与稳定构筑 |
| bay02 中环 | 维护环检修 | 塔位多但供能紧，迫使取舍 |
| bay03 湾口 | 对接臂故障潮 | 短弧 + 故障密集，考验隔离/旁路 |

波次从 5 提到 8，但不是简单加三波：

- 第 3 波：第一次检查单；
- 第 5 波：第一次故障选择；
- 第 7 波：合同事件（如审计/停电/交接）；
- 第 8 波：小高潮/Boss 或“必须做一次不可逆选择”。

### 3.4 L1 → L2 → L3：用作者内容填层，不用系统填层

| 层 | 内容增量 | 厚度贡献 | 成本 |
| --- | --- | --- | --- |
| **L1 班次** | 3 份合同、12 张检查单/故障卡、3 条事故链 | 同一张图玩出不同班 | 低 |
| **L2 岗位** | 2 个职业、塔座模块、备件、3 名湾民 | 同一班长出长期选择 | 中 |
| **L3 城市** | 6 个城市事件、舱室、执照 | 你不在时城怎么活 | 高 |

顺序不要反：L1 没做厚之前做 L3，只会得到“更大的空”。

### 3.5 表现层：让内容被记住

厚度也包括“记得住”：

- 1 名调度员/班长的语音与短对话；
- 3 名湾民，各带一个与班次相关的小请求；
- 3 段音乐：准备/交战/结算；
- 12 个环境音与故障音；
- 结算页的“本班事故卡”，可回看。

不需要全量配音；关键是**每班至少一个可记住的声音/面孔/事故**。

## 四、v0.2「三班制」内容清单

建议作为下一个内容切片，不新增模式、不做日常：

| 类别 | 当前 | v0.2 目标 | 量级 |
| --- | ---: | ---: | --- |
| 职业 | 1 | 1（已实现） | 不做 L2 |
| 地图 | 3 | 3（已实现） | 不新增地图 |
| 波次/图 | 8 | 8（已实现） | +3 波/图 |
| 塔 | 6 | 6（已实现） | +焊补、信标 |
| 敌人 | 7 | 7（已实现） | +护盾载体、分裂残片 |
| 班次合同 | 3 | 3（已实现） | 稳定班/审计班/故障潮 |
| 检查单/故障卡 | 12 | 12（已实现） | 3 类 × 4 张 |
| 事故链 | 1 条样例 | 3 条 | 低报/旁路/隔离各一条 |
| 湾民 | 0 | 3 | 各 1 个请求 |
| 城市事件 | 0 | 0 | 留给 L3 |
| 音乐 | 0 | 3 段 | 准备/交战/结算 |
| 环境/故障音 | 短音效 | 12 个 | 不追求全配音 |

**内容量级**：3 图 × 8 波 = 24 个波次节点，但共享 3 份合同与 12 张卡；不是 24 段完全独立的内容。

## 五、版本切片

### v0.2 · 三班制（建议先做）

- 目标：同一张图能玩出三种班；
- 内容：3 合同、6 塔、7 敌、8 波、12 卡、3 事故链、3 湾民、3 段音乐；
- 验收：10 人试玩，每图至少 3 套可行构筑，重玩意愿 ≥60%。

### v0.3 · L2 岗位层

- 2 职业（外环守卫 + 中环维护）；
- 塔座 2 槽、备件、事故链；
- 1 张新图（中环维护环深化或湾口新段）；
- 8 敌、8 塔；
- 验收：职业差异改变前 3 波决策，而不是只改数值。

### v0.5 · L3 轻城市

- 3 职业、5 图、10 敌、8 塔；
- 6 个城市事件、舱室、执照；
- 只做“你不在时城怎么活”，不做全城模拟；
- 验收：离开 3 天回来有事发生，但不惩罚离开。

## 六、内容生产管线

内容厚度不能靠手写 JSON 堆：

```text
内容提案（一页）
  → numbers/ 表格（数值与引用）
  → export_numbers.py
  → game/data/*.json
  → MissionPack 目录
  → 自动测试 + 沙盘 + 人类试玩
```

每份内容必须带：

- 一句“这一班为什么不同”；
- 一个可失败/可取舍的决策；
- 一个可被记录的后果；
- 一个验收指标（不是“感觉好玩”）。

## 七、验收指标

| 指标 | 目标 |
| --- | --- |
| 单局时长 | 10–15 分钟（8 波） |
| 每局真实决策 | ≥5 个 |
| 每图可行构筑 | ≥3 套 |
| 主导策略 | 不存在一套明显最优 |
| 人类试玩 | 10 人 × 3 图 |
| 重玩意愿 | ≥60% 想再来一班 |
| 内容矩阵覆盖 | 6 塔 / 7 敌 / 3 图 / 8 波 / 3 合同 |
| 失败可归因 | 玩家能说出“我哪一步做错了” |

## 八、不做什么

- 不新增第四种玩法；
- 不做日常/体力/限时登录；
- 不用“20 波”冒充厚度；
- 不做只改数值的塔/敌皮肤；
- 不在 L1 没做厚之前做 L3；
- 不把内容全塞进一张图。

## 九、需要拍板

1. 是否按 **v0.2 三班制** 作为下一内容切片？
2. 3 份合同选哪三种：稳定班 / 审计班 / 故障潮，还是其他组合？
3. 新塔是否就用“焊补 + 信标”这两个动词？
4. 新敌人是否就用“护盾载体 + 分裂残片”？
5. 单局目标时长 10–15 分钟是否接受？
6. 是否先做 10 人人类试玩，再决定 L2？

## 十、我的建议

**先做 v0.2，不先做 L2/L3。**

理由：

- 当前最短的板不是“没有长期系统”，而是“同一班不够厚”；
- 三班制能用最低成本验证“岗位感”是否真的成立；
- 如果三班制都不能让玩家想再来一班，L2/L3 只会把问题放大。
