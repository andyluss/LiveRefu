# ART-B1 · 三环三套视觉语法

> **一句话**：外环、中环、内环不是三种颜色，是三套“材质 + 光 + 密度 + 声音”的语法。
> **形式化**：`Ring → (Palette, Material, Light, Density, Sound)`。

## 一、形式化表述

```text
Grammar = (Palette, Material, Light, Density, Sound)
Grammar(Outer)  = (coldGray+orange,  metal+ceramic,  hard,   sparse, wind+pump)
Grammar(Middle) = (warmWhite+sage,   wood+fabric,    soft,   medium, voices+water)
Grammar(Inner)  = (dark+bronze,      stone+brass,    formal, dense,  echo+paper)

distinct(Grammar(r1), Grammar(r2)) ⇒ ΔPalette ∨ ΔMaterial ∨ ΔLight
```

## 二、通俗解释

玩家不看标签，也能靠“看起来/听起来像哪里”判断自己在哪：

- **外环**：冷、硬、空。金属、陶瓷、警示条、泵声、风。人是小的，城是大的。
- **中环**：暖、软、有人气。木材、织物、植物、暖白灯、广播、孩子跑动。
- **内环**：暗、重、正式。石材、黄铜、深色木、回声、纸张、脚步。

三环的差异不是“换一套色板”，而是**换一种生活密度**。

## 三、条款

### MUST

1. **M1**：每个场景必须能明确归入外环/中环/内环之一，并使用对应语法。
2. **M2**：三环至少在两轴上不同：色板、材质、光、密度、声音。
3. **M3**：不得用同一套“通用科幻内景”套三环。
4. **M4**：外环不得过度温暖，中环不得过度冰冷，内环不得过度拥挤。
5. **M5**：转场必须让玩家感到“我换环了”，不能只换背景图。

### SHOULD

1. **S1**：外环用安全橙做活动部件；中环用琥珀做窗灯；内环用黄铜做权力/档案。
2. **S2**：中环保留植物与生活杂物；外环保留工具与备件；内环保留纸张与印章。
3. **S3**：声音也按环分层：外环低频、中环人声、内环回声。

### MAY

1. **Y1**：可以有“跨环空间”（摆渡舱、升降井），但必须显示两边语法的交界。
2. **Y2**：可以有“失修的中环”作为叙事例外，但不能成为默认。

## 四、判定与验收

```text
valid(scene) ⇔
  scene.ring ∈ {Outer, Middle, Inner} ∧
  uses(Grammar(scene.ring)) ∧
  Δ(scene, otherRings) ≥ 2 axes
```

检查：

- [ ] 遮住文字，能看出这是哪一环吗？
- [ ] 材质、光、密度是否一致？
- [ ] 是否只是换了一个颜色？
- [ ] 声音是否参与空间区分？

## 五、反例

- 三环都用同一套蓝灰金属 + 青色灯；
- 外环出现大量暖木家具；
- 中环像无菌医院，没有植物与杂物；
- 内环像夜市，没有回声与纸张。
