# 01 · 设计力评估

> **一句话**：LiveBay 的主题、岗位感与故障选择已经成立；8 波内容让“同一班”有了厚度；但职业、长期留存、表现层与真人验证仍然不足。
>
> **结论**：**3.70 / 5（B，约 74/100）**，处于 **L2+**；设计方向可信，内容刚够试玩，不够长线。

## 一、评估口径

设计力不是“文档写得多”，而是：

- 主题是否转化为**可玩的决定**；
- 一局是否有**可复述的选择**；
- 内容是否有**组合与变化**；
- 表现是否让人**记得住**；
- 长期是否有**再开一班的理由**；
- 设计是否有**可验证的边界**。

## 四、已经成立的部分

### 4.1 主题转成了决定

- 你不是指挥官，是值班人；
- 检查单不是弹窗，是“照签/复查/按惯例”的代价；
- 故障不是敌人，是“隔离/旁路”的选择；
- 审计/低报/事故记录让“记录”成为玩法。

这是 LiveBay 最有辨识度的部分。

### 4.2 8 波与 v0.2 内容

| --- | ---: |
| 塔 | 6 |
| 敌人 | 7 |
| 波次/图 | 8 |
| 检查单/故障卡 | 12 |
| 合同 | 3 |
| 湾民 | 3 |
| 音乐 | 3 段 |
| 环境/故障音 | 12 |

标准班 headless 结果：

- bay01 B / 41；

### 4.3 三张图有不同问题

- bay01 长弧：覆盖与稳定；
- bay02 回环：供能紧、塔位多；
- bay03 短弧：故障密集、冗余少。

## 五、设计债

| 债务 | 说明 | 优先级 |
| --- | --- | --- |
| 只有 1 个职业 | 岗位身份仍主要靠文案，不靠规则差异 | 高 |
| 无真正元进程 | ShiftMemory 记录不等于长期成长 | 高 |
| 缺人类难度曲线 | 8 波是 headless 平衡，不是人类节奏 | 高 |
| 表现层占位 | 程序化几何 + 占位音乐；缺角色/城市生活 | 中 |
| 可访问性/本地化 | 仅中文，无辅助选项 | 中 |
| 三图关卡叙事薄 | 有修正，缺“这张图专属的班次” | 中 |
| 卡牌文本未验证 | 12 张卡需要人类试玩判断是否打断 | 中 |

## 六、设计承诺 vs 当前

| 承诺 | 当前 |
| --- | --- |
| 你不是指挥官，是值班人 | 部分：检查单/故障成立，但多数时间仍像塔防 |
| 城市不是背景，是系统 | 弱：场景与文案有城市，玩法层几乎没有 |
| 夜班有节奏与代价 | 成立：8 波、准备/交战/整备、保障度 |
| 故障不是数值，是选择 | 成立：隔离/旁路/审计是最强系统 |
| 放置养成/长期城市 | 未成立：只有记录与低报 carry |

## 七、下一步

1. **10 人 × 3 图人类试玩**：理解成本、首波决策、失败归因、再开意愿；
2. **L1 常规化**：交接/巡检/低报/故障变成每班常规，不只样例；
3. **中场决策**：8 波内至少 5 个真实决策点；
4. **职业差异**：第 2 职业必须改变前 3 波，而不是改数值；
5. **表现层一次到位**：至少 1 名角色、城市生活层、音乐与环境音；
6. **可访问性/本地化**：输入重映射、字号、语言策略。

## 八、结论

设计方向已经成立，内容刚够试玩，但**不够长线**。

> 下一步不要先加 L2/L3；先用人类试玩验证“这一班是否值得再来一班”。
