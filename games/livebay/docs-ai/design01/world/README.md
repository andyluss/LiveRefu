# 世界观目录 · 逍遥湾

> 这里放**支撑玩法的世界参考**：地理、组织、岗位、日常生活、故障文化、生存资源。
>
> 除了标【人类已定】的内容，其余都是 **AI 参考候选**，不是最终设定；可以改、可以删、可以被玩法推翻。

## 一、这个目录解决什么问题

玩法需要的不只是“世界设定”，而是能被引用的**具体背景知识**：

- 为什么外环有塔位，中环没有？
- 夜班为什么有检查单、交接记录和低报？
- 断氧、断电、封舱时，城里的人会先救什么？
- 一个新玩法需要新的地点、组织、习俗时，去哪里找依据？

本目录的文档按“**能直接支撑玩法/叙事/美术**”来写，不追求百科式完整。

## 三、写作约定

1. **先标来源**：人类已定 / AI 参考 / 工程占位，三者不要混写。
2. **先写用途**：每个设定尽量回答“它能支撑哪个玩法/场景”。
3. **不写死数值**：数值放 `game/data/`；世界观只写量级、限制与代价。
4. **允许矛盾候选**：不确定的地方列 2–3 个候选，标代价，不偷偷定案。
5. **不替代人类源**：人类原始设定在 `docs-human/概念设定.md`；本目录只展开，不改写。
6. **不写百科**：优先写“玩家能遇到、能选择、能付出代价”的部分。
