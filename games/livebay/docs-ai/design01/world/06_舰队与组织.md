# 04 · 舰队与组织

> 组织不是背景板：每个组织都应该能给出**合同、权限、冲突和代价**。

## 一、舰队集群

【人类已定】逍遥湾是“人类移民舰队集群”成立的一座移动太空城，不是单艘船。

【参考】可以把“城”理解为一个**松散的联邦**：

```text
湾民议会（合法性）
├── 城务总署（日常运行）
│   ├── 配给与算法署
│   ├── 外环值班处
│   ├── 维护与工程工会
│   ├── 医疗与照护署
│   ├── 档案与广播中心
│   └── 港口与航运署
├── 舰队代表（各舰/各环）
└── 居民组织（互助会、传统派、竞技联盟）
```

> 这是一个候选结构，不是最终组织图；“谁听谁的”本身就是玩法冲突来源。

## 二、核心组织

### 2.1 湾民议会

- **职责**：危机裁决、预算/优先级、例外批准；
- **权力**：可以征用、封舱、停班、宣布撤离；
- **弱点**：日常不直接执行，依赖总署；出事时容易“集体负责=无人负责”；
- **玩法接口**：合同、危机事件、撤离决定、低报调查。

### 2.2 城务总署

- **职责**：把议会的决定变成流程；
- **组成**：配给、值班、维护、医疗、档案、港口；
- **文化**：流程正确 > 结果正确；表格齐全 > 人是否撑得住；
- **玩法接口**：检查单、交接记录、事故上报、权限门。

### 2.3 外环值班处

- **职责**：排班、塔位、巡检、故障隔离、交接；
- **文化**：不鼓励英雄，鼓励“按流程活下来”；
- **弱点**：人手不足、老设备、低报压力；
- **玩法接口**：塔防、生存、班次合同、故障处置。

### 2.4 维护与工程工会

- **职责**：维修、备件、管线、舱门、外环结构；
- **权力**：没有他们，塔和生命维持都转不动；
- **文化**：手艺、经验、非正式师徒制；
- **冲突**：工会知道设备老化，但预算/流程不让说；
- **玩法接口**：修舱、备件、封舱、故障链。

### 2.5 医疗与照护署

- **职责**：养生舱、心理辅导、职业康复、退役评估；
- **文化**：温和、专业、资源有限；
- **冲突**：照护标准 vs 岗位需求；“还能上班”不等于“还健康”；
- **玩法接口**：湾民状态、轮岗、退役、照护事件。

### 2.6 档案与广播中心

- **职责**：事故档案、班次记录、全城播报；
- **权力**：定义“什么算事故”；
- **文化**：措辞谨慎、数字干净、少用“失败”；
- **玩法接口**：广播、档案、低报线索、结算文本。

### 2.7 港口与航运署

- **职责**：船坞、对接、货运、救援；
- **权力**：外部接触的第一道门；
- **文化**：实用、江湖气、和外部船员有非正式关系；
- **玩法接口**：救援倒计时、外部事件、走私/加餐券、撤离。

### 2.8 能源与循环署

- **职责**：太阳能采集、主环网、储能、循环站、限电；
- **权力**：决定“谁先断电”、材料回收优先级；
- **文化**：工程理性、公共所有、对“浪费”敏感；
- **冲突**：外环要保防线，中环要保生活，内环要保备份；
- **玩法接口**：能量预算、日蚀、循环额度、维修合同。

### 2.9 维修公社

- **职责**：再制造、备件共享、维修培训；
- **权力**：没有他们，循环站和塔都转不动；
- **文化**：手艺、互助、维修权；
- **冲突**：公社自治 vs 总署流程；
- **玩法接口**：维修权、再制造、社区项目。

## 三、非正式组织

| 组织 | 作用 | 风险 |
| --- | --- | --- |
| 互助会 | 轮班替班、照护家属、共享配给 | 可能被当成“非官方工会” |
| 传统派 | 保留出发地节日/语言/宗教 | 与湾民身份冲突 |
| 竞技联盟 | 零重力球、跨环联赛 | 博彩、名额交易 |
| 维修黑市 | 备件/加餐券/预约 | 事故责任模糊 |
| 事故遗属会 | 追查低报、纪念死者 | 被档案中心“安抚” |

> 这些组织不需要全部进游戏；每个都可以成为一条支线/合同/广播。

## 四、权限与责任

【参考】城市用“权限”而不是“职位”来分配行动：

```text
封舱权限
断电权限
医疗优先权
档案查阅权
外部通讯权
```

- 权限可以临时授予，也可以被收回；
- 危机时，权限冲突比敌人更致命；
- 玩家作为值班人，通常只有**部分权限**，需要呼叫/借用/越权。

### 4.1 玩法接口

- 塔防：临时征用塔位、借电、调用备件；
- 生存：封舱/断电/撤离权限；
- 沉浸：申请照护、查阅档案、向议会申诉；
- 放置：权限升级、组织声望。

## 五、冲突线

| 冲突 | 双方 | 玩法表现 |
| --- | --- | --- |
| 效率 vs 照护 | 总署 / 医疗 | 轮岗、退役、岗位空缺 |
| 流程 vs 现场 | 值班处 / 工会 | 检查单 vs 先修再说 |
| 记录 vs 真相 | 档案中心 / 遗属 | 广播数字、事故档案 |
| 城 vs 船 | 议会 / 舰队代表 | 资源分配、撤离顺序 |
| 内部 vs 外部 | 港口署 / 外环 | 救援、走私、外部接触 |

## 六、写作用法

- 写一个新角色，先问：**他属于哪个组织？他有什么权限？他缺什么？**
- 写一个新事件，先问：**谁批准？谁执行？谁记录？谁负责？**
- 写一个新玩法，先问：**它需要什么权限？权限冲突在哪里？**
