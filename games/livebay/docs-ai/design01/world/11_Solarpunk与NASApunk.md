# 11 · Solarpunk 与 NASApunk

> **一句话**：NASApunk 是逍遥湾的**骨**——白盒、检查单、可维修；Solarpunk（太阳朋克）是它的**代谢**——太阳能、循环物质、可持续的政治经济。
>
> 两者不是两套美术，而是同一座城的两层：**工程怎么修，资源怎么循环，权力怎么分配。**

## 一、人类已定方向

【人类已定 2026-11-10】

- 逍遥湾太空城**主要依赖太阳能**；
- 物质尽量**循环利用**；
- 城市重视**可持续发展与环保**；
- 配套一套**太阳朋克的政治经济理念**；
- Solarpunk 与既有 NASApunk 配合，不替换 NASApunk。

> 本文其余内容都是 **AI 参考候选**：具体机构名、比例、数值与政治细节可以改。

## 二、为什么是 Solarpunk，而不是“绿色贴纸”

逍遥湾是一座封闭的移动太空城：

- 没有无限的空气、水、金属；
- 太阳能不是“免费电”，它需要巨大的采集面、储能、散热与维护；
- 废弃物不会“消失”，只会变成下一段舱段的污染；
- 任何“环保”都必须回答：**谁维护、谁付费、谁被排除。**

所以 Solarpunk 在这里不是“到处种树、人人幸福”的乌托邦，而是：

```text
太阳能 + 循环物质 + 维修权 + 能源民主
  × 封闭空间的稀缺
  × 机构疲惫与低报
```

它和 NASApunk 的“有裂缝的善意”是兼容的：

> 城市真的在努力可持续；但可持续的代价，往往由外环和夜班承担。

## 三、能源：太阳是公共基础设施

### 3.1 主供

【人类已定】主要依赖太阳能。

【参考】能源系统：

```text
月牙凸面光伏/光热阵列
  → 外环采集/整流
  → 主环网
  → 储能（电池/热储/飞轮）
  → 舱段配电
```

- 月牙凸面朝向恒星，是天然采集面；
- 外环尖角是整流/推进阵列，也是太阳能最集中的地方；
- 中环用暖光模拟昼夜，但电力来自同一张网；
- 内环有独立备份，危机时优先级最高。

### 3.2 太阳能的限制

| 限制 | 后果 | 玩法 |
| --- | --- | --- |
| 日蚀/遮挡 | 输入骤降 | 储能/限电事件 |
| 尘埃/微陨石 | 采集面效率下降 | 清洗/维修任务 |
| 储能容量 | 夜间/峰值不够 | 电力分配 |
| 散热 | 采集越猛，废热越多 | 热管理/舱段降级 |
| 距离/航向 | 光强变化 | 长期航程压力 |

> “主要依赖太阳能”不等于“永远有电”。储能和限电才是 Solarpunk 的戏剧来源。

### 3.3 政治经济：太阳公约

【参考】Solar Commons / 太阳公约：

1. **采集面是公共资产**：不能私人拥有大型光伏/光热阵列；
2. **能量预算是公共预算**：按算法 + 议会例外分配；
3. **基本能量权**：每个湾民有最低生活用电/用氧额度；
4. **超额用能**：用贡献点/合同/紧急授权支付；
5. **外环优先保供**：因为外环是采集与防线，但外环人常最后被补偿。

冲突：

- “太阳是免费的，为什么电要算钱？”
- “基本能量权”是否包括娱乐/舒适？
- 外环采集区承担风险，却拿不到同等能量配额；
- 内环备份充足，外环却要限电。

### 3.4 可命名的候选

- **太阳公约**：能源公共所有 + 基本能量权；
- **能量预算**：每班/每舱的功率配额；
- **日蚀窗口**：采集下降的预警期；
- **储能塔**：外环的巨型储能/热储设施；
- **限电工单**：危机时强制降载的工单。

## 四、物质：闭环不是“回收桶”

【人类已定】物质尽量循环利用。

### 4.1 循环层级

```text
减量 → 再用 → 维修 → 再制造 → 材料回收 → 受控废弃
```

- **减量**：少做一次性包装、少换整机；
- **再用**：备件/舱段/工具的二次分配；
- **维修**：优先修，不是优先换；
- **再制造**：把旧模块拆成可用零件；
- **材料回收**：金属/塑料/水/空气；
- **受控废弃**：无法回收的少量残渣，封存而不是排放。

### 4.2 循环的代价

- 回收需要能源，而能源来自太阳能；
- 分类/拆解需要人力，往往压给夜班/外环；
- 稀有元素不能无限循环，必须靠外部采集/贸易；
- “环保”可能变成“穷的人用旧东西，富的人用新东西”；
- 黑市会把可回收材料偷出闭环。

### 4.3 政治经济：循环公约

【参考】

- **物质账户**：每个舱段有材料进出账；
- **循环额度**：可回收材料优先给公共项目；
- **维修权**：设备必须可拆、可修、有备件；
- **再制造公社**：维护工会/互助会运营的拆解与再制造点；
- **受控废弃**：少量残渣封存，记录在案；
- **绿色溢价**：可持续产品更贵，还是更便宜？由政治决定。

> 闭环不是“道德正确”，而是“谁承担拆解与分类的劳动”。

## 五、政治经济：可持续的分配

### 5.1 三条原则

1. **公共所有**：太阳采集面、主环网、储能、循环中心是公共基础设施；
2. **基本权利**：最低能量/水/氧/维修服务是权利，不是慈善；
3. **按代价分配**：超额用能/材料由贡献点、合同或议会例外支付。

### 5.2 与既有双轨制的关系

- 日常：算法配给 + 能量预算；
- 危机：议会接管 + 限电/封舱/征用；
- 申诉：可以，但常在算法与议会之间被踢回；
- 低报：事故数字被“绿色叙事”修饰——“系统运行正常”“已按惯例处理”。

### 5.3 政治光谱（候选）

| 派别 | 主张 | 风险 |
| --- | --- | --- |
| 循环派 | 更严格的闭环、维修权、限电 | 被批“让所有人过苦日子” |
| 增长派 | 更多采集面、更多舒适、更多外部贸易 | 被批“把风险推给外环” |
| 公社派 | 能源/循环设施由互助会/工会管理 | 被批“架空议会” |
| 传统派 | 保留出发地生活方式 | 被批“不适应封闭城市” |
| 效率派 | 算法优化、减少人为例外 | 被批“没有人负责” |

> 玩家不需要选边；玩家在值班中被迫做出这些派别之间的取舍。

## 六、视觉：NASApunk 的骨，Solarpunk 的代谢

### 6.1 配比

【参考】70% NASApunk + 30% Solarpunk：

- NASApunk：白盒、检查单、模拟 UI、机构色、磨损、编号；
- Solarpunk：太阳能玻璃、暖光、植物、循环管线、维修花园、公共空间；
- 不是“把设备涂成绿色”，而是“让能量与物质流动可见”。

### 6.2 视觉语法

| 元素 | NASApunk | Solarpunk 叠加 |
| --- | --- | --- |
| 结构 | 外露桁架/接缝 | 光伏玻璃/遮阳/绿植架 |
| 光 | 冷白/警示橙 | 暖金/柔绿/日光模拟 |
| 管线 | 折线/接头 | 水循环/营养液/热回收 |
| 表面 | 标签/磨损 | 修补痕迹/手写养护记录 |
| 空间 | 岗位/舱段 | 公共花园/维修庭院/循环站 |
| UI | 检查单/按钮 | 能量预算/循环账户/日蚀预警 |

### 6.3 禁忌

- 不要把 Solarpunk 做成“无摩擦的绿色乌托邦”；
- 不要用大面积荧光绿/全息植物；
- 不要让植物脱离维护系统（谁浇水？谁补光？）；
- 不要用“自然”掩盖劳动与不平等。

## 七、玩法接口

| 玩法 | Solarpunk 接口 |
| --- | --- |
| 塔防 | 太阳能输入/储能/日蚀限电；塔组功率 |
| 生存 | 电力/氧气/热管理；低功率夜班 |
| 放置 | 循环站/维修花园/储能升级 |
| 沉浸 | 能源预算争议、维修权、绿色溢价 |
| 扩展 | 太阳能阵列/循环中心/公社合同 |

### 7.1 低功率夜班的解释

现有「低功率夜班」可以正式解释为：

```text
日蚀窗口 + 储能不足 + 外环限电
```

- 电力不是“凭空少”，而是太阳能输入下降；
- 备用电池是储能塔的应急份额；
- 封舱减少氧气/热损失，也减少采集面；
- 救援抵达意味着外部接电/补给窗口。

> 不需要改现有玩法数值，只需要把“电”换成“太阳能的班次预算”。

## 十、一句话总结

**NASApunk 让城市能修；Solarpunk 让城市能循环。**
两者合起来，才是逍遥湾：一座靠太阳活着、靠维修撑住、靠分配决定谁先断电的城。
