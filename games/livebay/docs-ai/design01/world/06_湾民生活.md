# 06 · 湾民生活

> 用于沉浸玩法、放置养成、NPC 对话与日常叙事。**不是风俗百科**；每条都应该能变成场景、道具或选择。

## 一、湾民是谁

【人类已定】航行约 200 年，第七代；大多数居民认同“湾民”身份，地球是传说。

【参考】湾民身份的三个层次：

| 层次 | 表现 | 冲突 |
| --- | --- | --- |
| 制度身份 | 配给号、贡献点、岗位记录 | 无记录的人不存在 |
| 地方身份 | “我是外环的/中环的/内环的” | 环际偏见 |
| 记忆身份 | 家族来自哪艘船、哪道菜、哪句方言 | 传统派 vs 湾民 |

## 二、一天怎么过

【参考】中环居民按“班次”生活，不按昼夜：

```text
醒来 → 配给早餐 → 工作/学习/照护 → 娱乐/社交 → 养生舱 → 睡眠
```

- 外环值班人作息相反：别人睡时他们上班；
- 中环的“白天”是暖光模拟，夜晚降低色温；
- 广播每天固定时段播报，是全城的共同节拍。

## 三、吃什么

【参考】

- 基础配给：藻类蛋白、菌菇、豆类、合成淀粉、维生素块；
- 加餐券：换取真实口感、香料、甜点、外部船员带来的东西；
- 节日菜：保留出发地做法，但食材已本地化；
- 夜班餐：高热量、易保存、单手能吃；
- 禁忌：浪费食物是重罪；把配给券当货币是灰色地带。

### 3.1 可写的食物细节

- “第七段面”：夜班食堂的招牌，其实是藻蛋白面 + 一点真辣椒；
- 加餐券可以换“有嚼劲的东西”；
- 传统派家里会做“出发地菜”，但第二代已经不知道原味；
- 外环人喝茶/咖啡，中环人喝花草饮；
- 养生舱不允许带食物。

## 四、怎么玩

【参考】

| 娱乐 | 空间 | 玩法接口 |
| --- | --- | --- |
| 零重力球 | 娱乐舱/体育舱 | 跨环联赛、博彩、名额 |

| 虚拟场景 | 娱乐舱 | 沉浸式回忆/训练 |

> 游戏里的“音乐”可以作为湾民生活的一部分：夜班电台、传统派合唱、内环仪式音乐。

## 五、怎么说话

【参考】

- 通用语 + 环际口音；
- 外环用工程缩写/编号/手势；
- 中环更礼貌、更回避冲突；
- 内环用流程语言（“经研究”“按程序”“原则上”）；
- 传统派保留出发地方言/宗教词；
- 脏话多与设备/班次有关，而不是性/身体。

### 5.1 常用词候选

| 词 | 含义 |
| --- | --- |
| 同班 | 一起值班的人，比同事亲 |
| 接段 | 接手一个舱段/岗位 |
| 按惯例 | 不按流程、但大家都这么做 |
| 干净数字 | 低报后的事故数字 |
| 留灯 | 为死者/失踪者保留工位灯 |
| 下环 | 从外环回中环，带“活着回来”的意思 |

> 术语最终以 `../13_术语表.md` 为准；这里只给语感。

## 六、怎么纪念

【参考】

- 事故死者：名字进档案，工位留灯，低调纪念；
- 失踪者：不宣布死亡，保留配给号一段时间；
- 退休：交接仪式 + 一只旧工具/一件工服；
- 节日：出发地纪念日、建城日、救援日；
- 葬礼：物质有限，多采用集体纪念/回收仪式。

> 低报事故的死者，往往没有正式纪念；这是叙事的痛点。

## 七、家庭与照护

【参考】

- 家庭形式多样：血缘、合住、互助会、同班；
- 儿童教育在中环；外环值班人常错过家长会；
- 养生舱也承担心理辅导/职业康复；
- 老人/伤者/退役者由照护署与互助会共同支持；
- “还能上班”是残酷的健康标准。

## 八、阶层与偏见

【参考】

| 群体 | 被怎么看 | 真实处境 |
| --- | --- | --- |
| 外环人 | 粗、能扛、没文化 | 风险最高、声音最小 |
| 中环人 | 安稳、软弱、被保护 | 也不自由，只是风险被转移 |
| 内环人 | 冷漠、官僚、特权 | 承担决策，也承担甩锅 |
| 传统派 | 固执、怀旧 | 保留记忆，也被边缘化 |
| 外部船员 | 野、不可信、有钱 | 带来物资，也带来风险 |
