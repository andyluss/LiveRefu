# 08 · 技术方案

## 一、技术栈

| 层 | 选择 |
| --- | --- |
| 渲染 | Three.js r187 / 0.187.0（本地 vendor，ES module，含 three.core.js） |
| 3D | 程序化几何 + 基础材质；无外部模型 |
| 音频 | WebAudio 生成式 pad/琶音/噪声/唱针；四张唱片 |
| UI | 原生 HTML/CSS/ES modules |
| 存储 | localStorage |
| 服务 | 静态文件；无后端 |
| 测试 | Node test（会话纯逻辑） |

> 这是“新 Web 技术栈”的轻量组合：不需要构建工具即可运行，也不依赖 CDN。

## 二、结构

```text
game03/
├── index.html
├── src/
│   ├── main.js       Three.js 场景/交互/UI 绑定
│   ├── session.js    专注会话纯逻辑（可测试）
│   ├── audio.js      WebAudio 环境声
│   └── style.css
├── vendor/three.module.js
├── tests/session.test.js
└── README.md
```

## 三、运行

```bash
cd games/livebay
./run.sh game03
# http://127.0.0.1:8033/
```

静态服务器是必需的：ES module 不能稳定通过 `file://` 加载。

## 四、渲染

- PerspectiveCamera + 手写轨道相机（无 OrbitControls 依赖）；
- 房间由 Box/Sphere/Cylinder/Torus/Points 程序化搭建；
- 灯光：Hemisphere + Ambient + Directional + Point（台灯）+ 补光；
- 阴影：主光 + 台灯；限制 mapSize；
- 动画：猫尾/植物/尘埃/星球/灯光呼吸；
- 交互：Raycaster 拾取，向父级查找 `userData.interact`。

## 五、会话逻辑

- `session.js` 不碰 DOM/Three；
- 创建、开始、暂停、重置、tick、进度、格式化、记录；
- 单元测试覆盖完成/暂停/重置/记录上限；
- UI 每秒更新，不依赖帧率计时。

## 六、音频

- `audio.js` 首次用户手势后创建 AudioContext；
- pad：4 个振荡器 + lowpass + LFO；
- 噪声：雨/风/唱针；
- 低鸣：正弦；
- 音量分层；静音。
- 不自动播放，遵守浏览器策略。

## 七、存储

```text
localStorage['slow-cabin-state-v1']
  sessions / totalMinutes / plantLevel / duration / intention / audio
```

- 本地优先；
- 无账号/云同步；
- 清空浏览器数据会丢失；
- 不记录每次专注的实时状态。

## 八、风险

| 风险 | 缓解 |
| --- | --- |
| WebGL 不可用 | 提供静态说明/降级提示（待补） |
| 移动端性能 | 降低像素比/阴影/粒子 |
| 音频被浏览器阻止 | 首次手势启动，失败提示 |
| Three.js 体积 | 本地 vendor，gzip 后仍可接受 |
| 房间只是计时器皮肤 | 交互/成长/声音必须成立 |
| 无后端导致数据丢失 | 明确本地边界；未来可导出 |

## 九、Demo 范围

已实现：

- 3 层大宅、第一人称自由走动、楼梯、三种场景、物件交互；
- 1/15/25/45 分钟专注；
- 意图/暂停/重置/完成记录；
- 生成式环境声与四张生成式唱片；
- 植物/灯/夜航状态；
- localStorage。

未实现：

- 更多独立建筑/装饰商店；
- 云同步/账号；
- 完整移动端适配；
- WebGL 降级页面；
- 导出/迁移。
