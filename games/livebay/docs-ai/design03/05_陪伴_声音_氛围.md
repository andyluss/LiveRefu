# 05 · 陪伴、声音与氛围

## 一、猫

- 不提供效率、不提醒、不评价；
- 会呼吸、甩尾、偶尔看你；
- 可以摸，但不强制互动；
- 不会饿死/离家/惩罚玩家；
- 是“在场”，不是“宠物养成系统”。

## 二、植物

- 每次专注/浇水有一点成长；
- 最多 4 级（MVP）；
- 不枯萎、不死亡；
- 只作为房间记忆与视觉变化。

## 三、窗外

- 夜航城市/星点/行星；
- 可切换夜色，不改变玩法；
- 提供“远处”感，避免封闭焦虑；
- 光变化与专注阶段联动。

## 四、四张生成式唱片（MVP）

| 唱片 | 和声/节奏 | 空间 |
| --- | --- | --- |
| 夜航 | 暖 pad + 慢琶音 | 默认夜航 |
| 雨室 | 小九和弦 + 柔和琶音 | 雨港 |
| 深空 | 低音漂移 + 稀疏高音 | 看远处 |
| 晨光 | 大七和弦 + 明亮琶音 | 晨光 |

四张唱片都由 WebAudio 实时生成，不依赖音频文件；切换唱片不改变专注规则。

## 五、声音分层

| 层 | 内容 | 作用 |
| --- | --- | --- |
| 雨 | 滤波噪声 | 包裹感 |
| 风 | 低频噪声 | 空间深度 |
| 唱针 | 稀疏 crackle | 温暖/时间感 |
| 低鸣 | 55/82.5/110Hz 低频 + 泛音 + 缓慢呼吸 | 稳定情绪，笔记本扬声器也能感到 |
| 钟声 | 完成提示 | 柔和结束 |

- 生成式，不依赖外部音频文件；
- 每层可调音量；
- 首次用户手势后启动；
- 可静音；
- 不做歌词/强节奏。

## 六、声音原则

- 声音是空间，不是播放列表；
- 不抢注意力；
- 循环不产生明显接缝；
- 完成钟声不超过 2 秒；
- 不做“白噪音库”堆量。

## 七、氛围节奏

| 专注阶段 | 光 | 声 | 猫 |
| --- | --- | --- | --- |
| 到达 | 暖灯 | 低 | 在 |
| 安定 | 稳定 | 渐入 | 呼吸 |
| 深入 | 稍暗/窗光 | 稳定 | 睡/蜷 |
| 回来 | 变暖 | 钟声 | 抬头 |
