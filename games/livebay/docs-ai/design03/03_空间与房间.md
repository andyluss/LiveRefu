# 03 · 空间与房间

## 一、空间原则

- **一间房**，不是开放世界；
- 俯视/斜视 3D，可环绕、缩放，但不能自由飞行；
- 每个物件都有“功能 + 情绪”；
- 空间是安静的，不是信息密集的。

## 二、房间分区

```text
            舷窗 / 夜航城市
                  |
  书架 —— 书桌（工作区） —— 唱机
                  |
        地毯（休息区）—— 猫
                  |
              植物 / 角落
```

| 区域 | 物件 | 功能 | 情绪 |
| --- | --- | --- | --- |
| 工作区 | 书桌、笔记本、台灯、茶杯 | 开始专注 | 聚焦、温暖 |
| 窗 | 舷窗、星球、星点 | 看远处/换夜 | 开阔、安静 |
| 休息区 | 地毯、椅子、猫 | 坐下/休息 | 被陪伴 |
| 角落 | 植物、书架 | 房间成长 | 生命力 |
| 声音 | 唱机 | 环境声控制 | 氛围 |

## 三、场景变体（MVP）

| 场景 | 光/窗 | 房间变化 | 用途 |
| --- | --- | --- | --- |
| 夜航 | 暖灯 + 冷窗光 | 书架、猫、基础植物 | 默认，城市夜航 |
| 雨港 | 低窗光、青绿 | 更多植物、舷窗雨点 | 包裹感、低刺激 |
| 晨光 | 暖橙窗光 | 桌面唱片、墙上暖弧 | 收尾/开始一天 |

场景不改变专注规则，只改变空间情绪；可以随时切换。

## 四、相机

- 初始视角：可看到桌面、窗、猫、植物；
- 拖动环绕，滚轮/双指缩放；
- 限制角度，避免穿墙/眩晕；
- 点击物件打开小卡，不切场景；
- 不做第一人称/自由行走（MVP）。

## 五、交互物件（MVP）

| 物件 | 动作 | 反馈 |
| --- | --- | --- |
| 台灯 | 开关 | 光/热变化 |
| 植物 | 浇水 | 长大一点 |
| 猫 | 摸一摸 | 尾巴/呼噜 |
| 舷窗 | 换夜 | 窗外色调/星点 |
| 唱机 | 开关声音 | 环境声 |
| 茶杯 | 放下 | 小文本 |
| 椅子 | 坐下 | 小文本 |
| 笔记本 | 开始专注 | 计时开始 |

> 交互不是解谜；是“摸一摸这个空间”。

## 六、空间与专注

- 开始时：镜头轻微推近桌面，灯光聚焦；
- 专注中：环境动态变慢，窗光微弱变化；
- 回来时：镜头轻微拉远，灯变暖；
- 不使用全屏遮罩；UI 可隐藏。

## 七、性能

- 低多边形、程序化几何；
- 无外部贴图依赖；
- 阴影只给主光/台灯；
- 移动端降低像素比/粒子；
- 静止时仍渲染（呼吸/尘埃），但低功耗。

## 八、待裁决

1. 视角是斜视/俯视，还是第一人称？建议斜视。
2. 是否允许多房间？MVP 不做。
3. 是否做自由走动？不做。
4. 是否做窗外可探索？不做。
