# 09 · 范围、风险与决策

## 一、MVP（已实现）

| 项 | 内容 |
| --- | --- |
| 空间 | 1 间 3D 书房，3 种场景状态（夜航/雨港/晨光） |
| 相机 | 环绕/缩放 |
| 专注 | 1/15/25/45 分钟；暂停/重置/完成 |
| 意图 | 一句；可留空 |
| 声音 | 雨/风/唱针/低鸣/旋律；4 张生成式唱片；可静音 |
| 互动 | 台灯/植物/猫/窗/唱机/杯/椅/笔记本 |
| 成长 | 植物等级、总分钟、最近记录 |
| 存储 | localStorage |
| 测试 | 7 项会话逻辑 |

## 二、正式版候选

- 装饰/房间主题；
- 更多窗外场景；
- 唱片/声音包；
- 猫的更多动作/命名；
- 导出/导入；
- 可选的买断/支持者包；
- 移动端专门适配。

## 三、不做

- 战斗/塔防/生存；
- 任务管理/待办；
- 排行榜/连续打卡；
- 抽卡/限时 FOMO；
- 多房间/开放世界（MVP）；
- 必须联网/账号；
- 社交/多人。

## 四、风险

| 风险 | 概率 | 影响 | 缓解 |
| --- | --- | --- | --- |
| 只是计时器皮肤 | 中 | 高 | 房间互动/声音/成长必须成立 |
| 3D 性能/移动端 | 中 | 中 | 降级/低像素比 |
| 声音版权/生成质量 | 中 | 中 | 生成式/授权 |
| 内容成本 | 高 | 中 | 先 1 房间，不堆量 |
| 商业化压力导致 FOMO | 中 | 高 | 买断/支持者包优先 |
| 玩家不需要“房间” | 中 | 高 | 真人测试：是否愿意停留 |

## 五、验证指标

- 首次开始时间（<1 分钟）；
- 专注中 UI 交互次数（越低越好）；
- 完成/中断后的回来率；
- 房间互动次数；
- 声音使用/静音比例；
- 是否愿意装饰/再来；
- 浏览器性能（FPS/内存）。

## 六、待裁决

1. 默认 25 分钟还是 15 分钟？
2. 1 分钟试玩是否保留在正式版？
3. 是否做装饰商店/买断？
4. 是否做多房间？
5. 是否做猫的命名/更多动作？
6. 是否支持用户导入音乐？
7. 是否做账号/云同步？
8. 是否做移动端优先？

## 七、下一步

1. 真人试玩 Demo，观察“是否愿意停留”；
2. 补 WebGL 降级/移动端；
3. 增加 2–3 个装饰/窗外场景；
4. 决定商业化；
5. 再谈完整版。
