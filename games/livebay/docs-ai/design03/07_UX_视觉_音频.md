# 07 · UX、视觉与音频

## 一、视觉方向

- NASApunk 的“可维修白盒” + Solarpunk 的“暖光/植物/循环”；
- 暖木、黄铜、奶油纸、深墨绿；
- 低多边形/简化几何，不追求写实；
- 灯光是主角：台灯、窗光、唱机指示灯；
- 所有物件有标签/手写痕迹，但不过度信息。

## 二、屏幕布局

```text
┌─────────────────────────────────────┐
│ 品牌 / 夜航 / 会话状态     声音 帮助 │
│                                     │
│ 意图卡 / 时长 / 计时      3D 房间     │
│                                     │
│ 房间状态 / 记录            环境声混音 │
│                                     │
│ 键盘提示 / 小文本                    │
└─────────────────────────────────────┘
```

- 3D 房间是主角，UI 是玻璃浮层；
- 左侧：意图/时长/计时；
- 右侧：声音/房间状态/记录；
- 底部：轻提示；
- 菜单/欢迎覆盖层只在进入/帮助时出现。

## 三、界面原则

- 低摩擦：进入后 1 分钟内能开始；
- 低压力：不用红色警报、不用“失败”；
- 低干扰：专注中可隐藏 UI；
- 可读：数字/标签在玻璃上也清楚；
- 可退：声音可关、UI 可隐、数据本地。

## 四、交互

- 第一人称：WASD 走动、鼠标环顾、Esc 释放鼠标；
- 楼梯连接楼层；E 互动；
- 悬停显示名字；
- 键盘快捷键（Space/R/M/1–4/H）；
- 触屏支持单指旋转、双指缩放（Demo 基础）。

## 五、可访问性

- 减少动画（prefers-reduced-motion）；
- 键盘可达；
- 文本对比度；
- 声音可静音、可调；
- 不只靠颜色表达状态；
- 不自动播放声音；
- 不使用闪烁/高频警报。

## 六、音频

- 生成式 pad/噪声/唱针；
- 首次手势后启动；
- 每层独立音量；
- 完成钟声柔和；
- 不做突然响度变化；
- 可静音并记住设置。

## 七、性能

- 低多边形、无外部贴图；
- 阴影限制；
- 像素比上限 2；
- 移动端降低粒子/阴影；
- 静态场景仍保持低耗。

## 八、待裁决

1. 画风是低多边形还是手绘贴图？
2. UI 是否可完全隐藏？
3. 是否支持手柄？
4. 是否做移动端优先？
5. 是否做主题（白天/夜晚）？
