# 02 · 核心循环

## 一、三层循环

```text
一次专注：进入 → 写意图 → 选时长 → 专注 → 回来 → 记录
  ↓
一晚：1–3 次专注 + 休息 + 房间变化
  ↓
长期：房间/植物/唱片/记录慢慢积累，不逼上线
```

## 二、一次专注（15–45 分钟）

| 阶段 | 玩家 | 房间 | 时间 |
| --- | --- | --- | --- |
| 到达 | 进入房间、环顾 | 灯亮、猫在、窗外夜航 | 0–1 min |
| 安放 | 写下意图、选时长 | 桌面聚焦、环境声渐入 | 1–2 min |
| 专注 | 做事/休息/看窗外 | 光/声/猫保持陪伴 | 15–45 min |
| 回来 | 计时结束、环顾 | 灯变暖、植物一点变化 | 0–2 min |
| 记录 | 看今晚记录 | 房间留下痕迹 | 0–1 min |

## 三、核心动作

- 写一句意图（可留空）；
- 选时长（1/15/25/45，1 分钟为试玩）；
- 开始 / 暂停 / 重置；
- 点灯、浇水、摸猫、换夜、开唱机；
- 结束看记录。

> 没有“失败按钮”。暂停不是失败，离开也不是。

## 四、节奏

- 不靠通知打断；
- 计时结束用柔和钟声，不用警报；
- 可以关闭声音/隐藏 UI；
- 专注中房间动态很轻：灯微亮、猫呼吸、尘埃缓慢移动；
- 完成后房间变化要小，不做烟花。

## 五、奖励

| 行为 | 反馈 |
| --- | --- |
| 完成一次专注 | 记录 + 植物一点成长 |
| 累计分钟 | 只显示数字，不做排行榜 |
| 触摸/浇水 | 即时柔和反馈 |
| 回来 | 房间保持上次状态 |

> 奖励是“空间记得你”，不是“你赢了”。

## 六、无失败设计

| 情况 | 结果 |
| --- | --- |
| 中途暂停 | 保留进度，继续 |
| 离开/关网页 | 本地保留会话设置，不惩罚 |
| 只坐了 1 分钟 | 也算一次记录 |
| 忘记回来 | 房间还在，不产生负债 |
| 走神 | 没有检测/指责 |

## 七、验证

- 玩家是否在 1 分钟内开始？
- 专注中是否减少看计时器？
- 完成后是否感到“被陪伴”而不是“被评分”？
- 中断后是否愿意回来？
- 房间变化是否让人想继续装饰？
