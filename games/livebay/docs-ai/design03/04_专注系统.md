# 04 · 专注系统

## 一、目标

让“开始”变得容易，让“坐住”不需要意志力对抗，让“回来”没有羞耻。

## 二、意图

- 一句话，可留空；
- 建议标签：读完一章 / 写 500 字 / 整理一角 / 坐一会儿；
- 不进入待办系统；不设截止；
- 完成后不强制勾选；只记录。

## 三、时长

| 时长 | 用途 |
| --- | --- |
| 1 分钟 | 试玩/演示 |
| 15 分钟 | 低门槛开始 |
| 25 分钟 | 标准专注 |
| 45 分钟 | 深度工作 |

- 可暂停；
- 可重置；
- 完成后自动记录；
- 不强制休息，但结束时提示“慢慢回来”。

## 四、计时状态

```text
未开始 → 进行中 → 暂停 → 进行中 → 完成
                ↘ 重置
```

- 没有失败状态；
- 关闭页面不扣分；
- 不记录“中断次数”用于惩罚；
- 记录只保留完成/暂停的会话；
- 计时使用绝对截止时间，切换标签页/窗口失焦不会暂停；回到页面时按墙钟补算。

## 五、完成反馈

- 柔和钟声（可静音）；
- 灯变暖、植物一点变化；
- 显示本次分钟/意图；
- 记录到“最近专注”；
- 不播放烟花、不弹成就。

## 六、专注中的 UI

- 计时器可显示在房间边缘，不遮挡桌面；
- 可隐藏全部 UI（沉浸模式）；
- 不显示倒计时秒级跳动（显示分:秒，但低频更新）；
- 不弹通知；
- 不检测走神/切窗。

## 七、无惩罚

| 行为 | 处理 |
| --- | --- |
| 中途暂停 | 保留剩余时间 |
| 中途离开 | 本地保存设置，不下次羞辱 |
| 只做 1 分钟 | 记录 1 分钟 |
| 忘记回来 | 房间仍在，无欠债 |
| 关闭声音 | 不提示“你错过了” |

## 八、待裁决

1. 默认 25 还是 15 分钟？
2. 是否允许自定义时长？
3. 完成是否强制记录？
4. 是否做“休息计时”？
5. 是否记录中断次数（不展示）？
