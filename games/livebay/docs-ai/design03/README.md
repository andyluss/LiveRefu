# LiveBay 沉浸专注游戏策划 · design03

> **工作名**：《湾居 · 夜航书房》 / *Slow Cabin*
>
> **一句话**：一间会呼吸的 3D 太空书房。写下今晚只做的一件小事，点一盏灯，和猫一起坐一会儿；房间会记得你坐过的每一小会儿。
>
> **状态**：参考草案；3D Web Demo 已在 `game03/` 可运行；完整版未开发。

## 一、这是什么

一个独立的**专注/放松体验**，不是塔防，也不是任务管理工具：

- 没有敌人、波次、战斗；
- 没有失败、排行榜、连续打卡惩罚；
- 没有必须完成的目标；
- 只有一个房间、一段时间、一点点声音，以及你今晚想做的事。

它参考 Spirit City: Lofi Sessions 的**品类位置**（3D 房间 + 专注计时 + 环境声 + 陪伴 + 房间成长），但不复制其角色、房间、内容与世界观。

## 二、设计支柱

| # | 支柱 | 含义 |
| --- | --- | --- |
| 1 | **专注是一个地方** | 不是倒计时工具，是一个可以进入、环顾、坐下的空间 |
| 2 | **没有失败** | 暂停、离开、走神都不是失败；回来就好 |
| 3 | **房间记得你** | 植物、唱片、灯、猫与记录，慢慢留下痕迹 |
| 4 | **声音是建筑** | 雨/风/唱针/低鸣不是背景，是空间的一部分 |
| 5 | **小仪式，不逼人** | 选意图、点灯、开始；不制造焦虑与 FOMO |

## 三、目标体验

| 体验 | 玩家应该感到 | 设计手段 |
| --- | --- | --- |
| **进入** | 从忙乱切换到“这里可以慢” | 开门、灯光、环境声、镜头 |
| **安放** | 一件事被放在桌面上 | 意图输入、时长选择、房间聚焦 |
| **陪伴** | 不是一个人硬撑 | 猫、植物、窗外城市、唱机 |
| **完成** | 不是“打卡成功”，是“坐了一会儿” | 无失败、柔和结算、房间变化 |
| **回来** | 房间还在，不需要重新开始 | 本地保存、轻记录、无惩罚 |

## 五、与 design01/02 的关系

| 项 | design01 | design02 | design03 |
| --- | --- | --- | --- |
| 类型 | 塔防 | 舱段生存 | 3D 专注/放松 |
| 失败 | 漏过 | 死亡/失联 | 无失败 |
| 空间 | 弧形路径 | 房间图 | 一间 3D 房间 |
| 核心资源 | 供能/保障度 | 氧/电/压力 | 注意力/时间（软性） |
| 敌人 | 波次 | 环境故障 | 无 |
| 成长 | 职业/合同 | 知识/程序 | 房间/植物/装饰 |
| 实现 | Godot `game/` | Godot `game02/` | Web `game03/` |

> 共享的是“NASApunk + Solarpunk”的视觉伦理与“慢好”态度，不共享玩法循环。

## 六、Demo

- 代码：[`../../game03/`](../../game03/README.md)
- 运行：

```bash
cd games/livebay
./run.sh game03
# 打开 http://127.0.0.1:8033/
```

- 技术：Three.js（本地 vendor）+ WebAudio + localStorage，无后端。
- 已有：3D 房间、台灯/植物/猫/窗/唱机/杯/椅/笔记本交互、专注计时、环境声、房间成长、记录。
- 未做：完整装饰系统、更多房间、账号/云同步、移动端专门适配、付费内容。

## 七、边界

- 这是参考策划与 Demo，不是最终产品；
- 不代表 LiveBay 主项目转向；
- 不复制 Spirit City 的角色/内容/美术；
- 所有数值与内容是原型量级，不是平衡/商业定案。
