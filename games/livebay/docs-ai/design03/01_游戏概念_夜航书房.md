# 01 · 游戏概念：夜航书房

> **工作名**：《湾居 · 夜航书房》 / *Slow Cabin*
>
> **高概念**：一栋漂在夜航城市上方的三层 3D 大宅。你写下今晚只做的一件小事，选一段时间，点灯，坐下。房间会慢慢记住你。

## 一、一句话

> 不是“帮你专注”的工具，而是一间**愿意陪你专注的房间**。

## 二、目标体验

- 进入房间的 30 秒内，身体先松下来；
- 专注时不需要一直看计时器；
- 结束后不觉得自己“打卡失败”；
- 下一次回来，房间有一点变化，但不需要重新开始。

## 三、设计支柱

1. **专注是一个地方**：房间、窗、灯、椅、猫，比进度条更重要；
2. **没有失败**：暂停、离开、走神都不是失败；
3. **房间记得你**：植物、唱片、灯、猫、记录；
4. **声音是建筑**：雨/风/唱针/低鸣随房间变化；
5. **小仪式，不逼人**：点灯、写意图、开始；没有每日惩罚。

## 四、非目标

【不做】

- 不做战斗、塔防、波次、敌人；
- 不做任务管理/待办清单/项目管理；
- 不做排行榜、连续打卡、社交压力；
- 不做抽卡/内购驱动的装饰；
- 不做开放世界/更多独立建筑（MVP）；
- 不做必须联网/账号；
- 不做恐怖/强叙事/过场动画。

## 五、目标玩家

| 玩家 | 为什么来 | 需要什么 |
| --- | --- | --- |
| 学生/远程工作者 | 需要开始、坐住 | 低摩擦进入、计时、无压力 |
| 焦虑/注意力困难 | 害怕开始与失败 | 无失败、可暂停、短时长 |
| Lofi/氛围爱好者 | 喜欢房间/声音/陪伴 | 可探索的空间、声音混合 |
| 装饰/收集玩家 | 喜欢房间变化 | 轻成长、非抽卡 |

## 六、差异化

| 常见专注工具 | 本作 |
| --- | --- |
| 计时器 + 白噪音 | 可进入的 3D 房间 + 环境声 |
| 打卡/连续天数 | 房间记忆，无惩罚 |
| 任务清单 | 一条意图，不压迫 |
| 游戏化奖励 | 装饰/植物/唱片，非数值 |
| 社交/排行榜 | 单人、本地、可退出 |

## 七、成功标准

- 玩家能在一分钟内开始；
- 专注中不会频繁看计时器；
- 完成后愿意再回来；
- 失败/中断后不产生羞耻；
- 房间让人想停留，而不只是“完成任务”。

## 八、停止条件

- 变成任务管理工具；
- 需要靠提醒/惩罚留住玩家；
- 3D 房间只是计时器皮肤；
- 声音/装饰成本超过体验价值；
- 玩家只关心“打卡”，不关心房间。
