# 07 · 叙事、角色与结局

## 一、叙事原则

- **环境叙事优先**：房间、门、日志、血迹、未关的灯，比大段对话有效；
- **广播不可靠**：城市说“正常”，舱段在失压；
- **不解释全部**：低报事故只埋线索，不揭开；
- **玩家的记录是叙事的一部分**：结算不是旁白，是玩家写的班后记录。

## 二、主角

【方向】无名值班人，外环第七段夜班。

- 不写脸/性别/过去；
- 有岗位身份、权限、工具箱；
- 通过动作/记录塑造性格，不通过台词；
- 玩家不是“天选者”，是“最后一个还在段里的人”。

## 三、NPC（第一版 1–2 人）

### 3.1 NPC A：巡检员「岚」

- 位置：居住舱/医疗舱；
- 状态：腿伤/缺氧；
- 技能：知道一条管线捷径；
- 选择：救她需要时间/O2；不救会少一条捷径与证词。

### 3.2 NPC B：通讯员「周」

- 位置：主控室/对接臂；
- 状态：恐慌/轻度伤；
- 技能：能改写广播/呼叫救援；
- 选择：带他走会拖慢；留下他可能帮你争取窗口，也可能死。

> NPC 不是“队友战斗单位”；是**资源/知识/道德选择**。

## 四、广播

广播是城市的声音，也是压力：

| 类型 | 内容 | 作用 |
| --- | --- | --- |
| 官方 | “局部异常，已按惯例处理” | 与舱内现实反差 |
| 救援 | “窗口 18:40，请保持对接臂可用” | 目标/倒计时 |
| 家属/私人 | 点名呼叫某人 | 情感/选择 |
| 错误 | 过时地图/错误门号 | 信息不可靠 |
| 低报 | “外环事故 0 起” | 主题 |

> 广播文本要短、可听、可错过；重要信息要有字幕/重复。

## 五、日志与证据

- 班前检查单：上一班留下“已按惯例处理”；
- 维修日志：被划掉/补记的条目；
- 私人终端：未发送的消息；
- 事故记录：数字对不上；
- 这些不是收集品，是**判断依据**：能改变你对门/人/救援的决策。

## 六、四种结局

| 结局 | 条件 | 情绪 |
| --- | --- | --- |
| **救援** | 撑到救援，对接臂可用 | 活下来，但城市可能低报 |
| **撤离** | 主动离开，放弃未完成 | 合法、苦涩 |
| **留下** | 救援走了，继续修/救人 | 高风险、可能死 |
| **沉默** | 救援错过/通讯断，无法记录 | 最暗，留下线索 |

### 6.1 结算不是分数

结算显示：

- 救了几人/放弃几段；
- 记录是否真实；
- 城市是否知道；
- 下一局解锁的程序/记忆；
- 一句“班后记录”，由玩家选择。

> 不做“S/A/B”评级；做“这一班留下了什么”。

## 七、低报主题

玩家在结算时可以：

- **如实记录**：可能被追责/影响城市；
- **低报**：符合惯例，保住班次，但掩盖真相；
- **沉默**：不写，或写“无异常”；
- **带走证据**：交给谁？可能开启后续。

> 不是善恶选择；是“你要不要成为系统的一部分”。

## 八、叙事节奏

- 0–3 min：广播/环境，建立“这里刚发生过什么”；
- 3–10 min：日志/NPC，建立“谁被留下”；
- 10–18 min：广播/救援，建立“外面怎么看你”；
- 18–20 min：记录，建立“你留下什么”。

## 九、写作禁忌

- 不写大段解释世界观的独白；
- 不写“玩家拯救世界”；
- 不写纯恶反派；
- 不写 jump scare 代替系统压力；
- 不写与生存选择无关的收集品。

## 十、待裁决

1. 主角是否有名字/背景？
2. NPC 做 1 个还是 2 个？
3. 低报是否影响后续场景？
4. 结局是否做“沉默”隐藏线？
5. 广播是否可被玩家改写？
6. 是否保留“证据”跨局？
