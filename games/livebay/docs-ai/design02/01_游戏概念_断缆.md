# 01 · 游戏概念：断缆

> 工作名：《逍遥湾：断缆》 / *LiveBay: Severed*
>
> 高概念：外环一段舱壁被碎片切断。你是夜班值班人，带着一套不够用的工具，在 20 分钟里决定：先封哪道门、先修哪条线、先救哪个人，以及要不要在救援到来前撤出去。

## 一、一句话与三句话

**一句话**：

> 一场没有敌人的舱段生存：用氧气、电力、压力和时间，和一座正在坏掉的城抢人。

**三句话**：

1. 你不是指挥官，是值班人；没有武器，只有工具、权限和判断。
2. 舱段是一个会漏、会烧、会失压、会断电的系统；每个门和管线都连着别处。
3. 救援会来，但不一定来得及；撤离是合法结局，留下记录也是。

## 二、目标体验

| 体验 | 玩家应该感到 | 设计手段 |
| --- | --- | --- |
| **紧** | 时间/氧气在减少，不能全做 | 救援窗口、消耗、不可逆封舱 |
| **懂** | 知道“为什么失败” | 可见的管线/门/压力、日志、回放 |
| **疼** | 放弃某段/某人是有代价的 | 资源/空间/NPC 的不可兼得 |
| **静** | 没有战斗的噪音，压力来自环境 | 声音、呼吸、金属、广播 |
| **留** | 失败也留下知识/记录 | 程序解锁、地图记忆、报告 |

### 2.1 情绪曲线

```text
到达（不安）
  → 评估（信息不足）
  → 第一次封舱/断电（代价）
  → 故障链（失控）
  → 救援窗口（选择）
  → 撤离/留下（结算）
  → 班后记录（余味）
```

## 三、设计支柱

### 3.1 生存是维护，不是战斗

- 没有敌人、没有波次、没有塔；
- 威胁是压力差、氧气、火、电、结构、污染；
- 玩家的“攻击”是扳手、封舱、旁路、灭火器；
- 胜利不是“杀光”，是“让系统撑到救援/撤离”。

### 3.2 每个选择都有空间与时间代价

- 封舱：止漏，但可能把人关在外面；
- 断电：灭火，但停氧循环/门；
- 救人：消耗氧气/时间，可能错过救援；
- 修 A 段：B 段继续坏。

### 3.3 失败留下知识，不留数值惩罚

- 死亡/撤退不扣等级；
- 解锁的是程序、地图记忆、工具使用经验、城市记录；
- 下一局更强的是“你知道先看什么”，不是“攻击力 +10%”。

### 3.4 撤离是合法结局

- 撤离不是坏结局；
- 留下来完成关键修复/救人，是更高风险的选择；
- 结算按“救了多少、记录是否真实、城市是否知道”评价，不按击杀。

## 四、非目标

【不做】

- 不做塔防、波次、塔位、敌人；
- 不做射击/近战/战斗；
- 不做开放世界/自由建造；
- 不做多人联机；
- 不做随机生成的大地图；
- 不做长期数值养成/装备刷取；
- 不做“生存 crafting 沙盒”；
- 不做恐怖 jump scare 为主。

> 这些不是永远不能做，而是第一版不做。每加一个，都会稀释“舱段生存”的焦点。

## 五、目标玩家

| 玩家 | 为什么来 | 需要什么 |
| --- | --- | --- |
| 系统/管理游戏玩家 | 喜欢资源耦合、取舍、复盘 | 可读的系统、失败归因 |
| 叙事/世界爱好者 | 喜欢机构疲惫、低报、夜班 | 环境叙事、记录、结局 |
| 生存游戏玩家 | 喜欢压力、资源、空间 | 真实但可读的生存规则 |
| 短会话玩家 | 15–25 分钟一局 | 快速进入、明确目标、可暂停 |

## 六、差异化

| 常见生存游戏 | 本作 |
| --- | --- |
| 打怪/建基地/造装备 | 修舱/封门/分配电/救人 |
| 地图越大越好 | 一张舱段，房间少但关系深 |
| 数值成长驱动 | 知识/程序/记录驱动 |
| 死亡重来 | 失败留下知识，撤离合法 |
| 恐怖/战斗为主 | 系统/环境为主，安静但紧 |

## 七、成功标准（参考）

- 玩家能在 10 分钟内说出“我为什么死/为什么撤”；
- 一局至少出现 3 次“不能全做”的选择；
- 失败后愿意再试，因为知道下次先看什么；
- 没有战斗，仍然有压力；
- 撤离/留下都能产生可讲述的故事。

## 八、停止条件

如果出现以下情况，应暂停/缩小：

- 生存压力主要来自“看不见的数值”，而不是空间/资源；
- 玩家死亡后说不出原因；
- 没有战斗就没有紧张感；
- 内容成本超过 1 张场景的可控范围；
- 需要靠大量随机事件才能撑时长。

## 九、一句话总结

> **不是“在太空里打怪”，而是“在太空里把一扇门、一条线、一个人，撑到下一班”。**
