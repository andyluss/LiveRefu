# 04 · 生存系统

> 生存不是“多几条蓝条”，而是**几个资源互相转换、互相拖累**。本文定义第一版的系统边界。

## 一、资源总表

### 1.1 主资源（必须做）

| 资源 | 载体 | 消耗/恢复 | 失败 |
| --- | --- | --- | --- |
| **氧气** | 房间 + 玩家 suit | 呼吸/泄漏/循环 | 窒息 |
| **电力** | 舱段电池/主网 | 门/灯/循环/工具 | 断电、门失效 |
| **压力** | 房间 | 破口/开门/补压 | 失压、爆炸、无法通行 |
| **温度** | 房间 | 加热/散热/火灾 | 失温/烧伤 |
| **污染** | 房间/水/空气 | 泄漏/烟/循环 | 中毒/感染 |

### 1.2 次资源（第一版可简化）

| 资源 | 作用 | 第一版处理 |
| --- | --- | --- |
| 水 | 冷却/饮用/卫生 | 只做“循环站”状态，不做个人口渴 |
| 备件 | 修门/泵/工具 | 物品，不做全局数量 |
| 药品 | 伤/感染 | 物品，不做长期疾病 |
| 电池 | 临时供电 | 物品/房间 |
| 封条 | 封门/补漏 | 物品 |

## 二、玩家状态

| 状态 | 来源 | 后果 | 恢复 |
| --- | --- | --- | --- |
| 缺氧 | suit O2 低/房间低 | 视野变窄、动作变慢、死亡 | 换罐/富氧舱 |
| 失温 | 低温房间/湿衣 | 手抖、动作慢、死亡 | 保暖/热源 |
| 烧伤 | 火/火花/蒸汽 | 持续伤、动作慢 | 医疗 |
| 失压伤 | 快速失压 | 伤/昏迷 | 医疗/加压 |
| 疲劳 | 时间/负重 | 动作变慢、失误 | 休息（很少） |
| 压力/恐慌 | 事故/NPC 死亡 | 判断力下降（UI 抖动/提示延迟） | 呼吸/同伴/安全屋 |
| 感染 | 污染/伤口 | 持续恶化 | 药品/医疗舱 |

> 第一版只做 4 个：缺氧、失温、烧伤、疲劳；恐慌作为叙事/UI 层，不做复杂数值。

## 三、房间模拟

每个房间每 tick 计算：

```text
O2:  + 循环供氧 - 人员呼吸 - 泄漏
P:   + 补压 - 泄漏 - 开门/破口
T:   + 加热 - 散热 - 火灾/开门
E:   + 电池/主网 - 门/灯/循环/工具
C:   + 污染源 - 过滤/通风
```

### 3.1 关键规则

- 氧气/压力/温度不是“全舱一个数”，而是**逐房间**；
- 门是房间之间的阀门；开门会交换气体/压力/温度/污染；
- 断电会停循环/门/灯，但不会立刻让氧气归零；
- 封舱能止漏，但会把人和资源关在里面/外面；
- 火需要氧气，通风可能助燃，也可能排烟。

### 3.2 数值量级（占位）

| 项 | 量级 |
| --- | --- |
| 单间氧气 | 3–8 分钟 |
| suit O2 | 6–10 分钟 |
| 电池 | 5–10 分钟关键负载 |
| 补压 | 10–20 秒/次 |
| 封门 | 8–20 秒 |
| 焊接 | 15–40 秒 |
| 救援窗口 | 18–22 分钟 |

## 四、故障链

### 4.1 五类故障

| 故障 | 表现 | 传播 |
| --- | --- | --- |
| **泄漏** | 嘶声/霜/压力下降 | 沿管线/门缝 |
| **火灾** | 烟/热/跳闸 | 沿可燃物/通风 |
| **电气** | 火花/跳闸/门失效 | 沿电缆/配电 |
| **结构** | 变形/碎片/门卡死 | 沿舱段 |
| **污染** | 雾/水/毒 | 沿水/空气 |

### 4.2 级联示例

```text
碎片击穿 → 失压
  → 门自动关闭 → 有人被困
  → 断电 → 循环停 → O2 下降
  → 玩家封舱 → 压力保住，但被困者 O2 不够
```

> 故障链不是脚本，是系统状态的结果；玩家要能追溯“哪一步导致的”。

## 五、动作与代价

| 动作 | 时间 | 资源 | 改变 | 风险 |
| --- | --- | --- | --- | --- |
| 封门 | 8–20s | 封条/电 | 阻断压力/火/污染 | 困人/断通路 |
| 开门 | 2s | 电 | 通行/交换 | 失压/助燃 |
| 断电 | 3s | 无 | 停负载 | 停氧/门/灯 |
| 复电 | 5s | 电 | 恢复 | 过载/火花 |
| 焊接 | 15–40s | 焊条/电 | 补漏/结构 | 火花/复漏 |
| 补压 | 10–20s | 气/电 | 压力恢复 | 泄漏未修则白费 |
| 通风 | 10s | 电 | 排烟/换气 | 助燃/污染扩散 |
| 灭火 | 8–20s | 灭火剂/O2 | 灭火 | 复燃/缺氧 |
| 搜救 | 20–60s | 时间/O2 | 救人/物资 | 被拖慢 |
| 医疗 | 10–30s | 药 | 稳定伤情 | 感染/依赖 |

## 六、资源转换

```text
电 → 门/灯/循环/工具
气 → 压力/氧气
水 → 冷却/过滤/饮用
备件 → 修复/替换
时间 → 一切
```

**没有免费资源**：每个恢复动作都消耗另一种资源或时间。

## 七、可读性

- 每个房间有 3 个“体感信号”：声音、光、温度/雾；
- 关键数字只在检查器/面板出现；
- 玩家不需要读 5 个条，但需要能回答“这间还能待多久”；
- 颜色只做状态提示，文字/图标兜底。

## 八、失败条件

| 失败 | 触发 | 前兆 |
| --- | --- | --- |
| 窒息 | suit/房间 O2 归零 | 呼吸声、视野变窄、警告 |
| 失压 | 压力过低/快速失压 | 风声、门变形、耳鸣 |
| 失温 | 体温过低 | 手抖、画面冷色、动作慢 |
| 烧伤/伤重 | 火/爆炸/结构 | 火花、烟、疼痛音 |
| 被困 | 门锁死/救援错过 | 广播倒计时、门无电 |
| 死亡 | 以上任何一项到终点 | 不是瞬间，有 5–10s 前兆 |
