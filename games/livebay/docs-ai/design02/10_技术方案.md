# 10 · 技术方案

> 本文只证明“能做”，不进入现有 `game/` 工程；如果未来立项，应作为独立 Godot 项目。

## 一、引擎与形态

| 项 | 建议 |
| --- | --- |
| 引擎 | Godot 4.7 |
| 渲染 | 2D（等距/侧视），GL Compatibility |
| 语言 | GDScript |
| 数据 | JSON（房间/事件/物品/场景） |
| 平台 | PC 优先 |
| 单局 | 15–25 分钟，可暂停 |
| 存档 | 班次内自动；班次结束写记录 |

## 二、架构

```text
SurvivalApp
├── SectionScene      2D 房间/角色/门/特效
├── SectionRuntime    固定步长模拟
│   ├── RoomGraph
│   ├── ResourceModel
│   ├── HazardModel
│   ├── DoorModel
│   └── EventDirector
├── PlayerController  移动/交互/工具
├── ReadModel         HUD/地图/检查器
├── AudioDirector
└── Save/Record
```

### 2.1 与塔防工程的关系

- 可借鉴：输入、音频、主题、存档、测试方法；
- 不复用：塔防 Sim、波次、塔位、HUD、GamePage；
- 独立项目，避免把生存硬塞进塔防架构。

## 三、房间图

```json
{
  "id": "bay01_severed",
  "rooms": [
    {"id": "corridor", "pressure": 1.0, "oxygen": 1.0, "temp": 0.7, "power": true, "doors": ["med", "control", "power"]}
  ],
  "doors": [
    {"id": "d_med", "a": "corridor", "b": "med", "state": "open", "sealable": true}
  ]
}
```

- 房间图是图结构，不是网格；
- 门/管线是边；
- 事件按条件触发；
- 所有状态可序列化，便于存档/测试。

## 四、模拟

固定步长（如 10 Hz）：

```text
for room in rooms:
  oxygen += supply - drain - leak
  pressure += fill - leak - door_exchange
  temp += heat - cool - exchange
  power = source - load
  contamination += source - filter
```

- 资源守恒/近似守恒；
- 门交换按压差；
- 火需要氧气/燃料；
- 事件只改状态，不直接播动画。

## 五、数据驱动

| 数据 | 内容 |
| --- | --- |
| `rooms.json` | 房间、连接、初始状态 |
| `doors.json` | 门、权限、可封 |
| `items.json` | 工具/备件/药品 |
| `events.json` | 条件、效果、文本 |
| `scenarios.json` | 目标、救援窗口、难度 |
| `procedures.json` | 程序/检查单 |

> 第一版手写 1 张场景；不要做程序生成。

## 六、存档

- 班次内：自动存档（每房间/关键动作）；
- 班次结束：写记录/程序/城市状态；
- 死亡：不删档，保留知识；
- 支持导出记录（文本/JSON）。

## 七、测试

| 测试 | 内容 |
| --- | --- |
| 单元 | 资源守恒、门交换、火灾蔓延 |
| 场景 | 固定种子跑 20 分钟，验证可达结局 |
| 失败归因 | 每次失败输出原因链 |
| 可读性 | 截图/玩家测试：能否说出状态 |
| 性能 | 6–9 房间、少量 NPC、2D |

## 八、技术风险

| 风险 | 缓解 |
| --- | --- |
| 系统耦合太复杂 | 先做 6 房间/3 故障的垂直切片 |
| 状态不可读 | 先做检查器/调试可视化，再做美术 |
| 事件脚本化 | 数据驱动 + 条件表 |
| 内容成本 | 1 张场景，复用房间/事件模板 |
| 与塔防工程混淆 | 独立项目/独立目录 |

## 九、MVP 技术范围

- 1 张场景，6 房间；
- 氧气/电力/压力 3 资源；
- 泄漏/电气/火 3 故障；
- 1 NPC；
- 1 种结局 + 撤离；
- 无元进程/无多场景；
- 目标：20 分钟可玩闭环。
