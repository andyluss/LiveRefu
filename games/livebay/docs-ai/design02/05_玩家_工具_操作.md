# 05 · 玩家、工具与操作

## 一、玩家是谁

【方向】无名夜班值班人；没有脸、没有战斗技能，只有：

- 一套外环工作服/头盔；
- 一只手提工具箱；
- 部分门/电权限；
- 一部能听广播、不能随时呼叫救援的通讯器；
- 一段必须由自己写完的班后记录。

> 玩家不是英雄；玩家是“最后一个还在段里的人”。

## 二、移动与空间

- 2D 等距/侧视；房间之间用门/管线井/破口连接；
- 移动消耗时间与 suit O2；负重会变慢；
- 不能跳/攀爬/战斗；只能走、爬、挤、拖；
- 视角可拉近/拉远，但**不做第一人称**（第一版）。

### 2.1 负重

| 负重 | 效果 |
| --- | --- |
| 轻 | 正常速度 |
| 中 | 速度 -10%，拖人 -20% |
| 重 | 速度 -25%，不能跑，动作更慢 |

> 搜刮不是“越多越好”：带不走的物资会变成下一局的记忆/标记。

## 三、工具

| 工具 | 用途 | 消耗 | 风险 |
| --- | --- | --- | --- |
| **多功能扳手** | 阀门/门/泵 | 无 | 慢 |
| **封条枪** | 封门/补小漏 | 封条 | 不可逆/困人 |
| **焊枪** | 补结构/管线 | 电/焊条 | 火花/火/烧伤 |
| **切割器** | 破门/切开变形结构 | 电/时间 | 火花/失压 |
| **压力表** | 读房间压力/泄漏 | 无 | 需要靠近 |
| **气体检测器** | 读 O2/污染/可燃气 | 电池 | 延迟/误报 |
| **备用电池** | 临时供电 | 一次性 | 过载 |
| **医疗包** | 止血/稳定 | 药品 | 感染/依赖 |
| **手电** | 照明 | 电池 | 暴露/耗电 |

### 3.1 工具设计原则

- 每个工具**只解决一类问题**，但可以通过组合解决复合问题；
- 没有“万能工具”；没有武器；
- 工具会坏/会没电/会用完；
- 工具升级是“更省/更稳/更安全”，不是“更高伤害”。

## 四、动作系统

### 4.1 交互

- 靠近 + 按住交互键；
- 动作有**时间条**，可被打断；
- 某些动作需要**双手**（不能同时拿工具/拖人）；
- 动作失败会消耗时间/资源，但不一定立刻死亡。

### 4.2 动作列表（第一版）

| 类别 | 动作 |
| --- | --- |
| 门 | 开/关/封/破 |
| 电 | 断电/复电/切换负载/换电池 |
| 气 | 补压/通风/封漏 |
| 火 | 灭火/隔离/排烟 |
| 人 | 搜救/拖拽/医疗/安抚 |
| 物 | 搜刮/携带/放置/拆解 |
| 信息 | 看表/听广播/读日志/标记地图 |

### 4.3 时间与风险

- 所有动作都有耗时；时间是最硬的资源；
- 高风险动作（切割/焊接/破门）有失败/反噬；
- 玩家可以取消，但已消耗的时间/材料不返还。

## 五、控制

### 5.1 键鼠

| 输入 | 行为 |
| --- | --- |
| WASD/方向 | 移动 |
| 鼠标 | 指向/选择 |
| E/左键 | 交互 |
| 按住 E | 执行长动作 |
| Shift | 快走/拖拽 |
| Tab | 舱段地图 |
| Q | 工具轮盘 |
| Space | 暂停/规划 |
| Esc | 菜单/退出 |

### 5.2 手柄

- 左摇杆移动，右摇杆指向；
- A 交互/长按；
- LB/RB 切换工具；
- Y 地图；
- Start 暂停。

### 5.3 无障碍

- 可重映射；
- 长按/切换交互可选；
- 色盲友好状态（形状/文字）；
- 字幕/广播文本；
- 降低晃动/闪烁；
- 可暂停（生存压力不靠反应速度）；
- 视觉/听觉提示双通道。

## 六、状态与反馈

| 状态 | 玩家看到/听到 | 影响 |
| --- | --- | --- |
| 缺氧 | 呼吸变重、边缘变暗、警告 | 移动/交互变慢 |
| 失温 | 手抖、冷色、金属声变脆 | 动作变慢 |
| 烧伤 | 疼痛音、手部抖动 | 持续掉血 |
| 疲劳 | 呼吸、脚步、动作延迟 | 长动作更慢 |
| 恐慌 | UI 抖动、广播失真、提示延迟 | 判断力下降（可选） |

> 不做“血条占满屏幕”；状态通过身体/声音/边缘提示，数字在检查器里。

## 七、NPC 交互

- 可以拖/扶/背；不能“指挥战斗”；
- NPC 有 O2/伤/恐慌/技能；
- 救他会消耗时间/O2，也可能得到钥匙/知识；
- 不救不会立刻惩罚，但会在记录/结局里出现。

## 八、失败与重试

- 死亡后回到班次起点？【候选】：
  - A 重开整班（推荐，短局）；
  - B 从最近安全点重开（更宽容，但削弱压力）；
  - C 不可重开，只留记录（更硬核，但受众窄）。
- 第一版建议 A：整班重开，保留知识/记录。
