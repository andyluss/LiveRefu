# 03 · 世界与场景

> 世界观可以借用 design01 的逍遥湾；但本作只关心**一段舱壁**，不关心塔防战线。

## 一、事件：断缆

【方向】外环第七段被碎片群切断：

- 主电缆断，外环段失去主供；
- 两条压力管线破裂，舱段开始失压；
- 湾口对接臂关闭，救援船需要窗口；
- 广播说“局部异常，已按惯例处理”；
- 夜班值班人被困在段内。

这不是“外星人入侵”，是**一次会被低报的工业事故**。

## 二、空间：一张舱段剖面

【方向】2D 等距/侧视剖面，6–9 个房间，不是开放世界。

```text
        [救援对接臂]
              |
[医疗舱]--[主控室]--[配电间]
    |          |          |
[居住舱]--[中央走廊]--[断裂段]
              |
          [循环站]
```

### 2.1 房间类型

| 类型 | 功能 | 生存意义 |
| --- | --- | --- |
| 中央走廊 | 通行 | 连接一切，也最容易失压 |
| 主控室 | 广播/权限/地图 | 信息与门控 |
| 配电间 | 电力分配 | 门/氧/灯/维修 |
| 循环站 | 水/氧/过滤 | 长期生存 |
| 医疗舱 | 药品/照护 | 受伤/NPC |
| 居住舱 | 补给/私人物品 | 搜刮/叙事 |
| 断裂段 | 破口/危险 | 高风险高回报 |
| 对接臂 | 撤离 | 时间窗口 |
| 储物/管线井 | 备件/捷径 | 探索 |

### 2.2 房间状态

每个房间有：

- 压力；
- 氧气；
- 温度；
- 电力；
- 污染；
- 门状态；
- 人员/尸体/物资；
- 可见度。

> 玩家看到的不是“数值面板”，而是门灯、雾、霜、火花、声音、压力表。

## 三、三张场景

### 3.1 断缆（默认/教学）

| 项 | 内容 |
| --- | --- |
| 核心 | 失压 + 断电 + 救援窗口 |
| 时长 | 20 分钟 |
| 关键选择 | 封哪段、救谁、是否撤离 |
| 新系统 | 门/压力/电力 |
| 难度 | 标准 |

### 3.2 低功率夜班

| 项 | 内容 |
| --- | --- |
| 核心 | 电力不足，氧气循环与门抢电 |
| 时长 | 20 分钟 |
| 关键选择 | 保氧还是保门/保通讯 |
| 新系统 | 电池、负载、日蚀窗口 |
| 难度 | 困难 |

### 3.3 封舱

| 项 | 内容 |
| --- | --- |
| 核心 | 火/烟/污染在舱段蔓延，门是武器也是牢笼 |
| 时长 | 18–25 分钟 |
| 关键选择 | 封哪段、开哪扇、放弃谁 |
| 新系统 | 火/烟/污染、门控 |
| 难度 | 高 |

> 三张场景共享房间/资源系统，但事件表与目标不同。不要做三套规则。

## 四、城市如何在场

- **广播**：救援窗口、事故数字、安抚话术；
- **权限**：门/电/撤离需要授权，玩家只有部分；
- **配给**：药品/备件有限，城市不会无限支援；
- **低报**：结算时可以选择如实/低报/沉默；
- **不在场**：没有 NPC 城市漫游，城市通过声音/记录/窗口存在。

## 六、场景写作规则

1. 每个房间至少一个“可读的生存信息”（门灯/声音/霜/火花）；
2. 每个场景至少一个“必须放弃”的选择；
3. 每个失败都要有前兆；
4. 不靠随机跳吓；靠系统耦合；
5. 不写“这里很恐怖”；写“这里失去了什么”。

## 七、待裁决

1. 是否固定 6 房间，还是 8–9 房间？
2. 是否允许玩家进入断裂段？
3. 三张场景是否共用同一主角？
4. 城市广播是否真实/可被玩家验证？
5. 是否加入“其他幸存者”作为常规系统，还是仅剧情 NPC？
