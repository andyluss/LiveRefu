# LiveBay 生存游戏策划 · design02

> **工作名**：《逍遥湾：断缆》 / *LiveBay: Severed*
>
> **一句话**：一场 20 分钟的舱段生存。你不是去打退什么，而是在氧气、电力、压力与救援窗口之间，决定先救哪一段、放弃哪一段、最后谁留下。
>
> **状态**：参考草案；暂不开发；不改动 `game/` 现有工程。

## 一、这是什么

这是一套**从生存玩法出发**的独立策划，不是把 design01 的塔防换皮。

- 没有塔；
- 没有敌人波次；
- 没有“守到最后一波”；
- 核心是**封闭空间里的资源、压力、门、故障、救援与记录**。

它复用 design01 的世界观土壤（逍遥湾、三环、外环夜班、低报、Solarpunk 能源），但**玩法、循环、HUD、关卡、技术方案全部重新设计**。

## 二、设计支柱

| # | 支柱 | 含义 |
| --- | --- | --- |
| 1 | **生存是维护，不是战斗** | 玩家做的是检查、隔离、修复、搜救、撤离；不是射击/塔防 |
| 2 | **每个选择都有空间与时间代价** | 封舱能止漏，也会把人关在外面；供电能修门，也会断氧 |
| 3 | **失败留下知识，不留数值惩罚** | 死亡/撤退解锁程序、地图记忆与记录，不靠刷级变强 |
| 4 | **撤离是合法结局** | 不是“逃跑可耻”；活着交接、留下记录，也是完成 |
| 5 | **城市不在场，但一直在场** | 广播、救援窗口、低报、配给，让“外面的制度”影响舱内生存 |

## 三、类型与形态

| 项 | 选择 |
| --- | --- |
| 类型 | 单人生存 / 系统管理 / 轻叙事 |
| 视角 | 2D 等距剖面 / 侧视舱段 |
| 单局 | 15–25 分钟 |
| 结构 | 一局 = 一个班次；多局 = 多次值班 |
| 平台 | PC（键鼠/手柄）优先；暂不做移动/联机 |
| 失败 | 死亡、被困、救援错过、主动撤离 |
| 成长 | 知识/程序/地图记忆/城市记录；不做数值膨胀 |
| 美术 | NASApunk 白盒 + Solarpunk 能源/循环；低多边形/矢量 |
| 引擎 | Godot 4.7（参考 design01 工具链，但独立运行时） |

## 五、与 design01 的关系

| 项 | design01 | design02 |
| --- | --- | --- |
| 核心 | 岗位塔防 | 舱段生存 |
| 敌人 | 波次/故障 | 环境/故障链（无敌人） |
| 空间 | 弧形路径 + 塔位 | 房间图 + 门/管线/舱段 |
| 资源 | 供能/保障度 | 氧气/电力/压力/热/污染 + 个人状态 |
| 失败 | 漏过/保障度 | 窒息/失压/失温/烧伤/被困 |
| 成长 | 职业/合同/评级 | 知识/程序/城市记录 |
| 代码 | 现有 `game/` | **不实现**，仅策划参考 |

> 共享的是世界与设计伦理，不共享塔防循环。

## 七、边界

- 这是**参考策划**，不是已经批准的产品方向；
- 不修改 `design01` 的塔防设定，也不改 `game/` 代码；
- 所有数值都是量级/占位，不是平衡定案；
- 如果未来要做，先做 1 张场景的垂直切片，不要一次做完整游戏。
