# 00 · 阅读指南与定位

## 一、这套文档解决什么

design02 只回答一个问题：

> **如果逍遥湾不做塔防，做一款真正的生存游戏，它应该是什么样？**

它不是 design01 的扩展包，也不是“塔防的生存模式”。它从零回答：

- 玩家在 Survive 什么？
- 空间、资源、时间如何互相咬合？
- 没有战斗，压力从哪里来？
- 一局多长、失败如何、重玩为什么？
- 它与逍遥湾的世界观如何相容，但不被塔防绑住？

## 二、状态标记

| 标记 | 含义 |
| --- | --- |
| 【方向】 | 本文建议的默认方向；人类可改 |
| 【候选】 | 2–3 个可选方案，附代价 |
| 【占位】 | 为了能讨论而暂定的数值/名词 |
| 【待裁决】 | 需要人类拍板，见 12 |
| 【不做】 | 明确不在本策划范围内 |

> 没有标记的叙述是描述性整理，不是定案。

## 三、文档关系

```text
README
  → 01 概念（为什么做）
  → 02 循环（怎么玩）
  → 03 世界 / 04 系统 / 05 操作 / 06 内容（玩什么）
  → 07 叙事 / 08 元进程（为什么再来）
  → 09 UX / 10 技术 / 11 范围（怎么做）
  → 12 决策（现在定什么）
```

## 四、与 design01 的边界

| 可以借用 | 不借用 |
| --- | --- |
| 逍遥湾世界、三环、外环夜班 | 塔防核心循环 |
| 低报/机构疲惫/慢好三生 | 塔/波次/敌人/塔位 |
| NASApunk + Solarpunk 视觉伦理 | 现有 HUD/App/GamePage |
| 白盒化/清澄/可退出 | 现有 `game/` 运行时 |
| 生存资源的世界解释 | design01 的平衡数值 |

## 五、读者路径

### 5.1 10 分钟判断“要不要做”

读：01 → 02 → 11 的范围与停止条件。

### 5.2 做原型前

读：02 → 04 → 06 → 10 → 11。

### 5.3 做叙事/内容

读：03 → 07 → 06。

### 5.4 做评审

读：01 的非目标 + 11 的风险 + 12 的待裁决。

## 六、写作约定

- 不写“玩家会喜欢”；写“玩家要做什么决定、付什么代价”；
- 不写“沉浸感”；写“哪个信息在什么时候可见”；
- 不写“随机生成”；写“哪些变量组合、如何验证”；
- 不把“生存”当氛围词；每个系统都要能导致失败/取舍；
- 不把“没有战斗”当卖点；要证明压力来自系统耦合。
