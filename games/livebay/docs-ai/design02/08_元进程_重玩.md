# 08 · 元进程与重玩

## 一、原则

- **不靠数值膨胀**：没有攻击力/血量/背包等级的永久增长；
- **知识就是进度**：程序、地图记忆、判断经验；
- **失败不惩罚**：死亡/撤离都留下记录与知识；
- **不逼玩家回来**：没有每日/体力/限时活动。

> 重玩的理由是“我现在知道先看什么”，不是“我再刷一轮变强”。

## 二、四类持久进度

| 类型 | 获得 | 作用 | 不作用 |
| --- | --- | --- | --- |
| **程序** | 完成/发现 | 解锁新动作/更快检查 | 不直接加数值 |
| **地图记忆** | 探索/标记 | 显示捷径/危险点 | 不自动全图 |
| **城市记录** | 结算/选择 | 新事件/救援条件/结局 | 不做善恶条 |
| **关系** | 救/放弃 NPC | NPC 再出现/证词 | 不刷好感度 |

## 三、程序系统

【方向】程序是“检查单/操作卡”，不是技能树。

| 程序 | 解锁 | 效果 |
| --- | --- | --- |
| 快速封舱 | 第一次成功封舱 | 封门时间 -20% |
| 压力优先 | 发现压力泄漏 | 检查器显示泄漏方向 |
| 电池旁路 | 修复配电 | 可用电池给门/循环 |
| 烟气判断 | 经历火灾 | 通风前显示助燃风险 |
| 救援窗口 | 完成一次救援 | 广播提前 30s 提示 |

> 程序只改“信息/操作”，不改“伤害/血量”。

## 四、城市状态

| 状态 | 影响 |
| --- | --- |
| 信任 | 救援是否准时/是否给权限 |
| 记录 | 低报/如实会影响后续广播与事件 |
| 资源 | 备件/药品/电池的供给 |
| 舆论 | 是否有人来调查/纪念 |

> 城市状态是“世界记得你”，不是“你变强了”。

## 五、场景解锁

```text
断缆（教学）
  → 低功率夜班（电力）
  → 封舱（火/门）
  → 隐藏：沉默（低报线）
```

- 解锁靠完成/发现，不靠刷次数；
- 每张场景有独立目标与事件；
- 不强制线性；玩家可选。

## 六、重玩结构

| 层 | 保留 | 重置 |
| --- | --- | --- |
| 班次 | 无（短局） | 资源/房间/事件 |
| 场景 | 程序/地图记忆 | 具体物资/事件顺序 |
| 城市 | 记录/关系/信任 | 单次事故细节 |

## 七、反刷设计

- 不给“重复同一场景”的数值奖励；
- 不给每日任务；
- 不给抽卡/装备；
- 失败也解锁知识，避免“必须赢”；
- 场景内容有限，但组合/选择足够重玩。

## 八、玩家画像

| 玩家 | 留存动机 |
| --- | --- |
| 系统玩家 | 试不同分配/路线 |
| 叙事玩家 | 看不同结局/记录 |
| 完美主义 | 救所有人/全记录 |
| 短会话 | 15–20 分钟一局 |

## 九、待裁决

1. 程序是否做成可见树，还是“发现即解锁”？
2. 城市状态是否跨场景可见？
3. 是否做隐藏结局线？
4. 是否允许玩家自定义难度？
5. 是否做“每日班次”？建议不做。
6. 是否做成就？可做，但不影响数值。
