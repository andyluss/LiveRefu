# 09 · UX、美术与音频

## 一、视觉方向

- NASApunk 白盒：外露结构、接缝、标签、检查单；
- Solarpunk 代谢：太阳能、暖光、循环管线、植物（少量、可维护）；
- 2D 等距/侧视剖面：房间像剖面模型，不是写实第一人称；
- 颜色以“状态”而不是“装饰”使用；
- 暗但不黑：玩家要能读懂空间，不靠手电猜。

## 二、屏幕布局

```text
┌──────────────────────────────────────┐
│ 广播/目标/救援窗口        [暂停] [地图] │
│                                      │
│        舱段剖面 / 房间 / 角色          │
│                                      │
│ [suit O2] [状态] [工具] [交互提示]      │
└──────────────────────────────────────┘
```

- 顶部：目标/救援/广播字幕；
- 中间：世界；
- 底部：suit O2、状态、工具、交互；
- 地图是覆盖层，不是常驻小地图；
- 检查器/日志按需打开。

## 三、HUD 原则

1. 只显示“现在会死”的信息：O2、压力/温度、suit 状态；
2. 房间状态通过环境表达，数字在检查器；
3. 不用 5 个常驻条；
4. 颜色 + 形状 + 文字三重编码；
5. 可隐藏 HUD（沉浸模式），但保留关键警告。

## 四、地图

- 2D 平面图 + 房间状态；
- 显示：门、压力、火、断线、已知人员；
- 未知区域用“未扫描”而不是空白；
- 地图不是全知：需要扫描/记忆；
- 玩家可标记，但标记会过期。

## 五、颜色

| 状态 | 色 | 辅助 |
| --- | --- | --- |
| 正常 | 暖白/灰绿 | 稳定灯 |
| 注意 | 琥珀 | 慢闪 |
| 危险 | 橙红 | 快闪 + 声音 |
| 失压 | 冷蓝/白霜 | 风声/耳鸣 |
| 断电 | 深灰/黑 | 手电/应急灯 |
| 污染 | 黄绿/雾 | 检测器 |

> 颜色不能单独承担信息；色盲模式用形状/图标/文字。

## 六、角色/动画

- 玩家：剪影 + 工具/头盔/状态；
- NPC：姿势/伤/呼吸，不做精细面部；
- 动画：开门、封门、焊接、拖拽、呼吸、手抖；
- 不做过场动画；用环境/镜头/声音叙事。

## 七、声音

| 层 | 内容 | 作用 |
| --- | --- | --- |
| 环境 | 金属、风、泵、远处广播 | 空间/状态 |
| 玩家 | 呼吸、脚步、工具 | 身体/紧张 |
| 事件 | 泄漏嘶声、火花、门锁 | 预警 |
| 音乐 | 低音 drone/稀疏 | 不抢信息 |
| 静默 | 突然安静 | 更可怕 |

### 7.1 声音可读性

- 关键声音有字幕/视觉提示；
- 不同故障有不同节奏/频段；
- 不靠 jump scare；
- 可单独调音量。

## 八、可访问性

- 色盲/低视力：形状/文字/高对比；
- 听觉：字幕/视觉警告；
- 运动：减少晃动/闪烁；
- 操作：重映射/长按切换/暂停；
- 认知：检查器/日志/目标复述；
- 难度：资源/事件/救援窗口可调。

## 九、UI 风格

- 纸质检查单/标签/手写批注；
- 物理按钮/拨杆/指示灯；
- 不做全息/无边框玻璃；
- 数字用等宽；重要信息用大字；
- 每个面板有来源/时间/权限（白盒）。
