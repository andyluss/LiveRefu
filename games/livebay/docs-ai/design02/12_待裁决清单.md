# 12 · 待裁决清单

> 这些是 design02 要进入原型前必须拍板的问题。默认建议不是决定；人类可改。

## P0：不做就无法开始

| # | 问题 | 选项 | AI 建议 | 代价 |
| --- | --- | --- | --- | --- |
| D01 | 空间形态 | A 2D 等距 / B 2D 侧视 / C 第一人称 | **A 2D 等距** | 第一人称成本高、恐怖化 |
| D02 | 第一版资源 | A 氧/电/压 / B 加温度 / C 五资源 | **A 三资源** | 少温度层次，但可读 |
| D03 | 第一版场景 | A 断缆 / B 低功率 / C 封舱 | **A 断缆** | 教学最稳，火/门后置 |
| D04 | NPC 数量 | A 1 / B 2 / C 0 | **A 1** | 少道德复杂度，但可控 |
| D05 | 失败重开 | A 整班重开 / B 检查点 / C 不可重开 | **A 整班** | 短局可接受；检查点削弱压力 |

## 默认边界

【不做】

- 塔防/波次/敌人；
- 战斗；
- 开放世界/基地建造；
- 多人；
- 每日任务/赛季；
- 数值刷取；
- 程序生成地图。

## 需要人类回答的 10 个问题

1. 你真的想做“没有战斗的生存”吗？
2. 20 分钟一局是否合适？
3. 玩家是否接受“撤离是合法结局”？
4. 死亡重开整班是否太挫败？
5. 第一版是否只做 1 张场景？
6. 是否接受 2D 等距/剖面，而不是第一人称？
7. NPC 是资源/道德选择，还是完整同伴 AI？
8. 低报/记录是否要做成核心，而不只是结局文本？
9. 是否愿意先做白盒模拟，不先做美术？
10. 如果测试发现“没有战斗就不紧”，是否愿意停止/转向？

## 结论

> 先拍 D01–D08；其他都可以在原型后改。
>
> **不要一次做完整个游戏；先证明 20 分钟舱段生存成立。**
