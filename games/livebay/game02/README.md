# LiveBay: Severed（断缆）

> design02 生存游戏的可玩 MVP 原型。独立 Godot 工程，不依赖 `../game/` 的塔防运行时。

## 运行

```bash
./run.sh game02          # 启动
./run.sh game02-test     # 模拟测试 17 项
./run.sh game02-check    # 无头启动 180 帧
```

## 当前范围

- 1 张场景：外环第七段 / 断缆；
- 6 个房间：中央走廊、主控室、配电间、循环站、医疗舱、救援对接臂；
- 3 个主资源：氧气、电力、压力；
- 3 类故障：泄漏、火灾、断电；
- 1 个 NPC：巡检员岚；
- 结局：撤离 / 失联 / 死亡；
- 无塔防、无波次、无敌人、无战斗。

## 操作

| 输入 | 行为 |
| --- | --- |
| WASD | 在房间内移动 |
| E | 交互：过门/修漏/灭火/切换主电/补氧/救人/撤离 |
| R | 封门（消耗封条） |
| F | 救援窗口在对接臂时“留下” |
| TAB | 舱段地图 |
| SPACE | 暂停 |
| ESC | 暂停/菜单 |

## 设计边界

- 这是 MVP，不是完整 design02；
- 第二场景（低功率夜班/封舱）、元进程、城市记录未实现；
- 数值是原型量级，不是平衡定案；
- 与 `../game/` 共享设计伦理/世界，不共享塔防代码。
