系统流 / 谁改了什么

Datanumbers → JSON → MissionPack；hash/清单。
Sim路径/塔/敌/波/故障；固定步长。
RuntimeClock/EventBus/CommandBus/BlackBox；回放。

白盒化不是把 UI 变透明，而是让改变有边界：数据、规则、视图、记录各自可指认。

这页故意没做的事

没有假装完整战斗、没有真实寻路、没有精确 DPS 模拟、没有在线数据。它是设计沙盘：帮你看结构、压力与缺口，不替平衡拍板。
