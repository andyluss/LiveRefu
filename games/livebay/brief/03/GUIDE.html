SLOW CABIN / PLAYER GUIDE

先把灯点亮，
剩下的事慢慢来。

这里不是任务管理工具。没有失败、没有排行榜、没有必须完成的清单。你只需要选一个场景、一张唱片，写下一句今晚想做的事，坐一会儿。

一次1 / 15 / 25 / 45 分钟
三种场景夜航 / 雨港 / 晨光
四张唱片夜航 / 雨室 / 深空 / 晨光
第一次：点「进入书房」，允许声音；写一句意图，选 1 分钟试玩，点「开始专注」。剩下交给房间。
开始操作房间声音结束建议隐私

01 / START开始

进入书房后，先不要急着点开始。看一眼房间，写一句意图，选一个你觉得“做得到”的时长。

意图可以很轻

「读完手边这一章」「写 500 字」「整理桌面一角」「什么都不做，坐一会儿」都可以。留空也可以。

先选短的

第一次建议 1 分钟或 15 分钟。短的不是不认真，是让开始发生。

02 / CONTROLS操作

拖动环绕房间
滚轮 / 双指缩放
点击物件台灯 / 植物 / 猫 / 窗 / 唱机 / 杯 / 椅 / 笔记本
SPACE开始 / 暂停
R重置
M静音
1–4切换时长
H帮助

03 / ROOM场景、唱片与物件

右侧可以随时切换场景与唱片；点击房间里的物件也会触发小互动。

台灯开关灯；光的变化会影响房间氛围。
植物浇水；完成专注也会让它慢慢长大。
猫摸一摸；它不提供效率，只是在。
舷窗切换夜航/雨夜；不改变玩法。
唱机切换下一张唱片（也可以点右侧 MUSIC）。
笔记本开始专注。
所有互动都不是解谜，也不要求“正确顺序”。想点哪里就点哪里。

04 / SOUND声音

雨、风、唱针、低鸣与旋律是独立的生成式声层。四张唱片会换和声与琶音，不换专注规则。可以单独调，也可以全部静音。建议戴耳机，但不是必须。

声音不会自动播放：浏览器要求先点击「进入书房」或声音按钮。静音状态会被记住。

05 / END结束与记录

完成

柔和钟声，记录本次分钟和意图；植物可能长一点。没有烟花，没有排名。

中断

暂停/离开/切到后台都可以；计时按真实时间继续，回来后补算。下次回来，房间还在，不会扣分。

06 / TIPS几条建议

不要先整理房间

装饰是之后的事。先坐 1 分钟，比先摆好一切更重要。

可以只看窗外

专注不是必须产出。坐着、呼吸、听雨，也算这一班。

不要连打卡

没有连续天数。断了就断了，回来就好。

把 UI 收起来

专注时尽量少看计时器；让房间承担陪伴。

07 / PRIVACY隐私

所有数据（意图、记录、总分钟、植物等级、声音设置）只保存在浏览器 localStorage。没有账号、没有后端、没有上传。清理浏览器数据会丢失记录。
