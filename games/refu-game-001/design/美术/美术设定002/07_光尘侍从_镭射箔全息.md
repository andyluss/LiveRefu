# 07 · 光尘侍从：镭射箔全息

一句话：**会变色的箔，角度就是内容。**

## 一、为什么透明

**世界观**：它们记录与广播——记录员「棱」登记路线并广播公频，语气像档案（[设定圣经](../../故事/小说_节点之海/00_设定圣经.md)）。牌子只能单向读到就是暗号，所以本体是镭射箔：角度换，颜色换，内容不换。

**机制**：把「档案」做成实体挂件。

| 机制 | 透明化 | 出处 |
| --- | --- | --- |
| 记录片 | 手掌大亚克力片，刻针刻字，铜边 | [23](../../23_规则卡组_Roguelike远征.md) |
| 题栏 | 不透明纸白刻痕 | [第 37 章](../../故事/小说_节点之海/第37章_东线与西线.md) |
| 取用次数 | 片角计数器，取用跳一格 | [第 33 章](../../故事/小说_节点之海/第33章_种子.md) |
| 公频广播 | 箔面翻页，白线亮起 | [第 29 章](../../故事/小说_节点之海/第29章_小队.md) |
| 排行榜 | 三条刻痕：节点数、难度分、用时 | [26](../../26_远征_种子与排行榜验收.md) |

**心理**：镭射垫板、全息贴纸、亚克力挂件——廉价但闪得认真。

| 原型 | 用法 | 反面 |
| --- | --- | --- |
| 镭射垫板 | 膜的角度色 | 整块镜面 |
| 全息贴纸 | 界面层贴纸 | 跟着折射糊掉 |
| 亚克力挂件 | 悬浮碎片、记录片 | 实心水晶 |

全族最 bling，但按 [01](01_透明体系总则.md) 只到级 3 交互，闪烁 ≤ 3Hz。

## 二、材质配方

| 层 | 做法 | 红线 |
| --- | --- | --- |
| L1 体表膜 | 镭射箔薄膜，全透强偏光，箔纹方向各异 | 雾度近 0 |
| L2 内腔光核 | 白线加小灯泡，待机暗、广播全亮 | 只由状态驱动 |
| L3 界面层 | 刻字面、棱面映字、贴纸 | 始终不透明，渲染最上 |
| L4 边缘光 | 银色切边高光走一周 | 偏青，1–2 px |

箔色由视角与箔纹夹角决定，不由光源。切边不变色，钉住剪影。白线是神经，广播时铺开。

**箔是透明的，字是不透明的。**

| 项 | 透明 | 原因 |
| --- | --- | --- |
| 箔（本体） | 是 | 角度是内容 |
| 刻字面、棱面映字 | 否 | 机制可读底线 |
| 贴纸层 | 否 | 撕下即离开 |
| 挂绳结 | 否 | 朝向锚点 |

**箔管好看，字管好用，字永远比箔亮。**

## 三、色板

| 视角 | 颜色 | 十六进制 | 用途 |
| --- | --- | --- | --- |
| 正对 0° | 青 | `#5FF3E0` | 待机基准 |
| 偏 30° | 蓝绿 | `#4FD8FF` | 移动布防 |
| 偏 60° | 品红 | `#B26BFF` | 广播中 |
| 掠射 85° | 紫 | `#7A4DFF` | 剪影边缘 |
| 反角 | 暖金 | `#FFD86B` | 翻面取用 |

| 名称 | 十六进制 | 用在哪 |
| --- | --- | --- |
| 记录纸白 | `#F4F6F3` | 刻字面底、题栏、记录片 |
| 广播高亮 | `#7CF9FF` | 白线、公频字条 |
| 取用琥珀 | `#FFB347` | 取用次数 |

同一块箔换角度即读出发布态：未发布青、已刻录品红、广播中紫、已归档暖金。**转镜头即读。**每态另配箔纹作冗余（[01](01_透明体系总则.md)）。

## 四、造型与比例

| 元素 | 形态 | 尺寸 |
| --- | --- | --- |
| 主碎片 | 不规则薄片，3–5 片一组 | 高约 0.6 格 |
| 悬浮小碎片 | 绕体公转的碎屑 | 主片五分之一 |
| 记录片 | 圆角方片 | 比手掌大一圈 |
| 挂绳 | 细绳加一个结 | 绳宽约 2 px |

剪影规则：碎片轮廓加挂绳，缺一不可；留缝不小于 1 px；剪影内须有不透明线，12 格外仍可辨。内部可见箔纹、刻字面、线圈、悬浮碎片。

**不透明芯三处**：刻字面（字朝哪它朝哪）、挂绳结（结在上）、金属边框（最宽边为正面），同时是朝向锚点。

## 五、个体「棱」的视觉

| 项 | 视觉要点 |
| --- | --- |
| 身份 | 光尘侍从·记录员，星辉造，全族最规整、碎片最少 |
| 棱面映字 | 浮字笔画很细，像拿针在玻璃背面写字（[第 29 章](../../故事/小说_节点之海/第29章_小队.md)） |
| 登记路线 | 刻针入片，刻字面浮起很淡的光 |
| 广播公频 | 棱片翻面，白线铺到脚下，念「已广播至今日公频」 |
| 语气 | 像档案，有节拍：翻页、停顿、念一遍 |

与星辉主族（[04](04_星辉议会_晶体棱镜.md)）同框：主族棱镜、从族箔；主族常亮、从族脉冲；从族体量 0.55–0.7，不遮主族射程。**箔永远低半格。**另有两名同类，按旧挂绳处理。

## 七、动效

| 时机 | 动效 | 红线 |
| --- | --- | --- |
| 待机 | 角度扫光，青到蓝绿来回 | 循环不短于 4s |
| 广播 | 白线亮起 0.8s，箔面翻页 0.3s | 一次性 |
| 取用记录片 | 贴纸撕下手感：片角先翘，整片脱离 | 不超过 0.5s |
| 护盾充能 | 膜层从光尘附着到目标塔 | 与 10s 同步 |
| 被摧毁 | 箔面卷曲，向紫收，切边先灭 | 不超过 0.6s |

闪烁 ≤ 3Hz，不覆盖超过 25% 屏幕。低端机只留级 1。

## 九、好处清单

1. **信息层与材质层分离**：箔管角度，字管可读；
2. **角度即叙事**：转镜头读出四个发布态；
3. **与孢子侍从一眼分开**：孢子是球泡、苔绿、菌丝（[06](06_孢子侍从_气泡薄膜.md)）；光尘是碎片、虹彩、箔纹；
4. **档案变成可收集物**：记录片可刻、可取、可归档；
5. **闪得动也降得下来**：有级 1 至级 3 分级与 3Hz 红线。

## 十、弱点与对策

| 弱点 | 对策 |
| --- | --- |
| 镭射过闪 | 全透 ≤ 6，偏光随距离衰减 |
| 刻字跟着折射 | 界面层不折射，渲染最上 |
| 印刷出不来角度色 | 只留基准色 `#5FF3E0`，其余用烫银工艺 |
| 与星辉主族过于相像 | 主族折射、从族反射；常亮对脉冲 |
| 状态只靠色 | 每态配箔纹或贴纸形状作冗余 |
| 记录片太亮抢数值 | 战场内降为雾透剪影，只在记录席全亮 |

## 十一、验收清单

1. **不透明芯**：能指出刻字面、挂绳结、金属边框三处不透明部件；
2. **角度可辨**：四个发布态去色后仍能靠箔纹与切边区分；
3. **字比箔亮**：题栏与取用次数的对比度高于同帧箔面；
4. **动效合规**：闪烁 ≤ 3Hz，交互粒子 ≤ 40 且 1 秒内回收；
5. **同框可辨**：同框时体量与「常亮对脉冲」可被盲测认出。
