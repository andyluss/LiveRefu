# 05 · 齿轮帮：透明玩具壳

> 卡面：用途＝从族齿轮帮的透明体质细案 ｜ 依赖：[00 主题宣言](00_主题宣言_千禧透明美学.md)、[01 透明体系总则](01_透明体系总则.md)、[14 卡表](../../14_卡表_铁砧联邦核心12卡.md) ｜ 状态：v0.1 · 2026-09-14

一句话：透明＝**千禧年的透明塑料玩具壳**：透明掌机、电子宠物、糖果色 PVC，看得见里面的小齿轮与灯泡。

## 一、为什么透明

| 层 | 内容 | 落点 |
| --- | --- | --- |
| 世界观 | 被造出来给外族人看的机器。透明壳＝信任设计：壳能拆、件能换、坏在哪看得见 | 外壳贴检验标记，内腔留标准件编号 |
| 机制 | 维修要看见修谁、还剩多久（8/s、6s、射程 2 格），搬运要看见光环罩住哪几座塔（2 格） | 油管亮度随时长衰减，光环落地由边缘光描出 |
| 心理 | 千禧年透明消费电子的集体记忆：低成本、可爱、廉价但快乐，与战场沉重刻意反差 | 允许流痕与指纹，禁止做旧 |

## 二、材质配方

按 [01 总则](01_透明体系总则.md) 第一节四层拆解：

| 层 | 部件 | 口径 | 参数 |
| --- | --- | --- | --- |
| L1 体表膜 | 外壳 | 透明 ABS／PVC 注塑 | 雾度 12–18%，n≈1.50，厚 6–10 px，必有流痕与合模线，允许指纹与 ≤2 px 划痕 |
| L2 内腔光核 | 灯泡与 LED | 自发光 | 糖果黄 #FFD23F，呼吸 0.5–2 Hz，兼状态灯 |
| L3 界面层 | 贴纸、丝印、小窗 | 不透明 | 不参与折射，丝印 #3A3F4A，小窗 2×2 格 |
| L4 边缘光 | 塑料边缘 | 菲涅尔描边 | 宽 2–3 px，白高光 85% |

分工：外壳取半透上限（透过 72–80%，禁真做 100%）｜内部零件一律不透明｜贴纸永远清晰。

## 三、色板

| 用途 | 色名 | 十六进制 |
| --- | --- | --- |
| 主色 | 糖果黄 | #FFD23F |
| 点缀 | 蜜橙 | #FF9A3C |
| 点缀 | 泡泡粉 | #FF74B8 |
| 点缀 | 汽水青 | #57D9D0 |
| 电池仓冷光 | 冷蓝 | #4C8DFF |
| 灯泡最亮帧 | 芯亮青白 | #9FE8FF |
| 不透明芯 | 深塑料灰 | #3A3F4A |

族别不靠颜色，靠**圆角矩形轮廓 + 齿轮剪影 + 灯泡数量**（[01](01_透明体系总则.md) 第三节）。

## 四、造型与比例

| 项 | 规则 |
| --- | --- |
| 几何语言 | 圆角矩形为唯一母题，圆角半径＝短边 22–28%，禁尖角与切割面 |
| 玩具比例 | 头身比 1:2.2，头大身小，掌＝头宽 1.4 倍 |
| 过粗关节 | 关节直径＝肢体直径 1.8 倍，外露不透明轴芯 |
| 剪影规则 | 灯泡凸起、圆角矩形身体、两到三条粗腿，0.8 秒可辨 |
| 缩放 | 最小可读高 34 px，低于此值只留剪影与灯泡 |

内部可见结构（必须真画出）：

| 结构 | 位置与动作 |
| --- | --- |
| 小齿轮组 | 胸腔 3–5 枚，待机微转，工作加速 |
| 弹簧 | 每关节 1 根，随步伐压缩 |
| 电池 | 背部 2 节，冷光 #4C8DFF 漏出 |
| 灯泡 | 头顶 1 枚、胸前 2 枚，呼吸兼状态灯 |
| 线圈 | 手臂与油管外侧，通电逐圈点亮 |

**不透明芯放在哪**（总则第三节硬约束）：

| 件 | 作用 |
| --- | --- |
| 电池仓 | 全局最暗，朝向与重量锚点 |
| 马达 | 腰后，驱动齿轮组 |
| 玻璃眼 | 唯一光学件，负责表情 |
| 木托盘 | 仅秤所有，唯一木质不透明件 |

## 五、两个命名个体的差异

以 [00 设定圣经](../../故事/小说_节点之海/00_设定圣经.md) 第八节为准：维修工＝**铆钉**，搬运工＝**秤**。

| 维度 | 铆钉（ANV-M01） | 秤（ANV-M02） |
| --- | --- | --- |
| 轮廓 | 矮胖，抱大油壶 | 高瘦，三条腿，背托木托盘 |
| 标记 | 左眼焊疤，不透明疤块 | 大护目镜，两块不透明镜片 |
| 内部 | 齿轮组、油管 | 弹簧、线圈、承重杆 |
| 唯一不干净处 | 琥珀油 #E8A33D，半透 60%，会晃会挂壁 | 木托盘 #C89B6A，有磨损纹 |
| 底层色 | 糖果黄偏橙 #FFC13A | 糖果黄偏青 #FFD86B |
| 工作光 | 油管内发光，见得着液体流动 | 光环落地，边缘光描一圈糖果黄 |

**铆钉有液体，秤有木头**，缩到 34 px 也能区分（[故事/01](../../故事/01_短篇_火线换装.md) 两人同框）。

## 六、逐卡视觉要点

数值只引用不改（来源 [14](../../14_卡表_铁砧联邦核心12卡.md)、[数值/01](../../数值/01_铁砧联邦_12卡.md)）。

| 卡 | 落场 | 工作中 |
| --- | --- | --- |
| ANV-M01 维修工（15 费／支援槽／修复 8/s／持续 6s／人口 1／射程 2 格） | 外壳先到、零件后落位，灯泡由暗转亮 | 油管点亮、琥珀油流动，6s 由外壳刻度环从满到空表示，修复对象被糖果黄描边，射程 2 格为圆角矩形地板贴片。`on_wave_end` 修复量 +50% 时灯泡闪两次 |
| ANV-M02 搬运工（12 费／支援槽／光环同标签塔攻速 +10%／范围 2 格／人口 1） | 三条腿先落地，木托盘后压上 | 线圈逐圈点亮，范围 2 格为贴地塑料圈 #FFD23F。`on_deploy` 相邻塔 +2 能量时光点从托盘飞向相邻塔，光环只描弹药塔 |
| ANV-M03 路障小队（20 费／路径槽／生命 200／阻挡 2／存在 15s） | 抽出折叠板，1 秒拼成矮墙 | 承重杆受力弯曲，灯泡转橙。15 格刻度每格 1 秒，生命 200 用裂纹逐级表达。`on_expire` 残留减速 3s（−20%）时碎成半透明方块，贴片转汽水青 |

## 七、动效

闪烁 ≤3 Hz，内发光不得盖过数值（[01](01_透明体系总则.md) 第五节）：

| 状态 | 表现 | 预算 |
| --- | --- | --- |
| 待机 | 灯泡 0.5 Hz 呼吸，齿轮每 3 秒一圈，一条随镜头移动的高光条 | 级 1 加级 2，≤6 粒 |
| 维修 | 油管由暗到亮，琥珀油贴图滚动，刻度环收缩 | ≤8 粒 |
| 搬运 | 光环落地半透圆环冲击波，线圈逐圈点亮 | ≤12 粒 |
| 受伤 | 灯泡降到 40% 亮度并偏红，外壳换裂纹贴花 | 级 2 |
| 被摧毁 | 外壳先碎、零件后散，碎片停留 2 秒淡出 | 级 3，≤40 粒 |
| 15s 倒计时 | 15 格刻度逐格熄灭，最后 3 格转橙抖动，归零碎裂 | 级 2 加级 3 |

## 八、UI 表现

| 位置 | 表现 |
| --- | --- |
| 支援槽 | 透明塑料底座加不透明芯点，放入时亮糖果黄，空槽与占用槽另用形状区分（[07](../../07_移动端与界面.md) 第四节） |
| 从族人口 | M01 与 M02 各占人口 1，透明小格加齿轮图标，占满变实心（[04](../../04_塔防核心战斗.md) 第二节） |
| 卡面 | 亚克力卡框全透，三个数字印在不透明色块上，数字层最亮最实 |
| 后勤链触发 | 羁绊「后勤链」（2 张「维修」→ 每波开始自动修复全体 5%）触发时四名从族同框：两名维修工与两名搬运工排成一列同时点亮灯泡，一串光点传向受损塔位 |
| 同屏上限 | 全透单位 ≤6，单帧透明层 ≤8，齿轮帮按半透登记不占额度 |

## 九、好处清单

1. **工作时长可视**：持续 6s 由刻度环走完，剩余时间长在模型上；
2. **维修对象可视**：修复 8/s 打给谁、射程 2 格覆盖到哪，由地板贴片与描边直接给出；
3. **可爱度带来情感联结**：全案唯一允许廉价但快乐的材质，玩家先记住铆钉与秤，再记住功能；
4. **与三主族同屏区分**：铁砧冷钢蓝层压方正、涌潮腐殖绿有机水滴、星辉棱镜白棱形切割、齿轮帮糖果黄圆角玩具。

## 十、弱点与对策

| 弱点 | 对策 |
| --- | --- |
| 玩具感与战争违和 | 玩具感只锁在从族一层，主族与敌人保持沉重 |
| 透明小物件过小 | 以 34 px 最小可读高设阈值，低于阈值只留剪影、灯泡与一处识别标记 |
| 性能 | 单帧透明层 ≤8，远离镜头 12 格降为雾透，低端机只留 L1 与 L4 |
| 廉价感把控 | 塑料只许齿轮帮用，廉价感靠合模线与流痕这类精确细节建立 |

## 十一、验收清单

1. 三个单位各有至少一个不透明件（电池仓／马达／玻璃眼／木托盘）并支撑朝向判断；
2. 外壳落在半透档 72–80%，有流痕与合模线，不含做旧污渍（琥珀油与木托盘为登记例外）；
3. 铆钉与秤在 34 px、去色后仍可区分；
4. 灯泡与光环闪烁 ≤3 Hz，内发光不遮挡能量、基地生命、漏怪计数与卡面数字；
5. 修复持续 6s 与路障存在 15s 是模型上的刻度，不只是卡面文字。
