## 一、为什么用 SVG

| 维度 | SVG（本目录） | PNG / JPG |
| --- | --- | --- |
| 存储形式 | **纯文本**，可 diff、可 review、可手改一行颜色 | 二进制，改一个色要重画 |
| 缩放 | 矢量，任意尺寸不糊（手机到海报同一份） | 放大即糊，需多份导出 |
| 体积 | 每张 4–9 KB | 每张 50–180 KB |
| 与文档联动 | 颜色/数值可直接对着配方文档改 | 无法追溯 |
| 生成方式 | 可用脚本批量生成（本目录即如此） | 需图像库或设计工具 |
| 导出 | 可一键转 PNG / PDF（见下） | 只能再压 |

结论：**过程稿、规范图、卡面版式、图标、地图示意一律用 SVG**；需要发群、发社媒、给外部看时再导出 PNG。位图只在"画光影细节的最终美术稿"时才必需。

## 三、怎么用

- **看**：浏览器直接打开 `.svg`；或看 `PNG预览/` 里的同名 PNG；在编辑器/IDE 里也能预览。
- **改**：SVG 是文本，改一个十六进制值就换色；改 `viewBox` 数字就换尺寸。
- **导出位图**（本机已装 librsvg）：

```bash
rsvg-convert -w 900 01_xxx.svg -o 01_xxx.png      # 定宽 PNG
rsvg-convert -w 2048 01_xxx.svg -o 01_xxx@2x.png  # 2 倍图
rsvg-convert -f pdf 01_xxx.svg -o 01_xxx.pdf      # 转 PDF（矢量）
```

- **再生成整套**：本目录的 SVG 由脚本生成（Python 拼接模板 + defs），改脚本后批量重跑即可保持风格一致。

## 四、约定

1. 画布 512×512（卡面为 512×512 内嵌 400×452 卡框），左上有标题、左下有两行出处水印；
2. 字体写 `PingFang SC, Noto Sans SC, sans-serif`，缺失时回退系统无衬线；
3. 颜色一律取自 [00_美术总纲_基调与色板](../00_美术总纲_基调与色板.md) 的 16 色全局色板，不得即兴加色；
4. 图内出现的数值（费用、伤害、攻速、护盾、层数等）必须能在策划文档里查到，**图不能创造数值**；
5. 这些是**样例/规范示意**，不是最终美术稿：它们用于对齐结构、配色与信息层级。
