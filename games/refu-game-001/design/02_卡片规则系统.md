# 02 · 卡片规则系统（全卷核心）

> 卡面：用途＝定义"卡"与组合规则，全卷一切系统引用本文件 ｜ 依赖：[00_决策记录](00_决策记录.md) ｜ 状态：v0.1 · 2026-09-14

## 一、卡的最小契约

任何一张卡都包含三层、九个字段，缺一不可：

| 层 | 字段 | 说明 |
| --- | --- | --- |
| 卡面层（玩家读） | 名称 / 图标 / 费用 / 关键词 / 一句话效果 | 小屏只显示前三个数字与一个关键词 |
| 规则层（引擎读） | 类型 / 槽位 / 数值块 / 事件钩子 | 引擎只认这四项，杜绝隐式依赖 |
| 叙事层（美术/文案） | 归属 / 风味文本 / 视觉标签 | 可整块替换而不影响规则 |

## 二、七类卡

地图卡、波次卡、事件卡、塔卡、单位卡（含召唤/支援）、技能卡、**规则卡**。
前六类组成一局的内容；**规则卡**定义"这局按什么玩法进行"——这是未来融合玩法的唯一接口（见 [09_路线图与融合玩法](09_路线图与融合玩法.md)）。

## 三、槽位（Socket）＝唯一接口

- 塔位槽：放塔卡；支援槽：放从族支援卡；修饰槽：挂修饰卡（改数值或行为）；事件槽：地图卡预留，放事件卡；
- 规则：**卡不能做它槽位没声明的事**。想扩展，就加槽位或加插槽型卡，而不是给旧卡打补丁。

## 四、组合四法则

1. **叠加**：同槽位多张修饰卡叠加，按声明顺序结算；
2. **替换**：升级/变体卡替换原卡，旧卡回收；
3. **连锁**：满足触发条件时，事件钩子按链式调用；
4. **羁绊**：同标签卡达到阈值（建议 3）触发套装效果——这是"卡片融合感"的主要来源。

## 五、高内聚松耦合五律

1. 单一职责：一张卡只做一件事；
2. 显式接口：只通过槽位、标签、事件钩子交互；
3. 无隐式依赖：删掉任意一张卡，其余卡仍能自洽运行（remove-safe）；
4. 独立可平衡：数值块独立，改一张卡不影响他人；
5. 可无痛移除：下线的内容不留下"孤儿机制"。

## 六、验证方式（设计期自检）

任一新卡入库前，问四句：**它属于哪一类？放哪个槽？删掉它谁受影响？和谁成羁绊？** 四问答不清，卡就不合格。
