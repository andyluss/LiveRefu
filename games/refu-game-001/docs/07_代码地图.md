## 三、`core/battle/` 里的 41 个文件按职责分四组

| 组 | 文件 | 说明 |
| --- | --- | --- |
| **状态与门面** | `battle_state.gd`、`battle_internals.gd`、`battle_api.gd` | 状态字段 / 内部记账 / 只读查询门面 |
| **装配与循环** | `battle_setup.gd`、`battle_world.gd`、`battle_challenges.gd`、`battle_loop.gd`、`battle_cleanup.gd` | 开局的四件套装配、路径与地形场、挑战卡修正、每帧调度、收尾清理 |
| **流程** | `battle_energy.gd`、`battle_spawn.gd`、`battle_waves.gd`、`battle_wave_end.gd`、`battle_rating.gd` | 能量、出兵、波次与调度、波末与胜负、结算 |
| **交战** | `battle_fields.gd`、`battle_stats*.gd`、`battle_targeting.gd`、`battle_towers.gd`、`battle_tower_fire.gd`、`battle_projectiles.gd`、`battle_damage.gd`、`battle_enemies.gd`、`battle_blocking.gd`、`battle_fort_attack.gd`、`battle_destroy.gd` | 场结算、属性管线、选靶、开火、弹道、伤害、敌人行为、退场 |
| **卡片规则** | `battle_placement.gd`、`battle_place_*.gd`、`battle_skills.gd`、`battle_effects.gd`、`battle_effect_*.gd`、`battle_scope.gd`、`battle_bonds.gd` | 放置与落位、技能与回收、钩子解释器与各类 op、标签范围、羁绊 |
| **查询与反馈** | `battle_queries.gd`、`battle_ui_queries.gd`、`battle_feedback.gd` | 查表、界面派生查询、飘字与日志 |

## 四、调用方向（单向，别反向）

```
app/ 界面  ──读状态/调命令──▶  Battle（core/battle.gd）
view/ 绘制 ──读状态────────▶  Battle / BattleState
tools/ 验收 ──驱动─────────▶  Battle + AutoPlayer
        ▲
        └── 全部经 autoload 门面 GameData / AppState 读数据
```

规则：`core/` **不 import `view/` 与 `app/`**（否则无头验收就废了）。
`view/` 只读不写；`app/` 才允许调用命令（`place_card` / `cast_card` / `sell_tower` / `pick_draw`）。
