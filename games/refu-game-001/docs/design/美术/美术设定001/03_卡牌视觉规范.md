## 一、七类卡的卡面骨架

所有卡共用同一外框与信息带，只改中部主图与底部标识。

| 类型 | 顶部带 | 中部主图 | 底部带 |
| --- | --- | --- | --- |
| 地图卡 | 入口数图标 | 俯视图，四角小字给塔位数 | 地形图标：高台、沼泽、腐蚀地、共鸣石、虚空 |
| 波次卡 | 波次序号 | 三格敌人剪影条 | 威胁值数字，见 [数值/04](../../数值/04_敌人数值与波次威胁值.md) |
| 事件卡 | 触发条件图标 | 环境主图：沙暴、断电、酸雨 | 时长与作用格数 |
| 塔卡 | 费用 | 塔身立绘 | 标签色条与关键词 |
| 单位卡 | 费用 | 单位立绘，含支援与召唤 | 人口占用图标 |
| 技能卡 | 费用 | 效果符号 | 持续秒数与范围 |
| 规则卡 | 模式图标 | 全幅边框加模式示意 | 被禁用或被替换的卡类图标 |

卡面层只承担一眼可读，细节进长按详情；卡背统一磁带棕纸图折痕。

## 二、三层九字段如何落到可见信息

| 层 | 字段 | 可见位置与形态 |
| --- | --- | --- |
| 卡面层 | 名称 | 顶部左对齐，两行以内，超出省略 |
| 卡面层 | 图标 | 顶部右侧的族徽或类型图标 |
| 卡面层 | 费用 | **数字一**，左上黄铜圆牌，CRT 绿字 |
| 卡面层 | 关键词 | 底部标签色条上的短词 |
| 卡面层 | 一句话效果 | 小字一行，有余量时显示，可折叠 |
| 规则层 | 类型 | 卡框顶边的形状缺口，七类七种 |
| 规则层 | 槽位 | 底部色带，颜色即槽位色 |
| 规则层 | 数值块 | **数字二**右上为主数值，**数字三**右下为次数值 |
| 规则层 | 事件钩子 | 只在长按详情内以图标短句呈现 |
| 叙事层 | 归属／风味文本／视觉标签 | 二级说明页整页呈现，可整块换 |

数字取法随类型固定：塔卡为费用、伤害、攻速；单位卡为费用、生命、人口；技能卡为费用、效果值、秒数；地图卡为费用、标准塔位数、事件槽数；波次卡为波次序号、威胁值、原型数；事件卡为费用、时长、格数；规则卡为费用、上限项数、被禁卡类数。位数上限三位，超出用缩写，全值进长按详情。

## 三、槽位色与标签色

槽位色走底部色带，标签色走标签条，两者不得互用。

| 槽位 | 色值 | 说明 |
| --- | --- | --- |
| 标准槽（塔位） | `#7C9DB8` | 钢蓝亮，取铁砧高光 |
| 支援槽 | `#63C08A` | 修补绿，标注稀缺度 |
| 修饰槽 | `#8E7BD6` | 光谱紫，与永久修饰同源 |
| 路径槽 | `#C7A46B` | 沙尘土黄，贴地语义 |
| 事件槽 | `#D8452B` | 警示橙红，唯一危险色 |

| 标签 | 色值 | 字形缺口 |
| --- | --- | --- |
| 弹药 | `#C98A3C` | 上缘方缺口 |
| 工事 | `#6B7C8C` | 上缘双缺口 |
| 维修 | `#63C08A` | 上缘十字 |
| 腐蚀 | `#8FBF3F` | 下缘滴状 |
| 孵化 | `#D9B96A` | 下缘圆缺口 |
| 拦截 | `#5E6FA8` | 左缘竖缺口 |
| 能量 | `#6FD3E0` | 右缘尖缺口 |

标签一律"色加形"双编码（[07_移动端与界面](../../07_移动端与界面.md)）：色弱玩家靠字形缺口识别标签，靠剪影识别族属。十条标签中护盾最亮、穿甲最暗，标签条按亮度排序。

## 四、稀有度、解锁态、挑战章与永久修饰

| 状态 | 表现 |
| --- | --- |
| 常规 | 单线纸边 |
| 精良 | 双线铜边，铜包角 |
| 稀有 | 三线银边，包角铆钉 |
| 棱彩 | 光谱渐变边，包角金线 |
| 未解锁 | 整体灰度加磁带条纹，右下留缺口锁位 |
| 已解锁未升级 | 常规显示，右下空心三角 |
| 已升级 | 右下实心三角，卡面加一道斜刻痕 |
| 挑战卡 | 叠沙尘滤镜与橙红斜纹，等级刻在黄铜圆章上 |
| 永久修饰 PMOD | 顶部磁带棕标签带，右上打"永久"孔位 |

稀有度只改边框包角，不改数值块与卡面骨架。挑战卡难度章按等级 1 至 3 刻点，单局最多带 3 张、等级合计不超过 6，侧栏六格刻度条显示已用等级（[13_卡表_挑战卡样例](../../13_卡表_挑战卡样例.md)）。PMOD 的"本局有效"用磁带卷轴进度环表示叠层，如 PMOD-01 可叠 3 便有三格刻度（[23_规则卡组_Roguelike远征](../../23_规则卡组_Roguelike远征.md)）。二者形状编码不同：挑战卡覆沙，PMOD 贴磁带标签，色弱也能分辨。

## 五、可读性红线

| 红线 | 要求 |
| --- | --- |
| 色弱 | 禁止以红绿区分敌我，禁止单色区分十条标签，状态必须色加形双编码 |
| 光晕 | 辉光不透明度上限 40% 且在数值层之下，数字区留纯色底衬 |
| 对比度 | 数字与底衬对比度不低于 4.5 比 1，户外不低于 7 比 1 |
| 最小字号 | 4.7 英寸屏（1080 宽）上，卡面数字不小于 12pt，关键词不小于 10pt，长按详情正文不小于 11pt |
| 触控 | 触控目标不小于 9mm，卡间隔 2mm 以上，禁止精确小目标 |
| 动效 | 不用景深与动态模糊，信息以卡面与槽位高亮呈现 |
| 像素密度 | 立绘按 3 倍出图，1.5 倍机型只降纹理，不降字号与描边 |

自检：取一张卡做灰度化、缩到 4.7 英寸实机尺寸、再做红绿盲模拟，三关都过才算达标。
