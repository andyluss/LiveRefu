# 02 · 视觉识别：三从族

> 卡面：用途＝齿轮帮、孢子侍从、光尘侍从的形态、比例、动作与落场动画 ｜ 依赖：[03_种族总览](../../03_种族总览.md)（D4）、[00_美术总纲_基调与色板](00_美术总纲_基调与色板.md)、[01_视觉识别_三主族](01_视觉识别_三主族.md) ｜ 状态：v0.1 · 2026-09-14
> 前提：三从族**只以支援卡与召唤卡形态**进入主族卡池，不单独成阵营，因此美术上必须始终"低于并依附于"主族单位。

## 一、共同口径

| 口径 | 规则 |
| --- | --- |
| 比例基准 | 主族塔高记为 1.0，从族整体落在 0.15 至 0.55 之间，单卡不得高于主族塔顶 |
| 视线关系 | 从族站在主族的脚下或身侧，不抢塔的射界，也不遮塔的关键结构 |
| 色彩从属 | 从族取主族色板并降饱和一档，点缀色可自持，但主色必须能读出所属主族 |
| 存在感 | 从族不做常驻大剪影，靠动作与粒子被注意到，而不是靠体量 |
| 数量感 | 从族可成群出现，成群时单体进一步缩小，避免总量压过主族 |

## 二、齿轮帮（铁砧联邦从族）

形态关键词：折叠腿、铜壳、木托盘、玻璃眼。铜壳不是纯装饰，壳上的凹痕与掉漆记录它被用过多少次；玻璃眼是一枚凸透镜片，随动作调整焦距，是所有齿轮帮唯一的高光点。

| 项目 | 规格 |
| --- | --- |
| 比例对照 | 常规小工 0.45 至 0.55（相对主族塔 1.0），路障小队 0.5，搬运工的托盘宽 0.6 |
| 结构 | 头身一体，折叠腿三节，双肩有挂钩，背后背工具 |
| 材质 | 铜壳加合成材料关节，腿部液压杆外露 |
| 动作语汇 | 小步快走、关节咔哒、折叠腿收放；维修时仰头举油壶，搬运时躬身用肩扛 |
| 主从关系 | 塔位属于主族，齿轮帮在塔基与路径之间穿行；主族塔射界前方 1 格内不得站定 |

**支援卡落场**：卡面先亮起黄铜触点，小工从折叠状态展开，约 0.25 秒后站定敬一次礼，再进入循环动作。维修工落场时头顶维修灯闪三下，搬运工落场时托盘先着地再竖起身体。

## 三、孢子侍从（涌潮虫群从族）

形态关键词：菌丝、孢子囊、湿膜。它没有固定身高，也没有手足，一切以"团"和"网"为单位；湿膜是它的皮肤，孢囊是它的心脏，菌丝是它的手。

| 项目 | 规格 |
| --- | --- |
| 比例对照 | 团状体直径 0.3 至 0.5（相对主族塔 1.0），菌毯为贴地薄层，厚度不超过 0.05 |
| 结构 | 主体是一枚鼓起半透的孢囊，底部伸出菌丝，顶部留一道裂口 |
| 材质 | 生物质湿膜，囊内可见絮状物，裂口边缘带干壳的纸纤维感 |
| 动作语汇 | 呼吸式胀缩、菌丝缓慢蔓延、孢子向上弹射；不做拟人行走，也不使用工具 |
| 主从关系 | 贴地或贴附塔身，永不超过主族单位的中线，颜色整体压暗一档 |

**支援卡落场**：落点先起一圈菌丝环，再扩散孢子雾，最后孢囊鼓起定形。若该卡带腐蚀或孵化标签，落点地面留下对应颜色的短暂渍痕，渍痕不得遮住路径描边。

## 四、光尘侍从（星辉议会从族）

形态关键词：棱面映字、悬浮碎片。它由若干棱面碎片组成，碎片表面滚动着看不懂的短句或数字，作为"光尘正在读数"的视觉暗示。

| 项目 | 规格 |
| --- | --- |
| 比例对照 | 单片碎片 0.15 至 0.25（相对主族塔 1.0），成群时散布直径不超过 0.8 |
| 结构 | 三至七枚棱面碎片，绕一个看不见的核心缓慢公转 |
| 材质 | 玻璃棱面加极细金线，投影极淡或不作投影 |
| 动作语汇 | 缓慢自转、绕塔公转，碎片对齐时短暂连成一条光路 |
| 主从关系 | 悬浮在主族塔的上方与间隙，光芒不得覆盖卡面层数字所在的界面区域 |

**支援卡落场**：卡面先碎成棱片，棱片沿一条光路汇聚，最后环成一顶小棱冠停住。护盾类落场时棱冠外再套一层六边形薄壳，共鸣类落场时与最近的塔位拉出一条瞬时白线。

## 五、同框与落场动画总则

| 项目 | 规则 |
| --- | --- |
| 主从层级 | 同框时以体量、饱和度、投影三层拉开：主族体量大、饱和高、投影清晰，从族体量小、饱和低一档、投影变淡或省略 |
| 动画时长 | 单张支援卡落场 0.4 至 0.6 秒，2 倍速下按比例压缩，不因加速而丢失落点提示 |
| 并发上限 | 同一瞬间最多两张支援卡落场，超出则排队，避免遮挡战场读数 |
| 信息优先 | 落场动画一律位于数值层与血条层之下，任何粒子不得越过卡面的三个数字 |
| 色弱兜底 | 三从族各有独立形状语言（折叠腿、菌丝环、棱面群），不依赖颜色也能区分归属 |
| 阵亡与回收 | 从族离场只做收缩与淡出，不做大型爆散，避免和敌方死亡特效混淆 |
