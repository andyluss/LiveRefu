# 第 03 章 教官的火线换装

> 卷一《卡匣新兵》 ｜ 第 03 章 ｜ 2026-09-14

复盘室在哨站最底下，墙皮鼓起来一块，风从通风口进来，把沙落在机器顶上，积成一条细线。谢临把磁带推进右屏的槽，卷轴转了半圈才咬住。

控制台边沿用胶布贴着一张裁下来的纸，上面写着一个名字。那是她上一轮漏掉的那只，唐砺让她写下来贴在这儿。她每次坐下都会看见它，看得太多次，名字已经不太像名字，倒像卡面上的一行小字。

这是第七盘。前面六盘她跳着看完了，看唐砺怎么起手，怎么把能量攒到二十才放第一座塔，怎么在波间结算的那几秒里决定下一张卡。铅笔在纸角记钝了，她就在水泥地上磨一磨。

第七盘标签上写着一个旧日期，地图是峡谷哨站，就是她现在坐着的这张图。她按下播放。

屏幕先亮起一片绿。`MAP-ANV-01`，`入口 1`，`塔位 标准 8 / 支援 3 / 修饰 1`，`路径 约 40s`。左屏的绿字一行一行往上爬，像有人拿磷火在里面写字。录像里的哨站比她见过的旧，霓虹管只亮半截，粉色的光落在沙上，沙像悬着的铁锈。唐砺的背影站在控制台前，比现在瘦，护目镜推在额头上，镜片还没磨出那道白痕。

首波小兵八只。他没在布防期放东西。能量从十点一格一格往上爬，爬到二十，他把模块炮塔按进左侧高台，骨架升起来，液压杆顶开沙土。射程圈因为高台多出百分之十五，正好罩住沼泽后面那截窄口。接着他挂了贫铀弹芯，八点，炮管散热片红了半圈。

谢临在纸上算。模块炮塔伤害十二，配上贫铀弹芯多四分之一，一发十五。攻速从每秒一发掉到零点九发。十五乘零点九，每秒十三点五，比原来高一点五。她在十三点五下面画了一道线。这张纸她折成两半，一半记唐砺的账，一半留给自己。纸很薄，铅笔一划就透到背面。

这一波他打得省。八只小兵一只一只倒，每倒一只账上浮一点。她数着绿字，数到第四波末尾，账上五十二。

第五波来了。装甲四只，精英两只，后面跟着八只小兵。

第一只装甲走进射程。咚。咚。咚。血条掉得很慢。谢临把这一段倒了回去，看第二遍，又看第三遍。画面里唐砺的手在控制台上敲，一下，一下。

然后他拆了那座塔。

卡匣拔出来的时候触点带着余温，绿字报出返还，`+9`。投入二十加八，拿回来九点。塔位空了。谢临的笔停住。在她受过的全部训练里，塔位上的东西只有两种下场，升级，或者被摧毁，没有第三种。

唐砺把模块化基座按上了空塔位。六点。铁壳扣住底座，长出一个新挂点，槽口朝上敞着。绿字里那行小字变了，本塔标签，弹药。他给它加了第二个标签，工事。

账上二十五。交叉火力网要二十八。

谢临往后靠了一下。她知道后面会发生什么，她已经知道答案，可她的手心还是出汗。二十五，二十六，二十七。每一只死在路上的小兵往账上添一点。二十八。

卡匣落进槽位。炮管撤下去，换上来一串短粗的散射管，管口排成扇形。它不再是单体，伤害八，一秒一点二发，打的是小范围。溅起来的沙子是热的。

交叉火力，五点。差五点。谢临往前凑，鼻尖几乎碰到屏幕。她看见一只装甲挥下前肢，桩子身上那层护盾叮地碎成一片光屑。绿字跳出来，`on_shield_break：+5`。他把交叉火力插进修饰口。五点进账，五点燃掉。

然后，火力网那一栏满了。

谢临数了三遍。交叉火力网，搬运工的光环，刚挂上的交叉火力。三张弹药。羁绊亮起来，全场弹药塔攻速加一成。同标签的塔还在互相咬合，交叉火力网每命中一次，同标签攻速再叠百分之二，交叉火力本身一层百分之十五，最多两层。散射管的颜色从暗红烧成橘白，弹幕密得像雨。

六秒之后，第五波结束了。

谢临把带子倒回基座扣上的那一帧，停住。她盯着那个新长出来的挂点看，看了很久。塔还在原来的槽里，位置没动，外壳没换，它只是多了一个标签，就变成了另一张卡能做的事。原来卡不是砌进墙里的砖。卡是插在墙上的。

她伸手去够卡匣箱。箱盖开着，樟脑和黄铜的味往外冒。她把模块化基座抽出来放在掌心里，铁壳是凉的，比别的卡厚半分，指尖一抹就留下一道印。

天快亮的时候唐砺推门进来。他看了一眼屏幕上定格的画面，又看了一眼她脚边那堆写了字的纸。

「你在算什么。」

「算他的账。」谢临说，「拆掉少九点，基座六点，网二十八点，交叉火力五点。前四波他本来可以直接建网，省掉一次拆。」

唐砺没接她这句。他把手放在中屏边上，指节敲了两下，绿字里那行标签跟着闪了闪。

「前四波来的是散兵。」他说，「散兵排着队走，一发一个。网打群，一发八点摊在四只身上，一只两点。你要的是十二点还是两点。」

「可是最后还是要换。」

「最后要换，不代表一开始就要换。」他把袖子往上卷了卷，「卡不是给你用一整局的。卡是给你用一波的。」

谢临在纸上把那道线又描了一遍。她觉得自己懂了。

第二天夜里，哨站照例清一轮旧网漏下来的散兵。波次是熟的那一套，一开到六，敌情她自己背得下来。谢临站在自己的控制台上，柯岭在她右边摊开纸图。他今天话少，只在图上标了两个红圈，一个在入口高台，一个在沼泽后的窄口。

「两边都薄。」他说，「你看着办。」

第三波，四只装甲，前后拉开二十步。

她记得录像里的手法。她把手按在入口高台那座模块炮塔上，拆。返还九点。账上二十四。基座，六点，剩下十八。她等账上跳到二十八，把交叉火力网按进槽位。散射管张开，第一轮弹幕打出去，落在最前面那只装甲身上。

一只两点。

后面三只还在二十步外，排成一条直线，溅射够不着。装甲一格一格往前推，走得不快，可它不掉。她想再挂交叉火力，账上九点，差五点。想放搬运工凑第三张弹药，搬运工要十二点，差三点。支援槽空着，她刚才把能量全花在了基座上。

五张卡里她只凑出两张弹药。火力网那一栏浅浅地亮着，差一张，怎么也不满。

第三只装甲的同伴从侧面绕过去。柯岭喊了一声，声音发紧。她把剩下的九点全砸在门前，只够放一座模块炮塔。塔升起来的时候，两只快速已经贴着它的射程圈外缘跑过去了。

基地生命从二十掉到十八。

结算的绿字一行一行往上吐。谢临站着没动。柯岭想说什么，张了张嘴，又合上。风从通风口进来，把控制台上那张贴着的纸吹起一角，又落下。基地生命的数字停在十八，绿的，很稳，像什么都没发生过。

唐砺是最后才来的。他没看结算屏，先走到她的纸质图前，低头看那条铅笔线。他在图上那个被她拆过的塔位上按了一下指头，然后往上移，移到沼泽后面那截窄口，停住。

那儿有一座旧塔，从头到尾没动过。

「我算错了秒。」谢临说，「换早了，第三波不该换，第五波才该换。弹药也不够，差一张。」

唐砺把手从图上拿开。

「你换的是卡，不是位置。」

他说完就走了。门在身后合上，风又把沙吹进来一条线。

谢临在控制台前坐下来。她把那张纸翻到新的一页，在最上面写了一行字。

每一波的第几秒可以换卡。

写完她想了想，在下面画了一道横线。横线下面空着。她把带子重新推进槽里，倒回第五波，一格一格地数。数到某一帧，她按下暂停，把那个数字抄下来，在前头加了一个问号。

那个数字是十四。
