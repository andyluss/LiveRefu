# 共鸣的间隙

> 短篇 ｜ 族属：星辉议会 ｜ 2026-09-14

棱镜回廊的夜班从一盒磁带开始。

闻昭把校准带推进卡座，机器先咳了两声，才吐出那种介于诵经和心跳之间的调子。三下低，一下高，再四下低——这是回廊地基上三块共鸣石的相位读数。音不对的时候，她就用铅笔在纸图上把线往左挪半格。纸图用旧了，边缘被黄铜触点压出一排浅坑。

"十一波。末波写着精英二，空中五，小兵六。"光尘侍从飘在控制台右侧，声音细得像玻璃在很远的地方碎。

"嗯。"她没抬头。

CRT 屏上，回廊是一条绿得发黑的环。入口在十二点，路径绕内圈整整一周，四十五秒一圈，出口贴着基地。十个标准塔位像十颗钉在环上的铜铆钉，三个支援槽躲在环里，两个修饰槽卡在内圈的两个弯。三块共鸣石在三点、七点、十点——谁挨着它们，谁就多一份共鸣。三点和七点之间被一条虚空隔断，那里画着一道叉。

她在纸图上画线。铅笔从三点那块石头出去，连到旁边的标准位，再绕进内圈的支援槽。她画的是共鸣区，默认一格；今天只画一条线，因为开局的能量只够撑起一条。

"三号位放什么？"光尘问。

三号位在内侧弯道后面，打不到长直道。放一座棱镜哨塔，二十四能量，只覆盖最后九秒；放一座共鸣方尖碑，三十能量，它自己不开火，却给左右相邻的塔各加一成半攻速和一成半射程——而它左边紧贴三点那块共鸣石。

"方尖碑。"她说。

"三号位是长直道的补火口，漏了没人补。"

"我在四号位补。"

这是她第几次这么算了，记不清。她只认一条规矩：能量伤害只认一半护甲。精英护甲八，在星辉的镜片里就是四。棱镜哨塔一发十六，不该被那八点铁壳白白吃掉。铁砧的动能弹打上去要哭，星辉的算得清。

布防期十五秒。三点石头北侧一座哨塔，南侧压一座方尖碑；七点石头西侧一座相位炮台，炮口对着内圈的长直道——蓄力两点五秒，一发四十五，直线穿三个。入口段摆了棱光屏障，给路径上的友方罩一百二十的盾，每波刷新，盾破时反弹十点伤害回去。内圈两个修饰槽，一个挂聚焦棱镜，伤害加两成，射程减一成；她咬了咬牙挂上去，因为长直道不差那点射程。另一个槽空着，等。

支援槽先落一张光尘导引，邻塔射程加一成半，落地时共鸣计数加一点。护盾充能十六能量，扣在手上；视野棱镜十二能量，也扣着。

"共鸣计数三。"光尘报。三点石、方尖碑、光尘导引，相邻成链。计数过二，整组攻速加半成。数字小得可笑，可在这条回廊上，半成攻速就是九秒里多打出来的两发。纸图右下角她写过"谐振"两个字，今天她带够了两张共鸣卡，那条线是活的。

磁带又转了一圈。入口的绿点亮了。

前七波她几乎没动手。空中五只贴着内圈弧线切进来，哨塔的对空口径够得着，两发一只。精英跟在小兵后面，护甲在屏幕上显成一层薄薄的亮边。第八波中段，她把视野棱镜丢进最后一个支援槽，顺手标记了左边那头精英；标记落下，所有塔的准星都往它身上偏了半寸。

也就是那一波，屏障的盾破了。

不是被精英砸破的，是被挤破的。五只空中一起压过来，盾的读数从一百二掉到零，只用了四秒。破的那一瞬，全场棱镜哨塔的攻速跳了一格——盾破加一成攻速，十秒；同时反弹的十点伤害打在最前面那只空中身上，把它从七十削到六十。

然后反噬顺着回廊的铜基座走。纸图上那条线就是"相邻"，而相邻是双向的：增益从方尖碑流出去，震荡也会沿着同一条线回来。三号位那座方尖碑的护盾被震到零，它自己的盾只等护盾矩阵，而那张卡她没舍得挂，槽位留给了聚焦棱镜。

"全场塔盾见底。"光尘说，"方尖碑挨着的那两座也掉了三成。"

护盾充能，十六能量。全场塔护盾加八十，持续十秒。她按下去的时候手不抖，心里在滴血：这十六本来是要留给技能的。方尖碑的盾回到八十，重新上线，链子没断。可能量只剩五十一了。

两头精英并排走进长直道。相位炮台开始蓄力，环形进度条在 CRT 上爬，两点五秒一格；共鸣给它加速，进度条比平时快了一线。空中五只也拐了进来，贴着内圈排成一条斜线——回廊是环，它们为了抄近路全切了内弦，内弦把五只压成了一条直线。

进度条还剩三分之一的时候，左边精英剩两百一十血，右边剩两百四。她手上有两张技能卡。

共鸣过载，十八能量，全场共鸣效果翻倍，持续六秒，落地时共鸣计数加二。时空缓滞，二十能量，全场敌人减速三成，持续五秒，被减速的敌人吃能量伤害多一成。两张加起来三十八，她只剩五十一，够。可放完就只剩十三，方尖碑要三十，哨塔要二十四——什么都补不回来。

"没有标记了。"光尘提醒她。刚才为了腾能量，她已经把视野棱镜拔了下来，那张卡退回卡座，返还的能量刚好补平缺口。标记没了，计数还在三。

"知道。"她说，"自己算。"

穿过内圈的白线只有一次。她得在炮台蓄满的那一瞬，让减速和过载同时压在场上：缓滞早一点，敌人就走不出射程圈；晚一点，左边精英已经拐过弯。她盯着磁带上的校准音，第三下低的、一下高的——内弦比外圈少走七秒。她把手指悬在两张卡上，等那个"高"。

高音响起的同一拍，她连着把两张卡推了下去。声音像有人把两枚硬币按在同一张桌上。

绿色的环暗了一瞬。共鸣过载落地，三点那两座塔的射程圈猛地涨开，把整段长直道卷进来，纸图上那条一格宽的线，在屏幕上宽成了两格；时空缓滞落地，五只空中和两头精英的移动条都慢了三成，像磁带被谁按住了转速。屏幕上所有伤害数字都跳了一下——那一成能量加成，全场能量伤害都吃。

七点，进度条走到头。

那不是一声爆炸，是一道白线。白线沿内圈长直道切过去，穿过左边精英的胸口，擦过它身后跟着的两只空中，再从右边精英的肩甲上刮下一条。穿三是上限，边缘那半只不算。左边精英的读条归零——四百二十，走完了。

"漏了。"光尘说。

两只空中从白线的缝里钻过去。基地生命掉了两点。只剩十三能量，她什么都放不了，只能看着那座哨塔一只一只把它们点掉。

十一波走完。磁带停了。

结算屏亮起来，基地生命九十八。评级的三维里，"组合触发次数"那一栏闪着：共鸣计数峰值五、共鸣过载一次、破盾反噬一次、蓄力精准命中三单位一次。护盾链那一格是灰的——她只带了两张护盾卡，第三张的槽位买了火力。

闻昭把铅笔放下。纸上那条从三点绕到七点的线，她画得偏了半格，正好压在方尖碑的槽上。她伸手擦掉，重画——这次线贴着四号位边缘走，绕开了长直道的空档。方尖碑还在，旁边多留了一个修饰槽的名字：护盾矩阵。另一个槽，她还没想好要不要写共鸣节点。

"下一局，"光尘问，"三号位还放方尖碑吗？"

"放。"她说，"但先给它一张盾。"

磁带弹出来。机器咳了两声，安静下去。
