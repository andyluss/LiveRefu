Game design guide · cards as rules

卡片就是规则，
规则就是世界。

《节点防线》是一款星际式三族对抗的卡片塔防。它最核心的设计不是“卡面好看”，而是：塔、单位、技能、地图、事件、规则，全部用同一套卡规范表达。玩家组的是卡组，打的是一套被卡组织起来的世界。

The loop

一局，五分钟

日常碎片关 3–5 分钟；周常长局 20+ 波。玩家不操作单位走位，只做“放卡与调度”。

01 / CHOOSE
选关地图、波次、挑战卡；选难度代价与额外奖励。
02 / BUILD
组卡主族骨架 + 从族支援 + 中立卡；受人口与中立比例限制。
03 / DEPLOY
布防15 秒布防期；把塔卡放进塔位，准备首波。
04 / DEFEND
交战6–8 波；能量增长、击杀返还、波间三选一调度。
05 / SETTLE
结算评级三维：基地生命、能量效率、组合触发次数。

不是“点技能打赢”

没有英雄微操；胜负来自放什么、放哪里、什么时候换、如何组合。

不是“数值堆塔”

评级鼓励组合触发，挑战卡把难度变成自选代价，而不是单纯加血。

不是“只有 UI 是卡”

地图、波次、事件、规则都是卡；玩法扩展靠换规则卡组。

规则层

让引擎不需要猜；删除任意一张卡，其余卡仍能自洽运行。

Seven kinds

七类卡，一套槽位

CONTENT

地图卡

出生点、固定路径、基地、塔位、地形。地图不是背景，是规则。

CONTENT

波次卡

敌人出场顺序、间隔、路线与预算；WAV-ANV-A 的 B=158 是基准。

CONTENT

事件卡

沙暴、断电等战场条件；可以由规则卡禁用。

BATTLE

塔卡

放入塔位即生效；升级是替换为高阶卡，拆除返还部分能量。

BATTLE

单位卡

召唤到路径或支援槽，负责拦截、输出或辅助。

BATTLE

技能卡

一次性或持续，消耗能量，用于救场与节奏调整。

META

规则卡

定义“这局按什么玩法进行”：资源、胜利条件、禁用卡类。融合玩法的唯一接口。

SOCKET

槽位 = 接口

塔位、支援槽、修饰槽、事件槽。卡不能做它槽位没声明的事；扩展靠加槽位，不靠给旧卡打补丁。

COMBO

组合四法则

叠加、替换、连锁、羁绊；同标签达到阈值触发套装效果。

Three main · three kin

三主族，各带一个小跟班

主族是骨架，从族是只以支援/召唤卡进入该族卡池的特色插件；互克通过机制，不靠单纯数值。

ANVIL COMPACT / 铁砧联邦

人系 · 工事与后勤

模块化工事、机动换位、火力网、弹药切换。

专属：模块换装
局内替换修饰卡，改变同一座塔的职能。
从族 · 齿轮帮 / 维修、搬运、临时路障
TIDE SWARM / 涌潮虫群

虫系 · 数量与进化

铺场、孵化、腐蚀地带、廉价海量。

专属：进化枝
满足条件后，单位卡“替换”为高阶变体。
从族 · 孢子侍从 / 菌毯、孵化加速、腐蚀附着
ASTRAL CONCLAVE / 星辉议会

星灵系 · 护盾与共鸣

护盾充能、精准打击、能量导引、少而强。

专属：共鸣
相邻塔位形成共鸣区，共享部分增益。
从族 · 光尘侍从 / 护盾、视野、能量导引

Battle grammar

局内只做三件事

放卡

能量来自自动增长与击杀返还；人口限制同时存在的单位；塔位决定射程与路径关系。

换卡

升级替换、修饰挂载、技能救场；组合触发比单卡强度更重要。

调度

每波结束 +1 调度点，三选一；决定下一波是补输出、补控制还是补经济。

状态 / 规则作用设计意图
对空部分塔只能打地面，部分可对空让“放哪里”与“放什么”同时成为问题
腐蚀 / 减速 / 护盾持续伤害、移动控制、吸收伤害用状态而不是纯数值制造组合空间
羁绊同标签达到阈值触发套装“卡片融合感”的主要来源
挑战卡局前 1–3 张自选难度修饰难度轴与玩法轴正交；高分靠自选代价
