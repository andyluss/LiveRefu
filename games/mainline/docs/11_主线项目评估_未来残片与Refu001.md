## 一、问题

工作区同时存在两个可运行的 Godot 卡片塔防：

- **未来残片 / future-debris**：PC 买断 + Demo，主线纲领的当前候选；
- **Refu Game 001 / 节点防线**：手机竖屏卡片塔防，已有一个可玩垂直切片和大量设计资产。

问题不是“哪个设计更好”，而是：

> **哪一个更适合作为接下来一段时间的工作区主线项目？**

主线的定义不是“最有创意”，而是同时满足：

1. 能形成可验证的商业闭环；
2. 已经有足够可玩的内容证明核心循环；
3. 有可持续的内容/美术/工程产能；
4. 风险可以被拆成阶段门槛，而不是一次性赌注。

## 二、结论

**建议继续以《未来残片》作为当前主线项目。**

**Refu Game 001 保留为第二轨预研 / 设计实验室，不在现在切换主线。**

更准确地说：

- 未来残片是“**现在就能被做成产品**”的项目；
- Refu 是“**设计密度很高、未来可能更有趣，但当前完成度还不足以承担主线**”的项目。

这不是对 Refu 设计质量的否定；它只是还没有完成从“设计卷 + 垂直切片”到“可发行产品”的跨越。

## 四、为什么未来残片更适合主线

### 1. 已经跨过“能不能做出来”的门槛

未来残片不是只有一个概念或演示，而是已经有：

- 一局完整闭环：选关 → 战斗 → 结算 → 存档；
- 120 张卡、16 关 / 8 章、4 势力、11 条规则卡；
- 数据契约、视觉 token、主题落地、无头自检、玩法行为验收；
- PC 买断、免费 Demo、商店页素材与发行节奏。

这意味着它剩下的主要是**质量、内容与市场验证**，而不是从零证明工程可行性。

### 2. 机制和主题是同一件事

“电力越强，残渣越多；残渣留在地图上，最后可能反噬你。”

这是玩法、叙事与美术共享的一套核心矛盾。对主线项目来说，这种“机制即主题”的强度，比单纯增加卡牌数量更容易形成记忆点。

### 3. 有明确的商业容器

PC 买断 $19.99 + 免费 Demo + 章节/纪元扩展，是一个可被定价、可被验证、可被发行节奏承接的容器。

Refu 的设计也有潜力，但目前没有同等清晰的商业容器。

## 五、为什么不是现在的 Refu

Refu 的设计质量不低，甚至在部分维度更强：

- “卡片即规则”的系统比普通塔防更彻底；
- 三主族 + 三从族、进化枝、共鸣，有更强的构筑空间；
- 36 张卡面、6 张地图、两套美术方案、40 章故事，创作密度很高。

但作为**主线**，它现在的问题是：

1. 只有 **1/3 的主族**真正可玩；
2. 只有 **1 张地图、6 波**；
3. 其余 24 张卡、5 张地图、事件卡、进化枝、共鸣计数尚未实现；
4. 两套美术方向还没有最终裁决；
5. 移动端商业模型没有像未来残片那样形成可执行的发行证据；
6. 设计文档和故事体量已经很大，但“可玩内容”没有同步跟上。

它更像一个**高潜力的设计实验室**，而不是当前就能承担主线商业目标的项目。

## 六、建议的主线策略

### 主线：未来残片

把未来残片锁定为主线，并设置一个明确的人类试玩门槛：

- 10–15 名外部玩家试玩；
- 观察完成率、复玩意愿、对“残渣”机制的理解；
- 用试玩结果决定继续加内容还是收缩范围；
- 在门槛通过前，不继续无上限扩卡。

通过后，再进入正式内容与美术生产。

### 第二轨：Refu 作为预研

不建议直接 archive，也不建议现在投入主线级资源。建议保留为小预算预研：

- 目标不是“再做一个完整游戏”，而是验证三族构筑是否真的有趣；
- 最小门槛：三族可玩、6 张地图、20+ 卡、一次 15 分钟外部试玩；
- 在达到门槛前，不争夺主线资源；
- 卡牌系统、美术、故事作为独立资产保留。

### 资源分配

```text
未来残片  80%：主线冲刺、试玩、内容/美术
Refu 001   20%：有限预研，或暂时冻结
```

不要两个项目同时按主线规模推进。两个都做“完整版”的结果，通常不是两个都成功，而是两个都延期。

## 七、什么情况下应该改判

只有在以下条件同时出现时，才值得把主线切到 Refu：

1. 未来残片的外部试玩明确失败：玩家不理解核心机制，或完成后没有复玩意愿；
2. Refu 已经达到三族可玩、6 张地图、20+ 卡的完整垂直切片；
3. Refu 有外部试玩证据，而不只是设计文档；
4. Refu 的商业模型和平台策略已经明确；
5. 切换不会破坏未来残片已有的资产与发行窗口。

否则，**因为“Refu 的设计更酷”而切换主线，风险大于收益**。
