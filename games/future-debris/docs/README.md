## 二、目录角色

```text
docs/
├── planning/       # 项目为什么、往哪走（从 mainline 迁入）
├── spec/           # 玩法/商业化/发行/试玩设计
├── discussions/    # 讨论留痕
├── shots/ video/   # 运行截图与录像
├── style-samples/  # 视觉样张
└── 01–11_*.md      # 实现裁决、工程、数据、视觉、规则、关卡、表现、卡池
```

- `planning/` 是**项目级规划**，不复制 mainline 的跨项目决策；
- `spec/` 是**做什么**，实现文档是**怎么做**；
- 讨论记录保留原判断，不删不改；裁决补在原文，不另起炉灶。
