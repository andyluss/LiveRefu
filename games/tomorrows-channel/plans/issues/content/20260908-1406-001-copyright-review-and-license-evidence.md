# 问题：内容卡版权逐张复核未完成 + 个别授权凭证/载体待定

> 状态：**open**（未解，待主策划复核 + 主程序给凭证载体；M1 默认谨慎不入池）
> 发现：2026-09-08 14:06 · 发现人：主策划（版权 taxonomy）
> 类型：content · 优先级：**高**（合规门禁依赖，防内容管线漏）

## 现象 / 问题描述

版权 taxonomy（[`05_copyright-taxonomy.md`](../../../docs/lead-designer/05_copyright-taxonomy.md) §6）列出多项**逐张/口径级待定**，均落到"具体素材的逐张复核"：

1. **`cc_by` 具体条款是否允许商用**：CC BY 原则上可商用，但部分素材可能有"仅用于非商业/编辑用途"的平台附加条款；须逐张看 `license_url` + `source` 实际条款。**M1 默认谨慎**：未逐张复核前按不可入池处理；
2. **个别素材归属存疑**（如《Floral Shoppe》封面母题替换、作者字段为空的需回源站核补）——主美术 README §四；
3. **`unknown` 素材分类与处置**：建议拒绝入池、保留档案待主美术补证；
4. **授权合同（`licensed`）的凭证载体**：单独授权素材需授权凭证承载（沿用 `data/`？是否需 `licenses/` 子目录存合同）——程序侧需给落位；
5. **`license_url` 是否改为"凭证附件 + 链接"双承载**：部分授权无公开 URL，需支持 `license_url` 或本地凭证路径二选一。

> 注： **`cc_by_sa` 同构外溢**问题已在开发计划 §七 决策记录③ 定案（CC BY-SA 仅作 moodboard 参考、不入正式资产，规避同构外溢），本节不再列为未决；版权字段结构分歧另见 `technical-001`（勿重复）。

## 影响 / 卡点

- 内容卡入池门禁（`status→approved`）依赖逐张复核；未复核来源一律不得入池，否则内容卡池无法铺量；
- 程序侧"防漏发"合规闸门（schema 校验 + CI）需要明确的 `license` 枚举与凭证载体才能落地；
- 影响 M1 收藏 1 卡（出口标准 #4）与内容管线铺量。

## 尝试 / 参考

- 主策划 taxonomy §2 字段规范、§3.4 入池门禁、§6 待定表；
- 主程序 [`04_response-gdd.md`](../../../docs/lead-programmer/04_response-gdd.md) §3：内容版权由"法律风险"转"工程合规闸门"（强制版权字段 + schema 校验 + CI；法律判定责任在主策划）。

## 解决方向 / 需求

- **主策划**：确定逐张复核的责任归属与流程（含 CC BY 商用条款、归属存疑素材回源）；给出 `ml_unknown`/`cc_by` 的入池裁决规则；
- **主程序**：给授权凭证载体（`licenses/` 目录 / 本地凭证路径双承载）一个落位，纳入技术-006 schema；
- **主美术**：素材库复用走统一 `copyright` 登记 + 复核门禁；存疑素材先回源核证。
