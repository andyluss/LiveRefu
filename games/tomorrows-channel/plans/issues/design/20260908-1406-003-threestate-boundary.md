# 问题：三态边界不一致（M1 验收#3「三态可切」vs 会议意见「设置/图鉴后置 M3」）

> 状态：**resolved**（已定策，引用 `00-project-plan.md` 决策记录②）
> 发现：2026-09-08 14:06 · 发现人：UI 设计美术 A（主策划拍板）
> 类型：design · 优先级：中（本项已解）

## 现象 / 问题描述

M1 三态边界存在两处口径差异（[`05_m1-ui-skeleton.md`](../../../docs/ui-artist-a/05_m1-ui-skeleton.md) §八 ⑥）：

- 开发计划 M1 验收口径 #3 写「三态可切换（漫游/专注/设置-图鉴）」；
- 本角色 M1/M2 会议意见 §二 写「设置态、图鉴态后置 M3」。

## 影响 / 卡点

- 若不澄清会在验收口径上产生分歧：M1 是否要做出完整"设置/图鉴"界面，还是仅骨架/极简占位。

## 尝试 / 参考

- UI A 按「骨架三态可切 + 设置/图鉴仅极简占位」落地（`05_` §三 完整度矩阵），既满足"可切"又不为 M1 烧全流程。

## 解决方向 / 需求 → 已定

主策划在开发计划 `00-project-plan.md` §七 决策记录② 拍板：**M1 骨架支持 漫游↔专注 可切、设置/图鉴态后置 M3（只定骨架+占位）**。该边界与 UI 落地口径一致。
