# 问题：M1 磁带基调渲染/视觉参数待收敛（fx_preset 相关）

> 状态：**open**（未解，待主美术/图形/程序确认定稿）
> 发现：2026-09-08 14:06 · 发现人：主美术（图形 A 联动）
> 类型：design · 优先级：**中**（影响 M1 磁带氛围观感与 `fx_preset.json` 收敛）

## 现象 / 问题描述

主美术基线（[`05_m1-tape-baseline.md`](../../../docs/lead-artist/05_m1-tape-baseline.md) §六）给出磁带基调的**可调初值**，但多组视觉/渲染参数仍需主美术 / 图形 A / 程序确认后定稿：

- **P1 暖底 LUT 关键色**（`tape_lut_*`，sRGB 初值，需色彩管理——联动 technical-005）；
- **P2 容器暖光色温**（设备自身 2400K / 台灯 2800K）；
- **P3 暖光强度比 / 辉光半径**（6:4；≈220px @1080p，2D 假辉光）；
- **P6 扫描线 / 微噪强度**（3px / 0.06–0.10；0.03–0.06）；
- **P5 中央窗口区域界定**（圆角 16px、64%×58%、bezel 10–14px——影响 `02_` 裁剪/遮罩）。

收敛前仅为 M1 实现初值；蒸汽波/太空均不纳入本基线（守范围）。

## 影响 / 卡点

- 未定稿则 `data/fx_preset.json` 只能放占位；磁带"灯下接收机"母意象是否"可辨"依赖这些参数；
- 影响 `02_` 资源规格与分层资源命名（容器-信号分层裁剪/遮罩）；
- 影响静默可用验收基图（暖光"基底 vs 动效"边界 P7）。

## 尝试 / 参考

- 主美术基线 §一 (LUT / §二 容器暖光 / §三 中央窗口 / §5.1 占位皮肤)；§六 参数交接表；
- 图形 A [`05_m1-render-slice.md`](../../../docs/graphics-programmer-a/05_m1-render-slice.md) §五"向主美术"（容器暖光量化/中央窗口区域/磁带动效样本/静态回退验收基准）、§七 决策记录。

## 解决方向 / 需求

- **主美术定稿**：暖光色温/强度比/辉光半径、窗口区域、扫描线/微噪强度、静态回退验收基准；
- **程序 + 图形 A**：确认色彩管理（P4）、容器-信号分层执行；收敛入 `data/fx_preset.json`；
- 静态回退验收：交付"动效开/关"两态基准图（对齐 M1 验收 #1）。
