# 问题：动效（后处理）是否覆盖 UI 未定 + 静默可用边界

> 状态：**open**（未解，待图形程序员 A / UI 美术 A / 主程序共定）
> 发现：2026-09-08 14:06 · 发现人：UI 设计美术 A（图形 A 联动）
> 类型：design · 优先级：**高**（M1 启动后最先要对齐的点之一）

## 现象 / 问题描述

扫描线 / 微噪 / 星雾 / 慢色偏等后处理动效**是否覆盖 UI**，以及覆盖时的强度上限，仍未定（[`05_m1-ui-skeleton.md`](../../../docs/ui-artist-a/05_m1-ui-skeleton.md) §八 ③；图形 A [`01_rendering-tech-draft.md`](../../../docs/graphics-programmer-a/01_rendering-tech-draft.md)、[`05_m1-render-slice.md`](../../../docs/graphics-programmer-a/05_m1-render-slice.md) §五）。

主美术基线建议 **窗口内容覆盖、顶栏/边框不覆盖**（[`05_m1-tape-baseline.md`](../../../docs/lead-artist/05_m1-tape-baseline.md) §六 P8）；且"全局关闭动态后频道仍成立"（静默可用）与"结束提醒泛光强度"也需定边界。

## 影响 / 卡点

- 直接影响 UI 字号/对比度/语义色可读性（CRT 覆盖会磨损文字）；GDD §8.8 一句话帮助、§8.3 计时呈现的可读性依赖此边界；
- 影响"静默可用"验收（动效全关后静态基图仍成立）与"结束提醒"呈现方式（免打扰、可关、频道音色）。

## 尝试 / 参考

- 图形 A `01_` §五（CRT 扫描线是否作用于 UI）、`05_m1-render-slice.md` §四（静默可用回退）；
- 主美术 P8 建议（窗口内容盖、顶栏/边框不盖）、P7 暖光"基底 vs 动效"边界；
- UI A 已在骨架层预留"动效全局开关"位（`05_` §八 ⑦）并落"在 CRT/扫描线下可读性已检查"自检项。

## 解决方向 / 需求

- **图形程序员 A + UI 美术 A** 出"动效开/关" UI 层叠约定（窗口内容 vs 顶栏/边框是否覆盖、强度上限）；
- **主程序/主美术** 拍板：静默可用边界、结束提醒泛光强度、可及性底线（对比度）/分级；
- UI A 据此锁定字号/对比度/语义色方案。
