## 三、心得 / 经验

- **口径先行**：跨角色共享的"字段结构/枚举/接口"必须最先定死（如 content_card schema），否则数值/主程序/合规各自为政，M1 中途才发现分歧（本次版权字段即此教训）。
- **并行 agent 需约定边界**：多 agent 共享 git index 会互相 `git add -A` 扫入他人文件；应约定"各 agent 只 add 自己职责路径"，且关键在**内容正确性**而非提交归属（归属可事后拆分）。
- **盘点问题尽早做**：M1 结束就盘点 issues（18 个），把"待验证/未冻结/待确认"显式化，避免散落在各文档【待定】里失控。
