## 二、M1 单频道（磁带暖未来）闭环排期（重点）

### 2.1 目标与验收（策划口径，主程序执行）

验证"氛围陪伴手感"——专注 **25min 不打断**、混音台 **≥2 轨**可用、**收藏 1 卡**、**静默可用**（关动态后静态底图+音景仍成立）。M1 值的是"**闭不闭环**"而非"漂不漂亮"，故用占位资源 + 轻量后处理。

### 2.2 任务拆解与粗估（人日，1 人日 ≈ 1 全工日；来源主程序开发计划会意见 §2.1）

| # | 任务 | 内容 | 估(人日) |
| --- | --- | --- | --- |
| 1 | 工程引导 | Godot 4.7.x 工程初始化、project.godot、目录结构、配置加载管线(JSON→Resource)、GDScript 规范/CI 钩子 | 2–3 |
| 2 | 配置表 schema 落地 | content_card(含版权字段)/channel/timer/mixer_track/collectible 五张表 + schema 校验 + CI 闸门 | 1–2 |
| 3 | 频道装载 | 单频道(磁带) 配置装载：视觉皮肤(色调LUT/背景)+音景+内容池，按"**可插拔 bundle**"抽象 | 2–3 |
| 4 | 氛围播放 | 音景循环起播、音量/预置；影音卡 M1 用静态占位替代 | 1–2 |
| 5 | 番茄计时 | 番茄 25+5、频道皮肤化呈现、结束轻提示(音色+可关闭)、时段小结数据 | 3–4 |

| 8 | 频道滤镜(最小) | 磁带 扫描线/微噪 2D 后处理，可关闭（GDD 静默可用要求） | 2–3 |

| 11 | 集成与自测 | 闭环串通、退出标准自测、macOS/Windows **本地导出自检**（非签名/分发，见 `04_` §1.4，分发 M2 末再启动） | 2–3 |

### 2.3 排期（已回填，不含 M2 并行项）

**合计 ≈ 23–31 人日**。去重并行（UI 骨架与逻辑层、App 壳 spike 与核心循环）后：

- **核心闭环（#1–7、10、11；不含滤镜 #8 与 App 壳 #9）≈ 15–20 人日 ≈ 2–3 周（单人）** —— 对齐 M1 出口标准；
- **全套 M1（含滤镜 #8 + App 壳去风险 #9）≈ 3–4 周（单人）/ 2–2.5 周（双人）**；
- **若人力单薄**：把 #8（滤镜）、#9（App 壳）下移为"**去风险尾插**"，不进出口标准；核心闭环仍须成。

> 结论（与开发计划会一致）：**不建议 M1 单人压到 2 周**；按"核心 2–3 周 / 全套 3–4 周"排期执行。

### 2.4 M1 第一周必锁（最高返工风险，缺一则阻塞）

1. **渲染器选择**（图形 A + 主程序）：默认 Compatibility，双渲染器 2D 后处理对照切片后拍板；
2. **配置表 schema**（数值 A + 主策划）：五张表字段 + 版权字段 + CI 校验；
3. **版权 taxonomy**（主策划）：版权类型取值域（公版/CC0/自产默认入池，CC BY/BY-SA 需复核标记）。

## 三、M2（预告，待 M1 后回填）

- **排序**：磁带 → 太空 → 蒸汽波；蒸汽波素材搜集与小样**并行提前启动**（M2 前段即开始，防拖到后段卡期）。
- **程序侧任务**：频道化架构泛化（单频道→多频道 bundle）、滤镜栈定型（扫描线/星雾/慢色偏）、2D 后处理性能预算落地、内容池批量装载。
- **前置依赖**：M1 的 #3 必须按"**频道 = 可插拔 bundle**"抽象，否则 M2 需重构。
- **待主程序定**：是否每频道切渲染后端（磁带=Compatibility；若太空/蒸汽波可用 2D/Compatibility 实现则单后端最省）。
- **周期粗估**：2–3 周（与 v0.1"1–2 周并行"略松，因含多频道化）。
