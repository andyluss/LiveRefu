## 一句话立场

**M1 用 placeholder 美术——可行**（M1 出口标准是功能、非风格）；但 M1 对应频道恰是"磁带暖未来"，需投**一份最小可辨的"关键氛围"**（灰盒拼贴 + 暖底 LUT + 终端皮肤 + 扫描线一版），以保住"陪伴手感"这个 M1 真正要验的体验。**M2 三频道并列做美术——不合理**，应先定"磁带风格定稿 + 母意象/双层光/资源规格"这条主链，再顺序扩太空、蒸汽波；蒸汽波因**零素材覆盖**必须列为 M2 早期（与磁带定稿并行）的高优先补充，否则卡 M2。

## 一、M1 美术投入（磁带频道最小风格）

- **投入量级**：低。约 **0.25–0.5 周**（主美术本人），不投正式美术资产、不投量产。
- **产出（灰盒 + 关键氛围）**：
  1. **磁带频道一张氛围定调灰盒**（placeholder 拼贴）——用 [`moodboard/方向A_磁带暖未来/`](../../../docs/lead-artist/moodboard/方向A_磁带暖未来/) 现有素材拼一张"琥珀暖底 + 终端边框 + 表盘"的参考，作为 M1/M2 共用的定调基准；
  2. **关键氛围一版**：暖底 LUT + 终端边框（容器"中央窗口"）+ 扫描线/微噪（先静态）、指示灯呼吸 → 交给图形程序员 A 收敛进 `data/fx_preset.json`；
  3. **静态验收基图**：磁带频道"动效关"一态截图标准（对齐 GDD §9 静默可用）。
- **理由**：M1 出口标准 = 专注 25min 不打断 / 混音台可用 / 可收藏 1 卡（功能驱动），所以**纯灰块也可接受**；但 M1 真正要验的是**"陪伴手感"**这一体验，磁带又是 M1 唯一频道——若连"暖未来"的辨识度都没有，体验指标会误判成"题材没钩子"。因此 M1 的 placeholder 应**带温度**，而非无差别灰色占位。
- **边界**：只做磁带一版，**不为太空/蒸汽波做任何正式美术铺路**（避免蔓延）；太空/蒸汽波与全量美术留 M2。

## 二、M2 三频道美术排期意见（先定磁带 → 再扩展）

- **不建议三频道并行做美术**。理由：
  1. **跨频道共用层未定**：母意象容器 / 双层光 / 资源规格（`02_`）是"一主锚 + 同源辅助 ≤20%"纪律与工业化扩频道的前提，必须先立起一个频道把它定住；
  2. **素材覆盖不均**：磁带（17）/ 太空（26）充足、**蒸汽波（0）** → 三频道同时推，蒸汽波必卡 M2；
  3. **UI 皮肤骨架**：需先有磁带的皮肤基准，UI 设计美术 A 才能派生太空/蒸汽波皮肤（区分度靠皮肤、共用骨架）。
- **建议顺序**：① 磁带做**风格定稿**（M2 出口"风格切片"：磁带/太空/蒸汽波各 1 场景达风格定稿）——把 M1 的磁带关键氛围升成正式风格，同时立起母意象容器 + 双层光 + 资源规格；② 再扩**太空**（素材现成，用方向 C 肃穆基调，排除方向 B 乐观感）；③ 最后**蒸汽波**（最晚，因素材要补）。
- **调档建议**：主程序按"1–2 周、可与 M1 并行"排 M2，我建议 **M2 拆两段**：前段 = 磁带定稿 + 共用层（并行 M1 收尾），后段 = 太空 + 蒸汽波——避免把三频道塞进同一周。

## 三、蒸汽波素材缺口排期（高优先、靠前补）

- **别等到做蒸汽波才补**。蒸汽波是零覆盖，且与太空同属紫/品红系，需要**尽早拉大区分度**（太空 = 冷/肃穆/对比强，蒸汽波 = 暖粉/柔光/松弛），供图形程序员 A 收敛色带。
- **动作**（主美术在 M1 间隙完成，不阻塞 M1）：
  1. 新建 **`moodboard/方向D_蒸汽波黄昏/`**（沿用 `.meta.txt` 许可追溯体例）：粉紫大理石雕像、VHS 雪花/磁迹、棕榈剪影/网格地平线、死商场中庭、《Floral Shoppe》**母题**（封面本身有版权 → 以公有领域雕塑照替代）；
  2. 补**"接收机本体"参考**（服务母意象）：30s–70s 老式调谐收音机正面/斜侧面；
  3. 合规：全部走 Wikimedia Commons CC/公有领域，逐张核许可。
- **时点**：**M2 开工前到位**（不阻塞 M1），但**必须早于 M2 太空段**完成，以便"冷肃穆 vs 暖松弛"能在太空段就对比出来。

## 四、对其它角色的依赖（需先对齐什么）

| 角色 | 需先对齐 | 优先级 |
| --- | --- | --- |
| **图形程序员 A** | ① **母意象"容器层 × 频道窗口"区域界定**（接收机中央"屏幕/窗口"的尺寸、位置、圆角/遮罩形状）→ 直接影响 `02_` 资源规格与分层资源命名；② **三频道动效视觉样本**（磁带扫描线密度/微噪强度、太空星雾色调/密度、蒸汽波慢色偏目标色带）+ **静态验收基图** → 供其收敛 `data/fx_preset.json`；③ **sRGB vs 广色域（P3）** 定色值；④ "静默可用"暖光边界（暖光常亮属基底不可关 / 呼吸辉光属可关动效）的验收基准 | ①② 为 M1/M2 前置；③④ 为 M2 |
| **UI 设计美术 A** | ① **"频道即皮肤"分层**：共用交互骨架 + 每频道皮肤（边框/材质/字体倾向），区分度靠皮肤**不重画骨架**；② **母意象接收机 UI 骨架**（旋钮/刻度/spinner）与三态界面（漫游/专注/设置图鉴）共存，不喧宾夺主；③ **动效是否覆盖 UI**（扫描线/慢色偏）→ 影响字号、对比度、语义色（按钮态/警示色）的"动效开/关"层叠约定 | ①② 为 M1（磁带皮肤基准）；③ 为 M2 |

> 图形程序员 A 已给出"双层光"的 **Way A（分层合成，M1 推荐）/ Way B（单 pass 双 LUT，M2 升窗）** 与性能增量（≈0.1–0.3ms，不新增全屏 pass）——**我采纳 Way A 优先**。其所列【待定】中，"执行壳渲染目标（Shader 语言）"与"是否每频道切渲染后端"虽是 M2 开工前置，**属主程序拍板**，我在本意见不越界，只提请主策划汇总。
