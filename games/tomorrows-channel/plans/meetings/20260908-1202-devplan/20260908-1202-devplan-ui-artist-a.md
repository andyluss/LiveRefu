# UI 设计美术 A · 对 M1/M2 UI 投入的会议意见

> UI 设计美术 A · 2026-09-08 12:02 · 类型：开发计划会意见（供定稿参考，非最终决议）
> 输入：GDD §8/§9/§11、M0 评审汇总（`docs/_shared/review-meeting-summary.md`）、主程序 `02_里程碑`、本角色 `01_视觉字体`/`02_组件清单`

## 一、一句话立场

**M1 不做整套正式 UI，也不做裸灰盒——M1 用「最小可用面板 + 磁带本频道的轻量 Token 皮肤」先跑通「频道即皮肤」的骨架与换肤管线；M2 再按 磁带 → 太空 → 蒸汽波 顺序做三套正式频道皮肤，且必须等主美术 Token/色板定稿后才动工。**

> 核心：本产品卖的是「氛围陪伴」，UI 不是点缀而是器物。所以 UI 投入的取舍不是「做不做正式美术」，而是「何时把换肤骨架与 Token 系统钉下来」。骨架一旦在 M1 因灰盒而变形，M2 就是重画不是换肤。

## 二、M1 UI 投入（磁带频道最小 UI 集）

**最小集 = 专注计时 / 混音台 / 收藏动作 三件**，正对应 GDD §11 的 M1 出口（专注 25min 不被打断、混音台可用、可收藏 1 卡）。

- **范围收口**：只做「漫游态 → 专注态」最小切换 + 计时 + 混音 + 收藏；设置态、图鉴态、图鉴全流程一律后置到 M3。
- **placeholder vs 频道皮肤=不是二选一，是「轻量 Token 皮肤」**：
  1. 专注「不打断的手感」很大程度靠计时呈现与降噪表达——纯灰盒虽能过功能，却验证不了本产品最核心的体验钩子；
  2. 但只给磁带频道烧一层薄皮肤（荧光屏色 + 一档边框材质 + 数字终端字体 + 最小面板）成本可控，又恰好在真实频道上验证了「换肤管线」。
- **M1 交付物**＝交互骨架（3 态骨架 + 按钮 3 态 + 焦点态）＋ 磁带频道一组 Token（色/字体/边框/面板）＋ 最小组件；**不做整套润色美术**。

## 三、卡片 / 频道皮肤（M2）

M2 = 风格切片，3 频道各 1 景达风格定稿。**UI 皮肤顺序：磁带 → 太空 → 蒸汽波。**

- **磁带**：M1 默认/专注频道，已有薄皮肤，M2 只需正式化（成本与风险最低）。
- **太空**：与磁带反差最大，先用它钉死「换肤范围 / 对比度上限 / 材质跨度」，防止皮肤串味。
- **蒸汽波**：情绪差异最大（放松/漫游），用它验证「暖而不燥、静而不闷」的下限与降噪/放松呈现。

**与主美术 Token/色板的关系（关键）**：GDD §9 明确频道区分靠 **LUT + 材质 + 动态元素，而非重绘 UI 骨架**。因此三套频道皮肤必须是**同一套 Token/组件系统上的 3 组 Token 集，绝不各自重画**。为此须在 M1→M2 窗口内，由主美术 + 我**一次性定稿中央 Token 系统**——色板、频道 LUT 值、边框/面板材质、字体角色、动效档位，并纳入图形侧「容器暖光 × 频道色」分层规则。三频道皮肤只挂 Token。这既是「频道即皮肤」能便宜的根因，也意味着 M2 皮肤工作**必须等待**主美术 `01_`/`02_` 定稿，不能提前铺开。

## 四、对其它角色的依赖（需先对齐）

| 依赖角色 | 必须先对齐什么 | 为什么 / 卡点 |
| --- | --- | --- |
| **主美术** | ① 磁带频道 Token 色板 + 显示/装饰字体方向；② 「容器暖光 × 频道色」分层下 UI 归属哪一层（信号/中央窗口），边框与面板材质主锚清单；③ 主美术 `02_` 资源规格（命名/尺寸/sRGB/切片） | Token/色板不定，M1 轻量皮肤与 M2 换肤管线都无从落地——**M1 UI 的关键路径**，也是最早要卡的点 |
| **主程序** | ① Godot 下「换肤可行性」：皮肤是**运行时 Token 热切换**还是**预烘焙 UI 主题**；② 字体加载与回退（CJK 小字号抗锯齿、等宽数字 tabular figures、装饰字体版权与回退）；③ 九宫格切片按钮 3 态与组件复用 | 换肤是运行时切换还是烘焙，决定我 Token 系统的组织方式与 M2 成本；字体回退不先验，CRT 小字号下中文可读性会翻车（教训见 `01_`§三） |
| **图形程序员 A** | ① 屏幕后处理（CRT 扫描线/辉光）**是否盖 UI**，若盖给出强度上限；② 「容器暖光」恒亮作基底、UI 是否在其中、动效关闭时 UI 是否保留 | 已在 `01_`§五登记为开放项；直接决定扫描线能压 UI 到什么程度，以及「静默可用」下 UI 的呈现边界 |

> 优先序：**主美术 Token/色板最早且最关键**（同时阻塞 M1 轻量皮肤与 M2 管线）；程序「换肤可行性」、图形「扫描线是否盖 UI」是 M1 启动后最先要对齐的两个点。

## 五、决策记录
