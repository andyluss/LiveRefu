# 数值工作表与调参流程模板（草案 v0.1）

> 数值策划 A · 用途：统一数值工作表样式与调参流程，保证所有数值变更可评审、可回溯、可被主程序直接落地为配置表。

## 一、工作表模板（每张表固定头部）

```
表名：            （与 data/ 配置文件名一致）
版本：            （v0.x → v1.0 冻结）
维护人：          数值策划 A
依赖：            （GDD 章节 / 上游表）
说明：            （这张表驱动什么体验目标）
变更记录：        （日期 | 谁 | 改了什么 | 为什么）
```

## 二、调参流程（闭环）

```
1. 提出调参（来自验算/反馈/新需求）
2. 登记意图（目标体验不变 or 变更）
3. 改表 + 更新版本号
4. 模拟验算（若可）
5. 评审（主策划确认目标未偏离）
6. 冻结（写入变更记录，交主程序生效）
```

每一步都必须有"人/日期/原因"可查。

## 三、数值表约定（与主程序对齐）

1. 表格式：CSV/JSON 由主程序定，本目录维护"人读版"（Markdown 表格）同步；
2. 字段命名：`snake_case`，中文说明放注释列；
3. 禁止魔法数：所有常数进 `meta` 表；
4. 数值一律带单位与上限说明（例：时间=秒，货币=整数）。
