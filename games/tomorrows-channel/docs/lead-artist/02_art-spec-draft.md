# 美术风格规范与资源规格草案（草案 v0.1）

> 主美术 · 2026-09-06 · 状态：待风格方向定稿后细化
> 本文先定"规范的骨架与必填字段"，数值（具体色值、尺寸）待方向定稿回填。

## 一、规范覆盖范围

1. 角色与场景造型语言（比例、剪影、材质语言）
2. 色彩规范（主色/辅色/点缀色/禁忌色）
3. 光照与后处理基调
4. icon 语言与 UI 插画（交 UI 设计美术 A 执行）
5. 动效风格基调（交图形/程序侧评估成本）

## 二、资源规格（必填字段模板）

每类资源登记：命名 / 尺寸（含多平台）/ 格式 / 颜色空间 / 导入设置 / 负责人。

| 字段 | 说明 | 示例（方向 A） |
| --- | --- | --- |
| 命名 | 系统_类型_用途[_变体] | `ui_terminal_frame_01` |
| 分辨率 | 基准 + 上限 | 1080p 基准、4x 上限 |
| 格式 | 原始/压缩 | PNG 原始、ASTC 压缩 |
| 颜色空间 | Linear/sRGB | sRGB（2D 为主） |
| 导入设置 | 滤波、mipmap、九宫格 | 最近邻滤波（保扫描线锐度） |

## 三、资源目录约定（与主程序 01_ 对齐）

```
assets/
├─ art/characters/     # 角色（按场景/阵营子分）
├─ art/environments/   # 场景与道具
├─ art/ui/             # UI（UI 设计美术 A 维护）
├─ art/fx/             # 特效序列/材质
└─ audio/              # 音频（后续增设音效角色时启用）
```

## 四、评审清单（每批美术交付自检）

- [ ] 命名符合规范且唯一
- [ ] 主锚点一致，辅助元素在允许清单内
- [ ] 资源规格（尺寸/格式/导入设置）达标
- [ ] 与相邻资产（UI 边框、角色比例）无冲突

## 五、协作请求

- 图形程序员 A：风格化后处理（CRT/镀铬）对美术输出的额外要求（如不透明分层）。
