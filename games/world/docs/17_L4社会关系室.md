# 17 · L4 社会关系室

> **一句话**：只加载 L4 社会能力，展示派系、关系、声望与社会动作；不依赖 L5 世界系统。

入口：

```text
http://127.0.0.1:8787/web/society.html
```

## 一、内容包

`data/demo.society/`：

```json
"kits": ["core", "interaction"]
```

社会内容：

- 2 个 faction：种植者 / 工程师
- 4 个 actor，各 2 人
- 初始关系：两两同盟、跨派系紧张
- `reputations.player = 0`
- 没有 rules / quests / dialogue / scripts / schedules / systems

## 二、L4 能力

- Faction membership / trust
- Relationship trust / affinity / interactions
- Player reputation
- Social actions：

```text
talk       trust +1  affinity +1  reputation +1  interactions +1
support    trust +2  affinity +2  reputation +2  target faction +2
thank      trust +1  affinity +1  reputation +1  target faction +1
propose    trust +3  affinity +2  reputation +2  target faction +3
mediate    trust +2  affinity +1  reputation +1  target faction +2
insult     trust -4  affinity -4  reputation -3  target faction -4
```

所有值 clamp 到 `-100…100`。

## 三、页面

- 左右两派系领地与成员；
- NPC 间关系线：正关系绿色、负关系红色，粗细随 trust；
- 点击 NPC 选中目标；
- 右侧 faction trust 条、目标关系、声望、社会动作按钮；
- 事件日志：`relationship_changed` / `reputation_changed` / `faction_trust_changed`；
- 独立性检查：L2 `0 schedules`、L3 `0 flags / 0 quests`、L5 `absent`。

## 四、本轮补齐

原有 L4：

- `faction.trust` 字段存在但从未改变；
- `support / thank / propose` 都只是 `record_talk`，效果相同。

本轮：

- 不同动作使用不同 trust/affinity/reputation 增量；
- 目标所属 faction 的 trust 随社会动作变化；
- 新增 `SocialEvent::Faction` → `faction_trust_changed`；
- `social_action` 同样受 `interaction_range` 限制；
- `PreviewWorld.social_action` / `TraceCommand::SocialAction` 可被 Web / trace / content-test 使用。

## 五、验证

```bash
cd games/world
./web/build.sh
node web/test_l4.cjs
./test/run_m1.sh
```

断言：

- 无 rules/quests/dialogue/scripts/schedules；
- `systems` 为空；
- talk 后 reputation +1、player-target relationship +1；
- support 后 faction trust +2；
- insult 后另一 faction trust -4、reputation 回落；
- 无 flags、无 L5。

## 六、边界

L4 仍不做：

- faction 之间的持续关系/外交；
- 群体行为/派系决策；
- 声望阈值对规则/交易的自动影响；
- 社会事件对 L5 系统的联动。

L5 内容在包中完全缺失，社会状态仍能建立和变化。
