## 四、M0 实际架构

```text
data/demo.harbor (JSON pack)
        │  worldc validate / build
        ▼
world-pack  ── Pack / schema / validation / hash
        │
        ▼
world-core  ── World / tick / command / event / rule / quest / schedule / save / replay
        │
        ├── world-host-headless（Runner，stdout JSON）
        ├── world-cli（worldc）
        ├── world-ffi（C ABI, cdylib）
        │       └── hosts/c/main.c
        └── world-script / world-script-wasm（QuickJS spike）
```

### 4.1 一次 tick 的 M0 实现

1. `World::advance(frame_dt_us)` 累加；每 `1/tick_hz` 秒执行一次 `tick_once()`。
2. `tick_once()`：应用上一阶段排队的命令 → 推进 tick/世界分钟 → 更新日程行为。
3. 命令路径：`interact`/`talk`/`pickup`/`give_item`/`set_flag`/`start_quest`/`toast`/`play_sound`/`emit`/`activate_zone`。
4. 规则：`on` + `target` + `when`（has_item/flag/quest_active）→ `then`/`else` 动作。
5. 任务：事件驱动进度（talk/item_acquired/flag_changed），完成时发事件并执行奖励。
6. 事件：`EventEnvelope { seq, tick, kind, source, data }`；存档/哈希只包含状态，不包含表现事件。
7. 存档：JSON 信封 + checksum；回放：trace + 每 60 tick 关键帧哈希。

### 4.2 C ABI

- 版本握手、`WorldConfig.struct_size`、`catch_unwind` 隔离 panic。
- 高频变换走 `WorldTransformPod` POD 数组；事件/命令/存档走 JSON 字节 + 两段式缓冲。
- 已实现函数见 [`world.h`](../code/include/world.h)；`worldc header` 可重新生成。
- C 宿主与 Headless 使用同一 trace、同一 tick 顺序，最终哈希一致。

## 七、与方案的偏差

| 项 | 方案 | M0 实际 | 原因 / 后续 |
| --- | --- | --- | --- |
| ECS | `bevy_ecs` | 确定性 slab 存储 | 避免同时验证边界与 ECS；M1 复核，见 [ADR-005](../plans/ADR-005-slab-store.md) |
| 规则 | TypeScript DSL | JSON 规则 + Rust 解释器 | M1 做 TS → 规范化 JSON 编译器，规则格式不变 |
| 脚本 | QuickJS `ScriptHost` | 仅 spike（能跑一条表达式） | M1 接入事件/命令/查询/预算 |
| C 头文件 | schema 生成 | `worldc header` 模板生成 | M1 改为 schema/IDL 生成并做签名比对 |
| 空间 | 导航/碰撞 | 仅 `Transform` + bounds 校验 | M1 做 `worldc bake nav` 与 Aabb 查询 |
| 场景流式 | Zone 休眠/加载握手 | 单 Zone 激活 | M1 做多 Zone + 资产依赖 |
| 存档 | 二进制/CBOR 评估 | JSON + checksum | M2 基准后决定 |

## 八、已知限制（M1 必须处理）

> M1 更新：3 已补 TS DSL/Web 编辑器；4 已有逻辑资产索引与 `world_zone_assets`；5 已有导航烘焙/A*
> 与移动碰撞；6 QuickJS 仍未接入正式规则。以下保留为 M0 当时的记录。

1. **NaN/次正规数未规范化**：当前 Demo 不触发；Det1 之前必须补哈希规范化。
2. **只验证了 macOS**：三平台 CI 工作流已加，但尚未推送运行。
3. **没有 TS DSL / Web 编辑器**：作者仍要写 JSON；M1 的核心交付。
4. **没有资产管线**：`world_zone_assets` 返回 `[]`；M1/M2 接逻辑资产 ID。
5. **没有导航/碰撞查询**：只有占位字段；M1 做 bake + Aabb/raycast。
6. **QuickJS 未接入规则**：规则仍由 Rust 解释；M1 才把脚本作为内容规则的可选执行器。
7. **ABI 头文件手写**：M1 生成，避免漂移。
8. **事件未持久化**：存档只存状态；黑匣子/事件日志是 M4。
9. **坏包 fixture 是整包副本**：6 个 fixture 各复制一份 Demo，Demo 改动后会漂移；M1 改为「mutation case + 临时目录生成」。

## 九、M1 建议入口（按依赖顺序）

1. `worldc` 的 TS DSL 编译器 + 类型生成（产出仍是当前 `Pack` JSON）。
2. Web 预览：wasm 内核 + 最小 2D/3D 视图 + 输入 → 同一 trace 哈希一致。
3. `worldc bake nav` + Aabb/raycast + 多 Zone 激活/资产依赖。
4. `ScriptHost` 正式接入 QuickJS（事件/命令/查询/预算/沙箱）。
5. 5k 实体基准 + 性能 profile；决定 `bevy_ecs` 是否替换 slab。
6. 三平台 CI 真正跑绿，再宣称 Det1。
