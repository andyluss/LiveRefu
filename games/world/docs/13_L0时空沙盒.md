# 13 · L0 时空沙盒

> **一句话**：只加载 `core` kit 的独立演示，证明固定 tick、Zone、A*、碰撞、路径跟随与哈希不依赖 L1–L5。

入口：

```text
http://127.0.0.1:8787/web/spacetime.html
```

## 一、为什么单独做

现有 Demo 大多同时使用 L1 交互、L2 日程、L3 任务等。即使 L0 工作，也很难从画面判断“这是不是上层在替它跑”。

L0 沙盒反过来：

- 内容包 `kits: ["core"]`；
- 没有 actors / items / rules / quests / dialogues / schedules / scripts；
- 没有 social / systems；
- 只有 Zone、导航网格、Prop collider、player 和固定 tick。

如果它仍能移动、碰撞、寻路、回放与计算哈希，就能说明 L0 不依赖上层。

## 二、内容包

`data/demo.spacetime/`：

```text
pack.json                     kits: ["core"]
world/spacetime.world.json    只有 player + seed + start_time
world/zones/spacetime.zone.json
world/props/*.prop.json       只有 collider，没有规则/视觉
world/nav/nav.spacetime.json  烘焙 A* 网格
loc/zh-CN.json
```

没有：

```text
world/actors/
world/items/
rules/
quests/
dialogue/
schedules/
scripts/
```

Prop 带一个空的/占位的 interactable 字段只是满足 schema；没有任何规则或脚本消费它。

## 三、画面

页面：

- Canvas 2D 俯视；
- 绘制 Zone 边界、1m 网格、nav blocked 格、Prop AABB、玩家、trail、A* 路径与目标；
- HUD 显示 tick、时钟、位置、速度、剩余 waypoints、哈希；
- 右侧「Independence Check」实时显示：
  - L1 `0 inv / 0 commands`
  - L2 `0 schedules / 0 actors`
  - L3 `0 flags / 0 quests`
  - L4 `absent`
  - L5 `absent`

操作：

```text
WASD            直接移动
点击地面         A* 寻路
演示 A* 路径     自动走一条跨障碍路径
Space            暂停/继续
R                重置世界
```

## 四、动态障碍

页面「移动障碍」按钮会通过：

```json
{"op":"move_prop","target":{...},"x":-8,"z":-2}
```

移动中央 pillar，并在同一 tick 内：

- 清除旧 AABB 覆盖的 nav 格；
- 标记新 AABB 覆盖的 nav 格；
- 把实时 `nav` 写回 preview state；
- 页面立即重绘 blocked 格。

这不是只动表现：A* 使用的是更新后的 nav。

## 五、实现边界

L0 只做：

- 固定 60Hz tick / 时钟；
- Zone 边界；
- 移动学 `speed / tick_hz`；
- 圆形玩家 vs AABB/圆形障碍；
- 烘焙 nav 的 4 邻接 A*；
- 路径跟随；
- 快照/哈希中的时空字段。

它不知道：

- 背包、门锁、对话；
- 日程、任务、规则、脚本；
- 社会关系、能源/天气。

页面上的 L1–L5 是**空内容**，不是被 L0 调用。

## 六、验证

```bash
cd games/world
./web/build.sh
node web/test_l0.cjs
./test/run_m1.sh
```

`web/test_l0.cjs` 断言：

- `kits == ["core"]`
- actors/items/rules/quests/dialogues/schedules/scripts 全部为空
- `social` / `systems` 为空
- 玩家初始 inventory 为空
- 场景中只有 player / prop
- `move_to` 后玩家沿路径移动
- reset 后 final hash 回到初始值

浏览器：

```text
2D / 2.5D / 3D / L0 四页 runtime PASS
```

## 七、它证明了什么

不能证明：

- L0 已经“完整物理引擎”（没有重力/跳跃/斜坡/连续碰撞）；
- L0 单独可以替代完整 World；
- 跨 CPU 逐位一致。

可以证明：

- L0 的 tick、空间、碰撞、A*、路径与哈希在**没有上层内容**时仍工作；
- 上层是可选内容/编排，不是 L0 的前置条件；
- 页面/测试可以直接观察 L0 状态，而不是透过 L3 任务或 L1 交互间接判断。
