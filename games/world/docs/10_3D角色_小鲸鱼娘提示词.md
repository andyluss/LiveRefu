## 一、公开资料与共识

社区把 DeepSeek 的鲸鱼形象拟人化为“鲸鱼娘 / 深海鲸鱼少女”。综合公开资料，较稳定的共识是：

- 蓝色长发，通常为深蓝到浅青的渐变；
- 鲸鱼鳍形状的耳鳍、鲸鱼尾鳍；
- 深蓝与白色为主的女仆风长裙/围裙；
- 聪明但懒，嘴甜、傲娇；被说胖会立刻反驳；
- 主食白米饭，把用户叫“鱼片”；
- 常见 Q 版/少女比例，头顶有呆毛，蓝眼睛。

## 二、可执行提示词（主提示词）

> 一位成年感的深海鲸鱼少女，原创 3D 角色，站姿展示。整体是深海蓝、月光青、珍珠白与少量暖金的高对比配色。她有一头从深海靛蓝过渡到月光青的长发，发梢像透明海水，层次分明；头顶一撮会微微晃动的呆毛，两侧是半透明的鲸鱼鳍状耳鳍。脸是精致的动漫风格，深海蓝眼睛，眼中有青色高光；表情是“聪明但懒得解释”的轻微傲娇，嘴角克制地上扬。她穿深蓝与白色相间的长裙式女仆装：白色围裙、金色细边、泡泡袖、束腰、层叠裙摆；背后有一条巨大的鲸鱼尾，尾鳍半透明、带青色发光边缘。配饰包括小鲸鱼尾发夹、珍珠纽扣、细金链，以及一颗悬浮的米粒/米饭碗意象（可选，不抢主体）。整体像从数据海面升起的守护者：优雅、聪明、略带慵懒，不是性感化手办，不是幼态化，不出现官方 logo。

## 三、视觉规格

### 3.1 比例与轮廓

| 项 | 规格 |
| --- | --- |
| 身高 | 约 1.62 m（展示尺度，非写实解剖） |
| 头身 | 约 1:6.5，动漫少女比例 |
| 剪影 | 大头 + 长裙 + 大尾鳍；正面看是 A 字裙，侧面看尾巴形成第二曲线 |
| 站姿 | 轻微 contrapposto，重心在右腿；左手抬起做“别催”的小手势 |
| 关键轮廓 | 头顶呆毛、双耳鳍、腰后鲸尾、裙摆外扩 |

### 3.2 色彩

| 名称 | Hex | 用途 |
| --- | --- | --- |
| 深海靛蓝 | `#071A33` | 发根、裙身主色、尾巴深色 |
| 海水蓝 | `#1E5D8C` | 发中段、布料中间调 |
| 月光青 | `#6FE7DC` | 发梢、耳鳍透光、尾巴发光边 |
| 珍珠白 | `#F4F1E8` | 围裙、领口、袖口 |
| 暖金 | `#D9A441` | 细边、纽扣、发夹、链子 |
| 眼睛深蓝 | `#123E66` | 虹膜底色 |
| 眼高光 | `#BFF8F1` | 虹膜高光与边缘光 |

### 3.3 头部

- 头：略扁的球体，下巴收窄；不要过度 Q 版。
- 眼：大而横向的动漫眼，深蓝虹膜、青色环、两个高光点；上眼线深靛蓝。
- 眉：细、平、略微下压，表达“懒但聪明”。
- 嘴：小、闭合、轻微上扬；不做夸张笑容。
- 鼻：极小的高光点，不建模写实鼻。
- 耳鳍：从耳侧向外后方展开的半透明鳍，3 根鳍条，边缘青色发光。
- 头发：
  - 发根深靛蓝，发中海水蓝，发梢月光青；
  - 前发分层，侧发到肩下，后发到腰；
  - 至少 20 组发束，避免“头盔感”；
  - 头顶 1 根呆毛，尾端分叉；
  - 发束有粗细变化和微卷。

### 3.4 服装

- 深蓝长裙式女仆装，裙长到小腿；A 字/钟形裙摆。
- 白色围裙从胸口到裙摆，带荷叶边。
- 白色泡泡袖 + 深蓝袖口 + 金色细边。
- 白色领口、深蓝领结、金色小鲸鱼尾胸针。
- 腰部束腰，背后大蝴蝶结（深蓝 + 白边）。
- 材质：深蓝哑光丝绒、白色棉麻、金色金属、珍珠纽扣；不要高反射塑料。

### 3.5 鲸鱼特征

- 尾：从腰后下方长出，先向下再向后弯，尾柄粗、尾鳍宽；尾鳍半透明，青色发光边。
- 耳鳍：左右对称但不完全一样，保持生物感。
- 背部可有一小片背鳍，但不要做成鱼人恐怖感。
- 尾和耳鳍是“身份标识”，必须比普通发饰更醒目。

### 3.6 配饰与道具

- 小鲸鱼尾发夹（金色 + 青宝石）。
- 珍珠纽扣、细金链。
- 可选：悬浮的白米饭碗/米粒，作为“主食”梗；不要遮挡脸。
- 不做官方 logo 胸牌。

## 四、3D 制作规格

- 交付：`web/models/deepseek-whale-girl.glb`
- 坐标：Y-up，脚底在 y=0，面朝 +Z 或 -Z 统一（展示页会旋转）。
- 尺度：1.6–1.7m。
- 预算：20k–60k triangles；≤8 个 PBR 材质。
- 网格分组命名：
  - `Body`、`Head`、`Hair_Root`、`Hair_Strands`、`EarFin_L/R`、`Tail_Root`、`Tail_Fin`、`Dress`、`Apron`、`Bow`、`Accessories`。
- 材质：
  - `MAT_Hair_Deep`、`MAT_Hair_Tip`、`MAT_Skin`、`MAT_Dress`、`MAT_White`、`MAT_Gold`、`MAT_Fin`（透明 + emission）、`MAT_Eye`。
- 展示动画（Three.js 侧）：
  - 尾巴缓慢左右摆动；
  - 发梢二级摆动；
  - 呼吸/轻微上下浮动；
  - 相机自动环绕 + 用户 OrbitControls；
  - 粒子气泡/米粒漂浮，不遮挡主体。
- 灯光：冷色主光 + 青色轮廓光 + 暖金补光；深色海面背景。
- 交付验收：
  - GLB 在 Three.js 中可加载；
  - 正面/侧面/背面都能读出“鲸鱼耳鳍 + 尾巴 + 女仆长裙”；
  - 不出现官方 logo；
  - 移动端可旋转/缩放，R-016 三态正常；
  - 不依赖外部 CDN。
