# 18 · L5 世界系统控制室

> **一句话**：包内只有 L5 systems 在运行，展示天气、光伏、风电、储能、水、AI 负载与五种能源策略。

入口：

```text
http://127.0.0.1:8787/web/systems.html
```

## 一、内容包

`data/demo.systems/`：

```json
"kits": ["core"],
"systems": {
  "solar_kw": 180,
  "wind_kw": 120,
  "battery_kwh": 240,
  "initial_battery_kwh": 60,
  "water_m3": 600,
  "initial_water_m3": 30,
  "ai_count": 4,
  "base_load_kw": 30,
  "policy": "balance"
}
```

没有 actors / items / rules / quests / dialogue / scripts / schedules / social。

## 二、L5 能力

- 天气：clear / breezy / cloudy / rain，按固定 tick 周期切换；
- 日照因子：按世界时钟计算光伏；
- 风电：按天气因子计算；
- 负载：base + AI + policy；
- 储能：`battery += net × dt / 3600`；
- 水：政策消耗与降雨补给按秒速率积分；
- 策略：balance / irrigate / compute / profit / commons；
- 低量警告：battery / water < 10% 发 `system_warning`。

## 三、本轮修正

之前：

- 每个 tick 都 `battery += net / 3600`，相当于放慢 60 倍；
- 水只按每 tick 固定量变化，不受策略影响；
- AI 负载只有基础值，策略没有影响；
- 没有低量警告。

现在：

- 正确 60Hz 时间步：`net × (1/60) / 3600`；
- irrigate / commons / compute / profit 有不同水耗；
- compute 提高 AI 负载；
- battery/water 低于 10% 发一次 `system_warning`，回到 20% 后重置；
- `energy_updated` 增加 `net_kw / battery_pct / water_pct / ai_load_kw / daylight`；
- SystemsDef 增加可选 `initial_battery_kwh / initial_water_m3`；
- 新增 `PreviewWorld.set_system_policy` 与 `TraceCommand::SetSystemPolicy`。

## 四、页面

- 左：L5 契约与 L1–L4 为空的独立性检查；
- 中：微电网示意图（太阳/光伏/风机/电池/水罐/AI/负载）；
- 右：系统数值、资源条、策略按钮、事件；
- 时间加速（×1 / ×60 / ×300）仍按固定 tick 推演；
- 策略切换会立即反映到负载、水耗与 AI 负载。

## 五、验证

```bash
cd games/world
./web/build.sh
node web/test_l5.cjs
./test/run_m1.sh
```

断言：

- 只有 systems，无 L1–L4 内容；
- 初始水低触发 `system_warning`；
- `compute` 提高 load；
- `irrigate` 降低 water；
- battery 不为负；
- 没有 social。

## 六、边界

- 天气是确定性周期，不是真实气象；
- 没有天气预报/季节；
- 没有电网故障/黑市交易；
- 没有把资源状态反馈到 L1–L4 的规则；
- 数值是演示级，不是工程级能源模型。
