# 15 · L2 行为实验室

> **一句话**：只加载 `core + agency`，展示“世界分钟 → behavior → target → A* 路径 → 逐 tick 移动”，不依赖 L3–L5。

入口：

```text
http://127.0.0.1:8787/web/agency.html
```

## 一、内容包

`data/demo.agency/`：

```json
"kits": ["core", "agency"]
```

- 3 个 Actor：worker / courier / guard
- 3 个 schedule：早班休息 → 工作 → 休息；信使配送 → 取件 → 休息；守卫巡逻
- 每个 schedule entry 带 `target` X/Z
- 没有 rules / quests / dialogue / scripts / social / systems

## 二、L2 行为链

```text
clock_minutes
  → schedule entry
  → behavior
  → target
  → L0 A* path
  → npc_paths
  → 逐 tick 移动
```

页面 HUD 显示：

- 当前时钟 / tick；
- 每个 actor 的 behavior；
- 活跃路径数；
- schedule 时间窗与目标；
- `schedule_changed` 事件。

## 三、时间控制

- 默认 `SIM ×1`；
- `×60`：每帧推进 60 个固定 tick，快速观察换班；
- `×300`：更快；
- “跳到 08:00” / “跳到 09:00”：按固定 tick 快进；
- 暂停/重置；
- 加速不改变单 tick 结果。

## 四、独立性

页面实时显示：

```text
L1  0 commands / 0 inventory
L3  0 flags / 0 quests
L4  absent
L5  absent
```

L2 只依赖 L0 的时钟/空间/A*/移动，不依赖 L1 交互、L3 叙事、L4 社会、L5 系统。

## 五、验证

```bash
cd games/world
./web/build.sh
node web/test_l2.cjs
```

`web/test_l2.cjs` 断言：

- kits 含 core / agency；
- rules/quests/dialogue/scripts 为空；
- social/systems 为空；
- 07:55 worker = rest；
- 300 tick 后 08:00 worker = work；
- worker 已移动并存在 `npc_paths.worker`；
- 收到 `schedule_changed`；
- L3–L5 仍为空。

## 六、边界

L2 仍不做：

- 需求/效用/记忆（M3 活 NPC）；
- 行为失败重试/避让；
- 对话/任务（L3）；
- 社会关系（L4）；
- 世界系统（L5）。

当前是“日程驱动的行为”，不是完整活 NPC。
